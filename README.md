# PLC Hackathon 2026 - Assignments

This repository holds the project archives for two PLC hackathon assignments.

> **Note:** The vendor installers are **not included** in this repository. Obtain them from the respective vendor (Siemens / Schneider Electric) or from the hackathon organizers.

## Assignment 1 - Siemens TIA Portal

- **Project file:** [`siemens-tia-portal/PLC_hackathon_2026_V21.zap21`](siemens-tia-portal/PLC_hackathon_2026_V21.zap21) (TIA Portal project archive)
- **Required software:**
  - Siemens TIA Portal **V21**
    - STEP 7 Professional
    - WinCC Basic / Comfort / Advanced
  - Siemens Automation License Manager **V6.2 SP5**
- **Opening:** In TIA Portal V21, use *Project > Retrieve* and select the `.zap21` file.

## Assignment 2 - Schneider Electric EcoStruxure Machine Expert (EESTEC)

- **Project file:** [`schneider-machine-expert/EESTEC_hackaton_students.projectarchive.zip`](schneider-machine-expert/EESTEC_hackaton_students.projectarchive.zip) (Machine Expert project archive; TM241CEC24R PLC + HMI)
- **Required software:**
  - Schneider Electric **EcoStruxure Machine Expert**, installed via the **ESEMACS10** installer (Schneider Electric Software Installer)
  - A valid (floating) license, per the installation guide supplied with the installer
- **Opening:** Extract the `.zip` if needed, then open the project archive in EcoStruxure Machine Expert.
