27.1.2 Setting Up the Printer

  1. In the Navigator window's Project tab, right-click the Target node and select Properties.

  1. In the Property Inspector, set Printer to Enabled.

When the Printer property is set to Enabled, Vijeo Designer Editor generates the _Printer and _Form variables, and assigns them to the printer. For more information, see Section 27.1.4, Printer and Form Variables.

  1. From the Printer Type drop down menu, select the printer type you want to use. To find the printer supported by your target, see Appendix 5, Hardware Specifications.

To print real-time alarm messages, alarm batches, and forms, set the printer type to Text (ASCII), PCL 3/5 or Epson ESC-P. When you set the printer type to Text (ASCII), you will not be able to print snapshots in the same project. You will only be able to print snapshots when the printer type is set to PCL3/5 or Epson ESC-P.

  1. If you set the printer type to PCL 3/5 to print forms, you will only be able to print text without any text or font formatting.

  1. In the Printer Setup property for the target, click to display the Printer Setup dialog box. For more information on the Printer Setup dialog box, see Section 27.1.3, Defining Printer Settings.
