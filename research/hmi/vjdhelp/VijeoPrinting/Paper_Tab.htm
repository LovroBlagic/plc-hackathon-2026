27.1.3.2 Paper Tab

The table below describes the Paper features for all printers types except HP PCL3. HP PCL3 printers do not support Landscape printing.

Property

Description

Paper Size

Select the paper size that is compatible with your printer. See your printer's user manual for more information.

Margins

Margins provide blank space around the top edge and the bottom edge of the page. Define the margins in millimeters.

Orientation

Two options are provided for print orientation:

  • Portrait

  • Landscape

 

HP PCL3 Printers

Property

Description

Output

You can choose Color printing or Black Ink Only (Dithered) for black and white/gray scale printing.
