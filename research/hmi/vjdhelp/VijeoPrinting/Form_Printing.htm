27.3 Working with Forms

Vijeo Designer Form feature allows you to create reports, receipts, and forms that you may want to print or e-mail to recipients at runtime.

On a form, you can use the set of fonts available for each system language you selected. You can type in all the available fonts, but you can only print the selected system language. For example, if you selected English as the system language and Hebrew is an available font, you can type in Hebrew but you can only print English.

 

To set up form printing, you will need to:

  1. Set up the text printer, and enter printer control codes.

  • You can set up other printers besides the text printer. However, if you use a printer that is not a text printer, certain formatting features will be disabled, such as bold, italics, and underline.

  • If you want to enable formatting features in forms, you must enter printer control codes, such as bold, italics, and user custom codes.

  1. Create a form or report.

  2. Trigger form printing.

 

To set up form e-mailing, you will need to:

  1. Set up the E-mail server and define e-mail recipients - see Section 4.14.1, Setting up E-mail.

  2. Create a form or report.

  3. Trigger form e-mailing - see Section 4.14.3, Triggering E-mails.

 

For more information on how to delete, copy, or move forms, see Section 27.3.3, Cutting, Copying, and Pasting Forms.

For more information on how to add a data display or message display to a form, see Section 27.3.4, Adding a Data Display or Message Display.

 

Data Quality Handling in Form

At runtime, if data quality is unreliable or unknown, the data display objects on the form will display the data quality character you defined in the printer settings. If the variable width is not defined for the variable with bad quality, the user-defined data quality characters will be displayed once. If the variable width is defined for the variable with bad quality, the user-defined data quality characters will be repeated to fill up the width of the variable.

When form printing on a non-text printer and data quality is bad, a data quality character that displays is a question mark (?). For example, if a numeric display object is set with six digits and the data quality is bad, the form will display six question marks for the object.
