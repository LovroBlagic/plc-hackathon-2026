27.1.1 Selecting a Printer

You need to select the printer you want to use with the target machine and set up the printer in Vijeo Designer. The types of printers you can use depend on the target machine. For more information on printer types and finding a compatible printer, see Appendix 5, Hardware Specifications.

  • Not all printers support color printing. The following printers support color printing:

  • Windows Default Printer

  • HP PCL3

  • See Appendix 5, Hardware Specifications for your target's supported printing connection.

  • To prevent the bar code from printing incorrectly on an Epson ESC/POS printer, you should not put the bar code on the same line as other objects. You can put a tab code on the same line as a bar code as it does not affect the printing.

  • Printers using ESC/P2 may not always be backwards compatible with the older ESC/P format.

27.1.1.1 Finding a Compatible Printer

Before you buy a new printer, check to see that it is compatible with Vijeo Designer.

  1. Find the printer manufacturer's web site on the World Wide Web.

  2. Search the products pages for the specific printer you are interested in buying.

  3. Find the specifications page for that printer. Some web sites may have a general or abbreviated specifications page with a link to more detailed specifications on another page. Open the page with the more detailed specifications.

  4. On the specifications page, search for the words, "printer language," "printing language," or "emulation mode."

  5. Check that the printer language matches one of the printer types listed in the table above. If it does not, it may not be compatible with Vijeo Designer.

  • If you cannot find the printer language information on the manufacturer's web site, contact the manufacturer directly to ensure the printer is compatible with Vijeo Designer.
