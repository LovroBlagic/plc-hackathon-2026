27.1 About Printing

Vijeo Designer Printing

The following features print from Vijeo Designer.

  • Reports - You can print these types of reports:

  • Panel Reports

  • Action Reports

  • Variable Reports

  • Target Function Key Labels
    On XBTGK target machines, you can print labels to identify the operations that the target function key will run. You can use label templates to create function key labels and then print them. Insert the printed labels under the target function keys on the XBTGK target machine. For more information, see Section 27.2, Customizing and Printing Target Function Key Labels.

Run-time Printing

UNINTENDED EQUIPMENT OPERATION

When you connect one or more USB devices to a target machine via a USB hub, you must use a USB hub with external power supply.

Failure to follow these instructions can result in death, serious injury, or equipment damage.

 

The following features print from your target machine during runtime.

  • Alarm and Event Messages
    In Vijeo-Designer Runtime, you can print alarm messages and screen and video snapshots. For details, see Section 16.3.5, Printing Alarm and Event Messages, and Section 19.2.2, Printing Screen Snapshots. For a list of supported printers, see Appendix 5, Hardware Specifications.

  • Snapshots
    Snapshots allow you to capture a copy of the target machine's screen during run time or capture a frame of the Video Display and print out the snapshot on a printer connected to the target machine. For information on printing Video Snapshots, see Section 19.1.6.3, Printing Video Snapshots. For information on printing Screen Snapshots, see Section 19.2.2, Printing Screen Snapshots.

  • Screen snapshot printing is not supported on Text (ASCII) printers.

  • Forms
    Vijeo-Designer's form printing feature allows you to create reports, receipts, and forms that you may want to print at runtime. For more information, see Section 27.3, Working with Forms.
