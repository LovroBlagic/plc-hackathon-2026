27.1.3.3 Printer Control Codes Tab

This section describes the Printer Control Codes tab in the Printer Setup dialog box. It also describes how to import printer control codes previously defined and saved in a file, and how to export printer control codes you have defined.

For Epson ESC-POS compatible and HP PCL3 compatible printers, you can find printer control codes in the folder where you installed Vijeo Designer in /Vijeo-Frame/PrinterDefinitions.

  • When a PCL3 printer is selected, it is in image mode. If the character in the font does not have full length, the printing result will be a dotted line. A printer in text mode will provide you with better printing results.

The table below describes the properties in the Printer Control Codes tab. To print forms to a text printer, you must enter printer control codes. To look up and enter specific printer control codes, refer to the user manual that accompanies your text printer.

Property

Description

Standard Codes (Hex)

Provides some standard text and font formatting options, such as bold and italic. Consult the printer's user manual to obtain the printer control codes.

On Code

Enter the printer control code that will turn on this formatting. You can enter up to 50 characters.

Off Code

Enter the printer control code that will turn off this formatting. You can enter up to 50 characters.

Form Control (Hex)

Provides some standard paragraph and page formatting options, such as tab, carriage return and form feed. Consult the printer's user manual to obtain the printer control codes.

[Tab]

Enter the printer control code for a tab space. You can enter up to 50 characters.

[CR]

Enter the printer control code for a carriage return. You can enter up to 50 characters.

[FF]

Enter the printer control code for a form feed or page break. You can enter up to 50 characters.

Custom Codes (Hex)

Allows you to define custom formatting options as needed. You can enter up to 20 custom codes, two custom fonts, and a barcode. Consult the printer's user manual to obtain the printer control codes.

Code #

Provides a numeric identifier for your formatting option.

OnCode

Enter the printer control code to turn on the formatting option. You can enter up to 50 characters.

OffCode

Enter the printer control code to turn off the formatting option. You can enter up to 50 characters.

Description

Enter a description of the custom printer control code. You can enter up to 50 characters.

Data Quality Char(s)

Enter the character(s) to be displayed on the printout when a variable produces bad data quality in a Data Display object on the form. You can enter up to three characters. Each character must be a printable ASCII character.

Width (in characters)

Enter the width, from 0 to 9999, of the paper that the text will be printed on. The Form Editor will display a dotted line to indicate the width of the paper. If this property is set to 0, the line will not display in the Form Editor.

 

Importing and Exporting Printer Control Codes

To import printer control codes:

  • Click Import to select a file that contains printer control codes. The default file type is Printer Definition Files (.VJDPrintDef). The printer control codes will be copied to the properties in the Printer Control Codes tab.

To export printer control codes:

  • Click Export to create a file that contains the printer control codes you have defined. The printer control codes will be copied to the file. The default file type is Printer Definition Files (.VJDPrintDef).
