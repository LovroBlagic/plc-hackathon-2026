27.2 Customizing and Printing Target Function Key Labels

Label templates are available for target machines that support target function key label design. For more information on which target machines support label design, see Appendix 5, Hardware Specifications. After you finish creating your labels, you can print them.

To customize function key labels:

  1. In Target properties, expand the FunctionKeys property.

  2. In the Labels property, click the ellipsis icon.

  3. In the dialog box that opens, select one of the following:

  4. Create a new label. Select the label template for your target type, which opens in Microsoft Word, and then customize your labels.

  5. Open an existing label. In the file browser, select the label you want to open.

  1. Print the labels.
