27.3.1 Creating a Form or Report

You can create up to 50 forms for each target. The maximum size of a form or report is 200 characters wide by 300 lines. You can enter any number of objects and data in a form, as long as they do not exceed the form's maximum size. To create a form or report:

  1. In the Navigator window, right-click the Forms & Reports node, and select New Form.

You have created a new form. The Property Inspector for the new form is displayed with settings in the name and FormID properties. The Form Editor is also displayed.

  1. Create the new form in the Form Editor.

To change the appearance of text characters, such as font type, font size, or color, use the icons in the Form Editor toolbar or printer control codes. The text formatting options available depend on your printer's capabilities. For more information on how to set up printer control codes, see Section 27.1.3.3, Printer Control Codes Tab.

The following table describes each icon in the Form Editor toolbar:

Icon

Description

Select or manipulate objects.

Create a text object.

You can use the right-click menu to edit, move, copy and paste, and delete the text object.

Select and create a numeric, string, date or time data display object. For more information, see Section 27.3.4, Adding a Data Display or Message Display.

Create a message display. For more information, see Section 27.3.4, Adding a Data Display or Message Display.

Draw a horizontal line, vertical line, double horizontal line, double vertical line, rectangle, double line rectangle, table, or double line table.

If you are drawing a table, the Edit Table dialog box opens so you can specify the number of rows and columns you want in the table. To resize a row or column, click the row or column divider and drag it to create the size you want. Use the right-click menu to edit the table, such as inserting a new column or inserting a new row.

To set bold, italics, or underline to a text, data display, or message display object, select the object and press the formatting you want to apply to the object. If a printer control code for any of these text formatting properties was not entered, the associated toolbar button would be disabled.

If you set bold, italics, or underline without selecting an object, the formatting will apply to all subsequent objects.

  • You must define the bold, italics, and underline printer codes for the text printer. If the printer codes are not defined, these formatting features will be disabled.

You can select from either of these options:

  • Overwrite Text in All Languages to overwrite the text in all languages with the text string in the current language.

  • Copy Text to Empty Languages to copy the text from the current language to text objects of other languages that are empty.

The selected option  would apply to all the text objects on the form.

  1. When you use Overwrite Text in All Languages, the text string in the current language may be longer than the text string used in another language. The text object may stretch and overlap an adjacent text object. In this case, when the project is validated in editor, a warning message displays indicating the text is overlapped in form printing.

 

Add the printer control code for a form feed to the form.

  • You must define the form feed printer code for the text printer. If this printer code is not defined, the form feed feature will be disabled.

 

Add the printer control code for a tab to the form.

  • You must define the tab printer code for the text printer. If this printer code is not defined, the tab feature will be disabled.

Select the custom formatting option as defined in the Printer Control Codes tab in the Printer Setup dialog box. If a description was added for each code, it will display beside the printer code. A code is grayed out if a printer control code was not defined in the Printer Setup dialog box.

A user code with both the OnCode and OffCode defined are only enabled if an object has been selected. You can only apply a user code with both OnCode and OffCode defined to an object that has been selected.

You can apply a user code with only an OnCode defined by clicking at a location on the form.

  1. If you want to apply bold, underline, or italic features to your text, select a text object and apply the format. All text in the text object will be formatted.

  2. If you want to apply bold, underline, or italic features only to selected text in a sentence, you would have to break the sentence into multiple text objects and apply the formatting to the text.

  3. On a form, you can only use the set of fonts available for the system language. For example, if the system language is English, you can only use the fonts available for the English system language.

  1. To make changes to the objects you create, select the object and use the right-click menu.
