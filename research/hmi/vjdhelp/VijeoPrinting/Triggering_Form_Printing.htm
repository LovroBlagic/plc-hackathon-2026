27.3.2  Triggering Form Printing

On the panel, you can set up an operation to trigger form printing at runtime. To set up an operation to print a form:

  1. Create one of the following:

    • Action

    • Switch

    • Selector

    • Function Key.

  1. Define a Print Form operation for your object. For more information, see Section 9.5.17, Print Form Operations.

  2. At runtime, print the form using the action, switch, selector, or function key set with the Print Form operation.
