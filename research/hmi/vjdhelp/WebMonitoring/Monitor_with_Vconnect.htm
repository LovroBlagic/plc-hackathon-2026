23.3 Monitoring Target Machines with EcoStruxure Secure Connect Advisor

This section describes how you can display or operate on a personal computer or smart device, the screens of display units in remote locations, over the Internet with a secure system to prevent unauthorized access from external sources.

EcoStruxure Secure Connect Advisor

Even without a VPN router, as long as you have an Internet connection, you can use EcoStruxure Secure Connect Advisor to create a secure system. EcoStruxure Secure Connect Advisor is structured to connect display units on the work site (SiteManager), with computers or smart devices in the office (LinkManager), over a server (GateManager).  For more information, refer to Vijeo Connect User Guide.

  • GateManager:
    Server for creating an encrypted connection between display units on the work site (SiteManager) and personal computers or smart devices in the office (LinkManager). You can use GateManager to check the network connection status of SiteManager and LinkManager. The GateManager Administrator registers the SiteManager and LinkManager and allows access to the network.

  • SiteManager:
    Display unit having SiteManager Embedded enabled is called SiteManager. Setup for accessing the network is handled from the software; SiteManager Embedded.

  • LinkManager:
    Software installed on computers. This software allows remote access to SiteManager and/or devices represented by agents on the SiteManager. Setup for accessing the network is handled using the LinkManager or LinkManager Mobile software. For remote monitoring and operation, you can use the following software and features to act as the LinkManager. Different configurations are possible depending on the package purchased. Refer to the license that comes with each package:

  • Webgate

  • SoMachine

  • Vijeo Designer

  • Vijeo Design'Air

For more information about setting up EcoStruxure Secure Connect Advisor on target machines, see 26.3.1.3, Setting Up the Network for EcoStruxure Secure Connect Advisor Usage.

See Appendix.5, Hardware Specifications, for the list of target machines that support EcoStruxure Secure Connect Advisor.
