23.2.9.2 Viewing Project and Target Information

On the web server, you can view project and target information. For example, you can get network information for the target by displaying the subnet mask or find out what project is running by viewing the project parameters, or figure out how much memory is available by viewing the memory parameters.

In the main menu of the Web Gate Environment, select the Diagnostics tab to view the following information:

  • Project, to display the parameters of the project such as panel type, Project Name, Target Name, Editor Version, and Runtime Version.

  • Ethernet and TCP/IP, to display TCP/IP parameters for the target such as IP Address, Subnet Mask, and Default Gateway, and Ethernet parameters for the target such as MAC Address and Ethernet Frame Format.

  • Memory to display the amount of DRAM memory available and the total amount of DRAM memory used.
