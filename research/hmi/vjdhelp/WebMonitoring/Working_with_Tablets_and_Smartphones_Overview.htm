23.1 Working with Tablets and Smartphones

This chapter describes the following features that enable you to use the Tablet/Smartphone to access Vijeo Designer user applications on target machines over a WiFi wireless, 3G, 4G, or LTE network:

  • Vijeo Design'Air Plus – This feature enables an operator to access a Vijeo Designer user application and present the data using the advanced graphic capabilities on a Tablet/Smartphone. The operator can also monitor and modify values in the user application on the Tablet/Smartphone. For more information on the feature's capabilities, see Section 23.1.1, Vijeo Design'Air Plus.

  • Vijeo Design'Air – This feature enables an operator to view, control, and interact with the target machine at run time using a Tablet/Smartphone. For more information, see Section 23.1.2, Vijeo Design'Air.

Using Tablet/Smartphone Gestures in Vijeo Design'Air and Vijeo Design'Air Plus

The tablet/smartphone supports the following gestures to interact with the Vijeo Designer user application:

  • Tap to click – Tap with one finger (a press and a release) to click.

  • Pinch to zoom and move around – Zoom into and out of the view of the application and move it around, by holding down two fingers in a pinch gesture and moving around the screen. You must zoom into the view of the application before you can move the application around the screen.

  • Swipe to navigate – Flip through panels in the application, by using one finger in a swipe motion. You can only swipe to the next or previous panel if the next or previous panel number exists and the panel numbers are in sequential order. You must zoom out of the view of the application before you can swipe.

  • One-finger drag – Hold down one finger and move the application around the screen. You must zoom into the view of the application before you can move the application around.

  • iOS Only. Three-finger swipe - Use three fingers and swipe left to right to return to the main window.
