23.2.5.2 Installing Web Gate Client Files

Web Gate requires client files to be installed on the client PC. In most cases, Web Gate Client files automatically install when a client PC connects through Web Gate to a target. However, you must manually install the Web Gate Client file on the client PC if:

  • Target does not support CF Cards/SD Cards

-or-

  • Target’s Web Server data location is set to Main Drive

Follow the instructions below to manually install the Web Get Client Files. For more information on the Web Server data location setting, see Appendix 5.11.1, Types of Data Locations. To see if your target supports CF cards/SD Cards, see Appendix 5, Hardware Specifications.

 

To manually install Web Gate Client Files onto a client computer:

  1. From the Vijeo Designer Installation DVD, run Web_Gate_Client_Files.exe from:
    <DVD Root>\Tools\Web Gate Client Files\Web_Gate_Client_Files.exe

  2. Follow the Web Gate Client Files Installation wizard to install the client files onto the client computer.

  • If you do not have the Vijeo Designer installation DVD, contact the Customer Support Center.
