23.1.1.1 Setting Up a Tablet/Smartphone Project

This section describes how to set up a tablet/smartphone project in Vijeo Designer.

  1. In Vijeo Designer, create a new project. For more information, see Section 4.3.2, Creating a New Project.

  2. Set up the target machine. For more information, see Section 4.5, Setting Up a Target. This is the target machine you want your tablet/smartphone project to communicate with.

  3. On the target machine, set up the variables and alarms that the target machine can share with the tablet/smartphone.

  4. Data sharing on the target machine – In the Target properties, enable Data Sharing and set the Port.

  5. Data sharing with variables – In the Variable properties, set Sharing to Read Only or Read/Write.

  6. Data sharing with alarms – In the Alarm Group properties, set Sharing to Read/Write.

For more information, see Section 22.1, Sharing Data Between Tablets, Smartphones, and Target Machines.

  1. Add a tablet/smartphone target. For more information, see Section 4.5.2.1, Adding a Target. In the Create New Target dialog box, set the Target Type to Tablets and Smartphones, set the Model to Android, and then specify the resolution.

  2. Associate the tablet/smartphone with the target machine. In the Target properties for the target machine, expand Remote Management:

  1. In the Vijeo Design'Air Plus property, select the tablet/smartphone project you want to download.

  2. Set Target Discovery to Enabled.

    1. At run time, the target machine only allows one instance of Vijeo Design'Air or Vijeo Design'Air Plus to access its data at a given time. For example, if Vijeo Design'Air Plus has an active data sharing connection to the target machine, Vijeo Design'Air cannot establish a remote connection. If Vijeo Design'Air has a remote connection established, Vijeo Design'Air Plus can still download and launch the project, but it cannot share data with the target machine. To view or manage remote connections at run time, see sections Vijeo Design'Air Plus System Variables and Vijeo Design'Air System Variables.

  1. If you want to set up security so that at run time only authorized users can transfer the application from the target machine to the tablet/smartphone, see Vijeo Design'Air Plus Safety and Security.

  1. Design the panel for the tablet/smartphone. For more information on the shapes, parts, and Toolchest parts you can create on tablet/smartphone panels, see Section 23.1.1.2, Drawing Graphics on a Tablet/Smartphone Panel.

  1. When you design your panel, keep in mind that the panel design will be slightly resized when it displays at run time to accommodate the task bar that displays on the tablet screen. However, no distortion of images should occur since the panel preserves the aspect ratio during the resize. If you do not want the panel to resize, specify a Custom resolution for the tablet and subtract the size of the task bar.

  1. Download the project to the target machine. For more information, see Section 25.6, Downloading the Project.

Once the download is completed, the tablet/smartphone can download the project from the target machine. For more information, see Section 23.1.1.3, Working in Vijeo Design'Air Plus.

 

  • Changing the display language is not supported on the tablet/smartphone. The tablet/smartphone displays the default language only. If you want to display a different language on a tablet/smartphone application, from the Vijeo Designer editor, select a different default language then download the project again. The next time you view the application from your tablet/smartphone, it will display the selected language.

 

Vijeo Design'Air Plus Safety and Security

You can control access to target machines by requiring Vijeo Design'Air Plus users to provide authentication for transferring the project to tablet/smartphone or for launching the project. You can also secure the variables that run operations from unauthorized or unintended access by setting their properties to Read Only.

  • When designing a project for Vijeo Design'Air Plus, carefully consider the potential of accidental touches on objects that run operations. Apply security to prevent unauthorized access. You must inform and warn the operators of hazards related to operating machinery remotely. For more information on how to secure the target machines and variables, see Section 4.8, Setting up Security Protection for Targets and Projects and Section 6.2.3, Variable Properties.

  1. Expand the Environment node and click Security.

  2. In the Property Inspector, for Vijeo Design'Air Plus Security, select Use Security.  

  3. In the Security editor, in the Vijeo Design'Air Plus column for the specific user group, select Read/Write.

At run time, the Vijeo Design'Air Plus operator must provide a valid user name and password to transfer the project from the target machine to the tablet/smartphone or to launch the project.

 

Vijeo Design'Air Plus System Variables

There are two system variables for managing a connection between Vijeo Design'Air Plus application and a target machine:

  • _AirPlus.Connections: Indicates the number of Vijeo Design'Air Plus clients connected to a target machine.

  • _AirPlus.DisableConnections: Controls access between Vijeo Design'Air Plus client and the target machine. When the value of this variable is set to TRUE (i.e., 1), all active connections between Vijeo Design'Air Plus clients and the target machine are dropped, and no new connections are allowed. To control the data sharing connection at run time, you can use a method, such as a switch or an action, to toggle the value of this variable.
