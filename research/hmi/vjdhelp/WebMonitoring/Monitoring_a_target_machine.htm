23.2.6 Connecting to Web Gate

To access a target machine from a remote PC, the remote PC must meet the requirements listed in Section 23.2.5, Setting up a Remote PC to use Web Gate.

To connect a remote PC to a target:

  1. Start Runtime on the target machine.

  2. Start the browser on the remote PC.

  3. In the browsers's address bar, enter the IP address of the target machine.

Example 1

When Web Gate uses 80 (default) as its port number:
http://192.168.0.2

Example 2

When Web Gate uses a non-default port number (such as 800):
http://192.168.0.2:800

  • The Web Gate server cannot use port number 8000, which is reserved.

  • The Web Gate server cannot use port numbers that are used for other Vijeo Designer features or for protocols. For more information, see Section 5.8.6, Preventing Port Number Conflicts.

The browser connects to the target, and the Web Gate environment displays in the browser. For more information, see Section 23.2.7, Web Gate Environment.

  • To connect to a Runtime running on the same PC as the Web Gate client, type http://127.0.0.1 into the Internet Explorer address field.
