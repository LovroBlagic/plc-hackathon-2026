23.1.2.1 Setting Up Vijeo Design'Air Server

To enable Vijeo Design'Air access:

  1. In Navigator window's Project tab, click the Target node.

  2. In the Property Inspector, expand the Remote Management node, and then Vijeo Design'Air node.

  3. Define the Remote Management property settings as described in the following table:

    Property

    Description

    Vijeo Design'Air

    Select Enabled to allow the Vijeo Design'Air client access to the target machine (the server).

    1. At run time, the target machine only allows one instance of Vijeo Design'Air or Vijeo Design'Air Plus to access its data at a given time. For example, if Vijeo Design'Air Plus has an active data sharing connection to the target machine, Vijeo Design'Air cannot establish a remote connection. If Vijeo Design'Air has a remote connection established, Vijeo Design'Air Plus can still download and launch the project, but it cannot share data with the target machine. To view or manage remote connections at run time, see sections Vijeo Design'Air Plus System Variables and Vijeo Design'Air System Variables.

    Port

    Available when VijeoDesign'Air is Enabled, enter the port number used by Vijeo Design'Air Application.  Default value for the port number is 6002. You can set the port to any value within the standard port range (1000 to 65535).

    Thumbnail Icon

    Select to assign a thumbnail icon to the Vijeo Design'Air server so you can differentiate between projects on the network. For more information, see Vijeo Design'Air Server Thumbnail Icon.

    Target Discovery

    Select Enabled so the Vijeo Design'Air client can detect the target machine (the server) on the network.

  4. Define the security settings for the Vijeo Design'Air server. For more information, see Vijeo Design'Air Server Security.

  5. Save and validate the project.

  6. Download the project to the target machine. The server, downloaded to the target machine as part of Vijeo Designer Runtime files, runs when the target machine starts up.

    Vijeo Designer Runtime opens on all target machines. With the exception of iPC target machines, Vijeo Designer Runtime takes up the entire panel display of the target machine. On iPCs, Vijeo Designer sends an image of the entire primary display from the target machine to the Vijeo Design'Air client, allowing you to interact with other application windows rather than just Vijeo Designer Runtime.

The following describes the scenarios for the Remote Management settings:

Vijeo Design'Air

Target Discovery

Description

Disabled

Disabled

The user cannot access the target machine using the Vijeo Design'Air client and the target machine (the server) cannot be detected on the network.

Enabled

Disabled

The user can access the target machine using the Vijeo Design'Air. However, the Vijeo Design'Air client cannot detect the target machine (the server) automatically. The user needs to manually enter the target machine's IP address and port number in order to connect to the target machine using the Vijeo Design'Air client.

Enabled

Enabled

The Vijeo Design'Air client can automatically detect the target machine and the user can access the target machine using the Vijeo Design'Air client.

 

Vijeo Design'Air Server Thumbnail Icon

You can select a base panel in your project as the thumbnail icon for the Vijeo Design'Air server. For example, you can use this feature to differentiate between various Vijeo Design'Air servers detected on a tablet or smartphone at run time. The thumbnail icon is the base panel's image scaled down to 100x100 pixels while preserving its aspect ratio.

To select a thumbnail icon:

  1. In Navigator window's Project tab, click the Target node.

  2. In the Property Inspector, expand the Remote Management node, and then Vijeo Design'Air node.

  3. Select Thumbnail Icon check box and click the ellipsis.

  4. In the Panel List dialog box, select a Base panel and click OK.

At run time, Vijeo Design'Air client displays a thumbnail icon of the selected Base panel next to the target machine's information. If you do not select a thumbnail icon at build time, the Schneider Electric's logo will be displayed instead.

  • You can only select base panels for thumbnail icons.

  • Each target machine can only have one thumbnail icon.
