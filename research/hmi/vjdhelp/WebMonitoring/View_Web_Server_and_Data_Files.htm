23.2.9.3 Viewing Web Server and Data Files

The file viewer feature in the web server allows you to view and copy the data files stored on the target machine to your local machine. However, files can only be viewed if the target machine's File Browser setting is enabled. For more information on the File Browser property in the target properties, see Section 4.5.1, Target Properties.

To open the file viewer, select the Maintenance tab from the main menu in the Web Gate environment. You can view Web Server files or data files in the main, secondary, and optional drives. You can also copy the files from the target machine. Right-click a file and select Save Target As... from the menu, and save the file to the location you want.
