23.2.9.1 Using the Variable Browser

The Variable Browser allows an operator to view and modify variables in the target machine from the web environment. This feature enables an operator to monitor real-time information on the target machine and the PLCs connected to the target machine. Using the Variable Browser in the Monitoring tab, the operator can:

  • Display variable lists

  • Create custom variable lists

  • Update selected HMI or controller variables with current values

  • Stop data updates

  • Change values

  • Search for specific variables in a list.

The Variable Browser displays the variables from the selected variable list in alphabetic order with their corresponding values, as shown in the following example.

 

For a variable to display in the Variable Browser, the variable must have its Sharing property set to Read-Only or Read/Write in the Variable Properties dialog box. Variables that are set to None will not display in the Variable Browser. For more information on how to set up the Sharing property for a variable in the Editor, see Section 6.2.3, Variable Properties.

For internal variables, the values will always display. For external variables, where data is updated through an external link, the values may not always display due to bad data quality or unknown data. If data quality is bad, the last known value will be displayed with the bad data quality indicator . If data is unknown because the value has not yet been scanned, a dash (-) will be displayed.

 

Working with the Variable Browser

The following table describes each component in the Variable Browser.

Component

Description

This drop-down list displays the variable lists that you can view in the Variable Browser. You can select hmi or control to display all HMI or all Control variables, or any of the other user-defined lists. Any variable lists that you create will be displayed in this drop-down list. The variable lists are stored in \data\varlists as Unicode text in the target machine.

When this Stop icon displays, it indicates that values are being updated and that your display contains current values. The Stop icon is available for you to use if you want to stop the values from being updated.

When this Refresh icon displays, it indicates that values have stopped being updated and that your display does not contain current values. The Refresh icon is available for you to use if you want to resume value updates.

The Edit Mode button toggles between view and edit modes. When in view mode, you will just see a list of the variables in the selected list. When in edit mode, you will see check boxes beside each variable, enabling you to:

  • Select HMI or Control variables to add variables to existing variable lists or to a new list.

  • Select variables from a user-defined variable list for removal.

The Add button displays when you are in Edit Mode and the hmi or control variable list is selected. This function allows you to add selected variables to an existing variable list or to a new list. You can add a maximum of 50 variables to a variable list.

Select the variables, and then click the Add button to open the Add Variables to List dialog box. Select a variable list. If you select New List..., enter the name for your new variable list. Then click Add..

The Delete button displays when you are in Edit Mode and a user-defined variable list is selected. This function allows you to remove selected variables from a variable list.

Select the variables you want to remove, and then click the Delete button to display a dialog box to confirm. Click OK to delete the selected variables from the list.

The Lock icon indicates that the variable is read-only. You cannot change the displayed value for a read-only variable.

Click the Search icon to display the Name Filter field. Type in part of the variable name you are looking for and click to display the variables with the names that match the text you entered. Click to clear the Name Filter field and display all the variables in the variable list.

Changing Variable Values

If the variable is set to Read/Write, you can change the value of the variable. Place your cursor on the value and right-click to open the Change Value dialog box. Change the value, and click Write.

If the variable is Read-Only and the locked icon is displayed, you can open the Change Value dialog box, but you will not be able to make changes to the value.
