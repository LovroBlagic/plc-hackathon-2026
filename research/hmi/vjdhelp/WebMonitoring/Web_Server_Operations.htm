23.2.9 Web Server Operations

You can perform Web Server operations by using the following features:

  • Variable Browser: Display select variable data remotely and to update the display with current values.

  • Statistics: View Information about the Target and Project.

  • File Viewer: View and copy Web Server files and data files in the main, secondary, and optional drives.

Depending on the Web Gate/Web Server Connection security settings that have been set up for the target machine, you may need to enter a user name and password each time you want to use a web server feature. For more information on target security for Web Server use, see Section 4.8.2.4, Protecting Web Server/Web Gate Connections from Unauthorized User.
