23.2.4 Setting Up a Target for Web Gate Monitoring

The following table describes the Web Gate components that a user should set up in their targets.

Publish To

Specify which Panel or Scripts run only on the target machine, only on the Web Gate client PC, or on both.

Variables

Specify which variables to view and edit from the Web Gate client PC. See Section 22.1, Sharing Data Between Tablets, Smartphones, and Target Machines.

Exclusive Input

Exclusive Input prevents simultaneous inputs to the same variable. With this feature you can stop other target machines from changing the value of variables that you're working on in the remote PC. See Section 22.2, Setting Up Exclusive Input Relationships.
