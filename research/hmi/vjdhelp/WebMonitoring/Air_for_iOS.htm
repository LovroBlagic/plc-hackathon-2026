23.1.2.3 Setting Up the Vijeo Design'Air Client - iOS

You can set up a tablet and smartphone with iOS operating system version 6.0 or later as the Vijeo Design'Air client. To do so:

  1. From App Store, download Schneider Electric’s Vijeo Design'Air application.

  2. Touch the Vijeo Design'Air icon to launch the application. The Vijeo Design'Air main view opens.

  3. Touch the search network icon to open the Remote Servers menu that displays a list of HMI target machines that can act as Vijeo Design'Air servers. For more information on how to set up a target machine as a server, see Section 23.1.2.1, Setting Up Vijeo Design'Air Server.

  4. In the Remote Servers, touch the add to favorites icon next to any of the detected Vijeo Design'Air servers to add them to Favorites. You can touch the refresh icon to update the list.

  5. In Favorites, touch any Vijeo Design'Air server to connect to it. You can also manually add a Vijeo Design'Air server to Favorites by using its IP address. For more information, see Connect to Vijeo Design'Air Server using IP Address.

Once the connection is established, you can view the HMI project on your tablet or smartphone and perform single-touch actions. The HMI view on tablets and smartphones can display in landscape and portrait modes.

In the HMI view, you can press the snapshot icon to make a screen capture of the current view. You can then either save the captured image, or attach it to an e-mail for sending.

To exit an HMI view, use three fingers to swipe the screen from left to right. This action brings you back to the Favorites screen and disconnects the Vijeo Design'Air client from the server.

  • The  data transfer between the target machine and the tablet or smartphone is neither secured nor encrypted. Use it in a secure network environment or establish a virtual private network (VPN).

  • In a virtual private network (VPN) environment, the Search Network feature does not display the Vijeo Design'Air servers on the network. You will need to connect to Vijeo Design'Air servers using their IP addresses.

  • Vijeo Design'Air does not support Video Display objects.

Main View

The Vijeo Design'Air main view is for detecting, adding, and connecting to Vijeo Design'Air servers based on their IP addresses, and for configuring the connection set up. The following table describes it in more detail:

Item

Type

Description

Favorites

Content area

Lists the Vijeo Design'Air servers that you saved for quick access.  

Touch the arrow next to any of the servers to open the Edit Device dialog box where you can edit the following settings for a Vijeo Design'Air server: Name, IP Address, and Port Number.

Search Network

Action button

Lists Vijeo Design'Air servers that are detected on the network.

Touch the add to favorites icon next to any of the detected Vijeo Design'Air servers to add them to Favorites. This action removes the server from the search result.

Touch the refresh icon to update the list.

Edit

Action button

Puts the Favorites list into the edit mode, where you can perform the following actions:

  • Reorder: Touch and hold the list icon for any of the servers, drag the item to the desired location, and then release.  

  • Delete: Touch the delete icon for the server you want to delete, and then touch Delete. This action removes the Vijeo Design'Air server from Favorites.

Touch Done to save the changes.

Add

Action button

Touch to add a Vijeo Design'Air server to the Favorites by its IP address. The Add Device menu opens where you can enter the following information:

  • Name: Enter a name for the server (optional).

  • IP Address: Enter the server's IP address.

  • Port Number: Enter the server's port number. The default value is 6002. For more information, see Vijeo Design'Air Server Port Number.

After you fill the above fields, touch Save. The Vijeo Design'Air server is saved to Favorites.

Settings

Action button

Touch to configure the settings of the Vijeo Design'Air client. You can configure the following settings:

  • Show touch: Select ON to display a dot wherever you touch the screen in the HMI view.

  • Beep on touch: Select ON to play a beeping sound when you touch the screen in the HMI view.

  • View-only: Select ON to disable touch in the HMI view. This feature is useful for preventing accidental touches.

  • Keep awake while connected: Select ON to prevent the tablet or smartphone from entering sleep mode.

  • Show diagnostic information: Select ON to display the following information on the HMI view: target name, screen resolution, color depth, and update rate in frames per second.

  • Retry Timeout (secs): You can configure the time to attempt to re-connect to the Wi-fi. The minimum value is 5 and the maximum value is 120.

 

Connect to Vijeo Design'Air Server using IP Address

You can connect to a specific Vijeo Design'Air server if you know its IP address. To do so:

  1. On your tablet or smartphone, touch to launch the Vijeo Design'Air application.

  2. In the main view, touch the add icon to open the Add Device dialog box.

  3. Enter a name for the server (optional), IP address, and port number.

  4. Touch Save to add the server to Favorites.

  5. Touch to connect to the newly added server in the Favorites.

Vijeo Design'Air Server Port Number

The default value for the port number is 6002. You can set the port to any value within the standard port range (1000 to 65535). For more information on changing the default port number, see Section 23.1.2.1 Setting Up Vijeo Design'Air Server or 4.5.1.5 Remote Access.

Do not use a port number that may conflict with other port settings. For more information see Section 5.8.6, Preventing Port Number Conflicts.
