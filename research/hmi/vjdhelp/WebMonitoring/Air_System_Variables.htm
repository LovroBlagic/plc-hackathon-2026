Vijeo Design'Air System Variables

There are two system variables for managing a remote connection between the Vijeo Design'Air server and client:

  • _RemoteViewer.Connections: Indicates if a connection between the Vijeo Design'Air server and client exists.

  • _RemoteViewer.DisableConnections: Controls remote access between the Vijeo Design'Air server and client.

When you enable Vijeo Design'Air Security, the default value of the system variable _RemoteViewer.DisableConnections changes to 1, disabling any remote connections to the target machine. To allow a remote connection at run time, you can use a method, such as a switch or an action, to set this variable back to zero.

 

Example for Allowing Remote Access at Run Time

  • When designing a project for Vijeo Design'Air, carefully consider the potential of accidental touches on objects that run operations. Apply security levels on such objects to prevent unintended or unauthorized access. You must also inform and warn the operators of hazards related to operating machinery remotely. For more information on how to secure the target machines and objects, see Section 4.8, Setting up Security Protection for Targets and Projects, Section 4.8.2.1, Protecting Panels and Switches from Unauthorized Users, and Section 9.6, Using Interlock to Prevent Accidental Touch Input.

For example, you have enabled Vijeo Design'Air Security, which sets the default value of _RemoteViewer.DisableConnections to prevent the Vijeo Design'Air client from connecting to the target machine at run time. You want to give the operator the option to enable the remote access at run time.

At the build time, create the following items in your project:

Item

Steps

BOOL Variable

Create a BOOL variable and name it Accept.

Switch 1

  1. Draw a switch.

  2. In the Switch Settings dialog box, General tab, When Touch tab, for Operation, select Bit and Reset.

  3. In Destination, enter _RemoteViewer.DisableConnections and click Add.

  4. In the Label tab, for Label Type, select Static. In the text box, enter Enable Remote Access.

  5. In the Advanced tab, select Enable Interlock and enter the variable Accept.

  6. In the Security Level, select the security group that is authorized to enable remote access.

  7. Click OK to close the dialog box.

Text Object

Draw a Text object and enter a safety message to warn the authorized user of the hazards of operating machinery remotely. For example:

WARNING: UNINTENDED EQUIPMENT OPERATION

You must consider the potential of accidental touches from remote mobile devices. Know and understand the hazards regarding equipment movement started by a remote operation. You, as the operator, are responsible for all gates and interlocks for protecting people and equipment.

Failure to follow these instructions can result in death, serious injury, or equipment damage.

I understand and accept responsibility regarding use of this functionality.

Switch 2

  1. Draw a switch.

  2. In the Switch Settings dialog box, General tab, When Touch tab, for Operation, select Bit and Set.

  3. In Destination, enter the BOOL variable, Accept, and click Add.

  4. In the Label tab, for Label Type, select Static. In the text box, enter "I Accept".

  5. Click OK to close the dialog box.

Login Toolchest Part

 From the Toolchest Folders, Security sub-folder, Drag and drop a Login Toolchest part onto your panel.

 

Save, Validate, and download your project.

At run time, the operator logs into the Login Toolchest part and reads and accepts the warning message by pressing I Accept button. The BOOL variable changes to 1, which makes the Enable Remote Access button available.

When the operator touches the Enable Remote Access button, the value of  _RemoteViewer.DisableConnections becomes zero, enabling Vijeo Design'Air client connections  to the target machine.

You can also design another switch to set the value of _RemoteViewer.DisableConnections back to 1 which disables all remote connections to the target machine.
