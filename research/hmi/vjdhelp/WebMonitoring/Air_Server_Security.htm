Vijeo Design'Air Server Security

You can control access to the Vijeo Design'Air servers by requiring Vijeo Design'Air clients to provide authentication at login.

You must secure the target machine and the objects that run operations from unauthorized or unintended access. You can control access to the target machine with the Login Toolchest part, and protect objects that run operations by using Security Levels. For more information, see Section 4.8.2.1, Protecting Panels and Switches from Unauthorized Users, and Section 9.6, Using Interlock to Prevent Accidental Touch Input.

  1. Expand the Environment node and click Security.

  2. In the Property Inspector, for Vijeo Design'Air Security, select Use Security. The default value of the system variable _RemoteViewer.DisableConnections changes to 1, disabling any remote connections to the target machine. To re-enable the remote access at run time, you can use a method, such as a switch or an action. For more information, see Vijeo Design'Air System Variables.

  3. In the Security editor, in the Vijeo Design'Air column for the specific user group, select Denied, Read Only or Read/Write. Select Denied when you want to deny any communication with remote users. Select Read Only when you want to ignore touch request from remote users and display information or a dashboard for remote users. Select Read/Write to enable touch operations for remote users.

  4. In the Property Inspector, for Target Security, select Use Security. Expand the Target Security node and define Security Mode, Logout Behavior, Secured Object Behavior, and Password Management.

At run time, the Vijeo Design'Air client operator must provide a valid user name and password to connect to the Vijeo Design'Air server. Once connected, the user must then login to the target machine, using a Login Toolchest part, to access the secured panels and objects.
