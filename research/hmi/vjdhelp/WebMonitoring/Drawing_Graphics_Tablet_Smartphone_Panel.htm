23.1.1.2 Drawing Graphics on a Tablet/Smartphone Panel

You can use Vijeo Designer's drawing tools to create and edit a visual representation of your project design. This section describes the drawing tools available on a tablet/smartphone panel:

  • Supported shapes and parts in Graphical Tools

  • Supported objects in the Tablet toolbar

  • Color gradient feature to apply to your shapes, parts and Toolchest parts

  • Switch Configuration to set up remote alarm monitoring

  • Table Resources to set up predefined messages for a state display part

 

Supported Shapes and Parts

In Vijeo Designer, you can draw the following shapes and parts from the Graphical Tools toolbar:

  • Lines

  • Polylines

  • Polygons

  • Ellipse

  • Bezier Curves

  • Rectangle

  • Arc

  • Pie

  • Symmetric Polygon

  • Text

  • Image

For more information on how to draw shapes and parts, see Section 7, Drawing Graphics. Unsupported shapes and parts are grayed out in the toolbar.

 

Supported Objects

On a tablet/smartphone panel, you can access the Tablet toolbar which allows you to draw the following objects and configure their settings in the Property Inspector:

  • Switch - a graphic object that, when tapped, performs an operation.

  • Lamp - a graphic object that represents the current state of a variable in the system.

  • Numeric Display - a graphic object that displays a number stored in the PLC register. You can change the number using a numeric keypad.

  • String Display - a graphic object that displays a string stored in the PLC register. You can change the string using the alphanumeric keypad.

  • Vertical and Horizontal Bar Graph - a graphic object that links to a variable or expression. When the value of the variable or expression increases or decreases, the size of the indicator increases or decreases. The bar graph can be vertical or horizontal.

  • Slider - a graphic object that allows you to send a value to the PLC register using touch and drag.

  • Circular Meter - a graphic object that links to a variable or expression. When the value of the variable or expression increases or decreases, the indicator needle rotates to point to the correct value on the meter. The circular meter can be a full circle or pie-shaped.

  • State Display - a graphic object that displays a predefined message associated with an integer variable value, as defined in the table resource.

The Tablet toolbar also contains a drop-down list of themes that you can apply to change the physical appearance of all the objects in the target. The themes are: Bevel, Chrome, Contemporary, Gloss, Pearl, Rounded Bevel, Slate, and Standard. You can change the theme using the following methods:

  • Target Level - Select the Tablet Theme in the Graphical Panels properties for the Tablet. Then set the Theme in the Panel Theme of each panel's toolbar to Use Tablet Theme. The theme is applied to all the objects in all the panels.

  • Panel Level - Select the theme in the Panel Theme drop-down list located on the panel's toolbar. The theme is applied to the objects on the panel. The Use Tablet Theme option uses the theme defined in the Graphical Panels properties.

  • Object Level - Select the object and define the Theme in the object properties. The theme you select is applied to the individual object. The Use Tablet Theme selection uses the theme defined in the Graphical Panels properties, and the Use Panel Theme selection uses the theme defined in Panel Theme in the panel toolbar. This selection overrides the theme settings made at the target and panel levels.

To draw an object:

  1. On a panel for a Tablet target, select and click an object from the Tablet toolbar, and then draw the object on to the panel.

  1. Define the Name and other properties specific to the switch, lamp, numeric display, string display, vertical/horizontal bar graph, slider, circular meter, and state display in the Property Inspector.

Switch Configuration for Remote Alarm Monitoring

A tablet/smartphone does not have local alarms but it can access shared alarms from other targets in the project. To set up data sharing of alarms, you can create a remote category, which is a collection of shared alarm groups, in the tablet/smartphone target. You can add alarm groups to a remote category in a tablet/smartphone target.

  • Before you create remote categories, you must enable data sharing on the targets and on the alarm group.

  • A remote category in a tablet/smartphone target only supports normal alarm groups. It does not support other types of alarms groups (such as diagnostic alarm groups) and event groups.

For example, add Alarm Group 1 in target machine 1 to the remote category created in the tablet, and then draw a switch with an Alarm Panel operation on the tablet panel. At run time, an operator can tap the switch on the tablet application to open the alarm panel, where the operator can view and interact with the alarms in Alarm Group 1 from target machine 1.

To set up the Alarm Panel:

  1. Right-click the Alarms & Events node for a tablet/smartphone target, and select New Remote Category to display the Remote Category Settings dialog box.

  2. Select the target machine and the target machine's alarm groups you want to access.

  3. Click to select the draw tool, and draw the switch. For more information, see the procedure to draw an object.

  4. Click the ellipsis in the Actions property.

  5. In the Actions dialog box, set the touch condition and select System in the Operations drop-down list. For more information, see the switch properties table.

  6. Select Alarm Panel, and then click Add.

  7. Click OK.

For more information on how an operator can view and interact with the alarms on the Alarm Panel at run time, see Remote Alarm Monitoring.

 

Table Resources

You can create a table resource for your tablet/smartphone project and associate a set of predefined states of an integer variable with specific messages. You can then use this table resource in a State Display object. At run time, when the value of the variable changes, the state display's content also changes to the message associated with that variable value.

Each table resource has an Invalid state. At run time, if a value in the variable does not match a value defined in the table, the Invalid state content will be displayed.

You can create up to 10 table resources in a tablet/smartphone project and up to 255 states for each table resource. Also, you can import or export a table resource file (*.tbl) inside a tablet/smartphone project or between tablet/smartphone projects.

To set up a table resource:

  1. In the tablet/smartphone target Navigator window, expand the Resource node.

  2. Right-click the Table node, and click New Resource.

  3. In the New Resource Library dialog box, enter a name for the table resource, and specify the number of states.

  4. In the Content column of the Resource Editor, enter a message for the Invalid state and each integer value. The maximum length for each message is 255 characters.

  5. Right-click a row to add, delete, copy, and paste states.
