23.2.3.1 Web Gate Inactivity Time-Out

You can specify the time period that a client connected to a target using Web Gate can be inactive before the client will be disconnected from the target. The timer resets if an action is performed on Web Gate before the time-out occurs. For more information on the Inactivity Time-Out property, see Section 23.2.3, Web Gate Settings.

If the Web Gate client is inactive for the time period specified in the Inactivity Time-Out property, the Web Gate client disconnects from the target, and data sharing becomes disabled between the target and the Web Gate client. With data sharing disabled, variables with the following settings in the Sharing property of the Variable Properties dialog box will have the corresponding effect on global actions (published to Web Gate or to All), switch actions, and panel scripts (published to Web Gate or to All):

  • Variables set to Read/Write — All actions and scripts with read/write operations on these variables will stop.

  • Variables set to Read Only — All actions and scripts with read operations on these variables will stop.

  • Variables set to None — These variables will not be affected by data sharing being disabled. All actions and scripts with local Web Gate variables will continue to execute.

After the time-out, a panel displays on the client machine informing you that the Web Gate connection was terminated due to inactivity. To reconnect, you can do one of the following:

  • Press a Reconnect button on a system panel that enables you to reconnect to Web Gate and return to the previous panel.

  • Reopen the Internet Browser and reconnect to Web Gate.
