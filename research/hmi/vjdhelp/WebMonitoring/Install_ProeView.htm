23.2.5.1 Installing the ActiveX Control

Install the Vijeo-Designer Web Gate ActiveX control from the Web Gate environment. For information on the Web Gate environment, see Section 23.2.7, Web Gate Environment.

  • While Web Gate ActiveX Control is backward compatible, we recommend you use the same version of Web Gate ActiveX Control as the Vijeo Designer Runtime on your target machine.

To install the Web Gate ActiveX control:

  1. Connect to Web Gate. See Section 23.2.6, Connecting to Web Gate.

  2. Click Monitoring in the menu bar at the top of the Web Gate environment page.

  3. Click Install Web Gate Control in the submenu that appears to the left of the page.

  4. Follow the instructions that appear on the page to install the Web Gate ActiveX control.

Installing the ActiveX Control on Windows 7, 8.1 or 10

For Windows 7, 8.1 or 10, you must configure the local security policies to allow installation of the Web Gate ActiveX control.

To configure the local policies you can use one of the following two methods:

Method 1:

  1. At the command prompt, run secpol.msc.

  2. In the Local Security Settings dialog, expand the Local Policies folder.

  3. Select Security Options.

  4. Disable User Account Control: Run all administrators in Admin Approval Mode.

  5. Restart your PC.

Method 2:

  1. From the Start menu click Control Panel.

  2. Click User Accounts to open User Accounts dialog box.

  3. Click Change User Account Control Settings.

  4. In the User Accounts Control Settings dialog box, move the slider to the lowest level, "Never Notify".

  5. Click OK to close the dialog box and restart your computer.
