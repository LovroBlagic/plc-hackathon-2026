1.3 Comparing Vijeo Designer, Vijeo Designer Runtime, and SoMachine

 

Vijeo Designer

  • Vijeo Designer is where you develop the HMI user application for the target machine.

Vijeo Designer Runtime

  • Vijeo Designer Runtime is an application that resides on the target machine and runs the HMI user application.

SoMachine

  • SoMachine is where you can develop, configure, and commission the entire machine in a single environment (including logic, motor control, HMI and related network automation functions).
