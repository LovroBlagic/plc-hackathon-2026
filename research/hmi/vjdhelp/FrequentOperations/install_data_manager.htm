20.5.1 Installing and Removing Data Manager and Command Line

You can install Data Manager and Command Line on any computer, independent from Vijeo-Designer. To install Data Manager and Command Line, run DMInstall.exe from the VJDDMToolInstall folder on the Vijeo-Designer DVD.

  • Data Manager and Command Line are automatically installed on your PC when you install Vijeo-Designer. The steps below are only required if you are installing Data Manager and Command Line on an independent computer, or if you are removing Data Manager and Command Line from an independent computer.

Installing Data Manager and Command Line on a Independent Computer

  1. Copy DMInstall.exe from Tools/VJDDMToolInstall folder on the Vijeo-Designer DVD, and paste it onto your computer.

  2. Run DMInstall.exe and follow the installation wizard's on-screen instructions to install Data Manager and Command Line.
    By default, Data Manager and Command Line installs to: C:\Program Files\Schneider Electric\Vijeo-Designer\Tools\Data Manager.

Removing Data Manager and Command Line from an Independent Computer

Remove the Data Manager and the Command Line from your computer by using the Add/Remove Programs in the Windows Control Panel.

  1. Click the Windows' Start button.

  2. Click Settings and then click Control Panel.

  3. Run the Add/Remove Programs application.

  4. Click Vijeo-Designer Data Manager in the programs list.

  5. Click Remove.

  6. Follow the on-screen instructions to remove Data Manager and Command Line from your computer.
