20.5.3.3 Converting CSV/TXT Files using the Command Line

You can convert .csv and .txt files into recipe files (.rcp) using the command line as well as the Data Manager. For information on converting .csv and .txt files using the Data Manager, see Section 20.5.2.3, Sending Files to a Target.

When converting a .csv or .txt file to a .rcp file, only the following recipe information is converted: Recipe Name, Recipe ID, Access Right, Recipe Labels (language IDs and label text), Ingredient Name, and Recipe Value.

Converting CSV/TXT Files

  1. Launch the command prompt.

  2. Use the Get command to download the recipe file (*.rcp) or files from the target machine. The recipe files will be used to validate the data in the .csv or .txt file. For information on the Get command, see Section 20.5.3.1, Transferring Data using the Command Line.

  3. Use the DataConverter with the -rp and -ccr options to convert the .csv or .txt file to a recipe file. The -rp option specifies the folder of the recipes downloaded in the previous step. The -ccr option tells the DataConverter that you are converting a .csv or .txt file to a .rcp file. For more information on the options, see Section 20.5.3.2, Converting Data using the Command Line. DataConverter validates the .csv or .txt data against the recipe data in the recipe file. If the ingredient data in the .csv or .txt file matches that in the recipe file, DataConverter updates the recipe file with the .csv or .txt data. If there is no match, the conversion fails and an error message displays.

  4. Use the Put command to upload the new recipe files to the target machine. The updated recipe files overwrites the recipe files in the target machine. For more information on the Put command, see Section 20.5.3.1, Transferring Data using the Command Line.

A complete example from downloading the recipe file, and then converting the .csv file, to uploading the updated recipe file:

  1. C:\Program Files\Schneider Electric\Vijeo-Designer\Vijeo-Frame>DataTransferTool\DataTransferTool -ip 10.187.225.12 -user MyUserName -pwd MyPassword -get -Secondary -rdf Recipe -localfolder "C:\temp\recipedownload" -r *.rcp

  2. C:\Program Files\Schneider Electric\Vijeo-Designer\Vijeo-Frame>DataConverter  -i "C:\temp\recipeCSV" -o "C:\temp\recipeCSV" -rp "C:\temp\recipedownload" -s -ccr -v

  3. C:\Program Files\Schneider Electric\Vijeo-Designer\Vijeo-Frame>DataTransferTool -ip 10.187.225.12 -user MyUserName -pwd MyPassword -put -localfolder "C:\temp\recipeCSV" -secondary -rdf Recipe -r *.rcp

  • When input is a file, you must provide the full path for the output file and the recipe file. For example, if you want to convert the file, r00001.csv, in the subfolder "recipegroup1" in "C:\temp\recipeCSV", you would type: DataConverter -i "C:\temp\recipeCSV\recipegroup1\r00001.csv" -o "C:\temp\recipeCSV\recipegroup1" -rp "C:\temp\recipedownload\recipegroup1" -ccr -v.

  • When input is a folder, DataConverter automatically adds the subfolder names to the output folder and the recipe folder. For example, if you want to use the folder name instead of the file name in the previous example, you would type: DataConverter -i "C:\temp\recipeCSV" -o "C:\temp\recipeCSV" -rp "C:\temp\recipedownload" -s -ccr -v.

  • The input folder and the output folder can be the same. However, the recipe folder must be different from the output folder since you are validating the recipe folder against the output folder.
