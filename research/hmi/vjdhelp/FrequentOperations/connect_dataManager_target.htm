20.5.2.1 Creating a Target Connection

To send or retrieve data from a target machine, you must create a profile of the target machine that you want to connect to.

  • If you do not enter a user name and password for your target machine's profile in the Configure a Target window, you will be required to enter in the target's user name and password when you connect to the target machine.

Creating a Target Machine Profile

  1. Start the Data Manager.
    In the Windows Start menu, point to Programs, Schneider Electric, Vijeo-Designer‚ Tools, and Vijeo-Designer Data Manager.

  2. On the main page, use the Media drop-down list to select New Target Connection and then click Create.

  1. In the Configure a Target window, create your target's profile. The table below describes the target property settings.

Property

Description

Name

Create a name for the target. The target's name must contain no more than 32 valid characters and must follow the naming conventions.

For details, see Appendix 9, Naming Conventions.

Connection

Select a connection for sending or retrieving data:

  • Ethernet

  • Ethernet Over NAT

  • USB

  • The remote target is a FTP server

Ethernet Over NAT allows the Data Manager to establish an Ethernet connection to access targets behind a NAT device such as a router. To access targets behind a NAT device, contact your network administrator. The network administrator makes sure:

  • Gateway routers that support port forwarding are used.

  • The NAT address, Control Port, and Data Port are configured.

  • The Control Port and Data Port are not blocked by the firewall.

 

  • To connect to targets inside a subnet, the most secure option is to use a VPN router rather than port forwarding. If you choose to use the port forwarding feature, it should be active for a short time only so unauthorized users cannot get access to the target.

  • The network settings (IP Address, DHCP, Subnet Mask, and Default Gateway) must be correctly assigned to the target. The wrong settings can break communication between the target and the router.

Target Address

Type in the target machine's IP address or host name. This feature requires your network to have a DNS server that can store IP addresses and host names. If you enter a host name, the Data Manager contacts your network's DNS server to validate the host name's IP address.

Host names must follow DNS host naming conventions. For more information on these conventions, see Appendix 9 Naming Conventions.

Connect Via

Enter a valid IPv4 address or a host name. The Data Manager uses this IP address to establish the Ethernet connection. This property is enabled only when you select the Ethernet over NAT connection. This feature requires your network to have a DNS server that can store IP addresses and host names. If you enter a host name, the Data Manager contacts your network's DNS server to validate host name's IP address.

Host names must follow DNS host naming conventions. For more information on these conventions, see Appendix 9 Naming Conventions.

Control Port

Enter a value between 1025 and 65535 to define the control port that the command will be sent through. This property is enabled only when you select the Ethernet over NAT connection.

The Control Port value entered in this window must be the same as the Control Port value in the NAT device port forwarding settings and mapped to the target's Control Port value set to 6001. For example, if the Control Port value in the NAT device settings is set to 6021, the Control Port value in the Configure a Target window must be set to 6021 and must be mapped to the target's Control Port value.

Data Port

Enter a value between 1025 and 65535 to define the data port that will enable data transfer between the target and the PC. This property is enabled only when you select the Ethernet over NAT connection.

The Data Port value entered in this window must be the same as the Data Port value in the NAT device port forwarding settings and mapped to the target's Data Port value set to 13777. For example, if the Data Port value in the NAT device settings is set to 13977, the Data Port value in the Configure a Target window must be set to 13977 and must be mapped to the target's Control Port value.

Anonymous Connection

Select this check box to connect anonymously to the target. Be aware that the target may not be set up to accept anonymous connections.

Anonymous connection settings are enabled and disabled in the target machine's security settings in Vijeo Designer. See Section 4.8.7, Security Settings.

User name

Type in the target machine's user name. This field is optional because you can enter the user name either in this property or in the User name property when you connect to a target. Authentication is required in order to use Data Manager.

User names are set up in the target machine's security settings in Vijeo-Designer. See Section 4.8, Setting up Security Protection for Targets and Projects.

Password

Type in the target machine's password. This field is optional because you can enter the password either in this property or in the Password property when you connect to a target. Authentication is required in order to use Data Manager.

Passwords are set up in the target machine's security settings in Vijeo-Designer. See Section 4.8, Setting up Security Protection for Targets and Projects.

Confirm Password

Retype the password in this field to confirm the password.

Save Password

Select this check box if you want to save the password for this target machine profile.

Data Location

Specify where run-time data is located on the target machine. The locations of the drives depend on the type of target machine.

  • Main Drive - The main drive can be the Internal Memory (Flash Memory), CF card, or hard disk drive.

  • Secondary Drive - The secondary drive can be any drive or a CF Card/SD Card. For targets that do not support a CF Card/SD Card, there is no secondary drive.

  • Optional Drive - An optional drive is a drive connected externally to the target, for example, a USB drive.

For more information on the data locations supported by a specific target series, see Appendix 5.11.2, Supported Drives by Target Types. For a list of targets that support optional drives, see Appendix 5, Hardware Specifications.

  • For targets with security enabled, you can enter the user name and password in the target's profile to automatically log into the target when connecting. Otherwise, you will be prompted to enter the user name and password when connecting to the target.

  1. Click Create to add the target's profile to Data Manager.
