20.1.1 Updating the _CurPanelID System Variable Directly

You can write a value directly to the _CurPanelID system variable by using scripts or the keypad in Runtime.

Specifying a Value to _CurPanelID using a Keypad

When changing a panel using the keypad, a value is written to the _CurPanelID system variable using a Numeric Display or Value Animation. This section explains how to set a value using the Numeric Display.

  1. Select the Numeric Display icon from the Graphical Objects toolbar, and on the panel draw the display area.

  1. In the Numeric Display Settings dialog box, in the General tab click in the Variable field.

  1. In the Expression Editor Pad that displays, click the Include System's icon and display the system variables in the Variable List.

  1. Select the _CurPanelID system variable, and click OK.

  1. In the Format select Dec.

  1. To use the numeric display to enter the panel ID, in the Input Mode tab select the Enable Input Mode check box, and the Display Popup Keypad check box should be selected.

  1. Click OK and at run time you can now use the numeric display to change panels.

For more information about other the Numeric Display, see Chapter 11, Displaying and Inputting Data.

  • The _CurPanelID system variable stores the value in BIN format.

  • If you try to enter a panel number that does not exist in the project, _CurPanelID will not store the number and the panel change will not occur.

Using _CurPanelID in Scripts

You can use the _CurPanelID system variable in the same script as the Vijeo-Designer variable. This section explains how to use the _CurPanelID system variable in a script using the following sample.

Example: Panel Change by Password

First, you should set a password. When you enter the correct password on the password entry screen, a panel will change. If the password does not match, a pop-up window displays a warning.

Sample Script

  1. Create an Action on panel 1.

  2. Define the following settings for the Action:. Set the Trigger to Conditional and the Trigger Variable to BOOL01.

  1. Click Next>

  2. Set the Operation to script and type in the following script:

int a;

 

// Assign value of variable to a

a = Integer01.getIntValue();

 

// Check input value with password

if (a == 1101)

{

_CurPanelID.write(2);

}

else

// Open popup window at coordinates 100,100

{

Window1.open(100,100);

Window1.changePanel(10001);

Window1.show(true);

}
