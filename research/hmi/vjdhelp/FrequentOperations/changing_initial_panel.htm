20.3 Setting the Startup Panel

When launching Runtime (when powering up the target machine), by default, the first panel displayed is panel number 1. However, you can set any panel to display at startup. For example, you can use the Panel #1000 as a start-up screen which provides switches to display other panels. This is useful when you want to add a menu screen to an existing project.

20.3.1 Setting Up a Panel for Startup

  1. Right-click the Target and select Properties.

  1. In the Property Inspector, select from the InitiaPanelID's drop down list which panel will be the first to appear at startup.
