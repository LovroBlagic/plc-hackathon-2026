20.2.6 Adding a User Application Language

  1. Double-click the Environment node, then right-click the Languages node and select New Language... to display the New Language properties in the Inspector.

  1. In the New Language dialog box, specify a Language Name, Locale, and the Language Font settings.

The following table describes the Language settings in the New Language dialog box.

Property

Description

Language Name

The language must have a name that is unique—no duplicates—within the target. You can use up to 32 characters in a name.
For details, see Appendix 9, Naming Conventions.

Locale

The Locale serves many purposes:

  • Provides a hint to the system so it can find the closest matching font when selected fonts are not available.

  • Changes the language of strings displayed in the alarm summary and other parts with fixed labels.

  • When inputting text, changes the layout of the keypad so special European characters are available.

You can select English, French, German, Italian, Spanish, Portuguese, Simplified Chinese, or Traditional Chinese.

LanguageFont

The language's font settings—font, style, and size (or height and width, depending on the type of target machine).

Font

The font type. This is one of the many typefaces you have set up for use with the language you are adding.

Font Width

The font's size. Some fonts require a font width and font Height.

Font Height

Font Style

The font's face—Normal, Bold or 3D.

Digit Grouping Character

You can select the character used to separate the digits displayed in a Numeric Display part: comma or space.

 

  • Use the following area of the New Language dialog box to set up the copying of font and text information from existing text objects into the added language. For details, see Section 20.2.10, Useful Features when Adding Languages.

  1. Click OK to confirm the addition of the language.

Configuring Language Settings in the Property Inspector

  1. Right-click the newly added language and select Properties to display its properties in the Property Inspector.

The following table describes the properties available in the Property Inspector.

Property

Description

Language Name

The language must have a name that is unique—no duplicates—within the target. You can use up to 32 characters in a name.
For details, see Section Appendix 9, Naming Conventions.

LanguageID

The number that identifies the language—from 1 to 32767.

Description

The user's comment about the language—up to 255 characters. This field may be left blank.

Locale

The Locale serves many purposes:

  • Provides a hint to the system so it can find the closest matching font when selected fonts are not available.

  • Changes the language of strings displayed in the alarm summary and other parts with fixed labels.

  • When inputting text, changes the layout of the keypad so special European characters are available.

You can select English, French, German, Italian, Spanish, Portuguese, Simplified Chinese, or Traditional Chinese.

Digit Grouping Character

You can select the character used to separate the digits displayed in a Numeric Display part: comma or space.

LanguageFont

The language's font settings—font, style, and size (or height and width, depending on the type of target machine). Click the to change the font settings as required.

 

Font

The font type. This is one of the many typefaces you have set up for use with the language you are adding.

FontSize

The font. size. Some fonts require a font width and font Height.

FontStyle

The font's face—Normal, Bold or 3D.

Overwrite Text in All Languages

This property is available only if the project contains multiple languages. This feature overwrites the text in all languages with the text in the current language. Click to confirm the overwrite.

Copy Text to all Empty Languages

This property is available only if the project contains multiple languages. This feature copies text in the current language to other languages with no text strings. Click to confirm the copy.
