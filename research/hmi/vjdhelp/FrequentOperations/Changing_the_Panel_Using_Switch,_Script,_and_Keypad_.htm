20.1.2.2 Changing the Panel Using Switch, Script, and Keypad

After using a switch, script, or keypad to change the panel, a change panel operation initiated by the equipment may not work. To make sure the change panel operation by the equipment always works, either use a program on the equipment or add a script. This section later describes how to add a script.

Change Panel Operation Using a Switch, Keypad, or Script

If you use a switch, keypad, or script to change the panel, the new panel ID is directly written to the _CurPanelID system variable and then copied to the Write To variable.

Change Panel Operation from the equipment

If you change the panel from the equipment, the operation occurs through the Read From variable, and then copied to the _CurPanelID system variable, which changes the panel.

Problem That Arises When Using the Equipment to Change Panels

If you combine the switch, script, or keypad change panel operation with the equipment change panel operation, the values in the _CurPanelID system variable and Read From variable may not match. As a result, the panel may not change when you run the panel operation from the equipment.

This section describes how the change panel operation works and the eventual problem where the panel does not change.

  1. Write 2 to the device address D100 to change Panel 1 to Panel 2. The 2 value is copied to the system variable _CurPanelID.

  1. Write 3 to the system variable _CurPanelID using a switch, script, or keypad to change the panel to Panel 3.

The panel displays 3. However, the value of D100 (Read From variable) remains 2. Because the values are not synchronized, a change panel operation may not work.

  1. Write 2 to the device address. The panel does not change.

How to Fix

To change the panel, add the following action.

  1. Create an action and set Trigger Type to Conditional, Trigger Variable to _CurPanelID, and Trigger Condition to On Data Change.

  1. Set the operation to script and write the script. In the following example, the integer variable (DM101) is used as the Read From variable.

int a=0, b=0;

 

// Assign the current panel number to a

a = _CurPanelID.getIntValue();

 

// Assign the Read From variable value to b

b = DM101.getIntValue();

 

// Synchronize _CurPanelID and Read From

// variable

if (a != b)

{

DM101.write(a);

}
