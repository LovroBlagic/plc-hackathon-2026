20.5.3 Transferring and Converting Runtime Data using the Command Line

Command Line provides the user with the ability to manage recipe files (.rcp), data logging files (.dat), alarm files (.csv), video files (.mpeg), screen shot files (.jpeg), and the project backup files (.vdz) on a target machine. You can use this feature to extract data from a target that supports an Ethernet connection.

Using Command Line you can:

  • Get (retrieve) - Get recipe files (.rcp), data logging files (.dat), alarm files (.csv), and video files (.mpeg), screen shot files (.jpeg), and the project backup files (.vdz) from a target machine during run time. Command line can be configured to delete files on a target machine after successfully retrieving them.

  • Put (send) - Put recipe files (.rcp), comma separated files (.csv), or text files (.txt) on a target machine during run time.

  • Convert - Convert recipe files (.rcp) and data logging files (.dat) into either comma separated value files (.csv) or text (.txt) files.

  • Batch Process Files- Use Command Line in a batch file process so that you can retrieve, send, or convert files automatically on a regular basis.

  • Command Line supports Get and Put files only over the Ethernet. Command Line does not support serial connections or USB connections.
