20.2.2 Configuring the System Language

The system language refers to text in the Vijeo-Designer Runtime Configuration menu and error messages. Vijeo-Designer's available system languages are English, French, German, Italian, Spanish, Portuguese, Simplified Chinese, and Traditional Chinese.

  1. In the Navigator window's Project tab, double-click the Environment node, then right-click the Languages node, and select Properties to display the Languages properties in the Inspector.

  1. In the Property Inspector, click the SystemLanguages ellipsis to open the System Language Manager.

  1. In the System Language Manager dialog box, select the system languages you want on the target machine.

  • Size Required indicates the system language's file size (KB) when downloaded to the target machine.

  1. Click OK to return to the Property Inspector.

  2. In the InitialSystemLanguage property, specify the language to display Vijeo-Designer Runtime error messages or when you access the Configuration menu after launching Vijeo-Designer Runtime.

For information about Vijeo-Designer Runtime Configuration menu options, see Chapter 26, Setting Up the Target Machine.
