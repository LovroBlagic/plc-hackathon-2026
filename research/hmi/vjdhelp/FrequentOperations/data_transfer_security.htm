20.5.2.7 Data Manager Password Security

Some target machines and recipe groups (.rcp) have security features that prevent unauthorized users from tampering with them. See the sections below for information on Target Security and Recipe Security.

Target Security

Some target machines require a user name and password before allowing you to send file to or retrieve files from it. Passwords and user names are set up for the target in Vijeo-Designer. Some target machines may be configured to accept anonymous connections. See Section See Section 4.8, Setting up Security Protection for Targets and Projects.

User names and passwords follow these conventions:

  • Maximum number of characters for a user name or password is 32.

  • User names and passwords only use the following characters: a–z, A–Z, 0–9, _ (underscore).

  • User names and passwords are case sensitive.

Recipe Project Identifier

Some recipe groups require a Recipe Project Identifier before allowing you to convert them or send them to a target. A Recipe Project Identifier is a string that is no longer than 32 characters. The Recipe Project Identifier is set up for the recipe in Vijeo-Designer. For more information on the Recipe Project Identifier, see Section 17.3.2, Setting Up the Recipes Node. For more information on converting recipe files, see Section 20.5.2.4, Converting Recipe and Data Logging Files.
