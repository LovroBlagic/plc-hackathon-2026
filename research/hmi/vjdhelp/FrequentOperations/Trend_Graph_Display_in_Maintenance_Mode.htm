20.5.4.2 Trend Graph Display in Maintenance Mode

When maintenance mode is enabled, the logging of variables in a trend graph is affected. All the recording of data logging stops and data is not written to the Runtime Data Location. When maintenance mode is disabled, the recording of data logging resumes.

When maintenance mode is enabled and data logging stops, you can remove the Runtime Data Location. However, you should wait at least 15 seconds to ensure that the data has stopped writing to the Runtime Data Location before removal.

The data is output to a file and saved in binary format (*.dat), which you can output to a .csv file. When you view the output file in a spreadsheet application or text editor, you will notice that the Quality column shows a value of 3 to indicate that the record was in maintenance mode.

The trend graph displays the halt in data logging with a red rectangular indicator at the time the panel went into maintenance mode and another red rectangular indicator at the time the panel came out of maintenance mode.

If power was turned off during maintenance mode, the trend is unable to get the record when the panel came out of maintenance mode. In this case, the second red rectangular indicator will not be drawn. The trend starts recording when the power turns back on.
