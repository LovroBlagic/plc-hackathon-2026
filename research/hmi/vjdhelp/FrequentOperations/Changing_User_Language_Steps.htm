20.2.5 Switching to a Different User Application Language: Steps

To switch to a different user application language, follow the steps below:

Steps

1.

Add the language you want to use to the Language folder.

2.

Draw objects, as required, for your project. When setting up text strings, labels for parts, and alarm messages, enter the strings in each language.

3.

Set up a language change with either a system variable—for use in a script or to associate with the equipment program—or a switch.
(You do not need to use the Vijeo-Designer Runtime Configuration menu.)
