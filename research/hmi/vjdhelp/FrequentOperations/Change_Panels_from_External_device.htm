20.1.2 Changing the Panel

You cannot access the _CurPanelID system variable directly from the equipment. If you want to change a panel from the equipment, assign Read From and Write To variables to the _CurPanelID system variable. The Read From and Write To variables should be integer variables with device addresses to the equipment.

Panel Change Structure

To change panels from the equipment, store the new panel ID in the Read From variable's device address. When the value changes, the value is copied from the Read From variable to the _CurPanelID system variable, which initiates the change panel operation.

Since the _CurPanelID and Write To variables are synchronized, if a panel change occurs, the value of the _CurPanelID system variable gets copied to the Write To variable. On the equipment, if you require the ID of the target machine's current panel, you should monitor the value in the device address associated with the Write To variable.
