20.5.4.3 Event Log Display in Maintenance Mode

Run-time errors are displayed in the Event Log and logged to the SRAM. When maintenance mode is enabled, the errors that occur in this mode are flagged. When maintenance mode is disabled, errors that occur will no longer be flagged. However, errors that occurred while in maintenance mode remain flagged.

While in maintenance mode, you can still clear errors logged in the Event Log by clicking the icon.
