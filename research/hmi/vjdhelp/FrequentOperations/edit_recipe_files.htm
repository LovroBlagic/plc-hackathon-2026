20.5.2.5 Editing Recipe Files

Data Manager can edit the ingredients of a recipe file (.rcp). The recipe file must be available locally to edit it using the Data Manager. For information on retrieving a recipe file from a target, see Section 20.5.2.2 Retrieving Files from a Target.

Opening Recipe Files

  1. Start Data Manager.
    In the Windows Start menu, point to Programs, Schneider Electric, Vijeo-Designer‚ Tools, Data Manager, and click Vijeo-Designer Data Manager.

  2. On the main page, use the Media drop-down list to select Local Files and then click Next.

  1. Select Edit Recipe Files and click Next.

  1. Click the Recipe Group ellipsis button, select the recipe file (.rcp), and click Open.

The Recipe Group's list of ingredients display in the Data Manager Recipe Editor.

Editing Recipe Files

The following table lists the Data Manager Recipe Editor properties. Each row in the Recipe Editor spreadsheet is a single recipe ingredient. You can only edit a recipe ingredient's value.

Property

Description

Recipe Group

Name of the recipe file (.rcp) open in the Recipe Editor.

Recipe

List of the recipes in the recipe group. When a recipe is selected, the recipe's ingredient properties display in the Recipe Editor.

Language

List of languages for the recipe group. When a language is selected, the Labels set up for the selected language display in the Label column.

  • Be aware that RCP files do not contain language labels; therefore, the Language drop down list only shows the name of the language the recipe was created in. For example, if you have three different application languages named English, French, and Spanish, and you created the recipe with an English Vijeo-Designer, the Language drop-down list will show the three languages as: 1. English, 2. English, 3 English.

Variable

The name of the ingredients variable.

Label

The name of the ingredient.

Editable

Shows if the ingredient's value is editable.

Min

Minimum value for the ingredient.

Max

Maximum value for the ingredient.

Value

The defined value for the ingredient.

To edit the ingredient value, click the ingredient's cell and type in the new value. Be aware that the values you enter must be within the ingredient's Min and Max range.

 

Be aware that RCP files do not contain the language labels.
