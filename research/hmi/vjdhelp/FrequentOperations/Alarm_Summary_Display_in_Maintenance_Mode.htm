20.5.4.1 Alarm Summary Display in Maintenance Mode

When maintenance mode is enabled, the alarm summary display is affected. Alarms triggered while in maintenance mode are flagged, meaning that the row is shaded. You cannot save flagged alarms to a Runtime Data Location or print flagged alarms.

The effects on the alarm summary display differ depending on the Display Mode in the Alarm Settings.

When Display Mode is set to:

  • Active: Alarms are not flagged. When the target machine is back online, the alarms are saved to the Runtime Data Location or printed.

  • History: Alarms are flagged if maintenance mode is enabled. Maintenance mode has no effect on existing alarms, only new alarms. Flagged alarms cannot be saved to the Runtime Data Location or printed.

  • Log display mode: All alarm rows added to the alarm summary while in maintenance mode are flagged and cannot be saved to the Runtime Data Location or printed.

While in maintenance mode, you can acknowledge, delete, and clear all alarms and restore them to "normal".
