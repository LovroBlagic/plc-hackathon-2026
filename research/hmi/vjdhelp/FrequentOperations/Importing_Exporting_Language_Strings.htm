20.2.9 Importing and Exporting Language Strings

The Export Language feature exports all related language strings to a tab-delimited text file (.txt). The Import Language feature imports the strings in a tab-delimited text file into the selected language. If a target has more than one language, you can choose to export or import language strings from a particular language, or from all the languages in the target at once.

  • The language import and export features are not intended to be used for transferring strings from one target to another target. Exported strings can only be imported back into the target that they were exported from.

Export a Single Language

The exported language strings can be edited using a text editor or a spreadsheet program. You can even localize the strings into another language. When you export a single language, the text file contains three columns, as described in this table:

Column

Description

String ID

Displays a value for the string ID. Do not edit this column.

String

Displays the string you can localize into another language.

String Location

Displays where you can find the string.

 

  • Empty labels will still export with a string ID, blank string, and a string location to where that string will be used.

  • A gray dotted line displays on the panel to denote that the selected language is empty for a text object.

To export language strings for a particular language:

  1. Expand the Languages node, right-click the language you want, and select Export Language.

  1. When the Export Language To dialog box appears, select the file name and the location where you want to export the language to, and click Save.

To import language strings for a particular language:

  1. Expand the Languages node, right-click the language you want, and select Import Language

  2. Select the .txt file whose strings you want to import into the selected Language.

  • Never change the pound symbol when exporting and importing text. If you use the Export Language function to export text, and you import text that overwrites the pound symbol (#) in a text object set up with Value animation, the text object continues to use Value animation but does not work properly.

Export All Languages

When you export all languages, a string column is added for each language. For example, if there are two languages, the text file will contain an ID column, two language string columns, and a location column. The text file when exporting all languages also contains a header line to identify the ID, language strings, and location columns. There is no header line when exporting a single language.

To export all languages in a Target:

  1. Right-click the Language node and select Export Languages.

  1. In the Export All Languages To dialog box, select the file name and the location where you want to export the language to, and click Save.

To import all languages to a target:

    1. Right-click the Language node and select Import Languages.

    2. In the Import All Languages From dialog box, select the .txt file whose strings you want to import.

  • For a successful import, the number of languages and the language names in the text file must match the same number of languages and the language names in Vijeo-Designer. Language names are case sensitive.
