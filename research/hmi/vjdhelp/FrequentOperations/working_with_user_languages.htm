20.2.7 Associating a Language with a Text Object or an Alarm

This section describes how you can enter text or an alarm message for the selected language. To change the language in the text display, see Section 11.7.2.3, Switching Text Files by Language.

Associate a Language with a Text Object

  1. Select the text object icon from the Graphical Objects toolbar and create a text object on the panel.

  2. When the Text Editor opens, it will display the text object's default Language settings. You can apply your text string to different languages in one of two ways:

  • Type the text string for Language 1, then click one of the Copy Text buttons to copy your text string to other languages for display when those languages are selected.

  1. Enter text to be displayed in the text object for each language.

Click:

To:

Overwrite Text in All Languages...

Copy the text string to all languages registered in the project.

Empty Languages Operation

Available when multiple languages are set in the Language node. Click the list box and select one of the following:

  • Text content only: Copies the text defined in the label and pastes it in the languages that have empty labels.

  • Text content, font, size, and style: Copies the text font, size, and style defined in the label and pastes it into the languages that have empty labels.

  1. If you are not using Overwrite Text in All Languages or Empty Languages Operation, change to a different language and enter the text you want to display.

  • Switch the language from Language 1 to Language 2, then type a string of text.

  1. Click OK to confirm the change.

Associate a Language with an Alarm

Alarm messages can be in different languages. Follow the directions below to associate a language with an alarm message.

  1. In the Variables Editor, double-click a variable's row number  to access the Variable properties dialog box.

  1. In the Variable Properties dialog box, click the Alarm tab, select the Alarm checkbox to enable the alarm, and click the Alarm Message button to access the Alarm Message Editor dialog box.

  1. In the Alarm Message Editor dialog box, you can apply your text string to different languages in one of two ways:

  2. Type the Alarm Message for Language 1, then click one of the Language buttons.
