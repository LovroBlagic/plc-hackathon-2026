20.5.3.2 Converting Data using the Command Line

Command Line can convert recipe files (.rcp) and data logging files (.dat) into comma separated files (.csv) or text files (.txt).

Converting Files

  1. Launch the command prompt.

  2. Change the directory to: C:\Program Files\Schneider Electric\Vijeo-Designer\Vijeo-Frame

  1. Type the command and parameters as follows:
    DataConverter     input output [options]

The command has the following return values:

  • 0 - File conversion was successful.

  • Greater than 0 - File conversion was not successful due to an error.

Example:

C:\Program Files\Schneider Electric\Vijeo-Designer\Vijeo-Frame>DataConverter -i "C:\Program Files\Schneider Electric\Vijeo-Designer\Vijeo-Runtime\Public\Projects\Target1\Data\log\Integer01\target1_Integer01_20030717.dat" -o "D:\data\logfile" -s -cw -cf -ch -ct

C:\Program Files\Schneider Electric\Vijeo-Designer\Vijeo-Frame>DataConverter  -i  "C:\Program Files\Schneider Electric\Vijeo-Designer\Vijeo-Runtime\Projects\Target1\"  -o  "C:\My Documents\Project\" -s -cw -cf -ch -ct

The following table describes Command Line parameters for converting recipe files (.rcp) and data logging files (.dat) to a .csv file or .txt file.

Parameter

Parameter Options

Description

Comment

Source Data

-i "input path"

Converts the files in the specified folder.

Required parameter.
Enclose the path and the file extension with double quotation marks ("").

Output

-o "output path"

Saves the output file in the specified folder.

Required parameter.
Enclose the path with double quotation marks ("") (the output file name is the same as the source data file.)

Option

-s

Include subfolders. Usually used when processing all the .dat files in a target.

Optional parameters.

You may use any or all of these options together.

-b

When processing subfolders (-s), enable this feature if you want to duplicate the target machine's data file folder structure in the output folder.

-cw

If a file with the same name already exists in the output folder, the file is overwritten.

-cf

Creates a new folder as the output folder.

-ch

Adds column headings (Time stamp, Data, and Quality) to the data logging's (.dat) output file.

-ct

Converts the data logging file's (.dat) time stamps to date string in this format: MM/DD/YY
Example: 07/17/2004

(July 17th, 2004)

-ct0

Converts the data logging file's (.dat) time stamps to date string in this format: YY/MM/DD
Example: 04/07/17

(July 17th, 2004)

-ct1

Converts the data logging file's (.dat) time stamps to date string in this format: DD/MM/YY
Example: 17/07/04

(July 17th, 2004)

ct2

Converts the data logging file's (.dat) time stamps to date string in this format: MM/DD/YY
Example: 07/17/2004

(July 17th, 2004)

-ct3

Converts the data logging file's (.dat) time stamps to date string in this format: YYYY/MM/DD
Example: 2004/07/17

(July 17th, 2004)

-ct4

Converts the data logging file's (.dat) time stamps to date string in this format: DD/MM/YYYY
Example: 17/07/2004

(July 17th, 2004)

-v

Displays the progress of data conversion. You can use the progress indicator as a diagnostic tool in case an error occurs during data conversion.

-d

Sets the field delimiter character. You can use any character on your keyboard as a delimiter except the vertical bar (|). Use t for <tab>.

The comma "," field delimiter outputs the file to a .csv file. All other delimiters outputs files to a .txt file.

Example: -dt

-rp

Specifies the folder for the downloaded recipe files from the target. DataConverter uses the recipe information in the files to validate the CSV/TXT data. Once validated, the data is converted and merged with the recipe files.

Use these options to convert a CSV/TXT file to a RCP file. For -rp, enclose the path with double quotation marks ("") See Section 20.5.3.3, Converting CSV/TXT Files using the Command Line.

-ccr

Indicates you want to convert a .csv file (in simplified format) to a .rcp file. If a file with the same name already exists, the file is overwritten.

-csr

Indicates you want to convert a .rcp file to a simplified .csv file rather than the full .csv file format.

Use this option to convert a RCP file to a CSV file.

-crf

Converts the RCP files to Runtime CSV common format.

Use this option to convert a RCP file to a CSV file.

-cfr

Converts the Runtime CSV common format files to RCP format.

Use this option to convert a CSV file to a RCP file.

 

  • Command Line uses spaces as delimiters between the data conversion command and each parameter (input, output, option). Be sure to use quotation marks when you define a path or filename.

  • You may have to include the path of the executable file if you run data conversion from a batch file or from a different directory.

  • There are many ways to define the output path.
