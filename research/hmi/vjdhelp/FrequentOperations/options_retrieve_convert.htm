20.5.2.6 Data Manager Options for Retrieving and Converting Files

The table below describes the Data Manager Options dialog box properties.

Property

Description

Overwrite if file exists

Select this option if you want the file being retrieved or converted to overwrite any duplicate files that are in the output folder.

Create Folder

Select this option to create a new folder for the output file. See Section 20.5.2.4, Converting Recipe and Data Logging Files.

Build Tree

Select this option to duplicate the target machine's data file folder structure in the output folder.

When you select Build Tree, Data Manager duplicates the target machine's data file folder structure in the output folder. The folder structure and the file names in the output folder will be defined as follows:

CSV/TXT Field Delimiter

Specify the output file's field delimiter. The Comma delimiter outputs the file into .csv file format.

All other delimiters will output the file into a .txt file format. This property applies only to Recipe and Data Logging file conversions.

Add Header

Select this option if you want the data logging's output file to have the following column headings: Time stamp, Data, and Quality. This option only works for converting data logging files.

Convert time stamp to date string

Select this option to format the time stamp for the output file. You can select the date format for the time stamp in the Format Type drop-down list.

  • Unformatted time stamps display as the number of seconds from the epoch time of January 1st, 1970, 0:00:00. For example, if data is recorded on 18:31, September 23, 2003, its time stamp is 1064341876 seconds.

Format Type

This property is available if the Convert time stamp to date string property is selected.

Create multiple CSV files

If you have a file that exceeds 65,536 rows of data, Microsoft Excel will not be able to open that file. Select this option to split a large-sized CSV file into one or more separate CSV files so that you can open them in Excel.

If this option is not selected and the CSV file exceeds 65,536 rows of data, the file will not open in Excel.

Delete Files on Target after Retrieval

When enabled, Data Manager deletes the specified files on the target once the files are successfully retrieved from the target.

 

  • If you select to delete data logging files, you are removing an entire file. Though you may only want to delete data records on a few select days, this delete operation removes the entire data file in which those data records are stored. Verify that the data file(s) you are deleting are the ones you want to remove.

Convert Recipe files (RCP) after retrieval

When enabled, you can select one of the following options for the recipe file:

  • Convert to full format. Data Manager retrieves the recipe file (.rcp) from the target and converts the recipe file to a .csv or .txt file using the full format. The full format of the .csv/.txt file includes all the information in a recipe group, including all the recipes and recipe ingredients. Using this file, you can edit recipes and recipe groups in an external editor such as Notepad or MS Excel. After editing the file, to update the project on the target machine, first import the recipe group into Vijeo Designer (create a new recipe group or overwrite an existing recipe group) and then download the entire project. For more information on the full recipe format, see Section 17.3.5.4, Sample Full Recipe Format.

  • Convert to simplified format. Data Manager retrieves the recipe file (.rcp) from the target and converts the recipe file to a .csv or .txt file using the simplified format. The simplified format of the .csv/.txt file contains only a subset of the recipe group information. Using this file, you can edit recipes and recipe groups in an external editor such as Notepad or MS Excel. After editing the file, to update the project on the target machine simply send the file, which works even while the target machine is online. For more information, see Sending .csv or .txt Files.

  • Convert to common recipe. Data Manager retrieves the recipe file (.rcp) from the target and converts the recipe file to a .csv or .txt file using the common recipe format. The common recipe format of the .csv/.txt file contains all the information in a recipe group, including all the recipes and recipe ingredients. Using this file, you can edit recipes and recipe groups in an external editor, such as Notepad or MS Excel. However, you cannot add or remove ingredients. After editing the file, to update the project on the target machine, first import the recipe group into Vijeo Designer (create a new recipe group or overwrite an existing recipe group) and then download the entire project. For more information on the common recipe format, see Section 17.3.6.3, Sample Common Recipe Format.

Keep retrieved Recipe files (RCP) after conversion

This property is available when the Convert Recipe (RCP) after retrieval option is selected.

When selected, the Data Manager keeps a copy of the retrieved recipe file (.rcp) in the output folder.
