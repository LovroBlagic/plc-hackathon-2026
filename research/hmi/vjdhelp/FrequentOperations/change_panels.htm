20.1 Switching Panels

Vijeo Designer allows you to change panels on a target machine by using a switch or a keypad. Panel changes can be achieved through either a program on the equipment or a Vijeo Designer script. This section describes how to change panels and its structure.

Change Panel Operation

When changing a panel, use a system variable called _CurPanelID. For information about System Variables, see Section 6.7 System Variables. The _CurPanelID system variable is a 32-bit integer and stores the panel number displayed on the target machine. You can use a switch, keypad or script to write a value directly to the _CurPanelID to change the panel display.

  • The value in the _CurPanelID system variable is updated when you change panels using a switch, object, or script.

  • The Initial Panel ID specified in the target properties is stored in the _CurPanelID system variable during run time startup.

Switching a Panel from Equipment

A switch, a keypad, and a script can write directly to the _CurPanelID system variable. However, a program on the equipment cannot write directly to system variables.

In order to trigger a change panel operation from equipment, set up an external variable in the system variables's Read From property. Use the program on the equipment to write the panel number to the device address to change panels.

Use a device address in the system variable's Write To property to find out which panel is currently displayed on the target machine
