20.5 Managing Run-time Data

Vijeo-Designer provides features for managing the recipe files (.rcp), data logging files (.dat), alarm files (.csv), video files, screen shot files (.jpeg), and the project backup files (.vdz) on target machines. To manage run-time data files, the user can use:

  • Data Manager
    A graphical user interface program that can: retrieve run-time data files from the target machine; send recipe group files to a target machine; delete run-time data files on a target machine after retrieving them; convert retrieved recipe files and data logging files into .csv or .txt files; edit retrieved recipe files; and install the Data Manager on any computer, independently from Vijeo-Designer.

  • Command Line
    An interface program that runs from the Windows command prompt that can: retrieve run-time data files from the target machine; send recipe group files to a target machine; delete run-time data files on a target machine after retrieving them; convert retrieved recipe files and data logging files into .csv or .txt files; batch process retrieving, sending, and converting run-time data files; and install the Command Line on any computer, independently from Vijeo-Designer.

  • Maintenance Mode
    A feature that stops all alarm, event, and data logging from being saved to the CF Card/SD Card. You can use the maintenance mode feature to extract data from a target that does not support an Ethernet connection.

  • Run-time Data Location Manager
    A feature that enables users to specify where the run-time data files are stored on the target machine.

  • The Data Manager and the Command Line support retrieving and sending files over the Ethernet and USB. The Data Manager and the Command Line do not support sending and retrieving files over serial connections.
