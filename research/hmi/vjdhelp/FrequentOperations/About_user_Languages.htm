20.2.4 About User Application Language Switches

After creating a project, you download it to the target machine and execute it in run time. At run time, the language displayed on the panel—in the labels, text strings, alarm messages, and text objects—is the User Application Language. You can set up and display many different user application languages, such as English, Chinese, Japanese, and the European languages.

This section explains how to switch the user language in Vijeo-Designer.

Setting a Language to a Specific Font

When you change the user application language, you are changing the fonts. Each language uses a different font specific to its language (such as Arial and Times New Roman for English, and MS Mincho and MS Gothic for Japanese). At run time, you can switch from one language and its fonts to another.

Do You Have the Font You Need?

Each computer has a specific set of fonts installed. The set of fonts depends on the Operating System and other applications installed on the computer.

Some target machines use internal language specific fonts. For a list of all the supported languages and fonts, see Section 20.2.11, Font Support for Different Languages.

If you set a text object's BitmapDisplay property to Yes, you can display a graphical representation of any font installed on your Windows editor.
