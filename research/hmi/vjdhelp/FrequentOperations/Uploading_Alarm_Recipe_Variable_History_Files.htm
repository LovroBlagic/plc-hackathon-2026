20.5.3.1 Transferring Data using the Command Line

Command Line can Get (retrieve) recipe files (.rcp), data logging files (.dat), alarm files (.csv), video files (.mpeg), screen shot files (.jpeg), and the project backup files (.vdz) from a target machine. Command Line can also Put (send) recipe files (.rcp) on a target machine.

Transferring Files

  1. Launch the command prompt.

  2. Change the directory to: C:\Program Files\Schneider Electric\Vijeo-Designer\Vijeo-Frame

  3. Type the command and parameters as follows:

DataTransferTool  TargetMachine  UserName Password  Operation  Disk  DataPort  DataType  Path [Option]

The command has the following return values:

  • 0 - Data transfer was successful.

  • Greater than 0 - Data transfer was not successful due to an error.

The following example gets all the data logging files for the month of December, 2004, from the target machine and copies to the folder D:\data\logfile:

C:\Program Files\Schneider Electric\Vijeo-Designer\Vijeo-Frame>DataTransferTool -ip 192.168.2.1 -User MyUserName -pwd MyPassword -get -secondary -remotedatafolder Log -localfolder "D:\data\logfile" -r -delete 200412*.dat

Parameter

Parameter Options

Description

TargetMachine

-ip

Required parameter.

Defines the target machine. You can use the target machine's IP address or host name. You must specify port 6001 along with the IP address or host name.

Example:

 

-ip 192.168.2.1:6001

-ip MyComputerName:6001

UserName

-user

Required parameters.

Use these parameters to define the target's user name and password as defined in the Target's Security settings defined in the Target properties. See Section 4.8, Setting up Security Protection for Targets and Projects.

User names and passwords are case sensitive.

Example:

-user MyNaMe -pwd MyPaSsWord

-user A41010  -pwd 90210

Password

-pwd

Anonymous

-ua

Option parameter.

Some targets allow anonymous connections through the Command Line. Use this parameter to make an anonymous connection to the target machine.

Example:

C:\Program Files\Schneider Electric\Vijeo-Designer\Tools\Data Manager>DataTransferTool -ip 192.168.2.1 -ua -get -secondary -remotedatafolder Log -localfolder "D:\data\logfile" -r -delete 200412*.dat

Operation

-get

Required parameter.

Defines the operation: -get for getting the specified data from the target machine, -put for sending recipe files (.rcp) onto the target machine.

Only one of these operations can run at a time.

The -put operation is only for transferring recipe files to the target machine.

Read/Write, Delete user rights are required to overwrite a file that already exists on the target machine.

-put

Disk

-Main

Required parameter.

Defines the location of the data:

-Main for the Main drive, -Secondary for the Secondary drive, and -Optional for the Optional drive.

-Secondary

-Optional

Data Port

-NAT

Enables the Data Transfer Tool to work in NAT mode. To set up, contact your network administrator. For more information, see Section 25.6.1.2, Downloading through a Router.

The IP address will be treated as a NAT device address, and the Control Port and Data Port values will be treated as NAT device port forwarding settings.

Example:

datatransfertool -ip 10.187.225.26:7000 -NAT 14777 -user ABC -pwd MyPwd -get
-secondary -rdf Log -r -lf c:\download

DataType

-remotedatafolder

 

or

 

-rdf

Defines which data to get or put.

Get

When running a get operation, type one of the following:

  • Alarm

  • Log

  • Recipe

  • Project

  • Video

  • Snapshot

Alarm: Files generated by alarm outputs. See Section 16.3.6, Outputting Alarms and Events to a.CSV File.

Log: Data logging files generated by changes in data. See Section 13.1, About Data Logging.

Recipe: Recipe group files that store recipes. See Section 17.1, About Recipe.

Project: File contains a backup copy of the editor project. See Section 21.5.2, Backing up Projects to Main Drive, CF Card/SD Card, or USB Drive.

Video: File generated in run time for a video recording. See Section 19.1.1, About Video.

Snapshot: A JPEG file that contains a snapshot of the target machine's screen. See Section 19.2, Saving and Printing Screen Snapshots.

  • You cannot operate with more than one type of data in a single command.

Put

When running a put operation on a single recipe group, type: Recipe/RecipeGroupName

When running a put operation on all the recipe groups, use the recursive option –r and type: Recipe

Path

-localfolder

 

or

 

-lf

Gets the data and copies it to the defined path, or puts the data from the defined path onto the target machine.

 

When using the put operation with recipe files (*.rcp), after building the application in the Vijeo-Designer editor, the recipe files are located in:

\TargetName\

C:\Program Files\Schneider Electric\Vijeo-Designer\Vijeo-Frame\Vijeo-Manager\Security\Build\Projects\TargetName\Data\Recipe\

 

  • Enclose the path with double-quotation marks.
    Example: "C:\Documents and Settings\All Users\Data"

Options

-r

Optional parameter.

Includes subfolders. Used with data logging files and recipe files.

-delete

Optional parameter.

When running a get operation, after the file is successfully copied, this parameter deletes the specified data file from the target machine.

 

  • You cannot delete Recipe files (.rcp) after you have retrieved them.

-nobuildtree

Optional parameter. Sets the Vijeo Designer command line to not create folders for retrieved data files. When this option is specified, the folders will not be created. By default, without this parameter being specified, the command line will create folders for retrieved data.

*.*

Optional parameter.

Specifies the last parameter in the command. Use this parameter to identify which files to work with. If there are no specified files, then operates on all the files of the type specified by the -remotedatafolder tag.

You can use any file specification characters.

Example:

*.*  All files

a*.*  All files that begin with "a"

*.dat  All files with the ".dat" extension

a?.dat  Files that begin with "a" plus another character.

  • Command Line uses spaces as delimiters between the data transfer command and each parameter. Be sure to use quotation marks when defining paths.

  • You may have to include the path of the executable file if you run data transfer from a batch file or from a different directory.
