What's New in Version 5.0

Click the following categories to view information about the new and improved features for Vijeo Designer Version 5.0.

  • New Script Methods

    New Equipment script methods are available for setting an equipment's IP address during run time.

    For more information, see Section 18.3.8.10, Equipment Methods.

  • Reference Variables

    Vijeo Designer's reference variables feature allows a panel operator to access a different set of data in specified variables based on parameters that can be changed at runtime by the panel operator.

    Reference variables refer to other variables for their values. The references can be changed dynamically during run time. You can also dynamically change the variable that an object, graph, selector, slider, switch, etc., is referencing during run time.

    For information on this feature and how to set up reference variables, see Section 6.13, Reference Variables.

  • New File Viewer and Variable Browser in the Web Gate Environment

    Vijeo Designer has added the Variable Browser in the Web Gate environment, so that the panel operator can view and modify variables in the target machine from the web environment. For more information, see Section 23.2.9.1, Using Variable Browser.

    Also, the new file viewer feature in the web server allows the panel operator to view and copy the data files stored on the target machine to your local machine. For more information, see Section 23.2.9.3, Viewing Web Server and Data Files.

  • SoMachine Feature Updates

    Recipe Manager

    A new Toolchest Recipe Manager is added to manage SoMachine Recipies

    For more information, see Section 17.4.1.5 Creating the SoMachine Recipe Manager.

     

    Recipe Import

    You can import SoMachine recipes into Vijeo Designer.

    For more information, see Section 17.3.6, Exporting and Importing Recipe Groups.

     

    Variable Sharing

    Sharing variables between SoMachine and Vijeo Designer has been updated.

    For more information, see Section 4.13.2 Using SoMachine and Vijeo Designer Variables.

     

    Reports

    You can create HTML reports from SoMachine on the variables, panels, and actions used in your Vijeo Designer application.

    For more information, see 4.13.6 Creating SoMachine and Vijeo Designer Reports.

     

  • New Information Types

    The following new information types have been added:

    • HMI_Application_Checksum has been added to the Sys.getInfoInt system method. For more information, see Section 18.3.8.5, System Methods: Sys.getInfoInt.

    • Application_Build_Date and Application_Build_Time have been added to the Sys.getInfoString system method. For more information, see Section 18.3.8.5, System Methods: SysgetInfoString.

    The new information types are available for selection when you set up Information Operations. See Section 9.5.13, Information Operations.

     

  • Updated PacDrive Equipment Configuration

    The Port property has been added to the equipment configuration dialog box for ELAU PacDrive. For more information, see the PacDrive manual.

    The new XBTGT Series target types are as follows:

    XBTGH Series

    The XBTGH Series offers a handheld solution to the current range of supported Harmony target machines. For a list of supported features for the XBTGH target type, see Appendix 5, Hardware Specifications.

    The new XBTGH Series target type is as follows:

    • XBTGH2460

    iPC Series

    New targets are added to the iPC Series. For a list of supported features for each target type, see Appendix 5, Hardware Specifications.

    The new iPC Series target types are as follows:

    • Smart MPC ST21xxx20

    • Compact MPC KT22xxx20
