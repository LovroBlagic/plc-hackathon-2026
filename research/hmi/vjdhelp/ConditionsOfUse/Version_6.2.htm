New Features

  • Microsoft Windows 8.1 32-Bit and 64-Bit Support

    Vijeo Designer now runs on Microsoft Windows 8.1 32-bit and 64-bit operating systems.

  • Microsoft Windows 10 32-Bit and 64-Bit Support

    Vijeo Designer now runs on Microsoft Windows 10 32-bit and 64-bit operating systems.

  • State Display Object in Vijeo Design'Air Plus

    Vijeo Designer now supports a new State Display object, which enables you to define content with an associated integer variable value. At runtime, when the variable value is set, the predefined content displays.

    For more information, see Section 23.1.1.2, Drawing Graphics on a Tablet/Smartphone Panel.

  • Information of Hot Standby PLC (M580) is available as DDT (Defined Data Type)

    Vijeo Designer supports M580 Redundant CPU Variables which enables you to get information from Hot Standby PLC (M580).

    For more information, see Modbus TCP/IP Driver manual..

  • FTPS for upgrading runtime and downloading projects

    Vijeo Designer now support FTPS (File Transfer Protocol Secure) for upgrading runtime and downloading projects securely.

     

     

  • SMTPS for sending secured emails

    Vijeo Designer now support SMTPS (Simple Mail Transfer Protocol Secure) for sending secured emails.

     

Improved Features

  • Adding Label to Lamp Object in Vijeo Design'Air Plus

    You can now add labels to Lamp graphic objects in Vijeo Design'Air Plus.

    For more information, see Section 23.1.1.2, Drawing Graphics on a Tablet/Smartphone Panel.

  • Dual LAN Port Support

    Vijeo Designer now supports Dual LAN functionality on target machines that are equipped with Dual LAN ports (Ethernet 1 and Ethernet 2).

  • Adding Visibility Animation to Objects in Vijeo Design'Air Plus

    You can now add Visibility Animation to graphical parts and objects on a tablet/smartphone panel.

    For more information, see Section 23.1.1.2, Drawing Graphics on a Tablet/Smartphone Panel.

  • Screen Capture Feature in Vijeo Design'Air's HMI View

    You can now make a screen capture in Vijeo Design'Air's HMI View, and either save the screen capture or attach it to an e-mail for sending.

    For more information, see Section 23.1.2.2 Setting Up Vijeo Design'Air Client - Android or 23.1.2.3 Setting Up Vijeo Design'Air Client - iOS.

  • Custom Folder Feature for Copy Data To Drive Operation

    You can now specify a destination folder for copying data files from the main, secondary or optional drive to a secondary or optional drive on a target machine.

    For more information, see Section 9.5.15.1, Copy Data To Drive Operation.

  • Security (Allow Ethernet Download & Upload)

    To protect the project and data on the target machine from unauthorized changes or access, additional level of security added to download, upload, command line instructions, Data Manager and Runtime Installer.

    For more information, see Section 4.5.1.2, Network Settings.
