What's New in Version 6.1

Click the following categories to view information about the new and improved features for Vijeo Designer Version 6.1.

  • Android Tablet/Smartphone

    Vijeo Designer now supports the Android Tablet/Smartphone.

    For information on the new target's capabilities, see Appendix 5, Hardware Specifications.

New and Updated Drivers and Equipment

  • ABB Automation COMLI Driver

    Vijeo Designer now supports the ABB Automation COMLI driver. For more information, see Appendix 2, Device Driver Manuals.

     

  • Biometric Switch

    Vijeo Designer now supports the Schneider Electric Biometric Switch XB5S5B2L2 external hardware equipment. The Biometric Switch enables you to set up security and authenticate users at run time using their fingerprints. For more information, see Section 24.9, Biometric Switch.

     

  • Illuminated Switch

    Vijeo Designer now supports the Schneider Electric Illuminated Switch HMIZRA external hardware equipment. The Illuminated Switch enables you to monitor and control operations outside of a target machine's touch panels. For more information, see Section 24.8, Illuminated Switch.

     

  • Melsec-FX (CPU) Equipment

    Vijeo Designer now supports the FX3G PLC for the Melsec-FX (CPU) driver. For more information, see Appendix 2, Device Driver Manuals.

  • Melsec-Q CPU (SIO) Equipment

    The Melsec-Q CPU (SIO) protocol supports several new CPUs. For a complete list, see Appendix 2, Device Driver Manuals.

  • Melsec QnU Ethernet Driver

    Vijeo Designer now supports the Mitsubishi Melsec QnU Ethernet driver. For more information, see Appendix 2, Device Driver Manuals.

  • Simatic LOGO! Equipment

    Vijeo Designer now supports the Simatic S7 LOGO! OBA7 equipment for the Siemens AG Simatic S7 Ethernet driver. For more information, see Appendix 2, Device Driver Manuals.

  • Sysmac CJ2 Ethernet Equipment

    Vijeo Designer now supports the CJ2 Ethernet equipment for the Omron Corporation Sysmac FINS (Ethernet) driver. For more information, see Appendix 2, Device Driver Manuals.

  • Updated Zelio/Millenium Driver

    Vijeo Designer now supports communication between the Zelio/Millenium driver and HMIGTO target machines. For more information, see Appendix 2, Device Driver Manuals.

     

New Features

  • Circular Meter Object for Tablet and Smartphone Projects

    Vijeo Design’Air Plus enables you to display numeric values using a circular meter. For more information, see Section 23.1.1.2, Drawing Graphics on a Tablet/Smartphone Panel.

     

  • Customizing Web Server and Web Gate Pages

    In Vijeo Designer, you can now customize the look of the Web Server and Web Gate pages by changing elements on the web pages, such as the logo and images on the home page.

    For more information, see Section 23.2.3.3, Customizing Your Web Server and Web Gate Pages.

  • File Script Methods

    Vijeo Designer now supports a new script method that enables you to read from a text file at run time. For more information, see Section 18.9.1.11, File Methods.

     

  • Link Objects

    The Link Objects node in the Navigator window allows you to design and create a library of definition objects using Vijeo Designer objects, parts, and Toolchest parts.

    For more information, see Section 21.1.4, Link Objects.

  • New Dialog Table Function to Synchronize Clocks after DST Change

    Vijeo Designer supports a new dialog table function that synchronizes a target machine clock that does not have battery backup with the PLC clock after a DST change. For more information, see Section 5.6.2.28, Set Terminal Clock Offset.

     

  • New Machine Energy Dashboard Toolchest Parts for SoMachine Projects

    Vijeo Designer has added Machine Energy Dashboard (MED) Toolchest parts for use in a SoMachine application so operators can now measure and monitor energy efficiency.

    For more information, see Section 4.13.11, Using SoMachine MED Toolchest Parts.

  • New String Parameter for Equipment Method

    The setProperty() Equipment script methods now supports setting an equipment's address during run time.

    For more information, see Section 18.9.1.10 Equipment Methods.

     

  • New Supported Symbol Import File

    Vijeo Designer has added SoMachine Basic Project Files (*.smbp) to the list of its supported symbol import files. For more information, see Section 6.3.4.2, Data Type Import Rules.

     

  • New Tower Light Toolchest Part

    Vijeo Designer now supports the tower light hardware, with added functionality in both the build-time and run-time software. For more information, see Section 24.7, Setting Up a Tower Light.

  • Parison Graph Toolchest Part

    The new Parison Graph Toolchest part allows you to plot the profile of a parison. This Toolchest part can be useful during blow molding process where you can alter the profile thickness of a parison. For more information, see Section 12.4.8, Parison Graphs.

     

  • Radial Color Gradient in Vijeo Design'Air Plus

    Vijeo Design’Air Plus enables you to apply radial color gradients to parts and objects. For more information, see Section 23.1.1.2, Drawing Graphics on a Tablet/Smartphone Panel.

     

  • Sorting in the Text Resource Editor

    In the previous versions of Vijeo Designer, text resources were automatically sorted by state. In Vijeo Designer 6.1, you can now sort the text resource by Integer Value or by Label.

    For more information, see Section 21.1.5.13, Sorting in the Text Resource Editor.

  • Variable Placeholders for Machine Energy Dashboard (MED) Toolchest Parts

    Vijeo Designer now supports the use of Placeholders in Machine Energy Dashboard (MED) Toolchest parts. For more information, see Section 4.13.11, Using SoMachine MED Toolchest Parts.

     

  • Vijeo Design'Air

    Vijeo Designer now enables you to remotely access and monitor target machines using a tablet or a smartphone. In this configuration, the target machine acts as the server while the tablet or smartphone acts as the client communicating over a WiFi wireless network. For more information, see Section 23.1.2, Vijeo Design'Air.

  • Vijeo Design'Air Plus

    You can now create a Tablet/Smartphone project in Vijeo Designer. At run time you can use a tablet or smartphone, using its advanced graphic capabilities, to interact with the target machine.

    For more information, see Chapter 23.1.1, Vijeo Design'Air Plus.

  • XY Graph Toolchest Part

    The new XY Graph Toolchest part allows you to plot a block of data with X and Y coordinate pairs instantaneously. For more information, see Section 12.4.9, XY Graphs.

     

Improved Features

  • Alarm Messages with Dynamic Content

    Vijeo Designer now provides an option for users to retain the same alarm message through alarm state changes. For more information, see Section 16.2.4.1, Alarm Group Settings.

  • Backing up Editor Projects to Main Drive

    You can now back up Editor projects to a target machine’s main drive. For more information, see Section 21.5.2, Backing up Projects to Main Drive, CF Card/SD Card, or USB Drive.

     

  • Changing E-mail Addresses at Run Time

    You can now change destination e-mail addresses at run time. For more information, see Section 9.5.20, E-mail Operations.

  • Communication with RSLogix 5000 v19 and v20

    Vijeo Designer now supports communication with RSLogix 5000 v19 and v20. For more information, see RSLogix5000 (L5K).

  • FIPIO Driver Support of Diagnostic Alarms

    You can now configure diagnostic buffer alarms using the FIPIO drivers, which enables you to view them at run time.

    For more information on how to set up diagnostic buffer alarms in Vijeo Designer, see Section 16.3.2.1, Displaying Diagnostic Alarms.

  • Increased Limits for Subject and Message Length in E-mail with Dynamic Content

    The maximum lengths of the e-mail subject and message have been improved to accommodate the use of dynamic variables in the e-mail. For more information, see Section 9.5.20, E-mail Operations.

  • Hiding the Set Date/Time Prompt

    You can now configure the Auto Set property to hide the Set Date and Time screen when the target machine starts up.

    For more information, see Section 24,4,4, Time Management.

  • Right-Click Menu in Recipe Group Editor

    Vijeo Designer added a new right-click menu in the right pane of the Recipe Group Editor so you can work easily with recipe ingredients. For more information, see Section 17.3.4, Editing a Recipe Group.

  • Thumbnail Icon for Vijeo Design'Air

    You can now select a base panel as the thumbnail icon for Vijeo Design'Air server. For more information, see Section 23.1.2.1, Setting Up Vijeo Design'Air Server.

  • Variable Placeholders in Objects

    In this new version of Vijeo Designer, Toolchest object reuse has been improved. You can create a collection of objects, assign variable placeholders for each object, group the objects, and place the grouped object in the Toolchest for later use and reuse, for export, and for sending to other users working on the same project.

    For more information, see Section 21.2.4, Working with Variable Placeholders.

  • View-only Mode for Vijeo Design'Air

    Using Vijeo Design'Air, you can now connect to an HMI in the View-only mode. This feature is useful for preventing accidental touches. For more information, see Sections 23.1.2.2, Setting Up Vijeo Design'Air Client - Android, and 23.1.2.3, Setting Up Vijeo Design'Air Client - iOS.

  • Vijeo Design'Air and Vijeo Design'Air Plus Security

    You can now set up Vijeo Design'Air and Vijeo Design'Air Plus security settings independent of Web Gate/Web Server security. For more information, see Vijeo Design'Air Server Security and Vijeo Design'Air Plus Safety and Security.
