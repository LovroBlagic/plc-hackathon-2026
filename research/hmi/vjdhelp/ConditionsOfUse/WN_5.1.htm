What's New in Version 5.1

Click the following categories to view information about the new and improved features for Vijeo Designer Version 5.1.

  • E-mail

    Vijeo Designer e-mail can send notifications to inform users of events occurring on the target machine during runtime. E-mail can contain a text message or a user created form as its subject.

    For more information, see Section 4.14, Working with E-mail.

  • New Protocols and Protocol Equipment

    New Protocol

    • Melsec - QUTE CPU Direct

    New Equipment types for protocols:

    • ELAU Pacdrive - PacDrive LMCx00C

    • Modbus RTU - CT Modbus

    Update to Modbus TCP/IP

    • Modbus TCP/IP - Supports UDP

    Update to ELAU Pacdrive

    • ELAU Pacdrive - Supports CoDeSys V3.x

    For more information, please review the associated protocol manual in Appendix 2. Device Driver Manuals.

  • New Recipe Toolchest Part

    New Recipe Toolchest part enables you to display all recipes as a list. For more information, see Section 17.4.1.6, Creating the Recipe List Part.

  • New Script Methods

    Equipment Methods

    New Equipment script methods are available for setting an equipment's properties during run time.

    For more information, see Section 18.9.1.10 Equipment Methods.

     

    System Methods

    • Sys.ClearAllDataLoggingInMemory  - clears all Data Logging data from the target's SRAM or DRAM

    • Sys.login - logs a user into a target machine that is set up with security.

    • Sys.logout - logs a user out of a target machine that is set up with security.

    For more information, see Section 18.9.1.5, System Methods.

     

    Float Methods

    New float methods are available to use in scripts.

    • intBitsToFloat - method returns the float value of a given bit representation.

    • floatToIntBits - method returns a representation of the specified floating-point value according to the IEEE 754 floating-point "single format" bit layout

    For more information, see Section 18.9.2.4, Float Methods.

  • Data Manager Enhancements

    Anonymous Connections

    Data Manager now can support connections from anonymous security users. For more information on setting up the Data Manager security to accept anonymous connections, see Section 4.8.6, Security Settings.

     

    Build Tree Option

    The Data Manager and the Data Manager Command Line now support the build tree option. Build tree option builds creates folders for data files the Data Manager retrieves.

    For more information, see Section 20.5.2.6, Data Manager Options for Retrieving and Converting Files.

  • XML Support for Variables

    Vijeo Designer variables can be imported and exported in an XML file. The XML format allows all of the variable's properties to be imported and exported.

    For more information, see Section 6.6, Copying Variables Between Projects.

  • New Splash Screen

    A new feature allows the user to create a custom welcome screen to display on the target during startup.

    For more information, see Custom Welcome Screen in Section 4.5.1, Basic Setup of a Target.

  • New Download Project Enhancement: Download through a Router

    Vijeo Designer projects can now be downloaded through a router.

    For more information, see Section 25.6.1.2, Downloading through a Router.

  • Security Enhancements

    User Manager Toolchest Part

    The User Manager toolchest part now supports a new mode: Limited. This mode permits a logged in user to only be able to modify existing security users whose security level is less than that of the user currently logged in.

    For more information, see Section 4.8.5, Managing Security Users at Run Time.

     

    Password Management

    Password Management has been added to Vijeo Designer Security. Password Management includes the following features:

    • Security Lockout - Lockout unauthorized users after a number of failed login attempts.

    • Password Strength Rules – Create rules for user passwords.

    • Password Expiry - Expire passwords after a defined period of time

    For more information, see Section 4.8.9, Managing Security Passwords.

  • Web Gate Enhancement

    Web Gate has been enhanced so it does not require a secondary drive on the target machine (i.e. CF Card) to run.

    For more information on setting up a target for Web Gate, see Section 23.2.4, Setting up a Target for Web Gate Monitoring.

  • Reference Variables

    Vijeo Designer's reference variables feature allows a panel operator to access a different set of data in specified variables based on parameters that can be changed at runtime by the panel operator.

    Reference variables refer to other variables for their values. The references can be changed dynamically during run time. You can also dynamically change the variable that an object, graph, selector, slider, switch, etc., is referencing during run time.

    For information on this feature and how to set up reference variables, see Section 6.13, Reference Variables.

  • New File Viewer and Variable Browser in the Web Gate Environment

    Vijeo Designer has added the Variable Browser in the Web Gate environment, so that the panel operator can view and modify variables in the target machine from the web environment. For more information, see Section 23.2.9.1, Using Variable Browser.

    Also, the new file viewer feature in the web server allows the panel operator to view and copy the data files stored on the target machine to your local machine. For more information, see Section 23.2.9.3, Viewing Web Server and Data Files.

  • New Target Machines

    Vijeo Designer now supports the following Harmony target machines:

    • HMISTO511

    • HMISTO512

    • HMISTU655

    • HMISTU855

    For information on these target capabilities, see Appendix 5, Hardware Specifications.

  • Modbus Dual Ethernet Connection

    Vijeo Designer now supports Modbus dual Ethernet connection between the target machine and a PLC.

    For more information, see Section 5.2.7, Setting Up Redundant Ethernet Connections.

  • Enhanced Data Storage Feature

    Vijeo Designer now supports Optional Drive as a data storage option for user application files, data files/forms, recipe files, and web server files.

    For more information, see Appendix 5.11.3, Supported Data for Each Drive.

  • Recipe Import/Export in CSV Format

    Vijeo Designer allows you to export recipe files to CSV format. You can make changes to the CSV file using Excel or another tool, and import the recipe file back into the target using the USB drive or CF Card.

    For more information, see Section 9.5.15, Copy Data Operations, and Section 17.6.10, Working with SoMachine Recipes at Run Time.

  • Event Logging System

    Vijeo Designer supports an event logging system in which operations and events, after they occur, are logged. You can define the types of events (user events, system error events, or system events) you want to view and then display them in an Event Summary.

    For more information, see Section 16.1, Alarms and Events.

  • Authorization of User Actions

    Vijeo Designer provides a validation feature in which authorization is required before a protected action or operation can proceed.

    For more information, see Section 4.8.9, Setting Up Authorization for User Actions.
