3.2 Compatibility

The files created in Vijeo Designer are called projects. Projects created in Vijeo Designer 5.0.0 or newer are compatible with current versions of the program. If you open an old project with a current version of the Vijeo Designer, the project is updated and then cannot be opened again by the older version of Vijeo Designer. It is recommended you Export or Backup your project before opening it in a newer version. For information on Backing up or Exporting projects, see Section 21.4, Importing/Exporting Projects, and Section 21.5, Backing Up Projects.

Be aware of the compatibility issues when upgrading your Vijeo Designer project from one version to another. For more information on compatibility issues, see Section 3.4, Upgrading Vijeo Designer Projects.

Currently Installed Versions of Vijeo Designer

  • To determine which version of Vijeo Designer you are using, from the Help menu click About. For more information, see Section 2.3, Version and license information for Vijeo Designer.

  • To determine which version of Vijeo Designer Runtime you are using, open the Vijeo Designer Runtime Configuration menu on the target machine. For more information, see Section 26.1, Configuration Menu.
