What's New in Version 6.3

Click the following categories to view information about the new and improved features of Vijeo Designer Version 6.3.

New Target Machines

  • iPC Target Machines

    Vijeo Designer now supports the following Harmony target machines:

    • Harmony P6

    • Harmony P6 Basic Box

    For information on these target machines' capabilities, see Appendix 5, Hardware Specifications.

New Features

  • Https Server

    Vijeo Designer now supports the Https Server to replace the Http server.

     

     

  • VijeoViewer

    Vijeo Designer now supports new way to remotely connect to Web Server in Vijeo-Designer HMI Target. VijeoViewer is a Windows Desktop application. It remotely connects to the HMI target, monitoring the target screen, viewing Web Server files and data files.

     

     

  • New License Manager Support

    Vijeo Designer now supports customer activation of licenses of both the Buildtime and Runtime.
    Check the following link for details on the New License Manager:     License Manager GSE Manual

     

     

End of support

  • End of support for Target types

    Vijeo Designer can no longer support the following Target types.

    • iPC Compact Series & Compact PC Box Series

    • Flex PC Box Series

    • HMIGTW Series

    • iPC S-Box Series

    • Smart PC Box Series

    • iPC Smart Series

    • XBTGTW Series

    • XBTGT Series

    • XBTGK Series

    • HMISTO Series

     

Projects using one of the listed obsolete target models will change to HMIGTO6310 when importing the project.

  • End of support for the Biometric Switch

    Vijeo Designer can no longer support the Biometric Switch.
