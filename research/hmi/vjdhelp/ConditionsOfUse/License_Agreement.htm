Purchasing Vijeo Designer Software or Vijeo Designer Licenses

Vijeo Designer includes one license that is required to install the software on one computer. Each additional computer on which Vijeo Designer is installed requires the purchase of additional Vijeo Designer software.

A license is valid even after you upgrade versions.

Schneider Electric does not re-issue software licenses and bears no responsibility if a license is lost, stolen, or damaged. Be sure to keep all licenses in a safe place.

 

Installing Vijeo Designer as Part of SoMachine

There are two licensing scenarios when installing Vijeo Designer as part of SoMachine:

  • Vijeo Designer that installs with SoMachine will become the Limited Edition after 21 days. This is only for launching Vijeo Designer separately from SoMachine. When launched with SoMachine, Vijeo Designer will be the full retail release.

  • To register Vijeo Designer as the full Standalone release, install Vijeo Designer from the Vijeo Designer installation DVD first. Then install SoMachine and Vijeo Designer from the SoMachine installation DVD. This will result in two separately installed instances of Vijeo Designer.
