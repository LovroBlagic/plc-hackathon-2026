What's New in Version 6.0

Click the following categories to view information about the new and improved features for Vijeo Designer Version 6.0.

New Target Machines

  • HMISTO Target Machines

    Vijeo Designer now supports the following HMISTO target machines:

    • HMISTO501

    • HMISTO531

    • HMISTO532

    For more information on the new targets' capabilities, see Appendix 5, Hardware Specifications.

  • iPC Target Machines

    Vijeo Designer now supports the following iPC target machines:

    • Box Performance HMIBPxxx2/HMIBPxxx5

    • Box Universal HMIBUxxx1/HMIBUxxx2

    • HMIGTW5354/Panel W HMIPWC5 (800x600)

    • HMIGTW7354/Panel W HMIPWC7 (1024x768)

    • Panel Performance HMIPPx7 (1024x768)

    • Panel Performance HMIPPx9 (1280x1024)

    • Panel Universal HMIPUx7 (1024x768)

    • Panel Universal HMIPUx9 (1280x1024)

    For information on the new targets' capabilities, see Appendix 5, Hardware Specifications.

New Drivers

  • Emerson Process Management Driver Support

    Vijeo Designer now supports the Emerson Process Management ROC Plus SIO and ROC Plus TCP/IP drivers. For more information, see Appendix 2, Device Driver Manual.

  • Generic EtherNet/IP Explicit Driver Support

    Vijeo Designer now supports the Generic EtherNet/IP Explicit driver for target machines with Ethernet capability. For more information, see Appendix 2, Device Driver Manuals.

  • Siemens S7-1200 PLC Support

    Vijeo Designer now supports Siemens S7-1200 PLC. For more information, see Appendix 2, Device Driver Manual.

  • Toyopuc Driver Support

    Vijeo Designer now supports the Toyopuc driver for Ethernet and serial connections. For more information on the Toyopuc driver, see Appendix 2, Device Driver Manuals.

  • Zelio/Millenium Driver Support

    Vijeo Designer now supports the Zelio/Millenium driver for the Harmony HMISTO501 target. For information on the Zelio/Millenium driver, see Appendix 2, Device Driver Manuals.

    When using the To/From PLC functions for the Zelio/Millenium protocol, you can add any functions and mix the To PLC and From PLC exchanges. For more information, see the Zelio/Millenium Driver Manual.

New Features

  • Common Security Feature

    You can now define common security groups and security users on multiple target machines from a single location. For more information, see Section 4.8.6, Common Security.

  • Deadband Feature in Data Logging

    Vijeo Designer supports the deadband feature in data logging to help reduce the number of records that are logged.

    For more information, see Section 13.2.2, Creating a Data Logging Group.

  • E-Mail Attachment

    You can now add an attachment to your e-mail. The attachment can contain stored data (such as screen snapshots and recipe files) and real-time data (such as alarm and event records). For more information, see Section 4.14.5, Adding an Attachment to an E-mail.

  • HMI Design Guide

    This design guide describes the basics for creating easy-to-use HMI applications. For more information, refer to HMI Design Guide.

  • Host Name

    Vijeo Designer now supports host names for target machines. Host names require your network to have a valid DNS server on it. For more information on host names, see Section 4.5.1.1, General: Host Name.

  • Microsoft Windows 7 64-Bit Support

    Vijeo Designer now runs on Microsoft Windows 7 64-Bit operating system.

  • NAT Support for Data Manager

    Data Manager's NAT support allows you to establish an Ethernet connection in order to access targets on different subnets. For more information on how to configure the NAT address and the port forwarding settings, see Section 20.5.2.1, Creating a Target Connection.

  • New Operations

    Decision Operation

    The decision operation runs sets of operations depending on the decision expression’s true/false value. You can create a set of operations to run for the expression’s true value and create a different set of operations to run for the expression’s false value. For more information on the decision operation, see Section 9.5.23, Decision Operation.

    Variable Initialization Operation

    You can create a list of variables and set initialization values for each variable. Once the variable initialization operation runs, the values write to the variables. For more information, see Section 9.5.24, Variable Initialization.

    Set IP Address at Run Time

    You can now use Vijeo Designer to change the target machine's IP address at run time. For more information, see Section 9.5.25, Set IP Address.

  • Preserve Target System Settings on the Target Machine

    You can now preserve target system settings on the target machine so that they would not be overwritten with the values from the Editor. For more information, see the Preserve Run-Time Data property description in Section 4.5.1.1, General.

  • System Variable

    _FileTransferStatus

    The new system variable _FileTransferStatus enables users to monitor the status of data transferring between the target machine and a CF Card or USB drive. For more information on this variable, see Section 6.7.1, System Variables: _FileTransferStatus. For more information on the copy operation, see Section 9.5.15, Copy Data Operations.

Improved Features

  • Alarm Sharing

    Vijeo Designer now supports shared alarm groups and shared event groups. You can view and interact with a target’s shared alarms and events from another target. For more information on alarm sharing, see Section 16.3.1.4, Remote Categories.

  • Alarm Summary

    In the Alarm Summary, you can now easily set the same colors for the column text and background as the messages. For more information, see Section 16.2.6.2, Messages Tab.

    Vijeo Designer now enables you to display alarm and event messages in multiple lines. For more information, see Section 16.2.6.1, General Tab.

  • Change to PLC Symbol Import Feature

    In this release, you no longer need to have Unity Pro installed on the same computer as Vijeo Designer when importing .XVM symbol files.

  • Copy and Paste Actions

    Vijeo Designer now enables you to cut, copy, paste, and delete global Actions and Panel Actions. For more information, see Section 9.4.1, Working with Actions and Panel Actions.

  • Download Security

    Download security improvement protects unauthorized users from installing projects on target machines through USB drives. For more information on this feature, see Download Security in Section 4.8.7, Security Settings.

  • Dynamic Content

    The following improvements have been made to the dynamic content feature in Vijeo Designer:

    • Messages with dynamic content can now be used in Message Displays, E-mails, Forms, and Alarm Messages.

    • You can now easily insert a custom time stamp or predefined time stamp, and a variable using the right-click menu in the Label column of a text resource.

    For more information, see Section 21.1.5.12, Setting Up Messages with Dynamic Content.

     

  • Modbus RTU Baud Rate Improvement

    The Modbus RTU driver now supports 57.6k baud rates for communications. For more information on the Modbus RTU driver, see Appendix 2, Device Driver Manuals.

  • Overlay Image for Switches

    Add icons to your switches to help identify the switch's purpose. For more information, see Section 9.2.2, Switch Color Tab.

  • Read and Write Unlocated Variables

    With the new Preload Data Dictionary feature, Vijeo Designer can now respond dynamically to address changes. Vijeo Designer can also display variable values without delay whenever a Unity PLC program is modified and downloaded to the PLC.

    For more information on how to enable this feature, see Appendix 2, Device Driver Manuals.

  • Resize Panels at Target Change

    When changing the model or panel size of target machines, Vijeo Designer enables you to automatically resize the project panels, their content, fonts, and font resources to fit in the screen. For more information, see Section 4.5.2.3, Changing a Target.

  • Show or Hide System Error Windows

    You can now select whether you want to show or hide system error message windows. For more information, see Section 16.2.3, Setting Up the Alarms and Events Node.

  • Siemens S7-300/400 Series Block Addressing

    Vijeo Designer now uses ISO on TCP to allow access to data blocks numbered from 1 to 65535. For more information, see Appendix 2, Device Driver Manual.

  • Unit Labels

    Create unit labels for numeric displays to help panel operators understand what the numeric display numbers represent. For more information on Unit labels, see Section 11.2.1, General Tab.

  • Vijeo Designer Working Environment

    The Close All Tabs command is now available in the Window menu. You can also right-click a tabbed document to access this command.

    Close All Tabs allows you to close all the open tabs in the project.
