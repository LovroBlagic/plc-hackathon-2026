25.5 Installing Vijeo Designer Runtime

Vijeo Designer is the editor you use to design the HMI project. Vijeo Designer Runtime resides on the target machine and runs the project. The Vijeo Designer project and Vijeo Designer Runtime must be compatible. In most cases, you will not have to install Vijeo Designer Runtime separately from installing the Vijeo Designer project. When you download the project from Vijeo Designer, Vijeo Designer automatically downloads and updates the Vijeo Designer Runtime on the target machine.

 

  • When downloading a project from SoMachine onto a target machine, the Vijeo Designer Runtime on the target does not automatically update to match the version of Vijeo Designer on the project. Use the Vijeo Designer Runtime Installer to manually update the software on the target machine before downloading the project from SoMachine.

In some cases, you may want to install Vijeo Designer Runtime separately. Vijeo Designer Runtime Installer is tool used to download, install, and upgrade the target's Vijeo Designer Runtime. The following sections within this topic describe how to use Vijeo Designer Runtime Installer to download and install Vijeo Designer Runtime to the target machine. Target machine series support different methods for downloading Vijeo-Designer Runtime. See Appendix 5, Hardware Specifications for the download method supported by your target.

Vijeo Designer Runtime Download Methods:

  • Ethernet

  • Serial

  • USB

  • CF Card/SD Card
