25.7 Run the User Application

The following instructions demonstrate how to start Vijeo-Designer Runtime on the target machine to begin running the downloaded user application.

  • Before running the user application, use Simulation to check the memory requirement of each panel. Validation will not prevent memory usage errors.

iPC, XBTGTW, HMIG5U, HMIG5U2, and HMIG5U22

  • To start Vijeo-Designer Runtime and begin running the user application, double-click the Vijeo-Designer Runtime icon on the Desktop, or click the Windows Start button. Then point to Programs, Schneider Electric, Vijeo-Designer, and click Vijeo-Designer Runtime.

    • HMIG5U and HMIG5U2 run on Windows Embedded Standard 7, and HMIG5U22 runs on Windows 10 Enterprise LTSC, which are operating systems that support HORM (Hibernate Once Restore Many). HORM and Vijeo-Designer Runtime cannot concurrently run. To create a hibernation image file for HORM, shut down Vijeo-Designer Runtime. Once Vijeo-Designer Runtime starts up, HORM will be disabled and the image file will be destroyed.

  • To stop the user application and exit Vijeo-Designer Runtime, press CTRL+Z on the keyboard. You can also use Switches or Touch animation to exit the runtime. See Section 9.5.10, System Operations, or 9.2.7.2, Setting Up Touch Animation.

XBTGC, XBTGT, XBTGK, HMIGK, HMIGTO, HMIG3U, and HMIGTUX

  • Turn on the target machine to start Vijeo-Designer Runtime and begin running the user application. If the application is set up to run from the CF Card/SD Card, the CF Card/SD Card must be inserted before turning on the target machine.

  • Turn off the target machine to stop the user application and exit Vijeo-Designer Runtime.
