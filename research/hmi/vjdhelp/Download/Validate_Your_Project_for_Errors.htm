25.2 Checking for Errors Before Downloading

To check for potential errors before building and downloading a project, you can:

  • Validate the project.

  • Simulate runtime operations.

Validation is the quickest way to locate common problems. Diagnostic information displayed in the Feedback Zone pinpoints specific problems that can be fixed before downloading to the target machine.

If validation passes with no errors, you can build and download.

If there are errors, check the settings that failed validation.

 

Validation checks whether:

  • Property values are within allowable ranges.

  • References to objects are valid.

  • Settings are correct.

  • You should run Validation several times while developing the project, to catch problems early in the development cycle.

25.2.1 Validating the User Application

  1. In the Navigator window's Project tab, right-click the Target node, and click Validate.

The progress message box pops up.

The Feedback Zone opens and displays messages about the validation process. Errors are highlighted in red and warnings in yellow.

  1. If there are any errors or warnings, double-click the error message or press F4 to display the location of the error.

  1. Correct the errors and validate again. Repeat until all the errors are corrected.

  • If there are any errors in the project, you cannot download to the target machine. Warnings are acceptable and do not prevent the download operation.

Once all the errors are resolved, a green highlight indicates success and the "Validation Complete" message displays.

For more information on messages in the Feedback Zone, see Section 28.2, Message List.

  • In addition to validating the entire user application, you can validate a single script. To validate a single script, right-click inside the script editor, then click Validate.

  • To validate multiple targets in the same project, right-click the Project node and click Validate All.

  • Validation will not prevent memory usage errors. Before running the user application, use Simulation to check the memory requirement of each panel.
