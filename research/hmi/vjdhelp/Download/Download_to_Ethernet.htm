25.6.1.1 Downloading over the Ethernet

  • After starting download, do not forcibly exit Vijeo-Designer, or turn off either the PC or target machine during download. Trying to cancel or interrupt the download process can make the target machine inoperable. If you have trouble starting the target machine, see Section 25.6.6, Recovering the System on a Target Machine.

Downloading

  1. Connect the Vijeo-Designer editor PC and the target machine to the network.

  2. Start Vijeo-Designer Runtime on the target machine.

  3. iPC or XBTGTW: On the Windows desktop, double-click the Vijeo-Designer Runtime shortcut.

  4. All other targets: Turn on the power.

  1. In Vijeo-Designer, in the Navigator window's Project tab, right-click the Target node and click Properties to open the Property Inspector.

    • Set Download to Ethernet.

    • Type the target machine's IP Address in the Target IP Address property, or enable Host Name and type in the target machine's host name

  • Assign a unique IP Address to each target machine. When you connect the target machine to the network and it detects a duplicate IP address, an error message displays and the target machine disconnects from the network.
    Checking for duplicate IP addresses also occurs when:

    • A new network device is connected

    • A disconnected network device is reconnected

    • A network device's IP address is reconfigured at runtime

    • Using a host name requires a valid DNS server on your network that is set up with the target’s IP address and host name. For more information on the download property's host name, see 4.5.11, General: Host Name.

    • Make sure the target machine you are downloading to is the same target type as defined in the Target properties.

  1. Right-click the Target node, and click Download.

  • Downloading erases the files on your target. You can preserve them by using the Preserve Run-Time Data feature.

  1. If the [Allow Ethernet Download & Upload at Run Time] check box is selected, during validation warning message 2133 appears in the Feedback Zone. For information on how to handle this message, see Warning 2133.

  2. If the Preserve Run-Time Data property is enabled in the target properties, the Download to Target dialog box opens. Confirm the download and whether you want to delete all the run-time data, including the recipe data, security data, and target system settings that you had selected to preserve in the target properties. If you want to delete all the run-time data (such as data logging, alarms, videos, and snapshots), the recipe data, security data, and target system settings you had previously selected to preserve, select the check box and click Yes.

  3. If you are downloading to the iPC or XBTGTW, the target machine will restart and present the Windows login screen. After logging on, start Vijeo-Designer Runtime if it isn't set up to start automatically. A dialog box displays in the iPC or XBTGTW as the connection between the editor and target machine is being established. Do not close this dialog box.

After the user application is successfully sent over the network to the target machine, Vijeo-Designer Runtime loads and runs the user application.

  • If the editor (Vijeo-Designer) and runtime (Vijeo-Designer Runtime) versions don't match, the Runtime Installer application starts up automatically (except when the download is initiated from SoMachine, in which case Runtime needs to be updated manually). If you want to revert to an older runtime version, see Section 25.5, Installing Vijeo-Designer Runtime, and follow the steps for your target machine type.

  • When you run Vijeo Designer on Windows, make sure the target is connected to the network before you start the Runtime installation over the Ethernet.
