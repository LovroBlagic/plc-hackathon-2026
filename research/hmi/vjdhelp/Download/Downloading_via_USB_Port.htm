25.6.3 Downloading over the USB Port

Use USB download when you can connect the target machine to the editor PC's USB port. For a list of target machines that support USB downloads, see Appendix 5, Hardware Specifications.

USB downloads require one of these specially designed download cables:

  • XBTZG935

  • Standard A-miniB Cable +  XBTZGUSBB.

  • For information on how to download using the USB/Serial download cable (XBTZG925), see Section 25.6.2, Downloading over the Serial Port.

  • For the HMISTU, HMISTO, HMIGTO, HMIGTU, HMIGTUX, and HMIGK use the mini-B USB port only for installing Vijeo Designer Runtime or for downloading a project.

  • After starting download, do not forcibly exit Vijeo-Designer or turn off the target machine during download. Trying to cancel or interrupt the download process can make the target machine inoperable. If you have trouble starting the target machine, see Section 25.6.6, Recovering the System on a Target Machine.

  • For a USB download, the transfer speed rate is in the range of 320K bits per second to 1M bits per second. The transfer speed rate varies depending on your target type, the number of data files (video, sound, text, images, etc) in your project, and your target's storage medium. For example, on an XBTGT6340 target, the sample project VJD_Overview_V5_800X600.vdz will take approximately five minutes to download.

Before You Download

Check the following conditions before downloading.

  • USB Driver
    The USB cable requires a special USB driver that is installed on your PC when you installed Vijeo Designer.

Downloading

  1. Connect the USB download cable to the USB ports on the editor PC and the target machine.

  • Connect the USB cable directly to the target machine for best results.

  • You can also connect the USB cable through a hub and into the target machine's USB port. When connecting through an USB hub, you should connect only one USB download cable and one target machine to the hub. However, Vijeo-Designer Runtime allows more than one USB component to be connected and working correctly as long as the USB components are not in the same class driver.

  1. Start Vijeo-Designer Runtime on the target machine.

  2. iPC or XBTGTW: On the Windows desktop, double-click the Vijeo-Designer Runtime shortcut.

  3. XBTGT, XBTGC, or XBTGK Series: Turn on the power.

  1. In Vijeo-Designer, in the Navigator window's Project tab, right-click the Target node and click Properties to open the Property Inspector. Set Download to USB.

  • If the target machine supports Ethernet, the Download properties also list IP address settings. The target machine uses the IP address for communicating with PLCs or sharing data with other target machines on the network.
    Even if the IP address is already set up on the target machine, it's overwritten with the IP address defined here. After download is complete, you can change the IP address settings on the target machine.
    If the target machine is not used in a network environment, you can ignore these settings.

  • Make sure the target machine you are downloading to is the same target type as defined in the Target properties.

  1. Right-click the Target node, and click Download.

  • Downloading erases the files on your target. You can preserve them by using the Preserve Run-Time Data feature.

  1. If the Preserve Run-Time Data property is enabled in the target properties, the Download to Target dialog box opens. Confirm the download and whether you want to delete all the run-time data, including the recipe data, security data, and target system settings that you had selected to preserve in the target properties. If you want to delete all the run-time data (such as data logging, alarms, videos, and snapshots), the recipe data, security data, and target system settings you had previously selected to preserve, select the check box and click Yes.

  1. If you are downloading to the iPC or XBTGTW, the target machine will restart and present the Windows log in screen. After logging on, start Vijeo-Designer Runtime if it isn't set up to start automatically. A dialog box displays in the iPC or XBTGTW as the connection between the editor and target machine is being established. Do not close this dialog box.

After the user application is successfully sent over the network to the target machine, Vijeo-Designer Runtime loads and runs the user application.

  • If the editor (Vijeo-Designer) and runtime (Vijeo-Designer Runtime) versions don't match, the Runtime Installer application starts up automatically (except when the download is initiated from SoMachine, in which case Runtime needs to be updated manually). If you want to revert to an older runtime version, see Section 25.5, Installing Vijeo-Designer Runtime and follow the steps for your target machine type.
