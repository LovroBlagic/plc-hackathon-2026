25.6.4.1 Installing a Single Application to Multiple Targets from a CF Card/SD Card

Vijeo-Designer's Multi-Install feature allows you to download a single application to a CF Card/SD Card and then install the application to multiple target machines.

  • You can only download one application to a CF Card/SD Card. You cannot download two applications to one CF Card/SD Card. The second application would overwrite the first application on the CF Card/SD Card. To download another application without overwriting, you would need to specify a different CF Card/SD Card.

Downloading

  1. Insert the CF Card/SD Card into a CF Card/SD Card reader.

    • Use CF Card/SD Cards manufactured by Schneider Electric only. CF Card/SD Cards from other manufacturers do not meet required specifications. For more information about CF Card/SD Cards you can use, see Appendix 1, Hardware Manuals.

  1. In Vijeo-Designer, in the Navigator window's Project tab, right-click the Target node and click Properties to open the Property Inspector. Set Download to File System.

  2. In the Path property, define the location of the CF Card/SD Card reader.

  • Only local path names are supported for download. To download to a network drive, first map the network drive to your local drive and then define this path for download.

  • Multi-Install will not change the IP address the target machine has been configured with.

  1. In the Install Options property, select Multi Install.

  2. Right-click the Target node, and click Download.

  3. After Vijeo-Designer indicates download is complete, make sure the CF Card/SD Card reader has completed writing before you remove the CF Card/SD Card.

  • Even though Vijeo-Designer may indicate download to the CF Card/SD Card is complete, do not immediately remove the CF Card/SD Card from the drive. Although downloading to the drive may be complete, writing to the CF Card/SD Card may not be. Use the reader's lamp indicator or other method to confirm the write operation has ended before you remove the CF Card/SD Card.

  1. To install the files from the CF Card/SD Card to the target machine, insert the CF Card/SD Card in the target machine's CF Card/SD Card slot and turn on the machine.

Insert the CF Card/SD Card.

On the target machine's CF Card/SD Card dip switches, make sure DipSwitch1 = ON so it loads the application from the CF Card/SD Card into internal memory (flash memory). When this dip switch is OFF, the target machine runs the user application stored in internal memory. Turn on the target machine to install the user application and update the run-time system files.

After all the data is copied over, the runtime and user application begin.

  1. Because Multi Install uses the same communication settings from one target to another, make sure they do not conflict with each other. The communication settings you should check include IP addresses and Target node addresses on PLC networks.

  2. If the user application is set up with data logging or saves other information to file, insert a blank CF Card/SD Card.
