25.3.2.2 Set, Reset, and Write To External Variables

With the icons in the Simulation Tool's menu bar, you can simulate setting/resetting bit addresses and writing values to word addresses.

Set Variable

Click the Set Variable icon to write a value of 1 to all variables.

 

Reset Variable

Click the Reset Variable icon to write a value of 0 to all variables.

 

Write To Variable

  1. Select the variable that you want to write to, then click the Write To icon to display the Write Data dialog box.

  1. In the Write Data dialog box, type the value you want to write to the selected variable then click OK.

The written value is simulated in the Vijeo-Designer Runtime simulation screen.

  1. Press CTRL+Z to exit simulation.
