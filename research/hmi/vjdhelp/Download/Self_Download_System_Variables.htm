25.6.9.2 Self Download System Variables

There are two system variables that provide information about the Self Download process: _SelfDownload.Status and _SelfDownload.Error.

The following tables list and describe their values:

 

_SelfDownload.Status

Value

State

Description

0

Idle

No current Self Download operation.

1

In Progress

Target machine is connecting to the FTP server, checking for update files, or downloading files.

2

Error (fail)

The target machine encountered an error during the Self Download. The target machine will not attempt to download again until the Self Download is re-triggered.

8

Success (download not needed)

The target machine determined that it is currently running the same or a newer version of the project than the one on the FTP Server, and the Force Download option is not selected. Therefore, downloading and updating is unnecessary.

16

Success (download complete)

The target machine has successfully downloaded files from the FTP Server and is now ready to restart and install these files.

 

 

_SelfDownload.Error

Value

State

Description

0

No Error

-

1

Local Storage Failure

The drive you chose in the Self Download to property is unavailable or does not have enough free space.

2

Could not Find FTP server

The target machine failed to open a connection to the FTP Server.

4

Login Failed

The target machine failed to log in to the FTP server using the user name and password provided in the Operations settings.

8

Folder Error

The target machine cannot navigate to the FTP server folder specified, because:  

  • The folder does not exist.

  • The user does not have access permission.

  • The folder does not contain a ProductVersion.inf file.

16

Incompatible Project

The target machine cannot download the project, because:

  • The project on the FTP server is for a different target machine type.

  • The project uses a different run-time version and does not provide run-time files.

  • The run time cannot analyze the ProductVersion.inf file.

32

Different Project

The project on the FTP server is a different project from the one running on the target machine, and the Force Download option is not selected.

64

Network Failure

The target machine lost connection to the FTP server during the download process, or the server returned an unexpected response.

128

Download Failed

CRC check failed.

256

Update Failed

The Install operation was triggered, but the target machine cannot restart itself due to an unsuccessful download.
