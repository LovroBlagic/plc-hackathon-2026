25.3.1 Simulating the Panel Display

You can mimic the graphical display of the target machine by using the Simulation command. Run touch operations by touching switches, touch animated objects, and data inputs. With the simulation feature, you can double-check your project on the PC—and the animation of any objects or parts—before downloading it to the target machine.

  • When the equipment is not connected to the editor PC and an external variable is displayed on the panel, a communication error occurs. To simulate external variables, either connect the equipment to the editor PC or use Device Simulation (see Section 25.3.2, Simulating Device Addresses).

  1. Right-click the Target node and click Start Simulation (Build) to begin the Simulation.

If the equipment is not connected, then device address values appear with the Data Quality icon and a runtime error message displays.

  1. Simulate touch operations by clicking switches, touch animated objects, and data displays set up in the user application and simulated in the Vijeo-Designer Runtime simulation screen.

  2. To end the simulation and return to Vijeo-Designer editor, press CTRL+Z.

  • The build operation runs before the user application is simulated. If you don't want to run build, and simulate a previous version, in the Build Options dialog box select Do Not Build. For information about the Build Options and the build process, see Section 25.4, Building the Project.
