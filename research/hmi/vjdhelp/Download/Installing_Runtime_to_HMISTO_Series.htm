25.5.3 Installing Runtime to HMISTO Series

To install Vijeo Designer Runtime over the USB port using the Vijeo Designer Runtime Installer, you need to use the USB cable BMXXCAUSBH018.

  1. Connect the USB cable to the Type A USB port on the editor PC and the mini-B port on the HMISTO target machine.

  1. On the Vijeo-Designer editor PC, click the Windows Start button, then point to Programs, Schneider Electric, Vijeo-Designer, Tools, and click Runtime Installer

  1. In the Vijeo-Designer Runtime Installer dialog box, select the series number of your target machine. Set Download to USB.

  1. Click Send to start the installation of Vijeo-Designer Runtime.

When runtime installation is complete, a message box displays.

  1. Click OK to close the message box, then click Exit to close the Vijeo-Designer Runtime Installer dialog box.
