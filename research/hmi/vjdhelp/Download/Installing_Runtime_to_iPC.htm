25.5.1 Installing Runtime to iPC and XBTGTW Series

Vijeo Designer Runtime on the iPC and XBTGTW Series must be registered through the Runtime Manager. For more information on the Runtime Manager, see Section 25.5.1.3, Registering Runtime: Runtime Manager.

The Runtime Installer can install or upgrade Vijeo Designer Runtime.

The Runtime Installer supports two installation methods:

  • Ethernet

  • USB

  • If your iPC target has an older version of Vijeo Designer Runtime, Vijeo Designer will not automatically upgrade Runtime to the current version. A message displays informing you of the version mismatch and will prompt you to install Runtime from the product DVD. Press OK to install and register the current version of Runtime. Then you can proceed with the project download.

25.5.1.1 Installing Runtime Using Ethernet

Install Runtime

The Runtime Installer supports IP addresses or host names for targets. Host names require your network to have a DNS server that can store IP addresses and host names. For host names, set up your DNS server with the target's host name and IP address before installing the Runtime. The Runtime Installer contacts your network's DNS server to validate the host name's IP address. Contact your network administrator for information about your DNS server.

  1. Using an Ethernet cable, connect the target machine to the editor PC.

  1. On the Vijeo-Designer editor PC, click the Windows Start button, then point to Programs, Schneider Electric, Vijeo-Designer, Tools, and click Runtime Installer.

  1. In the Vijeo-Designer Runtime Installer dialog box, select your target machine series. Set Download to Ethernet, and define the target machine's network settings.

  2. Click Send to start the installation of Vijeo Designer Runtime.

When runtime installation is complete, a confirmation message displays.

  1. Click OK to close the message box, then click Exit to close the Vijeo Designer Runtime Installer dialog box.

 

Install Runtime over NAT

The Vijeo Designer Runtime can be downloaded to a target machine through a router. The following procedure assumes that your PC and target machine are already connected to the network and the router has been set up with the correct port forwarding rules. For more information on port forwarding and an example of downloading through a router, see Section 25.6.1.2, Downloading through a Router.

  1. On the Vijeo-Designer editor PC, click the Windows Start button, then point to Programs, Schneider Electric, Vijeo-Designer, Tools, and click Runtime Installer.

  2. In the Vijeo Designer Runtime Installer dialog box, select the series number of your target machine. Set Download to Ethernet, and define the following:

  3. IP Address: Target Machine's IP Address

  4. Connect Through: Define the Router's Public IP address

  5. Control Port: Define the port configured on the router that forwards to Target Machine Port 6001

  6. Data Port: Define the port configured on the router that forwards to Target Machine Port 13777

  1. Click Send to install Vijeo Designer Runtime.

 

25.5.1.2 Installing Runtime Using USB

To install Vijeo-Designer Runtime over the USB port, you need to use the USB cable XBTZG935 created specifically for USB downloads. The USB cable requires a special USB driver that is installed on your PC during the Vijeo Designer installation.

  • You can connect the USB cable through a hub and into the target machine's USB port. When connecting through an USB hub, connect only one USB download cable and one target machine to the hub. Vijeo-Designer Runtime allows more than one USB component to be connected and working correctly as long as the USB components are not in the same class driver.

  1. Connect the USB cable to the target machine and to the editor PC.

  1. On the Vijeo-Designer editor PC, click the Windows Start button, then point to Programs, Schneider Electric, Vijeo-Designer, Tools, and click Runtime Installer

  1. In the Vijeo-Designer Runtime Installer dialog box, select the series number of your target machine. Set Download to USB.

  1. Click Send to start the installation of Vijeo-Designer Runtime.

When runtime installation is complete, a message box displays.

  1. Click OK to close the message box, then click Exit to close the Vijeo-Designer Runtime Installer dialog box.

 

25.5.1.3 Registering Runtime: Runtime Manager

The iPC and XBTGTW Series comes pre-installed with Vijeo Designer Runtime. Vijeo Designer Runtime on the iPC/XBTGTW must be registered through the Runtime Manager. A trial period is available for temporary use of the Vijeo Designer Runtime on the iPC/XBTGTW. Once the trial period expires, Vijeo Designer Runtime on the iPC/XBTGTW becomes unavailable.

Runtime Manager

Start Trial Version - Starts the trial version of Vijeo Designer Runtime.

Register Runtime - Registers the Runtime using the Runtime Installation Wizard.

Disable Auto Start - Disables the Runtime Manager and Vijeo Designer Runtime from automatically starting once the iPC/XBTGTW is turned on.
