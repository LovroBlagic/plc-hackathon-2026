25.6.6 Recovering the System on a Target Machine

Use the Recovery Methods listed in the table below when:

  • Vijeo-Designer Runtime is damaged on the target machine.

  • You cannot recover your target's password and you need to reset the password.

  • After recovering the system on the target, you will need to download your project again.

  • For iPC and XBTGTW targets, the Runtime Recovery Tool cannot recover the Runtime if the version on the target is newer than the version on the PC with Vijeo Designer installed.

  • Recovery Methods erase both the project on the target machine and any run-time data files.

  • For recovering the system on XBTGT2110 target machines, contact your local Schneider Electric Technical Support agency.

  • If you need additional serial recovery cables, contact your local Schneider Electric Technical Support agency.

  • Back up all your run-time data from the target machine before recovering.

Recovering the Runtime on the iPC and XBTGTW

The following instructions demonstrate how to recover Vijeo Designer Runtime using the Runtime Installer Tool. The following

  1. On the target machine, exit Vijeo Designer Runtime.

  2. On the target machine, run the Runtime Recovery Tool (usually available on the target machine's desktop).

  3. On the editor PC, run the Runtime Installer Tool.

  4. In the Runtime Installer Tool, select iPC or XBTGTW Series and select either Ethernet or USB

  • Ethernet - Specify the Target's IP Address

  • USB - You must use the USB cable XBTZG935 created specifically for USB downloads

  1. Click Send to start the reinstallation of Vijeo Designer Runtime.

When runtime installation is complete, a confirmation message displays.

  1. Click OK to close the message box and complete the reinstallation.

  • You can also recover runtime using the Restore Tool on the Runtime CDROM provided with the iPC or XBTGTW. Be aware that this CD formats the iPC/XBTGTW disk and reinstalls Windows XPe as well as Vijeo Designer Runtime. Refer to the iPC or XBTGTW User Manual for instructions.

Recovering the Runtime on the XBTGT1005 Series, XBTGT2000 and Higher Series and XBTGK Series

  1. On the Vijeo Designer editor PC, click the Windows Start button, then point to Programs, Schneider Electric, Vijeo-Designer, Tools, and click Runtime Installer.

  2. In the Vijeo-Designer Runtime Installer dialog box, select your target series from the drop-down list box.

  3. Select the Recovery check box.

  4. Follow the instructions shown in the Vijeo-Designer Runtime Installer dialog box to recover the system on the target.
