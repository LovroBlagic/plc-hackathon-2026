25.1 Downloading and Checking Projects at Runtime

After you develop the HMI, you can download the project to the target machine and run the user application. However, you should take steps to make sure the project is defect free before you begin downloading the project.

The following diagram illustrates the typical workflow after you draw the HMI.

After you complete the HMI project, check for errors by validating the project. Once the project is free of any obvious errors, the next step is to build the project and simulating runtime operations. Build generates the files used by the target machine. Once a project successfully builds, you can download the files to the target machine and run the project.

You will probably go through the validation, build, simulation, and download process several times as you discover errors and mistakes that were made during project development. Maximize your time by debugging the project as soon as you begin development, to catch mistakes early.

  • Before downloading, Vijeo-Designer Runtime must be installed on the target machine. See Section 25.5, Installing Vijeo-Designer Runtime.
