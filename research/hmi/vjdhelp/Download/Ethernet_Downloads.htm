25.6.1 Ethernet Project Downloads

Vijeo Designer projects can be downloaded over the network to the target machine. Not all target machines support Ethernet downloads. For a list of target machines that support Ethernet downloads, see Appendix 5, Hardware Specifications.

The following sections describe procedures and information for downloading projects over Ethernet:

  • Ethernet download procedures - Section 25.6.1.1 Downloading over Ethernet

  • Downloading through Routers - Section 25.6.1.2 Downloading through a Router

  • Downloading through Firewalls - Section 25.6.1.3 Downloading through a Firewall

  • Configure any 3rd party FTP servers installed on iPC to use a port other than port 21. Port 21 is used for the download process.
