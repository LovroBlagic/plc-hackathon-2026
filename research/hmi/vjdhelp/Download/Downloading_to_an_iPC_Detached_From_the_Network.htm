25.6.5 Downloading to a Network Folder

Use the Network Folder download method when the target machine is an iPC/XBTGTW.

Use File System to download the user application to either a network folder, CF Card/SD Card, or USB drive. For a list of supported target machines, see Appendix 5, Hardware Specifications.

For iPC/XBTGTW, once the download is complete, take the file to the target machine and use the Vijeo Designer Application Installer to install the user application into Vijeo-Designer Runtime. For other target machines, place the optional drive into the target and reboot to install the application.

If your PC has only one drive partition (that is, only a C:\ drive), you will not be able install your Vijeo Designer application as a .vda file. You must download using a USB cable or the Ethernet.

Before Download

Make sure the version number of Vijeo-Designer Runtime matches the Vijeo-Designer editor. If the versions do not match, update the editor or runtime. For information on displaying version numbers, see Section 26.4.4, Displaying Version Information.

Downloading

  1. In Vijeo-Designer, right-click the Target node and click Properties to open the Property Inspector. Set Download to File System.

  2. In the Path, type the drive letter of the destination (e.g. F:\), which can be either a network folder (for iPCs) or an optional drive.

  • Only local path names are supported for download. To download to a network drive, first map the network drive to your local drive and then define this path for download.

  • In the download path, use ASCII characters only.

  1. Right-click the Target node, and click Download. The user application is downloaded to the defined location as a .vda file.

  2. Move the downloaded file (.vda) to a drive visible from the target.

  3. On the target, click the Windows Start button, point to Programs, Schneider Electric, Vijeo-Designer, Tools, then click the Vijeo-Designer Application Installer.

  4. In the Application Installer, use one of the following methods to select the compressed project file:

  • Type the path of the .vda file.

  • Click Browse and locate the .vda file.

  • Drag and drop the .vda file from Explorer.

  1. If you are using a Smart iPC or XBTGTW to download the user application, you have to unlock the Main drive.

  • If the Main drive is locked, in the message box that displays, click Unlock and Restart to shut down and restart Windows.

  • After Windows starts up, if a run-time message box displays, click Quit.

  • Next, run the Vijeo-Designer Application Installer to continue installation.

  • When installation is complete, click Lock And Restart to protect the Main drive.

  1. Start Vijeo-Designer Runtime to run the user application.

  • During download, do not forcibly exit Vijeo-Designer, or turn off either the PC or target machine during download. Trying to cancel or interrupt the download process can make the target machine inoperable. If you have trouble starting the target machine, see Section 25.6.6, Recovering the System on a Target Machine.

  • If the editor (Vijeo-Designer) and runtime (Vijeo-Designer Runtime) versions don't match, download will proceed after you confirm a version update when prompted. Update either the editor or the runtime.
