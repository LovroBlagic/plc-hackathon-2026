25.6.8 Downloading to Multiple Targets

When you have more than one target connected to a project, you can download to all the targets automatically by selecting Download All on the Project node. This will download the project files to each target in turn (not simultaneously). Thus, Download All is the equivalent to selecting Download on each Target node, one at a time. The targets do not have to be the same target types or models, or use the same download methods.

Before You Download

Check the following condition before downloading.

  • Vijeo-Designer Runtime
    Make sure Vijeo-Designer Runtime is already installed on the target machine. For information on how to install the runtime, see Section 25.5, Installing Vijeo-Designer Runtime.

  • Make sure the version number of Vijeo-Designer Runtime matches the Vijeo-Designer editor. If the versions do not match, update the editor or runtime.

Downloading

  1. Connect the appropriate cables from the editor PC to each target machine.

  1. Start Vijeo-Designer Runtime on the target machines.

  2. iPC or XBTGTW: On the Windows desktop, double-click the Vijeo-Designer Runtime shortcut.

  3. XBTGT, XBTGC, or XBTGK Series: Turn on the power.

  1. Make sure each target is set up with the proper downloading method. See Section 25.6, Downloading the Project, for more information on the downloading methods available and for which methods are supported by each target.

  1. Right-click the Project node, and click Download All...

  2. If you are downloading to an iPC or XBTGTW, the target machine will restart and present the Windows log in screen. After logging on, start Vijeo-Designer Runtime if it isn't set up to start automatically. A dialog box displays in the iPC or XBTGTW as the connection between the editor and target machine is being established. Do not close this dialog box.

After the user applications are successfully downloaded, Vijeo-Designer Runtime loads and runs the user applications.

  • After starting download, do not forcibly exit Vijeo-Designer or turn off the target machine during download. Trying to cancel or interrupt the download process can make the target machine inoperable. If you have trouble starting the target machine, see Section 25.6.6, Recovering the System on a Target Machine.

  • If the editor (Vijeo-Designer) and runtime (Vijeo-Designer Runtime) versions don't match, the Runtime Installer application starts up automatically (except when the download is initiated from SoMachine, in which case Runtime needs to be updated manually). If you want to revert to an older runtime version, see Section 25.5, Installing Vijeo-Designer Runtime and follow the steps for your target machine type.
