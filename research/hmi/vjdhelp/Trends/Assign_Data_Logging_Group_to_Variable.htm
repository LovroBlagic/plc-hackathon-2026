13.2.3 Assigning a Data Logging Group to a Variable

Follow these steps to associate a variable with a data logging group.

  1. Click the data logging group to display the Data Logging Spreadsheet.

  2. In the Data Logging spreadsheet, click Add to open the Variables List dialog box.

  3. Select the variable you want to add to the data logging group. The variable will appear in a new row on the spreadsheet.

  • You can also set the data logging group in the Variable Property Inspector.

  • Project validation checks data logging group property values in variables and checks that the number of data logging variables has not exceeded the maximum.

  • Project validation checks for data logging group property values in variables used in trend graphs. If the Data Logging Group property for the variable is set to None, then an error message will display.

Removing a Variable from the Data Logging Group

  1. Select the variable you want to delete.

  2. Right-click the row number of the variable. Select Remove from group to remove the variable.

You can remove multiple variables by clicking the first row number column and dragging down to select the variables you want to remove. Then right-click and select Delete.
