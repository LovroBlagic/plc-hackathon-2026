13.3.2 Setting Up Trend Graphs

  1. Click the Trend Graph icon in the Graphical Objects Parts toolbar, or from the Draw menu select Trend Graph.

  1. Click the area on the panel where you wish to start the trend graph image. Move the cursor diagonally to create the appropriate size for the Trend Graph. Click the panel again when you have the proper size.

  1. Right-click the Trend Graph and choose Properties. The Trend Graph's properties will appear in the Inspector. Use the properties tables below to define the desired trend graph and channel settings.

Graph Settings

Direction

You can select the direction of the graph from Up, Right, Down, Left.

Data Location

Select the location of the data axis. When the Direction is Left or Right, the options are Left and Right. When the Direction is Up or Down, the options are Top and Bottom.

Select the location of the time (horizontal) axis. When the Direction is Left or Right, the options are Top and Bottom. When the Direction is Up or Down, the options are Left and Right. The time axis displays the axis line only. The time does not display.

Num Of Samples

Select the number of data samples to display on the graph.

Example. When Num Of Samples (number of points) = 11:

 

 

Minimum number of samples is 2. The maximum number of samples depends on your target machine. For example, if you have a setting of 800×600 (SVGA) pixels panel on your target machine, the maximum number of samples will be 800 points (when Direction is Right or Left).

If you want to display labels, you must consider the width of the labels because labels will lower the maximum value to less than 800 points.

 

Pitch

This property is read only. This setting defines the amount of spacing between data samples (in pixels) by automatically calculating from the size of the graph and the value specified in Num Of Samples.

Scroll

When the graph data area fills up, this setting controls the number of samples the trend graph will scroll to make room for new data samples.

Clear Trigger

Select the check box to enable the Clear Trigger property. Trend graph data samples erase when the Clear Trigger variable’s value changes. For BOOL Clear Trigger variables, a value change from False to True (0 to 1) erases the data. Erasing does not occur for True to False (1 to 0) value changes. For Integer Clear Trigger variables, any value change erases the data except if the value changes to 0.

  • When using a Real-Time Trend Graph with triggered data logging, and you use a Clear Trigger Variable to erase its data, all the data gets cleared but reappears again after a few moments. In this case, the current value of variables get drawn on the trend graph, and clearing the display does not erase the stored data. As the data is updated at regular intervals, the current values appear seconds after the graph data cleared as per the trend graph settings. If you want to use triggered data logging, consider using a Plot trend graph, where you can use a trigger variable to capture values on the graph, and use a clear trigger variable to erase the graph values.

Range Settings

Click on to access the Range Settings properties. The properties are defined below.

Data from variable values are converted using the defined Value Range and Display Range.

If values are truncated, they are rounded to the nearest decimal place.

 

Value Range

Value Range From

Defines the minimum value of data stored in the variable that is assigned to the channel.

If the variable data is smaller than the Value Range From value, the data will be considered equal to the Value Range From value.

Value Range To

Defines the maximum value of data stored in the variable assigned to the channel.

If the variable data is larger than the Value Range To value, the data will be considered equal to the Value Range To value.

Display Range

Display Range Min

Defines the minimum value displayed by the graph.

Display Range Max

Defines the maximum value displayed by the graph.

Each line plotted on the Trend Graph is called a channel. Each graph can display up to eight channels.

  1. To define a channel, set it to Enabled and click the icon.

See the table below for descriptions on the Trend Graph Channel properties.

 

Trend Graph Channel Properties

Property

Description

Channel1-8

You can select the channels you want to graph by setting each channel to Enabled or Disabled. Enable a channel to set the following properties.

Variable

Sets a variable to a channel. You can assign a local variable or a remote variable from another target to the channel.

 

 

Local variables in this field display just their name, for example, BOOL01. Remote variables display their Target name followed by their variable name, for example, Target2.DINT01.

 

  • Ensure that the variable you assign to the channel has a data logging group associated with it. For more information, see Section 13.2.3, Assigning a Data Logging Group to a Variable.

  • Data sharing must be enabled to log remote variables on the trend graph. For more information, see Section 22.1.1, Setting Up Shared Variables.

Select Enabled or Disabled. When Enabled, dots appear on the trend graph at points wherever a data sample is taken. Both Baseline and Mark cannot be Enabled at the same time.

  • The size of the marks is fixed.

  • These settings are not available if you select Fill for Display Format.
