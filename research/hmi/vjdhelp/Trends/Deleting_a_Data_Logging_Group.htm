13.2.4 Deleting a Data Logging Group

  1. Right-click the Data Logging node, and select Delete...

  1. In the confirmation dialog box that opens, select Yes to delete the data logging group.

When the data logging group is deleted, all variables assigned to that data logging group will continue to be associated with that data logging group. The Data Logging Group property in the variable's properties will be highlighted red and its value will be the data logging group name with "Not Defined" beside it, for example, LoggingGroup01: Not Defined.

During project validation, you will see an error message in the Feedback Zone for any variable that has an invalid data logging group assigned to it. To fix, you need to enter a valid data logging group in the variable properties.
