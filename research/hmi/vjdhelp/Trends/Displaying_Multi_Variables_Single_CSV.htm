13.1.1.5 Saving Multiple Variable Values to a Single CSV File

You can save a collection of variable values into a single CSV file using custom event messages. This process works by logging a custom event message that contains multiple variable names and variable values to an event group. Then outputting the event group messages to a single CSV file.

 

The following instructions describe how to create an event group and a custom event message so you can save multiple variable values to a single CSV file:

  1. In the Navigator window, add an event group under the Alarms and Events node. For more information, see Section 16.3.1, Alarm and Event Groups.

  2. In the event group properties, select the Save to File check box, and click the Configure button.

  3. In the Save to File dialog box, click the Format tab and put Date, Time, and Message columns into the Columns to Save list. For more information, see Section 16.2.4.2, Event Group Settings.

  4. Create a new text resource and create a custom event message with dynamic content to log your variables values. For example, the following custom event message would log the values of 3 variables: "Variable1: <var:variable1>, Variable2: <var:variable2>, Variable3: <var:variable3>". For more information on dynamic text content, see Section 21.1.5.12, Setting Up Messages with Dynamic Content.

  5. Create an action with an Event Message operation to periodically trigger the custom event message to log to the event group. For more information, see Section 9.5 22, Event Message Operations.

  6. Create a switch to trigger the event group's Save to File operation to save the event messages to a CSV file. For more information, see Section 16.3.6, Outputting Alarms and Events to a CSV File.
