13.2 Setting Up a Variable for Data Logging

From the Data Logging node, you can create and manage data logging groups, and then associate variables to a data logging group. For all target types, you can set a maximum of 80 data logging groups. If you try to create more than 80 groups, a message displays informing you that you have reached the maximum number of groups.

For projects created in Vijeo-Designer Version 4.3 and earlier that are converted to the current version, variables that use data logging are assigned to a data logging group that best matches the old data logging settings. Trend graph Toolchest parts are also updated to use the current data logging system.

All variables are validated during project validation. Variables that are used in a real-time trend graph that are not associated to a data logging group will be shown in error. To fix, you must assign the variable to a data logging group or remove the variable from the trend graph.

This section describes how to:

  • Set up data logging

  • Create a data logging group

  • Assigning a data logging group to a variable

  • Delete a data logging group.
