13.1 About Data Logging

Data logging allows you to collect and store variable values. With data logging, you can specify what variables you want to log, determine the frequency of data sampling, and specify where the data will be stored.

Data logging supports BOOL, REAL, integer types, and STRING variables. The number of variables that you can log in one project depends on the target machine. Variable data is used by the Trend Graph function. You should not exceed the recommended maximum number of variables used in one data logging group. See Appendix 4, Run-Time Specifications.

Data logging enables you to keep a history of particular elements in a production process, which you can use, for example, to analyze, audit, and track performance. You can display logged data in graphs and save the data to file.

Key Data Logging Features

Vijeo-Designer provides these key data logging features:

  • Data logging allows you to select a data collection method – periodic or trigger – so you can determine how often you want your data to be sampled. The periodic method gives you a snapshot of the data at regular time intervals. The trigger method gives you a snapshot of the data when the trigger is activated. For more information, see Section 13.1.1.2, Specifying When to Collect Data.

  • You can manage how much data is being stored and where the data will be stored (DRAM, SRAM, or file). The DRAM storage option preserves the most recent data. The SRAM storage option preserves a specified number of data records for a data logging group. The file storage option uses the SRAM as a storage medium until its capacity is reached, in which case, the data in SRAM is written to file. For more information on displaying logged data, see Section 13.1.1.3, Storing Your Collected Data.

  • You can display logged data in Real-Time Trend Graphs, Historical Trend Graphs, or Plot Trend Graphs. A real-time trend graph shows the data samples of a variable and is updated at a regular interval when new data samples from the variable are added. An historical trend graph displays data samples and allows you to view data sample history. A plot trend graph displays current values collected using the trigger data collection method. With a block trend graph, you can display multiple data samples at a point in time. For more information, see Section 13.1.1.4, Displaying Your Data.

  • Logged data that is stored as a file can then be converted into a .csv file using the Data Manager. This enables you to preserve your collected data for future reference. For more information, see Section 20.5.2.4, Converting Recipe and Data Logging Files.

  • Toolchest parts are provided in Vijeo-Designer to make it easier to create historical trend graphs, plot trend graphs, block trend graphs. You can choose the graph that you want, and then drag and drop it into your panel.

  • You can assign variables from other targets to a single trend graph. This enables you to monitor logged data from multiple targets on a single display. For more information, see Section 13.3.2, Setting Up Trend Graphs.
