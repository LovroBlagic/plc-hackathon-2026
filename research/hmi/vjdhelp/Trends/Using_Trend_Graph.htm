13.1.2 Types of Trend Graphs

This section describes the different types of trend graphs (real-time, historical, or plot) that you can create to display your logged data.

If you find target machine performance to be slow when using trend graphs, check for the following:

  • The number of data samples specified to display on a trend graph is higher than the number of records specified to store in RAM. This means that besides displaying current records, the system needs to access the data file to obtain older records for display on the trend graph. To minimize the problem, reduce the NumofSamples value in the Trend Graph Property Inspector, or increase the No. of Records in RAM value in the Logging Group Settings dialog box.

  • The number of days to store data records and maximum data size values are too high and a lot of data is collected. The slower performance may be due to the amount of variable values being logged over an increased period of time and having a larger file to access. To solve this problem, reduce the No. of Days and Maximum Data Size values in the Logging Group Settings dialog box. We recommend a maximum of 90 days' history. If you want to keep permanent records of your variable data, regularly move the data from the target machine to your database, and then delete the data on the target machine.

13.1.2.1 Real-Time Trend Graphs

You can use the Trend Graph function to create a line graph that shows the current values of one or more specified variables. Trend graphs are updated at a regular interval when new data samples from the variable are added. When the data area on the graph fills up, the graph scrolls by the number of intervals you specify to make room for new data samples. You can specify 1 second or more for the interval.

 

  • You can display data for up to eight different variables, each set up as a channel, in a trend graph.

  • When you download the user application a second time, the data will clear and the trend graph display will reset. Always be sure to back up your projects.

  • When displaying several variables with different Logging Interval settings in the same trend graph, the trend graph will always display the data using the shortest logging interval.
    For details about Logging Intervals, see Section 13.3.2, Setting Up Trend Graphs.
