13.4.2 Setting Up Historical Trend Graphs

  1. Click the Toolchest icon to open the Toolchest window.

  2. Select the TrendGraph folder, and then select the Historical Trend folder.

  3. Move the Historical Trend Graph onto the panel using the drag and drop operation.

You can choose from three types of parts for the Historical Trend Graph.

  • Trend3D_01 - Trend graph with 3D color. Ideal for the target machine with 256 color display or more. The minimum size (width x height) is 350 x 250 pixels. The time stamp for the latest data, number of visible samples, and logging interval (s/Sample) appear at the top of the graph.

  • Trend2D_0002_01 - Trend graph with 2D color. The time stamp for the latest data, number of visible samples, and logging interval (s/Sample) appear at the top of the graph.

  • Trend_0003_01 - Trend graph in smaller size with 2D color. The time stamp for the latest data appears at the top of the graph.

  1. Be aware that the date/time you select in the graph calendar defines the date/time of the first sample to display on the graph. The date/time displayed in the graph’s header is the date/time of the last sample displayed on the graph.

  1. Right-click the Historical Trend Graph and click Properties. The Historical Trend Graph properties display in the Inspector.

TimeAxisRange

Defines how data samples are plotted on the X-axis in the trend graph. Select one of the following options:

  • NumOfSamples: Displays the number of data samples defined in the Value or Variable properties.

  • Time: Displays data samples within the time period defined in the Value or Variable properties.

If you set the time range to view the maximum number of samples, each pixel from the left to the right in the trend graph's display area will be used to represent one sample. If the number of samples for display exceeds this range, a red "+" sign will be displayed near the upper left corner of the graph to indicate the graph cannot show everything. You can adjust the graph's display range by resizing the graph itself.

For example, if you set a channel variable for triggered logging, the time intervals will always be one second. In this case, you will have too many samples to display, and a red "+" sign will display.

NumOfSamples

This property is displayed when you select NumOfSamples in the TimeAxisRange property. Click to expand the NumOfSamples properties. Specify a Constant Value or Variable to indicate the number of data samples to display in a trend graph view.

Value

This property is available when NumOfSamples is set to Constant Value. Enter a value within the valid range (2 to 800) to indicate how many data samples to display in a trend graph view.

If you want to view more data samples, enter a high value within the valid range. If you want to view less samples, enter a low value within the valid range.

Variable

This property is available when NumOfSamples is set to Variable. Specify an integer variable to indicate how many data samples to display in a trend graph view. At Runtime, you can change the number of samples to display on the trend graph by changing the variable value.

 

  • Though you can change the number of data samples that you want displayed on the trend graph, the trend graph may not give you expected results because the number you entered may have exceeded the trend graph's limit (2-800).

Time

This property is displayed when you select Time in the TimeAxisRange property. Click to expand the Time properties. Specify a Constant Value or Variable to indicate the number of data samples to display in a trend graph view.

Unit

Select seconds, minutes, hours, or days as the time unit.

Value

This property is available when Time is set to Constant Value. Enter a value within the valid range (2 to 800) to indicate the time period for data samples to display on the trend graph.

Variable

This property is available when Time is set to Variable. Specify an integer variable to indicate the time period for data samples to display on the trend graph. At Runtime, you can change the time period for data samples to display on the trend graph by changing the variable value.

 

  • Though you can change the time period, the trend graph may not give you expected results because the number you entered may have exceeded the trend graph's limit (2-800).

DataAxis

Decimals

Enter a value from 0 to 10 to define the number of decimal places to include in the numerical values on the data axis.

When the number of decimal for the data axis label is 0, the display range will be from -9.9e16 to +9.9e16. The more decimal places there are, the less the maximum value of the display range will be.

If values are truncated, they are rounded to the nearest decimal place.

PowerOffIndicator

Define when the target machine will be turned off, then back on. Because you can use the historical trend graph to review past data, there may be periods when the target machine was off and no data was collected.

When you select Line as the indicator, vertical lines the height of the graph area are drawn between the points when the target machine turned off and when the target machine turned on.

When you select Rectangle as the indicator, the entire area between these points are shaded in the selected color.

PenIndicator

Select Enabled to add arrows that indicate the current variable value in the Data Axis.

Each line plotted on the Trend Graph is called a channel. Each graph can display up to eight channels.

  1. To define a channel, Enable it and click its icon.

 

See the table below for descriptions on Historical Trend Graph Channel Properties.

Historical Trend Graph Channel Properties

Property

Description

NumOf Channels

The number of channels you can graph. You can set up a maximum of eight channels.

Channel# Variable

 

Sets a variable to a channel. You can assign a local variable or a remote variable from another target to the channel.

 

 

Local variables in this field display just their name, for example, BOOL01. Remote variables display their Target name followed by their variable name, for example, Target2.DINT01.

 

  • Ensure that the variable you assign to the channel has a data logging group associated with it. For more information, see Section 13.2.3, Assigning a Data Logging Group to a Variable.

  • Data sharing must be enabled to log remote variables on the trend graph. For more information, see Section 22.1.1, Setting Up Shared Variables.

For each channel, click to access the advanced settings shown below.

 

  • You cannot use system variables in the Historical Trend Graph.

Color

Select the line color for each channel

BackColor

Select the background color for each channel.

LineStyle

Select the line style for each channel.

LineWidth

Select the line width for each channel.

Mark

Select True or False to display marks on the graph for each channel. When True, dots appear on the graph at points wherever a data sample is taken.

  • If you used historical trend graphs in version 4.2, and you upgrade the Toolchest parts by adding a historical trend graph using the current version, the Mark property is forced to False.

Restore Defaults

Click the arrow button to restore the original default property settings.

Placeholder

You can assign a placeholder in any property that requires a variable definition. Click the ellipsis to open the Placeholders dialog box and edit the variable placeholder for the object. The dialog box only displays if you had set up a placeholder for the object. For more information on placeholders, see Section 21.2.4, Working with Variable Placeholders.
