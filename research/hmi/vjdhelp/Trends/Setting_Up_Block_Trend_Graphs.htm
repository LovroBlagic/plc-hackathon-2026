13.6.2 Setting Up Block Trend Graphs

  1. Click the Toolchest icon to open the Toolchest window.

  2. Select the Graph folder, the TrendGraph folder, and then the Block Trend folder.

  3. Move the Block Trend Graph onto the panel using the drag and drop operation.

  4. Right-click the Block Trend Graph and click Properties. The Block Trend Graph properties display in the Inspector.

Use the tables below to define the graph and channel properties for the Block Trend Graph.

Block Trend Graph Properties

Property

Description

Name

The Block Trend Graph part's name.

Whenever an object is created, a default name is generated. When renaming an object, its name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

For details, see Appendix 9, Naming Conventions.

Version

This property is read only. It displays the name of the part and the supporting Vijeo Designer's version.

Top

The coordinates, in pixels, of the top-left corner of the object.

  • Top is measured from the top of the object to the top of the panel. Enter a value for object height.

  • Left is measured from the left side of the object to the left side of the panel. Enter a value for object width.

By changing these properties, the graphical object can be moved up, down, left, and right.

 

 

Left

Width

The width/height of the Block Trend Graph in pixels. The minimum size for each Block Trend Graph is 320W x 240H pixels.

Height

Display Time

Set Display Time to Enable and define the Display Time properties.

Time Format

Select a time format.

Date Format

Select a date format.

Time Font

Click to open the Font Editor. Select your font preferences for the time display and click OK.

Text Color

Select a text color from the color palette.

Trigger Type

The Trigger is evaluated using the condition selected here. When the condition is met, data collection takes place. Select When True, When False, and On Data Change.

  • When True. Whenever the Trigger Variable changes from 0 to any value, a snapshot of the data is taken.

  • When False. Whenever the Trigger Variable changes to 0 from any value, a snapshot of the data is taken.

  • On Data Change. Whenever the Trigger Variable changes in value, a snapshot of the data is taken.

Trigger

Enter an integer or BOOL variable to control when data collection takes place. You can enter a string variable if the Trigger Condition is set to On Data Change. Use Trigger Condition to define how this variable triggers data collection.

Value Min

Defines the minimum and maximum values the block trend graph will display.

You can use a constant value or a variable. Use the variable if you want to change the minimum and maximum values dynamically at runtime. Make sure the Min value is less than the Max value.

Value Max

Frame Color

Select a color for the frame. The color palette displays when you click the color area.

Data Axis Scale

Select Enable to display the scale along the data (vertical) axis of the graph.

Color

Select the color of the data (vertical) axis scale.

Divisions

Defines the number of divisions for the data axis. Enter a value between 1 and 100.

Data Axis Label

Select Enable or Disable to display the data axis label. If you select Enable, the block trend graph displays the data labels along the data axis scale.

Label Font

Click to open the Font Editor. Select your font preferences for the label and click OK.

Color

Select the text color for the data axis label from the color palette.

Data Axis Grid

Select Enable or Disable to display grid lines on the block trend graph.

Color

Select the color of the grid lines along the data (vertical) axis.

Channel Axis Grid

Select Enable or Disable to display grid lines for each channel.

Color

Select the color of the grid lines along the channel (horizontal) axis.

Channel Axis Scale

Select Enable to display the scale along the channel (horizontal) axis of the graph.

Color

Select the color of the channel (horizontal) axis scale.

Number of Data

Enter a constant value or variable to define the number of data samples you want to display on the block trend graph. The constant range is between 1 and 1024. The value of the variable must be between 1 and 1024. Use the variable if you want to change the number of data to be displayed at runtime.

Channels

Specify the number of channels to graph. You can set up a maximum of eight channels.

Channel#

Each line plotted on the block trend graph is called a channel.

Variable

Set a block integer variable to a channel. In the block integer variable properties, specify the Start Address for the device addresses.

Start Index

Enter a variable to define the first block element in the block variable that stores the data values. The default Start Index value is 0, as defined in the variable's Initial Value property. On the block trend graph, the display starts from the Start Index.

Style

Select a style (line or bar) for the block trend graph.

Color

Select the line color for each channel on the block trend graph.

Back Color

Select the background color for each channel on the block trend graph.

Line Style

Select the line style for each channel on the block trend graph.

Line Width

Select the line width for each channel on the block trend graph.

Fill Pattern

Select the style of the fill pattern.

Mark

Select the style for the marks that will display on the graph. You can select from many styles, such as a dot, circle, cross, diamond, and rectangle.

Restore Defaults

Click the Restore arrow button to restore the original default property settings.

Placeholder

You can assign a placeholder in any property that requires a variable definition. Click the ellipsis to open the Placeholders dialog box and edit the variable placeholder for the object. The dialog box only displays if you had set up a placeholder for the object. For more information on placeholders, see Section 21.2.4, Working with Variable Placeholders.

  1. Create a switch to activate the trigger for the block trend graph. For more information, see Section 9.2, Creating Switches. Set the switch to a Bit-Toggle operation. Set the Destination variable for the switch to the same variable specified in the Trigger property.

  1. Set up the equipment for your project. For more information, see Section 5.2, Setting Up Your Equipment.

  2. Set the Start Index to a variable. Then create a numeric display and reference it to the variable specified in the Start Index property. At runtime, you can change the elements you want displayed on the block trend graph, starting with the value specified in the variable for the Start Index.

  1. To zoom in/out of the block trend graph:

  • Set the Number of Data property to a variable. Then create a numeric display and reference it to the variable specified in the Number of Data property. At runtime, you can change the number of data for display on the block trend graph. To zoom in to the data, specify a high number of data to display. To zoom out, specify a low number of data to display.

  • Set the Value Min and Value Max properties to a variable. Then create a numeric display for each, and reference it to the variable specified in each Value Min and Value Max property. At runtime, you can change the minimum and maximum values to zoom in/out of the data.
