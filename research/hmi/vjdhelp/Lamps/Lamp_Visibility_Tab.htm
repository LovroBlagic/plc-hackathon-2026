10.2.4 Visibility Tab

Use the Visibility tab to set up features such as Visibility and Blink.

 

Property

Description

Enable Visibility

Select Enable Visibility and then select a variable that controls whether the lamp is visible (ON) or not (OFF). You can set up a BOOL or integer variable, or a boolean expression.

  • If true, the lamp will display.

  • If false, the lamp will not display.

Invisible when in invalid state

Available only for N-State lamps. If selected, the N-State lamp will not be drawn when it is in an invalid state. The N-State lamp is in an invalid state if the value of the variable does not equal an Integer Value. For more information on assigning Integer Values to a state, see Section 21.8, Using Value List.

Enable Blink

Select Enable Blink to make the switch blink. You can set up a BOOL or integer variable, or a boolean expression.

  • If true, the lamp will blink.

  • If false, the lamp will not blink.

Speed

Set the blinking speed to fast or slow. A fast blink rate is 350 ms and slow blink rate is 700 ms.
