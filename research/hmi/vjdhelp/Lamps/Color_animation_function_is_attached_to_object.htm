10.5.1 Creating Your Custom Lamp with Color Animation

  1. On the panel, draw a graphical object shape you want to use as a lamp.

  2. Select the drawing and double-click to open the Animation Properties dialog box.

  3. In the Mode property, select one of these options, and follow the steps for the selected mode:

    • Free Form – allows you to select color animation by using the local settings.

    • By State – allows you to use color resources in color animation.

  4. To have the lamp labels and lamps change colors together, you can create labels to match the lamps.
