10.2.3 Label Tab

In the Label tab of the Lamp Settings dialog box, you can specify text for each state of the lamp, its Language (when the lamp is set up with multiple languages), Font type, Font Style, Font Size, and Alignment.

You can set the label only on a lamp object.

The contents of the Label tab depends on the type of lamp you set up (Lamp or N-State Lamp). For more information on the lamp types and categories, see Section 10.2.1, General Tab.

 

The following table describes the Label tab properties.

Property

Description

Label Type

To set up labels on the lamp, select Static, On / Off (for Lamps), or N-State (for N-State Lamps).

  • Disabled: Select to disable the lamp's labels.

  • Static: Select if you want to set up the same string for all lamp states. The label you define in the Label setting is applied for all states.

  • On / Off State: For Lamps, select if you want to set up different labels for the On and Off states.

  • N-State: For N-State Lamps, select if you want to set up a different label for each state.

When you select Static or On / Off as the Label Type, the following settings become available so that you can configure the text labels for the Lamp.

Text Resource

Available when Label Type is On / Off (for Lamps) or N-State (for N-State Lamps).

Select the Text Resource you created in the Resource Library to use for the lamp's labels. For more information on using Resources in your parts, see Section 21.1.4.2, Selecting Resources for Your Part.

Language

Select the language that you want to set up the label for. You can set up a different label for each user language. For more information, see Section 20.2, Switching Languages.

Font Resource

Select the Font Resource you created in the Resource Library to use for the lamp's labels. For more information on using Resources in your parts, see Section 21.1.4.2, Selecting Resources for Your Part.

(ON/OFF) Label

Font

Select a font for the text.

Font Style

Select a style for the text, either Normal, Bold, or 3D. 

Label Text Box

Enter up to 255 characters of text to be displayed on the lamp for each state.

 

  • When inputting multiple lines of text, the carriage return [Enter] also counts as a character.

  • Tabs are not supported by Editor or Runtime.

Font Size

(Width/Height)

Set the text width and height.

Overwrite Text in All Languages

Available when multiple languages are set in the Language node. Overwrites the text in all languages with the text defined in the Label. For more information, see Section 20.2, Switching Languages.

Empty Language Operation

Available when multiple languages are set in the Language node. Click the list box and select one of the following:

  • Text content only: Copies the text defined in the label and pastes it in the languages that have empty labels.

  • Text content, font, size, and style: Copies the text font, size, and style defined in the label and pastes it into the languages that have empty labels.

Alignment

Select the placement of the text. You can select a combination of horizontal and vertical alignments.
