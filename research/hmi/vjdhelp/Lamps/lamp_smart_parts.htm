10.7.1 Lamp Part Properties

Special Lamps: Rotary Lamp

In the Property Inspector, specify the variable or device address that controls the rotary lamp's OFF/ON changes, including its rotation speed.

The following list describes Rotary Lamp properties.

Property

Description

Name

The lamp's name.

Whenever an object is created, a default name is generated. When renaming an object, its name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

For details, see Appendix 9, Naming Conventions.

Description

This read-only property is the name of the part and the version of Vijeo-Designer that supports the part.

Top

The coordinates, in pixels, of the top-left corner of the object.

  • Top location: –32768 to (32767 – height)

  • Left location: –32768 to (32767 – width)

By changing these properties, the graphical object can be moved up, down, left, and right.

Left

Width

The object's width and height can be set from 1 to 3000 pixels.

Height

Variable

Specify a BOOL variable to turn the lamp OFF or ON.

TurnTime

Select the rotation speed of the lamp either Slow or Fast.

RestoreDefaults

The arrow button restores the original default property settings. A message prompts you to either continue with the restore or cancel the action.

Placeholder

You can assign a placeholder in any property that requires a variable definition. Click the ellipsis to open the Placeholders dialog box and edit the variable placeholder for the object. The dialog box only displays if you had set up a placeholder for the object. For more information on placeholders, see Section 21.2.4, Working with Variable Placeholders.

 

Special Lamps: Tower Lamp

In the Property Inspector, specify the variables or device addresses that control the tower lamp's OFF/ON changes, including the tower's rotation cycle and the blink action for each of the five lamps in the tower.

The following list describes Tower Lamp properties.

Property

Description

Name

The lamp's name.

Whenever an object is created, a default name is generated. When renaming an object, its name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

For details, see Appendix 9, Naming Conventions.

Description

This read-only property is the name of the part and the version of Vijeo-Designer that supports the part.

Top

The coordinates, in pixels, of the top-left corner of the object.

  • Top location: –32768 to (32767 – height)

  • Left location: –32768 to (32767 – width)

By changing these properties, the graphical object can be moved up, down, left, and right.

Left

Width

The object's width and height can be set from 1 to 3000 pixels.

Height

OnRed

Specify a BOOL variable that displays the lamp's specified color when the value is ON.

OnYellow

OnGreen

OnBlue

OnWhite

BlinkRed

Specify a BOOL variable that blinks the lamp's specified color when the value is ON. The OnRed variable's value must also be ON.

BlinkYellow

BlinkGreen

BlinkBlue

BlinkWhite

BlinkCircleInterval[ms]

Specify a length of time (ms.) for a one-revolution cycle of the tower lamp. This setting applies to all five lamps in the tower.

RestoreDefaults

The arrow button restores the original default property settings. A message prompts you to either continue the restore or cancel the action.

Placeholder

You can assign a placeholder in any property that requires a variable definition. Click the ellipsis to open the Placeholders dialog box and edit the variable placeholder for the object. The dialog box only displays if you had set up a placeholder for the object. For more information on placeholders, see Section 21.2.4, Working with Variable Placeholders.
