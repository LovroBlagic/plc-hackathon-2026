10.5.2 Creating Labels for Custom Lamps

To create a lamp with a label, set up a text object with Color and Value Animation. In the Value Animation, specify text strings for the ON label and the OFF label. To synchronize the ON/OFF displays of the lamp and label, use the same BOOL variable for the Color and Value animations.

  • Under the Value tab, if you select the Enable Input Mode and Display Popup Keypad check boxes, you can touch the lamp to display a keypad for changing the lamp state.

 

For details about setting up keypads, see Section 11.9, Inputting Data with Keypads.
