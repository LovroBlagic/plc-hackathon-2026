10.2.1 General Tab

This section describes how to define the basic settings for a Lamp or N-State Lamp.

  • Lamp Settings

  • N-State Lamp Settings

Lamp Settings

In the General tab, define the Lamp's Name, Variable, Category, and Style.

The following table describes the General tab properties for a lamp.

Property

Description

Name

The lamp's name.

Whenever an object is created, a default name is generated. When renaming an object, its name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

For details, see Appendix 9, Naming Conventions.

Variable

Select an integer or BOOL variable that will control the lamp states.

State

Icon that toggles between the lamp states controlled by the Lamp variable. You can view how the lamp changes between the ON and OFF lamp states in the Color tab.

Category

Select either Primitive, Bitmap, or User Defined. Depending on the category you select here, the shapes in the Style list change.

 

Primitive

Defines the shapes available in the Style list. Using Primitive, you can define colors for the various states of a lamp.

Bitmap

Defines the bitmap shapes available in the Style list. The list includes bitmap images that you had previously defined. You cannot edit colors using this option.

User Defined

Allows you to define your own images for the various states of the lamp. To select your own image, in the Category field, set to User Defined and define the image for the corresponding lamp state in the Color tab.

Style

Defines the shape of the lamp. The available shapes differ depending on the category (Primitive, Bitmap, or User Defined.

From the Bitmap and Primitive style lists, you can:

  • Select a lamp image thumbnail from the list (as shown, above).

  • Click the User-Defined icon to select a user-created image.

  • Click the Browse... icon to open the Style Browser, then select a pre-defined lamp image.

In the User-Defined Style menu, the style menu is fixed. In the ON or OFF settings area of the dialog box, you must click the Browse... button to use an image from your hard drive.

The color of pre-defined and User Defined shapes cannot be changed, but the color of most Primitive shapes can be easily changed.

N-State Lamp Settings

In the General tab, define the N-State Lamp's Name, number of States, Category, Style, and Control Type.

The following table describes the General tab properties for an N-State lamp.

Property

Description

Name

The lamp's name.

Whenever an object is created, a default name is generated. When renaming an object, its name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

For details, see Appendix 9, Naming Conventions.

States

The number of display states for the lamp. The default is 3. Select 3 to 32 states for Bit and Word by Bit control types. Select 3 to 31 states for the Word by Value control type. For example, for a four-state lamp, the states are 0, 1, 2, and 3.

  • You can set up from 3 to 17 states when using a 16-bit Integer with a Word by Bit control type.

Category

Select either Primitive or User Defined. Depending on the category you select here, the shapes in the Style list change.

 

Primitive

Defines the shapes available in the Style list. Using Primitive, you can define colors for the various states of a lamp.

User Defined

Define your own images for the On and Off lamp states. To select your own image, in the Category field, set to User Defined and define the image for the corresponding lamp state in the Color tab.

Style

Defines the shape of the lamp. The available shapes differ depending on the category selected.

From the Primitive style list, you can:

  • Select a lamp image thumbnail from the list (as shown, above).

  • Click the User-Defined icon to select a user-created image.

  • Click the Browse... icon to open the Style Browser, then select a lamp image.

In the User-Defined Style menu, the style menu is fixed. In the ON or OFF settings area of the dialog box, you must click the Browse... button to use an image from your hard drive.

The color of User Defined shapes cannot be changed, but the color of most Primitive shapes can be easily changed.

Control Type

Select the Bit, Word by Bit, or Word by Value method to control the lamp.

Bit

When you select Bit, the Number of States you specify (3–32) determines the number of variables to define (2–5). The binary value of the defined variables (0–31) represents the state of the lamp.

Word by Bit

When you select the Word by Bit method, the Number of States you specify (3–32) determines the maximum number of bit positions. The number of states includes state 0 (when all the bits are OFF) and each bit position (up to 32).

Word by Value

When you select the Word by Value method, you can set up 3–31 states. The variable value (0–31) defines the lamp state.

  • If the value of the variable is lower than 0 or greater than the highest defined state, the lamp will display the Out of Range state.

  • When a REAL variable is selected for the control variable, real values are typecast into a Integer value, which defines the Lamp's state. For example, the real value 5.6 is typecast into the Integer value 5, which sets the Lamp state to 5.
