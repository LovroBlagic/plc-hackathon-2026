10.6 Creating a Message Display

Although the List tool is best suited to create a message display, you can also use the lamp tool to create a message display. Draw a Lamp to create a two-message display or N-State Lamp to create a 3 to 33 message display. To create message displays with up to 256 messages, draw using the List tool, see Section 14.1, Message/Image Display: Overview.

  • The following instructions describe how to create a message display without a border using the Blank Area style. To create a message display with a border, replace the Blank Area style with a different style.

Creating a Two-Message Display

  1. In the Graphical Objects toolbar, click the lamp icon and select Lamp from the list.

  1. Click and draw the area on the panel where you want to place the lamp.

The Lamp Settings dialog box opens.

  1. In the General tab, select a variable.

  1. In the Style property, select style 000000 from the list.

  1. In the Label tab, select On/Off as the Label Type and type the messages you want to display when the variable is ON and OFF.

  1. In the Color Tab, set up the ON/OFF Color Label.

  1. Click OK to insert the completed message display on the panel.

Creating a 3-33 Message Display

  1. In the Graphical Objects toolbar, click the lamp icon and select N-State Lamp from the list.

  1. Click and draw the area on the panel where you want to place the lamp.

The N-State Lamp Settings dialog box opens.

  1. In the General tab, specify the settings to control the lamp. Select Bit or Word by Value for 3-32 states. Select Word by Bit for 3-32 states. In the Style property, select style 000000 from the list.

  1. In the Label tab, set the Label Type to N-State and define the messages for each state.

  1. Click OK to insert the completed message display on the panel.
