10.7 Rotary Lamps and Tower Lamps

To create lamps, you should use the drawing tools. If you need to use the rotary and tower lamps available in the Toolchest, you can drag and drop them from the Toolchest onto the panel, and then set up their properties.

For more information about specifying the properties for these lamps, see Section 10.7.1, Lamp Part Properties.

Types of Lamps Available in Vijeo-Designer

Type of Lamp

Description

Rotary

In the rotary lamp, a change in color occurs when the value of the specified BOOL variable changes from OFF to ON, which initiates the rotation of the lamp, and from ON to OFF, which stops the lamp's rotation. The color of the rotary lamp is fixed.

 

Tower

In the tower lamp, five lamps are assigned one color each (red, yellow, green, blue and white), and each lamp is assigned a combination of two variables to turn it OFF and ON. The OFF/ON color changes occur according to the changes in variable combinations.
