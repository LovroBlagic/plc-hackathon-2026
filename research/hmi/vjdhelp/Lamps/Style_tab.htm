10.2.2 Color Tab

In the Color tab of the Lamp Settings dialog box, you can specify the colors, pattern, and blink feature of the lamp for its different states. The contents of the Color tab depends on the type of lamp you set up (Lamp or N-State Lamp), and your selection in the Category list box (Primitive, Bitmap, or User Defined). For more information on the lamp types and categories, see Section 10.2.1, General Tab.

  • Primitive or Bitmap Settings

  • User-Defined Settings

When Category is Primitive or Bitmap

Specify colors, pattern, and blink feature for each state of the lamp.

Color Settings

Text Color

Select a color for each state. The Color palette displays when you click the color area. Transparent color is not supported. For more information, see Section 7.3.1, Color Palette.

Select a label color for lamps with the Label setting enabled.

When you use a 3D font style, you can select the 3-dimensional color for the label text.

Set the frame color when you select a lamp style with a frame.

Select a color for the lamp. This color is also the lamp's foreground color when a pattern other than 1:Solid is selected.

Select a color for the lamp's background color when a pattern other than 1:Solid is selected.

Select a pattern for the lamp's Fore and Back colors.

When you select pattern 1:Solid, only the Fore Color displays. When you select a pattern other than 1:Solid, both the Fore Color and Back Color display.

If the Pattern is solid, the Back Color will not display.
When the Pattern setting is solid, only the Fore Color (in this case, yellow) displays as a solid pattern.

When the Pattern setting supports two colors, both the Fore and Back Colors (in this case, yellow and blue)display a two-color pattern.

When Category is User Defined

You can select User Defined images to create On/Off Lamps (2 states) or N-State Lamps (3-31 or 3-32 states).

When you select a User Defined lamp image, you can use one image for all lamp states or specify a different image for each lamp state.

Blink

Select None, Fast, or Slow, to apply the blink feature to the selected lamp state.

Image

To specify an image to represent the lamp state, click Browse, and in the Open dialog box, select an image and click Open.

The User-Defined image opens in the Color tab of the Lamp Settings dialog box.

Transparent Color

Available when Category is User Defined. Set a color in the lamp's image to become transparent. To make a color transparent:

  1. Select the Transparent Color check box.

  2. Click the color box to open the Color Palette.

  3. Select the color to turn transparent and click OK.
