10.1 Overview

Vijeo Designer allows you to create two different types of lamps:

  • On-screen lamps, which are lamps that you can draw on the panel by using a lamp Toolchest part or creating your own. This chapter describes on-screen lamps and how to set them up.

  • Physical lamps, which is a tower light you can connect to your target machine and configure the settings at build time and at run time. For more information on physical lamps, see Section 24.7, Setting Up a Tower Light.

Vijeo Designer gives you two ways to place on-screen lamps on your panel—use the lamp part or draw your own lamp and apply Color animation to it. Using Color animation, you can display a lamp with a maximum of 32 states that correspond to the variable values defined.

  • By using the lamp part, you can define all the settings quickly and easily in one dialog box. Using the N-State lamp part, you can define up to 33 states.

  • By drawing your own lamp, you can apply Color animation in combination with other animations.
