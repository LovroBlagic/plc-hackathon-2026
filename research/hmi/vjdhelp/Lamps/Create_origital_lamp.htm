10.5 Creating Your Own Lamp

If you need to create your own style of lamp, you create a graphical object and then apply color animation to create your own lamp.

 

Steps

1. Draw an object for use as a lamp.

2. Apply Color Animation to the object.

 

  • To create a lamp with a label, you need to use a text object and apply both Color Animation and Value Animation.
    For more information, see Section 10.5.2, Creating Labels for Custom Lamps.
