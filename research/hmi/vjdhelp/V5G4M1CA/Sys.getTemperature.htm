Sys.getTemperature

Function

The getTemperature() system method retrieves an integer value that is 10 times the current internal temperature of the target machine. The temperature is in Celsius.

Format

int Sys.getTemperature();

Example:

int MyTemp;

MyTemp = Sys.getTemperature();

if ( myTemp != -9999 )

{

TemperatureVariable.writeIntValue(MyTemp);

}

else

{

TemperatureInvalid.writeIntValue(TRUE);

}

Return Value

Returns the internal temperature as an integer value. Valid values are between 1 and 2,147,483,647.

Returns -9999 if reading of temperature is unsuccessful.

  • getTemperature() is only supported by the HMIX7PR target machine. The method is allowed in a script regardless of which target machine has been chosen. However, the method will not be validated for all target machines, and an error value of -9999 will be returned.

  • The returned integer is ten times the actual temperature in Celsius. To display the actual temperature, divide the returned integer by 10, or simply display the integer with the last digit presented as a single decimal value.
