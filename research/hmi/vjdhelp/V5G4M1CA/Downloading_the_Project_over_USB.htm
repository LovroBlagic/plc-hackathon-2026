Downloading the Project to HMIBMW over USB Port

Use USB download when you connect the target machine to the editor PC's USB port.

 

Before You Download

Make sure that the editor PC has the USB Driver installed. The USB cable requires a special USB driver that is installed on your PC when you install Vijeo Designer.

 

Downloading

  • During download, do not forcibly exit Vijeo Designer or turn off the target machine. Trying to cancel or interrupt the download process can make the target machine inoperable.

  1. Connect the USB cable to the Type A USB port on the Editor PC and the mini-B USB port on the HMIBMW target machine.

  • Connect the USB cable directly to the target machine for best results.

  • You can also connect the USB cable through a hub and into the target machine's USB port. When using a USB hub, you should connect only one USB download cable and one target machine. Vijeo Designer Runtime allows you to connect more than one USB component, as long as the USB components do not belong to the same type of device.

  1. Start Vijeo Designer Runtime on the target machine.

  1. In Vijeo Designer, in the Navigator window's Project tab, right-click the Target node and click Properties to open the Property Inspector. Set Download to USB.

  • Make sure you selected the correct target type in the Target properties.

  1. Right-click the Target node and click Download.

  2. After the user application is successfully sent to the target machine, Vijeo Designer Runtime loads and runs the user application.
