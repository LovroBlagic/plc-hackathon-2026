Installing Vijeo Designer Runtime to HMIBMW Series

Before you download the project to the target machine, you need to download the runtime system files. The Runtime Installer is a separate application used to download, install, and upgrade Vijeo Designer Runtime.

 

Installing Runtime Using Ethernet

The Runtime Installer supports IP addresses or host names for targets. Host names require your network to have a DNS server that can store IP addresses and host names. For host names, set up your DNS server with the target's host name and IP address before installing Runtime. The Runtime Installer contacts your network's DNS server to validate the host name's IP address. Contact your network administrator for information about your DNS server.

To install Vijeo Designer Runtime over Ethernet:

  1. Using an Ethernet cable, connect the target machine to the editor PC.


  2. On the Vijeo Designer editor PC, click the Windows Start button, then point to Programs, Schneider Electric, Vijeo Designer, Tools, and click Runtime Installer.

  3. In the Vijeo Designer Runtime Installer dialog box, select your target machine series. Set Download to Ethernet, and define the target machine's network settings.

  4. Click Send to start the installation. When Runtime installation is complete, a confirmation message displays.

  5. Click OK to close the message box, and click Exit to close the Vijeo Designer Runtime Installer dialog box.

Installing Runtime Using USB

To install Vijeo Designer Runtime over the USB ports using the Vijeo Designer Runtime Installer:

  1. Connect the USB cable to the Type A USB port on the Editor PC and the mini-B USB port on the HMIBMW target machine.

  2. On the Vijeo Designer editor PC, click the Windows Start button, then point to Programs, Schneider Electric, Vijeo Designer, Tools, and click Runtime Installer.

  3. In the Vijeo Designer Runtime Installer dialog box, select the series number of your target machine. Set Download to USB.  

  4. Click Send to start the installation. When Runtime installation is complete, a confirmation message displays.

  5. Click OK to close the message box, and click Exit to close the Vijeo Designer Runtime Installer dialog box.
