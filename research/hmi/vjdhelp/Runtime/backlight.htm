26.3.3 Setting Up Backlight Control

In this menu, you set up the Backlight to turn off after the target machine has idled for a certain period of time. The backlight turns back on when an alarm or system error occurs or the user touches any of the following: panel screen, Function Key, Mouse, or Keyboard. In order for the backlight to turn back on, an alarm summary or alarm banner must exist on the current panel. When the Backlight turns back on, the Backlight timer resets to zero.

To set up Backlight Control:

  1. In the Offline tab, touch the Backlight button to display the Backlight Control menu.

  1. In the Backlight Control menu, select Wait, then define a length of time for the panel to wait before the backlight turns off.

You can set the time to 15 or 30 seconds, or 1, 2, 5, 10, 15, or 30 minutes.

  1. Touch OK to accept the settings and return to the Vijeo-Designer Runtime Configuration Menu. To cancel the entry, touch Cancel to return to the Vijeo-Designer Runtime Configuration Menu.

  2. After completing all the settings, touch the To Run Mode button in the Vijeo-Designer Runtime Configuration Menu.

The Vijeo-Designer Runtime Configuration Menu closes and Runtime restarts.

  • Backlight control is not supported for iPC or XBTGTW target machines. To adjust the backlight on these target machines, use the Windows Control Panel to adjust backlight settings.

  • The Enable Touch if Backlight is Burned Out checkbox does the following if the backlight burns out:

  • When cleared, the touchscreen is locked out as a safety precaution.

  • When selected, the screen is still active but not illuminated, exposing the screen components to accidental touch.

Schneider-Electric recommends clearing the Enable Touch if Backlight is Burned Out checkbox. Select only when you have a specific need for this feature.
