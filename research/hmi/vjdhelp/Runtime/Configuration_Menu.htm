26.1 Configuration Menu

Vijeo-Designer Runtime is installed with a runtime configuration menu that allows you to change various settings on the target machine.

The runtime configuration menu allows you to change offline and system settings.

Offline Configuration Menu

A setting may or may not be configurable, depending on which target machine the application is running on. For more information on each item, see Section 26.3, Offline Configuration Menu Items.

Offline Configuration Menu Items

Description

Network

View and change the IP address of the target machine. You can also enable or disable DHCP and view MAC address and DNS information.

Buzzer

Sets up the sound emitted when the panel is touched.

Backlight

You can set up the backlight saver feature to automatically turn off the backlight when not in use to extend the backlight's lifetime.

Self-Test

On a regular basis, you should test if there are any errors in the system and interface.

Option

Configures the COM1 port as a power supply.

IO Manager

Changes communication settings for communication drivers and equipment.

Web Gate

Configures Web Gate server and client settings.

MultiMedia

Configures video input and display settings.

  1. To change an item in the Offline configuration menu, touch each icon and a dialog box opens.

  1. Select either OK or Cancel.

  2. Select OK to stop the project and restart the target machine. The configuration screen for the menu item you selected is displayed.

  3. Select Cancel to return to the Offline configuration menu.

If the project is not running or runtime is not running yet, the above dialog box will not display.
For more information, see Section 26.2, Displaying the Runtime Configuration Menu.

System Configuration Menu

System settings are configurable even when your user application is running on the target machine. A setting may or may not be configurable, depending on which target machine the application is running on. For more information on each item, see Section 26.3, Runtime Configuration Menu Items.

System Configuration Menu Items

Description

Stylus

Not applicable.

Date/Time

Adjusts the date and time.

Restart

Restarts the target machine.

Ver. Info

Displays version information for the editor and runtime.

Language

Changes the language displayed by the user application and runtime system.

Memory Info

Displays the amount of memory used in DRAM, Secondary Drive, and Main Flash.

Brightness

Changes the brightness and contrast for the target machine's display.

Option

Supported by monochrome, grayscale, and amber target machines only.

Reverses black and white areas on the panel.

Diagnostics Menu

Diagnostics menu items help you test the communication system on the target machine.

Diagnostics Menu Items

Description

Variables

Tests communication between the target machine and selected equipment for all associated variables.

Statistics

Displays communication statistics for the selected equipment.
