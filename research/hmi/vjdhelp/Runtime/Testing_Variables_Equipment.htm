26.5.1 Testing Variables Assigned to Equipment

This feature tests the communication link between connected equipment and variables on the target machine. All target machines and equipment support this test.

  1. In the Diagnostics tab, touch the Variables button to display the Test Variable Device Addresses screen.

  1. In the Test Variables Device Addresses menu, select the equipment whose variables you want to test.

  2. Touch the Start Test button.

The test reads the value for each variable associated with the selected equipment. If any of the variables fail, because of an error in the equipment or a time-out error, the event log displays a message with the name of the variable.

  1. After you complete testing variables from one equipment, you can continue testing variables for other equipment connected to the target machine.

  1. Alternatively, you can test all equipment at once by selecting Test All in the Select Equipment drop-down list.

  2. Touch the Return button to display the Vijeo-Designer Runtime Configuration Menu.

  3. Touch the To Run Mode button to return to the user application.
