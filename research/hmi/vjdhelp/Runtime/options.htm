26.4.8 Setting Black/White Invert for Monochrome, Grayscale, and Amber Displays (Optional)

This feature is available only for monochrome target machines. Select this option to reverse black and white areas on the panel. You can also configure this setting in the Target properties in the Vijeo-Designer editor. For more information on which models support Black/White Invert settings, see Appendix 5, Hardware Specifications.

  1. In the System tab, touch the Option button to display the Option menu.

  1. In the Invert Black and White area, select one of the following options:

  2. Normal: Displays the image in black and white colours.

Normal

Invert Black and White

  1. Invert: Displays the image by inverting black and white colours.

  1. Click OK to accept the setting and return to the Vijeo-Designer Runtime Configuration Menu.

  2. After completing all the settings, touch the To Run Mode button in the Vijeo-Designer Runtime Configuration Menu to return to the user application.
