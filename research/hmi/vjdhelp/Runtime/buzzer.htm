26.3.2 Setting Up the Buzzer

The buzzer emits sound when the panel is touched. You can also set up the buzzer in the target properties in the Vijeo-Designer editor. All target machines support this setting.

  1. In the Offline tab, touch the Buzzer button to display the Buzzer menu.

To work with the Buzzer, the user application cannot be running.

If the user application is running, a dialog box opens to enable you to stop the user application and exit Vijeo-Designer Runtime. Touch OK to stop the runtime and display the Buzzer settings. Touch Cancel to return to the Vijeo-Designer Runtime Configuration Menu.

  1. In the Touch Buzzer window, select one of the following:

  2. None for no buzzer sound

  3. When Press Touch Object for a buzzer that sounds when a Touch animated object is touched

  1. Touch OK to accept the changes and return to the Vijeo-Designer Runtime Configuration Menu. Touch Cancel to return to the Vijeo-Designer Runtime Configuration Menu without making any changes.

  2. After completing all the settings, touch the To Run Mode button in the Vijeo-Designer Runtime Configuration Menu.

The Vijeo-Designer Runtime Configuration Menu closes and Runtime restarts.
