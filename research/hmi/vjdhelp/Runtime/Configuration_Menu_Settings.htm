26.3 Offline Configuration Menu Items

Not all target machines support all the Offline Configuration Menu items. For more information, see Appendix 5, Hardware Specifications.

Offline Configuration Menu Items

Description

Network

Changes the IP address of the target machine.

Buzzer

Sets up the sound emitted when the panel is touched.

Backlight

You can set up the backlight saver feature to automatically turn off the backlight when not in use to extend the backlight's lifetime.

Self-Test

On a regular basis, you should test if there are any errors in the system and interface. For more information on testing, see the user manual for each target machine.

Option

Configures the COM1 port as a power supply, and allows you to enable or disable the front USB ports on supported target machines.

IO Manager

Changes communication settings for communication drivers and equipment.

Web Gate

Configures Web Gate server and client settings.

MultiMedia

Configures video input and display settings.
