26.4.5 Setting Up Languages

  1. In the System tab, touch the Language button to display the Language Selection menu.

  1. In the Language Selection menu, select the System, User Application, and Keyboard languages.

  2. System: Language in which the runtime system displays error messages and the Vijeo-Designer Runtime Configuration Menu.

  3. User Application: Languages added by the user.

  4. Keyboard Languages: Language you can select for keyboard mapping.

  1. Touch OK to accept the changes and return to the Vijeo-Designer Runtime Configuration Menu. Touch Cancel to return to the Vijeo-Designer Runtime Configuration Menu without making any changes.

  2. Touch To Run Mode button to return to the user application.
