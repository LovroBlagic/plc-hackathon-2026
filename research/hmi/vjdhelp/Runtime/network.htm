26.3.1 Setting Up the Network

This section describes the Network configuration menu items for the target machines that support Ethernet:

  • Single LAN Usage

  • Dual LAN Usage

  • EcoStruxure Secure Connect Advisor Usage (Available only on HMIG3U)

  • Download/Upload

To obtain a list of the target machines that support single LAN and dual LAN ports, see Appendix 5, Hardware Specifications.

 

26.3.1.1 Setting Up the Network for Single LAN Usage

  • Static IP

  • DHCP

  • MAC / DNS

Static IP Settings

This setting is available for Ethernet models only. For information about which models support this setting, see Appendix 5, Hardware Specifications.

  1. In the Offline tab, touch Network button to display the Static IP tab in the Network menu.

  1. In the Static IP tab, touch a field in the IP Address, Subnet Mask, or Default Gateway to display the keypad, and enter valid address values.

  1. Touch OK to accept the changes and return to the Vijeo-Designer Runtime Configuration Menu. (Touch Cancel to return to the Vijeo-Designer Runtime Configuration Menu without making any changes.)

  1. After completing all the settings, touch the To Run Mode button in the Vijeo-Designer Runtime Configuration menu.

The Vijeo-Designer Runtime Configuration menu closes and Runtime restarts.

  • Assign a unique IP Address to each target machine. If the target machine detects a duplicate IP address, it stops communicating over the Ethernet. The target machine checks for duplicate IP addresses when:

    • A new network device is connected

    • A disconnected network device is reconnected

    • A network device's IP address is re-configured at runtime

  • If you set up an IP address that does not match the IP address class (A, B or C) as indicated by the Subnet Mask, then the target machine may halt during operation. For valid IP address configuration, see your network administrator.

  • If your target supports supernetting, the IP address class does not need to match the subnet class. For a list of the targets that support supernetting, see Appendix 5, Hardware specifications.

  • For target machines that support dual Ethernet ports, the IP address displayed in the Runtime Configuration Menu is the first IP address defined in the Windows Control Panel.

DHCP Settings

The DHCP tab enables/disables DHCP and sets the target's host name. For DHCP, once enabled, the target automatically retrieves its IP address from your network’s DHCP server. This saves you from manually configuring the target’s network settings. For information on the targets supporting DHCP, see Appendix 5, Hardware Specifications. For the host name, you must have a valid DHCP server synchronized with a DNS server on your network. Once the host name is entered, the target registers the host name and target IP address with the DHCP server. Host names must follow DNS host naming conventions. For more information on these conventions, see Appendix 9, Naming Conventions. Contact your network administrator for information on your network’s DHCP and DNS server.

 

  • Setting the host name from the DHCP tab requires you have a DHCP server synchronized with a DNS server on your network.

To configure DHCP from the editor:

  1. In the Navigator window's Project tab, right-click the Target node and click Properties.

  2. In the Property Inspector, expand the Download property.

  3. Set the DHCP property to Enabled.

  • If Download is Ethernet, you need to enter the target machine's IP address to download the application to the target machine. At run time, the DHCP server may assign a different IP address to the target machine.

To configure DHCP at run time:

  1. Open the Runtime Configuration Menu. For more information, see Section 26.2, Displaying the Runtime Configuration Menu.

  2. In the Offline tab, touch the Network button to open the Network menu.

  3. Touch the DHCP tab at the top of the Network menu.

  4. Enable or disable DHCP using the DHCP checkbox.

  5. Touch the Static IP tab to return to the Network menu.

  • You may experience a delay when changing tabs as the target machine retrieves an IP address from the DHCP server.

  1. Touch OK to save the changes.

To configure the host name at run time:

  1. Open the Runtime Configuration Menu. For more information, see Section 26.2, Displaying the Runtime Configuration Menu.

  2. In the Offline tab, touch the Network button to open the Network menu.

  3. Touch the DHCP tab at the top of the Network menu.

  4. Touch the Host Name field and enter in the target's host name.

  5. Touch the Static IP tab to return to the Network menu.

  • You may experience a delay when changing tabs as the target machine registers the host name and target IP address with the DHCP server.

  1. Touch OK to save the changes.

MAC Address and DNS Settings

The MAC address and DNS settings are available for Ethernet models only. For information about which models support this setting, see Appendix 5, Hardware Specifications.

 

MAC Address Information

A Media Access Control (MAC) address is a unique 12-digit hexadecimal value associated with a network card. MAC Address is also known as a hardware address or a physical address.

At run time, you can view the MAC address of a target machine that supports Ethernet using either scripts or the Runtime Configuration Menu.

To view the MAC address using the Runtime Configuration Menu:

  1. Open the Runtime Configuration Menu. For more information, see Section 26.2, Displaying the Runtime Configuration Menu.

  2. In the Offline tab, click the Network button to open the Network menu.

  3. Touch the MAC/DNS tab at the top of the Network menu.

  4. The MAC Address is displayed in the Network MAC/DNS tab. You can also enable or disable the DNS from this screen. For more information on DNS support, see DNS Settings.

To view the MAC address using scripts:

  • Use the MAC_Address_1 and MAC_Address_2 parameters with the system method Sys.getInfoString(int param) in the editor. See Section 18.9.1.5, System Method: Sys,getInfoString.

  • Be aware that some targets have two MAC Addresses, because they contain two network cards.

DNS Settings

Domain Name System (DNS) allows you to use domain names instead of IP addresses when connecting to computers from Vijeo-Designer Runtime's Web Browser. For more information on the Web Browser, see Section 11.8, Displaying Documents Using Browser.

To configure DNS from the editor:

  1. In the Navigator window's Project tab, right-click the Target node and click Properties.

  2. In the Property Inspector, expand the Download property.

  3. Set the DNS property to Enabled.

  4. Type the IP Address for the DNS server.

To configure DNS at run time:

DHCP must be enabled in order to configure DNS at run time. For information on enabling DHCP, see Section 26.3.1.1, DHCP Settings.

  1. Open the Runtime Configuration Menu. For more information, see Section 26.2, Displaying the Runtime Configuration Menu.

  2. In the Offline tab, touch the Network button to open the Network menu.

  3. Touch the MAC/DNS tab at the top of the Network menu.

  4. Enable or disable DNS using the Obtain DNS Setting check box. When disabled, you can change the IP address of the DNS.

  5. Touch the Static IP tab to return to the Network menu.

  6. Touch OK to save the changes.

  • You must enable DHCP in order to enable or disable DNS at run time.

26.3.1.2 Setting Up the Network for Dual LAN Usage

For target machines that support dual LAN ports, follow these steps to configure the network.

  1. In the Network Selection page of the Network configuration menu, press Ethernet 1 or Ethernet 2.

  2. In the Network Configuration page, use the Static IP, DHCP, and MAC/DNS tabs to configure the network you selected.

  • For HMIG3U target machines, the Ethernet 1 and Ethernet 2 settings for Subnet Mask, Static IP, and DHCP must be different to prevent communication issues on the Dual LAN ports.

Static IP Tab

  1. Touch the Static IP tab at the top of the Network menu.

  2. Touch a field in the IP Address, Subnet Mask, or Default Gateway. A keypad displays so you can enter valid address values.

  3. Touch OK to accept the changes and return to the Vijeo Designer Runtime Configuration menu. Touch Cancel to return to the Vijeo Designer Runtime Configuration menu without making any changes.

  4. After completing all the settings, touch To Run Mode. The Vijeo Designer Runtime Configuration menu closes and Runtime restarts.

DHCP Tab

  1. Touch the DHCP tab at the top of the Network menu.

  2. Enable or disable DHCP using the DHCP check box.

  3. Touch the Host Name field, and enter the target machine's host name.

  4. Touch the Static IP tab to return to the Network menu.

  5. Touch OK to save the changes.

MAC/DNS Tab

Before you change the settings in the MAC/DNS tab, the DNS property in the Target properties must be set to Enabled. For more information on how to define the DNS setting in the Editor, see Section 4.5.1.2, Network Settings.

  1. Touch the MAC/DNS tab at the top of the Network menu.

  2. Enable or disable DNS using the Obtain DNS Setting check box. When disabled, you can change the IP address of the DNS.

  3. Touch the Static IP tab to return to the Network menu.

  4. Touch OK to save the changes.

26.3.1.3 Setting Up the Network for EcoStruxure Secure Connect Advisor Usage

For HMIG3U, you can use EcoStruxure Secure Connect Advisor to connect display units on the work site (SiteManager), with computers or smart devices in the office (LinkManager), over a server (GateManager). For more information about EcoStruxure Secure Connect Advisor, see EcoStruxure Secure Connect Advisor or 23.3, Monitoring target machines with EcoStruxure Secure Connect Advisor.

 

From the Network Configuration menu, in the Network Selection page, use the EcoStruxure Secure Connect Advisor button to configure the SiteManager Embedded settings when the SiteManager is running. Next to the VijeoConnect button is an indicator showing the connection status with the GateManager.

The table below describes the various states of the indicator.

Color of the indicator

Connection

Red

Not Connected

Yellow

Connecting to GateManager

Green

Connected to GateManager

Blue

LinkManager connected or Go To Appliance*1 is active

*1 For more information about Go To Appliance, see EcoStruxure Secure Connect Advisor.

 

In the SiteManager Embedded setting page, you can see the following fields.

Field name

Description

Access Control

You can enable/disable SiteManager Embedded. If disabled, SiteManager Embedded will not connect to GateManager and you cannot change the SiteManager Embedded settings. The default value is disabled.

SME Version

Read-only field that displays the SiteManager version number.

Connection Status

See the table above.

Server Address

Defines the GateManager IP address or DNS hostname you are connecting. The license mail sent by GateManager has the address information.

Domain Token

Set the token for the GateManager server home domain. The Domain Token is used to establish the initial connection. The license mail sent by GateManager has the Domain Token.

Appliance Name

Set the name of this SiteManager Embedded appliance. The name is used by the GateManager administrator. The name should be different from other SiteManager Embedded Appliance Names using the same license. The name can be up to 64 characters long.

Proxy Address

You can set the IP address of Web Proxy or Web-Proxy Auto-Detect (WPAD) URL in this field. Web Proxy acts as a gate between SiteManager Embedded and GateManager.
Proxy User

Set the user name for the Web Proxy. Only Basic Authentication is supported. Length is limited to 64 characters. When you use the NTLM method for the Web Proxy, use the following formats:

DOMAIN\USERNAME

WORKSTATION:DOMAIN\USERNAME

Proxy Password

Set the password for the Web Proxy. The length is limited to 64 characters.

Factory Default

Use this button to reset all parameters to their default settings.

When this button is touched, the connection between SiteManager and GateManager is disconnected.

The SiteManager ID is regenerated and when reconnecting with GateManager, it identifies the SiteManager as a new device.

 

SiteManager Embedded is downloaded with the user application regardless of the download method.

 

26.3.1.4 Setting Up for Ethernet Download and Upload

In a normal operation environment for Ethernet supported target machines, you should disable the Allow Ethernet Download & Upload setting to increase security on the target machine and prevent unauthorized download, upload, update run time, and retrieve or send data file operations over the network.

  1. To perform a valid Ethernet operation on a target machine, open its configuration menu.

  2. Navigate to the Network panel and select the Allow Ethernet Download & Upload check box.

  3. Restart the target machine.
    You can now perform the desired Ethernet operation on the target machine.
