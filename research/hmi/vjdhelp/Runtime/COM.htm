26.3.5 Setting Up Target Machine Options

This menu allows you to use the COM1 port as a power supply and to set up the front USB ports on supported target machines. For information about which models support power supply and which models support front USB ports, see Appendix 5, Hardware Specifications.

  1. In the Offline tab, touch the Option button to display the Option menu.

  1. In the Option menu, select one of the following options:

  2. Enable: The 9th pin of the COM1 port supplies the power.

  3. Disable: The 9th pin of the COM1 port does not supply the power.

  • For COM1 port specifications, see the user manual for your target machine.

  • If you select Enable and at the same time attach a loopback cable to check the COM1 port, the SIO circuit may malfunction.
    For details about the loopback cable, refer to your loopback cable's user guide or reference manual.

  1. To enable the front USB ports, select the Enable Front USB Ports on Display check box and the Enable Front mini USB Port on Display check box. Remove the check marks to disable the front USB ports. These options are only available for target machines that are equipped with front USB ports.

  2. Touch OK to accept the settings and return to the Vijeo-Designer Runtime Configuration Menu.

  3. When all settings are completed, touch the To Run Mode button to return to the Vijeo-Designer Runtime Configuration Menu and restart runtime.
