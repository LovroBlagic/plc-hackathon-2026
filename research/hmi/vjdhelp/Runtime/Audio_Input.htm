Audio Input

Menu Items

Description

ADC Gain (dB)

Used to set the gain for the output signal.

Settings range from 0 to 15.

Each increase in the ADC input is equivalent to 1.5 dB

MIC volume (dB)

Used to set the MIC’s mixer input volume.

Settings range from 0 to 31.

Each increase in the range is equivalent to 1.5 dB.

MIC Gain Select

Used to set the MIC amp’s gain to either 0 dB or 20 dB.
