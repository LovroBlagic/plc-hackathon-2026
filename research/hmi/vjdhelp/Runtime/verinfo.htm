26.4.4 Displaying Version Information

Use this feature to display the version of Vijeo-Designer that created the user application, and the version of Vijeo-Designer Runtime that's running the user application. All target machines support this feature.

  1. In the System tab, touch the Ver. Info button to display the Ver. Info menu.

Vijeo-Designer Runtime Version is the runtime version installed on the target machine.

Vijeo-Designer Version and Build is the Vijeo-Designer editor version used to create and build the user application.

  1. Touch the Return button to return to the Vijeo-Designer Runtime Configuration Menu.

  1. Touch the To Run Mode button to return to the user application.
