26.3.6 Changing I/O Manager Communication Settings

The I/O Manager settings enable you to reconfigure the driver and equipment communication settings on the target machine. This operation is particularly useful after you upgrade the network or replace existing hardware.

You can configure communication settings for the following drivers.

  1. In the Offline tab, touch the IO Manager button to display the IO Manager menu.

  1. In the IO Manager menu, touch either the Driver Config or Equipment Config button and select the desired communication settings.

  1. Change the driver and equipment configuration settings. To view the driver and equipment configuration settings for the driver you are using, click the link in the table at the start of this topic.
    For descriptions about each setting, see Appendix 2, Device Driver Manuals.

  2. Touch OK to accept your changes.
