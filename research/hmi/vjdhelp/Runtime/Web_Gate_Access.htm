26.3.7 Changing Web Gate Access

The Access Control menu enables you to limit access to the target based on the remote PC's IP address. For information about which models support this setting, see Appendix 5, Hardware Specifications.

To change the Web Gate Access Settings in the Offline Configuration Menu:

  1. In the Offline tab, touch the Web Gate button to display the Web Gate menu.

  1. In the Web Gate menu, select one of the following options:

  2. Allow access from all IP addresses—Allows access to the target from any remote PC.

  3. Allow access only from entered IP addresses—Allows access to the target from only remote PC's with listed IP addresses.

  4. Reject access only from entered IP addresses—Blocks access to the target from remote PC's with listed IP addresses.

  1. Touch Add to register an IP address. You can either add a Single IP address or a Range of IP addresses.

  • Single—Enter one IP address in the IP address field.

  • Range—Enter the first and last IP addresses in the fields. All the addresses in between are added too.

  1. Touch OK to add the defined IP address to the list.

  1. Touch OK to accept the settings and return to the Vijeo-Designer Runtime Configuration Menu.

  2. When all settings are completed, touch the To Run Mode button to return to the Vijeo-Designer Runtime Configuration Menu and restart runtime.
