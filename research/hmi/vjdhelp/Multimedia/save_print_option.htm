19.2.4 Snapshot Save/Print Clear Option

The Save/Print Clear option resets the snapshot variables' values when a snapshot save or a snapshot print operation is performed. The Save/Print Clear options are described below:

None

The Status, Control, and Error variables do not reset when a snapshot save or print operation is performed.

Control Variable

The control variable's value is reset to 0 once a snapshot save or print operation is performed. The Status and Error variables are not automatically reset. The user can set up any method for resetting these variables.

Status/Error Variable

The Status, Control, and Error variables do not reset once a snapshot save or snapshot print operation. However, when control variable's value is reset, the Status and Error variables will automatically reset.

  • You must reset the control variable's value to zero after every snapshot operation. If you don't reset the Control variable, Runtime may not be able to detect when new snapshot operations are triggered.

Save/Print Clear Option Timing Charts

The timing charts below show the values of the snapshot control variables during a snapshot save operation. The snapshot control variables operate the same way for snapshot print operations.

Save/Print Clear Option = None

When Save is Successful

Operation Order:

  1. The user starts the snapshot operation by writing 1 to the Control variable. This turns the Control variable's Bit 0 ON.

  2. Status variable's Bit 0 turns ON for the file save.

  3. Save completes: Status variable Bit 0 turns OFF and Status variable Bit 1 turns ON showing save complete.

  4. The user needs to manually reset the value of the Control variable and Status variable.

When an error occurs during file save

Operation Order:

  1. The user starts the snapshot operation by writing 1 to the Control variable. This turns the Control variable's Bit 0 ON.

  2. Status variable's Bit 0 turns ON for the file save.

  3. An error occurs during saving: Status variable's Bit 0 turns OFF and the Status variable's Bit 2 turns ON.

  4. A Bit in the Error variable turns ON. This Bit corresponds to the error that occurred.

  5. The user needs to manually reset the value of the Control variable, Status variable, and Error variable.

 

Save/Print Clear Option = Control Variable

When Save is Successful

Operation Order:

  1. The user starts the snapshot operation by writing 1 to the Control variable. This turns the Control variable's Bit 0 ON.

  2. Status variable's Bit 0 turns ON for the file save.

  3. Save completes: Status variable Bit 0 turns OFF and Status variable Bit 1 turns ON showing save complete.

  4. The Control variable automatically resets.

  5. The user needs to manually reset the value of the Status variable.

When an error occurs during file save

Operation Order:

  1. The user starts the snapshot operation by writing 1 to the Control variable. This turns the Control variable's Bit 0 ON.

  2. Status variable's Bit 0 turns ON for the file save.

  3. An error occurs during saving: Status variable's Bit 0 turns OFF and the Status variable's Bit 2 turns ON.

  4. A Bit in the Error variable turns ON. This Bit corresponds to the error that occurred.

  5. The Control variable automatically resets. The user needs to manually reset the Status variable and the Error variable.

 

Save/Print Clear Option = Status/Error Variable

When Save is Successful

Operation Order:

  1. The user starts the snapshot operation by writing 1 to the Control variable. This turns the Control variable's Bit 0 ON.

  2. Status variable's Bit 0 turns ON for the file save.

  3. Save completes: Status variable Bit 0 turns OFF and Status variable Bit 1 turns ON showing save complete.

  4. The user manually resets the Control variable and the Status variable's Bit 1 automatically resets.

When an error occurs during file save

Operation Order:

  1. The user starts the snapshot operation by writing 1 to the Control variable. This turns the Control variable's Bit 0 ON.

  2. Status variable's Bit 0 turns ON for the file save.

  3. An error occurs during saving: Status variable's Bit 0 turns OFF and the Status variable's Bit 2 turns ON.

  4. A Bit in the Error variable turns ON. This Bit corresponds to the error that occurred.

  5. The user manually resets the Control variable. The Status variable's Bit 2 automatically resets and the Error variable's error Bit automatically resets.
