19.2.3.1 Screen Snapshot Control Variable

The snapshot variable, Control, controls the snapshot operations.

The following values define the snapshot operation.

Bit

Value

Operation Name

Description

-

0

No operation.

No operation.

0

1

Save

The snapshot is taken and the snapshot file is saved in .jpeg format to defined drive.

1

2

Print

The snapshot is taken and the snapshot is printed.

0 and 1

3

Save and Print

The snapshot is taken, the snapshot file is saved in .jpeg format to the defined drive, and the snapshot is printed.
