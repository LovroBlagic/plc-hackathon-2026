19.1.7.2 Playback Snapshot Tab

The Playback Snapshot tab provides settings for the recorded video snapshots.

Property

Description

Control Variable

An integer variable that controls the recorded video snapshot. See Section 19.1.11.1, Video Snapshot Control Variable.

Status Variable

An integer variable that indicates the status of the of the recorded video snapshot operation. See Section 19.1.11.2, Video Snapshot Status Variable.

Error Variable

An integer variable that indicates the error that occurred during the video operation. See Section 19.1.11.3, Video Snapshot Error Variable.

Save/Print Clear Option

Select the Save/Print Clear Option for your snapshot. For more information, see Section 19.1.11.5, Video Snapshot Save/Print Clear Option.

Automatic

Automatically increments the snapshot's file number by one each time a snapshot file is saved.

  • When the file name property is set to automatic, the file number resets to 0 whenever the target machine is shut off and turned back on.  Any additional recorded video snapshots will begin overwriting the snapshots that were saved.

Number of Files to Keep

Defines the maximum number of snapshot files the target can save. You can specify any number between 1 - 200.

Once the target reaches the maximum number of snapshots, the snapshot file number resets to 0. Any additional snapshots will begin overwriting the snapshots that were saved.

File Format Sample

Provides a sample of the file format with the defined settings.

Manual

Enables you to specify the snapshot's file name.

File No. Variable

This property is read-only. An integer variable. It displays the variable that controls the snapshot's file name. You can define the snapshot's file name by writing to this variable.

Add Date

Adds the date the snapshot was taken to the snapshot file name.

File Number Auto Increment

The file number variable is automatically increments by 1 each time a snapshot is taken.

Format

Specify the date format for the snapshot file name.

File Format Sample

Provides a sample of the file format with the defined settings.

File Compression

Define the amount of compression to be used on the snapshot file when it is saved in .jpeg format. For more information about compression, see About Snapshots.
