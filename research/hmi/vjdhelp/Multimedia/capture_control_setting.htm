19.2.3 Screen Snapshot Control Variables

The snapshot control variables are automatically created once Screen Snapshot is enabled in the target properties. You can use equipment to update the control variables. For more information, see Section 19.1.12, Using Control Variables on Connected Equipment.

Variable

Description

Read/Write from Equipment

Control Variable

Variable that controls the snapshots operations. See Section 19.2.3.1, Screen Snapshot Control Variable.

Read/Write

Status Variable

Variable that stores the value that corresponds with the status of the snapshot operation. See Section 19.2.3.2, Screen Snapshot Status Variable.

Write

Error Variable

If an error occurs during a snapshot operation, the error variable will display code for the error. See Section 19.2.3.3, Screen Snapshot Error Variable.

Write

FileNo Variable

Variable that stores the value of the snapshot's file name. See Section 19.2.3.4, Screen Snapshot FileNo Variable.
