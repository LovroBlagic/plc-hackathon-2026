19.1.7 Video Settings

To display the Video Settings:

  • In the Target properties, select NTSC or PAL from the Video drop-down list or click the Video Ellipsis button.

The following table provides an overview of the Video Settings tabs.

Tab

Settings

Section

Record

  • File name settings for recorded video.

  • Record to buffer settings.

19.1.7.1 Record Tab

Playback Snapshot

  • File name settings for the recorded video snapshot.

  • File compression settings for the recorded video snapshot.

19.1.7.2 Playback Snapshot Tab

Live Snapshot

  • File name settings for the live video snapshot.

  • File compression settings for the live video snapshot.
