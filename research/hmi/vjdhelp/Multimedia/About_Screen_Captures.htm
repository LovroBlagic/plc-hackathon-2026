About Snapshots

When saving snapshots, you can use compression to make the snapshot file size more manageable. See File Compression and Snapshot File Size below.

Vijeo-Designer provides the following features for managing snapshot files:

  • Data Location Manager: Defines the drive that the snapshots are stored on. For more information, see Section Appendix, 5.11.1, Types of Data Locations.

  • Data Manager and Command Line: Retrieves and deletes snapshot files from a target machine during run time. For more information, see Section 20.5, Managing Run-time Data.

File Compression

Determine the amount of compression to be used on the snapshot file when it is saved in .jpeg format. Keep in mind the following information when defining the snapshot compression settings:

  • Low Compression

  • High Quality Snapshots

  • Large file size

  • High Compression

  • Low Quality Snapshots

  • Small file size

Snapshot File Size

Storage space can become an issue if you are storing many snapshots. Make sure enough space is available on the drive the snapshot files are being stored on.

Use the following formula for determining the size of a snapshot:

(Screen Width X Screen Height X Color Depth ÷ 8 bits per byte ÷ 1024 KB per byte)

For example:

XBTGT5000: Screen Width = 640, Screen Height = 480, Color Depth = 16 bits per pixel

(640 X 480 X 16 ÷ 8 ÷ 1024) = 600KB

Each uncompressed snapshot on the XBTGT500 is 600KB.

  • Live Video Snapshots have a fixed width and height of 640x480 for NTSC and 768x576 for PAL.

  • Playback Video Snapshots will have the same width and height of the Video Display.
