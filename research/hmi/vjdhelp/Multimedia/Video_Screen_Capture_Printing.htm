Setting up Video Screen Snapshot Printing

You must set up live video snapshot printing and video playback snapshot printing separately. Use the steps below as a guideline for setting up both types of video snapshot printing. For more information on the snapshot control variables, see Section 19.1.11.1, Video Snapshot Control Variables.

  1. In the Video Settings dialog box, click either the Playback Snapshot tab or the Live Snapshot tab.

  1. Select the Save/Print Clear Option for your snapshot. For more information on the Save/Print Clear Option, see Section 19.1.11.5, Video Snapshot Save/Print Clear Option.

  2. Click the Print tab and define the snapshot print settings. For more information, see Section 19.1.7.4, Print Tab.

  3. Write the value 2 to the snapshot control variable to take a snapshot and print it. For information, see section 19.1.11.1, Video Snapshot Control Variables.
