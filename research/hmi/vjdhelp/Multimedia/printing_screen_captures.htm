19.2.2 Printing Screen Snapshots

Screen snapshots can be printed on a printer connected to the target machine. For more information on printers and print settings, see Chapter 27, Printing.

Screen Snapshot Print Features:

  • Header
    Snapshots can be printed out with header information that includes: project name, target name, panel ID, time, and date. See Screen Snapshot Print Settings: Header.

  • Font
    Font is configurable for snapshot headings. See Screen Snapshot Print Settings: Font.

  • Font Size
    Font size is configurable for snapshot print headings. See Screen Snapshot Print Settings: Font Size.

  • The Active Event Viewer and the Event Log viewer panels do not support screen snapshots.

  • Unexpected behavior may occur if alarm batch printing and snapshot printing are triggered at the same time. Monitor the batch printing status variable to ensure batch printing is complete. For more information, see Section 16.3.5.3, Configuring Batch Printing.

  • Screen snapshot printing is not supported on Text (ASCII) printers.

  • Objects that are moving or rotating do not print correctly.
