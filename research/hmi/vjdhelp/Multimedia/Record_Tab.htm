19.1.7.1 Record Tab

The Record tab provides the video recording settings.

Property

Description

Control Variable

An integer variable that controls video recording. See Section 19.1.10.1, Video Record Control Variable.

Status Variable

An integer variable that indicates the status of the video operation. See Section 19.1.10.2, Video Record Status Variable.

Error Variable

An integer variable that indicates the error that occurred during the video operation. See Section 19.1.10.3, Video Record Error Variable.

Automatic

Automatically increments the video recording's file number by one each time a video file is saved.

  • When the file name property is set to automatic, the file number resets to 0 whenever the target machine is shut off and turned back on.  Any additional video recordings will begin overwriting the recordings that were saved.

Number of Files to Keep

Defines the maximum number of video recordings the target can save. You can specify any number between 1 - 200.

Once the target reaches the maximum number of recorded videos, the _VideoRecord.FileNo variable resets to 0. Any additional recorded videos will begin overwriting the recorded videos that were saved to the drive.

File Format Sample

Provides a sample of the file format with the defined settings.

Manual

Enables you to specify the video recording file name.

File No. Variable

This property is read-only. An integer variable. It displays the variable, _VideoRecord.FileNo, that controls the video file name. You can define the video recording's file name by writing to this variable. In Runtime, the displayed value is for the next file number, not the current file number.

Add Date

Adds the date of the video recording to the video's file name. Select the date format from the Date drop-down list.

File Number Auto Increment

The _VideoRecord.FileNo variable is automatically incremented by 1 each time a video recording is taken.

File Format Sample

Provides a sample of the file format with the defined settings.

Record to Buffer

The target continually records the live video feed to buffer.

Define the buffer's size in minutes: 0.5-10. The text beside the field displays the buffer size in MB.

  • Not all target series support Recording to Buffer, see Appendix 5, Hardware Specifications, for a list of the targets that support this feature.

Save file as type

Select the file format that the video file will be saved as. This property is only available for XBTGT target machines that support video. For a list of the target machines that can record video in the VMG and MP4(MPEG4) format, see Appendix 5, Hardware Specifications.
