19.2.2.1 Setting up Screen Snapshot Printing

The steps below show how to set up snapshot printing for your project. Once screen snapshot is enabled for the target, the snapshot control variables, Control, Error, FileNo, and Status, are automatically created in the Variable Editor. For more information on the snapshot control variables, see Section 19.2.3.1, Screen Snapshot Control Variable.

  • For screen snapshot printing, do not set up an action script that will be triggered using an "on open" event. If the panel change and printing is done using one script, the output of the printing job will be all black.

  • We recommend you create a switch to trigger screen snapshots and a separate switch for the change panel operation. You should not create one switch with a screen snapshot operation and a change panel operation.

  • If you take a screen snapshot immediately after a panel change, the print output may be black. You should wait for a few seconds after the panel change before you perform the screen capture and print operation .

  1. In the target node's properties, select Enabled from the Screen Snapshot field to enable screen snapshot for the target.

The Screen Snapshot dialog box displays once screen snapshot is enabled.

  1. Select the Save/Print Clear Option for your snapshot. For more information on the Save/Print Clear Option, see Section 19.2.4, Snapshot Save/Print Clear Option.

  2. Click the Print tab and define the snapshot print settings. For more information, see Screen Snapshot Print Settings.

  3. Set up a method for writing values to the screen snapshot control variable to take snapshots and print them. For more information, see section 19.2.3.1, Screen Snapshot Control Variable.
