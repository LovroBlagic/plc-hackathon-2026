19.1.5.2 Playing Video Recordings

  1. Draw the Video Display. See Section 19.1.2, Drawing a Video Display.

  2. In the Video Display properties, set up one of the following:

Play a single video.

Select Play File and the Video Data File option, and then select the video file from the drop-down list.

For information on adding video files to a target, see Section 19.1.5.3, Video File Editor Operations: Adding Video Files to a project.

 

Play a video based on the value of a string expression.

Select Play File and select File Name. Define a string variable or an expression in the File Name field.

See Section 6.14, Assigning Variables Using Expressions.

 

Play a video the user selects on the Play Video keypad.

Select Play File and select None. Enable the Display Popup Keypad check box and select a Video keypad.

See Section Live / Play Video Keypad or Live / Record / Play Video Keypad.
