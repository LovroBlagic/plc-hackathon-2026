19.1.10.4 Video Record FileNo

An integer variable that controls the video file's file name. The FileNo variable has a range from 0 to 65536. The FileNo can be defined by the following methods:

  • Automatic - Automatically increments the video recording's file number by one each time a video file is saved. For more information, see Section 19.1.7.1 Record Tab.

  • Manual - Enables you to specify the video recording file name. For more information, see Section 19.1.7.1 Record Tab.

  • Equipment - Enables you to use the control variable properties to associate device addresses with the control variable. For more information, see Section 19.1.12, Using Control Variables on Connected Equipment.
