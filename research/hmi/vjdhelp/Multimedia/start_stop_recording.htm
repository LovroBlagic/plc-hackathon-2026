19.1.4.2 Setting up Start / Stop Video Recording

  1. In the Target properties, enable video by selecting NTSC or PAL. See Section 19.1.1, About Video: NTSC and PAL.

  2. Draw the Video Display. See Section 19.1.2, Drawing a Video Display.

  3. In the Video Display properties, select Display Live Feed. See Section 19.1.8.1, General Tab.

  4. In the Video Settings, define the video recording's file name options. See Section 19.1.7.1, Record Tab.

  5. Set up one of the following methods to start and stop video recording:

  6. Keypads - See Section 19.1.9.1, Keypad Video Controls.

  7. Switches - See Section 9.5.12, Video Operations.

  8. Scripts - See Section 18.3.8.8, Video Methods.

  9. Equipment - See Section 19.1.12, Using Control Variables on Connected Equipment.

  • You can define where the recorded video gets stored on the target. See Appendix, 5.11.1, Types of Data Locations.
