19.2.5 Setting Up Screen Snapshot for Web Gate Use

In Web Gate, you cannot perform screen snapshots directly using the screen snapshot Control variable. To perform screen snapshots from Web Gate:

  1. In the Editor, for the screen snapshot Control variable, enable Read From Variable and select a variable that you created. In the below example, the variable's Data Source is set to Internal and Sharing is set to Read/Write.

  1. Select the Security node in the Navigator, and define the Web Gate / Web Server Security property to Use Security.

  1. Create a security group with the Web Gate level set to Read/Write, and then create a Web Gate user for the security group.

  1. From Web Gate, control the screen snapshot by writing values to the Read From variable created in step 1.
