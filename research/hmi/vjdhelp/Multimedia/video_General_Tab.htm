19.1.8.1 General Tab

Property

Description

Name

The Video Display name.

The Video Display's name must follow the naming conventions described in Appendix 9, Naming Conventions.

Display Live Feed

Configures the Video Display to show the feed coming from the video camera connected to the target's RCA Composite port.

  • The feed can be live from the video camera or recorded and played from the video camera.

Play File

Configures the Video Display to play video files.

None

Does not initially display a video when the user changes to the panel the video display is on. The video display can still play videos, it just will not initially display a video. If selected, you must set up a Live/Play Video or a Live/Record/Play Video keypad for the video display.

See Section 19.1.9.1, Keypad Video Controls: Live / Play Video Keypad.

See Section 19.1.9.1, Keypad Video Controls: Live / Record / Play Video Keypad.

Video Data File

Plays the selected video whenever the user changes to the panel with the video display. The Video Display can still play other videos, it will just initially display the selected video. Select the video to display using the Video Data File drop-down list.

For a list of the target machines that can record video in the VMG and MP4(MPEG4) format, see Appendix 5, Hardware Specifications.

For more information on adding video files to targets, see Section 19.1.5.3, Video File Editor Operations: Adding Video Files to a Project.

File Name

The video defined by the expression or string variable plays whenever the user changes to the panel with the Video Display. The expression or string variable uses the video file's alias name to set which video to play. For more information on the video alias, see Section 19.1.5.3, Video File Editor Operations.

If you select a string variable to control the Video Display, you can play different videos by using a String Operation to write a video alias name to the video string variable. For more information on string operations, see Section 9.5.3, String Operation.

For more information on adding recorded video to targets, see Section 19.1.5.3, Video File Editor Operations: Adding Video Files to a Project.

Loop

This property is available when Play File is selected.

This feature continually loops the video file playing in the Video Display .

Display Popup Keypad

Enables the use of popup keypads for the Video Display.

Live Video

Enables the Live Video Keypad.

See Section 19.1.9.1, Keypad Video Controls: Live Video Keypad.

Live / Record Video

Enables the Live / Record Video Keypad.

See Section 19.1.9.1, Keypad Video Controls: Live / Record Video Keypad.

Live / Play Video

Enables the Live / Play Video Keypad.

See Section 19.1.9.1, Keypad Video Controls: Live / Play Video Keypad.

Live / Record / Play Video

Enables the Live / Record / Play Video Keypad.

See Section 19.1.9.1, Keypad Video Controls: Live / Record / Play Video Keypad.
