19.1.6.2 Saving Video Snapshots

You can save Video snapshots in .jpeg format and store them in the following location on a storage device connected to the target machine:

\public\projects\<target name>\Data\Video\

Video snapshots require you to set up Playback Snapshot and Live Snapshot separately.

With the snapshot operation, you can define snapshot file names and specify the file compression:

  • File Names
    File names can be defined either automatically with a number that increments each time a snapshot is taken or manually by a variable value. For more information on file names, see Section 19.1.7.2, Playback Snapshot Tab.

  • File Compression
    You can specify the quality of the snapshot .jpeg file. The higher the quality, the larger the snapshot file; conversely, the lower the quality, the smaller the snapshot file. See About Snapshots.

  • Make sure enough space is available on the storage device for snapshots. See About Snapshots.
