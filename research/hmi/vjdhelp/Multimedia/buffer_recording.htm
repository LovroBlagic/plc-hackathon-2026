19.1.4.3 Setting up Buffer Video Recording

  1. Draw the Video Display. See Section 19.1.2 Drawing a Video Display.

  2. In the Video Display properties, select Display Live Feed. See Section 19.1.8.1, General Tab.

  3. In the Target properties, enable video by selecting NTSC or PAL in the Video field. See Section 19.1.1, About Video: NTSC and PAL for more information.

  4. In the Video Settings, define:

  5. File Name Options

  6. Buffer settings

For more information on file name options and the record to buffer options, see Section 19.1.7.1 Record Tab

  1. Write the value 2 to the Video Record variable to trigger the buffer to flush to storage. See the Video Control Variable Section 19.1.10.1, Video Record Control Variable.

  • If you play a video file when the buffer is recording live video, buffer recording stops. When you resume buffer recording, previous buffer recording is overwritten.

  • You can define where recorded video is stored on the target. See Appendix 5.11.1, Types of Data Locations.
