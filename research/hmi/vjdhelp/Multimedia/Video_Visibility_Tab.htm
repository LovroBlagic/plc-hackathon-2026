19.1.8.2 Visibility Tab

Property

Description

Enable Visibility

This property makes the Video Display invisible or visible.

When the value defined in this field is true (ON), the Video Display is visible. When the value defined in this field is false (OFF), the Video Display is invisible.

Select a BOOL or integer variable or enter a boolean expression to control the Video Display's visibility.

Enable Blink

Select Enable Blink to make the Video Display blink. You can choose a BOOL or integer variable or enter a boolean expression.

  • If true, the Video Display blinks.

  • If false, the Video Display does not blink.

Speed

Set the blinking speed to fast or slow. A fast blink rate is 350 ms and a slow blink rate is 700 ms.
