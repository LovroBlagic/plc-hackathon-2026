19.1.8.3 Advanced Tab

Property

Description

Enable Interlock

Select Enable Interlock to set up a condition that must be true in order to use the Video Display. The condition can be a BOOL, integer variable, or boolean expression. For more information, see Section 9.6, Using Interlock to Prevent Accidental Touch Input.

  • During data input, if the interlock variable turns OFF, data input is cancelled. Video recording or playback will still continue.
