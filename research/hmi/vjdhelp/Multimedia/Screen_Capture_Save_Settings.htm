Screen Snapshot Save Settings

File Name

Property

Description

Automatic

Automatically increments the snapshot's file number by one each time a file is saved.

  • When the file name property is set to automatic, the file number resets to 0 whenever the target machine is shut off and turned back on.  Any additional screen snapshots will begin overwriting the snapshots that were saved.

Number of Files to Keep

Defines the maximum number of snapshot files the target can save. You can specify any number between 1 - 200.

Once the target reaches the maximum number of snapshots, the screen snapshot file number resets to 0. Any additional screen snapshots will begin overwriting the snapshots that were saved.

File Format Sample

Provides a sample of the file format with the defined settings.

Manual

Enables you to specify the snapshot's file name.

File No. Variable

This property is read-only. An integer variable. It displays the variable that controls the snapshot's file name. You can define the snapshot's file name by writing to this variable.

Add Date

Adds the date the snapshot was taken to the snapshot file name.

File Number Auto Increment

The file number variable is automatically increments by 1 each time a snapshot is taken.

Provides a sample of the file format with the defined settings.

File Compression

Define the amount of compression to be used on the snapshot file when it is saved in .jpeg format. For more information on file compression, see Section About Snapshots: File Compression.
