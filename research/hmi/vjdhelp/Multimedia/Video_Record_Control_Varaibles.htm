19.1.10 Video Record Control Variables

The video record control variables are automatically created when Video is enabled for the target. You can use equipment to update the control variables. For more information, see Section 19.1.12, Using Control Variables on Connected Equipment.

Variable

Description

Read/Write from Equipment

Control Variable

Variable that controls the video operations. See Section 19.1.10.1, Video Record Control Variable.

Read/Write

Status Variable

Variable that stores the value that corresponds with the status of the video operation. See Section 19.1.10.2, Video Record Status Variable.

Write

Error Variable

If an error occurs during a video operation, the error variable will display code for the error. See Section 19.1.10.3, Video Record Error Variable.

Write

FileNo Variable

Variable that stores the value of the video file's file name. See Section 19.1.10.4, Video Record FileNo.
