5.9.4 XBTGH Series Function Keys

The XBTGH Series supports both hardware function keys and keyboard function keys.

Operation Switch (O.P)

The Operation Switch helps prevent accidental panel touch inputs. When the Operation Switch setting is enabled, panel and function key touch operations are disabled on the target until the operator presses and holds down the Operation Switch. Once the Operation Switch is held down, panel and function key touch operations can run. When the operator releases the Operation Switch, panel and function key touch operations become disabled.

The Operation Switch is also a function key that can be set up to run operations. For more information on setting up Function Keys, see Section 24.5.4, Adding and Removing Function Keys.

The Operation Switch can be enabled and disabled in the project target properties. For more information, see Section 4.5.1, Target Properties.

Hardware Function Keys

The XBTGH Series supports hardware function keys. The XBTGH target machine has 11 function keys on the panel: F0 to F10. For information on how to set up the function keys, see Section 24.5.1.1, Target Function Key General Tab.

Be aware that these function keys can operate as a Target Function Key and as a Panel Function Key. For example, if you define two different operations using the same F1 function key, one assigned at the target level and the other assigned at a panel level, when the panel is displayed on the target and the operator presses F1, both operations will run.

  • For XBTGH Function Key simulation, the F0 function key maps to the F11 key on the keyboard. For more information on simulating the function keys, see Section 25.3.4, Simulating the Keyboard.

Keyboard Function Keys

The XBTGH target supports the use of keyboard function keys. The XBTGH Series uses the F1 to F11 function keys on the connected keyboard. The target's F0 function key is the F11 key on the keyboard. For more information on adding function keys to your project, see Section 24.5.4, Adding and Removing Function Keys.

Be aware that these function keys can operate as a Target Function Key and as a Panel Function Key. For example, if you define two different operations using the same F1 function key, one assigned at the target level and the other assigned at a panel level, when the panel is displayed on the target and the operator presses F1, both operations will run.
