5.10.3 HMIGK Series Keypad

The HMIGK target machine provides you with an Alphanumeric Keypad for you to input data. The keypad contains the following two parts:

  • Alphanumeric Keys

  • Cursor Keys

Alphanumeric Keys

The alphanumeric keys enable you to enter the 26-letter alphabet, numbers 0 to 9, and other characters. The following image shows an example of the alphanumeric keys on the Alphanumeric Keypad.

Each press of the key cycles through a character that can be entered with that key, for example, the "ABC7" key:

1 press: Input = A

2 presses: Input = B

3 presses: Input = C

4 presses: Input = 7

Pressing the "abc7" key simultaneously with the SHIFT key results in:

1 press: digit = a

2 presses: digit = b

3 presses: digit = c

4 presses: digit = 7

For another example, the "." key:

1 press: Input = .

2 presses: Input = ,

3 presses: Input = '

Fine Tuning

For numeric input in the data input field, use the Increment and Decrement keys on the Alphanumeric Keypad to increase or decrease the value. The fine tuning feature controls the rate at which the value increases or decreases. Each press of the Increment key increases the value by one, to the next least significant digit. For example, after a key press, the value 2 increases to 3; after a second key press, the value increases to 4. If you continue to hold down the Increment or Decrement keys, the increment value will begin to accelerate.
