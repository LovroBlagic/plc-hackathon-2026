At run time, the function keys on the HMIGK and XBTGK Series support simultaneous touch. This means that at run time you can simultaneously press multiple function keys on the HMIGK or XBTGK and all the associated functions will execute. However, when in simulation mode, if you simultaneously press function keys, only one function will execute.

All panel and target function keys are disabled when the Configuration menu displays.
