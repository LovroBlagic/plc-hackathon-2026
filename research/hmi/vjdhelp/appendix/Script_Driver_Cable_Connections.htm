5.4.1 Script Driver Cable Connections

The script driver is a generic serial communication driver that allows you to communicate with simple serial equipment.

For information on how to connect a script driver cable to your target machine see the following sections:

  • 5.4.1.1 XBTGT2000 Series or Higher, XBTGC2000 Series, XBTGK Series, iPC/XBTGTW Series, HMIGTO Series, HMIGTU Series, HMIGTUX Series, HMISCU Series, HMISTO Series, HMISTU Series, HMIGK Series, and XBTGH Series

  • On all target machines, it is not possible to use COM1 port for both the script driver and the target printer. If you do have both set to COM1, both will fail to print in runtime.

  • To use the script driver to send messages to a printer, the printer must have at least two communication ports: one for the script driver, one for the target printer. The script driver must use a serial port. The target printer can use any of the following:

  • A parallel port: XBTGT, XBTGC, XBTGK, HMIGK, and HMIGTO targets can use "USB-PIO."

  • A USB port: Only available for XBTGT, XBGTC, XBTGK, HMIGK, and HMIGTO targets. Must select the "USB" connection method.

  • An Ethernet port: Only available for XBTGT, XBTGC, XBTGK, HMIGK, and HMIGTO targets that support Ethernet; see Appendix 5, Hardware Specifications. Can select either the "IPP" or the "LPR" connection method.
