5.5 Configuration Menu Items Supported by Hardware Platforms

Vijeo-Designer Runtime is installed with a runtime configuration menu that allows you to change various settings on the target machine.

The runtime configuration menu allows you to change offline and system settings. Not all target machines support the same Configuration Menu Settings. Use this section as a reference for determining if your target machines support the different configuration menu items.

 

Offline Configuration Menu Items

  • iPC/XBTGTW

  • XBTGT

  • HMIGK/XBTGK

  • XBTGC

  • XBTGH

  • HMISTO

  • HMISTU

  • HMIGTO

  • HMISCU

  • HMIGTU

  • HMIGTUX

 

System Configuration Menu Items

  • iPC/XBTGTW

  • XBTGT

  • HMIGK/XBTGK

  • XBTGC

  • XBTGH

  • HMISTO

  • HMISTU

  • HMIGTO

  • HMISCU
