9. Naming Conventions

 

9.1 Parts, Devices, Objects, Variables, Passwords

You must use distinct names for all objects in the application. Be aware that although Vijeo Designer checks that you are using distinct names in your projects, there may be some scenarios which result in duplicate names and broken object name references. Test your application thoroughly on the run-time platform before going into a production environment.

The following characters are valid characters that can be used for naming parts, devices, objects, variables and passwords in Vijeo Designer:

  • Alphabet [ a-z, A-Z ]

  • Numbers [ 0-9 ]

  • Underscore [ _ ]

  • Other special characters, with the exception of punctuation marks, asterisk (*), pound key (#), backward slash (\), forward slash (/), angle brackets (<>), and the vertical bar (|).

  • You cannot use the underscore or numbers as the initial character for a name.

  • You cannot use the underscore character in a target name.

  • You cannot use spaces in a name.

  • Java names are reserved and cannot be used as names of objects in Vijeo-Designer.
    For a list of reserved words, see Appendix 3, Reserved Words.

9.2 Host Names

 

Host names must follow DNS host naming conventions.  For example: “TargetName.Domain.com” follows these conventions. Each word in the host name is a label defining the targets location within the DNS hierarchy: TargetName [leaf domain] . Domain [second-level domain] . com [top-level domain]

Host Label Conventions:

  • Labels are concatenated with dots.

  • Labels are not case sensitive.

  • Labels can only use ASCII letters a - z, numbers 0 – 9, or hyphens (-).

  • Labels must be 1 to 63 characters long.

  • Labels cannot start with digits or hyphens.

  • Labels cannot end with hyphens.

  • Entire host name cannot be longer than 255 characters.
