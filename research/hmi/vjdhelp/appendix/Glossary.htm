10. Glossary

A

Actions

Actions are runtime operations that run when a trigger (such as Periodic, Scheduled, Conditional, or Event) is activated. There are two types of actions: Global Actions (at the target level) and Panel Actions (at the panel level). For more information, see Section 9.4, Creating Actions.

Alarms

An alarm is a runtime event (based on user-defined conditions) that requires attention and that alerts the panel operator by displaying on the target machine. An alarm display on a panel can be an alarm summary or alarm banner, where the panel operator can view detailed alarm information and diagnose faults. For more information, see Section 16.1, Alarms and Events.

An alarm summary can display alarms that are in these four states: Active, Acknowledged (ACK), Not Acknowledged (UNACK), and Returned to Normal (RTN). For more information, see Section 16.2, Setting Up the Alarm or Event Summary. An alarm banner can display active and UNACK alarm messages. For more information, see Section 16.4, Alarm Banner.

Alias

An Alias is a user-defined name for a Video, Text, E-mail contact, or Sound file. The Video, Text, and Sound file aliases are used to call the file in an operation. For example, a sound file with an alias "MySoundFile", can be played by script operation: Sound.Play("MySoundFile");. E-mail contact aliases are used to specify the E-mail recipient in the E-mail operation. For more information on E-mail operation, see Section 9.5.20, E-mail Operations. For information on Video file aliases, see Section 19.1.5.3, Video Files Editor Operations. For more information on Sound file aliases, see Section 24.2.1, Working With the Sound File Editor. For more information on Text file aliases, see Section 11.7.2.1, Setting Up a Text Display. For more information

Animation Blink

Animation blink occurs on objects (such as lamps, switches, and meters) when a particular condition has been met. All target machines support animation blink. This is not the same as hardware blink. For more information, see Section 7.3.4, Blink Feature.

B

Blink

Blink is a feature that you can apply to an object and is used to indicate warnings or alarms. There are three types of blink: Hardware blink, animation blink, and function key LED blink. For more information, see Section 7.3.4, Blink Feature and Section 24.5.3, LED Control.

Block Trend Graph

A block trend graph allows you to display data for multiple data samples at one point in time. It is typically used if you want to display Block Variable data from the PLC. For more information, see Section 13.1.2.4, Block Trend Graphs.

C

D

Data Locations

Data locations are where data such as recipe, data logging, alarm, video, screen snapshot, and project backup files is stored on the main, secondary, or optional drive on the target machine. For more information, see Appendix 5.11, Data Locations.

Data Quality

Data quality indicates whether the values that are displayed on the panel are reliable. When a data quality icon displays at the top-right corner of the object, it means that there are communication errors and unreliable data, resulting in bad data quality. For more information, see Section 22.1.2, Data Quality for Shared Variables.

Data Sharing

Data sharing allows the targets on your network to read and write data to one another. With this feature, you can synchronize the data and processes between multiple targets. For more information, see Section 22.1 Sharing Data Between Tablets, Smartphones, and Target Machines.

Dialog Table

The Dialog Table provides a simple way for executing common functions and communicating commonly used data between the target machine (HMI) and the PLC. These operations are made possible by the Dialog Table exchanging a block of data on the target machine with a block of data on the PLC. When the values change in one of the blocks, the Dialog Table automatically updates the other block to have the same values. The functions that correspond to the updated values are then executed by the Dialog Table. For more information, see Section 5.6, Working with the Dialog Table.

DHCP

DHCP (Dynamic Host Configuration Protocol) is a network protocol that enables your network server to automatically assign an IP address to your target machine. For more information, see Section 26.3.1.1, DHCP Settings.

DIO Port

A DIO (Digital Input Output) port is a hardware interface on a target machine that is configurable for data input or output. The Alarm, Error, and Buzzer pins are supported by Vijeo Designer on the DIO port. For more information, see Section 24.6 DIO Ports.

DNS

DNS (Domain Name System) allows you to assign domain names instead of IP addresses when connecting to Vijeo Designer Runtime's Web Browser. For more information, see Section 26.3.1.1, MAC Address and DNS Settings.

DRAM

DRAM (Dynamic Random Access Memory) is a storage option in the target machine that allows you to store the most current data samples. When the number of data samples you want stored in the RAM exceed the number specified in the Logging Group Settings, the oldest data samples are removed so the most current data samples can be stored. You should not use DRAM as a storage option if you intend on preserving your data for a long time. Stored data in DRAM is erased whenever your target machine shuts down and restarts. For more information, see Section 13.1.1.3, Storing Your Collected Data.

E

Equipment

Indicates equipment, such as programmable logic controllers (PLCs), sequencers, and inverters..

F

Function Key LED Blink

The function key LED blink feature can indicate the state of a function key (such as enabled/locked). For example, when properly configured, if a function key is locked, the LED for this function key blinks red. For more information, see Section 24.5.3, LED Control.

Function Keys

Function keys are keys that the user can configure to execute operations. They can be physically on the target machine (depending on the target type) or on a USB keyboard connected to the target. There are two types of function keys: Panel Function Keys and Target Function Keys. For more information, see Section 24.5, Function Keys.

G

Global Actions

Global Actions are operations that execute when a trigger is activated, no matter which panel is displayed on the target. For more information, see Section 9.4, Creating Actions.

H

Hardware (HW) Blink

Hardware blink is used for animations only on primitive objects (e.g., lines and rectangles). It is different from the software blink that also applies to native parts (e.g. switches and lamps) and to alarms. For more information, see Section 7.3.4, Blink Feature.

I

Interlock

Interlock is a feature that can prevent touch inputs (such as pressing a switch, a selector, or function keys) and actions. If you enable the Interlock feature and specify a condition, the affected touch input or action is prevented when the defined condition is false. For more information, see Section 9.6, Using Interlock to Prevent Accidental Touch Inputs, and Section 24.5.5, Setting Up Interlock for Function Keys.

M

Main Drive

The main drive handles long-term storage, primarily storing the application. It can be the internal memory (flash memory), the system CF Card, or the system hard disk drive, depending on the target type. For more information, see Appendix 1, Hardware Manuals.

Master Panels

Master panels are panel templates that can be applied to any base panel in a project. On a master panel, all objects that have been added become common objects that will be present in all base panels using this master panel. For more information, see Section 4.7.2, Master Panels.

N

O

Optional Drive

The optional drive, such as a USB drive, enables you to easily extract data from the main and secondary drives. It can also be used instead of the secondary drive to handle the same types of files.

P

Panel Actions

Panel Actions are operations created for a specific panel and execute when a trigger is activated. The operations only execute when this panel is displayed on the target. For more information, see Section 9.4, Creating Actions.

Panel Function Keys

Panel Function Keys execute operations that are assigned to a specific panel. Operations execute when the panel is displayed on the target and the operator presses the Panel Function Key. For more information, see Section 24.5.2, Panel Function Key.

Parison Graphs

A parison graph is the profile thickness of a parison. An example use case of parison graph is during blow molding, where you can plot and modify the thickness of the material at run time. For more information, see Section 12.4.8, Parison Graphs.

PLC

A PLC (Programmable Logic Controller) is a device used for controlling automated processes in, for example, plants. A target running Vijeo Designer Runtime can communicate with a PLC using various drivers. For more information, see Appendix 2, Device Driver Manuals.

PLC Symbol Import

The PLC symbol import feature allows you to link the names and device addresses of symbols (also called variables or tags) configured in the PLC configuration software to Vijeo Designer variables. After linking the equipment's PLC symbol file, you can add the symbols from the linked file to the Vijeo Designer variable list. For more information, see Section 6.3.4, Using Aliases, Symbols, and Variables from Equipment Configuration Software.

Q

R

Recipes

A recipe is a pre-defined set of data and values, which can be used to manipulate data between the target and the equipment. For example, a Send operation will copy recipe values from the target to the equipment; a Snapshot operation will copy recipe values from the equipment to the target. For more information, see Section 17.1, About Recipe.

Retentive Variables

Retentive variables are internal variables that have their values stored in the SRAM (Static RAM) of the target, so that these values are restored after a power cycle. For more information, see Section 6.10, Retentive Variables.

S

Scan Group

A scan group is a group of external variables from a single equipment that are scanned at the same rate. There are four different scan rates offered: Fast, Medium, Slow, and User-Defined. For more information, see Section 6.3.2, Dividing Variables into Scan Groups.

Script

A script allows users to customize their runtime operations using Java methods supported by Vijeo Designer. A script can be used in an action, a switch, alarm touch actions, and alarm trigger actions. For more information, see Section 18.1, Programming with Scripts.

Secondary Drive

The secondary drive, which can be removable (depending on the target type), handles files, such as recipe files, runtime-generated files, and project backup files. It can be a CF Card/SD Card of a drive letter assigned to a drive (internal or external).

SoMachine

SoMachine is an automation solution featuring multiple integrated platforms (HMI and Control). The XBTGC targets offer HMI and Control in a single unit. For more information, see Section 4.13, Working with SoMachine.

SRAM

SRAM (Static Random Access Memory) is a storage option in the target machine that allows you to store a specified number data samples as defined in the Logging Group Settings. When the number of data samples you want stored in the RAM exceed the number specified in the Logging Group Settings, the oldest data samples are removed so the most current data samples can be stored. Data stored in SRAM is saved even if your target machine shuts down and restarts. For more information, see Section 13.1.1.3, Storing Your Collected Data.

SMS Gateway Address

SMS Gateway Address is a phone’s Email address. The address contains the phone number and the carrier specific domain. For example, 0123456789@carrier.com.

T

Target Function Keys

Target Function Keys execute global operations that are always available, no matter which panel is displayed on the target. Operations execute when the operator presses the Target Function Key, regardless of which panel is displayed on the target. For more information, see Section 24.5.1, Target Function Key.

Target Machine

A target machine is an HMI unit - the computer that runs Vijeo Designer Run Time - where the screen application is downloaded to and displayed. The target machine can be used for machine control, security access, alarm monitoring, data logging, and other tasks. Depending on the target type, it may support features, such as multimedia support, Web Gate functionality, and data sharing.

Toolchest Parts

Toolchest parts refer to parts available in the Toolchest window.

U

User Application

The screen application created with the Vijeo Designer Editor on the PC.

V

Variables

Variables are named spaces in memory that store data values. The data type of a variable depends on its purpose. There are three groups of variable types: basic variables, user data types, and block types. For more information, see Section 6.1, About Variables and Device Addresses, and Section 6.2.1, Variable Types.

W

Web Gate

Web Gate uses Data Sharing. You can use Web Gate to connect from a remote computer to your target through an Internet browser. This connection allows you to control and monitor targets from anywhere. For more information, see Chapter 23, Remote Monitoring with Web Gate.

X

XY Graph

An XY graph plots a set of data points with X and Y coordinates instantaneously. You can use this type of graph to plot data from a PLC's block or array type variable. For more information, see Section 12.4.9, XY Graphs.
