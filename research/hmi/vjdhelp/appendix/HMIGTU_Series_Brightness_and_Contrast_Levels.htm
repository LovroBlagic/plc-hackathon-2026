For HMIG3U target machines, you can manage brightness in the Offline Configuration Menu. In the drop-down field, select Manual to adjust the brightness level manually, or select one of the brightness profiles: Dark, Standard, or Bright.

For HMIG5U/HMIG5U2/HMIG5U22 target machines, you can manage brightness in the Windows Control Panel by clicking Hardware and Sound, then clicking Backlight Brightness Setting. Select Manual to adjust the brightness level manually, or select Auto so that a brightness profile can be selected.
