5.9 Function Keys Supported by Hardware Platforms

A Function Key is both a hardware key on your target machine and the F1-F15 keys on your keyboard. Be aware of the different types of Function Keys supported by your target machine:

  • iPC/XBTGTW Series Function Keys

  • XBTGT Series Function Keys

  • HMIGK/XBTGK Series Function Keys

  • XBTGH Series Function Keys

  • HMISTO Series Function Keys

  • HMISTU Series Function Keys

  • HMIGTO Series Function Keys

  • HMISCU Series Function Keys

  • HMIGTU Series Function Keys

  • HMIGTUX Series Function Keys
