5.9.8 HMISCU Series Function Keys

The HMISCU Series supports keyboard function keys. Be aware that a keyboard function key can operate as a Target Function Key and as a Panel Function Key. For more information on adding function keys to your project, see Section 24.5.4, Adding and Removing Function Keys.

  • The HMISCU Series uses the function keys from the connected standard keyboard, from F1 to F15. Most standard keyboards support function keys F1 to F12.

  • The HMISCU Series uses the function keys from the connected Harmony USB keyboard, from F1 to F12.
