5.11.4 Vijeo Designer Functions that Support the USB Drive

Vijeo Designer Function

Drive Capability

Download application

You can download the run-time system files and the application files needed by runtime to execute the application to a USB drive. For more information, see Section 25.6.4, Downloading to a CF Card/SD Card Reader or USB Drive.

Copy files

You can copy runtime-generated files (alarm, data logging, video, and screen snapshot files) stored on the secondary drive to a USB drive. You can create a switch to perform the copy data operation. For more information, see Section 9.5.15, Copy Data Operations.

For recipe files, you must first download the files to the main or secondary drive. At runtime, you can copy the recipe files from the main or secondary drive to a USB drive, using the Copy Data switch.

For more information on data locations, see Appendix 5.11.1, Types of Data Locations.

Store run-time generated files

You can store run-time generated files (alarm and event, data logging, video, and screen snapshot files) on a USB drive.

For more information on run-time data locations, see Appendix 5.11.1, Types of Data Locations and Appendix 5.11.3, Supported Data for Each Drive.

  • The initialization of USB devices in XBTGK series requires more time. To ensure that the initialization is complete before you start the HMI application, add a startup delay of 5 seconds. For more information, see Section 24.4.1, Startup Delay.
