5.3 Brightness and Contrast Levels Supported by Hardware Platforms

The brightness and contrast levels correspond to the input ranges for the _Brightness and _Contrast system variables. For example, if a target supports 8 levels of brightness and 8 levels of contrast, the _Brightness and _Contrast system variables will have an input range of Min = 0 Max = 7. See the table in Section 20.4.2, Relationship between Brightness and Contrast Values and Levels for more information.' For more information on adjusting brightness and contrast settings on your target machine, see Section 20.4, Adjusting Brightness and Contrast Settings.

  • Some target machines do not support the _Brightness or _Contrast system variables and therefore do not support adjustments to their brightness and contrast settings.
