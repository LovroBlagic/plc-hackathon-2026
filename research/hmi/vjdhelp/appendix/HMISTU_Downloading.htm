*1 When downloading an HMISTU 855 project on an HMISTU 855 display module, and then replacing it with an HMISTU 655 display module, you cannot just modify the HMISTU 855 project by selecting the HMISTU 655 as the target type in the Target properties and then download your project. An error message displays. The same occurs when you download an HMISTU 655 project and replace it with an HMISTU 855 display module.

For example, if you are running an HMISTU 855 project and you replace the HMISTU 855 display module with an HMISTU 655 display module, follow these steps so that the project will download correctly:

  1. Download the project made for an HMISTU 855.

  2. Use Runtime Installer to download to the target. This step downloads the Welcome screen, which does not differentiate between HMISTU 655 and HMISTU 855.

  3. Change the display module to an HMISTU 655.

  4. Download the project made for an HMISTU 655.
