5.9.7 HMIGTO Series Function Keys

The HMIGTO Series supports both hardware function keys and keyboard function keys.

Hardware Function Keys

Only the HMIGTO1300, HMIGTO1310, and HMIGTO3510 support hardware function keys. The function keys can operate as a Target Function Key and as a Panel Function Key.

On the HMIGTO1300 and HMIGTO1310, there are six function keys that are located on the right side of the panel. These function keys are named F1 to F6.

On the HMIGTO3510, there are eight function keys that are located at the bottom of the panel. These function keys are named F1 to F8.

Keyboard Function Keys

All the HMIGTO target machines support keyboard function keys. A keyboard function key can operate as a Target Function Key and as a Panel Function Key. For more information on adding function keys to your project, see Section 24.5.4, Adding and Removing Function Keys.

  • On a standard keyboard, the HMIGTO1300 and HMIGTO1310 support function keys F1 to F6, and the HMIGTO3510 supports function keys F1 to F8. All the other HMIGTO target machines support F1 to F12 function keys.

  • On a Harmony USB keyboard, the HMIGTO Series supports function keys from F1 to F12.
