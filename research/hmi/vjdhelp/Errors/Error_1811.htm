Error 1811: Recipe transfer failed.  Ensure the Target's Download property is set to Ethernet, USB, or Serial, and matches the target.

The editor is unable to establish a connection with the target machine.

Solution:

  • Make sure the target machine is ON.

  • Check the connections to make sure none of the wiring is loose.

  • If this message appears when uploading the recipe from the target machine to the editor, Download may be set to File System. Uploading recipes works only over Ethernet, USB, and Serial ports.

  • If this message appears when downloading the recipe from the editor to the target machine, then that target may not support the selected download method.
