Warning 2619: [Trend Graph] [object name] is too small to display the data axis labels. Increase the width and height or reduce the size and number of labels.

The trend graph is too small to display the defined data axis labels.

Solution:

  • Increase the size of the trend graph.

  • As another solution, you can reduce the area occupied by labels. You can disable the DataAxisLabel altogether, reduce the font size, or reduce the number of digits displayed (DisplayRangeMin/DisplayRangeMax).

This is only a warning, so the build is not interrupted.
