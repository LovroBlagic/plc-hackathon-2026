Printing Errors

This section lists the error variable codes for printing and form printing errors, the error name, the description of the error, and how to fix the error if possible.

_Printer.Status

Error Number

Error Name

Error Description

Solution

0

Ready / No error

—

—

1

Printer is busy

The printer is too busy for printing, or the server is busy with e-mail.

Wait for the printer to complete its current operation.

2

Finished

The printer has completed the print operation.

Check the printer.

4

Error

The printer is not connected, not selected, or is not initialized.

Check the printer cable, or connect the printer to the target.

Error Name

Error Description
