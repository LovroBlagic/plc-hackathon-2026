Error 4383: [object type] [object name] [animation type] [property name] invalid input variable.

The property requires a single variable that is read/write. Either the defined variable is read-only or the variable is used in an expression. For example, the Destination Variable in Switch and Touch animation Word and Bit operations require a single variable that is read/write.

Solution:

Try one of the following.

  • If the variable is used in Recipes, then the Editable checkbox might be cleared.

  • Select a different variable for the property.
