Error 2060: [Target][target name] [Logging Groups] Maximum limit of [80] logging groups has been exceeded. Please delete [int] logging groups.

The total number of data logging groups for a target exceed the maximum limit of 80.

Solution:

  • Remove any data logging groups that are not being used or are not associated to any variables.

  • Consolidate data logging groups that have the same sampling rate and are similar in other properties.
