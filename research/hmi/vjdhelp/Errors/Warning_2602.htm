Warning 2602: [Alarm Summary] [object name] contains an alarm group with a Num of History Alarms property or Num of Log Alarms property disabled. Alarm messages from this alarm group will not be displayed.

The alarm summary is set up to display active, historical, or log alarms from a particular alarm group. However, the corresponding NumOfAlarms property in the alarm group (NumOfHistoricalAlarms or NumOfLogAlarms) is not activated. As a result, the alarm summary will not display any error messages at startup or panel change.

Solution:

  • Make sure the alarm summary object is set up to display the type of alarms you want.

  • Note the alarm group the alarm summary is assigned to.

  • In the alarm group properties, select the corresponding NumOfAlarms property (NumOfHistoricalAlarms or NumOfLogAlarms) and enter the number of alarms to hold in memory.
