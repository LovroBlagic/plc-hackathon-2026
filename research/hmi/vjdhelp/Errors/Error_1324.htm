Error 1324: For this target type, COM Port configuration and Serial interface combinations are not supported.

On most target machines, the serial ports are restricted to a single type of serial interface: RS-232C or RS-422. The combination of Serial Interface and COM Port settings cannot run on the defined target machine.

Solution:

The Navigator window's Projects tab, I/O Manager node lists the drivers in the project. For each driver, review the COM Port and Serial Interface settings in the Driver Configuration and Device Configuration dialog boxes and compare them with the specifications in the hardware manual to make sure the defined combinations are supported.

When you change target types, always review the COM Port and Serial Interface settings in the Driver Configuration and Device Configuration dialog boxes. The new target type may not support the selected Serial Interface and COM Port combination.
