Recipe Errors

This section lists the error variable codes for recipe operation errors, the error name, the description of the error, and how to fix the error if possible. The Error code is stored in the recipe Error Variable and the Error Name (except for Reserved) is written to the _LastErrorString system variable. For more information on system variables, see Section 6.7, System Variables.

1

Communication Error

A communication error has occurred. This may be due to PLC communications or network problems.

Return to the editor and check communication settings in the I/O Manager. Build and download the user application.

 

Make sure the network cable is not damaged and is securely connected to the hub, bridge, or other network device.

2

Invalid Recipe Group

Recipe group does not exist.

Recipe group file may be corrupted.

Download the recipe group again. You can use the following features to download recipe groups:

  • Data Manager
    See Section 20.5.2.3, Sending Files to a Target.

  • Recipe Download
    See Section 17.5 Downloading Recipe Groups to the Target Machine.

4

Invalid Recipe

Recipe does not exist.

Recipe may be corrupted.

Download the recipe group again. You can use the following features to download recipe groups:

  • Data Manager
    See Section 20.5.2.3, Sending Files to a Target.

  • Recipe Download
    See Section 17.5 Downloading Recipe Groups to the Target Machine.

8

Operation Not Permitted. Locked

A recipe operation is being performed and the file has been locked.

Wait until the operation completes for the file to unlock.

16

Invalid Operation

The value in the recipe Control Variable does not match one of the expected values.

Make sure the values you write to the Control Variable are valid.

32

Operation Not Performed. Busy.

A recipe operation is being performed and the file has been locked.

Wait until the operation completes for the file to unlock.

64

Insufficient Disk Space

Cannot write to storage drive because drive is full.

Create a sufficient amount of space on the drive to save the data.

128

Invalid File

The recipe file may be corrupted, unable to open.

Download recipe again. Use data manager of download vijeo-tool.

256

Invalid Access Right

You don't have the correct access right to access the recipe.

Enter in the correct access right for the recipe. See Section 17.8, Setting Up Security for Recipes.

512

Maintenance Mode

Operation was triggered during maintenance mode. See Section 20.5.4, Performing Maintenance on the Panel.

Turn off maintenance mode.
