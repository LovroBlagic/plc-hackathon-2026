Error 2003: [object type] [object name] [Name] doesn't follow naming convention.

The name you have used contains invalid characters or is a reserved word.

Solution:

  • Invalid Characters: Enter a valid name with valid characters. For more information on valid characters, see Appendix 9, Naming Conventions.

  • Reserved Word: Java Keywords and Vijeo Designer Keywords cannot be used as names. For a list of all the reserved words in Vijeo-Designer, see Appendix 3, Reserved Words.
