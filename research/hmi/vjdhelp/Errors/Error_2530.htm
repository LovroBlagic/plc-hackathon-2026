Error 2530: [object type][object name][property field] A thin bar graph cannot support labels, threshold markers, scale, and other features. You can only add features to a wider bar graph.

A thin bar graph is not wide enough to display options such as labels, scale marks, and threshold markers. Those options must be disabled to use a thin bar graph. See Section 12.3 Bar Graph for details on using a thin bar graph.

Solution

  • To use a thin bar graph, in properties, set Plate Style to blank (000000), set the Indicator Style to 100%, and disable Threshold markers and Major and Minor Scales.

  • Otherwise, to display labels, threshold markers, scale and other options, increase the bar graph width to 40 pixels or greater.
