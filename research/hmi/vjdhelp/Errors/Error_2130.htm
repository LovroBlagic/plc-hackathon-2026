Error 2130: Invalid password strength. Increase the minimum password length, or reduce the minimum character properties.

This error message displays when the total entered in the Security node's Minimum Uppercase, Minimum Lowercase, and Minimum Digits properties is greater than the Minimum Length property value.

Solution:

Ensure the total in the Minimum Uppercase, Minimum Lowercase, and Minimum Digits properties is equal to or less than the value in the Minimum Length property by either:

  • Increasing the value in the Minimum Length property.

–or–

  • Reducing the values in the Minimum Uppercase, Minimum Lowercase, and Minimum Digits properties.
