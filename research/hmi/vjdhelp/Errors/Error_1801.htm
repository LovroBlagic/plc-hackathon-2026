Error 1801: [Target] [target name] File System path is invalid.

Error 1801: [object type] [object name] [field name] The Optional Drive path is invalid.

When downloading, the user application could not be written to the defined path.

Solution:

When using File System download, the error message appears due to one of the following:

  • You entered a Path that does not exist.

  • You entered a Path which you do not have access.

  • You entered a Path to which you have read-only rights.
