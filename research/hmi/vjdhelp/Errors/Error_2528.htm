Error 2528: [Text] [object name] [property name] Monochrome target does not support Transparent text when Bitmap Display is Yes.

In the specified text object, either the Text Color or 3D Color is set Transparent, and the text object is set up with Bitmap Display, which means it's converted into a bitmap. Because the target is limited to two colors (black/white), and bitmap transparency may produce undesired results (see Section 7.2.13, Displaying Image Objects), Transparent text combined with Bitmap Display is not allowed.

Solution:

  • Either select a color for the Text Color and 3D Color properties, or set Bitmap Display to No.
