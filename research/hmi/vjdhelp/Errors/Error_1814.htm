Error 1814: [Recipes] [DownloadTo] Destination does not match the target machine.

The Recipes node includes the DownloadTo property. The DownloadTo setting has been changed since the application was originally downloaded to the target machine.

Solution:

  • Display the properties for the topmost Recipe node (Recipes). Change the DownloadTo property setting and download the recipe again.

  • You may have changed the DownloadTo property setting because the application has become too large to fit into internal memory (flash memory). If that is the case, then you should right-click the Target node and select Download, to download the target application again.
