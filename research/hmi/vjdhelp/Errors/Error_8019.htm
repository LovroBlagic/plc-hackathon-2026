Error 8019: [script type] [script name] [line number] [type1] is not a field of type [type2].

You are either assigning a value to a field, or assigning a value from a field in a class.

Solution:

  • If you are assigning value to a field in a class, the value is the wrong data type.

  • If you are assigning a value to a local variable from a field in a class, the variable is the wrong data type.
