28.2.3.2 Compilation Error Messages

The following error messages can occur during compilation.

 

Error Message 

Description 

Error aborting build due to compiler errors. Please clean and rebuild target. If the error continues, consult the Release Notes and the online help.

An error has occurred while compiling.

Run the clean operation and build again.

If the error displays again, the error could be caused by the following:

  • Script Variables not initialized
    Variables in scripts may not be initialized properly. For more information on initializing variables in scripts, see Section 18.3.2, Script and Variables: Initializing Variables.

  • Invalid Script Method Parameters
    The Parameters used in script methods may be of the wrong type. For example, the method may require a String parameter, but a Integer parameter is used. Check your project's scripts to make sure the script method parameters are valid.

  • Invalid Variable Scope
    A variable's global and local scope may be conflicting. Check the variable scope of your project's scripts.
    For Example, the following script has conflicting global and local variables:

int a; //global variable

int b = 0;

if(b==0)

{

int a; //local variable

a = 2;

}
