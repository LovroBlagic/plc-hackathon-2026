Error 2204: [object type] [object name] [Enable Blink] Blink colors are defined in the selected resource. Please disable Blink animation.

The color settings for the object are defined in the color resource. The selected resource is using blink for one of its colors and you've also added Blink animation, which cannot co-exist with blink colors.

Solution:

  • Do any of the following to remove the blink color/Blink animation conflict:

    • Disable Blink animation.

    • Remove blink from the color in the resource.

    • Change the resource to one that does not use blink colors.
