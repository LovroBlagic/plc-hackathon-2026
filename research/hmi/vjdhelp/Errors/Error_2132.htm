Error 2132: [Vijeo Design'Air or Vijeo Design'Air Plus] is set to Use Security but no security group has been set to access [Vijeo Design'Air or Vijeo Design'Air Plus].

This message displays when, in the Property Inspector, Vijeo Design'Air or Vijeo Design'Air Plus are set to Use Security; however, in the Security editor neither of these features has been set to Read/Write.

Solution:

  • In the Security editor, for at least one of the security groups, set Vijeo Design'Air or Vijeo Design'Air Plus column to Read/Write.
