Warning 4320: [variable] [variable name] is not supported by this target type.

The target machine does not support the specified system variable. Some target machines do not support changes to their brightness and contrast and therefore do not support the _Brightness and/or _Contrast system variables. For a list of target machines that support changes to their brightness and contrast, see Appendix 5.3, Brightness and Contrast Levels Supported by Hardware Platforms.

Solution:

  • Do not use the specified system variable because the selected target type does not support it.

To locate the error in this project, double-click the error message in the Feedback Zone.
