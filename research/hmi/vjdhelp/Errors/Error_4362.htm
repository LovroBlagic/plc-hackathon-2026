Error 4362: [object type] [object name] [animation type] [property name] underscore character denotes a system variable. This field cannot accept system variables.

The specified fields in the Animation Properties cannot use system variables.

Solution:

To use the same value as the system variable:

  1. Create an internal variable.

  2. Create an application script and set Trigger to Conditional.

  3. In the TriggerVariable property, type the system variable.

  4. In the script, assign the value of the system variable to the internal variable created in Step 1.

int i = SYSTEM_VARIABLE_NAME.getIntValue( ); // get value

NEW_INTERNAL_VARIABLE.write(i);              // write to var

Every time the value of the system variable changes, it triggers the application script, which copies the value of the system variable to the internal variable.

  1. Use the internal variable wherever you planned to use the system variable.
