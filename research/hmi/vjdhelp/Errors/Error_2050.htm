Error 2050: [Target] [target name] [Graphical Panels] no panels exist.

The Graphical Panels node is empty. Your target needs at least one panel in the Graphical Panels node for you to work with the user application on your target machine.

Solution:

  • In the Navigator, add a panel to the Graphical Panels node, and set the Target's InitialPanelID property to this panel.

  • To locate the error from the Feedback Zone, double-click the error message.
