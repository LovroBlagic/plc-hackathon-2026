Error 2529: [Text] [object name] Transparency settings for the Back Color and Line Color do not match.

On monochrome target machines, the Back Color and Line Color in a text object must both be transparent, or both be set to a color.

For example, you cannot set the Back Color transparent and set the Line Color white.

Solution:

  • Either set both Back Color and Line Color transparent, or select a color for the Back Color and Line Color. If you select colors, the Back Color and Line Color do not have to be the same color.
