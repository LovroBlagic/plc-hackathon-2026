Error 2091: [Diagnostic Alarm Group] [name] [.sto file path] Directory or language folder does not exist. Please make sure the directory exists and there is a language folder for at least one of the locales used in the application.

Error 2091: [Diagnostic Alarm Group] [name] [.sto file path] A .sto file is missing in the defined directory. To use the custom .sto file, add the file to the language folder in the directory path.

Derived Function Blocks (DFB) use .sto files to store status messages. For information about how to work with .sto files, see Section 16.3.2.3, Displaying Derived Function Block Status Messages.

The custom .sto file path you've specified in the Diagnostic Alarm Group Settings is invalid.

As indicated in the message, there are three reasons why this error may occur:

  • The specified path does not exist.

  • The specified path does not contain a language folder.

  • There is no .sto file in the language folder.

Solution:

  • The most likely reason this error occurs is because the .sto files must be stored in subfolders that indicate their language. Custom .sto files must include language folders as part of the path: ENU for English, FRA for French, DEU for German, ITA for Italian, and ESP for Spanish.
    For example, type C:\STOFiles when .sto files are located in C:\STOFiles\ENU\DFBFilename.sto.
