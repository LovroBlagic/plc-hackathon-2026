Error 8021: [script type] [script name] [line number] first operand of conditional expression must be a boolean type.

The first operand in the specified conditional expression (x ? y : z) will not evaluate to a boolean value (0 or 1).

Solution:

  • Check if you're using numeric values. The script is expecting a conditional expression that returns true or false. Java does not evaluate numeric values as true or false.

  • Check if you're using a string type variable. String variables cannot be converted into a boolean.

  • Check if the expression returns void. Void cannot be converted into a boolean.
