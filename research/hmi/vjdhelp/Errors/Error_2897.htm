Error 2897: [USB] If you are using a target with only one USB port, you cannot add FIPWAY equipment and FIPIO equipment in the same project.

Error 2897: [COM1] has been selected in more than one driver or peripheral.

Error 2897: [High speed serial driver] has been selected in more than one driver or peripheral.

There is a conflict with the port. More than one driver is using the same port in the same project.

Solution:

  • Reduce the number of drivers in your project to only one, or

  • Change to a driver with the proper communication method.
