Error 1309: [Target] [targetname] [DataSharing] must be enabled when Web Gate is enabled.

After enabling Web Gate, Data Sharing has been disabled. Web Gate requires Data Sharing to communicate between the web browser and the target machine. For more information on Data Sharing, see Section 22.1, Sharing Data Between Tablets, Smartphones, and Target Machines.

Solution:

  • If you are going to use Web Gate, you must set Data Sharing to Enabled.
