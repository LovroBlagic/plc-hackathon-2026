Error 2061: [%s] [%s] [%s] Time-Based features cannot be used when Time Management Property is set to Disabled.

This error message displays when you are attempting to download a project to a target that does not have battery backup for the internal clock, contains a time-based object, and the Time Management feature is not enabled for the target.

Solution:

  • In the target properties' Startup Options, set the Time Management property to enabled or remove the time-based feature.
