Warning 2102: [object type] [object name] [Line Width] must be solid for this line width. Line style will be adjusted.

The specified object uses a dotted line style although the line width is greater than 1. Only line widths of 1 can support dotted line styles.

Solution:

  • Set LineStyle = [Solid] or [Invisible].

  • Set LineWidth = 1.

This is only a warning, so the build is not interrupted.
