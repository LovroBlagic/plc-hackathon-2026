Error 2075: [Panel] [panel name] references too many variables. The variable limit on a single panel for the selected target type is [int]. Either reduce the number of variables or select a target with a higher limit.

Too many variables on a single panel can cause memory, CPU usage, and communication problems.

The limit for the number of variables per panel is 800.

Solution:

  • Reduce the number of variables on the panel by separating the functionality into two or more panels.
