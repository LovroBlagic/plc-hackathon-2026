Error 1004: [filename] unexpected end of file found.

The specified filename has encountered an unexpected end of file, which is the fully qualified path of the file being read.

Solution:

  • Close the application and reboot your machine to ensure Vijeo-Designer isn't trying to open a damaged temporary file.

  • If this error message continues, the file you're trying to open may not be valid or has been corrupted. If you have a backup, continue your work using the backup.
