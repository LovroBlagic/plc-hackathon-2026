Error 1402: [Variable] [variable name] [Trigger Action] [Alarm Condition] is not supported by the current variable data type.

The alarm trigger action uses an alarm condition that the variable alarm cannot support. The variable data type may have changed after the variable alarm was originally set up.

Solution:

  • Open the Alarm Trigger Actions dialog box for the variable identified in the message. Review the condition (especially custom condition) set up for each alarm operation to make sure it is valid for the variable data type.
