Warning 2104: [object type] [object name] [LineStyle] cannot support dotted line styles for selected target. Line style will be adjusted.

The specified object uses a dotted line style, however your target machine doesn't support dotted line styles. The runtime application will change dotted lines to dashed lines.

Solution:

  • Set LineStyle = [Dashed] or [Solid].

This is only a warning, so the build is not interrupted.
