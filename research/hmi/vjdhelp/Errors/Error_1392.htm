Error 1392: [Variable] [variable name] [Logging Group] When using logged variable values, assign the variable to a data logging group.

The variable you want logged is not associated with a data logging group. In working with data logging, you must assign the variable to a data logging group, which contains a set of properties that specifies the data collection method and data storage details for a variable.

Solution:

  • Assign the variable to a data logging group using the Data Details tab in the Variable Properties dialog box or in the variable properties. For more information, see Section 13.2.3, Assigning a Data Logging Group to a Variable.
