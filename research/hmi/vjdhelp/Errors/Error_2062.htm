Error 2062: [Languages] [Language Name] [Locale] uses an invalid system language.

This error displays when you set up a user language that is not configured as a system language.

Solution:

  • Check the list of system languages configured in the System Languages Manager. If the Locale of the user language you are setting up is not one of the configured system languages, you can select the language in the System Language Manager. For more information, see Section 20.2.2, Configuring the System Language.
