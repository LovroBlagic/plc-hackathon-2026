Error 2637: [Target Name] [Alarm Category] [Remote Alarm Category Name] You cannot set up HMISTO531 and HMISTO532 targets as remote clients.

This message displays when you try to set up HMISTO531 or HMISTO532 as remote clients. The alarm summary size on an HMISTO531 or HMISTO532 target machine is small and would not be very useful as a remote alarm client.

Solution:

  • Select another target machine that has a larger panel size. For more information on target machine models and panel sizes, see Appendix 5.1.3, Models and Panel Sizes.
