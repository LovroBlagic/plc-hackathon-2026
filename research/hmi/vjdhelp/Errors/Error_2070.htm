Error 2070: [Panel] [panelName] [FunctionKeys] exceeds maximum limit of 32, please reduce the number of rows.

The validation process has detected more than 32 functions set up for a single function key.

Solution:

  • You can set up global and local function keys.

  • Set up global function keys in the Target node. Set up local function keys in the Panel node.

  • The total limit is 32 functions per key, which includes both global and local functions.

  • This error message appears because you've set up more than 32 global AND local functions onto a function key. Reduce the number of functions for that key.
