Error 1399: [Variable] [variable name] [Indirect Address] requires an integer type variable with both [Indirect Address] and [Reference] disabled.

This message indicates you are nesting Indirect Address and Reference variables. In other words, the variable you are using to define the indirect address is already set up with the indirect address and reference feature.

Solution:

  • For the Indirect Address, select an integer type variable that does not use an indirect address or reference.
