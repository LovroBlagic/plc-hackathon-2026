Error 8004: [script type] [script name] [line number] [type1] may lose data converting to type [type2].

Because you're converting values from the specified data type to a smaller data type, you may lose some data.

The following example produces this error, as it assigns a double value to an integer variable, losing the value after the decimal point.

E.g. int var1 = 5.5;

Solution:

  • Change the variable type.

    double var1 = 5.5;

  • Typecast the variable.

    int var1 = (int)5.5;
