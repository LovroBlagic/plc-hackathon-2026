Warning 4527: [Target] [Target Name] Vijeo Design'Air is enabled. At runtime, the simultaneous connection of Vijeo Design'Air and Vijeo Design'Air Plus to the target machine is not supported.

When you enable both Vijeo Design'Air and Vijeo Design'Air Plus in a project, this message displays to warn you that, at runtime, only one of these two applications can access data on the target machine. For example, if Vijeo Design'Air is connected to a target machine, Vijeo Design'Air Plus cannot open a data sharing connection to the same target machine.

Solution:

  • To prevent this warning message from displaying, have either Vijeo Design'Air or Vijeo Design'Air Plus enabled, not both. Note that this is only a warning, so the build is not disrupted.
