Error 8018: [script type] [script name] [line number] [type] does not have a field.

You are trying to use a field in a class that does not support that field.

Solution:

  • You cannot use fields with Vijeo-Designer objects. You can use fields with classes that support the field.

  • e.g. If you wanted to use pi (ratio of a circumference of a circle to its diameter), type "Math.PI". The Math class is offered by the Java programming language, and PI is a field supported by the Math class.
