Error 1007: [filename] cannot read file.

The specified file may be corrupted, or in a format that can't be read.

Solution:

  • Check to see if the file is being used by another application or opened by another user.

  • Read the file with the application assigned to that file type. If unsuccessful, the file is corrupted. If successful, save the file and try reading the file again in Vijeo-Designer.

  • If you are reading from a directory over the network, check if you have read access to that directory.

  • If none of the above is effective, do not save the project, close the application, reboot your PC and try reading the file again.
