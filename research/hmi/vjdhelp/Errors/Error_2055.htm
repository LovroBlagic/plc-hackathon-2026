Error 2055: [recipe object type] [recipe object name] label [label name] in language [language name] is a duplicate.  Duplicate labels are not allowed.

Recipe groups comprise recipes. Each recipe has a name and a label associated with it. The label is used at run time for display in the Recipe Manager and other lists. Labels for each recipe in the same recipe group must be unique. The same is true with ingredient labels.

Recipes comprise ingredients. Each ingredient has a name and label. The label is used at run time for display in list objects.

  • If the application uses multiple languages, labels from one language to another can be the same. However, labels for recipes within a recipe group, and labels for ingredients within a recipe, must be unique from one recipe to another, or from one ingredient to another, within that language.

Solution:

  • In all recipe groups, make sure recipe labels are distinct between recipes.

  • In all recipes, make sure ingredient labels are distinct between ingredients.

  • If the application has multiple languages, ensure recipe and ingredient label uniqueness in all the languages.
