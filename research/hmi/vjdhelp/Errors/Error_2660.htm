Error 2660 [object type] [object name] Characters are too large to fit. Either reduce the size of the characters or increase the size of the drawing.

Error 2660: [object type] [object name] Threshold displays cannot fit. To prevent this error, you can either decrease the size of the threshold or increase the size of the drawing.

Error 2660: [object type] [object name] Indicator is too large to fit.  To prevent this error, you can reduce the size of the indicator or increase the size of the drawing."

The labels, the numeric display, the threshold range (labels and scale), or the indicator you have configured in the part is too large for the part to display properly during run time.

Solution:

  • Increase the size of the part so that the labels, the numeric display, threshold displays, or indicator can fit.

  • For objects that have a numeric display, threshold, or indicator, decrease its width and height to reduce the area it requires.

  • For objects that have a label, reduce the size of the label by changing the label's font size or reducing the length of the label's text.
