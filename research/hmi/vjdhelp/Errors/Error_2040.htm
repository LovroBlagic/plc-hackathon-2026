Error 2040: [object type] [object name] [animation type] already added to object. Cannot add the same animation again.

The specified animation is used by at least one of the objects in the group. You can't add animation to a group when an object in the group already uses that animation.

Solution:

  • Ungroup the object, find the object(s) with the specified animation then disable the animation. Regroup the objects and add animation to the group.
