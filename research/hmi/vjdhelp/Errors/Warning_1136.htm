Warning 1136: [Target] [target name] the defined Key Size and String Keypad Layout can create string keypads that are too large to fit in the panel. To prevent this warning, set String Keypad Layout to Compact (Multipage).

You can set up mid-sized panels (640x480 and 800x600) using a combination of keypad layout and key sizes that can produce keypads unable to fit in the panel area.

Solution:

  • Set the string keypad layout to Compact (Multipage). If you are not using a string keypad, you can ignore the warning.
