Error 2600: [object type] [object name] [tab name] The object needs at least one action.

Error 2600: [object type] [object name] [state number] The state needs at least one action.

Switches and selector parts support touch operations. For switches, there are no operations set up in the defined object. For selectors, there are no operations set up in the defined state.

Solution:

  • For switches, add at least one operation.

  • For selectors, you can either add at least one operation or clear the Enable Actions check box.
