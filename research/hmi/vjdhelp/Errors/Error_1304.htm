Error 1304: [target name] You have exceeded the SRAM size for this target model. Please reduce the SRAM usage.

The SRAM size is different depending on which target model you use. SRAM is used to back up alarms, event messages, and variable history.

Alarms: When Backup Alarm Group = Yes in the Alarms node properties, the Num Of History Alarms and Num Of Log Alarms in the alarm group properties, plus the number of variable alarms, define how many alarms are backed up to SRAM.

Event Messages: Whenever a run time message displays, it gets recorded in the event log, which is stored in SRAM.

Data Logging: For each variable, up to 50 data records are queued in SRAM before it's flushed to the Secondary Drive or internal memory (flash memory).

Solution

  • Reduce the number of alarms to back up.

Backup Alarms = History + Log + Active

You can either reduce the number of variables that have an alarm, or reduce the number of history and log alarms in each alarm group.

  • Reduce the number of data records to store in the SRAM.
