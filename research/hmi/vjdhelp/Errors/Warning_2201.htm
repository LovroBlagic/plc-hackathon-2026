Warning 2201: [object type] [object name] [property name] The part does not use all the states defined by the resource.

This warning is issued because the number of states used by the part is less than the number of states available in the resource. You may have configured the parts and resources like this intentionally, and so may ignore the warning.

Solution:

  • Although not required, you may want to match the number of states defined by a resource with the number of states in parts that use the resource.

This is only a warning, so the build is not interrupted.
