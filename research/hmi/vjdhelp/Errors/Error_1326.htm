Error 1326: [Driver Name] driver does not support RS-485 serial interface for selected target model.

This error message displays when you use the RS-485 serial interface for a Unitel driver on an iPC target machine. In cases where the RS-485 serial interface is selected, when you validate, the error displays. The RS-485 serial interface requires a hardware timer that the iPC target machine does not have.

Solution:

  • Use the RS-422 serial interface RS-422, or use another driver, or use a target machine other than the iPC.
