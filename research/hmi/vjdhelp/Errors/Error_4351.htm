Error 4351: [object type] [object name] [field name] invalid remote variable before position [int].

The object is trying to use a variable from a different target machine but access to the variable has been denied.

Solution:

  • This error usually indicates one of two things: 1) Target DataSharing is not Enabled, or 2) Sharing is not enabled for the referenced variable.
    Make sure the Target's DataSharing property is Enabled, and that the variable's Sharing property = Read-only or Read/Write. For instructions, see Section 22.1.1, Setting Up Shared Variables.
