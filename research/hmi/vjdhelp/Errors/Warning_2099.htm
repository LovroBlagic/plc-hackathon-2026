Warning 2099: Your data text file exceeds #KBytes. You may experience performance problems at runtime.

The size of text files for use with text display parts is limited only by the amount of memory you have available on your target machine. This warning appears when the text file is larger than 50Kbytes.

Solution:

  • If the text display part is slow to display data, the text file may be too large for your system. Separate text into different files to reduce its size. You can add a variable to the text display to switch between text files (see Section 11.7.2.2, Switching Between Multiple Text Files).

This is only a warning, so the build is not interrupted.
