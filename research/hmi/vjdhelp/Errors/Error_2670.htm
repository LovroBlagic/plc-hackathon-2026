Error 2670: [object type] [object name] [Use Variable's Min/Max] is selected, but the associated variable's Input Range is not enabled.

The Use Variable's Min/Max property is enabled, but the variable specified in the variable field does not have input range enabled.

Solution:

  • Set up the variable's Input Range.

  • Disable the Use Variable's Min/Max property and use the Min and Max properties to define the Min and Max values.
