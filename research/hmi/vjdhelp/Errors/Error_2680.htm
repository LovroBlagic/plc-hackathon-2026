Error 2680:  [Video] [video object name] [Display Popup Keypad] When selecting None as the Default Video, the video popup keypad must be either Live/Play Video or Live/Record/Play Video.

The Popup Keypad is set to Disabled and Play File property is set to None. If there is no default video, you must have a way to select videos.

Solution:

  • Change the Popup Keypad to Enabled and select Live/Play Video or Live/Record/Play Video.
