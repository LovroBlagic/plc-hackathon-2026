Warning 2103: [object type] [object name] [Line Style] is only valid with solid line styles. Line style will be adjusted.

The specified object uses a line width greater than 1 although the line style is not solid or invisible. Only solid and invisible line styles can support line widths greater than 1.

Solution:

  • Set LineWidth = 1.

  • Set LineStyle = [Solid] or [Invisible].

This is only a warning, so the build is not interrupted.
