Error 2898: [Variable] [INT01] [Indirect Address] cannot be used by variables with %I or %Q addresses.

This error occurs when a project uses a Schneider driver, has an external variable set to %I or %Q as an address, and Indirect Address is enabled for the variable.

Solution:

  • The %I and %Q addresses are not supported when Indirect Address is enabled. Set Indirect Address to disabled.
