Error 2890: [Equipment] [Equipment Name] [Dialog Table] The Image of Static Function Keys is not supported for XBTGK targets when the Control Mode property for the target's Function Keys is set to Target Setting.

This error displays for XBTGK targets when you try to use the Image of Static Function Keys to store the status of the target's function keys on the PLC and the Control Mode setting for the target function keys is Target Setting.

Solution:

  • In the target properties, change the Control Mode setting for the target function keys to Dialog Table.
