Warning 2895: [Equipment] [ModbusEquipment01] [Dialog Table] Functions 1 and 24 to 28 will not run when the Function Key’s Control Mode is set to Target Setting.

This warning displays during validation if you have added conflicting dialog table functions with Target Setting as the Control Mode setting for the target function keys.

Solution:

  • In the target properties, change the Control Mode setting for the target function keys to Dialog Table.
