Warning 2106: [Security] [security group name] [security object] The defined security feature is unsecured. Group security settings will be ignored.

When the specified security object (Download, Data Manager, or Web Gate) is set to unsecured in the Security Property Inspector, the security settings defined in the Security Group Editor will not be effective. This means that there will be no security check for Download, Data Manager, or Web Gate.

Solution:

  • To ensure that there will be a security check for the security object, set Download, Data Manager, or Web Gate to secured.
