Warning 2050: [Target][target name] is not associated with any target machines. To prevent this warning, in the HMI Target properties (Remote Management, Vijeo Design'Air Plus), select [target name].

This message displays when the tablet target is not linked to any HMI target machines in your project.

Solution:

  • In the project, select an HMI target machine. In the property inspector, expand Remote Management and in the Vijeo Design'Air Plus property, select the tablet target.
