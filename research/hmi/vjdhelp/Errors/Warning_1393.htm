Warning 1393: [Variables] [KeepHistory] is Enabled for over [number] variables in [TargetName].  If the target machine does not support Secondary Drive or disk based storage, it does not record variable data to permanent storage media.

Historical data is set up for over [number] variables, which could cause disk space problems on target machines with limited disk storage. XBTGT2110 and XBTG2110 target machines do not record variable data to permanent storage media.

Solution:

  • Use the Data Manager regularly to extract and delete logged data.
