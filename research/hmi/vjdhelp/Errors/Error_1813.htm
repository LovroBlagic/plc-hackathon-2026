Error 1813: [Recipe Group] [recipe group name] Signatures between the editor and target do not match.

Each recipe group generates a unique signature based on the list of ingredients in the recipe. The signature must match, or in other words the list of ingredients must be the same, in order for the recipe operation to continue.

Solution:

  • To make the recipes match between the editor and target machine, right-click the Target node and select Download.

  • An alternative, if recipes on the target machine have to be preserved, is to use the Data Manager to retrieve the recipe files for import into a target project. For instructions on using the Data Manager, see Section 20.5.2, Transferring and Converting Data using the Data Manager.
