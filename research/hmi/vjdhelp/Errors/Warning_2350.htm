Warning 2350: [object type] [object name] [animation type] a close popup window operation occurs before a Momentary On/Off operation.

This warning is issued because a close popup window operation occurs before a momentary operation which could cause side-effects. Because the popup window closes, the momentary operation may not be able to complete its operations.

Solution:

  • Test your application to make sure no abnormal behavior occurs.

  • If you detect problems, find the defined object and view the touch operations. Find the popup window close operation, whether it's a script, action, or touch operation. Once you find the script that is causing the problem, move the operation after all Momentary operations.

This is only a warning, so the build is not interrupted.
