28.1 Run-time Events

A run-time event is a system error that occurs during run time. When a run-time event occurs, the Active Error Viewer appears and displays an error message that describes the error. The error message is also saved in the Error Log Viewer so that you can keep a record of the errors occurring in your system. See Section 28.2.4.1, Run-time Event Messages, for a list of Run-time Event messages, descriptions on each message, and information on how to resolve each event.

If your target machine supports the DIO port, a system error will trigger the DIO RUN pin to turn on and the Active Error Viewer to appear. The DIO RUN pin turns off once the user views all the event messages and closes the Active Error Viewer. For more information on DIO ports, see Section 24.6, DIO Ports and your target machine's hardware manual in Appendix 1, Hardware Manuals.

  • Error messages display once and do not appear again even if the error still exists in the system.

Active Error Viewer

When a run-time event occurs, the Active Error Viewer appears on the panel and displays the error message. The Active Error Viewer displays one message at a time.

System Error Log Viewer

The System Error Log Viewer can store and display up to 100 error messages. After the error log is filled, the oldest error messages become displaced for new error messages.

Users can access the System Event Log Viewer by using a switch, script, or the Show System Error Log Viewer icon in the Active Error Viewer. For details on displaying the System Error Log Viewer, see Section 28.1.2, System Error Log Viewer: How to Display the System Error Log Viewer.
