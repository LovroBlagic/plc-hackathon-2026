Warning 2500: [Image] [object name] [ColorDepth] 256 colors is not supported by target.

The color depth specified for your image is not supported by your target. The image will be filtered to 64 colors and may not appear as shown.

Solution:

  • Set ColorDepth = [64 colors] for the image.

  • In the target properties, set TargetColor = [256] to support the image's color depth. However, this will completely disable the blink color setting, except for Blink animation.

This is only a warning, so the build is not interrupted.
