Error 1800: [Target] [target name] cannot find defined target machine.

When downloading, connection with the target machine could not be established.

Solution:

When using Serial or USB download, the error message appears due to one of the following:

  • Target machine is OFF.

  • Download cable is not connected to the defined port on the editor PC.

  • Download cable connections are loose.

  • Invalid download cable is used.

  • Download cable is damaged.

  • Connected target machine is not supported.

When using Ethernet download, the error message appears due to one of the following:

  • Vijeo-Designer Runtime is not running or the target machine is not turned ON.

  • You entered an incorrect IP address in the Target's download properties.

  • The IP address set in the Target properties is not for a valid Vijeo-Designer target machine. You probably typed an IP address that belongs to other types of equipment.

  • You used Download All on a project that has more than one target set to the same IP address.

The error message displays if you do not download an HMISTU 655 or HMISTU 855 project correctly after changing the display module. To perform a project download correctly after changing the display module, follow the steps in Appendix 5.2.7.4, Features Supported by HMISTU Series - Downloading.
