Error 4416: [parts] [object name] [property name] is not valid. Requires a valid char or character literal.

An invalid character code or multiple characters have been entered into the specified property.

Solution:

  • If using character codes, make sure the character code is a valid Unicode, ASCII (hexadecimal), or ASCII (decimal) character code.

  • If using single characters, make sure there is only one character in the property.
