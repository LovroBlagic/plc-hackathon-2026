Error 1830: [Target] [target name] unable to continue download. Disk may be full.

Download has been interrupted and the most likely reason is the disk is full.

Solution:

Either decrease the size of the user application or increase the amount of disk space available.

Decrease size of user application:

  • If a common interface appears in multiple panels, use just one panel and delete the others. Or, move the interface into a popup window panel called from the various panels.

  • Reduce the number of images (bitmaps) in the user application.

Increase disk space:

  • Erase or format the disk then download again.

  • Defragment the disk.

  • Use a higher capacity Secondary Drive.
