Error 1125: [object type] [object name] [IP Address:Port No.] invalid IP address.

Error 1125: [object type] [object name] [host name] requires a valid Host Name.

The specified IP address, port number, or host name is invalid.

For host names, you need a valid DNS server on your network that has the target’s IP address and host name set up. Vijeo Designer contacts the DNS server and validates the host name after you type the host name in your project.

Solution:

  • For invalid IP addresses of port numbers, enter a valid IP address and port number separated by a colon (:).

  • For invalid host names, use a valid host name that is available on your DNS server. For more information on valid host names, see Appendix 9 Naming Conventions.
