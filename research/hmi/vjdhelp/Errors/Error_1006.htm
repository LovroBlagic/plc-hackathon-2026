Error 1006: [filename] cannot write to file.

The specified file cannot be written to.

Solution:

  • Check to see if the file is being used by another application or opened by another user.

  • Open the file with the application assigned to that file type. If unsuccessful, the file is corrupted. If successful, save the file and try saving to the file again in Vijeo-Designer.

  • If you are writing to a directory over the network, check if you have read/write access to that directory.

  • If none of the above is effective, save the information using a different filename, or use backup project to save the project.
