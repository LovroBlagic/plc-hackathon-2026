Error 1403:  [Variable] [variable name] [Trigger Action] [Alarm Condition]  At least one condition must be selected.

No alarm conditions are selected for an alarm trigger action. The variable data type may have changed after the variable alarm was originally set up.

Solution:

  • Open the Alarm Trigger Actions dialog box for the variable identified in the message. Review the condition (especially custom condition) set up for each alarm operation to make sure at least one condition is selected.
