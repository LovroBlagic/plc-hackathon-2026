Error 8056: [script type] [script name] [line number] references a variable with an indirect address. Indirect address variables cannot be used in scripts.

The variable used in the specified line number is set up with an indirect device address. Because of the latency from when the offset variable (indirect address) changes, to when the variable value is updated, indirect variables cannot be used in scripts.

Solution:

  • For the specified variable, clear the Indirect Address checkbox, or

  • Do not use the variable in scripts.
