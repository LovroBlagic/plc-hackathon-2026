Error 2740: [object type] [object name] [animation type] already added to object.  Cannot add the same animation again.

You are trying to add an animation that is already added to the object. This error is most common when working with grouped objects, when you try to add an animation to the group and the animation is already added to one of the objects in the group.

Solution:

  • Remove the animation from the individual object so you can add the animation to the group.
