Error 2803: [Target Type] [Target Name] [Property Name] The current target machine does not support the Set IP Address operation.

This error occurs when you make one of the following changes after your project successfully validated with a Set IP Address operation:

  • Changing the target machine to one without Ethernet capability.

  • Changing to an iPC, HMIG5U, HMIG5U2 or HMIG5U22 target machine.

Solution:

  • Select a target machine that has Ethernet capability and that is not an iPC Series target machine.

  • Select a target machine that is not a Windows-based target machine (such as iPC or HMIG5U). Windows-based target machines do not support IP address change at run time and cannot run the Set IP Address operation.

  • Make sure the DHCP property in the Target properties is set to Disabled.

  • Make sure the Set IP Address at Run Time property in the Target properties is selected.
