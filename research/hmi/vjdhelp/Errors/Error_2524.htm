Error 2524: [Text] [object name] [Text] only accepts '#' because [Value animation] is enabled.

The defined text does not support Value animation. Only hash symbols (#) support Value animation.

  • While multiple hash (#) symbols support Value animation, mixing # with other text or punctuation will disable the animation.

Solution:

  • Edit the text back to '#' if you want to keep Value animation.

  • If you don't need the Value animation, remove it.
