Error 2223: [Equipment] [Equipment Name] [Dialog Table] The Set Terminal Clock function does not work when the target’s Time Adjustment (DST) property is set to Enabled.

This message is issued when you have both the Set Terminal Clock function added to the Dialog Table and the target's Time Adjustment (DST) property set to Enabled.

Solution:

  • Remove the Set Terminal Clock function or set the Time Adjustment (DST) property to Disabled.
