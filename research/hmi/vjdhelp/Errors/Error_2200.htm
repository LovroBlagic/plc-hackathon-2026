Error 2200: [object type] [object name] [property name] The number of states defined in the resource is less than the number of states used by the part.

The defined object uses resources to define properties for its various states. However, the part is set up with more states than are defined in the selected resource, resulting in states without property definitions.

Solution:

  • Either reduce the number of states in the part or increase the number of states in the resource and define values for properties in added states.
