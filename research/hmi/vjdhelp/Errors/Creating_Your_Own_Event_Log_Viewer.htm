28.1.3 Creating a System Error Log Viewer

The System Error Log Viewer is part of Vijeo-Designer Runtime. If this System Error Log Viewer does not suit the requirements of your project, you can use a System Error Log from the Toolchest. Toolchest System Error Log viewers are useful because they can be positioned on any panel or any popup window, and they come in different sizes.

  • The System Error Log Large, System Error Log Medium, System Error Log Small Toolchest parts are designed for all target machines, except for the target with a 200x80 panel size. The Error Log-One Event  Toolchest part is the only log viewer you can use for targets with a 200x80 panel size.

Toolchest System Error Log viewers are displayed using the methods for displaying panels and popup windows. See Section 20.1, Switching Panels, and Section 15.1, Creating Popup Windows.

Adding a Toolchest System Error Log Viewer

  1. In the Toolchest window, click the Diagnostic folder.

  1. From the Toolchest window, drag and drop the System Error Log Viewer part onto a panel or popup window.

  • Your application can include system and user-created System Error Log Viewers.

  • The size of Error Log operation buttons in the editor may not match the actual size of buttons on the target machine.
