Error 1310: [Project] [project name] [Input Manager] select a target that supports Data Sharing.

The project is configured to use input synchronization, which ensures only one target in the project can display an exclusive input panel at one time. In the Project properties, you've selected as the Input Manager a target that cannot participate in the exclusive input relationship.

For more information about input synchronization, see Section 22.2, Setting Up Exclusive Input Relationships.

Solution:

  • Select as the Input Manager, a target that can support data sharing. The targets use data sharing to request exclusive input from the input manager.
