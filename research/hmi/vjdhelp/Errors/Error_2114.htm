Error 2114: [Security] [User Name] [%s - entered user name] Name already in use. Please enter a different user name.

This error occurs when at project level, in the Download User properties, the entered user name is same as a security user name; or, when in Security settings, the entered user name is same as the user name defined in the Project's Download User properties.

Solution:

  • Enter a different user name.
