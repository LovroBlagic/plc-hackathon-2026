Error 2022: [object type][object name][property name] out of range. Enter a non-zero value or expression.

You entered the value zero in the specified property.

Solution:

  • Enter any value other than zero.

  • If you enter a single variable, you should make sure the variable's initial value does not equal zero.

  • If the property accepts expressions, you should make sure the expression does not equal zero.

The value specified for the variable's data range in invalid.

Solution:

  • Enter a non-zero value within the variable's data range limits.
