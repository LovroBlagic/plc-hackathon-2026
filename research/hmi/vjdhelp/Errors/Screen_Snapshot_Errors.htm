Snapshot Errors

This section lists the error variable codes for snapshot operation errors (both video snapshot and run-time screen snapshot), the Error name, the description of the error, and how to fix the error if possible. The Error code is stored in the Error Variable and the Error Name (except for Reserved) is written to the _LastErrorString system variable. For more information on system variables, see Section 6.7, System Variables.

No Storage Drive

The storage drive the target machine is trying to store the screen capture on is not connected to the target machine.

Check storage drive and ensure it is connected to the target machine.

Hatch is open on the CF Card drive.

Close CF Card hatch.

Cannot write to storage drive because drive is full.

Storage Drive Error

The wrong disk is in the storage drive.

Insert the disk used at startup to continue operations.

Unable to delete the file.

The file number is out of range.

Specify a number within range.

Printer command error

The printer is receiving commands it isn't configured to handle.

  • Target machine is configured with the wrong printer driver

  • Magnetic interference between the target machine and printer
