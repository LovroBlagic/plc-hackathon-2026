Error 1861: [Target] [target name] application memory requirements exceed the available space on the target machine.

When downloading the user application to the target machine, the editor checks the available memory space on the target machine.

Solution:

Use one of the following three methods:

  • Reduce the size of the user application by reducing the number of graphics, panels, variables, and scripts.

  • Set Start From Secondary Drive to True.

  • If Start From Secondary Drive is True and the problem continues, use a Secondary Drive with more disk space.
