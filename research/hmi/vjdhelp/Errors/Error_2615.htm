Error 2615: [Trend Graph] [object name] [Variable] System variables may not be used in a Trend Graph.

A system variable has been assigned to the trend graph.

Solution:

  • Although you cannot directly use system variables in a trend graph, you could create a variable that stores the same value. Create an application script that copies the value of the system variable into this other variable. Use the system variable as the Trigger Variable, and set the Trigger Condition to On Data Change. You can then use this variable in the trend graph.
