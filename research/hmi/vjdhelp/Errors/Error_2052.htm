Error 2052: [Target] [target name] There are no panels published to HMI runtime.  Please review your panels' PublishTo settings.

Error 2052: [Target] [target name] There are no panels published to Web Gate.  Please review your panels' PublishTo settings.

Web Gate has been enabled in the target and none of the panels are set up to display on the target machine.

Target machines require at least one panel to be published to HMI Runtime or Web Gate in order to function correctly.

Solution:

  • Select at least one panel to publish to either HMI Runtime, Web Gate, or All. The initial panel is usually a good candidate.
