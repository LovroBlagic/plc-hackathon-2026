Warning 2133: [Target][target name][Allow Ethernet Download & Upload at Run Time] The security risk is elevated as the target machine allows Ethernet download and upload at run time. Disabling this setting is recommended.

In the Target node's Network properties, the Allow Ethernet Download & Upload at Run Time check box is selected. With this setting, the target machine is susceptible to unauthorized and potentially malicious changes.

Solution:

  • Once the user application is complete and the target machine is ready for an operation environment, clear the Allow Ethernet Download & Upload at Run Time check box and transfer the project to the target machine. After restarting the target machine, the following Ethernet operations on the target machine are disabled: download, upload, update run time, and retrieve or send data files.

  • You can still use other methods to update the user application or run-time system. See Sections 25.6.3 Downloading over the USB Port, 25.6.4 Downloading to a CF Card/SD Card Reader or USB Drive, and 25.6.5 Downloading to a Network Folder.

  • To use the network and update the user application or run time, transfer recipes, or get or send data files, you need to re-enable Ethernet download/upload on the target machine itself. Enter the configuration menu, and from the Network panel select the Allow Ethernet Download & Upload check box. After you complete Ethernet operations, clear the Allow Ethernet Download & Upload at Run Time check box and restart the target machine.

  • If you download a project with the Allow Ethernet Download & Upload at Run Time check box cleared, all system provided methods of displaying the configuration menu are disabled. Set up some other method to display the configuration menu, such as drawing a switch set up with the Configuration operation on a secured screen.
