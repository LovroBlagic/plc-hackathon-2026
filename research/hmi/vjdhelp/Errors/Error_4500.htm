Error 4500: [%s] [%s] [%s] Disable Web Gate to install Web Server on the main drive. Or use the secondary or optional drive.

This message displays when you try to install Web Server on the main drive, but the Web Gate setting in the target properties have been set to Enabled.

Solution:

  • If you want to install Web Server on the main drive, change the Web Gate setting in the target properties to disabled. Or, in the target properties, open the Data Locations dialog box and change the Web Server property to install on the secondary or optional drive.
