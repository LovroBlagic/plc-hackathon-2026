Warning 2093: [object type] [object name] [DownloadTo] the selected target machine does not support the CF Volume, data files will be downloaded to the Main Drive.

The target machine setup for the project does not use a Secondary Drive. As a result, Vijeo-Designer will download your files to disk or internal flash memory.

Solution:

  • Open the project in Vijeo-Designer Editor and change the target machine properties to use the Main Drive. If the target machine does not use a Secondary Drive, and files are copied to flash memory, you may experience a performance degradation or lack of disk space.
