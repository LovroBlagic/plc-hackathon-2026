Error 8002: [script type] [script name] [line number] only use "void" as a function return type.

The keyword void is used in the specified script but is either misplaced or used incorrectly.

Solution:

  • Make sure void is not used in a variable declaration as a variable data type.

  • Make sure void is not used as the return value from a function that is set up with a numeric return value.

  • Void can only be used as a function return type.
