Error 2071: [Panel] [panel name] [FunctionKeys] Operations will not run. Target Function Key is set up with system operations that prevent Panel Function Key operations.

Error 2071: [Object type] [object name] [FunctionKeys] Operations will not run. System operations are set up that prevent other Function Key operations.

When setting up operations, system operations such as change panel and go to Configuration will prevent subsequent operations from running. These operations are forced as the last operation in actions, switches, and animation.

In the case of function keys, target operations always run before panel operations. If you set up a system operation in the target function key, operations set up for panel function key cannot run. Similarly, system operations in the When Touch tab of a function key always run before other function key operations in other tabs.

 

Solution:

  • If you add system operations to a target function key, do not add any panel function key operations to that function key.

  • If you want to run the system operation when the function key is touched, move the system operation to the panel function key.

  • If you add system operations to the When Touch tab of a function key, do not add any other function key operations to that function key.
