Error 1000: [component name, dll name, file number or line number] internal error.

Unknown error.

Solution:

  • Save the project and restart Vijeo-Designer.

  • If the above doesn't resolve the error, note the contents of the error message and back up your project. Then, open a project you previously backed up.

  • If the error message continues to appear, uninstall then reinstall the software, and add the backed up project.

If the problem continues, please call customer support.
