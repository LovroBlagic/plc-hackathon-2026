Warning 2033: [object type] [object name] [property name] property is empty in [language name].

The project has multiple languages, but there are objects with text fields that are empty in the defined language.

Solution:

  • Make sure there is text in each language for the defined object.

This is only a warning, so the build is not interrupted. This message will not display again if the error remains and you validate or build the target again. If you clean the target and then validate or build it when the error remains, the warning message will display again.
