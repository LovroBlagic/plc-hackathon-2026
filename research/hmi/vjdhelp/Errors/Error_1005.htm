Error 1005: [filename] cannot open file.

The specified file is either corrupt or in a format that cannot be read.

Solution:

  • Check to see if the file is being used by another application or opened by another user.

  • The file may be read-only. Or, if the file is on the network, check if you have read/write access to that directory.

  • Open the file with the application assigned to that file type. If successful, save the file, and try opening the file again in Vijeo-Designer. If unsuccessful and you have a backup file, continue your work using the backup.
