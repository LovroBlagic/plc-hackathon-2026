Error 2056: [Recipes] [Recipe Controls] [RecipeControlVariable] Recipe Group int selected for Load on startup does not exist.

In the Recipe Control dialog box, you would select Load Recipe on Startup and then specify the recipe group in the drop-down list box. However, if you delete the specified recipe group from Recipes and do not modify the recipe group selection, when you validate the target, the error message displays in the Feedback Zone.

Solution:

  • In the Property Inspector for the Recipes node, click in the Recipe Controls property. In the Recipe Control dialog box, use the drop-down list box to select another Recipe Group.

  • If you delete a recipe group, open the Recipe Control dialog box to check that the selected recipe group is not the one you deleted.
