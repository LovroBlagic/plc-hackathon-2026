Error 2893: [Driver] [SoMachineNetwork Name] routing configuration is not correct for this target.

This message displays when the configuration of the driver is not correct for the current target. The error may occur when there are too many COM ports selected and the target only has one port. Or the driver has an Ethernet routing configuration, but the target does not support Ethernet.

Solution:

  • Check your driver configuration and make sure it is configured correctly for the target you are using.
