28.2 Message List

There are 5 types of messages in the Vijeo-Designer editor and runtime.

  • Editor error messages. Indicates setup problems in the Vijeo Designer project. This type of error, detected during validation, prevents you from building and downloading to the target machine.

  • Editor warning messages. Indicates possible setup problems in the Vijeo Designer project. Warnings tell the designer of abnormal settings which may or may not be mistakes. Even though your application may be full of warnings, detected during validation, they will not prevent you from building and downloading to the target machine.

  • Code Generation error messages. Indicates a setup problem in the Vijeo Designer project. A special type of error condition, code generation errors are detected when building the user application. Code generation errors result from a combination of set ups that can only be detected during build.
    For a list of code generation messages, see Section 28.2.3.1, Code Generation Error Message.

  • Compilation error messages. Indicates a problem with scripts in the Vijeo Designer project. Compilation errors are detected when compiling the user application.
    For a list of compilation error messages, see Section 28.2.3.2, Compilation Error Messages.

  • Runtime event messages. Events that occur at runtime can indicate errors, warnings, or changes in state.
    For a list of run-time event messages, see Section 28.2.4.1, Run-Time Event Messages.
