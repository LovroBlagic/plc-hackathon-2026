Error 1002: Compiler out of memory during build.

System memory is low so the build operation is not possible.

Solution:

  • Check to see if your system matches the system requirements.

  • Close all window applications then try running build again.

  • Check to see how much free disk space you have. You may experience this problem if free disk space is less than 10MB or if you haven't defragmented your hard drive recently.

  • If none of the above remedies will correct the problem, reboot your PC, start up the application and build again.

  • If all the above remedies are not effective, then the project may be damaged. Save your panels and scripts to the Toolchest. If you have a backup project, try using the backup and move the panels and scripts from the Toolchest to your project. If you don't have a backup, create a new project and move the panels and scripts from the Toolchest.
