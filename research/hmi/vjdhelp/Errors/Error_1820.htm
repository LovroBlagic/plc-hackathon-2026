Error 1820: [Target] [target name] communication error.

This message appears when the following conditions occur:

  • When using Ethernet download or installing Vijeo-Designer Runtime.

  • After download has begun and the communication link is broken.

Solution:

  • Restart the download or installation process.

  • If download is not possible anymore, the target machine's runtime system may be corrupted. In such cases, re-install Vijeo-Designer Runtime.

  • If Vijeo-Designer Runtime is corrupted, run Recovering the System on a Target Machine.
