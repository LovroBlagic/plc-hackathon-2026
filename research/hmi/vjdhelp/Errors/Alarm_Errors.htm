Alarm Errors

This section lists the error variable codes for alarm printing and alarm saving, the error name, the description of the error, and how to fix the error if possible. The Error code is stored in the Error Variable and the Error Name (except for Reserved) is written to the _LastErrorString system variable. For more information on system variables, see Section 6.7, System Variables.
