Error 2086: [Alarms] The total number of history and log alarms exceeds [max].

The total number of log and history alarms that you can set up in all the alarm groups is 80,000.

This limit is not checked until you validate or build the application.

Solution:

  • In the properties for each alarm group, confirm the values for the Num Of History Alarms and Num Of Log Alarms. The total of these values in all the alarm groups cannot exceed 80,000.
