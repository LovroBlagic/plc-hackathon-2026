Error 2502: [object type] [object name] [property] Image file must be a valid file format.

Error 2502: [Target] [target name] [Web server] [logo / default frame image] Image file must be a valid format.

An invalid image file has been associated with the image object.

Solution:

  • Confirm the image file selected to display as an image is actually a GIF, BMP, PNG, ICO or JPG, and not some other graphics format.
