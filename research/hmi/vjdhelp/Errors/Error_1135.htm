Error 1135: [Target] [target name] [Key Label Color] cannot be the same as [color property name: Character Key Back Color or Control Key Back Color].

In the System Keypad properties, the Key Label Color is the same as the Character Key Back Color or Control Key Back Color.

Solution:

  • Change the colors so that they are not identical.

Error 1135: [Target] [target name] [Text Display Color] cannot be the same as [color property name: Display Area Back Color or Invalid Color].

In the System Keypad properties, the Text Display Color is the same as the Display Area Back Color or the Invalid Color (for invalid values).

Solution:

  • Change the colors so that they are not identical.
