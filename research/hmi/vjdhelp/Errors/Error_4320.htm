Error 4320: [Variable] [Variable Name] [Parameter 1, 2, 3] requires a variable with a correct data type as specified in the [Reference String] property and cannot have the [Reference] property set to Enabled.

The variable cannot be used here because the data type is incorrect and the Reference property for that variable has been set to Enabled.

Solution:

  • Select a variable that has the correct data type as specified in the Reference String property and the Reference property set to Disabled.
