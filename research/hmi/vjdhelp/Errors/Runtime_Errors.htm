The security group that you are adding the user to uses fingerprints for authentication, but no fingerprints were captured by the biometric switch. Add the user again, and make sure the user's fingerprints are captured on the biometric switch.

Access to the variable was denied by the server.

Return to the editor, and for each variable, check the Sharing property setting in the Variable Properties. If the Sharing property is set to None, the variable cannot be viewed or edited by other targets on the network; if set to Read-Only, the variable can only be viewed by other targets on the network; if set to Read/Write, the variable can be viewed and edited by other targets on the network.

The target machine has detected one of the backlight bulbs is burned out and requires replacement. As a result, touch operations may be locked. (This setting is configurable.) Solution: - As instructed by the event message, first refer to your hardware manual to see if there are instructions on how to replace the backlight bulb. Please check following. Communication - communication settings in bar code scanner don't match bar code driver set up in the editor. Especially pay attention to end delimiter character. Cable - Connections loose, cable is damaged, or magnetic interference. Hardware - Bar Code Scanner is damaged.

Bar code input is not ASCII. Try scanning again. If problem continues, check the communication settings.

The bar code driver assumes scanned data is ASCII byte code. The data being scanned is not recognized as ASCII. Solution: - Check to make sure the bar code reader is configured to read ASCII code.
- Check the connection between the bar code reader and the target machine.
- Check for any magnetic interference that could alter the signals in the line.
- Make sure the bar code reader is not damaged.
- As a last resort, you may have to restart the runtime or build and download the application again.

Battery level is low.

On HMIGTO2310/2315, HMIGTO3510, HMIGTO4310, HMIGTO5310/5315, and HMIGTO6310/6315 target machines that only use a primary replaceable battery, this run-time event message displays when the battery voltage has fallen to or below the minimum of 2.76 V. For information on how to replace the primary battery, see the HMIGTO User Manual.

On HMIGK2310 and HMIGK5310 target machines that only use a primary replaceable battery, this run-time event message displays when the battery voltage has fallen to or below the minimum of 2.76 V. For information on how to replace the primary battery, see the HMIGK User Manual.

On HMIGTO2300, HMIGTO1300, and HMIGTO1310 target machines that only use a secondary rechargeable battery, this run-time event message displays when low voltage is detected. The secondary battery requires 24 hours to charge in order to perform a backup and 120 hours to charge for the battery to be fully charged.

On all HMIGTO target machines, if the rechargeable battery is fully charged, this message indicates the primary battery needs replacement. For more information, see the HMIGTO User Manual.

On all HMIGK target machines, if the rechargeable battery is fully charged, this message indicates the primary battery needs replacement. For more information, see the HMIGK User Manual.

For other types of target machines, this message indicates internal battery level is low.
Solution: Recharge the internal battery (4 hours or more) to restore to good working condition. Four hours of recharging will provide approximately 10 days of backup time. If the target machine has not been in use for an extended amount of time (one year or longer), recharge the battery for a minimum of 24 hours.
Note: The error message will not automatically disappear after recharging. After recharging the battery, turn the target machine off and then on again to restore.
