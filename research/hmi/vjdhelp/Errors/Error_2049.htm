Error 2049: When exporting a CSV/TXT file, you cannot select a field delimiter that is the same as a decimal symbol used in the CSV/TXT file.

This message displays when you are exporting a .csv or .txt, for example, on a French operating system (OS). Since the comma is used as a decimal symbol in the French OS, you cannot select a comma field delimiter.

Solution:

  • Select a different field delimiter.
