Error 8061: [object type] [object name] [property name] invalid method parameter before position [int].

Scripting methods are being used in expressions; however, an invalid method parameter has been detected before the defined character position.

For example, there may be too many parameters, not enough parameters, or the parameter data types may not match.

Solution:

  • See Section 18.9.1, Vijeo-Designer Methods, for the accepted parameters in each method.
