Error 2741: [object type] [object name] [animation type] not supported by any objects.

The defined animation was added to one or more objects, but is now not supported by those objects. This error is most common when working with grouped objects, where you may have changed properties in the group or deleted objects in the group so that the animation cannot be supported anymore.

For information about the animations that can be added to grouped objects, see Section 8.1.2 Animation Supported by Objects.

Solution:

  • Find the defined object, then either remove the animation or add a graphic to the group that supports the animation.
