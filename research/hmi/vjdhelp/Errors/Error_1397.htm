Error 1397: [Variable] [variable array element] [device address] is a %d bit register, which cannot be supported by the array. Change the settings in the array parent node or select a different device address.

The specified variable address is longer than allowed by the array.

This error occurs usually when a 32 bit register is selected and the array is set up with 16 bit data length. Included as 32 bit registers are driver statistics (see Section 5.3, Collecting Driver Statistics.)

Solution:

  • Make sure the device address selected in array elements match the array parent. You have the option of changing the settings in the array parent node or selecting a different device address in the array element.
