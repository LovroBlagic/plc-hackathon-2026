Error 1109: [object type] [object name] [property name] text too long. Maximum length [int].

Error 1109: [Target] [target name] [Web server] [page title] text is empty. Minimum length [int].

The specified property is either empty or uses too many characters.

Solution:

  • Enter the minimum number of characters as specified in the error message so the text field is not empty.

— OR —

  • Reduce the number of characters so its length is less than that specified in the error message.
