Error 2115: A User Name is required. Please enter a valid User Name.

Error 2115: A Password is required. Please enter a valid Password.

If you set the Download User property to Enabled in the Project properties, but you do not set the User Name and Password, when you validate the project, the error message displays.

Solution:

  • In the Project properties, if the Download User property is set to Enabled, enter the user name and password.
