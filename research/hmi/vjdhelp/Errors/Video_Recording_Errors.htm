Video Recording Errors

This section lists the error variable codes for video recording operation errors, the Error name, the description of the error, and how to fix the error if possible. The Error code is stored in the Error Variable, and the Error Name (except for Reserved) is written to the _LastErrorString system variable. The Error Variable is reset before every operation, so that it always shows the result of the last operation. For more information on system variables, see Section 6.7, System Variables.
