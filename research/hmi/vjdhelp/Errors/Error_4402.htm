Error 4402: [recipe] [recipe group] [ingredient] Only a Numeric Display part can use the UDINT variable.

The UDINT variable cannot be used for recipe ingredients.

Solution:

  • Choose a data type that is supported for an ingredient, such as INT, DINT, UINT, Integer, REAL, BOOL, STRING, Block Integer, Block INT, Block DINT, Block UINT, or block REAL.
