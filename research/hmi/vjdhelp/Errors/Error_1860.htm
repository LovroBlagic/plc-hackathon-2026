Error 1860: [Target] [target name] model does not match the connected target machine.

When downloading the user application to the target machine, the Target Type and Model set up in the editor must match the destination hardware.

Solution:

  1. In the Navigator window's Projects tab, right-click the Target node and click Properties.

  2. In the Property Inspector, review the Target Type and Model properties and make sure they match the target machine.

  3. If the problem continues, check the Download property and make sure the target machine is connected as defined.
