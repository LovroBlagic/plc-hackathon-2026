Warning 2894: [High speed serial driver] has been selected in more than one driver or peripheral.

There is a conflict with the port. More than one driver is using the same port in the same project.

Solution:

  • Reduce the number of drivers in your project to only one, or

  • Change to a driver with the proper communication method, or

 

  • In the case of using the Script Driver and the Printer on a single COM port, only a warning is issued. This combination is allowed at run time, only if the two drivers are not used simultaneously.
