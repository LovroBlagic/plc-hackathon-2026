Error 1301: [Target] [target name] too many variables. Variable limit is [8000 or 12000].

The target has too many variables.

Solution:

  • Reduce the number of variables in the target to less than the specified limit.

  • Included in the variable count are variables, variable array elements and the array placeholder, and structure variable elements and the structure placeholder.

  • System variables are not included in the variable count.
