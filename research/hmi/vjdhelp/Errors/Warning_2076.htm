Warning 2076: [object type] [object name] [Function Keys] The USB Keyboard is disabled. There is no way to trigger the defined Function Keys.

Defined Function Keys can only be triggered by pressing the corresponding keys on a USB Keyboard. If the USB Keyboard is disabled, the defined Function Keys cannot be triggered.

Solution:

  • Enable the USB Keyboard in the Target properties, Input Mode setting.

  • Or remove the defined Function Keys.

This is only a warning, so the build is not interrupted. The Function Keys will be defined but not used.
