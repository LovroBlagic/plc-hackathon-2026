Error 1303: [Target] [target name] [Input Manager] To use this target to manage Input Synchronization, Data Sharing must be enabled.

The multiple-target project is set up with input synchronization, which restricts inputs from only one target at a time. One of the targets in the project must be set up as the manager for input synchronization, and Data Sharing must be enabled for that target.

Solution:

  • View the properties of the target you've selected as the input manager, and set Data Sharing = Enabled.

  • Or, you can disable input synchronization for all the targets.
