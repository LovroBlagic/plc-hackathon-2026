Error 1803: [Target][target name][user application] "Data Files/Forms" and "Recipes" must download to the same drive as "User Application" when downloading to the File System.

This message displays when the target machine's Download is set to File System and then choose different destination drives for Data Files/Forms/Recipes and User Application.

Solution:

  • Choose the same destination drive for downloading Data Files/Forms/Recipes and the User Application.
