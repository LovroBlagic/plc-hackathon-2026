5.6.2.8 Terminal advanced state

This function is a 16 bit word used to store the current security setting for the target. When the value of the terminal advanced state word is greater than zero, it indicates a valid user has logged onto the target.

The current security level value of the target is stored in the terminal advanced state word's 3 least significant bits. The table below describes the different values of the terminal advanced state word based on the target's current security setting.

 

Login Activity

Terminal Advanced State Word Value

Run time starts up with an unsecured panel

0

User logs out of the target

0

User is logged out by inactivity timeout

0

User is logged in

> 0

 

  • The Dialog Table's terminal advanced state word only supports a maximum of 7 security groups. If your project requires more than 7 security groups, use the system variable _UserLevel to monitor the target's current security setting. For more information on system variables, see Section 6.7, System Variables.
