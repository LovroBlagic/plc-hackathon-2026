5.2.5 Changing Communication Settings at Run Time

After setting up the communication settings for the equipment in Vijeo-Designer, and downloading the user application to the target machines, you might upgrade the network or replace existing hardware. This action may require reconfiguration of communication settings with the equipment.

Instead of changing the settings in Vijeo-Designer and downloading the application again, you can change the settings directly on the target machine.

You can configure communication settings at run time for the following drivers.

  1. On the target machine, display the run time configuration menu. (See Section 26.2.)

  2. Touch the Offline tab, then the I/O Manager button.

  1. Touch the Driver Config button to configure the Driver settings. For the list of configurable settings for each driver, see Section 26.3.6, Changing I/O Manager Communication Settings.

    1. In the Driver Config menu, select the driver to display its communication settings.

    2. Make your changes.

    3. Touch OK to confirm the change.

  1. Touch the Equipment Config button to configure the Equipment settings. For the list of configurable settings for each equipment, see Section 26.3.6, Changing I/O Manager Communication Settings.

    1. In the Equipment Config menu, select the equipment to display its communication settings.

    2. Make your changes.

    3. Touch OK to confirm the change.

  • Changing communication settings is possible only while the target machine is offline.

  • Only the specified communication settings are configurable. To change other communication parameters, make the change in Vijeo-Designer.
