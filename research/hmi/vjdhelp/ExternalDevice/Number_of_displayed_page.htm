5.6.2.3 Number of displayed page

This function is a 16 bit word that stores the panel ID of the panel that is currently displayed on the target machine. The value is defined by the target machine system variable _CurPanelID and can range can be from 1 to 8999. For more information on system variables, see Section 6.7, System Variables.

  • When the Configuration menu or the Event Viewer is displayed on the HMI, this word is set to 0xFFFF.
