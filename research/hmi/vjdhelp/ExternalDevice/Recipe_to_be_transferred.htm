5.6.2.12 Recipe to be transferred

This function is a block of two 16 bit words that stores the recipe ID of the recipe to be transferred to the PLC. The value range for each word is 1 to 65000. Word 1 stores the recipe group ID while Word 2 stores the recipe ID.

Once the recipe transfer initiates, the following occurs:

  • The target machine writes the value 65535 to each 16 bit word.

  • The Report function Recipe transfer in progress bit is set to 0.

  • The Report function Recipe transfer error bit is set to 0.

If the recipe cannot be transferred, the following occurs:

  • The target machine writes the value 65535 to each 16 bit word.

  • The Report function Recipe transfer in progress bit is set to 0.

  • The Report function Recipe transfer error bit is set to 1.

For more information on the recipe IDs, see Section 17.3.3, Creating a Recipe Group. For more information on the Report function, see Section, 5.6.2.5, Report.

  • This function only reads the values of the default recipe control variable. Values of other recipe control variables are not read by this function.
