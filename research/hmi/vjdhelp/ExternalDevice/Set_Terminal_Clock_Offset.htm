5.6.2.28 Set Terminal Clock Offset

This function is a 16 bit word that allows the PLC clock to adjust to a DST change and synchronize the time change with a target machine that does not have battery backup. With the time synchronized after a DST change, trend graphs and other data logging functions can continue on the target machine using the current time.

To set the value to the terminal clock offset, and continue drawing the trend graph and logging data:

  1. Create an external Integer variable.

  2. Create an action to synchronize the value of the terminal clock offset by setting the initial value. For more information, see Section 9.4 Creating Actions. Define the action settings as follows:

    • Trigger Type -  Event.

    • Publish to - HMI Runtime.

    • Trigger Event - On Startup.

    • Operation - Word Set.

    • Destination: _TimeZoneOffset

  3. In IO Manager, click the Equipment for the Driver to display the Equipment properties, and click Dialog Table to open the Dialog Table Settings window.

  4. Enable the Dialog Table, and add the following functions:

    • Communication Control

    • Set Terminal Clock

    • Set Terminal Clock Offset

  1. Make sure the Start Address for Set Terminal Clock Offset corresponds to the Device Address defined for the external Integer variable created in step 1.

  2. Create another action to continue drawing trend graphs and logging data. Define the action settings as follows:

    • Trigger Type - Conditional

    • Publish to - HMI Runtime

    • Trigger Condition - On Data Change

    • Trigger Variable - the external Integer variable you created in step 1.

    • Operation - Script. Click New Script, and enter:
      Sys.flushAllDataLogging();
      Sys.clearAllDataLoggingInMemory();

  1. Click the Target node in the Navigator.

  2. In the Target pane, select Options, and disable the Time Adjustment (DST) check box so the time on the target machine's internal clock can be adjusted by the PLC value.
