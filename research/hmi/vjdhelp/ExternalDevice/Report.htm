5.6.2.5 Report

This function is a 16 bit word that reports on the Dialog Table processes.

  • By using the Report function in the Dialog Table, you can set up trigger actions to execute you press the Enter or ESC key on a popup keypad. To set up a trigger action, create an external variable, map the external variable to the Report function, and set up a trigger action to run when the Report function's value indicates an Enter or Esc key is pressed. For more information on trigger actions, see Section 16.3.4.1, Trigger Actions.

The table below describes each bit.

Bit Number

Description

Note

0

Confidential mode

Set to 1 when you log on to the target machine. Resets to 0 when you log off.

1

Reserved

Set to 1 if a valid user application is loaded in the target machine.

2

ENTER on entry

Set to 1 when the ENTER key is pressed in a part popup keypad. Resets to 0 at the next processing cycle.

3

ESC on entry

Set to 1 when the ESC key is pressed in a part popup keypad. Resets at the next processing cycle.

4

End of retry on TIME-OUT (1 min)

Set to 0 (unused)

5

Printing in progress

Set to 1 while printing. Resets to 0 when the printing is finished.

This feature is only for used alarm printing.

6

Printing fault

Set to 1 if a printing error occurs. Reset to 0 at the next processing cycle.

This feature is only used for alarm printing.

7

Printing stopped

Set to 0 (unused)

8

Recipe transfer in progress

Set to 1 when a recipe transfer is in progress. Resets to 0 once the transfer is complete.

9

Recipe transfer error

Set to 1 when a recipe transfer error occurs. Reset to 0 at the next processing cycle.

10

Terminal in stand-by

Set to 1 if the backlight is off. Set to 0 if the backlight is on.
