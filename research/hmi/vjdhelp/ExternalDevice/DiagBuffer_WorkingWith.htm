5.5 Working with Alarms on the Equipment (Diagnostic Buffer)

The Diagnostic Buffer stores alarms that are centrally located in the PLC. You can use the diagnostic buffer to display, on the target machine, alarms generated and stored on the PLC.

To display diagnostic buffer alarms on the target machine, you need to set up:

  1. Equipment (device driver) to communicate with the PLC

  2. A diagnostic alarm group that is associated with the equipment

  3. An alarm summary or alarm banner to display diagnostic alarms.

Reasons for using alarms in the diagnostic buffer

  • Precise date and time stamps of alarms
    Because the alarm is generated by the PLC, which is closest to the sensors and other equipment, the diagnostic buffer stores the exact date and time of an alarm, in addition to the exact sequence in which the alarms occur.

  • Multiple target machines display the same alarms
    Multiple target machines can monitor and interact with the same alarms in the PLC's diagnostic buffer. A target machine can acknowledge alarms in the diagnostic buffer, and the acknowledgement is signaled to other viewers connected to the PLC when each viewer next polls the PLC's diagnostic buffer. Date/time stamps are exactly the same from one viewer (target machine) to another.

Diagnostic buffer alarms

The diagnostic buffer stores a maximum 1000 alarms, as defined in the PLC configuration software. When the diagnostic buffer reaches the maximum limit, the oldest alarms are dropped to make room for new alarms.

There are three types of alarms stored in the diagnostic buffer:

  • Derived Function Block (DFB)

  • System

  • Sequential Function Chart (SFC)/Grafcet

  • PL7s do not transmit alarm acknowledgement (ACK) time stamps. If an alarm is acknowledged on an HMI, the alarm’s ACK time stamp will not be transmitted to other HMIs connected to the PL7. If the HMI with the time stamp is disconnected, it reloads the alarms from the PL7 once reconnected but loses the alarm’s ACK time stamp.

  • If the device on which the alarm is acknowledged loses its connection to the PLC, when it reloads the Diagnostic Buffer alarms from the PLC, the ACK date and time information is lost.

  • The maximum number of connections to a PLC's diagnostic buffer will vary depending on the PLC type.

  • For instructions on setting up diagnostic buffer alarms in Vijeo-Designer, see Section 16.3.2.1, Displaying Diagnostic Alarms.

  • The diagnostic buffer deletes alarms that have been acknowledged and returned to normal.
