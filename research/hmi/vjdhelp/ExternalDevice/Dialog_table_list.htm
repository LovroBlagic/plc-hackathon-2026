5.6.2 Dialog Table Functions

Supported Functions

The following table describes the functions supported between Vijeo-Designer and XBTL1000. Where indicated, other features can be used instead of using the Dialog Table. We recommend using these alternative features instead of the functionality in the Dialog Table.

  • Not all target machines support all functions. Functions that are not supported on a specific target machine can still be selected in the dialog table, but the function may be ignored at run time. See Appendix 5.2.10, Dialog Table Support, for targets that support each function.

  • Some functions cannot be used in more than one Dialog Table. The table below lists the functions that support being used in multiple Dialog Tables.

  • Only one Dialog Table function can be defined at a time when using the Device Simulator. The Device Simulator will display an error when more than one function is defined. To test Dialog Table functions in Device Simulation, each function must be tested individually by removing all functions until only one is defined.

Unsupported Functions

Unsupported functions are listed in the following table.

  • Vijeo-Designer lists all XBTL1000 Dialog Table functions, even the unsupported XBTL1000 Dialog Table functions. Unsupported functions are shown in red in the Dialog Table and become available when the Include XBTL featured functions check box is selected. Vijeo Designer allows you to add these unsupported functions to your dialog table so you can match the HMI project's dialog table to the PLC's dialog table.

For information on the functions not supported by Vijeo-Designer, see the XBTL1000 help system.
