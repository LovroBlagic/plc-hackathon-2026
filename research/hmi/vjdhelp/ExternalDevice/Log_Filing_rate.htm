5.6.2.6 Log Filling rate

This function is a 16 bit word that stores the current usage of a log alarm in an alarm group. A value from zero to 100 is entered in the LSB of this word. The percentage = (number of log alarms in one alarm group) / (the maximum number of log alarms for the same alarm group). Zero indicates that the log alarm is empty while 100 indicates that the log alarm is full. For information on selecting the alarm group, see Section 5.6.1, Dialog Table Settings.

If an alarm category containing a number of alarm groups is selected as the Alarm Group, this word stores the value for the alarm group with the highest value. For example, if AlarmCategory1 has two alarm groups, one at 10% and the other at 50%, the alarm group at 50% is stored.

  • Diagnostic alarm groups do not affect the percentage calculations. For more information on diagnostic alarm groups, see Section 16.3.2, Diagnostic Alarm Groups.
