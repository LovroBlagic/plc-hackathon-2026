5.6 Working with the Dialog Table

The Dialog Table provides a simple way for running common functions and communicating data between the target machine (HMI) and the PLC. These operations are made possible by the Dialog Table synchronizing a block of data on the target machine with a block of data on the PLC. When the values change in one of the blocks, the Dialog Table automatically updates the other block to have the same values. The functions that correspond to the updated values are then run by the Dialog Table. Data updates on the Dialog Table occur during a processing cycle that runs on a configurable schedule called the cycle time.

The Dialog Table settings are in the Property Inspector for the PLC equipment. For a list of the Dialog Table's supported functions, see Section 5.6.2, Dialog Table Functions.

  • Only one Dialog Table is available for each device driver. Dialog Tables are only available for the device drivers that support block variables. For information on adding a device driver to your project, see Section 5.2.1, Adding a Device Driver.

  • The Dialog Table has been designed exclusively for compatibility between XBTL1000 and Vijeo-Designer. New software features have been implemented for other models to replace those used in the Dialog Table. For more information, see Section 5.6.2, Dialog Table Functions.

  • Vijeo-Designer lists all XBTL1000 Dialog Table functions, even the unsupported XBTL1000 Dialog Table functions. Unsupported functions are shown in red in the Dialog Table and become available when the Include XBTL featured functions check box is selected. Vijeo Designer allows you to add these unsupported functions to your dialog table so you can match the HMI project's dialog table to the PLC's dialog table. For a list of unsupported function see Section 5.6.2, Dialog Table Functions: Unsupported Functions.

  • When upgrading from XBTL1000 to Vijeo-Designer, make sure the Vijeo-Designer's Dialog Table configurations match the PLC's Dialog Table configurations. Both Dialog Tables must have the same number of functions. The start address for the Dialog Tables must also be correct. If the two Dialog Table configurations do not match exactly, communication errors will occur. For information on defining the Dialog Table start address, see Section 5.6.5, Setting the Dialog Table Start Address.

  • Note that when configuring the Zelio/Millenium driver, you must follow the requirements as outlined in Section 5.6.7, Working with the Zelio/Millenium Driver.

  • To use function keys with the Dialog Table, you must first add function keys to the project in the Target Function Keys properties, and then set Control Mode to Dialog Table. For more information on Target Function Keys properties, see Section 4.5.1, Target Properties.
