5.6.1 Dialog Table Settings

Dialog table settings can be accessed from the Driver Equipment node.

The following table describes the Dialog Table Settings.

Property

Description

Enable Dialog Table

Select this check box to use the Dialog Table feature.

Start Address

Select the Start Address to define where the address for the Dialog Table begins in the PLC.

If you are using the Zelio/Millenium driver, this property is grayed out.For more information on configuring the Dialog Table for the Zelio/Millenium driver, see Section 5.6.7, Working with the Zelio/Millenium Driver.

Cycle Time

Define the time when the processing cycle occurs. The Cycle Time is defined in seconds, with a range from 0.1 to 65.5 seconds.

Depending on the operation and communication load at runtime, the Dialog Table processing cycle may not repeat exactly as defined in the Cycle Time.

  • Under heavy CPU loads, the processing cycle may become delayed.

Function

View, add and delete functions for the Dialog Table. For more information on the available functions and newer alternatives, see Section 5.6.2, Dialog Table Functions.

Size

Displays the total number of words used in the Dialog Table.

Authorization Word

Displays the size of the Dialog Table in hexadecimal. The value A50 is set at the beginning of the hexadecimal and Dialog Table total number of words used is set at the end of the hexadecimal. The value shown to the left of the hexadecimal number is the hexadecimal's numeric value.

Filling Rate

Alarm Group

Select the alarm group you want to use for the Filling Rate function. This property is available when the Log filling rate or one of the Advanced functions is used.

Alarm Table Size

Define the number of words used for the Alarm Table function. You can specify 1 to 32 words. The Alarm Table Size property is only available when the Alarm Table function is enabled in the Dialog Table. For more information on this function, see Section 5.6.2, Dialog Table Functions: Unsupported Functions.

Time Format

PLC

Specify the PLC time format as BCD or HEX.

This is available when the Set PLC clock function is added to the Dialog Table and is highlighted in the Function list. For more information on the time formats used by the PLC and the HMI, see Section 9.4.4, Example of Creating an Action.

Terminal (HMI)

Specify the target machine time format as BCD or HEX. This is available when the Set terminal clock function is added to the Dialog Table and is highlighted in the Function list.

Free Format Print Table Size

Define the number of words used for the Free Format Print Table function. You can specify 1 to 40 words. The Free Format Print Table Size property is only available when the Free Format Print function is enabled in the Dialog Table. For more information on this function, see Section 5.6.2, Dialog Table Functions: Unsupported Functions.
