5.4.1 Modbus Plus

You can use the following driver properties to control how global data is handled by the Modbus Plus Local Node. For information on global data, see the Modbus Plus Driver manual or Modbus Plus specifications.

 

Modbus Plus Driver Properties

Device Address

Name

Description

@prop:0

Enable Global Data

When Global Data Transmission on a Modbus Plus Local Node is set to Manually trigger, use this driver property to start global data transmission.

Write 1 to @prop:0 to turn global data transmission ON.

Write 0 to @prop:0 to turn global data transmission OFF.

  • If you disable global data transmission, global data values continue to be updated locally. When global data is enabled again, all the global data values are transmitted at once.

  • If one of the equipment expects to receive global data and doesn't receive it, or receives only a portion, then it will store zero to that register.

@prop:1

Update Global Data

Updates multiple global data values in one transmission.

  1. Write 1 to @prop:1 to signal the beginning of global data updates.

  2. You can now write values to the global data device addresses.

  3. At the end of the global data update, write 0 to @prop:1, which updates the global data.

Without this feature, each change to a global data word results in a separate write operation and could cause inconsistencies between global data values for one or more token rotations.

Use Update Global Data to make sure there are no inconsistencies in the global data.

  • If you define a Global Data Word Count greater than the number of global data device addresses that are mapped to variables, the value of the extra global data words will be zero.

  • The Global Data Word Count is 0 if you write a value less than 0, 32 if you write a value greater than 32.

  • To reference a global device address, set up an external variable named LocalNode_Global##. In the Device Address property, define the global address as global##, making sure the numbers match the numbers defined in the variable name.
