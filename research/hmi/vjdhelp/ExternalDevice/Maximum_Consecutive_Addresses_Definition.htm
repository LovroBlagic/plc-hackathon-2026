Maximum Consecutive Addresses

The maximum number of registers that can fit into a single request.

Maximum Consecutive Addresses is a term used in the protocol manuals. Maximum consecutive addresses helps define how requests are separated into different packets to maximize the communication efficiency between the target machine (HMI) and equipment.

Maximum Consecutive Addresses is used in combination with Gap Span.

Example

Driver has a Gap Span of 3 and Maximum Consecutive Address of 7, and uses the following registers:

  • If you are requesting %MW0 and %MW4, the result is a single request with a gap of 3 and 5 consecutive addresses.

  • If you are requesting %MW0~%MW2, and %MW4~%MW9, the result is two requests because the total range of registers is greater than 7, the maximum number of consecutive addresses allowed.
