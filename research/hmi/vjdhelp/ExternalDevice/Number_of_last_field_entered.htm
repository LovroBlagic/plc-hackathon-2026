5.6.2.4 Number of last field entered

This function is a 16 bit word that stores the Field ID of a part that was updated by its popup keypad. The part’s Field ID is stored by this function once the part’s popup keypad Enter button is pressed. If the part’s Field ID is 0, the Field ID will be ignored and not stored by this function. For more information on Field IDs, see Section 12.2.2.4, Input Mode Tab.
