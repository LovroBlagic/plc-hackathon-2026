5.2.2 Configuring Communication Settings

After adding a driver to your project, configure the communication settings. There are two parts to the communication settings: 1. Driver and 2. Equipment.

  1. Right-click the Driver node, and click Configuration.

  1. Define the communication settings in the Driver Configuration dialog box. Depending on the selected driver, different fields appear in this dialog box.
    Refer to Appendix 2, Device Driver Manuals for information about the properties of your particular driver.

  • Vijeo-Designer does not support the setting of multiple drivers to the same COM port. Set each driver to a different COM port.

  1. Click OK.

  2. Right-click the Equipment node and click Configuration.

  • Some device drivers have configuration settings in the Driver node only, or the Equipment node only. Refer to Appendix 2, Device Driver Manuals for information about the communication settings for your particular driver.

  1. Define the communication settings in the Equipment Configuration dialog box.

Different set up fields are in the Equipment Configuration dialog box, depending on the selected driver and equipment. Refer to Appendix 2, Device Driver Manuals for information about the properties of your particular driver/equipment.

The following is the Equipment Configuration dialog box for:

  • Manufacturer: Schneider Electric

  • Driver: Modbus (RTU)

  • Equipment: Modbus Equipment

  • After configuring the communication settings in Vijeo-Designer, you must also configure the communication settings on the equipment itself.
    For information about configuring the equipment, refer to Appendix 2, Device Driver Manuals.
