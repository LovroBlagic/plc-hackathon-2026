5.2.4 Setting Up Character Codes

You can set up character codes in the driver's String Encoding property. Select ASCII, Unicode, or ANSI.

The character code selected in the String Encoding property is used when writing data from the keypad to the equipment, and when displaying data from device addresses.

 

Code

Properties

ASCII

All text data communicated between equipment and a target machine is read/written as one-byte ASCII codes.

In data displays you can generally read and write character codes 00 to 7F. Depending on the font you use, you can also read and write character codes 80 to FF.

For a list of the ASCII characters used at run time, see Appendix 6, ASCII Table.

Unicode

Text data communicated between equipment and a target machine is read/written as 2-byte Unicode.

ANSI

ANSI uses an extended version of the ASCII code table. When ANSI is enabled, all text data communicated between the equipment and the target machine is read/written as one-byte ASCII codes.

For a list of the ANSI characters, see Appendix 6, ASCII Table.
