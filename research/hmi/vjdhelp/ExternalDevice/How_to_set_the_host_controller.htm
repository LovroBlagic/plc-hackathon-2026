5.2 Setting Up Your Equipment

To set up communications between the target machine and the equipment, you need to: add and configure the driver in Vijeo-Designer, match communication settings in Vijeo-Designer with the equipment, and download the user application to the target machine.

The table below outlines the steps to set up equipment. Steps 1 to 4 are discussed in this chapter. Steps 5 to 9 are discussed in the chapters that are referenced beside the steps.

Steps

Reference

1. In the Navigator window's Project tab, add a new Driver.

 

2. In the New Driver dialog box, select the Manufacturer, Driver, and Equipment.

 

3. Set up the communication settings in the Driver Configuration dialog box. Specify settings such as the Transmission Speed and Data Length.

 

4. Identify the equipment in the Equipment Configuration dialog box.

 

5. Create a variable, assign it to the Scan Group associated with the driver created in step 2, and define the device address for the variable.

See Section 6.3.1, Creating Device Addresses.

6. Use the variable created in Step 5 in animation, parts, and other functions.

 

7. Connect a cable between the target machine and equipment. Also make sure the settings in Vijeo-Designer match those on the equipment.

For more information, see Appendix 2, Device Driver Manuals.

8. Download the user application to the target machine, then start the runtime.

 

See Chapter 25, Downloading and Checking Projects at Runtime.
