5.6.2.9 Number of recipe transferred

This function is a block of two 16 bit words that store the recipe group ID and the recipe ID of the last successfully transferred recipe. These values are written after the recipe group is successfully transferred. Word 1 stores the recipe group ID and Word 2 stores the recipe ID. For more information on the recipe IDs, see Section 17.3.3, Creating a Recipe Group.

  • This function only reads the values of the default recipe control variable. Values of other recipe control variables are not read by this function.
