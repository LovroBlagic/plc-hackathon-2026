5.6.5 Setting the Dialog Table Start Address

The start address is the address where the Dialog Table begins on the PLC.

  • The Start Address that you use for the Dialog Table must have read/write permissions. Defining a Start Address with read-only permissions will cause the dialog table functions that write to the PLC to fail.

  1. In the Dialog Table Settings, click the Start Address ellipsis.

  2. In the Device Address dialog box, define the Start Address for the PLC Dialog Table. See your device driver manual for information on configuring an address.
