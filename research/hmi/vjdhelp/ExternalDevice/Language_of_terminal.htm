5.6.2.16 Language of terminal

This function is a 16 bit word that stores the user application language ID for the target machine. The values for this word are defined as follows:

  • 0 - No change

  • 1 to N - User application language number defined by the application.

For more information on the user application language ID, see Section 20.2, Switching Languages.

  • The Dialog Table user application language ID  takes priority over the user application language ID in the application. To allow the user application language ID to be set by the application, the PLC should write 0x0000 to this word.
