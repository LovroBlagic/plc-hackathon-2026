5.8.1 Driver Access Errors for Direct I/O, System Device, Constant Device

Some drivers may experience errors during run time because the equipment does not support access to these IEC types: Direct I/O (%I, %IW, %Q, %QW), System Devices (%S, %SW), and Constant Devices (%KW). The tables below list the equipment that does not support access to the IEC types.

  • Direct I/O (%I, %IW, %Q, %QW) is only available for integer type variables, and is not available for REAL or STRING variables.

  • HMI target machines can only read the value of Constant Device (%KW) variables.
