Gap Span

The maximum number of consecutive unused addresses that are allowed between registers in order for it to fit into a single request.

Gap Span is a term used in the protocol manuals. Gap span helps define how requests are separated into different packets to maximize the communication efficiency between the target machine (HMI) and equipment.

Gap span is used in combination with Maximum Consecutive Addresses.

Example

Driver has a Gap Span of 3 and Maximum Consecutive Address of 7, and uses the following registers:

  • If you are requesting %MW0 and %MW4, the result is a single request with a gap of 3 and 5 consecutive addresses.

  • If you are requesting %MW0 and %MW5, the result is two requests because the gap between %MW0 and %MW5 is greater than 3, the maximum gap span allowed.
