5.6.2.14 Recipe transfer not allowed

This function is a 16 bit word that controls recipe transfers. The following values of this word control recipe transfers:

  • 0 - Recipe transfer is enabled.

  • 1 - Recipe transfer is disabled.

If a recipe transfer is in progress and the value of this word changes to 1, the recipe transfer is completed without interruption and then recipe transfers are disabled.

  • This function only reads the values of the default recipe control variable. Values of other recipe control variables are not read by this function.
