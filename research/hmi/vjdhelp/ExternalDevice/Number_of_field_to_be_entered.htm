5.6.2.11 Number of field to be entered

This function is a 16 bit word that stores the part Field ID value. This word's value range is 1 to 65534.

The following values are reserved values for this word:

  • 0 - No field selected

  • 65535 - Completion

If the part Field ID cannot be written to the word:

  • The target machine writes the value 65535 to this word.

  • Depending on the data entry method for the part, the Report function bit for ENTER or ESC is set to 0.

If the part Field ID can be written to the word:

  • The target machine writes the value 65535 to this word.

  • Depending on the data entry method for the part, the Report function bit for ENTER or ESC is set to 1.

For more information on Field IDs, see Section 12.2.2.4, Input Mode Tab. For more information on the Report function, see Section 5.6.2.5, Report.
