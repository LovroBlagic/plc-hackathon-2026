5.7 Working with the Reflex Table

The Reflex Table provides a simple way for running common functions and communicating data between the target machine (HMI) and the PLC. The Reflex Table operates the same way as the Dialog Table operates; however, the Reflex Table supports a limited number of functions. For more information on the Dialog Table, see Section 5.6, Working with the Dialog Table.
