5.6.2.13 Table write authorization

This function is a 16 bit word that provides security for the Dialog Tables. The value is a hexadecimal number. If the hexadecimal number is invalid, the target machine cannot write to the Dialog Table and the PLC cannot execute any Dialog Table functions. The word becomes invalid when the LSB of the word does not match the length of the Dialog Table. You can find the valid value for the word in the Authorization Word field of the Dialog Table Settings dialog box.

If the word becomes invalid while Dialog Table processes are running, the processes finish running before the Dialog Table stops. When the Dialog Table stops, the Report function is not updated.
