5.2.6 Changing Equipment IP address at Run Time

You can dynamically change your equipment's IP address during run time using a block variable. For more information on block variables, see Section 6.9, Block Variables.

Store the equipment's IP address, Subnet Mask, and Default Gateway in a block variable. Set the block variable's start address to the appropriate device address on the equipment and use a sendData operation (see sendData ) to send the block variable to the equipment. The equipment resets its IP address to the newly written block variable values. IP address data must be stored in a specific order in the block variable and written to specific device addresses on the equipment. See your equipment's manual for the proper device addresses and see the example below for the IP address data order in the block variable.

Changing the Equipment's IP address using a block variable is supported by the following equipment:

  • Ethernet Supported Twido

  • You must activate this function on the equipment. See the equipment's manual for information on activating this function.

  • The block variables used to hold the IP address, Subnet Mask, and Default Gateway must be of UINT type. This prevents the values from changing signs during run time.

  • You must write the whole block variable that contains the IP address, Subnet Mask, and Default Gateway to the equipment using one sendData operation. The equipment IP address settings may not be set properly if you send the IP Address, Subnet Mask and Default Gateway individually.

  • You can also use script equipment methods to change the equipment's IP address. For more information, see Section 18.3.8.10, Equipment Methods.

Example:

The following script example shows how to change the IP address on an ethernet supported Twido equipment using a block variable.

IP Address Data

Device Address Data

IP: 10.187.225.219 (0A.BB.E1.DB)

Subnet Mask: 255.255.248.0 (FF.FF.F8.00)

Default Gateway: 10.187.224.2 (0A.BB.E0.02)

%SW33 – E1DB (IP 3rd & 4th)

%SW34 – 0ABB (IP 1st & 2nd)

%SW35 – F800 (Subnet 3rd & 4th)

%SW36 – FFFF (Subnet 1st & 2nd)

%SW37 – E002 (Gateway 3rd & 4th)

%SW38 – 0ABB (Gateway 1st & 2nd)

 

//-------------------------------------

//Script Created: Jun 23, 2009

//

// Description:

// This script is to change IP address on the connected Twido PLC

// & re-configure Vijeo Designer with the new IP

//

//

// It is assumed that a UINT structured variable "IP_Data" already contains new IP address as follows;

//

// IP_Data[0] = 010 // Ex. IP: 010.187.225.219

// IP_Data[1] = 187

// IP_Data[2] = 225

// IP_Data[3] = 219

//

// IP_Data[4] = 255 // Ex. Subnet Mask: 255.255.248.000

// IP_Data[5] = 255

// IP_Data[6] = 248

// IP_Data[7] = 000

//

// IP_Data[8] = 010 // Ex. Gateway: 010.187.224.002

// IP_Data[9] = 187

// IP_Data[10] = 224

// IP_Data[11] = 002

//

//-------------------------------------

// Load all new data to one array

int [] IP_Data_VJD = new int[4]; // holds new IP value to configure Vijeo Designer configuration

int [] IP_Data_Temp = new int[12]; // Temporary data storage for address data conversion

// Load IP values to temporary storage to send it to PLC

for( int elementNo = 0;  elementNo < 12;  elementNo++){

IP_Data_Temp[elementNo] = IP_Data[elementNo].getIntValue();

}

// Load IP address to temporary storage for configuring Vijeo Designer

for( int elementNo = 0;  elementNo < 4;  elementNo++){

IP_Data_VJD[elementNo] = IP_Data[elementNo].getIntValue();

}

//---------------------------------------

//

// Take all of the numbers entered and put them into blocktowrite.  Send this package

// to the proper PLC.

//

int [] blocktowrite = new int[6];

// Set IP 1st & 2nd data to 2nd element in block variable

long temp =(((IP_Data_Temp[1]&0xFF)<<0)&0x00FF)+ (((IP_Data_Temp[0]&0xFF)<<8)&0xFF00);

temp = temp & 0xffff; // clear out upper half

blocktowrite[1]=(int)temp;

// Set IP 3rd & 4th data to 1st element in block variable

temp =(((IP_Data_Temp[3]&0xFF)<<0)&0x00FF)+ (((IP_Data_Temp[2]&0xFF)<<8)&0xFF00);

temp = temp & 0xffff; // clear out upper half

blocktowrite[0]=(int)temp;

// Set Subnet Mask 1st & 2nd data to 4th element in block variable

temp =(((IP_Data_Temp[5]&0xFF)<<0)&0x00FF)+ (((IP_Data_Temp[4]&0xFF)<<8)&0xFF00);

temp = temp & 0xffff; // clear out upper half

blocktowrite[3]=(int)temp;

// Set Subnet Mask 3rd & 4th data to 3rd element in block variable

temp =(((IP_Data_Temp[7]&0xFF)<<0)&0x00FF)+ (((IP_Data_Temp[6]&0xFF)<<8)&0xFF00);

temp = temp & 0xffff; // clear out upper half

blocktowrite[2]=(int)temp;

// Set Default Gateway 1st & 2nd data to 6th element in block variable

temp =(((IP_Data_Temp[9]&0xFF)<<0)&0x00FF)+ (((IP_Data_Temp[8]&0xFF)<<8)&0xFF00);

temp = temp & 0xffff; // clear out upper half

blocktowrite[5]=(int)temp;

// Set Default Gateway 3rd & 4th data to 5th element in block variable

temp =(((IP_Data_Temp[11]&0xFF)<<0)&0x00FF)+ (((IP_Data_Temp[10]&0xFF)<<8)&0xFF00);

temp = temp & 0xffff; // clear out upper half

blocktowrite[4]=(int)temp;

//----------------------------------------

// Send new IP data, using a UINT block variable, to let the PLC change its own IP to new one.

BlockInt_PLC01.write( blocktowrite );

BlockInt_PLC01.sendData(true);

// Re-configure Vijeo Designer with new IP and restart the driver.

ModbusEquipment01.openConfig();

ModbusEquipment01.setProperty( "Con_IPAddress", IP_Data_VJD );

ModbusEquipment01.commitConfig();
