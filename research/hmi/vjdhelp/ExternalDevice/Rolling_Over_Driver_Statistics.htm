5.3.3 Rolling Over Driver Statistics

The rollover operation:

  • Copies the current driver statistics to the previous driver statistics.

  • Resets the current driver statistics to zero.

  • Instead of using variables, you can use the configuration menu to roll over driver statistics.

The following instructions demonstrate how to roll over driver statistics at midnight every day.

  1. Create an external variable named Rollover and in the Device Address field type @sys:3

  1. Set up an action with the following settings:
    Trigger Type: Conditional
    Trigger Variable: _Day (system variable)
    Trigger: On Data change.
    Operation: Script
    For the script write: Rollover.write(1);
    The script should write a value to the Rollover variable created in the previous step.
