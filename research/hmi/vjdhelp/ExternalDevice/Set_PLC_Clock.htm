  • Word 4 is based on a four digit year, for example, 2001. The first two digits, 20, are stored in bits 8 to 15. The last two digits, 01, are stored in bits 0 to 7.

The values of the words are defined by the following system variables on the PLC. For more information on System Variables, see Section 6.7, System Variables.
