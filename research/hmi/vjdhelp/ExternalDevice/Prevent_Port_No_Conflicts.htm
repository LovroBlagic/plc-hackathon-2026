5.8.6 Preventing Port Number Conflicts

Vijeo Designer features (such as download, data sharing, Web Gate, Vijeo Design'Air, Vijeo Design'Air Plus, and so on) use several port numbers. Some port numbers are configurable, allowing you can change them in Vijeo Designer Buildtime. However, some port numbers have a fixed value and cannot be changed.

A port number conflict occurs when you are modifying a configurable port number and select a value already used by a port number that cannot be changed. For example, changing the data sharing port number from 6000 (the default value) to 6002, which is the default port number used by Vijeo Design'Air, would result in a port number conflict.
