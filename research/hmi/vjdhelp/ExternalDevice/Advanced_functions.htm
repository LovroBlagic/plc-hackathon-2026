5.6.2.15 Advanced functions

This function is a 16 bit word that controls the following three functions:

  • Turning the Backlight On/Off

  • Changing the Security Level

  • Clearing the Alarm Log Database

These functions and their parameters are controlled by the MSB and LSB of this word:

  • MSB - Defines the function requested by the PLC.

  • LSB - Defines the function's parameters.

The table below describes the value ranges the LSB and MSB.

Turning the Backlight On/Off

Not all targets support Red, Green, and Orange backlight colors, see Appendix 5 Hardware Specifications for a list of targets that support this features. For targets that do not support these colors, writing Red, Green or Orange value to the LSB turns the target machine's backlight on

  • The Dialog Table backlight color takes priority over any backlight color settings in the application. To allow the backlight color to be set by the application, the PLC should write 0x00 to this word's LSB.

Changing the Security Level

In order to change the security level from the PLC Dialog Table, you must have Bitmask Based selected for the Security Mode and three security groups set up with the values shown in the table below.

When the PLC sets the security level, users cannot log on or log off of the target machine. Once the PLC resets the security level back to 0, the user that was logged on to the target before the PLC set the security level is automatically logged back on.

Clearing the Alarm Log Database

When the PLC writes 0x00FF to this word, the target machine erases the log alarms in the selected alarm group. This value must be reset to 0x0000 after the log alarms are erased. If the value stays at 0x00FF and the PLC writes 0x00FF to the function again, the alarms are not erased. This function only erases alarms when the change from 0x0000 to 0x00FF occurs. For information on selecting the alarm group, see Section 5.6.1, Dialog Table Settings.
