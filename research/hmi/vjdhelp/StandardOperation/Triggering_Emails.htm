4.14.4 Triggering E-mails

You can set up an E-mail operation to trigger an E-mail to a recipient at runtime.

To set up an E-mail operation trigger:

  1. Create one of the following to trigger the E-mail operation:

  • Action

  • Switch

  • Selector

  • Function Key

  1. Define an E-mail operation and specify if you want to add an attachment to your e-mail. For more information, see Section 9.5.20, E-mail Operations and Section 4.14.5, Adding an Attachment to an E-mail.

At run time, the E-mail can be triggered by the action, switch, selector, or function key set up with the E-mail operation.

 

Example of Creating a Switch to Trigger an E-mail

The following example, assumes you have already set up your Vijeo Designer E-mail server and you have already added E-mail contacts (Aliases) to Vijeo Designer E-mail.

  1. Click the Switch icon, and draw a Switch on a panel.

  2. In the Switch Settings dialog box, select E-mail in the Operation drop-down list.

  3. In the E-mail Operation see Section 9.5.20, E-mail Operations, specify the following:

  4. E-mail Recipient (Alias or Variable)

  5. Subject

  6. Message or Form ID

  7. Attachment configuration settings

  1. Click Add to add the E-mail operation to the Switch and then click OK.

At run time, the E-mail can be triggered by touching the Switch.
