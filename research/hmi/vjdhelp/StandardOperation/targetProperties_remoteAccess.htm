4.5.1.5 Remote Access

Property

Description

Type

Read-only property that identifies the hardware platform selected for the application to run on. For more information, see Section 4.5.1.1, General.

Model

Read-only property that identifies the target model selected for the application to run on. For more information, see Section 4.5.1.1, General.

Data Sharing

This property is available only if you selected a target type that supports Ethernet. When Data Sharing is Enabled, you can reference the variables and alarm groups in this target from other target machines. See Section 22.1, Sharing Data Between Tablets, Smartphones, and Target Machines.

Port

Available when Data Sharing is Enabled, enter the port number used for data-sharing communication with other target machines. If the default (6000) conflicts with other projects or services on the target machine, enter a different port number (1-65535). For more information, see Section 5.8.6, Preventing Port Number Conflicts.

Remote Management

In Vijeo Designer, this property is available for target machines that support Ethernet. For a complete list of target machines that support Remote Management, see Section Appendix 5, Hardware Specifications.

Use the Remote Management properties to enable the target machine to accept remote connection from tablets and smartphones. In this configuration the target machine acts as the server and the tablet or smartphone as the client. For more information, see Section 23.1.2, Vijeo Design'Air.

Target Discovery

This option defines if at run time the target machine can be detected by tablets and smartphones. For more information, see Section 23.1.2.1, Setting Up Vijeo Design'Air Server.

Vijeo Design'Air

This option defines if the Vijeo Deisgn'Air client can connect to the target machine. Select Enabled to allow connection.

You can select a thumbnail icon for the Vijeo Design'Air server. For more information, see 23.1.2.1 Vijeo Design'Air Server Thumbnail Icon. You can also change a port number for the Vijeo Design'Air server. For more information see Section 23.1.2.2, Vijeo Design'Air Server Port Number.

Vijeo Design'Air Plus

This option enables you to download a Tablet/Smartphone project to the target machine. For more information, see Section 23.1.1, Vijeo Design'Air Plus.

Web Server

When Web Server is enabled on a target, a user can view and modify variable data on the target machine or the PLCs connected to the target machine. See Section 23.2, Monitoring Target Machines with Web Gate. You have the option to enable Web Server only or enable both Web Server and Web Gate. For targets that do not support Web Gate due to limited memory, variables can be accessed remotely from the Web Server.

Port

Defines the port number used by the Web Gate HTTP server in the target machine. The default port number is 80.

Access Control

The Access Control tab enables you to limit access to the target based on the remote PC's IP address. See Section 23.2.3.2, Access Control Settings.

File Browser

This option enables Web Gate's File Viewer feature. The File Viewer feature allows you to view and copy files stored on the target machine using your web browser.

For more information on this feature, see Section 23.2.9.3, Viewing Web Server and Data Files.

Web Gate

When Web Gate is enabled on a target, a user can connect to the target through a browser on a remote PC. Web Gate can only be enabled if Web Server is enabled. You can configure the following Web Gate settings:

  • Publish — Defines the panels, scripts, and popup windows to be accessed from the remote PC. For more information, see Section 23.2.4.1, Web Gate Publish Settings.

  • InitialPanelID — Defines the panel that displays when the browser on the remote PC first connects to Web Gate.

  • Inactivity Time-Out (min) — Specifies the time period that a client connected to a target using Web Gate can be inactive. When the Web Gate client is inactive for the Inactivity Time-Out period, the client will be disconnected from the target. Enter a value from 1 to 1440 minutes. For more information, see Section 23.2.3.1, Web Gate Inactivity Time-Out.
