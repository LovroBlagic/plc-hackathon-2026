4.11.2 Saving a Project Under a Different Name

  1. In the File menu, select Save Project As to open the Save As dialog box.

  1. Enter the new project name in the Project Name field.

  2. Enter the project description, if necessary. This field accepts a maximum of 255 characters.

  3. Click OK. The management folder is saved.

  • To save a project to external storage media (such as a floppy disk), export the project from the Vijeo-Manager tab as a compressed file.
    For more information, see Section 21.4.2, Exporting Projects.
