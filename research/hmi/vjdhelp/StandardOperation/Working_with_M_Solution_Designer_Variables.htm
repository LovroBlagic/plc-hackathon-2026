4.13.2 Using SoMachine and Vijeo Designer Variables

You can use SoMachine variables in Vijeo Designer and Vijeo Designer variables in SoMachine. A variable created and published from SoMachine becomes automatically available in Vijeo Designer. A variable created in Vijeo Designer can be moved and used in SoMachine.

See the following sections for more information:

  • Using SoMachine Variables in Vijeo Designer

  • Using Vijeo Designer Variables in SoMachine

  • Avoid using features that write to read-only SoMachine variables. Writing values to read-only SoMachine variables (for example physical output variables) will cause temporary communication loss due to an error response from the PLC. After a short time, the HMI will reconnect to the PLC again and communication will resume as normal.

  • An additional security feature has been implemented for SoMachine, which requires both Vijeo Designer and SoMachine to have a matching set of login credentials before they can communicate and access one another's resources. This feature can be accessed in Vijeo Designer via a project's IO Manager node. For more information on this security feature in SoMachine, see SoMachine's online help.

  • You can enable or disable the Support Complex Structures property, also via a project's IO Manager node. Disabling this property may cause structures shared through SoMachine's Symbol Configuration to display incorrectly on HMISCU target machines. Do not share structures in Symbol Configuration when this property is not selected.
