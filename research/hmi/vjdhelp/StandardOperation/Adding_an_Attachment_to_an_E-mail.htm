4.14.5 Adding an Attachment to an E-mail

You can add e-mail attachments to your e-mails. You can send the following as an e-mail attachment:

  • Stored data: Screen snapshots, recorded videos, alarm or event CSV files, recipe RCP and CSV files, data logging DAT files, and files available on the target.

  • Real-time data: Alarm and event records. The record is embedded in the e-mail, so no file is created.

To add an attachment to an e-mail:

  1. Set up an e-mail operation to trigger an e-mail to a recipient at runtime. For more information on the procedure, see Section 4.14.4, Triggering E-mails.

  2. Select the Attach Data check box, and click the ellipsis to open the Attachment dialog box.

  3. In the Attachment dialog box, define the properties. For more information, see Configuring the Attachment Settings.
