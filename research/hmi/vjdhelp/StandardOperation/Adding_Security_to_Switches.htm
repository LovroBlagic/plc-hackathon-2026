Adding Security to Parts

Set up your security groups before adding security levels to Parts, see Section 4.8.2, Creating Security Groups. See Defining Security Levels for Security Groups for more information on security levels.

To add security to a Part:

  • In the Part Settings Advanced tab, use the Security Level drop-down list to select the security group that can access the switch.
    The image below shows an example of how to set the security level for a Part.

  • The numeric value in front of the security groups in the Security Level drop-down list is the security level value used for Level Based and Bitmask Based security. See Defining Security Levels for Security Groups for more information on security levels.
