4.10 Using Shortcuts

This section describes the tool windows and toolbars. By customizing tool windows and toolbars, you can make the Vijeo-Designer editor easier to use.

4.10.1 Using Tool Windows

To help you navigate through the Vijeo-Designer tool windows, this section describes how to:

  • Set the view mode for tool windows.

  • Dock tool windows.

  • Change your tool window to a tabbed document in the main window.

  • Hide a tool window when it is not in use.

  • Hide a tool window completely.

For more information on tool windows, see Section 4.4.2, Editor Tools.
