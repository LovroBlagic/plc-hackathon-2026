4.8.10 Managing Security Passwords

Vijeo Designer's password security management feature applies to all methods of target login, where you need to enter a valid user name and password. It provides the following functions:

  • Retires passwords after a designated period of time. For more information on how an operator can change an expired password, see Section 4.8.4.3, Managing Passwords at Run Time: Changing an Expired Password.

  • Ensures an operator changes the password after the initial login. For more information on how an operator can change a password, see Section 4.8.4.3, Managing Passwords at Run Time: Changing a Password.

  • Locks out a user after a specified number of login attempts. For more information on the lock-out state and how a user's account can be reactivated, see Section 4.8.4.3, Managing Passwords at Run Time: Exceeding the Number of Attempts to Log On.

  • Checks that passwords do not match previous passwords when changed. For more information on the Compare with Previous property, see Section 4.8.7, Security Settings.

  • Checks that a new password being created complies with the password strength criteria. For more information on the password strength properties, see Section 4.8.7, Security Settings.

To set up password security and define the password strength criteria in the Security Property Inspector, enter values in the Password Management properties. For more information, see Section 4.8.7, Security Settings. After setting up password security, you can then create users. For more information, see Section 4.8.3, Creating Security Users.

The password strength criteria is only enforced when passwords are being created. If you change the password strength criteria after creating passwords, those passwords created using the old criteria will still be accepted for login at Runtime. New passwords will be created using the updated criteria.

When developing the HMI user application for the target machine, the HMI designer needs to plan the following key methods in password security management:

  • Target Login

  • Password Change

Method to Log In to the Target

In the Editor, you can set up a Login part, FixedNameLogin part, or System Login Panel for the operator to log in to the target. You can set up other methods to log in to the target, such as using the Authorization part or a script. However, if the password expires, the operator would need to log in using a Login part, FixedNameLogin part, or System Login Panel to change the expired password.

Method to Change the Password

Password change can be done using the following methods:

  • New Password Panel – This is a system panel that displays automatically. After you log in, Vijeo Designer displays the new Password Panel to inform you your password has expired and prompts you to change your password. This panel also displays after a first-time login.

  • PasswordChange part – Set up this part so the operator can change a password when it becomes compromised. For more information, see Section 4.8.4.3, Managing Passwords at Run Time: Changing a Password.

  • UserManager part – Set up this part so that an operator with authority (such as a system administrator) can change passwords. For more information, see Section 4.8.5, Managing Security Users at Run Time.
