4.13.3 Controller Operations: Start/Stop/Lockout

Vijeo Designer provides features that allow the HMI application to interact with the XBTGC/XBTGT/HMISCU controller.

Start/Stop

You can start and stop the XBTGC/XBTGT/HMISCU controller application from the HMI application using one of the following:

  • Toolchest Part - The Toolchest's Configuration folder contains a Toolchest part for starting and stopping the controller. This Toolchest part is a set of grouped Switches and Lamps that can be customized to fit your application. For information on how to add a Toolchest part to you project, see Section 21.2.1, Working with Toolchest Objects.

  • Controller Operation - The Start/Stop controller operation is supported for Switches, Selectors, Function Keys, Actions, and Touch Animation. For more information on this operation, see Section 9.5.18, Controller Operations.

  • Driver Property - Driver properties (@prop) enable you to Run/Stop and monitor the controller application. For more information on driver properties, see Section 5.4, Working with Driver Properties.

  • For an HMI with Control devices, Actions and Panel Actions are not affected by the Start or Stop state of the controller. Actions and Panel Actions are managed only by the HMI.

Lockout

You can lockout the XBTGC, XBTGT, and HMISCU with the control's controller. The lockout is a master switch that prevents the user from running the controller in any way when enabled. The purpose of the lockout is to prevent injury resulting from unintended start-up of the system. The controller must be in stop mode before you enable lockout. Lockout is controlled by the system variable: _ControllerLockout. For more information on this system variable, see Section 6.7.1, System Variable List: _ControllerLockout.

For example, a manager can set or reset the _ControllerLockout variable from a secured panel on the HMI. When a critical issue occurs on the production line, the manager stops the controller using a Toolchest part and sets _ControllerLockout to 1. An operator attempts to restart the controller using the Toolchest part but is unable to restart until the manager resets the _ControllerLockout variable.
