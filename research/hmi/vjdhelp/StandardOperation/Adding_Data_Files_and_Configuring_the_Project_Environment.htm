4.12 Adding Data Files and Configuring the Project Environment

From the Environment node in the Navigator, you can add data files to your project, setup security protection, configure languages for the project.

Data Files

The Data Files node allows you to add data files to your project. Use the DownloadTo property to define where you want to store the files on the target. You can add the following data files to your project:

  • Browser Files

  • Sound

  • Text

  • Video

Security

The Security node allows you to define access rights for users. You can define target security, download security, Data Manager and command line security, and Web Gate / Web Server security. For information on setting up security, see Section 4.8, Setting up Security Protection for Targets and Projects.

Languages

The language node allows you to add and manage application languages for your project, as well as setting up the target's system languages. For more information, see Section 20.2, Switching Languages.
