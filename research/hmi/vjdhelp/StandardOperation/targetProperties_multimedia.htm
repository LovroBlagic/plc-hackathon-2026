4.5.1.6 Multimedia

Property

Description

Type

Read-only property that identifies the hardware platform selected for the application to run on. For more information, see Section 4.5.1.1, General.

Model

Read-only property that identifies the target model selected for the application to run on. For more information, see Section 4.5.1.1, General.

Buzzer

When sound is enabled, the system buzzer is emitted when:

  • There are keypad entries.

  • You touch an alarm in an alarm summary object with Direct Selection set to Enabled.

  • You touch an object with touch animation.

  • The Runtime Configuration menu is used.

  • You can change the buzzer setting at runtime using the Configuration Menu. See Section 26.1, Configuration Menu. 

Screen Snapshot

This property enables and configures the screen snapshot operation for the target machine.

Snapshot enables you to take a snapshot of the target machine's screen during run time and store it in .jpeg format or print it. For more information, see Section 19.2, Saving and Printing Screen Snapshots.

Video

This property enables and configures the video operations for the target machine. For more information on video, see Section 19.1.1, About Video.
