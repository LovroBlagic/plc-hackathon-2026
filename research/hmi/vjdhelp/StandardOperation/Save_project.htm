4.11 Saving, Closing, and Exiting Your Project

This section explains how you can save and close your project. Projects saved in Vijeo-Designer are displayed in the Vijeo-Manager tab of the Navigator window.

4.11.1 Saving a Project

You can use one of the following ways to save your project:

  • In the Project tab of the Navigator window, right-click a Project icon and select Save.

  • In the File toolbar, click the Save Icon.

  • In the File menu, select Save Project.

  • In the Project tab of the Navigator window, click the Save icon.

  • Projects are not saved when you perform a build.
