4.10.2.2 Special Editor Toolbars

Vijeo-Designer toolbars are listed as follows:

  • Graphical Objects toolbar

  • Arrange toolbar

  • Select Options toolbar

  • Object Information toolbar

  • Panel Configuration toolbar

  • State Options toolbar

Arrange Toolbar

The Arrange toolbar contains the icons you need to arrange the objects you have created.

Icon

Name

Functionality

Bring To Front

Moves a selected object forward to display it in front of all other objects.

Send To Back

Moves a selected object back to display it behind all other objects.

Rotate Left

Rotates a selected object 90 degrees counter-clockwise.

Rotate Right

Rotates a selected object 90 degrees clockwise.

Flip Horizontal

Flips a selected object across the X-axis.

Flip Vertical

Flips a selected object across the Y-axis.

Group

Places multiple objects into a group. Grouping allows you to treat several objects as a single group object.

Ungroup

Cancels the grouping of objects. If you ungroup an animation-enabled group object, the animation function will be lost.

Align to grid

Moves the top-left corner of an object to the nearest grid point.

Align Left

Aligns objects in a selected group vertically to the left edge of a selected area.

Align Center

Aligns objects in a selected group vertically to the center of a selected area.

Align Right

Aligns objects in a selected group vertically to the right edge of a selected area.

Align Top

Aligns objects in a selected group horizontally to the top of a selected area.

Align Middle

Aligns objects in a selected group horizontally to the center of a selected area.

Align Bottom

Aligns objects in a selected group horizontally to the bottom of a selected area.

Align Space Horizontal

Aligns objects in a selected group horizontally with equal spacing between them.

Align Space Vertical

Aligns objects in a selected group vertically with equal spacing between them.

 

Select Options Toolbar

The Select Options toolbar contains the icons you need to change the way you select objects. To use this toolbar, you must have selected multiple objects.

Icon

Name

Functionality

Select All

Selects all objects in a selected area.

Select Type

Selects only same-kind objects in a selected area.

Select Individual

Selects a single object in a selected area.

Select Previous

Selects the objects in order, from front to back, when Select Same Kind or Select One is selected.

Select Next

Selects the objects in order, from back to front, when Select Same Kind or Select One is selected.

 

Panel Configuration Toolbar

The Panel Configuration toolbar contains the icons you use to view objects on the panel grid (using zoom) and to move objects on the grid (snap to).

Icon

Name

Functionality

Zoom

Allows you to set the zoom that you want to view objects on the panel using set rages:

  • 50%

  • 75%

  • 100% (default)

  • 200%

  • 400%

  • 800%

Zoom In

Zooms in your view of the object on the panel.

Zoom Out

Zooms out your view of the object on the panel.

Snap To

Allows you to Snap to Matrix or Snap to Grid. For more information, see Section 4.9.3, Setting the Grid.

Show Grid

Allows you to set the grid type as Line, Dot, or None. For more information, see Section 4.9.3, Setting the Grid.

 

Object Information Toolbar

The Object Information toolbar contains the icons you need to view object information. See Section 21.6, Editing with Object Information.

Icon

Name

Functionality

Enable Object Info

Enables the display of  information about all objects in a panel and a project.

Variable Name

Displays variables associated to an object.

Variable Address

Displays the device address associated with an object.

Object Name

Displays the object name.

Z-Order

Displays the order that objects in a panel have been created.

Tab-Order

Displays the name of groups and their order, if you set tab grouping on data animation.

Animation

Displays animation icons associated with an object.

Change Panel

Displays the name of a panel associated with an object.

Field ID

Displays the input mode field ID associated with an object.

Display Popup & Alarm Banner

Displays the name, size, and position of the popup window and alarm banner shapes associated with an object.

 

State Options

The State Options toolbar contains icons that users can use to preview what parts look like at run time.

Icon

Name

Functionality

Up or Down

Displays the touch states of a switch or Selector.
See 9.2 Creating Switches.

See 9.3 Creating Selectors.

On or Off

Displays the states of a switch or Selector when it's either ON or OFF.
See 9.2 Creating Switches.

See 9.3 Creating Selectors.

Interlock

Displays the states of switches and other touch objects when their interlock feature is On.
See 9.6 Using Interlock to Prevent Accidental Touch Inputs.

State

Displays the state of parts, from state 0 to state 255.

You can use the plus and minus buttons to scroll through the states.

 

  • The State Options work only with parts created using the Graphical Objects toolbar. Switches, lamps, or other parts from the Toolchest do not interact with the State Options toolbar.
