4.8.8 Adding Project Security

You can add security to your projects so that unauthorized users cannot:

  • Open protected projects

  • Overwrite protected projects

4.8.8.1 Setting up Project Security

There are two ways you can add project security to a project:

  • Setting Up project security in the Project Node

  • Setting up project security while creating a new project

Setting Up Project Security in the Project Node

  1. In the Project tab, right-click the project node and click properties.

  2. In the Project's properties, enable the Project Password field.

The New Password dialog box appears.

  1. In the New Password dialog box, type in the following information:

Property

Description

Enter Password

Type in a password. Passwords use the following naming conventions:

  • Maximum of 32 characters

  • Valid characters are: a–z, A–Z, 0–9, _ (underscore)

  • Passwords are case-sensitive

  • You cannot set up blank passwords

Confirm Password

Retype the password in this field to confirm the password.

Hint

Type in a hint for your password. The password hint should help you remember your password if you forget it.

  • We recommend you create a hint so that if you forget the project password you can use the hint to easily remember the password.

 

  1. Click OK to set the password for the project.

Setting Up Project Security in the Create New Project wizard

You can add project security while creating a new project. For steps on creating a new project with project security, see Section 4.3.2, Creating a New Project.

4.8.8.2 Recovering Forgotten Passwords

If you forget your project password, click the password hint button in the Enter Project Password dialog box to display the password hint. The hint should help you remember your password.

If the hint does not help you remember your password, contact customer support to recover your password.

4.8.8.3 Changing Project Passwords

  1. In the Project tab, right-click the Project node and click Properties to display the project properties.

  2. In the Project properties, click the Project Password ellipsis button to display the Change Password dialog box.

  1. In the Change Password dialog box, type in the following information:

Property

Description

Enter Current Password

Type in the project's current password.

Enter Password

Type in a password. Passwords use the following naming conventions:

  • Maximum of 32 characters

  • Valid characters are: a–z, A–Z, 0–9, _ (underscore)

  • Passwords are case-sensitive

  • You cannot set up blank passwords

Confirm Password

Retype the password in this field to confirm the password.

Hint

Type in a hint for your password. The password hint should help you remember your password if you forget it.

  • We recommend you create a hint so that if you forget the project password you can use the hint to easily remember the password.

 

  1. Click OK to set the new password for the project.
