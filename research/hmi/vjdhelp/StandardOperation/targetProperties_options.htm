4.5.1.4 Options

Property

Description

Type

Read-only property that identifies the hardware platform selected for the application to run on. For more information, see Section 4.5.1.1, General.

Model

Read-only property that identifies the target model selected for the application to run on. For more information, see Section 4.5.1.1, General.

Start Up Options

Use this property to configure a Target Machine's start up options.

Start Up Delay

Enter a startup delay (0 to 300) in seconds that will delay the start of the project after Runtime is started. A startup delay allows time for equipment such as PLCs to initialize. See Section 24.4.1, Startup Delay.

Custom Welcome Screen

Select a custom welcome screen image to display during startup. Not all targets support this feature. For information about the targets that support the Custom Startup Screen feature, see Appendix 5, Hardware Specifications. For instructions on how to use this feature, see Section 24.4.3, Custom Startup Screen.

Check Project Integrity

If enabled, during startup Runtime checks the project on the Target Machine for errors. If errors are not detected, the project will start. If errors are detected, Runtime stops the project from starting and displays an error message. The error message prompts the user to either restart the target machine or download the project to the target machine. See Section 24.4.2, Checking Project Integrity.

Time Management

Select Use PLC Dialog Table to set up time management on the target so that it can support Vijeo Designer's time-based features, such as alarms, events, trend graphs, and date/time parts.

This setting is for targets that do not have battery backup for the internal real-time clock. For information about the targets that require time management to be set in order to support time-based functions, see Appendix 5, Hardware Specifications.

For instructions on how to set up time management on the target, see Section 24.4.4, Time Management.

SRAM Data Flush Rate

Defines how often data is flushed from DRAM to simulated SRAM. SRAM is simulated using the target machine's main drive.

The purpose of SRAM is to store data between run-time sessions and to back up data in case of a power failure. Data that is not flushed to the main drive is lost if a power failure occurs. Consider using an uninterruptable power supply (UPS) so you can gracefully shut down the machine.

  • Not all target machines support simulated SRAM, see Appendix 5, Hardware Specifications.

Data Locations

This property specifies where runtime data is stored. You can specify where the following types of runtime data are stored on the target machine:

  • Recipe files (.rcp) - Section 17.3.2, Setting Up the Recipes Node.

  • Data logging files (.dat) - SRAM and File in Section 13.1.1.3, Storing Your Collected Data.

  • Alarm and Event files (.csv) - Section 16.3.6, Outputting Alarms and Events to a .CSV File.

  • Video files - Section 19.1.1, About Video.

  • Snapshot files (.jpeg) - Section 19.2.1, Saving Screen Snapshots and 19.1.6.2, Saving Video Snapshots.

  • Project backup files (.vdz) - Section 21.5.2, Backing up Projects to Main Drive, CF Card/SD Card, or USB Drive.

For more information on Data Location settings, see Appendix 5.11.1, Types of Data Locations.

Low Space Notification (MB)

This property allows you to set up a notification that displays if the amount of free space on the storage device falls below the specified value. Select the check box to enable the Low Space Notification property, and enter a value between 1 and 1024 MB. This property is available for all targets that support a CF Card/SD Card or USB memory stick (optional drive).

During run time, if the amount of remaining free space is below the amount that you specified in this property, a message displays.

  • If you delete the message from the Event Log, the low space notification message will not appear again until the Low Space Notification event is first resolved, then a new Low Space Notification event occurs.

Exclusive Input

This property is enabled when Input Synchronization is enabled in the Project properties. For information on how to use this property, see Section 22.2, Setting Up Exclusive Input Relationships.

There are two ways to identify which panels in a target are set up with exclusive input:

  • Enabling Exclusive Input in the Target properties to select all the panels in the target

  • Enabling Exclusive Input in the Panel properties, to identify panels one by one.

Time Zone

Select the time zone for the target. The default is set to the editor computer's time zone. For information on how Time Zone affects how data is stored and displayed, see Section 4.5.3, Displaying Data Using Time Zone and Configuring Daylight Saving Time.

Some targets do not allow changes to the Time Zone in Vijeo-Designer. For information on which targets allow Time Zone changes, see Appendix 5, Hardware Specifications.

Time Adjustment (DST)

Enable this property to configure Daylight Saving Time for the target. The Time Adjustment properties can be viewed in the Property Inspector and configured in the Time Adjustment dialog box. Display the Time Adjustment dialog box by enabling Time Adjustment or by clicking the ellipsis button beside each property. For more information on configuring Daylight Saving Time, see Section 4.5.3, Displaying Data Using Time Zone and Configuring Daylight Saving Time.

Type

Displays whether Daylight Saving Time changes are based on a Rule, such as the "First Sunday March @ 2:00 AM", or on a specific Date, such as "March 1 @ 2:00 AM."

Add Time

Displays when time is added to the clock as Daylight Saving Time begins.

Subtract Time

Displays when time is subtracted from the clock as Daylight Saving Time ends.

Amount of Time

Displays the amount of time that is added when Daylight Saving Time begins and subtracted when Daylight Saving Time Ends.

E-mail

Set up E-mail to send e-mail notifications to users. For more information on setting up e-mail see Section 4.14, Working with E-mail.
