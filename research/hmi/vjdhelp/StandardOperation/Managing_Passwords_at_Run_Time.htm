4.8.4.3 Managing Passwords at Run Time

When you enable the Password Management for a project for the first time and set its Expire After (Days) property, at run time, the password expires immediately at start up. You must log in to the target machine and change your password.

Changing an Expired Password

When a user password expires, the operator must change the password. The method to change the password differs depending on the login method:

  • Logging in using a Login part, FixedNameLogin part, or script method "Sys.login" – On password expiry, after the operator logs in successfully, a new password panel opens indicating your password has expired and allows the operator to enter and confirm a new password.

  • Logging in from the Web Server/Web Gate, or using an Authorization Toolchest part or script method "Sys.validateUser" – On password expiry, the login will fail and a system message will display. The operator will need to log in using a Login part, FixedNameLogin part, or System Login Panel, and then will be able to change the password.

In the event the password has expired, the operator can still log in using the expired password and download to a panel using File System.

Changing a Password

An operator would change a password in the following cases:

  • The current password has become compromised.
    Use the PasswordChange part, the operator must enter a new password that complies with Password Management rules for password strength and number of attempts.

  • The operator is logging in for the first time.
    After logging in, the system panel prompts the operator to change the password.

  • The password has expired.
    The system panel informs the operator of the password expiry and to change the password.

  • The operator becomes locked out after exceeding the number of allowable attempts to log in.
    Using a UserManager part, an operator with the authority (typically a system administrator) has to reset the password to a temporary password for the operator.

  • The operator has a temporary password.
    After logging in with the temporary password, the system panel prompts the operator to change the password.

To change a password, the operator uses a system panel or parts configured in the Editor when developing the HMI user application. For more information, see Section 4.8.10, Managing Security Passwords.

Exceeding the Number of Attempts to Log On

Vijeo Designer allows a limited number of failed attempts during logon before it locks the operator out. After the lock-out, any subsequent logon attempts will fail. The number of attempts is defined in the Password Management properties. For more information, see Section 4.8.7, Security Settings.

To reactivate the user account, another operator with authority (such as an Administrator) must use the User Manager Toolchest part to reset the password to a temporary password for the operator. For more information, see Section 4.8.5, Managing Security Users at Run Time.
