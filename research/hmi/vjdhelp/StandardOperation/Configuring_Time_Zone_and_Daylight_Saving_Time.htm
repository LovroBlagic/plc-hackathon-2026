4.5.3 Displaying Data Using Time Zone and Configuring Daylight Saving Time

This section explains how the Time Zone and Daylight Saving Time affect how data is stored and displayed on a target. It also explains how to configure Daylight Saving Time.

Displaying Data using Time Zone and Daylight Saving Time

Targets store data using Greenwich Mean Time (GMT) and display data using the target's Time Zone and Daylight Saving Time settings. Therefore, the time displayed when viewing data at run time is GMT time, plus the Time Zone, plus Daylight Saving Time. When the time changes due to Daylight Saving Time, the stored data will not change, but the time displayed will. This applies to logged data, alarms, and event logs.

Configuring Daylight Saving Time

Some regions of the world change their time seasonally, such as turning the clock ahead one hour in Spring and turning the clock back one hour in Autumn. This is handled using the Daylight Saving Time settings.

Open the Time Adjustment (Daylight Saving Time) dialog box by enabling the Time Adjustment property in the Target node. When a target is first created, Daylight Saving Time is set to the same settings as the editor computer. You can change the settings to match the geographic region where the target will be used. Daylight Saving Time must be set properly to ensure data is logged and displayed using the correct time.

At run time, an event message appears when the time is changed due to Daylight Saving Time. Some targets do not allow changes to the Daylight Saving Time in Vijeo-Designer. For information on which targets allow Daylight Saving Time changes, see Appendix 5, Hardware Specifications.

Property

Description

Type

Select how the target determines when Daylight Saving Time starts and ends: either as a Rule, such as the "First Sunday March @ 2:00", or as a Date, such as "March 1 @ 2:00."

Rule - Add Time

Configure when Daylight Saving Time starts according to the specified Rule.

Date (field name not displayed)

Select the occurrence of the day of the week that Daylight Saving Time begins: First, Second, Third, Fourth, Last.

For example, First Sunday of March.

Day of the Week (field name not displayed)

Select the day of the week that Daylight Saving Time begins: Sunday, Monday, Tuesday, Wednesday, Thursday, Friday, Saturday.

Month (field name not displayed)

Select the month that Daylight Saving Time begins: January, February, March, April, May, June, July, August, September, October, November, December.

@ Time (field name not displayed)

Select the time, in 24 hour format, that Daylight Saving Time begins. The time can be any time between 00:00 to 23:59.

Rule - Subtract Time

Configure when Daylight Saving Time ends according to the specified Rule. The properties are the same as described in Rule - Add Time.

Date - Add Time

Specify the specific Date that Daylight Saving Time begins.

Month (field name not displayed)

Select the month that Daylight Saving Time begins: January, February, March, April, May, June, July, August, September, October, November, December.

Date (field name not displayed)

Select the day of the month that Daylight Saving Time begins. The range of days depends on the selected month. January, March, May, July, August, October, and December are valid from 1 to 31. April, June, September, and November are valid from 1 to 30. February is valid from 1 to 29. Only select February 29 on a leap year.

@ Time (field name not displayed)

Select the time, in 24 hour format, that Daylight Saving Time begins. The time can be any time between 00:00 to 23:59.

Date - Subtract Time

Specify the specific Date that Daylight Saving Time ends. The properties are the same as described in Date - Add Time.

Amount of Time to Add or Subtract

Enter the amount of time, in minutes, that will be added when Daylight Saving Time starts and subtracted when Daylight Saving Time ends. You can enter any whole number between -120 to +120.

For example, to add one hour, enter +60.
