4.8.7 Security Settings

The Table below describes the Security node's settings.

Property

Description

Target Security

This property enables or disables Target Security for the target machine. Target Security prevents an unauthorized user from accessing secured panels, popup windows, function keys, and Parts on target machines.

Security Mode

Specifies how security levels are checked against the security group's security level value. Select either Level Based or Bitmask Based. For more information, see Defining Security Levels for Security Groups.

Logout Behavior

The Logout Behavior properties configure the duration of the Inactivity time-out and the panel that displays when the time-out occurs.

Inactivity Time-Out [min]:

Select the check box and specify the time, in minutes, for the inactivity time-out.

Unsecured Panel

Specifies the panel that displays when inactivity time out occurs on an unsecured panel.

Secured Panel

Specifies the panel that displays when inactivity time occurs on a secured panel.

Secured Object Behavior

These properties define the behavior for secured objects.

Display

Specifies the secured object's display:

  • Normal: The object displays normally.

  • Lock Icon: The object displays with a lock icon.

  • Gray Out: The object is grayed out.

  • Invisible: The object is invisible.

When Touch

Specify the action the system will take when an unauthorized user touches a secured object. You can specify the following actions:

  • No Change: No actions occur.

  • System Login Panel: The System Login Panel displays. For more information on the System Login Panel, see Section 4.8.4.1, Logging In at Run Time: System Login Panel.

  • Go To Panel: The selected panel displays.

Password Management

These properties define rules for password expiry, password strength, and password access attempts. Select Enabled to define the password management properties. For more information on managing passwords, see Section 4.8.4.3, Managing Passwords at Run Time.

Expire After (Days)

Specifies the number of days before passwords expire. Enter a value between 1 and 3650. The default is 30 days.

Not all targets support the Expire After (Days) feature. For a list of supported targets, see Appendix 5, Hardware Specifications.

Number of Attempts

Specifies the number of attempts an operator can enter an incorrect password. Any subsequent failed attempts will lock out the operator. Enter a value between 1 and 20. The default is 3.

Password Strength

Select Enabled to define the following password strength criteria:

  • Minimum Length: Specifies the password's minimum length. The value can be 3 to 32.

  • Compare with Previous: Specifies the number of previous passwords to keep track of in order to restrict the use of previously used passwords. The value can be 1 to 10.

  • Minimum Uppercase: Specifies the number of uppercase characters the new password must have. The value can be 1 to 32.

  • Minimum Lowercase: Specifies the number of lowercase characters the new password must have. The value can be 1 to 32.

  • Minimum Digits: Specifies the number of digits the new password must have. The value can be 1 to 32.

Download Security

This property enables Download security for the target machine. Once enabled, only authorized users can download projects to secured targets. For more information on downloading projects, see Section 25.6, Downloading the Project. For more information on Download security, see Section 4.8.2.2, Protecting Targets from Unauthorized Project Downloads.

USB Media Install

Once this feature is enabled, only authorized users can download projects to secured targets through USB keys. For more information on downloading projects, see Section 25.6, Downloading the Project. For more information on Download security, see Section 4.8.2.2, Protecting Targets from Unauthorized Project Downloads.

Data Manager Security

This property defines the Data Manager Security for the target machine. Data Manager Security is set to Deny Access by default; therefore, you must set up a valid user name and password to use the Data Manager to access the target's data.

Data Manager Security Options:

  • Deny Access - Users cannot access the target machine using the Data Manager.

  • Use Security - Users with the proper security rights can access the target machine using the Data Manager.

  • Anonymous - Users without passwords and usernames can access the target machine using the Data Manager.

For more information on Data Manager security, see Section 4.8.2.3, Protecting Targets from Unauthorized Data Transfers.

Data Manager security is only available for target machines with Data Manager Ethernet support. For a list of these targets, see Appendix 5 Hardware Specifications.

Web Gate / Web Server Security

This property enables Web Server and Web Gate security for the target machine. For more information on Web Server and Web Gate security, see Section 4.8.2.4, Protecting Web Server/Web Gate from Unauthorized Users.

This property is only available when Web Server is enabled in the target properties. This property is always available for the security server, except when using Common Security.

Security Data

This property is available when Use Common Security is enabled in the Project properties. It defines whether to use common or local security settings.

  • Use Local
    Select this option to use the locally-defined security groups and security users. The target machine will not interact with the Security Server to verify users.

  • Use Common
    Select this option to use the security groups and users defined on the Security Server.

For more information, see Section 4.8.6, Common Security.

Client / Server

This property sets the target machine to act as a security client or security server.

  • Common security is dependent on the availability of the Security Server. If the Security Server is unavailable, then users may have difficulty running secured operations on target machines set up as security clients.
