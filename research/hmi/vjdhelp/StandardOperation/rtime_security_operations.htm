4.8.4 Runtime Security Operations

Below is a list of methods for logging users in and out of target machines at run time and for password management.

Logging In

  • System Login Panel
    The System Login Panel logs users into target machines. See Section 4.8.4.1, Logging in at Run Time: System Login Panel.

  • Toolchest Part
    Toolchest parts are available to log users into target machines. See Section 4.8.4.1, Logging in at Run Time: Toolchest Login Part.

  • Script
    A script method is available to log users into target machines. See Section 4.8.4.1, Logging in at Run Time: Script Login.

Logging Out

  • Inactivity Time-Out
    The Inactivity Time-Out logs a user out of a target machine after the Inactivity Time-Out expires. See Section 4.8.4.2, Logging Out at Run Time: Inactivity Time-Out.

  • Logout Switch
    A switch can be configured to logout a user during run time. See Section 4.8.4.2, Logging Out at Run Time: Switch Logout.

  • Toolchest Part
    A Toolchest part is available to logout a user during run time. See Section 4.8.4.2, Logging Out at Run Time: Toolchest Part Logout.

  • Script
    A script method is available to logout a user during run time. See Section 4.8.4.2, Logging Out at Run Time: Script Logout.

Managing Passwords

  • Password Expiry
    When a password expires, the user needs to enter a new password. See Section 4.8.4.3, Managing Passwords: Changing an Expired Password.

  • Password Change
    A user needs to change a password after a first-time login or when the current password has been expired. See Section 4.8.4.3, Managing Passwords: Changing a Password.

  • User Lock-Out
    A user can only have a specified number of login attempts before being locked out. See Section 4.8.4.3, Managing Passwords: Exceeding the Number of Attempts to Log On.
