4.3 Creating Projects

4.3.1 About Projects

A project is a file that you create in Vijeo-Designer.

A project includes all the information that you need (such as drawings, alarms and hardware information) to create an environment for your user application.

  • Fonts used by text objects you've drawn on the screen are not included as part of the project, as each target machine uses its own font sets. Vijeo-Designer displays the text in the font specified. However, if the target machine does not have the font that was used to create the project, the characters displayed on the target machine may be corrupted or another font set which most closely resembles the defined font may be substituted.
