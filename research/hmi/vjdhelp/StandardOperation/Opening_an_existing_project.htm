4.6 Working with Projects

4.6.1 Opening an Existing Project

  1. In the Vijeo-Designer dialog box, select Open Existing Project, and click Next

The Open Existing Project dialog box opens.

  1. Select the project that you want to open. Click Open.

The selected project opens in the Project tab of the Navigator tool window.

  • Alternatively, you can either select the project you want in the Vijeo-Manager tab of the Navigator window, and then double-click or click to open the project.

  • If you try to open another project when a project is already open, a dialog box opens, asking if  you want to save the project currently open.

  • When you open an older project in a current version of Vijeo-Manager, a warning message appears. Click Yes to update and open the project in the current version. Once you update the project, you will not be able to open it in previous versions.
