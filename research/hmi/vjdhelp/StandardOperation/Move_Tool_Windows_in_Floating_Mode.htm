4.10.1.2 Docking Tool Windows

To move a tool window to a global docking region.

  • Place your cursor on the title bar of the tool window, and drag it to the global docking region you want. The docking region becomes shaded when you drag the tool window close to one of the following docking icons:

Icon

Description

Docking control. Docks the tool window to a top, bottom, left, or right region of a window.

Centre docking region icon. Docks the tool window in the region where your cursor is positioned, and changes the tool window that was in that region to a tab.

Top docking region icon. Docks the tool window in the top region of the window view.

Bottom docking region icon. Docks the tool window in the bottom region of window view.

Left docking region icon. Docks the tool window in the left region of the window view.

Right docking region icon. Docks the tool window in the right region of the window view.

  • If you double-click the title bar of the tool window, it becomes a floating tool window again. If you double-click the title bar of the floating tool window, it moves to the last region it was docked on.
