4.10.2 Using Toolbars

Vijeo-Designer provides several toolbars to help make the designing, editing, and display functions more convenient to use. Click the toolbar icons to access those functions.

Vijeo-Designer has two categories of toolbars:

  • Basic Editor Toolbars. Provides the tools you need for project development, such as editing files.

  • Special Editor Toolbars. Provides the tools you need for creating panels.

  • When you place your cursor over an icon, a tool tip is displayed to describe what the icon is.
