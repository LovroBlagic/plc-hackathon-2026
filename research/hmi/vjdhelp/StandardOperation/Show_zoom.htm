4.9.2 Using Zoom

You can change the panel display size when you draw.

Zooming to a Specific Magnification

  1. Right-click the panel, select Zoom, and then select the zoom ratio you want.

  1. The panel is displayed in the specified size.

Zooming into a Specific Area Using the Zoom Tool

  1. Right-click the panel to bring up the shortcut menu, select Zoom Tool.

  1. Define the area you want to enlarge by clicking and dragging.

    The specified area is enlarged.

  • If you create a text object on the panel and then zoom the panel display out to 50% or 75%, the text in the object may appear to word-wrap, when in fact it has not. Zooming the panel display back in to a 100% or greater magnification will get rid of the text object's word-wrapped appearance.
