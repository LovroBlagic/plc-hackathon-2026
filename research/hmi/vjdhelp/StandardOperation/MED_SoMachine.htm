4.13.11 Using SoMachine MED Toolchest Parts

The Machine Energy Dashboard (MED) Toolchest parts are a convenient set of faceplates that represent the data from energy management function blocks in SoMachine.  

To use MED Toolchest parts, you must install Vijeo Designer 6.1 or later. In the Vijeo Designer Stand-Alone configuration, you can link MED parts to standard PLC registers to directly monitor energy usage. For more information, see Example: Monitoring PLC Registers Using MED Toolchest Parts. Alternatively, you can link MED Toolchest parts to their counterparts in SoMachine V3.1 or later. For more information on how to set up MED on SoMachine, see the SoMachine online help.

To add a MED Toolchest part to your project:

  1. In Vijeo Designer, click the Toolchest icon in the menu bar to open the Toolchest window, select the SoMachine folder and then the MED folder to display the MED Toolchest parts.

  2. Drag and drop the MED part onto the panel. The Placeholder dialog box opens.

  • Each MED Toolchest part is a grouped object. You can configure objects in the group by ungrouping them. Alternatively, in the Graphics List, you can expand the group and modify each object.

  1. In the Placeholder dialog box, click the Placeholder cell to enter or update the Placeholder name. The Placeholder name must start and end with a $ sign, for example $SoM.AOUWdgtVal$. For more information, see Section 21.2.4, Working with Variable Placeholders.

  2. Still in the Placeholder dialog box, click the Replace Variable cell to enter or update the variable. Alternatively, you can click the image next to the cell to open the Variable List dialog box, where you can browse and select a Structure variable.

  1. MED parts allow you to enter invalid variables. You can fix such errors in the Graphics List. For more information, see Section 21.3, Editing Objects with the Graphics List.

  1. Click OK to apply the changes and close the dialog box.

  2. Build and download the project to the target machine and to SoMachine.

Example: Monitoring PLC Registers Using MED Toolchest Parts

For example, you want to monitor device addresses in Modbus TCP/IP equipment using the InstantPower MED Toolchest part:

  1. Add the Modbus TCP/IP driver to your project and configure the driver settings. For more information, see Section 5.2, Setting Up You Equipment.

  2. Create two Structure variables: InstantPower_P and InstantPower_V. For more information, see Section 6.12, Structure Variables.

  3. Add elements for InstantPower_P and InstantPower_V. For more information, see Section 6.2.4.2, Creating Structure Data Types. The number of elements and their data types should match those of InstantPower MED Toolchest part, SoM.IPWdgtPara and SoM.IpWdgtVal.

  4. From the Toolchest window, SoMachine\Machine Energy Dashboard folder, drag and drop the InstantPower part to the panel. The Placeholder dialog box opens.

  5. In the Placeholder dialog box, click the Replace Variable cell for SoM.IPWdgtPara and type in InstantPower_P.

  6. Repeat step 5 for SoM.IpWdgtVal, and replace it with InstantPower_V.
