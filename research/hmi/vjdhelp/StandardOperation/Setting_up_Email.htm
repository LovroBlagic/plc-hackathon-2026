4.14.1 Setting up the E-mail Server

Follow the instructions below to configure your E-mail SMTP (Simple Mail Transfer Protocol) server settings. The instructions below assume that you already have an SMTP server setup for sending E-mail.

  • Note that Vijeo Designer's E-mail feature only supports SMTP. The E-mail feature will not work if the E-mail server it communicates with requires add-ons, such as SSL or other security features.

 

  1. In the target properties, enable E-mail and click the ellipsis button.

  2. In the E-mail dialog box, configure the following server properties:

Property

Description

IP Address/Name

Enter the IP Address of the SMTP server or enter the host name of the SMTP server. You can enter 1 to 50 characters.

  • To use a host name for a SMTP server, you must have a DNS server available on your network that is configured with the SMTP host name and IP Address. For more information on DNS, see Section 4.5.1, Target Properties.

Port

Enter the TCP port used by the SMTP server. Generally port 25 is used. The valid range for the port is 0 to 65535.

Authentication

Authentication may be required by your SMTP server.

  • Login - Login to access the SMTP server.

  • Password - Password to access the SMTP server.

Login

Enter the login ID for the SMTP server. You can enter 1 to 32 alphanumeric characters.

Password

Enter the password for the login ID. You can enter 1 to 32 alphanumeric characters.

Sender Name

Enter the name of the sender of the E-mail. You can enter 1 to 50 characters.

Reply Address

Enter the E-mail address to which an E-mail recipient can reply to. You can enter 1 to 100 characters.

Retry Count

Enter the number of times Vijeo Designer E-mail will attempt to re-send E-mail if a failure occurs. You can enter a value from 1 to 10.

Time before retry to send (in seconds)

Enter the time, in seconds, Vijeo Designer E-mail waits before re-sending an E-mail. You can enter 1 to 300 seconds.

 

  1. Click OK to set the defined properties.
