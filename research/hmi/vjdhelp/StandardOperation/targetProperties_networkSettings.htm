Read-only property that identifies the target model selected for the application to run on. For more information, see Section 4.5.1.1, General.

Network Configuration

Click the ellipsis to open the Network Configuration dialog box, where you can define the network settings for the target machine.

Network Configuration is set up for target machines that support single LAN or dual LAN ports. Ethernet 2 configuration is enabled for dual LAN target machines and disabled for single LAN target machines. To obtain a list of target machines that support dual LAN ports, see Appendix 5, Hardware Specifications.  

IP Address

Enter the IP address the target machine will use at runtime.  

If Download is File System, you need to set the Path, and Format. If an IP address is not entered, the default IP address of 0.0.0.0 will be set. By setting it to the default, all the Schneider equipment would operate in the same way.

If Download is Ethernet, Vijeo-Designer downloads the user application to this IP address. If the IP address is set to the default, the download will not occur.

For a USB or CF Card/SD Card download, if the IP address is set to the default, the download will occur. However, during the download, the Editor will change the IP address to 127.0.0.1. After the download, when you boot up the target machine, the IP address will automatically change to 10.10.x.y, where x and y are decimal values converted from the last two groups of numbers (two hexadecimal digits) from the MAC address of the target.

 

  • When using data sharing, variables shared by the target machine are compiled with this IP address. See Section 22.1, Sharing Data Between Tablets, Smartphones, and Target Machines.

  • If using an target machine that supports dual Ethernet ports, in the IP Address field you can type either IP address supported by the target machine. The IP address defined in this field is used for downloading, communicating with the Data Manager tool, and for Data Sharing.

  • If the IP address does not match the IP address class (A, B, or C) as indicated by the Subnet Mask, the target machine may halt during operation. For valid IP address configuration, see your network administrator. If your target supports supernetting, the IP address class does not need to match the subnet class. For a list of the targets that support supernetting, see Appendix 5, Hardware Specifications.

Default Gateway

DHCP/Host Name

When enabled, the target machine automatically retrieves an IP address from your network's DHCP (Dynamic Host Configuration Protocol) server at run time. This saves you from manually configuring the network settings on the target machine.

  • If Download is set to Ethernet, you need to enter the target machine's IP address to download the application to the target machine. At run time, the DHCP server may assign a different IP address to the target machine.

  • Enabling DHCP hides the target node's Subnet Mask, Default Gateway, and DNS properties. These settings are configured by the DHCP server.

Not all target machines support the DHCP feature. For a list of target machines that support this feature, see Appendix 5, Hardware Specifications.

Host Name

This feature sets the target’s host name and registers the target’s host name and IP address with your network’s DNS server. This feature requires you have a valid DHCP server synchronized with a DNS server on your network. Contact your network administrator for information on your network’s DHCP and DNS server.

Once the project downloads, the host name sets on the target and registers with the DHCP server. If the host name does not exist on the DHCP server, the DHCP server registers the host name and IP address on the synchronized DNS server. Host names must follow DNS host naming conventions. For more information on these conventions, see Appendix 9 Naming Conventions.

  • Setting the host name from this feature requires you have a DHCP server synchronized with a DNS Server on your network.

  • You can define the target's host name at runtime from the target's offline configuration menu. For more information, see Section 26.3.1.1, DHCP Settings.

DNS / IP Address

Enable DNS support and set the DNS server's IP address. Contact your network administrator for more information on your DNS server.

Not all target machines support the DNS feature. For a list of target machines that support this feature, see Appendix 5, Hardware Specifications.

Allow Setting IP Address at Run Time

Select the check box next to Allow Setting IP Address at Run Time to create a Set IP Address operation in the Editor. This feature allows the operator to change the target machine's IP address at run time.

This is not available when the DHCP property in the Target properties is set to Enabled or you have selected a target type that does not support this feature. For a list of target machines that support this feature, see Appendix 5, Hardware Specifications.

Allow Ethernet Download & Upload at Run Time

Clear this check box to protect the target machine from being updated after the project is successfully transferred to the target machine and the target machine is restarted.

The following operations are disabled when this check box is cleared:

  • Download/Upload project

  • Download/Upload recipes and recipe groups

  • Install or update run time with Runtime Installer

  • Send or retrieve files using the Data Manager, Data Transfer Tool (command prompt), or other FTP client

  • System provided methods to view configuration menu.

If you select this check box, a warning message appears describing the risk associated with enabling Ethernet download and upload. Use this setting only while debugging your project, updating the project or run-time system, or working with recipes and data files. Once the project is ready for use in a normal operation environment, clear this check box and download the project to the target machine.
