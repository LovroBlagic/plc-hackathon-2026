Keypad Decimal Point

Set up how you want the decimal point to display on the Numeric Keypad. Select Fixed or Move Floating. The Numeric Displays in the examples below have their display digits set to 4.2.

  • Fixed Decimal Point: The number of decimal places is fixed. For example, if you type 135, the Numeric Display displays 1.35

    If you type 13.5 in the field, the Numeric Display displays 13.50.

  • Floating Decimal Point: The decimal point is floating. For example, if you type 13.5, the Numeric Display displays 13.50.


    If you type 135, the Numeric Display displays 135.00.

System Keypad

Use these target properties to define system keypad settings. For more information, see Section 11.9.2, Types of System Keypads.

String Keypad Layout

Select Standard Keyboard, Alphabetical Order, or Compact (Multi-page).

Key Size

Specifies the key size for the target screen size. This property is hidden if the target screen size is less than 640x480. The default key size is automatically selected for your target screen size. For key sizes that are supported by targets and string keypad layouts, see Section 11.9.2, Types of System Keypads.

Key Label Color

Select the color for each area on the keypad. The Color palette displays when you click the color area. You cannot set transparent color for the keypad.

  • When you enter an invalid value on a color target machine, the Text Display Color turns red. Make sure you select a Text Display Color that is visible when the Display Area Back Color is red.

  • For monochrome targets, the Display Area Back Color blinks to indicate invalid values.

Function Keys

Configures the Target Function Keys for the target machine.

This feature is available for targets that support Function Keys and targets that support USB Keyboards. See Appendix 5, Hardware Specifications for a list of targets that support Function Keys and USB Keyboards.

Click the ellipsis button to display the Target Function Key dialog box. For more information on Function Keys, see 24.5 Function Keys.

Buzzer On Touch

Set the system buzzer to sound when the panel operator presses a Function Key on the target machine.

Label Print

Label templates have been provided so users can create their own labels for their target machine's function keys. For more information on using this feature, see Section 27.2, Customizing and Printing Target Function Key Labels.

Touch Screen Input

Set the property to Enabled to perform touch operations on the panel. For a list of the targets that support panel touch, see Appendix 5, Hardware Specifications.

If you want to disable panel touch operations and allow only keyboard operations, set this property to Disabled.

Control Mode

Set the Control Mode for the Target Function Keys:

  • Target Setting - This mode provides full functionality and support for Function Keys and Function Key LEDs. This mode is the default setting for all Vijeo-Designer applications that do not use the Dialog Table to control Function Keys and LEDs.

  • Dialog Table - This mode enables the Dialog Table to control the Function Keys and Function Key LEDs. When this mode is enabled, users will be able to configure up to 12 Target Function Keys and select from either Bit or Panel for their Function Key operations. Function Key LEDs setup is configured in the Dialog Table. This mode is the default setting for users who have converted their XBTL1000 projects into a Vijeo-Designer project and are continuing to use the Dialog Table. For more information on the Dialog Table, see Section 5.6, Working with the Dialog Table.

Operation Switch

The Operation Switch (O.P) helps prevent accidental touch inputs. When this feature is enabled, panel and function key touch operations are disabled on the target until the operator presses and holds down the Operation Switch. Once the Operation Switch is held down, panel and function key touch operations can run. When the operator releases the Operation Switch, panel and function key touch operations become disabled.

 

When the Operation Switch property is disabled, panel and function key touch operations will run normally without requiring the Operation Switch to be held down.

 

For more information on the Operation Switch, see Appendix 5.9.5, XBTGH Series Function Keys: Operation Switch.

See Appendix 5, Hardware Specifications for a list of targets that support the Operation Switch.

LED Control

Configures the colors and blink rates used for the Function Key LEDs. For a list of target machines that support LEDs, see Appendix 5, Hardware Specifications.

 

There are two LED Control methods:

  • Auto: Select the LED's colors and the blink rates in the LED Control drop-down list. For more information, see Section 24.5.3.1, LED Control Auto.

  • Manual: Use variables to define the LED's colors and blink rates. For more information, see Section 24.5.3.2, LED Control Manual.
