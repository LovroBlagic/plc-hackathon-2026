4.8.2.3 Protecting Targets from Unauthorized Data Transfer

Data Manager Security stops unauthorized users from using the Data Manager or the Command Line to transfer data to and from a secured target machine. For more information on the Data Manager and the Command line, see Section 20.5, Managing Run-time Data. Data Manager Security must be set to Use Security before you configure the Data Manager Security rights for security groups. You can also set Data Manager Security to accept anonymous users (users without user names and passwords). For more information on Data Manager security settings, see Section 4.8.7, Security Settings.

 

Security groups can be set up with the following types of Data Manager security:

  • Read - The security group can use the Command Line or the Data Manager to retrieve data from a target machine.

  • Read/Write - The security group can use the Command Line or the Data Manager to retrieve data from their target machine and send recipe files to the target machine.

  • Read/Write/Delete - The security group can use the Command Line or the Data Manager to delete data files on a target machine.

To set up a security group with Data Manager Security:

  • In the Security Editor, use the Data Manager drop-down list select the type of Data Manager security for the security group.
