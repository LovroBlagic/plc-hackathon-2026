4.11.3 Closing a Project

  1. In the Project tab of the Navigator window, right-click the Project node of a project you want to close and select Close.

  • You can also select Close Project from the File menu.

  • If the project is not yet saved, a dialog box opens asking if you want to save the changes you made to the project.

  • Click Yes to save and close the project as it is currently displayed.

  • Click No to close the project without saving any changes made to the project since the last save.

  • Click Cancel to return to the project's current display—without saving any changes.
