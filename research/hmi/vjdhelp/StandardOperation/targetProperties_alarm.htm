4.5.1.8 Alarm

Property

Description

Type

Read-only property that identifies the hardware platform selected for the application to run on. For more information, see Section 4.5.1.1, General.

Model

Read-only property that identifies the target model selected for the application to run on. For more information, see Section 4.5.1.1, General.

Alarm Banner

Set to Enable to set up the alarm messages that scroll across the panel. For more information, see Section 16.4, Alarm Banner.

If Alarm Banner is set to Enable, define the following properties.

Alarm Group

Define the alarm group or alarm category that the alarm banner displays.

Position

Set up the display position of alarm messages. The position can be Top, Middle, or Bottom.

Font

Define the font for alarm messages.

BackColor

Set up the background color of alarm messages.

TextColor

Set up the color of the alarm message text.

3D Color

Only available if 3D is selected for the Font Style in the Label tab.

Define the 3D text's shadow color.

Display Message

To reset the Alarm Banner messages, use one of the following three methods to terminate the banner messages. For more details on terminating conditions, see Section 16.4.4, Ending Alarm Banner Messages.

  • Only Once

  • Stop when RTN

  • Scroll to end when RTN

  • Stop when UNACK or RTN

Scroll Rate

You can choose slow, medium, or fast for the speed of the Banner messages

The speeds are as follows:

  • Fast: 200ms

  • Medium: 400ms

  • Slow: 800ms

Move Button

Enables a move button that moves the alarm banner up the screen when pressed.
