4.13.2.2 Using Vijeo Designer Variables in SoMachine

A variable created in Vijeo Designer can be moved and used in a SoMachine project. Be aware of how Vijeo Designer variable types are moved into SoMachine variable types. For more information, see the table Vijeo Designer Variable types to SoMachine Variable Types shown below.

To move a variable from Vijeo Designer to SoMachine:

  1. In the Variable Editor, right-click the variable or group of selected variables, and select Move to SoMachine.

  2. In the Move to SoMachine dialog box, specify where to move the variables into the SoMachine project and click OK.

The moved variables will be updated in the Variable Editor to show their new hierarchical location in the SoMachine project.

  • Once a variable is moved to SoMachine, you cannot undo the move.

  • When moving an external variable to a SoMachine project, the associated driver will change to the appropriate SoMachine driver.

  • SoMachine and Vijeo Designer variables may become unsynchronized. To synchronized the variables, build the SoMachine application. Building refreshes and synchronizes the variables.

  • The following types of Vijeo Designer variables cannot be moved to SoMachine:

  • Structures

  • Elements of Structures

  • Arrays

  • Elements of Arrays

  • Block Variables

  • System Variables

  • Reference Variables

  • Variables with indirect addresses

  • Variables inside folders can be moved to SoMachine, however the folder structure will not be maintained during the move.

  • Other types of Integers that are not listed in the table above cannot be moved to SoMachine.

  • You cannot cut, copy and paste variables between SoMachine and Vijeo Designer.
