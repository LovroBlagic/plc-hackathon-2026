4.8.2.1 Protecting Panels and Parts from Unauthorized Users

Target Security stops unauthorized users from accessing secured panels, popup windows, function keys, and Parts (Switch, Numeric Display, String Display, Message Display, Image Display, Meter, Bar Graph, and Selector). Target Security has two types of security modes: Level Based and Bitmask Based.
