4.8.6 Common Security

Common Security is a way to organize security groups and security users for multiple target machines from a single location. Without Common Security, you have to set up security users and security groups individually on each target machine.

Common Security is available for all target machines that support Ethernet. For a list of targets that support Common Security, see Appendix 5, Hardware Specifications.

To use the Common Security feature, you can:

  • Set up Common Security in the Vijeo Designer editor. For more information, see Section 4.8.6.1, Setting Up Common Security.

  • Change the Common Security groups and users from the target machine at run time. For more information, see Section 4.8.4.3, Managing Security Users at Run Time.

Common Security applies to security settings defined in the security editor. See Section 4.8.7, Security Settings. You cannot configure Common Security for project security or recipe security. For more information, see Sections 4.8.8, Adding Project Security or 17.8, Setting Up Security for Recipes.

  • The Biometric Switch and the Common Security features cannot co-exist in a project.
