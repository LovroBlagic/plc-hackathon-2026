4.10.2.1 Basic Editor Toolbars

The basic toolbars are:

  • File toolbar

  • Edit toolbar

  • InfoViewer toolbar

  • Tools toolbar

File Toolbar

The File toolbar contains the icons you need to work with projects.

Icon

Name

Functionality

New Project

Creates a new project.

Open Project

Opens an existing project.

Save

Saves a project.

Print

Prints various report information.

Validate Target

Checks the entire project for errors.

Build Target

Builds the entire project.

Download Target

Transfers a project to target machines.

Simulate

Performs the project simulation.

Edit Toolbar

The Edit toolbar contains the icons you use to edit projects.

Icon

Name

Functionality

Undo

Cancels the previous command and returns to the state before the operation. You can undo multiple operations.

  • Undo does not handle changes in fonts.

Redo

Performs the command just cancelled by Undo.

Cut

Cuts out a selected panel, script, or object, and places it into the clipboard.

Copy

Makes a copy of a selected panel, script, or object, and places it into the clipboard.

Paste

Pastes the information placed into the clipboard by the Cut or Copy command.

Duplicate

Copies and pastes multiple copies of the selected object.

Delete

Deletes a selected panel, script, or object.

Edit Text

Opens the Edit Text dialog box for a selected text object.

Animation

Opens the Animation Properties dialog box for a selected object.

 

InfoViewer Toolbar

The InfoViewer toolbar contains the icons you need to move or view the information displayed in the InfoViewer window.

Icon

Name

Functionality

Back

Moves one step back in the previous displays.

Forward

Moves one step forward in the display history.

Stop

Stops receiving information from the Internet.

Refresh

Updates the information currently on display.

Home

Opens the start page for InfoViewer.

New Address

Allows you to edit a URL. Click the icon to open the dialog box, and enter or edit the URL. When you click OK, the URL information you entered is displayed in the InfoViewer.

Tools Toolbar

The Tools toolbar contains the icons for the six tool windows.

Icon

Name

Functionality

Property Inspector

Shows or hides the Property Inspector window.

Graphics List

Shows or hides the Graphics List window.

Feedback Zone

Shows or hides the Feedback Zone window.

Toolchest

Shows or hides the Toolchest.

Navigator

Shows or hides the Navigator window.

InfoViewer

Shows or hides the InfoViewer window.

For more information, see Section 4.4.2 Editor Tools.
