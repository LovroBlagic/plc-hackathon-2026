4.5.2 Adding, Deleting, Changing, or Copying Targets

You can add, delete, change, or copy target machines to one or more projects; and within the same project, you can create applications for one or more target machines. By creating multiple user applications in the same project, the user applications can reference data from any of the other user applications.
For more information, see Section 22.1, Sharing Data Between Tablets, Smartphones, and Target Machines.

4.5.2.1 Adding a Target

  1. In the Project tab of the Navigator window, right-click Project and select New Target.

  1. In the Create New Target dialog box, select the Target Type and Model, then click Next to define target properties.

  1. Click Finish to add the target to your project.

  • The recommended maximum number of targets added to one project is 32.
