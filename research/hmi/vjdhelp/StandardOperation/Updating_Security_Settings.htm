4.8.6.2 Updating Common Security Targets

After the project is configured and user applications are downloaded to the target machine, you may want to configure another target machine with Common Security or change the security server.

Adding a Client Target

  1. For newly added Targets, configure Common Security. See Section 4.8.6.1, Setting Up Common Security.
    -or-
    For existing Targets, from the Navigator window select the Security node and view its properties. Change Security Data from Use Local to Use Common.

  • All previously configured security settings are now replaced by the common security settings.

  1. Download the project to the newly added or changed target. As long as there are no changes to the common security settings or changes to the security server, downloading to other target machines is not required.

Changing the Security Server

  1. From the Navigator window's Project tab, select the Project node and view its properties.

  2. In the Security Server property, select a target machine. This unit must be online for panel operators to run secured operations on the target machine.

  3. Download the project to all targets in the project.

  • To preserve security groups and security users configured at run time, in the Target node's Download properties, set Preserve Run-Time Data to Enabled.

  • If you change any of the following properties in the security server's Target, you need to download the project again to all target machines configured with common security:

  • Target IP address

  • DHCP

  • Host Name
