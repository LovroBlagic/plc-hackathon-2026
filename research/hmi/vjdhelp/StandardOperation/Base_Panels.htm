4.7.1 Base Panels

When you create a project, Vijeo-Designer automatically creates a panel in the Base Panels folder under the Graphical Panels node in the Navigator window. On a panel, you can place switches and lamps, or draw other objects. The panel you create becomes the display screen on target machines.

You can create a panel folder to control a group of  panels. You can copy or move panels between the panel folders and master panel folders. For more information on panel folders, see Section 4.7.1.2, Working with Panel Folders.

In a project, when you click Base Panels, the thumbnail view opens, displaying the thumbnails for panels and panel folders.

Opening a Thumbnail

To open a folder in the thumbnail view:

  • Double-click the folder thumbnail. The folder opens to display a thumbnail view of the panel folder contents.

To open a panel in the thumbnail view:

  • Double-click the panel thumbnail.

Thumbnail View Toolbar

The thumbnail view toolbar provides you with these functions:

  • Display the current path.

  • Change to a large thumbnail size.

  • Change to a small thumbnail size.

  • Go up one level.
