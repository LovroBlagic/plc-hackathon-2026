4.8.6.1 Setting Up Common Security

  1. In the Navigator window, select the Project node and view its properties.

  2. Set the Use Common Security property to Enabled.

  3. In the Security Server property:

    • Select the target machine that will act as the Security Server. When used at run time, the selected target machine must be online to enable common security.

    • Optionally, define the other common security properties in the Project node. For information about the Project node's property settings, see Section 4.3.2, Creating a New Project, Project Properties from the Project Tab.

  4. In the Navigator window under Target node, expand the Environment node and select the Security node to view its properties. For information about the Security node's property settings, see Section 4.8.7, Security Settings.

  5. In the Security Data property, select Use Common to set up the Target to use common security. Notice the Client / Server property is now fixed to Client.

  • If the Target you are setting up is the Security Server, then the Security Data is fixed to Use Common, and Client / Server is fixed to Server.

  1. In the security editor, define the security settings by:

    • Adding the security groups and security users. See Sections 4.8.2, Creating Security Groups and 4.8.3, Creating Security Users.

    • Defining the security properties. See Section 4.8.7, Security Settings.
