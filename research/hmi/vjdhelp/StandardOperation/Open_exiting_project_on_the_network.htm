4.6.4 Opening an Existing Project on the Network

Vijeo-Designer allows you to make project files stored in a PC accessible to other computers on the network. To do this, create a network, which is a special folder that connects to other folders on the network, to store a project. This feature is useful when you want to have a number of people to share a project.

  • A project stored on the network cannot be concurrently opened or edited by more than one user.

  • You can create a new project in a network link in the same way in any other folders. You can also drag-and-drop projects to add, or delete any project.
