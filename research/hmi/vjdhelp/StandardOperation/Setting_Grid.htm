4.9.3 Setting the Grid

A grid is made of either lines or dots. Grids help users to align objects and measure objects in a project.

  1. Right-click the panel to access the grid settings.

You can also set grid settings in the Graphical Panels properties and in the Popup Windows properties.

  1. Define your grid settings.

Property

Description

Show Grid

The grid consists of dots or lines shown on the panel at equal spaces, helping you draw or place objects on the panel.

  • Line or Dot: The grid is shown on the panel. In Runtime, the panel does not show the grid.

  • None: No grid is shown.

Show Ruler

The rulers are provided as reference for layout work. They show the exact horizontal and vertical position of an object placed on the panel.

  • True: The rulers are shown on the top and the left side of the panel. The position is indicated in dots.

  • False: No rulers are shown on the panel.

Snap To

Specify how you want to align objects to the grid, either Snap To Grid or Snap To Matrix.

  • Snap To Grid

If you place three of these squares horizontally, they will be aligned with their borders overlapping by one dot, as shown below.

  • Snap To Matrix

When you select Snap To Matrix, four dots, laid out as shown below, are treated as a single grid point.

If you place three of these squares horizontally, they will be aligned without their borders overlapping.

  • If you overlap touch-enabled objects with each other, you may disable the touch function of the overlapped object. Prevent this by using Snap To Matrix and place the objects without overlapping any of its borders.
    For more information, see Section 9.2.8, Troubleshooting a Switch.

GridXSpacing

GridXSpacing defines the amount of spaces (shown in dots) for the horizontal grid. GridYSpacing defines the amount of spaces (shown in dots) for the vertical grid. When setting these properties, use a value between 1 and the Maximum. The Maximum is one-half of the height defined in the Panel Size for the target machine. For example, if you select SVGA 800 x 600 in the Panel Size field, the value of the Maximum is 300 (Y) and 400 (X).
