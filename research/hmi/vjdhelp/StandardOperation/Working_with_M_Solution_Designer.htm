4.13 Working with SoMachine

About SoMachine and Vijeo Designer

Be aware of the distinction between SoMachine and Vijeo Designer. SoMachine designs applications for the XBTGC's controller and applications for PLCs, whereas Vijeo Designer designs HMI applications for target machines. When SoMachine and Vijeo Designer are installed together, Vijeo Designer becomes the editing environment for SoMachine’s HMI applications. For information on how to program the XBTGC controller and other PLC applications, see SoMachine's online help.

 

Key SoMachine and Vijeo Designer processes:

  • Using Variables: Use SoMachine variables in Vijeo Designer

  • Importing/Exporting Projects: Import and Export Vijeo Designer projects to and from SoMachine

  • Downloading HMI Applications: Download SoMachine HMI Applications to targets

  • Start/Stop/Lock the Controller: Start/Stop/Lock the Controller from the HMI application

  • Monitoring Controller Status: Monitor the status of the controller from the HMI application

  • Creating HMI Applications: Create HMI applications from SoMachine

  • Viewing SoMachine Log Files: Display log file contents at Runtime

  • Reporting: Create reports from SoMachine on HMI variables, panels, and actions

  • Saving, Closing, Opening HMI applications: Standard Vijeo Designer Operations within SoMachine

  • Using SoMachine MED Toolchest Parts: Use Machine Energy Dashboard (MED) Toolchest parts in your SoMachine application so operators can measure and monitor energy efficiency
