4.10.1.1 Setting View Modes for Tool Windows

To enable you to customize your Vijeo-Designer working environment, you can set individual tool windows to display in one of these view modes:

  • Docking Mode. The example below displays Vijeo-Designer tool windows (Navigator, Property Inspector, InfoViewer, Graphics List, Feedback Zone, and Toolchest) as Docked.

  • Floating Mode. The example below displays the Property Inspector in the Floating mode. The floating window is always available in the foreground.

 

To set the view mode for a tool window:

  1. In the tool window's title bar, click the drop-down list icon to open the menu.

  1. Select Docking or Floating.
