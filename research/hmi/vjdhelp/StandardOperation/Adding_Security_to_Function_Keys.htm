Adding Security to Function Keys

Set up your security groups before adding security to function keys. See section 4.8.2, Creating Security Groups. For more information on security levels, see Defining Security Levels for Security Groups.

To add security to a Target Function Key:

  • In the Target Function Key dialog box, select the function key in the function key list and use the Security Level drop-down list to select the security level for the function key.

For more information on the Target Function Key dialog box, see Section 24.5.1, Target Function Key.

  • To set up security for Panel Function Keys, apply security to the panels that have Panel Function keys defined for them. Only users who have security levels high enough to access the panel, will be able to run the Panel Function key operations associated with the panel. For more information on Panel Function Keys, see Section 24.5, Function Keys. For more information on setting up panel security, see Adding Security to Panels and Popup Windows.
