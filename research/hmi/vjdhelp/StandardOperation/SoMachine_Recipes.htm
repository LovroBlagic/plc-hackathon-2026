4.13.10 SoMachine Recipes

 

During run time, you can create, update, and delete SoMachine recipes stored on the controller from the HMI application. The toolchest part, SoMachine Recipe Manager, interacts directly with the controller's recipe file and the apply, save, and delete recipe function blocks.

For information on:

SoMachine Recipe Manager part - See Section 17.4.1.5, Creating the SoMachine Recipe Manager

SoMachine Recipe Manager Run Time Operations, see 17.6.10, Working with SoMachine Recipes at Run Time.

SoMachine recipes and function blocks, see the SoMachine online help.
