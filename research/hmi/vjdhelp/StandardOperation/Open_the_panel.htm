4.7 Working with Graphical Panels

The Graphical Panels node provides the following types of panels:

  • Base Panels—A panel is your canvas on which you can draw objects and place Toolchest parts.

  • Popup Window Panels—On a popup window panel, you can draw objects and place Toolchest parts. You can open the popup window panel over the current panel during Runtime using a switch, Touch animation, or script.

  • Master Panels—On a master panel, you can draw objects and place Toolchest parts, to create a panel of common objects that can be used for all base panels in a project.

  • If you right-click a panel that you want to open and select Open In New Window, the panel will open in the new window separate from the window in which another panel is already open. You can toggle between the two windows using a Window menu.
