4.8.2.5 Setting Up Security Group Authentication

The Password/Fingerprints column specifies the run-time login method for a security group. To set it up:

  1. Create a security group. For more information, see Section 4.8.2, Creating Security Groups.

  2. In the Security Editor, click the Password/Fingerprints cell to expand the list.

  3. Select one of the following:

    • Password: Users in the security group must provide their user names and passwords to log in to the target machine.

    • Fingerprints: Users in the security group must provide their fingerprints to log in to the target machine.

    • Either: Users in the security group must provide either their user names and passwords or their fingerprints to log in to the target machine.

    • Both: Users in the security group must provide both their passwords and their fingerprints to log in to the target machine.

    • When you choose Fingerprints or Both, at run time, you must have a functional biometric switch connected to your target machine to be able to log in.

    • You need a user name and password to log in to the target machine using Web Gate. To use Web Gate, set the authentication method to Password or Either.

    • If you choose Either authentication method and at run time you exceed the number of attempts to log on using your password, you can still log on with your fingerprint. However, you need to reactivate your account to be able to log on with your password. For more information on how to reactivate your account, see Section 4.8.4.3, Managing Passwords at Run Time: Exceeding the Number of Attempts to Log On.

    • If you choose Either authentication method and enable password expiry, you will be prompted to change your password when you try to log on using your password. For more information on how to change expired passwords, see Section 4.8.4.3, Managing Passwords at Run Time: Changing an Expired Password.

  1. Save, build, and download your project to the target machine.
