4.13.2.1 Using SoMachine Variables in Vijeo Designer

A variable created and published from a SoMachine project becomes automatically available in the associated Vijeo Designer HMI project. See SoMachine's online help for information on publishing SoMachine variables. The variable can then be used and accessed as a regular Vijeo Designer variable. For more information, see Selecting SoMachine Variables in Vijeo Designer HMI Applications below. Be aware of how SoMachine variable types are moved into Vijeo Designer variable types. For more information, see the table SoMachine Variable Types to Vijeo Designer Variable Types shown below.

 

Selecting SoMachine Variables in Vijeo Designer HMI Applications

When a SoMachine variable is published, you can access the variable in Vijeo Designer the same way you access other Vijeo Designer variables by using the Expression Editor Pad and the Variable List dialog boxes. For more information on these dialog boxes, see Section 6.14, Assigning Variables Using Expressions.

  • SoMachine and Vijeo Designer variables may become unsynchronized. To synchronized the variables, build the SoMachine application. Building refreshes and synchronizes the variables.

  • Deleting a variable from SoMachine will cause the corresponding variable to be deleted from Vijeo Designer.

  • Deleting a variable in Vijeo Designer will not cause the corresponding variable to be deleted in SoMachine. If the deleted variable is still referenced in the HMI project, the variable may be recreated automatically to correspond to the SoMachine variable.

  • Vijeo Designer has a maximum 32 character limit for variable names and section nests. For example, the following published SoMachine variable would not be available in Vijeo Designer because a section of the nest exceeds 32 characters:

SoMachine.PLS_SOM_XBTGC1100_PROGRAMMING_CONTROLLER.myVar

  • Vijeo Designer supports a maximum of 10 sections for nesting. Published SoMachine variables whose nesting exceeds this number will not be available in Vijeo Designer.

  • Vijeo Designer does not support non-zero based SoMachine arrays.

  • Vijeo Designer supports arrays with a maximum of 2048 elements. Published SoMachine arrays with elements exceeding 2048 will not be available in Vijeo Designer.

  • You cannot cut, copy and paste variables between SoMachine and Vijeo Designer.
