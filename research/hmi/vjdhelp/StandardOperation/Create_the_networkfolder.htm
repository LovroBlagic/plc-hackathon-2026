4.6.4.1 Creating a Network Link

  1. In the Vijeo-Manager tab of the Navigator window, right-click Vijeo-Manager and select New Network Link.

  1. When the Select Network Folder dialog box displays, select a folder and click OK.

  1. Enter the new folder name.

The network link is created.

  • If you select a folder and click OK without entering the folder name, the folder will be directly linked to the existing folder. If you want a direct link to a folder on another PC which has been set up as shared folder, you cannot change the name of the network link .
