4.5.1.1 General

Property

Description

Name

The target name.

Whenever a target is created, a default name is generated. When renaming the target, its name must be unique within the project, must contain no more than 32 valid characters, and must follow the naming conventions.

For details, see Appendix 9, Naming Conventions.

Description

Enter up to 255 characters to describe the target.

Type

Select the hardware platform that the user application will run on.

Target properties change depending on the Target Type you select. For a list of the supported target types, see Appendix 5, Hardware Specifications.

Model

Select the model supported by your tablet, smartphone, or target machine.

The available models depend on the Target Type you've selected. If you change the Type, the model changes to the closest match in size and color. For a list of the available target models, see Appendix 5, Hardware Specifications.

eXtreme Display

Target Color

Select the color supported by your target machine. For information on the colors supported by your target machine, see Appendix 5, Hardware Specifications.

 

  • When changing target machines or a target machine's color, different areas of an image may become transparent.

  • When you change target types or a target machine's color, the panel editor converts the colors in objects, parts, and images (BMP, JPG, EMF, and PNG) to colors supported by the new target machine type or the new target machine color. See Section 7.3.3, Previewing Colors for Target Machines.

  • The colors for target machines with Reverse - Monochrome or Reverse - 16 Colors Gray Scale are reversed at run time and Simulation. For example, an object with a black fore color in the Editor displays white during run time. See Section 7.3.3, Previewing Colors for Target Machines.

Resolution

Available when you select the iPC Series or Tablets and Smartphones in the Type property. Select the resolution supported by your tablet, smartphone, or iPC target machine.

 

  • Before you download, check the resolution setting. If the application is downloaded with an incorrect resolution setting, the panel design would not fit on the PC Box monitor.

InitialPanelID

Select the panel that appears when the project first starts up at runtime. The initial panel ID can be any integer between 1 and 8999. For more information, see Section 20.3, Setting the Startup Panel.

Thumbnail Icon

This property is specific to tablet/smartphone targets and is used in Vijeo Design'Air Plus.

Select the base panel you want to use as the application thumbnail icon when it displays in the Main View's Remote Servers and Favorites list on the tablet/smartphone.

If you do not select a base panel to use, the Schneider Electric logo is used as the thumbnail icon.

For more information, see Section 23.1.1.3, Working in Vijeo Design'Air Plus: Open a Tablet/Smartphone Application.

Download

Select one of the following download methods: Ethernet, File System, USB, or Serial. The available selections depend on the tablet, smartphone, or target machine. For the supported download method, see Appendix 5, Hardware Specifications.

For information about downloading, see Section 25.6, Downloading the Project.

Target IP Address

Enter the IP address the target machine will use at run time. This property is available only if you have selected the Ethernet download method.  

Vijeo-Designer downloads the user application to this IP address. If the IP address is set to the default, pop-up window displays prompting to enter a download IP address.

Host Name

Define the host name for the target. Host names must follow DNS host naming conventions. For more information on these conventions, see Appendix 9 Naming Conventions.

This feature requires your network to have a DNS server that can store IP addresses and host names. Set up your DNS server with the target’s host name and IP address before defining the host name in the project. Once you enter a host name, the Vijeo Designer contacts your network's DNS server to validate the host name's IP address. If the host name validates, the Target IP Address property populates with the host name’s IP address defined in the DNS server.

Contact your network administrator to set up IP addresses and host names on your DNS server.

 

  • You can define the target's host name at runtime from the target's offline configuration menu. For more information, see Section 26.3.1.1, DHCP Settings.

COM Port

Available when Download is set to Serial.

Select the COM port on the Vijeo-Designer editor PC that is used to download the project. One end of the download cable connects to this defined COM port on the PC where Vijeo-Designer editor is running, and the other end of the cable connects to the target machine's download port.

BaudRate

Available when Download is set to Serial.

The communication speed you select should be supported by the target machine's COM port and the PC COM port.

User Application

Defines the location of the user application: Main Drive, Secondary Drive, or Optional Drive. The Main, Secondary, and Optional drive locations are described in Appendix 5.11.1, Types of Data Locations.

Include Editor Project

The Include Editor Project feature creates a backup file of your project. The backup file is generated during the download process and is downloaded to a target's main, secondary, or optional drive.

The backup file contains the editor project file and the project's data files, such as sound files, image files, and text files. For more information, see section 21.5.2, Backing up Projects to Main Drive, CF Card/SD Card, or USB Drive.

  • If you are downloading your project to multiple targets, we recommend you Download All to avoid backup concurrency problems. For more information, see Section 21.5.2.1, Downloading Editor Project to Main Drive, CF Card/SD Card, or USB Drive: Backup Concurrency Problems.

  • When this feature is enabled, it may take a few moments to download a project to iPC/XBTGTW target machines.

  • Check the capacity of your destination drive and the size of the backup file to ensure the drive can support it.

  • Project backups created with the Backup Manager are not included in the Include Editor Project backup. For more information on the Backup Manager, see section 21.5.1, Backing Up Projects on your PC.

Path

This property is available when Download is set to File System.

Enter the drive letter (e.g. X:) and path of the removable media or folder.

  • Only local path names are supported for download.

  • Use only ASCII characters in the Path.

  • When you are downloading to a CF card/SD card reader or to a USB drive, you must set the path to the root directory of the CF card/SD card reader or the USB drive. If you set the path to an exact folder in the CF card/SD card or the USB drive, the download will not work.

Format

Available when Download is set to File System. This property is read-only.

  • User Application and Runtime downloads the runtime system files and the user application to the CF card/SD card. You can use this feature to update the run-time system files.

  • Compressed User Application downloads the user application to the location defined in the Path property.

Preserve Run-Time Data

Select Enabled and click the ellipsis  to open the Preserve Run-Time Data dialog box.

 

Select the Delete All Run-Time Data option to overwrite any data files on the target machine.

 

Select the Preserve Run-Time Data Files option to preserve the following run-time data between downloads:

  • Recipe files: Select the Recipe files check box so all the recipe data will be preserved. Changes to recipe data while editing the project may cause incompatibilities with the run-time data or result in data that cannot be preserved.

    • If you change a variable while editing the project, even a variable that is not related to recipes, you cannot preserve any recipe data.

    • If you change a single recipe (such as the recipe's name, ingredient list, or recipe value), you cannot preserve any recipe data.

    • If you add a recipe or delete a recipe from a recipe group, you cannot preserve any recipe data.

    • If you add, delete, or edit a recipe group, you cannot preserve any recipe data.

  • Security information: Select the Security information check box so all the security data is preserved. If security data is changed (such as a modified user group), you can preserve the existing security data but the modified security data is not downloaded.

  • Target system settings: Select the target system settings check box to preserve the following system settings on the target machine:

    • Offline Configuration Menu Settings - Network and Backlight (Wait, Wait Time)

    • Network Configuration Menu Items - Static IP (IP Address, Subnet Mask, Default Gateway), DHCP (Enable DHCP), MAC/DNS (Obtain DNS Setting, IP Address).

Use NAT

This feature allows you to download Vijeo Designer projects through a Router to a target machine.

For more information and an example of downloading through a router, see Section 25.6.1.2, Downloading through a Router.

  • Router IP Address - Define the Router's Public IP address.

  • Control Port - Define the port configured on the router that will forward to Target Machine Port 6001.

  • Data Port - Define the port configured on the router that will forward to Target Machine Port 13777.

  • The Router must have the following port forwarding rules:

    • The port on the router configured for the Control Port must forward to target machine port 6001.

    • The port on the router configured for the Data Port must forward to target machine port 13777.

  • This feature requires that a port forwarding router is properly configured with the correct port number to forward the project to the target machine.

  • No filters or firewalls can be in place to prevent network traffic between the Vijeo Designer PC and the target machine.

  • For security, we recommend using an VPN router rather than a port forwarding router.

  • This feature should not be used over an unsecured network; however, if this feature is used over an unsecured network, leave the port forwarding active for as short a time as possible so that unauthorized users cannot gain access to the target.

Install Options

Available for targets when Download is set to File System and the target supports a CF card/SD card or a USB removable drive. For a list of target machines that support the File System download method, see Appendix 5, Hardware Specification.

Select how the CF card/SD card or USB optional drive will be used: Single Install or Multi Install.

  • Single Install. Loads the runtime system files from the CF card/SD card or USB removable drive to internal memory (or to a specified data location), onto a single target machine.

  • Multi Install. Loads the user application from the CF card/SD card or USB removable drive to internal memory (or to a specified data location), onto multiple target machines.
    For Multi Install, since the drive can be removed so you can install onto multiple target machines, it is important that you do not install other files (such as recipe files) onto the removable drive.

SRAM Usage

This property displays the SRAM capacity of the target machine and how much is used to back up application data for the following components.

  • Alarms and Events - Alarm and event groups can be set up to back up their status to SRAM.

  • Data Logging - Variables associated with data logging groups can store changes in value in SRAM.

  • Retentive Variables - The value of internal variables can be maintained between run-time sessions.

SRAM Usage values are updated when you build the user application.
