4.8.2.2 Protecting Targets from Unauthorized Project Downloads

Download Security stops unauthorized users from downloading projects to secured targets. Secured targets require users to enter in their user name and password in order for download and installation to proceed.

Downloading to secured targets:

  • From Vijeo Designer –Enter the user name and password in Vijeo Designer.

  • From USB Keys (USB Media Install) – Enter the user name and password in the target.

Download security must be enabled before you can set up security groups with Download security, see Section 4.8.7, Security Settings.

To set up a security group with Download security:

  • In the Security editor, use the Download Access drop-down list to select Allowed for the security group.

 

  • Download security does not protect targets from CF Card/SD Card project installations.
