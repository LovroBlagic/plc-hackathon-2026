4.4.2 Editor Tools

To create projects efficiently, Vijeo-Designer uses several windows called tools. Each tool window displays information relating to the project and objects you are working with. For each tool window, you can change its size, or you can move, show, or hide it.

There are six types of tools in Vijeo-Designer, and their icons appear on the Tools toolbar. Click the icon if you want to show or hide a tool.

 

The following table describes each type of tool:

Tool

Icon

Description

Navigator

Displays the information for a selected project in a tree structure. This tool is used mainly during the development of a project. You can define the settings for the target machine, equipment, download operation, alarms, and variables.

Property Inspector

Displays the properties of a selected object, where you can edit the properties. If you select multiple objects at one time, the tool window displays only the settings common to all the selected objects.

InfoViewer

InfoViewer displays reports when using the Reports feature. You can also use it to navigate the web.

To browse web sites:

  1. Click on the InfoViewer toolbar.

  1. When the Enter New Internet Address dialog box opens, type in a URL address or select one from the list.

Toolchest

Displays parts and graphics.

You can use parts by dragging and dropping them from the Toolchest onto a panel.

You can also use the Toolchest to store any of the objects that you have created, such as graphics, panels, scripts, alarm groups, and character strings.

You can then import/export all the Toolchest folders to share among designers.
See Section 21.2, Using the Toolchest to Store and Reuse Common Objects.

Graphics List

Displays a list of the graphics on the current panel with the following information: drawing order, object name, x,y coordinates, animation, and variables.

An object that is selected on the panel is also highlighted in the Graphics List. If objects are grouped, the Graphics List shows the object group then individual objects within the group.

You can sort the Graphics List by clicking any of the columns at the top of the window.
See Section 21.3, Editing Objects with the Graphics List.

Feedback Zone

Displays error messages and shows the progress of validation, build, and download operations.

If a problem occurs, the window displays errors in red and warnings in yellow.

Press F4 or double-click an error message to jump to the location of the error.
See Section 25.2, Checking for Errors Before Downloading.
