4.4 Starting the Editor

4.4.1 How to Start the Editor

To start Vijeo-Designer, from the Windows Start menu, select Programs, Schneider Electric, Vijeo-Designer, and Vijeo-Designer.

Alternatively, you can double-click the Vijeo-Designer icon on your desktop.

  • Do not set any of the Vijeo-Designer folders read-only. Otherwise, the application may not start.

  • Users with User rights can run Vijeo-Designer but cannot install Vijeo-Designer.
