11.7.4 Adding Text Files to the Target

Text files added to the project are downloaded to the target along with the project during download.

You can choose one of the following options when adding Text files to a target:

  • Link - Links Text files to the project.

  • Copy into Project - Copies Text files into the project.

Adding a Text File to a project:

  1. Click the Text node.

  2. In the Text File Editor, click the Add button.

  3. In the Open dialog box, select the Text file and enable or disable the Copy File(s) into project checkbox:

Enabled: Copies the selected files into the project.

Disabled: Links the selected files to the project.

  1. Click the Open button to add the file to the project.
