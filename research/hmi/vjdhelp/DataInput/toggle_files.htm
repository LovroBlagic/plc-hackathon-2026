11.8.4 Opening Documents in the Browser

The Browser's string variable controls which document the Browser displays. By using a String Operation, you can write a document's name to the Browser's String variable and display that document in the Browser.

String Operations can be created with Selectors or Switches, see Section 9.5.3, String Operations.

The steps below use an example of a Switch to explain how to use a String operation to change the document displaying in the Browser.

  1. In the Switch's String Operation Source Field, type in the document's name following the string conventions below:

To

Do this

Display local documents

Type in the document's name.

For example, "help.doc"

 

Display a document on the Internet

Type in the document's URL.

For example, "www.schneider-electric.com"

Display a document on a network

Type in the document's file path and name.

For example, "\\Editorbuild\Release\\English\Help.doc"

  1. Define the Browser string in the Destination field and click Add to add the operation to the Switch.
