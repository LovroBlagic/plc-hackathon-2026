11.2.5 Advanced Tab

Use the Advanced tab to set up data input for a Numeric Display or String Display. You can also define variables for input status, input triggers, and interlock.

 

Properties

Description

Enable Interlock

Enables the data input only when a certain condition is met.

For more information, see Section 9.6, Using Interlock to Prevent Accidental Touch Inputs.

  • During data input, if the interlock variable turns OFF, data input is cancelled.

Use Input Trigger

This field is enabled if Enable Input Mode is selected in the Input Mode tab. Acts as a prompt for data input triggered by PLCs or scripts. When selected, enter a BOOL  variable or expression. When the state is ON, data input is enabled.

 

When using Input Trigger

When the variable is set to ON, you are in Input mode. You remain in Input mode until the variable turns OFF.

  • If the Enable Visibility variable is OFF and the Use Input Trigger variable turns ON, input operations from the part are not possible.

  • If the Input Trigger variable turns OFF during input and you have not completed data entry (for example, the ENTER key on the keypad has not been pressed), the input is cancelled and the popup keypad closes.

  • If the Input Variable is ON and you are in input mode, touching the ESC key will not return the display to its original value. It clears the display.

  • If you are already inputting data and the Input Trigger variable turns ON, you will remain in input state until the Input Trigger variable turns OFF.

  • When interlock is enabled and interlock is false, you cannot enter Input Mode.

  • When editing multiple data display parts on the same panel:

  • If the parts are in a tab group and they share one input trigger variable, they can be accessed consecutively in the order they were created.

  • If the parts are not in a tab group and share one input trigger variable, you can only edit the first created data display.

    In both cases you must handle the closing of the data display with an Action or PLC control.

When not using Input Trigger

When you touch the Data Display in Runtime, you are in Input mode.

  • If, in the middle of inputting data, you touch another data display, the current data input is cancelled, and the cursor moves to the newly touched data display.

 

  • During data input, if the Visibility variable turns OFF, input is cancelled.

Input Status Variable

This field is enabled if Enable Input Mode is selected in the Input Mode tab. Use the Input Status Variable to signal a PLC when data has been input from the keypad or bar code scanner. Use a BOOL variable that turns ON or OFF depending on the selected Status Mode.

  • You can use the input status variable to detect variable changes.

  • You can use the input status variable to know when the Data Display is in Input mode.

Status Mode

Select Input Status Variable to enable this field. Choose from the following four status modes.

Mode

Status Detected

Description

ON/OFF Reverse Mode

Numeric entries for the variable defined in the Basic tab.

The specified BOOL variable turns ON or OFF each time data is entered. In ON/OFF mode, the value toggles between 0 (OFF) and 1 (ON).

ON Trigger Mode

The specified BOOL variable turns ON each time data is entered. You need to reset the bit when data input is complete.

If set to ON Trigger Mode, a value of 1 is written to the Input Status Variable when data is entered.

  • If the bit is already ON when a number is entered into the variable, there is no change in the BOOL variable. Be sure to specify OFF as the initial value of the BOOL variable.

OFF Trigger Mode

The defined BOOL variable turns OFF each time data is entered. You need to set the BOOL variable when data input is complete.

If set to OFF Trigger Mode, a value of 0 is written to the Input Status Variable when data is entered.

  • If the state is already OFF when a number is entered into the variable, there is no change in the BOOL variable. Be sure to specify ON as the initial value of the BOOL variable.

Input Status Recognition Mode

Status of display

If the data display is in Input mode, the BOOL variable is ON. If the data display is not in Input mode, the variable is OFF.
Status Mode Operations

Status Mode Operations when combined with Input Trigger

Security Level

Sets the Security Level for the Numeric or String Display. Once a Security Level is defined, only users with the correct security level can access the Numeric or String Display's functions. For more information on security levels, see Section 4.8.2.1, Protecting Panels and Parts from Unauthorized Users.
