11.9.2.4 Change-Immediate Keypad

The Change-Immediate Keypad allows you to immediately increase or decrease the value of a variable associated with a part by using the Up/Down arrow keys on the keypad. The following image shows a Change-Immediate Keypad.

Change-Immediate Keypads can be used with a Image/Message Display, Bar Graph, Meter, or a Selector. To set up a Change-Immediate Keypad for your part, simply display the part's Settings dialog box, click the Input Mode tab, select the Enable Input Mode check box, and select Change-Immediate from the drop-down list.

Be aware of the Change-Immediate Keypad's special behavior for the Bar Graph and Meter.

Change-Immediate Keypad Behavior for Bar Graph and Meter

The following describes the Change-Immediate keypad behavior for the Bar Graph and Meter.

Keypad Inputs Accepted

  • Inputs are accepted when the keypad writes a value within the variable's Min/Max range.

Keypad Inputs Ignored

  • Inputs are ignored when the keypad writes a value outside the variable's Min/Max range.
