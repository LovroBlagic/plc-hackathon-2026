11.1 Overview

In Vijeo-Designer, you can display and input various types of data on graphical panels, such as numeric data, date and time, strings, and text files (.txt). Date and time, measurements, text strings and switch labels can be used for informational purposes, while critical information such as alerts, error messages or procedures can be triggered by specific events.

In addition to displaying data, the Numeric and String Displays support data inputs. Data input fields displayed at runtime use keypads for data entry. Keypads can have different behavior and formats depending on their intended use. For more information, see Section 11.9, Inputting Data with Keypads.

  • If you use Date Display or Time Display, you cannot input data from the keypad or keyboard.

A description of the different ways of displaying data and keypads is provided below.

You can display data in one of the following two ways:

  • Use the Data Display part, available on the Toolbar, to quickly create an object and configure its settings through a dialog box. Object shapes can be changed without creating a new part, and different states are displayed in the editor without simulating the project. Data Display parts can display variable values, time, and date.

  • Use Value Animation to create custom objects that display data. Although this method is more time consuming, it may appeal to users with more specific needs. User-created objects support multiple animations concurrently and can be grouped.
