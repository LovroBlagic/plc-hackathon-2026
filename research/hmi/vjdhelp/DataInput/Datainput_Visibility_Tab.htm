11.2.4 Visibility Tab

Use the Visibility tab to set up features such as visibility and blink for the Data Display.

The following table describes the Visibility tab properties.

Property

Description

Enable Visibility

Select Enable Visibility, and then select a BOOL or integer variable or enter a boolean expression that controls whether the Data Display is visible (ON) or not (OFF).

  • If true, the Data Display is visible.

  • If false, the Data Display is not visible.

  • If in the middle of data input this variable turns off, your input will not be stored. Whatever you were typing will be gone.

Invisible when in invalid state

This check box is not available for data displays.

Enable Blink

Select Enable Blink to make the data display blink. You can choose a BOOL or integer variable or enter a boolean expression.

  • If true, the data display will blink.

  • If false, the data display will not blink.

Speed

Set the blinking speed to fast or slow. A fast blink rate is 350 ms and slow blink rate is 700 ms.
