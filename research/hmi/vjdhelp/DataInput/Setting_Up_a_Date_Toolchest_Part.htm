11.4.3 Setting Up a Date Toolchest Part

This section explains how to create a Date Toolchest part, so you can change the date.

  1. Click the Toolchest icon in the menu bar to open the Toolchest window, and click the DateTime folder.

  1. Select the Date Display you want, and then drag and drop it onto the panel.

You can choose from these Date Toolchest parts.

Type

Part

Description

Date Switches

DateColorSwitch_1

A 2D calendar image for non-monochrome target machines.

DateColorSwitch_2

A 3D calendar image for target machines with 256 or more colors.

DateColorSwitch_3

A 3D calendar image for target machines with 64 or more colors.

DateBWSwitch_1

A 3D calendar image for monochrome target machines.

Date Text Display

Date_Display_01

A date display with background color but without a border.

Date_Display_3D_01

A 3D date display with background color and 3D border.

  1. Right-click the Date Display part, and click Properties. The Date Display properties display in the Property Inspector.

Use the table below to define the properties for a date switch or date text display.

Property

Description

Name

The Date Display part's name.

Whenever an object is created, a default name is generated. When renaming an object, its name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

For details, see Appendix 9, Naming Conventions.

Description

Displays the name of the part. This property is read-only.

Version

This property is read-only. It displays the name of the part and the supporting Vijeo-Designer's version.

Top

The coordinates, in pixels, of the top-left corner of the object.

  • Top is measured from the top of the object to the top of the panel. Enter a value from –32768 to (32767 –- object height).

  • Left is measured from the left side of the object to the left side of the panel. Enter a value from –32768 to (32767 – object width).

By changing these properties, the graphical object can be moved up, down, left, and right.

 

 

Left

Width

The width/height of the Date Display is in pixels. The minimum size for each Date Display is as follows:

  • Date_ColorSwitch_01: 20W x 20H pixels

  • Date_ColorSwitch_02: 20W x 20H pixels

  • Date_ColorSwitch_03: 20W x 20H pixels

  • Date_BWSwitch_01: 20W x 20H pixels

  • Date_Display_01: 100W x 20H pixels

  • Date_Display_3D_01: 100W x 20H pixels

Height

Variable Type

Select String or Separated Variable.

  • If you select a String, the Date Format and Date Variable properties are displayed.

  • If you select Separated Variable, the Date Format, Day Variable, Month Variable, and Year Variable properties are displayed.

Date Format

Select the date format for saving your date input at run time. Date formats vary depending on the part and variable type you selected.

Date Variable

This property displays if you selected String as the variable type. Click to select a string variable from the Variables List dialog box. This string variable stores the date input.

Day Variable

This property displays if you selected Separated Variable as the variable type. Click to select an integer from the Variables List dialog box. The day is stored in this integer variable.

Month Variable

This property displays if you selected Separated Variable as the variable type. Click to select an integer from the Variables List dialog box. The month is stored in this integer variable.

Year Variable

This property displays if you selected Separated Variable as the variable type and if you selected these date formats:

  • dd/mm/yyyy,dayOfWeek

  • dd/mm/yyyy

Click to select an integer from the Variables List dialog box. The year is stored in this integer variable.

Day of the Week Variable

This property displays if you selected Separated Variable as the variable type and if you selected the dd/mm/yyyy,dayOfWeek date format.

Click to select an integer from the Variables List dialog box. The day of the week is stored in this integer variable.

Text Color

Select the text color for run time display.

BgColor

Select the background color for run time display.

Font

Select the font and font size for run time display. If the font type is 3D, the 3D text color is always black.

Restore Defaults

Click the Restore Defaults button to display the confirmation message. Clicking OK will restore all values to the default settings.

Placeholder

You can assign a placeholder in any property that requires a variable definition. Click the ellipsis to open the Placeholders dialog box and edit the variable placeholder for the object. The dialog box only displays if you had set up a placeholder for the object. For more information on placeholders, see Section 21.2.4, Working with Variable Placeholders.

 

  • You cannot use system variables in Date Toolchest parts.

When you touch a date switch part in run time, a calendar displays so you can set the date.

When you touch a date text display part in run time, a keypad displays so you can set the date.
