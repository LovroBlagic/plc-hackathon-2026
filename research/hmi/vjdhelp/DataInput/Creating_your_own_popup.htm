11.9.5.3 Creating a Popup Window Panel for a Custom Keypad

You can create a popup window panel to display your custom keypad.

  1. In the Navigator window's Project tab, right-click the Popup Windows node and click New Popup Window.

  1. Open the popup window panel, and place the user-created keypad on the panel.

  1. Change the popup window size in the popup window properties, as necessary.
