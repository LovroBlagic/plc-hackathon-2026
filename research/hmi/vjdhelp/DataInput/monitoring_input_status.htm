11.9.8 Monitoring Input Status from Connected Equipment

The system variable _InputStatus monitors the input status of the Data Displays and value animated text objects in your project. When any Data Display or value animated text object goes into input mode, the value of the _InputStatus variable is one. When all Data Displays or value animated text objects go out of input mode, the value of the _InputStatus variable is zero.

You can monitor the _InputStatus variable from Connected Equipment by assigning external variables to the Read From and Write to fields. External Equipment cannot write directly to the _InputStatus variable.

If you want to globally monitor the input status of your data displays or value animated text object, use the _InputStatus system variable. See Section 11.2.5, Advanced Tab. If you want to monitor the input status of a specific data display or value animated text object, set up a status variable for the data display or value animated text object. See Section 11.9.4, Setting Up Data Inputs.

Assigning Input Status to a Device Address

  1. In the Variable Editor, click the System Variable icon to display the system variables.

  1. Right-click the _InputStatus system variable and select Properties.

  1. In the _InputStatus properties, select Write To Variable and associate the external variable that's linked to a device address on the connected Equipment.
