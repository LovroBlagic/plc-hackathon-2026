11.8 Displaying Documents Using Browser

Vijeo-Designer's Browser feature allows you to view web content on specific targets with Ethernet capability. Both Browsers can display documents that reside locally on the target and documents that reside remotely on the Internet or a network. You can open different documents in the Browser using a String Operation. For more information, see Section 11.8.4, Opening Documents in the Browser.

You can select from one of the following two Browser parts in the Toolchest:

  • Internet Explorer Browser

  • Multi-Platform Browser

For more information on the specific targets that support the Internet Explorer Browser and the Multi-Platform Browser, see Appendix 5, Hardware Applications.

You can use switches, Browser controls, and string keypads to manage documents and web content on the Browser. For more information on how to create switches and string displays in the Editor, see Section 11.8.6, Using Switches and String Displays to Display Documents.

 

  • The Data Quality icon is not supported for the Browser.

  • In the selected Browser Files folder, include only those files used by the Browser. Adding unnecessary files to the Browser Files folder may be an inefficient use of disk space.

Internet Explorer Browser

The Internet Explorer Browser supports the following types of documents:

  • Excel (.xls)

  • Word (.doc)

  • Power Point (.ppt)

  • Adobe Acrobat (.pdf)

  • HTML (.htm)

  • Video files (any file supported by the video player's codec)

When you open a PDF file for the first time in the Internet Explorer Browser, the Adobe Acrobat Reader licence agreement dialog box displays but is hidden under run time.

The Internet Explorer Browser launches Excel, Word, and Power Point documents in a separate window. You can configure these documents to open directly in the Browser by:

  • Saving your Word, Excel, or Power Point document in HTML format. HTML documents open directly in the Browser.

  • Installing the full version of Word, Excel, or Power Point on the target machine. Documents open directly in the Browser when the full version is installed.

  • For Word Only - Save your Word document in XML format. Install the Word XML Viewer on the target that supports the Browser. The Word document will then open directly in the Browser.

Documents in the Internet Explorer Browser accept data input through Toolchest Keypads. For more information, see Section 11.8.5, Inputting Data.

Multi-Platform Browser

The Multi-Platform Browser supports the following types of documents:

  • HTML (.htm)

  • JavaScript (.js)

  • JPEG (.jpg), GIF, PNG

  • CSS

You can use the System Keypad to input data into the documents displaying in the Multi-Platform Browser. For more information, see Section 11.8.5, Inputting Data.

 

  • The image used in the Multi-platform browser should not have a resolution that is higher than the HMI panel's resolution. See your hardware manual for your HMI panel's resolution.

  • Microsoft Office-generated HTML files are not standard HTML files. Viewing these files on the Multi-Platform Browser may cause limitations on your target machine and is not recommended.

  • The Multi-Platform Browser does not support the alpha channel (transparency) of PNG images. To display images with a transparent background, use the GIF file format.
