11.6 Displaying Text Using String Display

If you want to display text on a panel, you can use a String Display or a lamp.

Displaying Text Stored in String Variables

You can display and switch between text (such as production item name and personnel name) using one of the following methods:

  • Displaying Text Stored in Internal String Variables

  • You can display the text data defined in the variable's Initial Value.

  • When you type text into the variable using keypad or keyboard, the typed text will display.

  • Text display uses either String Display or Value Animation.

  • Displaying Text Converted using Character Codes

  • On the target machine, you can display as text character codes stored in device addresses.

  • Supported string codes are ASCII code (character code), Unicode and ANSI. The character codes are set up in the String Encoding property of each driver.
    For more information, see Section 5.2.4, Setting Up Character Codes and Section 11.6.2, Displaying Text with Character Code.

  • You can display text using either a String Display part or Value Animation.

Creating a Message Display

You can use the lamp tool from the Graphical Objects toolbar to create a message display on the panel. You can use either a Lamp or an N-State Lamp, and display up to 32 messages.

For more details, see Section 10.6, Creating a Message Display.
