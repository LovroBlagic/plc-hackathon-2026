11.2.2 Input Mode Tab

Use the Input Mode tab to set up data input for the Numeric Display and String Display. You can set up a popup keypad. You can also define variables for barcode input and error status, and assign tab groups for consecutive input on multiple Data Displays.

 

The following table describes the Input Mode tab properties.

Properties

Description

Enable Input Mode

Enables data input using a keypad. When the Enable Input Mode check box in the General tab is selected, this check box is automatically selected as well. Select this option to enable the subsequent options.

For more information, see Section 11.9, Inputting Data with Keypads.

You can set up the data input range in the Variable properties dialog box.
For more information, see Section 6.2.3, Variable Properties.

  • For Date Display or Time Display, you cannot use keypad input.

  • If you select an expression in the Variable property in the General tab, you cannot use the Enable Input Mode option.

  • For String Display, if you use the Recipe Control variable RecipeLabel, the Enable Input Mode option is disabled.

  • When a 32 bit unsigned integer variable is used in a Numeric display and input mode is enabled, the variable's min/max range is disabled and automatically set from 0 - 4,294,967,295.

Field ID

Set up a unique field ID for triggering the input mode from the _TouchField system variable. The field ID must be a value between 0 and 2,147,483,647. The default value is 0. If the Field ID's value is 0, the input mode cannot be triggered from the system variable. Each Field ID should be unique for your project. For more information on system variables, see Section 6.7, System Variables.

Display Popup Keypad

This field is automatically selected when you select Enable Input Mode. For String Display, a list box displays beside the Display Popup Keypad checkbox so you can select a String Keypad or Decimal Keypad.

Displays a popup keypad when inputting data. Enable data input by touching the area on the Data Display.
For more information, see Section 11.9.3, Using a Popup Keypad.

The popup keypad is predefined.

If you want to use a customized keypad, see Section 11.9.5, Using Custom Keypads.

Overwrite Variable's Input Range

This field is available for Numeric Display and is enabled when Enable Input Mode is selected. Select this checkbox to define numeric values or expressions to overwrite the variable's Min and Max values. To select the Min and Max values, enter the expression by typing it in the field or by using the Expression Editor Pad.

  • At runtime, some keypads typically show a Min and Max range. For targets with a panel size of 200x80, the keypad will not be able to show the Min and Max values. However the defined Min and Max values will be in effect. For example, if an invalid value is entered that exceeds the Min or Max range, the text color will change or the system will beep. You will need to correct the value before pressing ENT on the keypad.

Display Text as Asterisk

This field is available for Numeric Displays and String Displays. This field is available when the Enable Input Mode check box is selected.

Select this option to display input values as asterisks (*) in the display part's popup keypad and in the display part. Input values will show as three asterisks (***) in the display part.

Buzzer on Touch

Sets the buzzer for sound. When enabled, touch the display and the popup keypad to cause the buzzer to beep.

Barcode

When selected, enables data input from a bar code scanner.
For more information on bar code, bar code input address, and error status, see Section 24.1, Bar Code Scanners.

Tab Group

This field is read-only.
When tab group is set up on the Data Display for a Numeric Display or String Display, the Group No. and Order properties are shown here.

See Section 11.9.6, Continuous Input to Multiple Data Displays.
