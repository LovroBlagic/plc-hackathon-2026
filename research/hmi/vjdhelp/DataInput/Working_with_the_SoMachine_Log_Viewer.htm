11.7.4.2 Working with the SoMachine Log Viewer

At run time, if the trigger value and the trigger type condition match, the SoMachine log file contents will display. For example, if the trigger value has a BOOL value that changes from 0 to 1 and the trigger type is set to When True, the file contents will display. You can reload the file contents by pressing a switch you created. For more information, see Section 11.7.4.1, Setting Up the SoMachine Log Viewer.

The log file can display up to 65535 lines and allows up to 700 characters per line. If the line exceeds 700 characters, the excess characters will not display. You can use the horizontal and vertical scroll bars to navigate through the file.

 

Troubleshooting SoMachine Log Viewer

If a large file is being opened in the SoMachine Log Viewer at runtime, it may take a few moments to retrieve and display the file.

If the log file does not display in the SoMachine Log Viewer when the panel opens at run time or when you press the switch to reload the file content, the following may have occurred:

  • Incorrect values were entered in the Machine Name and File Name properties when configuring the log viewer in Editor. An error message will display in the log viewer at run time indicating the file cannot be found.

  • The file cannot load because the trigger value and the trigger type condition does not match.

  • The trigger variable has a bad quality, preventing the log viewer to load or reload the file. The bad data quality icon displays at the top right corner of the log viewer.
