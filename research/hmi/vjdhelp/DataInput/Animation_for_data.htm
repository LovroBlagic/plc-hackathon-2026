11.3.2.1 Working with Value Animation

  1. From the Graphical Objects toolbar, select the Text icon.

  1. Click and drag to define the text area, and the Text Editor will open.

  1. In the Text Editor, type the pound symbol [#], which will act as the numeric display, then click OK.

  1. Use only one pound symbol [#] character to enable Value animation—no additional text, character spaces, or carriage returns. The pound symbol must be a single-byte character.

  1. In the Text Property Inspector, define the color and font as needed.

  1. Right-click the text object and select Animation to display the Animation Properties dialog box.

  1. Click the Value tab, and select the Enable Value Animation checkbox.

  1. Define a variable or expression.

  1. Click OK to confirm the selection and close the Animation Properties dialog box.
