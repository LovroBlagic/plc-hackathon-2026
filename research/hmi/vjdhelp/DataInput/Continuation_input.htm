11.9.6 Continuous Input to Multiple Data Displays

After setting up a tab group, you can enter values in multiple Data Displays without having to click in the Data Display area after each and every input.

  • If you want to exit the Data Display area, touch the ESC key on the keypad.

  • If interlock is enabled in a Data Display within a Tab Group, that Data Display will skip to the next Data Display.

Setting Up the Tab Group

To enable continuous data input to Data Displays, set up the tab group.

  1. Select multiple Data Displays, then right-click and select Set Tab Group to open the Tab Order dialog box. The Set Tab Group selection is only available if all the selected Data Displays have Enable Input Mode selected.

  1. Select the group number and define the tab input order.

Removing a Numeric Display from a Tab Group

To remove a tab group, select one of the data display parts within the tab group, then right-click and select Remove Tab Group.
