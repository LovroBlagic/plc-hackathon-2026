11.7.3.1 Setting Up a Text Block Display

  1. Using a text editor, such as Microsoft Notepad, create a text file in .txt format.

Press the Enter key to start a new line. If a line is longer than the width of the Text Block Display, the text is clipped in the display. There is no horizontal scroll bar.

For a Text Block Display, there are two different ways to format each block in the text file;

  • Sequential: Blocks are formatted sequentially, starting from block 0. Insert a carriage return between each block, including the end of the last block. The separator is not displayed, so it can be blank or include text.

  • UserDefined: Blocks are formatted as defined by the user. At the start of the block, type the block number and a colon (:). There is no separator line.

  1. Save the text file. Make sure you select Unicode encoding when saving the file.

  1. In the Navigator window's Project tab, double-click Environment under the Target node, double-click Data Files,  and select Text.

  1. In the Text File Editor that opens, select the location and the name of the text file you created in step 1.

  1. Click the File Selection icon to display the Open dialog box and select the file created in step 1, or type the path of the text file in the File Name field.

When you select the text file, the file name (without the file extension) is displayed in the Alias column. Change the alias name as required.

  • Alias is another name for the text file. For example, a path name (location of the file + file name) may be very long, such as "C:\CompressionMoldingLineProject\OperationManual\ExchangeSteps.txt." If you have several text files in the same location, it may become very difficult to distinguish these files. For this reason, the Text File Editor offers an Alias so you can manage many text files easily.

  • You can register up to 200 text files.

  1. If you want to add more text files, click Add and register the text files one by one.

  1. Specify the storage location on the target machine for the text files.

Main Drive

You can store the text file in internal memory (flash memory).

Secondary Drive

You can store the text file on the Secondary Drive.

Optional Drive

You can store the text file on the Optional Drive.

 

  1. In the Navigator window's Project tab, select the panel where you want to place the Text Block Display.

  1. Click the Toolchest icon  in the menu bar to open the Toolchest window, and select the Text Display folder.

  1. Move the Text Block Display onto the panel using the drag and drop operation.

  1. In the Property Inspector, change the Text Block Display properties as necessary.

The dialog box only displays if you had set up a placeholder for the object. For more information on placeholders, see Section 21.2.4, Working with Variable Placeholders.

IndexType

IndexType and LinesPerBlock specify how to format the text file.

 

IndexType defines how each block is numbered: Sequential or UserDefined.

 

Sequential: Blocks are numbered sequentially, starting from block 0. Each block is a fixed size, defined by the LinesInBlock property. After each block, including the final block, is a row that does not appear in the text display.

UserDefined: Blocks are numbered as defined by the user. At the start of the block, type the block number and a colon (:). There is no separator line.

LinesPerBlock defines the number of lines for each block. Format your text file so each block is a fixed number of lines. Each block can have up to 200 lines.

  • Each block actually occupies one line more than defined here. When IndexType is Sequential, an extra line is required after each block, including the last block. When IndexType is UserDefined, an extra line at the start of each block is used to identify the block number.

If you select Show, a scroll bar will be displayed at the right side of the Text Display as shown below. You can use the scroll bar to scroll the text. You cannot change the position of the scroll bar, or the number of lines displayed at a time.

RestoreDefaults

The arrow button restores the original default property settings. A message prompts you to either continue or cancel the action.

Placeholder

You can assign a placeholder in any property that requires a variable definition. Click the ellipsis to open the Placeholders dialog box and edit the variable placeholder for the object. The dialog box only displays if you had set up a placeholder for the object. For more information on placeholders, see Section 21.2.4, Working with Variable Placeholders.

  • The number of characters per line in the Text Block Display is determined by the width of the Text Block Display and the font size.

  • If text is clipped at the end of a line:

  • Adjust the Text Block Display width and Text Block Display font size.

  • Adjust the line breaks in the text file.
