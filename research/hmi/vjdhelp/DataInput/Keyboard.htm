11.9.2 Types of System Keypads

Vijeo-Designer provides String, Numeric, Discrete, Change-Immediate, Scientific Notation, and Change-On-Enter keypads that work with targets that have different touch grids and screen sizes. Use the target properties to define system keypad settings.

Property

Description

String Keypad Layout

Select Standard Keyboard, Alphabetical Order, or Compact (Multi-page). This property is hidden if the target screen size is less than 640x480. For targets with a 200x80 screen size, the string keypad layout will automatically be Alphanumeric.

Key Size

Specifies the key size for the target screen size. This property is hidden if the target screen size is less than 640x480. The default key size is automatically selected for your target screen size. Key Label Color

Select the color for each area on the keypad. The Color palette displays when you click the color area. You cannot set transparent color for the keypad.

  • When you enter an invalid value on a color target machine, the Text Display Color turns red. Make sure you select a Text Display Color that is visible when the Display Area Back Color is red.

  • For monochrome targets, the Display Area Back Color blinks to indicate invalid values.
