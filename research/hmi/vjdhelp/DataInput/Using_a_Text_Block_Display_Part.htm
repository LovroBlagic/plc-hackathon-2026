11.7.3 Using a Text Block Display Part

You can use the Text Block Display part to display blocks of text efficiently, such as names of production items or personnel, or an operation manual.

A Text Block Display displays a text file (*.txt) stored on disk. Use the vertical scroll bars to review the contents of the text file.

You can do the following with a text file:

  • Display blocks of text from a text file in sequential mode or user-defined mode.

  • Save the text file used for Text Block Display in either the target's internal flash memory, Secondary Drive, Optional Drive.

You can select one of the following display formats for a Text Block Display part. For details on how to set up a Text Block Display, see Section 11.7.3.1, Setting Up a Text Block Display.

Display Format

Description

Sequential

You can set up a simple text file where each line is displayed sequentially. Separate each block by inserting a line. Anything entered in the line separator is not displayed. Each block can contain up to 200 lines.

 

In the following example, the text file is set up where there are 3 lines per block (lines 1-3, 5-7, 9-11), and lines 4 and 8 are the line separators.

In the Editor, define the properties for the Text Block Display by setting up the text file and the variables to define which block to display. Set the Index Type to Sequential and Lines Per Block to 3.

In run time, you can switch the text display by block. To switch between blocks, you need to use a variable to define which block to display.

User Defined

You can set up a text file where you can define a block number for any number of lines, followed by a colon (for example, X:). The block does not have to be sequential. Block size affects system performance.

 

In the following example, the text file is set up where there are 3 blocks, with 3 lines per block. Each block is separated by an integer, followed by a colon (0:, 1:, 2:).

In the Editor, define the properties for the Text Block Display by setting up the text file and the variables to define which block to display. Set the Index Type to User Defined and Lines Per Block to 3.

In run time, you can switch the text display by block. To switch between blocks, you need to use a variable to define which block to display.

 

  • There is no limit to the size of text files except for available disk space. However, the size of your text file affects system performance. The bigger the text file, the longer it takes to load the file. If you use large text files, at build time the editor displays a warning when the text file is larger than 50K.
