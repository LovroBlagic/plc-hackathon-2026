11.9.5.2 Using Blank and Special Keys

  1. Click the Toolchest icon in the menu bar to open the Toolchest window, and select the Blank or Special Keys folder.

  1. Move the key onto the panel using the drag and drop operation.

  1. In the key properties, define the character and label, or the operation and label.

The following table describes the Blank Key and the Special Key properties.

Property

Description

Name

The object's name.

Whenever an object is created, a default name is generated. When renaming an object, its name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

For details, see Appendix 9, Naming Conventions.

Version

Displays the part name and the Vijeo-Designer version. This property is read only.

Top

The coordinates, in pixels, of the top-left corner of the object.

  • Top is measured from the top of the object to the top of the panel. Enter a value from –32768 to (32767 – object height).

  • Left is measured from the left side of the object to the left side of the panel. Enter a value from –32768 to (32767 – object width).

By changing these properties, the graphical object can be moved up, down, left, and right.

Left

Width

Specifies the width/height of the object in pixels. Enter a value between 1 and 3000. You can change the width of the object by editing this property.

Height

CharacterCode

This property is for blank keys only. Define the character or character code. You can use UNICODE or ASCII (hexadecimal or decimal) code. The code written to the connected device differs depending on each driver's String Encoding setting. See Section 11.9.7, Entering Text with the Keypad.

Operation

This property is for special keys only. Select one of the following operations for this key:

 

Selection

Operation

Enter

Inputs the currently displayed data into the corresponding variable.

Clear

Clears the data displayed.

+/-

Changes the sign.

ESC

Creates the Escape key. Exits data input without changing the value.

BackSpace

Deletes one character to the left of the cursor.

<--

Moves the cursor left one character.

-->

Moves the cursor right one character.

Increment

Increases the value by one. Holding down the key increases the value by five.

Decrement

Decreases the value by one. Holding down the key decreases the value by five.

ForeColor

The foreground color of the key.

Label

Text that appears on the key.

TextColor

Color of the text label.

Buzzer

Select True or False. If you select True, the key buzzes when touched. If you select False, the buzzer is turned off.

RestoreDefaults

The arrow button restores the original default property settings. A message prompts you to either continue or cancel the action.
