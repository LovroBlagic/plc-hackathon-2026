11.7.1 Steps to Set Up a Text Display Part

Steps

1. Prepare a text file (*.txt).

2. Add the text file to the user application, and set up an alias.

3. Create a Text Display or Text Block Display part.

4. Set up properties for the part, which include:

  • Input alias name

  • Input file number

  • Input block/line number

  • Show/Hide scroll bar
