11.8.1 Displaying Local Documents

The Internet Explorer Browser and Multi-Platform Browser can display documents that reside locally on the target machine.

To display local documents:

  1. Add the documents you want to view to your project. See Adding Documents to the Browser Node below.

  2. Add the Browser to your project and configure the part to view Local Documents. See Section 11.8.3, Adding the Browser to a Project.

  3. Create a string variable to open the documents in the Browser. See Section 11.8.4, Opening Documents in the Browser.

  4. Set up a method for displaying documents by creating a switch, string display, or Browser controls. See Section 11.8.6, Using Switches and String Displays to Display Documents.

Adding Documents to the Browser Node

  1. Place all the documents want to view in the Browser into a single folder on your computer.

  2. In Vijeo-Designer, double-click Environment under the Target node, select Data Files, then right-click the Browser node and select Properties to display the Browser Files node Properties.

  1. In the Browser Folder property, click the ellipsis and select the folder that contains the Browser documents. Note that you cannot select a sub-folder of Vijeo Manager.

When you download your project to the target machine, the documents in the selected folder are also downloaded.

  • If you exceed 10 MB of files, a warning message displays to inform you that more time is required for each project save.
