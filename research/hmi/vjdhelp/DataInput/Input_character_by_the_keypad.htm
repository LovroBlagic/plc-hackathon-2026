11.9.7 Entering Text with the Keypad

If you enter text on the target machine, the character codes (ASCII , Unicode, or ANSI) are stored in the equipment's device address.

The character codes stored in the equipment can be selected in the driver's String Encoding property.

For details, see Section 5.2.4, Setting Up Character Codes.

Drivers that do not support the String Encoding property store the text using ASCII.

  1. Use the String Encoding property to select which character code will be used to store text strings in the equipment.

  1. Set String as the Data Type property. In the DeviceAddress property, specify the starting address of the equipment to store the string code.

  • When entering 2-byte characters from keypad/keyboard, you may be able to define strings that exceed the number of bytes set in the NumOfBytes property.
    However, the portion exceeding the number set in the NumOfBytes property will not be stored in the variable.

  1. Create a data display for displaying the variable data created in Step 2, and in the Data Display Settings dialog box Input Mode tab, select the Enable Input Mode checkbox. The Display Popup Keypad checkbox is automatically selected.
    See Section 11.6.2, Displaying Text with Character Codes.

When Display Popup Keypad is selected, the keypad will display if the data display part is in the input state. If you do not want the keypad to display, remove the check mark from the Display Popup Keypad check box.

  1. At Runtime, when you enter text in the data display part, the character code, as set up in the driver's String Encoding property, is written to the equipment side. When using a device that does not support the String Encoding property, the data uses ASCII.

  • The String Encoding property's storing order (Low/High) depends on the device used.
    For more information about the High- or Low-order position of a device, see the corresponding equipment driver manual's Supported Device Addresses section.

  • When the controller stores text strings, make sure the controller adds a NULL termination character at the end of the text string.
