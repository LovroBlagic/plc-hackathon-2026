11.8.3 Adding the Browser Part to Your Project

  1. In the Toolchest's Browser folder, select the Internet Explorer Browser or Multi-Platform Browser part. Then drag and drop it onto a panel in your project.

  2. Configure the following Browser properties:

Property

Description

Browser Type

This property is available only for the Internet Explorer Browser part. Select Local or Remote from the drop-down list.

  • Local: The Browser will only display documents that you added to the target. Both the Internet Explorer Browser and Multi-Platform Browser support the Local type.

  • Remote: The Browser behaves similarly to an Internet Browser in that it can follow links and navigate to other websites. Only the Internet Explorer Browser supports the Remote type. The Internet Explorer Browser uses the IE® Engine.

Local File Name

This property is available for both the Internet Explorer Browser and Multi-Platform Browser parts.

 

If you selected the Internet Explorer Browser part, this property displays only when the Browser Type is set to Local. Define the string variable used to identify which file to display.

 

It is recommended that you create a new string variable for the Browser. To set up and create the string variable, you need to define the following variable property:

  • Initial Value: For a local Browser, this is the name of the file to display, for example, Help.htm. For a remote Browser, this is the URL or IP address of the first website, for example, www.schneider-electric.com or 192.16.2 (depends on your DNS configuration).

URL

This property is available if you selected the Internet Explorer Browser part and the Browser Type is set to Remote. Set it to the Browser's string variable.

System Keypad

This property is available only for the Multi-Platform Browser. Set to Enabled so the keypad displays at run time.

At run time, you can only use the system keypad to input data into a document or web site, not to type in a new URL address. The system keypad displays when you touch an area on the web site or document.

If you set this value to Disabled, you should place a Toolchest keypad for inputting data. Otherwise, you will not be able to type anything into a document or web site.
