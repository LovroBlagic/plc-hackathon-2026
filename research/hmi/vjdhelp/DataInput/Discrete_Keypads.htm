11.9.2.3 Discrete Keypads

The Discrete Keypad enables you to switch between On and Off states. The following image shows an example of a Discrete Keypad.

Using a Discrete Keypad

You can easily set up a Discrete Keypad for your text object. Make the following selections in the Animation Properties dialog box:

  • Set Data Type to Bool, and select the Enable Input Mode and Display Popup Keypad check boxes.
