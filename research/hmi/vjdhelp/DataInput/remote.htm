11.8.2 Displaying Remote Documents

The Internet Explorer Browser part can display documents on the network or the Internet.

To display remote documents:

  1. Add the Browser to your project and configure the part to view remote documents. See Section, 11.8.3, Adding the Browser to a Project.

  2. Create a string variable for opening documents in the Browser. See Section 11.8.4, Opening Documents in the Browser.

  3. Set up a method for displaying documents by creating a switch, string display, or Browser controls. See Section 11.8.6, Using Switches and String Displays to Display Documents.
