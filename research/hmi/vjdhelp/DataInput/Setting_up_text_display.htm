11.7.2 Using a Text Display Part

The Text Display part displays the contents of one or more text files. The text file can display information (such as names of production items or personnel) or display instructions (such as an operation manual). You can use the Text Display in different formats, from displaying one-line messages to displaying longer documents such as an operation manual.

You can use scroll bars to review the contents of the text file.

By using the Text Display part, you can display text or perform the following actions on the target machine. For details on how to set up a Text Display, see Section 11.7.2.1, Setting Up a Text Display.

Actions

Description

Display a text file

When the text file includes more than one line, use the scroll bar to scroll through the file line by line. There is no horizontal scroll bar.

Jump to a specific line

You can display a specific line in a text file. To jump to a line, assign the line number in the Line Number Variable defined in the Text Display properties. You can also use the scroll bar to display line by line, but the line number variable allows you to use external equipment or scripts to jump to the specific line in the text file to display.

Jump to a specific paragraph

You can jump to a specific paragraph in a text file. Each paragraph in a text file is a block. To jump to a block, set up the Block Number Variable which defines which block to display.

Jump to a specific line in a paragraph

If you combine the line number and block number navigation features, the line number defines which line in the block to display. For example, if the Line Number Variable = 2, and Block Number Variable = 5, then the text display jumps to block 5, and then to the third line in the block.

Switch between multiple text files

You can display different text files using the Text Display part. To switch between files, you need to use the File Number Variable defined in the Text Display properties and set up numbers in the text files' alias names.

Switch between text files in different languages

You can switch between text files in different languages. For instance, when you change the user language from English to French, the text display can also switch between English and French text files.

 

  • You can set up a maximum of 200 text files that can be imported.

  • Text files do not have a size limit. However, you are limited by the disk space available and by system performance affected by large text files. The bigger the text file, the longer it takes to load the file. If you use large text files, at build time the editor displays a warning when the text file is larger than 50KB.
