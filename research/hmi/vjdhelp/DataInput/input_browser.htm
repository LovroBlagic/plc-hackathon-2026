11.8.5 Inputting Data

Inputting Data into the Internet Explorer Browser

Use Toolchest keypads to input data into documents displayed in the Internet Explorer Browser.

To add the keypad to your project:

  • Drag the keypad from the Toolchest Keypad folder and drop it onto the same panel as the Browser.

 

Inputting Data into the Multi-Platform Browser

Use the System Keypad to input data into documents displayed in the Multi-Platform Browser.

To add the System Keypad for the Multi-Platform Browser:

  • In the Multi-Platform Browser properties, set the System Keypad property to Enabled.

  • In the Target properties, define the properties for the System Keypad.
