11.3 Displaying Values Using Numeric Display

You can display the current value stored in device addresses.

There are two ways to display values: Numeric Display part and Value Animation.

  • Data Display: Use the Numeric Display tool, available on the Graphical Objects toolbar, to quickly create an object and configure its settings through a dialog box. Since parts allow you to select from predefined images, it is ideal for setting up the display quickly.

  • Value Animation: Use the Text object and add Value animation. Display values using this method to combine animations.
