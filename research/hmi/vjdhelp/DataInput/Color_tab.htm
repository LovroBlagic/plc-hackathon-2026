11.2.3 Color Tab

Use the Color tab to define the normal and warning color settings for all the elements of the Data Display, such as Text Color, 3D Text, Plate Color, Frame Color, and Text Blink.

 

The following table describes the Color tab properties.

Property

Description

Name

The object's name.

Whenever an object is created, a default name is generated. When renaming an object, its name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

For details, see Appendix 9, Naming Conventions.

Style

Use the Style list box to select the data display style you want.

Color Resource

Select the color resource that you created in the Resource Library for the Data Display.

For more information on using Resources in your parts, see Section 21.1.4.2, Selecting Resources for Your Part.

Normal Color Settings

Define the color settings with the following properties.

Text

Set the color of each component. The Color Palette is displayed when you click the color area. For more information, see Section 7.3.1, Color Palette.

You cannot set the color to Transparent.

  • If you want to set up a Data Display part with opaque text on a Transparent background, select 000000 from the Style List.
    Except for Text color, 000000 is always Transparent.

Frame Color settings are available only if you select a framed object.

The 3D text setting is only available if you selected 3D Style in the General tab. The selected color defines the shadow of the text.

When the font style in the General tab is not set to 3D, the 3D color property is grayed out.

The Plate Color setting defines the background color.

3D Text

Frame

Plate

Text Blink

Set up the blink speed—None, Fast, or Slow.

Warning Color Settings

Defines the color settings for four levels of warnings (HiHI, Hi, Lo, LoLo). For more information on the Text Color, 3D Text, Frame Color, Plate Color, and Text Blink properties, see the descriptions above.

HiHi

Hi

Lo

LoLo

Define the HiHi, Hi, Lo, and LoLo limits. You can use integer or real expressions.

At runtime, a HiHi or Hi warning occurs if the numeric value is greater than or equal to the HiHi or Hi value.

At runtime, a Lo or LoLo warning occurs if the numeric value is less than or equal to the Lo or LoLo value.
