11.6.1 Setting Up String Display

You can display text data in string variables using String Display or Value Animation. This section shows you how to display text using the String Display. If the text is written to a string variable from a keypad, keyboard, or script, the text will be displayed as is.

  • You should not create two string variables of different lengths that point to the same PLC address. You may get incorrect data in the string.

  1. Create a string variable. Specify the number of bytes the variable can store by setting the NumOfBytes property. For internal string variables, you can enter the initial string value.

  1. Click the Data Display object from the Graphical Objects Parts toolbar, and select String Display from the list.

  1. On the panel, click and draw the area where you want the string display, and then click again.

The String Display Settings dialog box opens.

  1. In the General tab, select:

  2. Variable

  3. Display Length: Number of Characters. Specify a number smaller than the variable's NumOfBytes property setting.

  • If you input more text than can be stored in the corresponding string variable (as defined in its NumOfBytes property), the input will be truncated.

  1. Select a Font Resource, or define the label settings, such as Font and Font Style, as required.

  1. In the Color tab, set up the color properties or select a Color Resource.

  1. Click OK to create a string display that displays the text stored in the string variable. After you execute runtime, the text defined in Initial Value is displayed on the target. If text is written to the string variable from keypad, keyboard, or script, the text is displayed as is.
