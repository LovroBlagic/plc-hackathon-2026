11.7.2.1 Setting Up a Text Display

  1. Using a text editor, create a text file in .txt format, and follow these formatting rules:

  • Use the Enter key to begin new lines.

  • Pay attention to the length of your lines. If a line in the text editor is longer than the width of the text display, the text is clipped in the display.

  • Insert two colons to identify the start of a text block. The two colons will not appear in the text display.

  • The following markers do not work.

  1. Save the text file. Select Unicode encoding when saving the file.

  1. In the Navigator window's Project tab, double-click Environment under the Target node, double-click Data Files, and then select the Text node to open the Text File Editor.

  1. In the Text File Editor, click the FileName row, and click the File Selection icon to display the Open dialog box and select the file created in step 1. Alternatively, you can type the path of the text file in the File Name field.

When you select the text file, the file name (without the file extension) is displayed in the Alias column. Change the alias name as required.

  • Alias is another name for the text file. For example, a path name (location of the file + file name) may be very long, such as "C:\CompressionMoldingLineProject\OperationManual\ExchangeSteps.txt." If you have several text files in the same location, it may become very difficult to distinguish these files. For this reason, the Text File Editor offers an Alias so you can manage many text files easily.

  • You can register up to 200 text files.

  1. If you want to display multiple text files, click Add and register the text files one by one. Each text file should use the same Alias with the final characters representing the three digit file number and two digit language number.

  1. Specify the storage location on the target machine for the text files.

 

Main Drive

You can store the text file in internal memory (flash memory).

Secondary Drive

You can store the text file on the Secondary Drive.

  1. In the Navigator window's Project tab, select the panel where you want to place the Text Display.

  1. Click the Toolchest icon in the menu bar to open the Toolchest window, and select the Text Display folder.

  1. Drag and drop the Text Display onto the panel, and resize as necessary.

  1. In the Property Inspector, change the text display properties.

The following table describes the Text Display properties.

Property

Description

Name

The object's name.

Whenever an object is created, a default name is generated. When renaming an object, its name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

For more information, see Appendix 9, Naming Conventions.

Description

Displays the part name. This property is read-only.

Version

Displays the version of Vijeo-Designer. This property is read-only.

Top

The coordinates, in pixels, of the top-left corner of the object.

  • Top is measured from the top of the object to the top of the panel. Enter a value from –32768 to (32767 minus object Height).

  • Left is measured from the left side of the object to the left side of the panel. Enter a value from –32768 to (32767 minus object Width).

By changing these properties, the graphical object can be moved up, down, left, and

right.

Left

Width

Defines the size (width and height) of the object in pixels. Enter values from 20 to 3000 for the Height, and from 10 to 3000 for the Width. By changing the values for these properties, you can change the object's width and height.

Height

FileName

Enter the alias, which is the name of the text file displayed in this part.

When using file or language numbers, do not include the file or language numbers at the end of the alias name.

FileNumber

Select True if you want to switch between multiple text files. To use the file number, the alias name of each text file must be the same with a three-digit number at the end of each alias to represent the file number. If you are switching between text files with different languages, you need a five-digit number.

You can combine this option with Block Number and Line Number.

FileNumberVariable

Specify the variable that stores the number of the current text file.

 

You can set up a variable placeholder. Select the structure variable and the element from the Variable List. To edit the variable placeholder you have set up for your object, in the Property Inspector for the object, click the ellipsis to open the Placeholders dialog box. The dialog box only displays if you had set up a placeholder for the object. For more information on placeholders, see Section 21.2.4, Working with Variable Placeholders.

BlockNumber

Select True if you've formatted the text file into blocks with double-colon (::) block indicators.

This option can be combined with File Number and Line Number.

BlockNumberVariable

Specify the variable that stores the block number. The number of the first block is zero.

You can set up a variable placeholder. Select the structure variable and the element from the Variable List. To edit the variable placeholder you have set up for your object, in the Property Inspector for the object, click the ellipsis to open the Placeholders dialog box. The dialog box only displays if you had set up a placeholder for the object. For more information on placeholders, see Section 21.2.4, Working with Variable Placeholders.

LineNumber

Select True if you want to jump to a specific line in the text file.

This option can be combined with File Number and Block Number. If you combine this option with block numbers, the line number specifies the line in a block, not the line in a file.

LineNumberVariable

Specify the variable that stores the line number. The number for the first line is zero.

  • When a specific line is already visible, specifying the line number does not change the display. Specify a line that is not currently in the display.

You can set up a variable placeholder. Select the structure variable and the element from the Variable List. To edit the variable placeholder you have set up for your object, in the Property Inspector for the object, click the ellipsis to open the Placeholders dialog box. The dialog box only displays if you had set up a placeholder for the object. For more information on placeholders, see Section 21.2.4, Working with Variable Placeholders.

Cursor

Select True if you want to change the text color for the current line. This property is available only if the Line Number is set to True.

Cursor BkColor

Specify the background and text colors for the cursor.

Cursor Color

Font

Specify in the Text Display the font, text size, and style for each language.

  • If you want to display a text file with 2-byte characters, make sure you select a font that supports those characters. For example, if you display a Japanese text file when an English/European font is selected, the text will not display properly.

Plate Color

Specify the background (area) and text colors for the entire Text Display.

Text Color

Text Alignment

Select from Left, Center and Right.

Frame Color

Specify the border color and the outer frame color (line color) for the Text Display.

Ruler

Select True if you want a line between each row of text.

Scroll Bar

If you select Show, a scroll bar will be displayed at the right side of the Text Display as illustrated below. You can use the scroll bar to scroll through the text file. The height of each row is defined by the font size.

A horizontal scroll bar is not available.

RestoreDefaults

The arrow button restores the original default property settings. A message prompts you to either continue or cancel the action.

Placeholder

Click the ellipsis to open the Placeholders dialog box and edit the variable placeholder for the object. The dialog box only displays if you had set up a placeholder for the object. For more information on placeholders, see Section 21.2.4, Working with Variable Placeholders.

 

  • The number of characters per line in the Text Display is determined by the width of the Text Display and the font size.

  • If text is clipped at the end of a line:

  • Adjust the Text Display width and Text Display font size.

  • Adjust the line breaks in the text file.
