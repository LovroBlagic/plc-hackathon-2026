11.8.6 Using Switches and String Displays to Display Documents

After you add and configure the Internet Explorer Browser or Multi-Platform Browser part in the editor, the document (applicable for both Browser parts) or URL (only applicable for the Internet Explorer Browser part) will display in the Browser during run time. Use the following methods to display or change documents in the Browser:

  1. Create a switch to display the document or URL in the Browser.

  2. Create a switch to add Browser operations to a Browser part.

  3. Create a string display to type in the document file name or URL address you want to display.

Display the Document or URL in the Browser Using a Switch

  1. Create a switch.

  2. In the Switch Settings dialog box, define the following properties:

  3. Operation: String.

  4. Source: Document's file name or URL in double quotes.

  5. Operation: Overwrite.

  6. Destination: Select the string variable.

  1. Click Add.

Add Browser Operations Using a Switch

  1. Create a switch.

  2. In the Switch Settings dialog box, define the following properties:

  • Operation: Browser.

  • Browser Object Name: Select the Browser object you are using.

  • Navigation Controls: Forward, Back, Reload, or Stop.

  1. Click Add.

Display a Document in the Browser Using a String Display

  1. Create a string display.

  2. In the String Display Settings dialog box, define the following properties:

  • Variable: Select the string variable.

  • Display Length: Set the length that would accommodate the number of characters in your document file name or URL address.

  • Enable Input Mode: Select the check box.

  1. Click OK.
