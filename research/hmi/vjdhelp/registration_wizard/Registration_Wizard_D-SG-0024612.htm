Requiring the Authorization Code
To require the Authorization Code, perform the following steps:
Step
Action
1
Start the Registration Wizard to register your software product.
For more information about starting the Registration Wizard, see Starting the Registration Wizard.
Result:
You are asked if you want to register the software now.
2
Click Yes.
Result:
The Select Task dialog box of the Registration Wizard is displayed.
3
Select Ask for an Authorization Code, and then confirm by clicking Next.
Result:
The wizard’s Select Registration Method dialog box is displayed. For further information on the different registration methods, see Registration Methods.
4
Select the registration method, and then confirm by clicking Next.
Result:
Depending on the registration method, you are prompted to provide user and license information either in the Registration Wizard’s User information dialog box shown below or on the SRC web site:
5
Enter the required user and license information, and then click Next in the Registration Wizard’s User information dialog box or Next on the SRC web site.
See also About Privacy to get more information about the privacy of your personal data.
See also Notes for Entering User and License Information to get more information where you can find the Part Number and Serial Number of your software product.
Result:
An Authorization Code Request form is generated. Depending on the registration method, the request form will be in the appropriate format to be communicated to the Schneider Electric SRC. For the detailed procedures, see Registration Procedures.
Notes for Entering User and License Information
When entering the required user and license information, at least the fields marked with an asterisk must be completed. Which fields are mandatory depends on the selected registration method.
You can find the Part Number and the Serial Number of your software product
  • on the box that contained your software product,
  • on the back of your software product CD case(s), or
  • on your certificate of authenticity.

Authorization Code
Numeric value which provides you with the rights to use the software product.
To enable the software, you are asked to enter an Authorization Code given by the Software Registration Center (SRC).
Software Registration Center (SRC)
A Schneider Electric department which processes the Authorization Code requests for software products. The SRC can be reached by phone, by fax and by web and by email to get an Authorization Code for your licence.
Part Number
It is a character string that characterizes a type of software product. For Schneider Electric software products, this Part Number is labeled on the box for your software product, on the back of your CD case(s) and on your certificate of authenticity.
Serial Number
It is an 11 digit character string that characterizes a single specimen of the software product. This Serial Number is labeled on the box for your software product, on the back of your CD case(s) and on your certificate of authenticity.
