authorization
To entitle you to use the software product legally.
An authorization is asking you to confirm in written form and officially that you are using the software product within the boundaries defined in the EULA (End User License Agreement) of the software product. Authorizations have primarily a legal impact.
Authorization Code
Numeric value which provides you with the rights to use the software product.
To enable the software, you are asked to enter an Authorization Code given by the Software Registration Center (SRC).
Code Entry Number
It is the random number that makes each installed software unique. This number is necessary to get an Authorization Code for your software product.
Computer ID
The primary purpose of the Computer ID number is to identify a specific PC hardware and/or software configuration. It is necessary to get an Authorization Code for your software product.
cookie file
A cookie file is used to transfer product and user information to the SRC and to receive the Authorization Code for the registration method by web and by web on another PC.
destination PC
PC with an unregistered software product. Transferring the registration information from another to this PC, see also Source PC.
EULA
End User License Agreement
Facility License
License agreement for a whole facility without a specific number of installed software products.
IP address
Internet Protocol address
P/N
see Part Number
Part Number
It is a character string that characterizes a type of software product. For Schneider Electric software products, this Part Number is labeled on the box for your software product, on the back of your CD case(s) and on your certificate of authenticity.
registration
The registration is the activity of storing the user information on the PC and send them to the Software Registration Center (SRC).
Registration Wizard
Program which guides you through the registration and transfer license right procedure.
removable media
A removable medium can be for example a floppy disk, a USB stick, a USB hard disk, a memory card or a PCMCIA card, etc.
S/N
see Serial Number
Serial Number
It is an 11 digit character string that characterizes a single specimen of the software product. This Serial Number is labeled on the box for your software product, on the back of your CD case(s) and on your certificate of authenticity.
Software Registration Center (SRC)
A Schneider Electric department which processes the Authorization Code requests for software products. The SRC can be reached by phone, by fax and by web and by email to get an Authorization Code for your licence.
source PC
PC with an registered software product for transferring the registration information from this to another PC, see also Destination PC.
SRC
see Software Registration Center
trial period
The software product will operate without being registered during this period.
update version
An Update Version enables you to update from a recent software product version xx.yy to a newer software product version xx.zz without losing the license.
Software Updates do not need an Authorization Code provided by SRC.
upgrade license
An upgrade license extends the capabilities of an already installed software product version.
Software upgrades always need an Authorization Code provided by the SRC.
USB
Universal Serial Bus
USB device
A USB device can be for example a USB stick or a USB hard disk.
USB stick
USB memory device for storing data
