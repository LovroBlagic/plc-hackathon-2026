Introduction
The following information is about how to start the registration process. You have 3 different possibilities to start the procedure.
Starting the Registration Wizard
There are the following 3 ways to start the Registration Wizard:
  • from the software product during trial period or when the trial period has been expired and the software product asks for registration,
  • from the About dialog box of the software product, or
  • from a shortcut in the program group.
After starting the Registration Wizard of an unregistered software product you will see a dialog box and an information about the status of your software product. The following list shows the information you will get:
  • if your software product is in the trial period
  • how often or how long you are able to start it as an unregistered software product (trial period)
  • if the trial period is already over
You need to press Yes to start the registration procedure during the trail period. You can press No if you want to start the unregistered software product during the trial period. For more information see Software Product Behavior. If you use an registered software product, this dialog box will not appear.
NOTE: If you use a software product with a mandatory registration and you press No after the trial period, the software product will not start again or it starts with a limited functionality.
