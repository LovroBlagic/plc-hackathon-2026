Introduction
In principle the Registration Wizard supports the following registration methods:
If you select...
Then...
Immediate 24/7
  • By web
  • By web on another PC
your software product is registered immediately.
If you want to use these methods, your internet browser must have cookies enabled. For more information on cookies, read the help provided with your internet browser.
Quick
  • By phone
you can register your software product as soon as you have called the Schneider Electric SRC and received the Authorization Code.
Delayed
  • By fax
  • By e-mail
you must wait for a response of Schneider Electric SRC, which may take up to 2 business days. Once you have received the Authorization Code, you can register your software product by selecting Enter received Authorization Code, see Entering the Received Authorization Code.
NOTE: The available registration methods vary depending on the kind of software product and version you are using.
NOTE: Precondition for a successful registration is that, depending on the method, the appropriate devices and connections are available and in working order. If you want to use web-based methods, your internet browser must have cookies enabled. For more information on cookies, read the help provided with your internet browser.
You can select the method in the Select Registration Method dialog box of the Registration Wizard, see Creating an Authorization Code Request
NOTE: If your software product can only be registered by web, then the Select Registration Method dialog box is not displayed.
Registration Procedure
Registering a software product requires the following main steps:
Step
Action
1
Create an Authorization Code Request, see Creating an Authorization Code Request.
Because you can select different registration methods, the procedure varies depending on the method. A detailed procedure is available for every method, see Registration Procedures.
2
Enter the received Authorization Code, see Entering the Received Authorization Code.
You need to enter the received Authorization Code in the following cases:
  • for every registration method, except by web,
  • if you interrupted the registration procedure after the Authorization Code Request, or
  • if you want to register a Facility License on further PCs. For the first PC, you need to ask for an Authorization Code and if you have received this Authorization Code you can also use it on further PCs.
If you register by web, you do not need to enter the Authorization Code manually.

Software Registration Center (SRC)
A Schneider Electric department which processes the Authorization Code requests for software products. The SRC can be reached by phone, by fax and by web and by email to get an Authorization Code for your licence.
Facility License
License agreement for a whole facility without a specific number of installed software products.
Authorization Code
Numeric value which provides you with the rights to use the software product.
To enable the software, you are asked to enter an Authorization Code given by the Software Registration Center (SRC).
