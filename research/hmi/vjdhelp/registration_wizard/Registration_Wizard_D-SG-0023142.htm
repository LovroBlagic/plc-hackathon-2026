Introduction
You can use the Registration Wizard for enabling all options of your license for your Schneider Electric software product.
NOTE: By registering a Schneider Electric software product, the licensee declares that the software product will be used within the boundaries described in the license agreement.
You can also use the Registration Wizard for transferring license rights between PCs, persons or companies.
Registering a Software Product
The complete registration procedure takes place in different procedures. The first procedure is the installation of the software product. The following procedure is to register the software product. You can use different methods to register your software product. Dependent on the registration method a third steps follows to complete the registration.
The different procedures are described in the following table:
Procedure
Description
Installation
The installation process temporarily enables the software product for the duration of a trial period. During the trial period, you should complete the registration. If you have not completed the registration until the end of the trial period, the functionality of the installed software product can be extremely reduced or it may not operate at all. The Registration Wizard will be still active after the trail period, so that you can proceed the registration.
For more information on the trial period, see Software Product Behavior.
Ask for an Authorization Code
You can register your software product by generating an Authorization Code Request. This request will be generated by using the Registration Wizard. The Authorization Code Request is sent to the Software Registration Center (SRC) providing information about the licensee, the software product and the PC on which it is installed. For more information, see Creating an Authorization Code Request.
The following registration methods are supported:
  • By web
  • By web on another PC
  • By phone
  • By e-mail
  • By fax
For more information, see Registration Methods.
Enter Received Authorization Code
This step is not essential and depends on the method you choose for the registration, e. g. in case of the registration By web the Authorization Code is entered automatically by the Registration Wizard.
As a result of receiving the Authorization Code Request, the SRC will issue an Authorization Code to permanently activate the software product allowing it to operate without any restrictions or reminders other than those imposed by the license rights. For more information, see Entering the Received Authorization Code.
Note: This step is essential in case of authoring a Facility License on a second or any further PC.
NOTE: The software products can only be registered on the PC on which they are installed and for which you have requested the Authorization Code, except Facility Licenses. For more information see Registering Facility Licenses.
However, you can transfer license rights. For further information, see Basics about Transferring License Rights. Facility Licenses cannot be transferred.
NOTE: For a Facility License, it is only required to ask for an Authorization Code once. Use the received Authorization Code for all of your PCs and select Enter received Authorization Code on each PC to be registered using the Facility License of the software product.
Other Functions of the Registration Wizard
The Registration Wizard also performs functions other than the ones mentioned.
The following table gives a description of these additional functions:
Function
Description
Upgrading
after an upgrade of a software product, it provides more capability and/or more features, e. g. from version M to version L, see Upgrading License Rights
Transferring
moving the software license rights from 1 PC to another, see Transfer via USB Device, Transfer via Removable Media and Transfer via Network
Transferring
moving the software license rights from 1 person/company to another, see Transferring the License to Another Person
Unavailable Options
Dependent on your software product some options or text boxes appear dimmed, that means they are not available.

Software Registration Center (SRC)
A Schneider Electric department which processes the Authorization Code requests for software products. The SRC can be reached by phone, by fax and by web and by email to get an Authorization Code for your licence.
Facility License
License agreement for a whole facility without a specific number of installed software products.
Authorization Code
Numeric value which provides you with the rights to use the software product.
To enable the software, you are asked to enter an Authorization Code given by the Software Registration Center (SRC).
