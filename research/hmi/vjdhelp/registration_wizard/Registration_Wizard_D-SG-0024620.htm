Introduction
If you need many installations of a Schneider Electric software product, Schneider Electric provides Facility Licenses for some software products.
That means you need to create an Authorization Code Request just once. After you have received the Authorization Code, you can register the software product on further PCs of your facility by using the same Authorization Code.
NOTE: Facility Licenses are only valid for 1 facility of your company.
NOTE: Please contact your nearest Schneider Electric service center to ask if a Facility License is available for your software product.
Authorization Code Request for Facility Licenses
For a Facility License you need to send only 1 Authorization Code Request to the SRC. This can be done in the same way as for other licenses (see Registration Methods).
NOTE: If you have received the Authorization Code for your Facility License then please write it on the CD case(s) or certificate of authenticity. This Authorization Code can be used to register all further PCs of your facility.
Registering an Additional PC
If you have a Facility License and want to register further PCs when the Authorization Code of the Facility License is already known, then perform the following steps:
Step
Action
1
Install the software product on the PC you want to register.
2
Start the Registration Wizard to register your software product, see Starting the Registration Wizard.
Note: If you use an unregistered software product, you need to click Yes to see the Select Task dialog box.
Result:
The Select Task dialog box of the Registration Wizard is displayed.
3
Select Enter received Authorization Code, and then confirm by clicking Next.
Result:
The wizard’s User Information dialog box is displayed as shown below:
4
Enter the required user and license information, and then click Next.
See also About Privacy to get more information about the privacy of your personal data.
See also Notes for Entering User and License Information to get more information where you can find the Part Number and Serial Number of your software product.
Result:
The wizard’s Enter received Authorization Code dialog box is displayed.
5
Enter the Authorization Code of the Facility License, and then click Next.
Result:
If the Authorization Code is correct, a dialog box is displayed prompting you to confirm the Part Number and the Serial Number of the software product that you want to register.
Note: If the Authorization Code is not correct, an error message is displayed and you must click OK and repeat this step.
6
Click OK to confirm the information.
Result:
The Exit the Registration Wizard dialog box is displayed.
7
Click Finish to close the Registration Wizard.
Result:
Your software product is now registered on this PC.

Software Registration Center (SRC)
A Schneider Electric department which processes the Authorization Code requests for software products. The SRC can be reached by phone, by fax and by web and by email to get an Authorization Code for your licence.
Authorization Code
Numeric value which provides you with the rights to use the software product.
To enable the software, you are asked to enter an Authorization Code given by the Software Registration Center (SRC).
Facility License
License agreement for a whole facility without a specific number of installed software products.
Part Number
It is a character string that characterizes a type of software product. For Schneider Electric software products, this Part Number is labeled on the box for your software product, on the back of your CD case(s) and on your certificate of authenticity.
Serial Number
It is an 11 digit character string that characterizes a single specimen of the software product. This Serial Number is labeled on the box for your software product, on the back of your CD case(s) and on your certificate of authenticity.
