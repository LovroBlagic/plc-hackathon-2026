Registering by Web
If you want to register your software product by web, perform the following steps:
Step
Action
1
In the Select Registration Method dialog box, click By web.
Result:
The Select Registration Method dialog box is displayed as follows:
2
Click Next.
Note: The PC on which you have installed the software product must have internet access.
Note: Your Internet Explorer must have cookies enabled to use this feature.
Result:
Your Internet Explorer is launched and the SRC web site is opened.
3
Enter the required user and license information and follow the instructions on the web site.
Note: At least, the fields marked with an asterisk must be completed.
Note: You can safe the information for further use by pressing Print. Schneider Electric recommends to do this to avoid the lost of information.
Note: In the special case of a Facility License, the Authorization Code will be displayed after the registration procedure again. Schneider Electric recommends to write the Authorization Code on the cover of the CD-ROM, because it will be used for the registration on further PCs.
Result:
The Authorization Code is generated immediately and the software product is registered on this PC without further action.
Registering by Web on Another PC
If you want to register your software product by web on another PC, perform the following steps:
Step
Action
1
On the PC on which the software product is installed, click By web on another PC in the Select Registration Method dialog box.
Result:
The Select Registration Method dialog box is displayed as follows:
2
Note the URL displayed in the dialog box, and then click Next.
Note: You can print the URL and the other information of the current dialog box by pressing Print.
Result:
The User Information dialog box is displayed.
3
Enter the required information, and then click Next.
Note: You should print the information of the current dialog box for further use by pressing Print.
Result:
The Enter received Authorization Code dialog box is displayed.
4
On a PC with internet access, start the internet browser and enter the URL you got in step 2.
Note: Your internet browser must have cookies enabled to use this feature.
Result:
The SRC web site is opened.
5
Follow the instructions on the web site.
Note: You must enter user and license information.
See also Notes for Entering User and License Information to get more information where you can find the Part Number and Serial Number of your software product.
Result:
The Authorization Code is generated immediately.
6
Note the generated Authorization Code.
Note: You can print the information of the current dialog box by pressing Print.
7
On the PC on which the software product is installed, enter the Authorization Code, and then click Next.
Note: If you already closed the Registration Wizard, you need to start the Enter received Authorization Code procedure again, see Entering the Received Authorization Code.
Result:
A confirmation dialog box is displayed.
Note: You can print the information of the current dialog box by pressing Print.
8
Click OK to close the confirmation dialog box.
Result:
The Exit the Registration Wizard dialog box is displayed.
9
Click Finish to close the Registration Wizard.
Result:
The software product is now registered on the PC on which it is installed.
Registering by Phone
If you want to register your software product by phone, perform the following steps:
Step
Action
1
In the Select Registration Method dialog box, click By phone.
Result:
The Select Registration Method dialog box is displayed as follows:
2
Click Next.
Result:
The User Information dialog box is displayed.
3
Enter the required user and license information. You can save the information for a further use by pressing Print.
Press Next to go further.
Note: At least, the fields marked with an asterisk must be completed.
See also About Privacy to get more information about the privacy of your personal data.
See also Notes for Entering User and License Information to get more information where you can find the Part Number and Serial Number of your software product.
Result:
The Call Registration Center dialog box is displayed.
4
Call the Schneider Electric SRC using the numbers displayed in the dialog box and press Next to open the Enter received Authorization Code dialog box. Follow the operators instructions.
Note: You will be asked for user and license information.
Result:
The Enter received Authorization Code dialog box is displayed. The SRC operator will provide an Authorization Code.
5
Note the provided Authorization Code and enter it. Click Next.
Result:
A confirmation dialog box is displayed.
Note: You can print the information of the current dialog box by pressing Print.
6
Click OK to close the confirmation dialog box.
Result:
The Exit the Registration Wizard dialog box is displayed.
7
Click Finish to close the Registration Wizard.
Result:
The software product is now registered on the PC on which it is installed.
Registering by Fax
If you want to register your software product by fax, perform the following steps:
Step
Action
1
In the Select Registration Method dialog box, click By fax.
Result:
The Select Registration Method dialog box is displayed as follows:
2
Click Next.
Result:
The User Information dialog box is displayed.
3
Enter the required user and license information.
Click Next to go further.
Note: At least, the fields marked with an asterisk must be completed.
See also About Privacy to get more information about the privacy of your personal data.
See also Notes for Entering User and License Information to get more information where you can find the Part Number and Serial Number of your software product.
Result:
The Select Fax Number dialog box is displayed.
4
Select 1 of the displayed fax numbers and use it to send the information to the selected SRC. Click Next to go further.
Result:
The Exit the Registration Wizard dialog box is displayed.
5
Click Finish to close the Registration Wizard.
Result:
The fax form for printing and transmitting is displayed.
6
Print and send the request to the SRC. The selected number is printed in the form.
Result:
The SRC will send response to your Authorization Code Request.
Note: Within 2 business days, the SRC will send a fax to the number you have given in the request form or if you have entered your e-mail address, you will get a response via e-mail. The fax or e-mail will contain the Authorization Code you need to register your software product.
7
Close the fax form.
Note: You can complete the registration when you have received the Authorization Code from SRC, see Entering the Received Authorization Code.
Registering by E-mail
If you want to register your software product by e-mail, perform the following steps:
Step
Action
1
In the Select Registration Method dialog box, click By e-mail.
Result:
The Select Registration Method dialog box is displayed as follows:
Note: Your PC must be connected to the network.
2
Click Next.
Result:
The User Information dialog box is displayed.
3
Enter the required user and license information. You can save the information for a further use by pressing Print.
Click Next to go further.
Note: At least, the fields marked with an asterisk must be completed.
See also About Privacy to get more information about the privacy of your personal data.
See also Notes for Entering User and License Information to get more information where you can find the Part Number and Serial Number of your software product.
Result:
The Select E-mail Address dialog box is displayed.
4
Select an e-mail address, and then click Next.
Result:
An e-mail containing your request is automatically sent to the SRC and the Exit the Registration Wizard dialog box is displayed.
Note: If an error occurs when sending the e-mail, it can also be sent manually using your standard e-mail program. Necessary data can be added to the e-mail by simply pasting the Windows clipboard content.
5
Click Finish to close the Registration Wizard and wait for the response.
Result:
Within 2 business days, the SRC will send an e-mail to the address you have given in the request form. The e-mail will contain the Authorization Code you need for registration of your software product.
Note: You can complete the registration when you have received the Authorization Code from SRC, see Entering the Received Authorization Code.

Facility License
License agreement for a whole facility without a specific number of installed software products.
Part Number
It is a character string that characterizes a type of software product. For Schneider Electric software products, this Part Number is labeled on the box for your software product, on the back of your CD case(s) and on your certificate of authenticity.
Serial Number
It is an 11 digit character string that characterizes a single specimen of the software product. This Serial Number is labeled on the box for your software product, on the back of your CD case(s) and on your certificate of authenticity.
Authorization Code
Numeric value which provides you with the rights to use the software product.
To enable the software, you are asked to enter an Authorization Code given by the Software Registration Center (SRC).
Software Registration Center (SRC)
A Schneider Electric department which processes the Authorization Code requests for software products. The SRC can be reached by phone, by fax and by web and by email to get an Authorization Code for your licence.
