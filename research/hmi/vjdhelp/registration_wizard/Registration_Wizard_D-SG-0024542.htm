What is the difference between the transfer via USB device and transfer via removable media?
The transfer via USB device is the option to transfer license rights by USB device. No information about the destination PC is required before the transfer process. The license rights are temporarily transferred from the source PC to a USB device from where it may be transferred back to the same or another PC. If your software product supports this transfer method it is recommended to use this method.
The transfer via removable media is the option to transfer license rights by removable media. The software must be installed on the target PC before the transfer process is started. The Computer ID and Code Entry Number of the destination PC are required during the transfer process.
Where can I find the requested information of the destination PC needed for transferring license rights via network or removable media?
During a transfer of license rights you will be asked to enter the Computer ID and Code Entry Number of the destination PC. You can find this information by running the Registration Wizard on the destination PC. Select the option Transfer License Rights and then click Next. The following screen will show you the Computer ID and Code Entry Number of the destination PC. It is recommended that you print this information to avoid mistakes when entering the information on the source PC. To avoid losing your license, it is strongly recommended to close the Registration Wizard on the destination PC before you transfer the license via network.
How can I locate a PC in the network if I want to transfer license rights via network?
If the PC is attached to a large network, the network browser is not always the best way to find the destination PC because it can take some time. If known, entering the destination PC's network name (e.g. \\DestinationComputername\) or the destination PC’s IP address (e.g. \\10.0.0.1\) is more efficient.
Why does the source PC not show the destination PC's shared folder?
Please check if you have the correct rights to access the destination PC. Contact your system administrator if you are in any doubt.
Why has the transfer of license rights via network failed?
Check the access rights of the shared folder. They must be set to read and write.
NOTE: The default access rights when using Windows XP are read only.
Can more than 1 license right of the same software product version be stored on a single media?
No, only 1 license right can be stored on a single removable media of the same software product version. If you attempt to save a second license right of the same software product version, an error message will be displayed.
How do I recover the media containing the license rights if it becomes faulty?
You cannot recover license rights from a faulty media. The license rights will be lost if
  • the hard drive containing an registered software product crashes,
  • faulty media is used for a transfer, or
  • you mistype the Computer ID or the Code Entry Number of the destination PC.
If you have lost your license rights during the transfer, please contact your nearest Schneider Electric service center.
What should I do if the source and destination PCs are not licensed after the license rights transfer?
If you have lost your license rights during the transfer of license rights, please contact your nearest Schneider Electric service center.
How do I save the license rights if the operating system on a PC that contains an registered software product must be reinstalled?
Use the transfer method Transfer license rights from this PC to another PC and then Transfer license rights to another PC via USB device to save the license rights on a USB device. If this option is not available for your software product you must transfer the license rights temporarily to another PC. Once the operating system has been reinstalled you can transfer the license rights back. For more information about transferring license rights, see Methods to Transfer License Rights.

removable media
A removable medium can be for example a floppy disk, a USB stick, a USB hard disk, a memory card or a PCMCIA card, etc.
source PC
PC with an registered software product for transferring the registration information from this to another PC, see also Destination PC.
Computer ID
The primary purpose of the Computer ID number is to identify a specific PC hardware and/or software configuration. It is necessary to get an Authorization Code for your software product.
Code Entry Number
It is the random number that makes each installed software unique. This number is necessary to get an Authorization Code for your software product.
destination PC
PC with an unregistered software product. Transferring the registration information from another to this PC, see also Source PC.
USB device
A USB device can be for example a USB stick or a USB hard disk.
