Introduction
You can transfer the license rights from your PC to another PC by using the network.
NOTE: Take care when transferring license rights. If you enter a wrong Computer ID or if network communication interrupts during the transfer, the license rights will be lost. In this case, please contact your Schneider Electric service center.
Transferring license rights by network requires various steps in the following sequence:
  1. steps performed to get the Computer ID of the destination PC
    Note: The software product program folder on the destination PC must be shared.
  2. steps performed to take the license rights from the source PC and give them to the destination PC
Getting the Computer ID of the Destination PC
To get the Computer ID of the destination PC, perform these steps on it:
Step
Action
1
Install the software product if you have not already done so.
2
Check that the software product on the destination PC is not already registered.
Note: If the software product on the destination PC is already registered, you will overwrite the license rights when transferring other license rights to this PC.
3
Configure the software product program folder and all subdirectories of the destination PC as shared.
Note: Make sure that the security option is set to full control. If you encounter problems when sharing the folder, please contact your system administrator.
4
Start the Registration Wizard, see Starting the Registration Wizard.
Result:
The wizard’s Select Task dialog box is displayed.
5
Select Transfer License Rights, and then click Next.
Result:
The wizard’s Select Transfer Task dialog box is displayed.
6
Write down the Computer ID of the destination PC shown in this dialog box or click Print to print out the data.
Note: If you make a mistake when writing down the Computer ID and use an incorrect number, the license rights will be lost. To avoid this, click Print to print out the data.
7
Click Cancel to close the Registration Wizard.
8
Close the software product.
Transferring the License Rights
To transfer the license rights from the source to the destination PC, perform the following steps on the source PC:
Step
Action
1
Start the Registration Wizard, see Starting the Registration Wizard.
Result:
The wizard’s Select Task dialog box is displayed.
2
Select Transfer License Rights, and then click Next.
Result:
The wizard’s Select Transfer Task dialog box is displayed.
3
Select Transfer license rights from this PC to another PC, and then click Next
Result:
The wizard’s Select Transfer Method dialog box is displayed.
4
Select Transfer licence rights to another PC via network, and then click Next.
Result:
The wizard’s Transfer Information dialog box is displayed.
5
In the Transfer Information dialog box, click OK if the software product on the destination PC is not registered.
Result:
The wizard’s Destination PC - License Rights Transfer is displayed as follows:
6
Enter and confirm the Computer ID of the destination PC, and then click Next.
Note: If you make a mistake when entering the Computer ID, the license rights will be lost.
Result:
A message box appears
7
Click Ok to confirm the message.
Result:
The wizard’s Choose Location of the Product dialog box is displayed.
8
Navigate to the shared folder of the destination PC, and then click Next.
Result:
If the transfer was successful, the Exit the Registration Wizard dialog box will be displayed and the software product on the source PC is no longer registered. The software product on the destination PC is now registered and will run accordingly.
9
Click Finish to close the Registration Wizard.
Note: The shared options of the software product program folder can be revoked now on the destination PC.
10
Close the software product.

Computer ID
The primary purpose of the Computer ID number is to identify a specific PC hardware and/or software configuration. It is necessary to get an Authorization Code for your software product.
source PC
PC with an registered software product for transferring the registration information from this to another PC, see also Destination PC.
destination PC
PC with an unregistered software product. Transferring the registration information from another to this PC, see also Source PC.
