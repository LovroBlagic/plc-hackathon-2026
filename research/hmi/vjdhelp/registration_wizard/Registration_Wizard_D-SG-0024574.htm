Introduction
You can transfer license rights of already registered software products by using the Registration Wizard.
Transfer Tasks and Methods
Transferring license rights is possible in the following ways:
  • transferring the license rights from one PC to another using
    • a USB device (Computer ID of the destination PC need not to be known)
    • a removable medium (Computer ID and Code Entry Number of the destination PC must be known)
    • a network (Computer ID of the destination PC must be known)
  • transferring the license rights from a removable media to a PC
  • transferring the license to another person or company
NOTE: The available transfer methods vary depending on the kind of software product and version you are using.
NOTE: In either case, license rights can be active on only one PC at a time.
NOTE: Take care when transferring license rights. If you enter a wrong Computer ID or Code Entry Number, or if damage occurs to the removable media, the license rights will be lost. In this case, please contact your Schneider Electric service center.
NOTE: We recommend to transfer license rights only if the software product and the version of the software product is the same on both source and destination PCs because license rights transfer between different software versions may lead to the loss of license.

Transfer from Removable Media to Another PC
You can use the option Transfer license rights from a removable media to this PC to transfer the license rights from the removable media to your PC.
Before you can perform this transfer one of the following steps is required:
  • Transfer license rights to another PC via USB device
    For more information on the transfer procedure, see Transfer via USB Device.
  • Transfer license rights to another PC via removable media
    For more information on the transfer procedure, see Transfer via Removable Media.
Transfer to Another Person or Company
Transferring the license to another person or company consists in modifying the licensee information on the PC on which the software product is registered. The new licensee information is sent to the SRC.
After a transfer to another person or company, it is possible to physically transfer license rights to another PC.
For more information on the transfer procedure, see Transferring the License to Another Person.

destination PC
PC with an unregistered software product. Transferring the registration information from another to this PC, see also Source PC.
Code Entry Number
It is the random number that makes each installed software unique. This number is necessary to get an Authorization Code for your software product.
Computer ID
The primary purpose of the Computer ID number is to identify a specific PC hardware and/or software configuration. It is necessary to get an Authorization Code for your software product.
USB device
A USB device can be for example a USB stick or a USB hard disk.
removable media
A removable medium can be for example a floppy disk, a USB stick, a USB hard disk, a memory card or a PCMCIA card, etc.
Software Registration Center (SRC)
A Schneider Electric department which processes the Authorization Code requests for software products. The SRC can be reached by phone, by fax and by web and by email to get an Authorization Code for your licence.
