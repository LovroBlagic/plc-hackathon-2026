Handling Specific Situations
The following table lists specific situations that may arise and describes how to handle them:
If you...
Then you...
plan to transfer license rights from the destination PC back to the source PC
can simply apply the transfer procedure again. It is not necessary to uninstall and reinstall the software product.
have submitted an Authorization Code request
must wait for the Authorization Code and enter it on the PC from which it originated before transferring license rights to or from another PC.
need to save your license rights because the operating system on a PC that contains an registered software product must be reinstalled
must transfer the license rights temporarily to a USB device (see Transfer via USB Device).
If this option is not available then you must transfer the license rights temporarily to another PC, see Transfer via Removable Media or Transfer via Network.
Once the operating system has been reinstalled you can transfer the license rights back.

destination PC
PC with an unregistered software product. Transferring the registration information from another to this PC, see also Source PC.
source PC
PC with an registered software product for transferring the registration information from this to another PC, see also Destination PC.
Authorization Code
Numeric value which provides you with the rights to use the software product.
To enable the software, you are asked to enter an Authorization Code given by the Software Registration Center (SRC).
USB device
A USB device can be for example a USB stick or a USB hard disk.
