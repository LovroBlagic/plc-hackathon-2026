Where can I find the Serial or Part Number?
The Serial Number or Part Number of your software product are labeled on
  • the box for your software product,
  • the back of your CD case(s), or
  • on your certificate of authenticity.
NOTE: Do not use the number printed on the software product CD itself instead of the Serial Number.
If you require additional assistance or want to speak to someone about how to obtain your Serial Number, please contact your Schneider Electric service center.
Why does the Registration Wizard open a new blank form but no web pages when I try to register by web?
The Registration Wizard uses the Internet Explorer to connect to the SRC web page. If there is no Internet connection available on your PC and you want to use Web registration you can use the option By web on another PC.
How does the e-mail registration deliver the request e-mail?
E-mail registration delivers the request e-mail directly with the Registration Wizard. It uses the SMTP protocol. If the SMTP protocol is blocked by a firewall in your network, your standard e-mail program will be opened and you can paste the content of the clipboard into the e-mail program to send it manually.
You also have the possibility to use an alternative SMTP server which is not blocked by your firewall. For a detailed description how to configure an alternative SMTP server, please refer to How can I configure an alternative SMTP server used for e-mail registration?.
What happens if a failure occurs during e-mail registering?
If e-mail registration fails at sending time, a copy of the e-mail is sent to the Windows clipboard. This copy can be simply pasted into your personal e-mail software to send it manually to the SRC.
How can I configure an alternative SMTP server used for e-mail registration?
To configure the SMTP server, perform the following steps:
Step
Action
1
Select Start → All programs → Accessories → Command Prompt to start a Command Prompt.
If you are using the operating system Windows Vista, start the Command Prompt by selecting Start → All programs → Accessories → Command Prompt and right-click the Command Prompt. Then select the option Run as administrator in the context menu.
2
Change to the directory of the RegistrationWizard.exe by entering a command in the Command Prompt and confirm the entry with ENTER:
e.g. cd/d "C:\Programs\Schneider Electric\MyProduct\Registration"
Note: The path of the RegistrationWizard.exe depends on the software product and may differ if you have not used the default path during installation.
Result: The path to the RegistrationWizard.exe is displayed in the Command Promt, e.g. C:\Programs\Schneider Electric\MyProduct\Registration> .
3
To open the Set SMTP Server dialog box, enter the following command in the Command Prompt and confirm the entry with ENTER:
RegistrationWizard.exe SET_SMTP_SERVER
Result: The Set SMTP Server dialog box is displayed.
4
Enter the name of an alternative SMTP server (e.g. smtp.example.com) and confirm your entry with OK.
Result: The SMTP server is configured and can be used for e-mail registration.
Where can I get support during registration or transfer of license rights?
If you need support during registration or transfer of license rights, click on the Support button on the start page of your Registration Wizard (Select Task dialog box) to get a list of Software Registration Centers. You can print-out the information by clicking the Print button.
Where can I get the fax form, because it was not displayed after the Registration Wizard has finished?
The Registration Wizard saves the fax as a text file. The name of the file depends on the software product, e.g. MyProduct_Fax_Sheet.txt. You will find this file in the temporary directory, e. g. \TMP or \TEMP. The Registration Wizard will then attempt to start the program that is associated with files that have the .txt file extension. If the file is not displayed open it manually, using a text editor such as Notepad, in order to print and fax it.
Why do I get the error message: Invalid Authorization Code?
There are several possible reasons for getting this error message dependant on the used registration method:
  1. registration by web on another PC, by phone, by e-mail, by fax
  2. registration by web
In case of a registration by web on another PC, by phone, by e-mail or by fax the error occurs when:
  • a wrong Authorization Code has been entered, that means an error was made when typing the Authorization Code.
  • an error was made while entering information about the PC to register (Computer ID or Code Entry Number).
  • an error was made writing down your Authorization Code for your notes on a paper or CD case (e.g. for a Facility License).
  • the wrong Part Number and/or Serial Number was entered during Authorization Code Request.
In these cases the solution is to check the entered numbers and carefully reenter the information. If necessary start a new Authorization Code Request or contact your nearest Schneider Electric service center.
In case of a registration by web the error occurs when:
  • cookies are not enabled in your browser.
  • the wrong Part Number or Serial Number was entered during registration by web.
The solution is to enable the cookies in your browser and to start a new Authorization Code Request with the correct Part Number and Serial Number or to contact your nearest Schneider Electric service center.
Is the user information saved on the PC during the registration process?
All information is saved for the actual user account during the registration process. If you are going to register again to upgrade your software product, it is not necessary to enter this information again.

Software Registration Center (SRC)
A Schneider Electric department which processes the Authorization Code requests for software products. The SRC can be reached by phone, by fax and by web and by email to get an Authorization Code for your licence.
Computer ID
The primary purpose of the Computer ID number is to identify a specific PC hardware and/or software configuration. It is necessary to get an Authorization Code for your software product.
Code Entry Number
It is the random number that makes each installed software unique. This number is necessary to get an Authorization Code for your software product.
Authorization Code
Numeric value which provides you with the rights to use the software product.
To enable the software, you are asked to enter an Authorization Code given by the Software Registration Center (SRC).
cookie file
A cookie file is used to transfer product and user information to the SRC and to receive the Authorization Code for the registration method by web and by web on another PC.
Part Number
It is a character string that characterizes a type of software product. For Schneider Electric software products, this Part Number is labeled on the box for your software product, on the back of your CD case(s) and on your certificate of authenticity.
Serial Number
It is an 11 digit character string that characterizes a single specimen of the software product. This Serial Number is labeled on the box for your software product, on the back of your CD case(s) and on your certificate of authenticity.
