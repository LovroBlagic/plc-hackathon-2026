Transfer License Rights from this PC to another PC
 
 
Overview
This section describes several possibilities to transfer license rights from a source PC to a destination PC. You can perform the transfer via USB device, removable media or via network.
NOTE: We recommend to perform the transfer via USB device, if this transfer option is available. The available transfer options depend on the kind of software product and the version you are using.
What's in this Section?
This section contains the following topics:
  • Transfer via USB Device
  • Transfer via Removable Media
  • Transfer via Network

source PC
PC with an registered software product for transferring the registration information from this to another PC, see also Destination PC.
destination PC
PC with an unregistered software product. Transferring the registration information from another to this PC, see also Source PC.
removable media
A removable medium can be for example a floppy disk, a USB stick, a USB hard disk, a memory card or a PCMCIA card, etc.
USB device
A USB device can be for example a USB stick or a USB hard disk.
