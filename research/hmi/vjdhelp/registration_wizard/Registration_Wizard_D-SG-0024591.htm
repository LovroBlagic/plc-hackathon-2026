Transfer via USB Device

Introduction
You can transfer the license rights to another PC by using a USB device.
NOTE: Take care when transferring license rights. If any damage occurs to the USB device, the license rights will be lost. In this case, please contact your Schneider Electric service center.
Transferring license rights by a USB device requires various steps in the following sequence:
  1. steps performed on the source PC
  2. steps performed on the destination PC
NOTE: We recommend to perform the transfer via USB device, if this transfer option is available. The available transfer options depend on the kind of software product and version your are using.
Steps to be Performed on the Source PC
To transfer license rights using a USB device, perform the following steps on the source PC:
Step
Action
1
Start the Registration Wizard, see Starting the Registration Wizard.
Result:
The wizard’s Select Task dialog box is displayed.
2
Select Transfer License Rights, and then click Next.
Result:
The wizard’s Select Transfer Task dialog box is displayed.
3
Select Transfer license rights from this PC to another PC, and then click Next.
Result:
The wizard’s Select Transfer Method dialog box is displayed.
4
Select Transfer license rights to another PC via USB device, and then click Next.
Result:
The wizard’s Select Drive dialog box is displayed.
5
Insert the USB device and wait until Windows has detected it.
6
In the Select Drive dialog box, navigate to the USB device, and then click Next.
Click Refresh if you do not see the drive letter of your USB device.
Result:
If the transfer was successful, the Exit the Registration Wizard dialog box will be displayed. The software product on the source PC is no longer registered.
7
Click Finish to close the Registration Wizard.
Now, you can remove the USB device correctly.
8
Close the software product.
Steps to be Performed on the Destination PC
To transfer license rights using a USB device, perform the following steps on the destination PC:
Step
Action
1
Insert the USB device used on the source PC and wait until Windows has detected it.
2
Start the Registration Wizard, see Starting the Registration Wizard.
Result:
The wizard’s Select Task dialog box is displayed.
3
Select Transfer License Rights, and then click Next.
Result:
The wizard’s Select Transfer Task dialog box is displayed. Select the option Transfer license rights from a removable media to this PC.
4
Click Next.
Result:
The wizard’s Select Drive dialog box is displayed.
5
In the Select Drive dialog box, navigate to the USB device, and then click Next.
Click Refresh if you do not see the drive letter of your USB device.
Result:
If the transfer was successful, the Exit the Registration Wizard dialog box will be displayed. The software product on the destination PC is now registered.
6
Click Finish to close the Registration Wizard. Now, you can remove the USB device correctly.

source PC
PC with an registered software product for transferring the registration information from this to another PC, see also Destination PC.
destination PC
PC with an unregistered software product. Transferring the registration information from another to this PC, see also Source PC.
USB device
A USB device can be for example a USB stick or a USB hard disk.
