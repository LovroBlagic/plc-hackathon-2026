Transfer via Removable Media
 
Submit Feedback
Introduction
You can transfer the license rights to another PC by using a removable media. Not all types of removable media are qualified for transferring license rights. Only those that have read and write capability can be used (e.g. floppy disks, USB sticks, USB hard disks, memory cards or PCMCIA cards, etc.).
NOTE: You can not use CDs or DVDs for transferring license rights.
NOTE: Take care when transferring license rights. If you enter a wrong Computer ID or Code Entry Number, or if damage occurs to the removable media, the license rights will be lost. In this case, please contact your Schneider Electric service center.
Transferring license rights by removable media requires various steps in the following sequence:
  1. steps performed to get the Computer ID and Code Entry Number of the destination PC
  2. steps performed to take the license rights from the source PC
  3. steps performed to give the license rights to the destination PC
Getting the Computer ID and Code Entry Number of the Destination PC
To get the Computer ID and Code Entry Number of the destination PC, perform these steps on it:
Step
Action
1
Install the software product if you have not already done so.
2
Check that the software product on the destination PC is not already registered.
Note: If the software product on the destination PC is already registered, you will overwrite the license rights when transferring other license rights to this PC.
3
Start the Registration Wizard, see Starting the Registration Wizard.
Result:
The wizard’s Select Task dialog box is displayed.
4
Select Transfer License Rights, and then click Next.
Result:
The wizard’s Select Transfer Task dialog box is displayed
5
Write down the Computer ID and Code Entry Number of the destination PC shown in this dialog box or click Print to print out the data.
Note: If you make a mistake when writing down the Computer ID or Code Entry Number and use an incorrect number, the license rights will be lost. To avoid this, click Print to print out the data.
6
Click Cancel to close the Registration Wizard.
Taking the License Rights from the Source PC
To take the license rights from the source PC, perform these steps on it:
Step
Action
1
Start the Registration Wizard, see Starting the Registration Wizard.
Result:
The wizard’s Select Task dialog box is displayed.
2
Select Transfer License Rights, and then click Next.
Result:
The wizard’s Select Transfer Task dialog box is displayed.
3
Select Transfer license rights from this PC to another PC, and then click Next.
Result:
The wizard’s Select Transfer Method dialog box is displayed.
4
Select Transfer license rights to another PC via removable media, and then click Next.
Result:
The wizard’s Transfer Information dialog box is displayed.
5
In the Transfer Information dialog box, click OK if the software product on the destination PC is not registered.
Result:
The wizard’s Destination PC - License Rights Transfer dialog box is displayed as follows:
6
Enter and confirm the Computer ID and Code Entry Number of the destination PC which you have written down or printed out before, and click Next.
Note: If you make a mistake when entering the Computer ID or Code Entry Number, the license rights will be lost.
Result:
The wizard’s Select Drive dialog box is displayed.
7
Insert the removable media and wait until Windows has detected it when you use a USB device.
8
In the Select Drive dialog box, navigate to the removable media, and then click Next.
Click Refresh if you do not see the drive letter from your removable media.
Result:
If the transfer was successful, the Exit the Registration Wizard dialog box will be displayed. The software product on the source PC is no longer registered.
9
Click Finish to close the Registration Wizard.
Now, you can remove the removable media from the source PC correctly.
10
Close the software product.
Giving the License Rights to the Destination PC
To give the license rights to the destination PC, perform these steps on it:
Step
Action
1
Insert the removable media and wait until Windows has detected it.
2
Start the Registration Wizard, see Starting the Registration Wizard.
Result:
The wizard’s Select Task dialog box is displayed.
3
Select Transfer License Rights, and then click Next.
Result:
The wizard’s Select Transfer Task dialog box is displayed.
4
Select Transfer license rights from a removable media to this PC, and then click Next.
Result:
The wizard’s Select Drive dialog box is displayed.
5
In the Select Drive dialog box, navigate to the removable media, and then click Next.
Click Refresh if you do not see the drive letter from your removable media.
Result:
If the transfer was successful, the Exit the Registration Wizard dialog box will be displayed. The software product on the destination PC is now registered.
6
Click Finish to close the Registration Wizard. Now, you can remove the removable media from the destination PC correctly.

Computer ID
The primary purpose of the Computer ID number is to identify a specific PC hardware and/or software configuration. It is necessary to get an Authorization Code for your software product.
Code Entry Number
It is the random number that makes each installed software unique. This number is necessary to get an Authorization Code for your software product.
removable media
A removable medium can be for example a floppy disk, a USB stick, a USB hard disk, a memory card or a PCMCIA card, etc.
USB device
A USB device can be for example a USB stick or a USB hard disk.
source PC
PC with an registered software product for transferring the registration information from this to another PC, see also Destination PC.
destination PC
PC with an unregistered software product. Transferring the registration information from another to this PC, see also Source PC.
