Failed to Open PDF File

If you see this page and the document you are looking for does not open, please try the following.

  • The document does not open because there is no associated application. You may have to install Acrobat Reader.

  • A message box reads "Unable to start (document)." To remove the dialog box, close Help.
    To view the document correctly, do one of the following:

    • In Windows Explorer, open the file from this folder ..\Schneider Electric\Vijeo-Designer\Vijeo-Frame\Help\
    • Exit Vijeo-Designer and restart the application.
