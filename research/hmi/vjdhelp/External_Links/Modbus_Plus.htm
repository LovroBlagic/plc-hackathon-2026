Modbus Plus

You can find the information about Modbus Plus in the PDF file that opened in Adobe Acrobat Reader when you linked to this topic.

  • To run Modbus Plus USB in simulation, you must install the Schneider Electric MBX driver suite. On the Vijeo Designer Installer DVD, select the "Tools\Modbus Plus Driver Suite" path and then double-click Driver.exe. Follow the installation wizard.

  • To run Modbus Plus USB on XBTGTW and iPC target machines, you must purchase and install the Schneider Electric MBX driver suite onto the target machine. Contact your local distributor for more information.
