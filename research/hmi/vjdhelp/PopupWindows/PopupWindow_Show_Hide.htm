15.2.2 Displaying and Hiding Popup Windows

Switches and scripts are used to open and close popup windows. This section explains how to configure a switch to open a popup window and how to configure a switch to close a popup window. For information on how to open or close a popup window using a script, see Section 18.3.8.3, Popup Window Methods.

Creating a Switch to Open a Popup Window

  1. On the Graphical Objects parts toolbar, click the Switch tool and select Switch.

  1. Draw the area on the panel where you want the switch. The switch settings dialog box appears once the switch is drawn.

  1. In the When Touch tab, select Popup from the Operation list.

  1. You cannot select Popup from Operation list in the While Touch tab.

  1. Select Open Popup from the drop-down list box.

  1. Select either Panel Name or Panel ID (Expression), and follow the steps in the table below for your selection.

 

Property

Description

Panel Name

Allows you to set a specific popup window panel the switch opens.

  • Use the drop-down list box to specify which popup window panel the switch opens

Panel ID (Expression)

Allows you to use an expression or a variable to define which popup window panel the switch opens.

  1. In the drop-down list box, specify a popup window group. This popup window group's properties (height, width, and mode) are used for the popup window panel's properties.

  1. Click the Expression Icon to display the Expression Editor Pad.

  1. In the Expression Editor Pad, either create an expression to specify which popup window panel opens, or create a variable whose value will specify which popup window panel opens.

  2. Click OK.

  • You should only display popup window panels that are from the popup window group specified in the Panel ID (Expression) drop-down list.

  1. In the Location area, select either At Position or Centered to define the (x,y) coordinates—specified in pixels—of the popup window panel's top-left corner.

  • If you specify (0,0) as the x,y coordinates, the top left corner of the popup window panel displays in the top-left corner of the graphical panel.

  • If you select Center, the top-left corner of the popup window displays at the center of the panel.

  1. Click Add to add the Open Popup operation for your switch, then click OK.

  • For details about creating a switch, see Section 9.2, Creating Switches.

  • You can also set up the same operation with Touch Animation.
    For details about switches, see Section 9.2.7, Creating a Custom Switch.

Create a Switch to Hide a Popup Window

  1. On the Graphical Objects parts toolbar, click the Switch tool and select Switch.

  1. Draw the area on the panel where you want the switch. The switch settings dialog box appears once the switch is drawn.

  1. In the When Touch tab, select Popup from the Operation list.

  1. Select Close Popup from the drop-down list box.

  1. Select either Panel Name or Panel ID (Expression), and follow the steps in the table below for your selection.

 

Property

Description

Panel Name

Allows you to set a specific popup window panel the switch opens.

  • Use the drop-down list box to specify which popup window panel the switch opens

Panel ID (Expression)

Allows you to set a popup window group the switch closes. The switch will close all open popup window panels that are within the selected popup window group.

  • In the drop-down list box, specify a popup window group

  1. Click Add to add the Close Popup operation for your switch, and then click OK.

  • For more information about creating a switch, see Section 9.2, Creating Switches.

  • You can also set up the same operation with Touch Animation.
    For more information, see Section 9.2.7.2, Setting Up Touch Animation.
