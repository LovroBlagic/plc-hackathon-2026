15.1 Creating Popup Windows

A popup window opens over the current panel. If you use a popup window for keypad input, you can open it when necessary, and close it when input is complete. You can open and close a popup window, or change the current panel using a switch, Touch animation, or script.

  • When you draw switches or other touch objects on popup window panels on target machine that supports a 40X40 touch grid, make sure the switch or touch object is aligned with the touch grid on the base panel, not the touch grid on the popup window. See Appendix 5, Hardware Specification, for your target's supported touch grid.

15.1.1 Basic Components of Popup Windows

Popup windows are composed of three components: Folders, groups, and panels.

When you create a project, a popup window folder is automatically generated. You can create multiple popup window groups and popup window panels in the folder.

The following table describes the three popup window components.

Component

Description

Popup Window Folder

This node is automatically generated when you create a project.

You can create popup window groups and popup window panels in this folder. This folder cannot be copied, deleted, or renamed.

Popup Window Group

You can add multiple popup window panels to a group. When you open the popup window, you can change the panel so long as the panel belongs to the same group.

Specify popup window properties, such as window size and display mode, in this node.

The popup window group is displayed in the format Group number: Group name, for example, 1: Window1.

Popup Window Panel

Create one or more popup window panels within a group. You can define the display of specific popup window panels within that group.

The popup window panel is displayed in the format Panel Number: Panel Name, for example, 10001: Panel4.

 

15.1.2 Steps to Set Up Popup Windows

Follow the steps below to set up popup windows.

Steps

1. Create a popup window group.

If you are creating a popup window for the first time, a default popup window group is available. Skip this step and start from Step 2.

2. Create a popup window panel, and draw graphical objects and/or parts on the panel.

3. Save the popup window panel, and return to a standard panel.

4. In the standard panel, create a Switch or Touch animation to show/hide the popup window.

You can also use scripts to show/hide popup windows.
