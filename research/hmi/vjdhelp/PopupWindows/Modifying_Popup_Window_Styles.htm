15.2.3 Defining Popup Window Styles

For iPC and XBTGTW target types, you can define the following window styles for a popup window — Frame Only, Frame with Title Bar, or None. This setting enables you to create popup windows that have a consistent look throughout your project.

At runtime, the popup window displays on the iPC or XBGTW target machine using the window style you specified:

  • Frame Only

  • Frame with Title Bar

  • None

To set up a window style for your popup windows:

  1. In the Navigator window, click the Popup Windows node.

  2. In the Property Inspector for the Popup Windows, select one of the following window styles:

  3. Frame Only

  4. Frame with Title Bar

  5. None.
