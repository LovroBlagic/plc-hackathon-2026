12.3.2.1 General Tab

This section describes the features in the Bar Graph Settings General tab for the Vertical Bar Graph and the Horizontal Bar Graph.

 

The table below describes the General tab's features for both the horizontal Bar Graph and the vertical Bar Graph.

Property

Description

Name

The Bar Graph's name.

The Bar Graph's name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions described in Appendix 9, Naming Conventions.

Data Type

Select the Bar Graph's display format.

  • Integer
    The Bar Graph displays integer values.

  • Float
    The Bar Graph displays real values. You can define the number of decimals to display in the Automatic labels. See the Display Digits field in Section 12.3.2.3, Label Tab for more information.

Variable

Defines the variable or the expression that controls the Bar Graph.

The Variable field accepts real and integer variables and expressions.

  • If you configure an expression in the Variable property, Input Mode becomes unavailable. Expressions also do not work with the Use Variable's Min/Max property.

Use Variable's Min/Max

When enabled, the Bar Graph uses the Min/Max values specified in the selected variable's Input Range. See Section 6.2.3, Variable Properties for more information on Variable's Input Range.

  • The Use Variable's Min/Max property does work when you have specified an expression in the Variable field.

Min Value

Defines the minimum value the Bar Graph will display.

You can use a constant, a variable, or an expression as the Min Value.

Max Value

Defines the maximum value the Bar Graph will display.

You can use a constant, a variable, or an expression as the Max Value.

Category

The Category's drop-down list defines the Bar Graph's Plate Style.

Select from:

  • Primitive
    Primitive allows you select the Bar Graph's Plate Style from the predefined styles available in the Plate Style drop-down list.

  • User Defined
    User Defined allows you to select your own image as the Bar Graph's Plate Style. Add the image to the Bar Graph in the Color tab; see Section 12.2.2.2, Color Tab.

Plate Style

Available when Category is set to Primitive. Select the Bar Graph's Plate Style from the drop-down list. Click Browse to open a Style Browser that contains a larger list of Plate Styles to choose from.

  • The Plate Style must be set to 000000 to create a thin bar graph.

Specify the position of both the Indicator and the scales on the Bar Graph.

Vertical Bar Graph

Center

The Indicator is located in the center and the scales are overlaid.

The Indicator is located at the top and the scales are located at the bottom.

The Indicator is located on the right side and the scales are located on the left side.

 

Indicator Size

Specify the Indicator's size. Size is defined as a percentage of the Bar Graph's width. Percentage is measured differently if the labels are disabled or enabled. See below for more information.

  • The Indicator's size cannot be less than 20%.

  • The Indicator's size must be set to 100% to create a thin bar graph.

When labels are disabled, size is defined as a percentage of the total width of the Bar Graph.

When labels are enabled, width is defined as a percentage of the width between the edge of the plate and the edge of the label.

Start Point

Specify the Indicator's start point on the Bar Graph.

The table below shows how the different Start Point settings affect the Indicator direction.

  • Labels are not supported when Center (Both Sides) is selected for the Fill Start Point.

Horizontal Bar Graph

Vertical Bar Graph

Left

The Bar Graph's Indicator starts on the left and fills to the right as the value increases.

Bottom

The Bar Graph's Indicator starts at the bottom and fills upward as the value increases.

Center (Both Sides)

The Bar Graph's Indicator starts in the center and fills equally right and left as the value increases.

Center (Both Sides)

The Bar Graph's Indicator starts in the center and fills equally up and down as the value increases.

Center (One Side)

The Bar Graph's Indicator starts in the center. The Indicator fills to the right when the value increases and the Indicator fills to the left as the value decreases.

This setting allows you to set the Indicator start point using the Zero Point property. See the Zero Point description below.

  • If Zero Point is disabled, the Bar Graph's center is set as the Indicator's Start Point.

Center (One Side)

The Bar Graph's Indicator starts in the center. The Indicator fills upward when the value increases and the Indicators fills downward as the value decreases.

This setting allows you to set the Indicator start point using the Zero Point property. See the Zero Point description below.

  • If Zero Point is disabled, the Bar Graph's center is set as the Indicator's Start Point.

Right

The Bar Graph's Indicator starts from the right and fills to the left as the value increases.

Top

The Bar Graph's Indicator starts from the top and fills downward as value increases.

Zero Point

Available when Start Point is set to Center (One Side).

Specify the value for the Indicator's Start Point using a constant, a variable, or an expression.

Scale

Define the properties for the Bar Graph's scale.

  • Labels are not supported if the Major Scales are disabled.

  • The Bar Graph's scale must be disabled to create a Thin Bar Graph.

Major

Minor

Number of Divisions

Specify the number of major and minor divisions for the Bar Graph's scales.

  • Major: 1-32

  • Minor: 1-16

Width

Specify the width of the Bar Graph's Major and Minor scales. Select a width between 1-9 pixels.

Length

Specify the length of the Bar Graph's Major and Minor scales.

Minor Scale length is defined as a percentage of the Major Scale length.

Major Scale length is defined in percentage. The percentage is measured differently depending on the following two situations:

  • Bar Graph without labels
    If labels are disabled, scale length is measured as the length between the Indicator and the Bar Graph's frame.

  • Bar Graph with labels
    If labels are enabled, scale length is measured as the length between the Indicator and the label.
