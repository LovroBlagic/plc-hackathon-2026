12.4.3 Circle Graphs

A circle graph shows the value of a variable as a fill level on a circular scale.

Circle Graph Properties

Property

Description

Name

The circle graph object's name.

Whenever an object is created, a default name is generated. When renaming an object, its name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

For details, see Appendix 9, Naming Conventions.

Description

This property is read-only. It displays the name of the part and in which version of Vijeo-Designer it was created.

Version

This property is read only and displays the editor version that created the part.

Top

The coordinates, in pixels, of the top-left corner of the object.

  • Top is measured from the top of the object to the top of the panel. Enter a value from -32768 to (32767 minus object height).

  • Left is measured from the left side of the object to the left side of the panel. Enter a value from -32768 to (32767 minus object width).

By changing these properties, the graphical object can be moved up, down, left, and

right.

Left

Width

The width and height of the object in pixels. Enter a value between 60 and 3000.You can change the width and height of the object by editing this property.

Height

Variable

The variable to be represented with this circle graph. The type of variable must be an integer type.

Start Point

Select the starting point of the graph.

From

Enter the minimum range of the variable. Since the graph sets the From value as 0%, any variable value that is less than the From value is displayed as 0%.

To

Enter the maximum range of the variable. Since the graph sets the To value as 100%, any variable value that is more than the To value is displayed as 100%.

FillColor

Select the color of the graph.

BackColor

Select the background color of the graph.

Pattern

Select the pattern of the graph.

PatternBackColor

Select the back color for the pattern. The PatternBackColor and the Fill color blend together to define the color for the selected patter.

LineColor

Select the color of the division lines on the graph.

HoleWidth

Select the size and color of the hole in the center of the circle graph.

HoleColor

EnableScale

Select whether or not to enable the scale.

NumOfDivision

Enter the number of main (bigger) divisions in the graph. You can specify any value between 2 to 360.This property will display only if you set the Scale property to True.

NumOfSubDivision

Enter the number of subdivisions (smaller divisions) in the graph. You can specify Invisible or any value between 2 to 10. This property will display only if you set the Scale property to True.

ScaleColor

Select the color of the division lines on the scale. This property will display only if you set the Scale property to True.

RestoreDefaults

Click the Restore Defaults button to display the confirmation message. Clicking OK will restore all values to the default settings.

Placeholder

You can assign a placeholder in any property that requires a variable definition. Click the ellipsis to open the Placeholders dialog box and edit the variable placeholder for the object. The dialog box only displays if you had set up a placeholder for the object. For more information on placeholders, see Section 21.2.4, Working with Variable Placeholders.
