12.2.2.4 Input Mode Tab

 

The following table describes the Input Mode tab properties.

Properties

Description

Enable

Input Mode

Enables data input using a popup keypad. Select this option to enable the options listed below.

 

  • If an expression is set in the Meter's variable field, you cannot use the Enable Input Mode option.

Field ID

Set up a unique field ID for triggering the input mode when the system variable, _TouchField, is changed. This number has a default value of 0, which indicates that the input trigger is not being used. The field ID must be a value between 0 and 2,147,483,647.

Keypad Type

This field is available when the Enable Input Mode check box is selected.

Define the type of popup keypad used by the Meter:

  • Change-Immediate:
    The Change-Immediate keypad has Up/Down arrows that immediately write values to the control variable once the arrows are pressed.
    This keypad requires you to use the Change Value By field to specify the value the Up/Down arrows will increase or decrease the control variable by.
    For more information, see Section 11.9.2.4, Change-Immediate Keypad.

  • Change-On-Enter:
    The Change-on-Enter keypad has Up/Down arrows that write values to the control variable only after the Enter key is pressed.
    This keypad requires you to use the Change Value By field to specify the value the Up/Down arrows will increase or decrease the control variable by. For more information, see Section 11.9.2.5, Change-on-Enter Keypad.

  • Numeric:
    This setting has different keypad types available, which are defined by the Format setting in the Label tab, see Section 12.2.2.3, Label Tab, or Numeric Display tab, see Section 12.2.2.5, Numeric Display Tab. See Section 11.9.2.2, Numeric Keypads, for a list of the layouts for the different keypad types.

 

Change Value By

Available when Keypad Type is Change-Immediate or Change-on-Enter.

Specify the amount the keypad increases or decreases the control variable by. You can specify a numeric value, real, integer, bool, or an expression.

 

Buzzer on Touch

Sets the buzzer to sound when the Meter is touched.
