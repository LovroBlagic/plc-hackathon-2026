12.2.2 Meter Settings

The following table describes the Meter tabs.

Tab

Settings

Section

General

The General tab defines the basic properties for the Meter such as name, styles (the look of the Meter), control variable or expression, rotation direction, Max/Min values, and formatting for the scale.

12.2.2.1 General Tab

Color

The Color Tab defines the Meter's colors and images, and defines the values for the Max, HiHi, Hi, normal, Lo, LoLo, and Min Threshold ranges.

12.2.2.2 Color Tab

 

Label

The Label tab defines the labels for each of the Meter's major divisions.

12.2.2.3 Label Tab

Input Mode

The Input Mode defines the Meter's keypad types and Buzzer settings.

12.2.2.4 Input Mode Tab

Numeric Display

The Numeric Display tab defines the Meter's Numeric Display settings.

12.2.2.5 Numeric Display Tab

Visibility

The Visibility tab defines the Meter's invisibility and blink features.

12.2.2.6 Visibility Tab

Advanced

The Advanced tab defines the Meter's Interlock feature.

12.2.2.7 Advanced Tab
