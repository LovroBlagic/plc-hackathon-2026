12.5.1 Working with Fill Animation

  1. Draw an object shape to be used as a graph.

  1. In the Animation property click on the icon to display the Animation Properties dialog box.

  1. Click the Fill tab. Select the Enable Vertical Fill Animation and/or Enable Horizontal Fill Animation check boxes.

  1. Define the variable that you want to graph.

  • Use an integer or real variable. When you use a real, only the whole number portion is used. Values to the right of the decimal point are ignored.

  1. Select the point where the fill starts in the Start Point, and the color of empty areas that aren't filled in the Back Area Color. The Fill animation uses the object's foreground color for the fill. When the variable value is less than the From value, the object is filled to the level that is defined in the Min%. When the variable value is more than the To value, the object is filled to the level that is defined in the Max%.

The center of the object is set to 0%, and the object is filled equally to up and down as the value increases.

Center (One Side)

The center of the object is set to 0%, and the object is filled upward as the value increases and downward as the value decreases.

Horizontal

Left

The left edge of the object is set to 0%, and the object is filled to the right as the value increases.

Right

The right edge of the object is set to 0%, and the object is filled to the left as the value increases.

Center (Both Sides)

The center of the object is set to 0%, and the object is filled equally to left and right as the value increases.

Center (One Side)

The center of the object is set to 0%, and the object is filled to the right as the value increases and to the left as the value decreases.

  1. Enter the variable data range in the Value Range, and the fill levels in the Display Range.
