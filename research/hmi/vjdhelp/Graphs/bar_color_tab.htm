12.3.2.2 Color Tab

This section describes the features in the Bar Graph Settings Color tab.

 

The following table describes the Color tab properties.

Property

Description

Name

The Bar Graph's name.

The Bar Graph's name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions described in Appendix 9, Naming Conventions.

Category

The Category's drop-down list defines the Bar Graph's Plate Style.

Select from:

  • Primitive
    Primitive allows you select the Bar Graph's Plate Style from the predefined styles available in the Plate Style drop-down list.

  • User Defined
    User Defined allows you to select your own image as the Bar Graph's Plate Style. Use the Image Resource property or the Image property to add the image to the Bar Graph. For more information, see below for descriptions of the Image Resource property and the Image property.

Plate Style

Available when Category is set to Primitive. Select the Bar Graph's Plate Style from the drop-down list. Click Browse to open a Style Browser that contains a larger list of Plate Styles to choose from.

Image Resource

Available when Category is set to User Defined.

Select an image you created in the Resource Library to use as the background for the Bar Graph. For more information on using Resources in your parts, see Section 21.1.4.2, Selecting Resources for Your Part.

Image

Available when Category is User Defined and Image Resource is set to Use Local Settings.

Set an image for the Bar Graph's Plate Style. Click Browse and use the Open dialog window to select an image.

Transparent Color

Available when Category is User Defined.

Set a color in the Meter's image to become transparent.

To make a color transparent:

  1. Select the Transparent Color check box.

  2. Click the color box to open the Color Palette.

  3. Select the color to turn transparent and click OK.

Color Resource

Select the color resource that you created in the Resource Library for the Bar Graph.

For more information on using Resources in your parts, see Section 21.1.4.2, Selecting Resources for Your Part.

Normal

Define the color settings for the Bar Graph when the value of the variable or expression being monitored is in the normal state.

Text

Defines the label's text color.

3D Text

Only available if 3D is selected for the Font Style in the Label tab.

Defines the 3D text's shadow color.

Indicator Blink

Defines the Indicator's blink speed. Select None, Fast, or Slow.

  • Blink and Indicator Blink cannot be used at the same time in a Bar Graph. Only one of these features can be enabled at a time in the Bar Graph.

Indicator

Defines the Indicator color.

Scale

Defines the scale color.

Frame

Defines the frame color.

Plate

Defines the plate color.

Threshold

Defines the value ranges and color settings for the Bar Graph's Threshold ranges (Max, HiHi, Hi, Lo, LoLo, and Min), and defines the values for the normal range.

Threshold ranges are the range of values that are outside the expected values for the Bar Graph's variable or expression.

  • Blink and Indicator Blink cannot be used at the same time in a Meter. Only one of these features can be enabled at a time in the Meter.
