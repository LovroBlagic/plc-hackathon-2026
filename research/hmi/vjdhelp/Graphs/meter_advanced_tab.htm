12.2.2.7 Advanced Tab

 

The table below describes the Advance tab's properties.

Properties

Description

Enable Interlock

Enables the data input only when the condition defined in the Enable Interlock field is met.

For more information, see Section 9.6, Using Interlock to Prevent Accidental Touch Inputs.

 

  • During data input, if the interlock variable turns OFF, data input is cancelled.

Security Level

Sets the Security Level for the Meter. Once a Security Level is defined, only users with the correct security level can access the Meter's functions. For more information on security levels, see Section 4.8.2.1, Protecting Panels and Parts from Unauthorized Users.
