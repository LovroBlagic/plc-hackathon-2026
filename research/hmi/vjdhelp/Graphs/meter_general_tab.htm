12.2.2.1 General Tab

 

Property

Description

Name

The Meter's name.

The Meter's name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions described in Appendix 9, Naming Conventions.

Indicator Style

Select the Indicator style from the Indicator Style drop-down list. Select Browse to open a Style Browser that contains a larger list of Indicators to choose from.

Data Type

Select the Meter's data display format.

  • Integer
    The Meter displays integer values.

  • Float
    The Meter displays real values. You can define the number of decimals to display in the Automatic labels and the Numeric Display. See the Display Digits field in Section 12.2.2.3, Label Tab and Section 12.2.2.5, Numeric Display Tab for more information.

Variable

Defines the variable or the expression that controls the Meter.

The Variable field accepts REAL and integer variables and expressions.

  • If you configure an expression in the Variable property, Input Mode becomes unavailable. Expressions also do not work with the Use Variable's Min/Max property.

Use Variable's Min/Max

When enabled, the Meter uses the Min/Max values specified in the selected variable's Input Range. See Section 6.2.3, Variable Properties for more information on a Variable's Input Range.

  • The Use Variable's Min/Max property does work when you specify an expression in the Variable field.

Min Value

Defines the minimum value the Meter will display.

You can use a constant, a variable, or an expression as the Min Value.

Max Value

Defines the maximum value the Meter will display.

You can use a constant, a variable, or an expression as the Max Value.

Category

The Category's drop-down list defines the Meter's Plate Style.

Select from:

  • Primitive
    Primitive allows you select the Meter's Plate Style from the predefined styles available in the Plate Style drop-down list.

  • User Defined
    User Defined allows you to select your own image as the Meter's Plate Style. Add the image to the Meter in the Color tab; see Section 12.2.2.2, Color Tab.

Plate Style

Available when Category is set to Primitive. Select the Meters's Plate Style from the drop-down list. Click Browse to open a Style Browser that contains a larger list of Plate Styles to choose from.

Start Angle/End Angle

The Start Angle property defines the angle where the Indicator begins its rotation. The End Angle property defines the angle where the Indicator ends its rotation.

  • If the Start Angle and the End angle are the same degree, the Label for the last Major Division is dropped from the Meter.

The image below shows how degrees are marked on the Meter.

Direction

Defines the direction the Indicator rotates:

  • Clockwise

  • Counter Clockwise

Meter Preview

This feature creates a preview of the Meter based on the settings you defined in the Start Angle, End Angle, and Direction properties.

Scale

Defines the properties for the Meter's scale.

Major

Minor

Number of Divisions

Specifies the number of major and minor divisions that segment the Meter.

  • Major: 1-32

  • Minor: 2-16

Width

Specifies the width of the Meter's Major and Minor scales. Select a width between 1and 9 pixels.

Length

Specifies the length of the Meter's Major and Minor scales.

The Major Scale's length is defined as a percentage of the Meter's radius, which is the length from the center of the Meter to the edge of the Meter. The Minor Scale's length is defined as a percentage of the Major Scale's length.

Threshold Range

Enables the use of Threshold ranges. Threshold ranges are configured in the Color tab, see Section 12.2.2.2, Color Tab.

Number of Divisions

Read-only property.

Displays the number of Threshold ranges that you configured in the Color tab.

Width

Specifies the width of the Threshold range. Width is defined as a percentage of the Meter's radius, which is the length from the center of the Meter to the edge of the Meter. For example:

  • Threshold Width: 25%

  • Threshold Range Width: 100%
