12.3.2.3 Label Tab

The Bar Graph has three Label types available:

  • User Defined Label

  • Floating Label

  • Automatic Label

  • Labels are unavailable when:

  • Bar Graph's Major scales are disabled.

  • The Bar Graph Start Point is Center (Both Sides).

User Defined Label Properties

 

Property

Description

Label Type

Select the type of Label from the Label Type drop-down list.

  • Disabled: Disables the Bar Graph's labels.

  • Automatic: The labels are numeric and are automatically created based on a calculation. See How Automatic Label Types Work for more information.

  • Floating: A floating label is a numeric label that floats beside the Bar Graph's Indicator. The label displays the current value of the control variable or expression. See How Floating Label Types Work for more information

  • User Defined: Define the Label for each of the Bar Graph's major divisions.

Overwrite Text in All Languages

Available when multiple languages are set up in the Language node. Overwrites the text in all languages with the text defined in the Label. For more information, see Section 20.2, Switching Languages.

Empty Languages Operation

Available when multiple languages are set in the Language node. Click the list box and select one of the following:

  • Text content only: Copies the text defined in the label and pastes it in the languages that have empty labels.

  • Text content, font, size, and style: Copies the text font, size, and style defined in the label and pastes it into the languages that have empty labels.

 

Floating and Automatic Label

How Automatic Label Types Work

Automatic labels are numeric and are defined by the following calculation: number of labels divided by the Bar Graph's Min and Max range. For example, if the number of labels is 11 and the Bar Graph's Min value is 0 and the Max value is 100, the automatic labels will be:

  • Be aware that when you select an odd number of labels and select the automatic label types, the labels will be decimal numbers.

How Floating Label Types Work

A Floating label displays the current value of the control variable or the control expression and floats along beside the Bar Graph's Indicator. When the Indicator increases or decreases, the floating label moves along with the changing size of the Indicator.

Display Digits

Specify the number of digits to display on the left and right of the decimal point.

When the Integer is selected as the Data Type in the General tab:

  • The range for integral digits is 1 to 10.

  • The range for decimal digits is 0 to 9.

When Float is selected for the Data Type in the General tab:

  • The range for integral digits is 1 to 17.

  • The range for decimal digits is 0 to 16.

  • An Integer bar graph and a Float bar graph may have the same Display Digits setting, but the labels display differently at runtime.

  • Values are rounded to the nearest supported decimal place.

Display Zero(s)

Select to display "0" when data is equal to 0.

Format

Available when the Bar Graph's Data Type is Integer.

The Format property defines both the format for the labels and the type of Numeric keypad for the Bar Graph. See Section 11.9.2.2, Numeric Keypads, for the list of keypad types. Select from the following:

  • Dec (decimal).
    Labels display in base decimal format. The Numeric keypad type is set to decimal. The range for integral digits is 1 to 10. The range for decimal digits is 0 to 9.

  • Hex (hexadecimal).
    Labels display in hexadecimal format. The Numeric keypad type is set to hexadecimal. The range for integral digits is 1 to 8.

  • Bin (binary).
    Labels display in binary format. The Numeric keypad type is set to binary. The range for integral digits is 1 to 32.

  • Oct (octal).
    Labels display in octal format. The Numeric keypad type is set to decimal. The range for integral digits is 1 to 11.

Use Digit Grouping
