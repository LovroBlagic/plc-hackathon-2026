12.2.2.5 Numeric Display Tab

 

Property

Description

Enable Numeric Display

Adds a Numeric Display to the Meter.

Display Digits

Specify the number of digits displayed to the left and right of the decimal point.

For an integer data type:

  • The range for integral digits is 1 to 10.

  • The range for decimal digits is 0 to 9.

For a REAL data type:

  • The range for integral digits is 1 to 17.

  • The range for decimal digits is 0 to 16.

  • An Integer meter numeric display and a Float meter numeric display may have the same Display Digits setting, but the labels display differently at runtime.

  • Values are rounded to the nearest supported decimal place.

  • If the data display tries to display more digits than what is defined in this property, an asterisk (*) is displayed instead of the value.

  • When displaying or entering integers with decimal places, the value is stored without the decimal point.

Format

Available when the Meter's Data Type is an integer type.

The Format property defines both the format for the labels and the type of popup keypad for the Meter. See Section 11.9.2.2, Numeric Keypads for a list of the layouts for the different keypad types. Select from the following:

  • Dec (decimal).
    Labels display in base decimal format. The Numeric keypad type is set to decimal. The range for integral digits is 1 to 10. The range for decimal digits is 0 to 9.

  • Hex (hexadecimal).
    Labels display in hexadecimal format. The Numeric keypad type is set to hexadecimal. The range for integral digits is 1 to 8.

  • Bin (binary).
    Labels display in binary format. The Numeric keypad type is set to binary. The range for integral digits is 1 to 32.

  • Oct (octal).
    Labels display in octal format. The Numeric keypad type is set to decimal. The range for integral digits is 1 to 11.

  • You can also define the Meter's popup keypad type using the Format property in the Numeric Display tab. Be aware that the keypad type defined using the Format property in the Label tab takes precedence over the keypad type defined using the Format property in the Numeric Display tab.

Zero Suppress

Suppresses leading zeroes in the display.

For example, when Zero Suppress is selected and the Display Digits is set to 5.0, the Numeric Display displays 30 instead of 00030.

Display Zero(s)

Displays 0 when the value for the Meter's control variable is 0.

When disabled, nothing displays when the value for the Meter's control variable is 0.

Digit Grouping

Displays the character (either a comma or space) used to separate the digits displayed in a Numerical display part.

Style

Select the Numeric Display's style from the list of predefined images in the Style drop-down list. The Browse icon opens a Style Browser that contains a larger list of predefined images to choose from.

Font Resource

Select the Font Resource you created in the Resource Library to use for the Meter's Numeric Display font. For more information on using Resources in your parts, see Section 21.1.4.2, Selecting Resources for Your Part.

Language

Available when multiple languages are set up in the Language node.

Select the Label's language. You can set up a different label for each user language. For more information, see Section 20.2, Switching Languages.

Font

Specify the font.

See Appendix 5, Hardware Specifications, for more information on Vijeo-Designer fonts.

Font Style

Select Normal, Bold, or 3D.

Font Width

Define the font height and width.

Font Height

Font Size

This property is only available for selected Fonts. Select the font's size.

Preview

The preview window shows you what the text will look like.

Alignment

Select the alignment of the text in the Numeric Display. Select left, center, or right.
