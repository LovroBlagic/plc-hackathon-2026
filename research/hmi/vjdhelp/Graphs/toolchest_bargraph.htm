12.4.2 Bar Graphs

A bar graph shows the value of a variable as a rectangular bar on either a vertical or a horizontal scale.

Bar Graph Properties

Property

Description

Name

The bar graph object's name.

Whenever an object is created, a default name is generated. When renaming an object, its name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

For details, see Appendix 9, Naming Conventions.

Description

This property is read-only. It displays the name of the part and in which version of Vijeo-Designer it was created.

Version

This property is read only and displays the editor version that created the part.

Top

The coordinates, in pixels, of the top-left corner of the object.

  • Top is measured from the top of the object to the top of the panel. Enter a value from –32768 to (32767 minus object height).

  • Left is measured from the left side of the object to the left side of the panel. Enter a value from –32768 to (32767 minus object width).

By changing these properties, the graphical object can be moved up, down, left, and right.

Width

The width and height of the object in pixels. Enter a value between 4 and 3000.You can change the width and height of the object by editing these properties.

Variable

The variable whose values will be represented. The type of variable must be an integer type. Displays the range specified by the ValueMin and ValueMax in percentage (%).

From

Enter the minimum value of the variable. Since the graph sets the From value as 0%, any variable value that is less than the From value is displayed as 0%.

To

Enter the maximum value of the variable. Since the graph sets the To value as 100%, any variable value that is more than the To value is displayed as 100%.

NumOfDivision

Enter an integer to determine the number of divisions in the scale.

Pattern

Select the pattern and color of the bar. When the pattern is selected, the FillColor and BackColor are blended to define the display color.

RestoreDefaults

Click the   Restore Defaults button to display the confirmation message. Clicking OK will restore all values to the default settings.

Placeholders

You can assign a placeholder in any property that requires a variable definition. Click the ellipsis to open the Placeholders dialog box and edit the variable placeholder for the object. The dialog box only displays if you had set up a placeholder for the object. For more information on placeholders, see Section 21.2.4, Working with Variable Placeholders.
