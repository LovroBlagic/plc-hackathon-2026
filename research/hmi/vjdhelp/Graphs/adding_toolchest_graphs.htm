  1. Click the Toolchest icon in the menu bar to open the Toolchest window.

  2. In the Toolchest, click the folder for the graph you want to place onto a panel.

  3. Move the graph onto the panel using the drag and drop operation.

  4. Set up the properties for the Toolchest graph using the information from the following sections:
