12.3.2.5 Visibility Tab

 

The following table describes the Visibility tab properties.

Property

Description

Enable Visibility

This property makes the Bar Graph invisible or visible.

When the value defined in this field is true (ON), the Bar Graph is visible. When the value defined in this field is false (OFF), the Bar Graph is invisible.

Select a BOOL or integer variable or enter a boolean expression to control the Bar Graph's invisibility.

 

  • If in the middle of data input this variable turns off, your input will not be stored. Whatever you were typing will be gone.

Invalid when in invalid state

This check box is not available for bar graphs.

Enable Blink

Select Enable Blink to make the Bar Graph blink. You can choose a BOOL or integer variable or enter a boolean expression.

  • If true, the Bar Graph blinks.

  • If false, the Bar Graph does not blink.

  • Blink and Indicator Blink cannot be used at the same time in a Meter. Only one of these features can be enabled at a time in the Meter.

Speed

Set the blinking speed to fast or slow. A fast blink rate is 350 ms and slow blink rate is 700 ms.
