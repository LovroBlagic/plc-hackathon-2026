12.2.2.2 Color Tab

 

Property

Description

Name

The Meter's name.

The Meter's name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions described in Appendix 9, Naming Conventions.

Indicator Style

Select the Indicator style from the Indicator Style drop-down list. Select Browse to open a Style Browser that contains a larger list of Indicators to choose from.

Category

The Category's drop-down list defines the Meter's Plate Style.

Select from:

  • Primitive
    Primitive allows you select the Meter's Plate Style from the predefined styles available in the Plate Style drop-down list.

  • User Defined
    User Defined allows you to select your own image for the Meter's Plate Style. Use the Image Resource property or the Image property to add the image to the Meter. For more information, see below for descriptions of the Image Resource property and the Image property.

Plate Style

Available when Category is set to Primitive. Select the Meters's Plate Style from the drop-down list. Click Browse to open a Style Browser that contains a larger list of Plate Styles to choose from.

Image Resource

Available when Category is set to User Defined.

Select an image you created in the Resource Library to use as the background for the Meter. For more information on using Resources in your parts, see Section 21.1.4.2 Selecting Resources for Your Part.

Image

Available when Category is User Defined and Image Resource is set to Use Local Settings.

Set an image for the Meter's Plate Style. Click Browse and use the Open dialog window to select an image.

Transparent Color

Available when Category is User Defined.

Set a color in the Meter's image to become transparent.

To make a color transparent:

  1. Select the Transparent Color check box.

  2. Click the color box to open the Color Palette.

  3. Select the color to turn transparent and click OK.

Color Resource

Select the color resource that you created in the Resource Library for the Meter.

For more information on using Resources in your parts, see Section 21.1.4.2 Selecting Resources for Your Part.

Normal

Define the color settings for the Meter's normal range.

The normal range is the range of expected values for the Meter's variable or expression.

The normal range is defined by the Max, Min, HiHi, Hi, Lo, and LoLo Threshold range values. The two examples below explain how the Threshold range values define the normal range.

Example 1

With a Threshold ranges of Min=0, LoLo=20, Lo=40, Hi=60, HiHi=80, and Max=100, the normal range becomes 41-59.

Example 2

With Threshold ranges of Min=0, LoLo=20, Lo=40, Hi=disabled, HiHi=disabled and Max=100, the normal range becomes 41-99

Text

Defines the label's text color.

3D Text

Only available if 3D is selected for the Font Style in the Label tab.

Define the 3D text's shadow color.

Indicator Blink

Defines the Indicator's blink speed. Select None, Fast, or Slow.

  • Blink and Indicator Blink cannot be used at the same time in a Meter. Only one of these features can be enabled at a time in the Meter.

Indicator

Defines the Indicator color.

Scale

Defines the scale color.

Threshold

Defines the Threshold color for the normal range.

Frame

Defines the frame color for the Meter and the Meter's numeric display.

  • You cannot configure the Frame color when the Plate style is 00026 or 000000.

Plate

Defines the plate color for the Meter and the Meter's numeric display.

  • Plate color cannot be defined when Category is User Defined.

Threshold

Defines the value ranges and color settings for the Meter's Threshold ranges (Max, HiHi, Hi, Lo, LoLo, and Min), and defines the values for the normal range.

Threshold ranges are the range of values that are outside the expected values for the Meter's variable or expression.

  • Blink and Indicator Blink cannot be used at the same time in a Meter. Only one of these features can be enabled at a time in the Meter.
