12.5 Creating Your Own Graphs

Using Fill animation, you can use a symbol or shape as a graph, similar to bar and tank graphs. Fill animation fills the object based on specified data.

  • You cannot create circle or pie graphs with Fill animation. To draw a circle or pie graph, use parts from the Toolchest.

  • To see which objects support Fill animation, see Section 8.1.2, Animation Supported by Objects.

  • To create a custom meter graph, use Rotate animation. See Section 8.4, Rotating Objects Using Variable Values.

Steps
