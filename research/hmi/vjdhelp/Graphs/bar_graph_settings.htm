12.3.2 Bar Graph Settings

The following table describes each tab in the Bar Graph's dialog box and references to more information.

Tab

Settings

Section

General Tab

The General Tab defines the basic properties for the Bar Graph such as name, styles (the look of the Bar Graph), control variable or control expression, Indicator fill direction, Indicator position, Max/Min values, and scale formatting.

12.3.2.1 General Tab

Color Tab

The Color Tab defines the Bar Graph's colors and images, and defines the values for the HiHi, Hi, normal, Lo, and LoLo ranges.

12.3.2.2 Color Tab

Label Tab

The Label tab defines the labels for each of the Bar Graph's major divisions.

12.3.2.3 Label Tab

Input Mode Tab

The Input Mode defines the Bar Graph's keypad types.

12.3.2.4 Input Mode Tab

Visibility Tab

The Visibility tab defines the invisibility and blink features for the Bar Graph.

12.3.2.5 Visibility Tab

Advanced Tab

The Advanced tab defines the Bar Graph's Interlock feature.

12.3.2.6 Advanced Tab
