12.2.2.3 Label Tab

The Meter has two Label Types available:

  • User Defined Label
    With User Defined Label types, users configure the text, font, font style, font width, and font height for each label in the Meter.

  • Automatic Label
    With Automatic Label types, users configure a label's font, font style, font width, and font height, but the label's text is defined by a calculation of the Meter's Min and Max range divided by the number of labels. For more information, see the following section How Automatic Label Types Work.

  • Labels impact the size of the Indicator and scales, which are scaled to fit the size of the labels.

Display Digits

Specify the number of digits to display on the left and right of the decimal point.

When the Integer is selected as the Data Type in the General tab:

  • The range for integral digits is 1 to 10.

  • The range for decimal digits is 0 to 9.

When Float is selected for the Data Type in the General tab:

  • The range for integral digits is 1 to 17.

  • The range for decimal digits is 0 to 16.

  • An Integer meter and a Float meter may have the same Display Digits setting, but the labels display differently at runtime.

  • Values are rounded to the nearest supported decimal place.

Display Zero(s)

Select to display "0" when data is equal to 0.

Format

Available when the Meter's Data Type is Integer.

The Format property defines both the format for the labels and the type of Numeric keypad for the Meter. See Section 11.9.2.2, Numeric Keypads for the list of keypad types. Select from the following:

  • Dec (decimal).
    Labels display in base decimal format. The Numeric keypad type is set to decimal. The range for integral digits is 1 to 10. The range for decimal digits is 0 to 9.

  • Hex (hexadecimal).
    Labels display in hexadecimal format. The Numeric keypad type is set to hexadecimal. The range for integral digits is 1 to 8.

  • Bin (binary).
    Labels display in binary format. The Numeric keypad type is set to binary. The range for integral digits is 1 to 32.

  • Oct (octal).
    Labels display in octal format. The Numeric keypad type is set to decimal. The range for integral digits is 1 to 11.

  • You can also define the Meter's popup keypad type using the Format property in the Numeric Display tab. Be aware that the keypad type defined using the Format property in the Label tab takes precedence over the keypad type defined using the Format property in the Numeric Display tab.
