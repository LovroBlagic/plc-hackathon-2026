12.4 Toolchest Graphs

Toolchest graphs allow you to create graphs quickly and easily by eliminating the need to draw frames and scales. Add Toolchest graphs to your projects by using the drag-and-drop operation.

The following graphs are available in the Toolchest.

Bar Graph

Displays the current value of the variable. Both Vertical and Horizontal Bar graphs are available in the Toolchest.

Circle Graph

Displays the current value of the variable.

Tank Graph

Displays the value of the variable representing the tank's fill level.

Meter Graph

Displays the value of the variable by a needle pointing to it on a circular scale.

Pie Graph

Displays the value of multiple variables.

Data Graph

 

Displays multiple device address or variable values at one time. The data graph allows you to display up to 8 different values at one time, as a single line.

Parison Graph

Displays the profile thickness of a parison. A parison is an extruded tube used in blow molding. Using the Parison Graph Toolchest part, you can plot, monitor, and adjust the profile thickness of the parison at run time. Parison Graph Toolchest part can plot 64 to 400 data points.

XY Graph

Displays data for multiple data samples with X and Y coordinates at one instance. An XY graph can display up to 256 data samples from each block or array variable in two styles, Line or Scattered. It can display a maximum of eight block or array variables.

 

  • For information on trend graphs, see Section 13.3.2, Setting Up Trend Graphs.

  • When graphing external variables, the graph display is affected by the Scan Rate defined in the variable's associated Scan Group. See Section 6.3.2, Dividing Variables into Scan Groups.
