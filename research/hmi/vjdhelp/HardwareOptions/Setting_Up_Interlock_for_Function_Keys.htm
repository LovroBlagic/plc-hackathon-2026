24.5.5 Setting Up Interlock for Function Keys

If you enable the Interlock property for a Function Key, the function key’s operations run only if the condition set in the Interlock is met. When the interlock variable value is ON, the Function Key operations are available. When the interlock variable is OFF, Function Key operations do not run when the user presses the Function Key.

Interlock Settings

You can use BOOL or integer variables or boolean expressions as the Interlock. Function Key operations are available when the value of the Interlock is ON.

Interlocking Groups of Function Keys

You can lock and unlock groups of Function Keys using Interlock. To lock or unlock a group of Function Keys, use the same Interlock variable for all the Function Keys you want to group together. When the Interlock variable turns on or off, all the Function Keys associated with the Interlock variable will become locked or unlocked.
