24.4.4 Time Management

You can set up time management on the target so that it can support Vijeo Designer's time-based features, such as alarms, events, trend graphs, and date/time parts. There are two ways to set up the time on the target:

  • Set up the target to get the time from the PLC

  • Set up the time in the target, and the time is stored in the SRAM.

Not all targets require time management setup. The time management setting is for targets that do not have battery backup for the internal clock. For information about the targets that require Time Management to be set in order to support time-based functions, see Appendix 5, Hardware Specifications.

  • If you create a project on a target that does not require time management setup and then change your target to one that requires it, make sure you check the Time Management property setting since it is initially set to the default (Disabled).

Setting Up Time Management Using the PLC Dialog Table

This procedure describes how to set up the target to get the time from the PLC, so you can use the time-based features in Vijeo Designer. Before you set up time management, make sure the target uses a driver that supports the Dialog Table.

  1. In the target properties' Startup Options, set the Time Management property to Enabled.

  2. Define the Time Management properties:

  3. Type: Select PLC Dialog Table to synchronize the internal clock from the PLC's dialog table.

  4. Auto Start: Select Enabled or Disabled, and set up the wait time (in seconds, 0-3600) as required. For more information, see Auto Start.

  1. In the Equipment properties for the driver, click the ellipsis in the Dialog Table property to open Dialog Table Settings. For more information, see Section 5.6.1, Dialog Table Settings. Select Set Terminal Clock to enable the function. Then make sure Set PLC Clock is not enabled.

At startup, if the PLC is connected, the project will start up immediately. If the PLC does not connect immediately, a screen displays with the message, "Waiting for Time Sync".

Setting Up Time Management Using Manual Date and Time Entry

This procedure describes how to set up the system clock by manually entering the correct date and time at target startup.

  1. In the target properties' Startup Options, set the Time Management property to Enabled.

  2. Define the Time Management properties:

  3. Type: Select Manual Configuration to enter the date and time manually.

  4. Auto Start: Select Enabled or Disabled, and set up the wait time (in seconds, 0-3600) as required. For more information, see Auto Start.

At target startup, a Date/Time switch displays to allow the operator to configure the date and time in the Date/Time configuration menu. The application will not start until the operator sets the date and time.

Setting Up Auto Start

Auto Start allows the target to start in cases where the PLC or operator is not available to set the time. If the Auto Start property is set to:

  • Enabled: After the wait time specified in the Time Management property expires, the target's clock is set to the last recorded time in the simulated SRAM (if any) plus 1 minute, plus the Auto Start time.

For example, if the Auto Start time is set to 180 seconds (3 minutes) and the last recorded time is 1:35pm, March 10, 2010, after the panel has waited for the 3 minutes, it will set the system clock to 1:39pm, March 10, 2010, and will start up.

If there was no last recorded time and the target has waited for the Auto Start time, the panel clock will default to 0:00 of January 1, 2000.

  • Disabled: The project remains in the startup panel until the PLC or operator provides the date and time.

If you want to hide the set date/time screen when the target machine starts up, set the Time property for Auto Start to 0.

Disabling Time Management

If the panel is going to be used for functions such as switches, lamps, text, and graphics display, and no time-based functions are used, you can disable time management. The target will always start immediately.

To disable time management, in the target properties, expand Startup Options and set the Time Management property to Disabled.
