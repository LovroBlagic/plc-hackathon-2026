24.5.2.3 Using Object Settings for Panel Function Keys

You can base the Panel Function Key settings on an existing object's settings or you can create a Switch to base the Panel Function Key settings on. This feature enables you to save time and create consistency among your objects and Function Keys. Panel Function Key settings can be based on a Switch, Data Display, Message Display, Meter, Bar Graph, or Selector that have Input Mode enabled. When an object is selected, the following settings will be used for the Panel Function Key settings:

  • Operations - When Touch, While Touch, and When Release

  • Advanced - Interlock, Hold Delay, and Security

To use the Use this objects settings feature:

  1. In the Panel Function Key dialog box, select a Function Key in the Function Key list.

  2. Select Use this object's settings.

  3. Select the Object from the Use this object's settings drop-down list, or click the New Switch button to create a Switch to base the Panel Function Key settings on.
