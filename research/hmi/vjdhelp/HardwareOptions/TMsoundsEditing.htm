24.2.2 Editing Sound Files

  1. Open the Sound File Editor.

  2. Edit the Alias, FileName, or both.

  3. To edit an Alias, click the Alias cell to rename the sound as used in the project. The alias is the name that Vijeo-Designer associates with the sound file. The alias is what you call when you work with the sound file in Touch animation, scripts, or alarms.

 

  • To edit a FileName, click the FileName cell then click the ellipsis to display the Open dialog box. Browse and select the new sound file, then click Open.

The Sound File Editor opens and displays the new sound file in the FileName column. The existing alias name does not change.
