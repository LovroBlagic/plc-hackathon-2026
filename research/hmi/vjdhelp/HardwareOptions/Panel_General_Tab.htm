24.5.2.1 Panel Function Key General Tab

The Panel Function Key dialog box is available from the Function Key property in the Panel properties.

The following table describes each property in the General tab.

Property

Description

Function Key List

Use the Function Key List to add and remove Function Keys. For information on how to add and remove Function Keys, see Section, 24.5.4, Adding and Removing Function Keys.

Use this object's settings

Select an object to base the Panel Function Key settings on or create a new switch to base the Panel Function Key settings on by using the New Switch button. When you select an object from the drop-down list or create a new switch, the following settings will be used for the Panel Function Key settings:

  • Operations - When Touch, While Touch, and When Release

  • Advanced - Interlock, Hold Delay, and Security

Only the objects that have Input Mode enabled will be available from the drop-down list. For information on how to use this feature, see Section 24.5.2.3, Using Object Settings for Panel Function Keys.

Use these settings

Set the Panel Function Key to use the settings defined in the Panel Function Key Setting dialog box.

When Touch

While Touch

When Release

These tabs define the conditions under which the operations run when the operator presses the Function Key. The list of available operations depends on the type of target machine. Check the Editor to see the list of supported operations. For the list of all available operations and descriptions of the operations, see Section 9.5 Operations.

 

Set up operations to run under different touch conditions using these three tabs:

    • When Touch Tab: Defines the operations that run when the Function Key is pressed.

    • While Touch Tab: Defines the operations that are repeatedly run while the Function Key is being held down.

    • When Release Tab: Defines the operations that run when the function key is released.

Operation List

Displays the list of operations for the Function Key in the order the operations will run.

For more information on creating multiple operations for one function key, see Section 9.5.19, Setting Up Multiple Operations.
