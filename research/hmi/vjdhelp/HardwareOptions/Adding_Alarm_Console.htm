24.8.1 Adding the Illuminated Switch

To add the illuminated switch to your project:

  1. In the Navigator window's Project tab, right-click the I/O Manager node and click New Driver.

  2. In the New Driver dialog box, select Schneider Electric USB Accessories as the Manufacturer and select Illuminated Switch for the Driver. Click OK.

  3. Click OK to close the Driver Configuration dialog box. The illuminated switch is now added to your project.

  • You can only add one illuminated switch driver to the I/O Manager node.
