24.9.3 Upgrading Existing Projects to Include Fingerprints

In Vijeo Designer 6.1 SP2 or later, user name, password, and fingerprint data for all users are stored in the project's central database called the Project User List.

To have fingerprint capturing/storing capability in projects created in previous versions of Vijeo Designer, upgrade the project to have the Project User List. Upgrading to the Project User List allows you to merge users in all security user groups into one list. The Project User List only accepts unique user names. When you upgrade to the Project User List, a wizard walks you through the list of conflicting user names where you can resolve conflicts. The following steps describe how to upgrade to the Project User List:

  1. In Vijeo Designer, from the menu bar click Security and then Project User List. A wizard starts showing the total number of users in the project and the number of conflicting user names.

  2. Click Next to go to the first conflict (if your project has no conflicts, proceed to step 5).

  3. The wizard lists the first set of duplicated user names that have different passwords. To resolve the conflict, do one of the following:

    • Rename User: Click the user name cell and type in a different name.

    • Delete User: Select one of the duplicated user names and click Delete User to remove the user from the Project User List.

    • Use this Password: Select one of the duplicated user names and click Use this Password. This action deletes all other passwords associated with this user name.

  4. Repeat step 2 and 3 to resolve all conflicts and then click Next.

  5. Click Finish to save the changes.

  • The wizard does not create a backup of the project. You may want to create a backup of your project before you proceed with the upgrade.

  • Changing user names may result in adding or removing users from security groups or creating new conflicts.

  • The Finish button becomes available when there are no more conflicts.

  • The changes only take effect when you click Finish.
