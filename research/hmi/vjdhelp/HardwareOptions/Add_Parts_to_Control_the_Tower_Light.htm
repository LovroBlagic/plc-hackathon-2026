24.7.3 Adding Parts to Control the Tower Light

An operator can make changes to patterns by using parts. You can add a switch or a numeric display to an unsecured panel, so that at run time, an operator can control the current state of equipment or materials.

The following example describes how to create three switches that enable an operator to change from a problem state (Pattern 1, a red-colored display) to a warning state (Pattern 2, an amber-colored display) to a normal state (Pattern 3: a green-colored display).

  1. Add a switch to your panel. For more information on how to create a switch, see Section 9.2, Creating Switches.

  2. In the General tab, create a Word operation. Set the Word operation properties as follows:

  • Source: Enter the pattern number. For this switch, enter 1 to indicate Pattern 1 (problem state).

  • Operation: Select Set.

  • Destination: Select the _TowerLightSetCurrentPattern variable.

  1. Click Add to add the operation.

  2. In the Label tab, select Static as the Label Type, and then type “Problem” in the Label text box.

  3. Click OK. You now have a switch that triggers the Problem state on your tower light at run time.

  4. Repeat steps 1 to 5 to create switches to trigger a Warning state and a Normal state. In the Word operation, enter 2 in the Source property to indicate Pattern 2 (warning state), and 3 to indicate Pattern 3 (normal state). In the Label text box, type "Warning" and “Normal” for their respective switches.

At run time, the operator can press the switches on the panel to trigger the Warning state, Problem state, and Normal state.
