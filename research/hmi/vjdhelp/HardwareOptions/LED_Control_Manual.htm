24.5.3.2 LED Control Manual

LED Control Manual enables you to define an LED's color and blink speed through variables. When LED variable values change, the LED changes its color and blink speed according to the new value. By using variables to control LED colors and blink speeds, you can set a group of LEDs to the same color and blink speed. For more information, see Controlling Groups of LEDs.

LED Control Manual requires you to set up a method (Switch, Script, Action, Selector, etc) to change the LED variable values. Furthermore, if you want to associate the LED's colors and blink speed to the state of a Function Key, you must set up a method that will monitor the Function Key state and change the variable value based on the state. For more information on Function Key states, see Section 24.5, Function Key: Function Key States.

When configuring LED Control Manual, be aware of the two types of Function Keys:

  • Target Function Key (Static): Static Function Keys are the Target Function Keys. For the location of the Static Function Keys on your target machine, see Appendix 5.9, Function Keys Supported by Hardware Platforms.

  • Panel Function Key (Dynamic): Dynamic Function Keys are the Panel Function Keys. For the location of the Dynamic Function Keys on your target machine, see Appendix 5.9, Function Keys Supported by Hardware Platforms.

LED Control Manual variables are defined in the Target node properties, see Section 4.5.1, Target Properties.
