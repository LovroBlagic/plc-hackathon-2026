24.1.1 Connecting the Bar Code Scanner to the Target Machine

UNINTENDED EQUIPMENT OPERATION

When you connect one or more USB devices to a target machine via a USB hub, you must use a USB hub with external power supply.

Failure to follow these instructions can result in death, serious injury, or equipment damage.

 

  1. On the bar code scanner, set up the termination character as Text+CR or Text+CR+LF.

If the bar code scanner times out without encountering the termination character (CR or CR+LF), any data that was scanned is cleared. Timeout occurs at 100ms.

  1. Connect the bar code scanner to the target machine's serial or USB port.
