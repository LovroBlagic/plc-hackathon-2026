24.7.1 Adding the Tower Light

This section describes how to add the tower light hardware device to your project.

  1. In the Navigator window’s Project tab, right-click the target’s I/O Manager node and click New Driver.

  2. In the New Driver dialog box, select Schneider Electric USB Accessories as the Manufacturer, select Tower Light, and then select the XVGU Series Tower Light equipment.

  3. Click OK to add the Tower Light equipment.

  4. In the Driver properties for the tower light, click the ellipsis in the Configuration property to open the Pattern Configuration dialog box.

  5. Define the following properties in the Pattern Configuration dialog box.

Property

Description

Pattern

Select the pattern (0 to 9) that you want to configure.

Layer 1, 2, 3

Color

Select a color for the layer. You can choose:

  • OFF

  • 1: Red

  • 2: Amber

  • 3: Green

  • 4: Blue

  • 5: Cyan

  • 6: Magenta

If you select OFF, the Blinking property is disabled.

Blinking

Select a blinking mode:

  • 0: None

  • 1: Slow

  • 2: Fast

Buzzer

Volume

Set the volume for the buzzer (OFF, Low, Medium, High).

Pitch

Set the pitch: (Low, High).

Beep Pattern

Set the beep pattern for the buzzer:

  • 0: Solid On

  • 1: Slow Interval

  • 2: Fast Interval

  • 3: 5-Pulse Pattern

 

  1. Click OK.
