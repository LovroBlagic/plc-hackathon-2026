24.9.5.2 Managing Users with Fingerprints

The User Manager Toolchest part enables you to add, modify, or delete users with fingerprint records at run time. To add the User Manager Toolchest part to your project:

  1. In Vijeo Designer, from the Tools menu click Toolchest.

  2. From the Security folder, drag and drop the User Manager to the panel.

  3. Save, build, and download your project to the target machine.

  • To prevent unauthorized access, place the User Manager Toolchest part onto a secured panel.

Add New Users with Fingerprints at Run Time

  1. Navigate to the panel that contains the User Manager Toolchest part.

  2. From the Group list, select the security user group.

  3. Enter the user name in the User field. Depending on the security group settings, you may need to enter and confirm password for this user.

  4. Touch , and then touch Start. Follow the steps below to capture the user's fingerprints:

    1. Place the user's first finger on the biometric switch. When the quality of scan is acceptable, a fingerprint icon appears on the screen.

    2. Repeat step a for the user's first finger. You must capture 3 fingerprints of the same finger.

    3. Choose a different finger and repeat steps a and b for the user's second finger. You must capture 3 fingerprints of the same finger.

  1. Touch to add the user's authentication data.

Edit Users with Fingerprints at Run Time

  1. Navigate to the panel that contains the User Manager Toolchest part.

  2. From the Group list, select the security user group.

  3. From the User list, select the user you want to edit.

  4. Touch , and then touch Start. Follow the steps below to capture the user's fingerprints:

    1. Place the user's first finger on the biometric switch. When the quality of scan is acceptable, a fingerprint icon appears on the screen.

    2. Repeat step a for the user's first finger. You must capture 3 fingerprints of the same finger.

    3. Choose a different finger and repeat steps a and b for the user's second finger. You must capture 3 fingerprint images of the same finger.

  5. Touch to save the modifications.

  • The biometric switch has 30 second inactivity timeout. If 30 seconds elapse between scans, the newly scanned fingerprints will be discarded. In the Edit User mode, check marks are still displayed to indicate that the user's previous fingerprints still exist in the target machine. No check marks are displayed for new users with no fingerprint records.   

Delete Users with Fingerprints at Run Time

  1. Navigate to the panel that contains the User Manager Toolchest part.

  2. From the Group list, select the security user group.

  3. From the User list, select the user you want to delete.

  4. Touch to remove the user from the target's user list and the biometric switch. If the biometric switch is not connected to the target machine, it will be updated the next time you connect it.

Clear Biometric Switch at Run Time

  1. In Vijeo Designer, from the Tools menu click Toolchest.

  2. From the Security folder, drag and drop the ClearBiometricSwitch to the panel.

  3. Save, build, and download your project to the target machine.

  4. At run time, navigate to the panel and touch the ClearBiometricSwitch. This action calls the Sys.clearBiometricSwitch() script method which clears the content of the biometric switch. For more information, see Section 18.9.1.5, System Methods(Sys.clearBiometricSwitch).
