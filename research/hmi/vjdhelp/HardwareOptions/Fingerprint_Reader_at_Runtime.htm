24.9.5 Working with Biometric Switch at Runtime

At run time, the target machine detects the connected biometric switch, verifies, and updates its content. If a biometric switch is not connected at start up, the update happens at the time you connect the biometric switch to the target machine.

You can replace a biometric switch at run time by unplugging the old biometric switch and plugging in the new one. The target machine detects the new biometric switch and updates its content if required.

  • You can only connect one biometric switch to the target machine and to the editor PC.

  • Vijeo Designer build time supports both Schneider Electric Biometric Switch XB5S5B2L2 and MorphoSmart™ MSO1300. At run time, only Schneider Electric Biometric Switch XB5S5B2L2 is supported.

  • Not all target machines support the biometric switch. For a list of supported target machines, see Appendix 5, Hardware Specifications.

  • After the Sys.clearBiometricSwitch() script method is run, the entire fingerprint database on the biometric switch is removed. Without the database, there are no fingerprints to identify. Therefore, the biometric switch will not be in Identify mode, and its light will be off and appear to be disconnected (without actually being disconnected). The biometric switch has to be reconnected to initialize its database and return to Identify mode.

  • If your biometric switch is connected to an iPC target machine, you must start Runtime as an administrator by right-clicking the program icon and selecting Run as administrator. This allows the switch to successfully initialize its database, and must be done for iPC systems running Windows 7 or Windows 8.1.
