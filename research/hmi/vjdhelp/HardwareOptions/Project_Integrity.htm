24.4.2 Checking Project Integrity

Users can set Vijeo-Designer Runtime to check a target machine's project for errors during the startup of a target machine. If the project does not have errors, Vijeo-Designer Runtime runs the project. If the project has errors, Vijeo-Designer Runtime will not run the project and will display an error message. The error message prompts you to either restart the target machine or download the project again. The application checksum can be retrieved from the target during runtime using an operation. For more information, see Section

Setting Up the Check Project Integrity

  1. In the Navigator window's Project tab, right-click the Target node and select Properties to display the Target's properties in the Property Inspector.

  2. In the target's Check Project Integrity property, select Enabled.

  3. In the Navigator window, right-click the Target node, then click Download (or Download All if you changed more than one target's Check Project Integrity property).

The project downloads to the target machine. On startup, Vijeo-Designer Runtime checks the project for errors.

  • For large projects, startup time may be affected if Check Project Integrity is enabled.
