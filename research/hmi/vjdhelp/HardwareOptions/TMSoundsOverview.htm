24.2 Target Machine Sound Files

Using this feature, Vijeo-Designer enables you to associate .wav sounds with Touch animation, scripts, and alarms. Use sound files to generate alarms or feedback to the user.

  • Not all target machines support the sound feature. See Appendix 5, Hardware Specifications for a list of targets that support sound.

  • You need to connect speakers to the target machine in order to use the sound feature. Information on connecting speakers is found in your target machine's hardware manual in Appendix 1, Hardware User Manuals.
    For example, information on connecting speakers for HMIG3U can be found in the HMIGTU Series User Manual, under Auxiliary Output/Speaker Output Interface (AUX) in section 4.3.

 

  • If you select a .wav file whose format is not supported, an error message will display during Validation.

  • There must be enough space to store the sound file, either on the CF Card/SD Card or internal memory (flash memory).

Play Sequence of Multiple Sound Files

You cannot play multiple sound files simultaneously. Even if you play multiple sound files, the first sound file must stop playing before the next sound file begins.

  • Sounds set up in the variable alarm properties play after any sounds set up in alarm trigger actions. In the alarm trigger action, you can play sounds using Special or Script functions.

Use the following steps to set up sound.

Steps

  1. Open the Sound File Editor, add a sound file.

  1. Type the alias for the sound file.

  1. Use the sound alias in an alarm, Touch animation, or script.
