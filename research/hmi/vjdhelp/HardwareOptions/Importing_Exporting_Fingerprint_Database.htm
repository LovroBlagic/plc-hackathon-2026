24.9.4 Importing/Exporting Fingerprints

You can transfer encrypted fingerprint records from one project to another by importing and exporting the Project User List. For more information on the Project User List, see Section 24.9.3, Upgrading Existing Projects to Include Fingerprints.

 

To Export Fingerprint Records

  1. In the Navigator window's Project tab, expand the Environment node and click Security.

  2. In Vijeo Designer, from the menu bar click Security, and then Export Users.

  3. In the file browser dialog box, navigate to the directory where you want to save the fingerprint records.

  4. Click Save to save the encrypted and encoded user authentication records.

To Import Fingerprint Records

  • Before importing fingerprint records into Vijeo Designer, make sure that the biometric switch configuration software (e.g., Harmony XB5SSoft) is not open.

  1. In the Navigator window's Project tab, expand the Environment node and click Security.

  2. In Vijeo Designer, from the menu bar click Security, and then Import Users.

  3. In the file browser dialog box, navigate to the directory where the fingerprint records are stored and select the file.

  4. Click OK to import.
