24.4.3 Custom Startup Screen

You can create a custom welcome screen to display on the target during startup. Not all targets support this feature. For information about the targets that support the Custom Startup Screen feature, see Appendix 5 Hardware Specifications.

 

Setting up the Custom Startup Screen

  1. In the Target node properties, expand the Startup Options property.

  2. Check the Custom Welcome Screen check box.

  3. Select the image to use for the Welcome Screen and click Open.

The default Custom Welcome Screen uses the image Splash.jpg, which is located in:

  • C:\Users\Public\Documents\Vijeo-Designer\Vijeo-Manager\Samples (for Windows)

–OR–

  • C:\Documents and Settings\All Users\Documents\Vijeo-Designer\Vijeo-Manager\Samples (for Windows XP)

  • Only JPEG files can be used for the Custom Welcome Screen.

  • The JPEG image's width and height cannot be greater than your target machine's screen resolution. For a list of target machines and the screen resolution for each model, see Section 2.2, Supported Tablets, Smartphones, and Target Machines.
