24.8.2.1 Illuminated Switch at IO Manager Node

At the IO Manager node, you can print labels for your illuminated switch. You can choose between two label templates, horizontal or vertical. To print labels, first you need to add the illuminated switch driver to your project. For more information, see Section 24.8.1, Adding the Illuminated Switch.

  1. In the Navigator window's Project tab, expand the IO Manager node and double-click Illuminated Switch to open the Illuminated Switch Driver dialog box.

  2. Click Print Label.

  3. In the Open dialog box, select a label template stored at this path and click Open: C:\Program Files\Schneider Electric\Vijeo Designer\Vijeo Frame\Help\Illuminated Switch Label H.dot (or Illuminated Switch Label V.dot)

    • The templates are MS Word documents designed for A6 paper size. You need to install Microsoft Word application to open the template files.

  1. Edit the template file, print the label, and close the file.

  2. Click OK to close the Driver Configuration dialog box.
