Controlling Groups of LEDs

LED Control Manual enables you to control the color and blink speeds for groups of LEDs. Change the bits of the Color and Blink variables to the same values at the same time and you can set a group of LEDs to the same color and blink speed. For more information on how the Color and Blink variable bits correspond to Function Keys, see Static Variable LED Color Table or Static Variable LED Blink Table.

Using your PLC's ladder program, you can set the color and blink speed for a group of LEDs. Set external variables for the LED Control Manual's Color and Blink variables and configure your PLC's ladder program to write to the bits of these variables. Alternatively, you can use the Variable Method XW to toggle specific bits of integer variables. For more information, see Section 18.9.1.6, Variable Methods: XW.
