24.5.1.2 Target Function Key Advanced Tab

 

 

The following table describes each property in the Advanced tab.

Property

Description

Interlock

 

Select Interlock to set up a condition that must be true in order to allow an operator to activate the Target Function Key operation. The condition can be a BOOL variable, integer variable, or boolean expression.

For more information on Interlock, see Section 24.5.5, Setting Up Interlock for Function Keys.

Hold Delay (sec)

Add a delay (1 to 60 seconds) to the initial touch input.

The Function Key operations are executed after the Function Key is pressed and held down for the number of seconds defined in this field. If the Function Key is released before the defined number of seconds, the operations will not run.

Security Level

Sets the Security Level for the Target Function Key. Once a Security Level is defined, only users with the correct security level can access the Target Function Key operations. For more information on security levels, see Section 4.8.2.1, Protecting Panels and Parts from Unauthorized Users.
