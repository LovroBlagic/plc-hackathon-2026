24.5.1.1 Target Function Key General Tab

The Target Function Key dialog box is available from the Function Keys property in the Target node properties, see Section 4.5.1, Target Properties.

The following table describes each property in the Target Function Key dialog box.

Property

Description

Function Key List

Use the Function Key List to add and remove Function Keys. For information on how to add and remove Function Keys, see Section, 24.5.4, Adding and Removing Function Keys.

When Touch

While Touch

When Release

These tabs define the conditions under which the operations run when the operator presses the Function Key. The list of available operations depends on your type of target machine. Check the Editor to see the list of supported operations. For the list of all available operations and descriptions of the operations, see Section 9.5, Operations.

 

Set up operations to run under different touch conditions using these three tabs:

  • When Touch Tab: Defines the operations that run when the Function Key is pressed.

  • While Touch Tab: Defines the operations that are repeatedly run while the Function Key is being held down.

  • When Release Tab: Defines the operations that run when the function key is released.

Operation List

Displays the list of operations for the Function Key in the order the operations will run.

For more information on creating multiple operations for one function key, see Section 9.5.19, Setting Up Multiple Operations.
