24.7.2 Drawing the Tower Light Toolchest Part

You can create a panel that includes the Tower Light Toolchest part. This part allows an operator to make changes at run time to the patterns that were defined in the Pattern Configuration dialog box in the Editor. Depending on your project design, this panel can be secured so that only authorized operators can make pattern configuration changes at run time. For more information on panel security, see Section 4.8.2.1, Protecting Panels and Parts from Unauthorized Users.

  1. Click the Toolchest icon in the menu bar to open the Toolchest window.

  2. Click the Lamps folder and then the TowerLight folder.

  3. Drag the PatternConfigure part onto the panel. The part is displayed on the panel.

  4. Define the position and display font in the Toolchest part properties.
