24.5.1 Target Function Key

Target Function Keys run global operations that are always available no matter what panel is displaying on the target. For the differences between Target Function Keys and Panel Function Keys, see 24.5, Function Keys: Differences between Panel Function Keys and Target Function Keys.

Labels can be printed out and attached to the Target Function Key to help identify the keys operations. For more information on printing Target Function Key labels, see Section 27.2, Customizing and Printing Target Function Key Labels.

 

The following table describes each tab in the Target Function Key dialog box and references for more information.
