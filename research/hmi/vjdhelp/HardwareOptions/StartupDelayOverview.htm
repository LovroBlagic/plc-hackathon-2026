24.4.1 Startup Delay

You can create a startup time delay for all the target machines in your project. When a startup delay is configured and Vijeo-Designer Runtime is triggered, a message will appear and count down the seconds to the target machine's startup.

When powering on the system, this function delays the HMI startup time to synchronize with an external device, in case the device takes longer to initialize.

Setting Up the Startup Delay

  1. In the Navigator window's Project tab, right-click the Target node and select Properties to display the Target's properties in the Property Inspector.

  2. In the target's StartUpDelay property, enter the number of seconds (0-300 sec) you want the StartUpDelay to wait before the target machine starts up.

  1. Repeat Steps 1-2 for each target machine, as necessary.

  2. In the Navigator window, right-click the Target node, then click Download (or Download All if you changed more than one target's StartUpDelay time).

The project downloads to the target machine, then delays the specified number of seconds before starting up.
