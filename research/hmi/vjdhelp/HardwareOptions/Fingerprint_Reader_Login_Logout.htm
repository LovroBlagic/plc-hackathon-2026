24.9.5.1 Logging in and out of Target Machines

At run time, users can log in to the target machine using a biometric switch depending on their security groups' authentication settings. For example, if authentication is set to Fingerprint, at run time you can place your finger on the biometric switch sensor and log in to the target machine. If authentication is set to Both (password and fingerprint), when you scan your fingerprint, Vijeo Designer Runtime prompts you to enter your user name and password as well. For more information on various authentication methods, see Section 4.8.2.5, Setting Up Security Group Authentication.

You can also log out of the target machine by scanning your fingerprint. A message displays indicating that you have successfully logged out.

  • The biometric switch allows one person to log in to the target machine at any given time. When the biometric switch authenticates a user's fingerprint, the previous logged-in user will be automatically logged out of the target machine.
