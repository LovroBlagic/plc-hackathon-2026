24.3.3 Enable the Buzzer in Parts

You can set up the buzzer in switches, radio switches, and data displays (either numeric or string), in addition to various Toolchest parts.

  1. Use the Graphical Objects tools menu to create a switch, radio switch, or data display (either numeric or string) part.

  1. In the setup dialog box, select the buzzer.

You can also set up a buzzer for the following parts in the Toolchest:

  • Blank Keypad Key

  • Special Keypad Key
