24.5.2 Panel Function Key

Panel Function Keys run operations that are assigned to a panel. Operations run when the panel is displayed on the target and the operator presses the Panel Function Key. Each panel in your project can have different Panel Function Key operations. For example, Panel Function Key R1 can be configured to run a script when Panel A is displayed and open a popup window when Panel B is displayed.

Labels can be positioned on each panel to help identify the Panel Function Key operations set up for the panel. To set up a label, create a Switch with a label that identifies the Panel Function Key operation and position it on the panel near the Panel Function Key. For more information on Switches, see Section 9.2, Creating Switches.
