24.5.3 LED Control

LEDs can indicate the Function Key's state. For example, when the function key is locked out, you can configure the LED to blink red. LED Controls are defined in the Target node properties. For more information on Target node properties, see Section 4.5.1, Target Properties. For a list of targets that support LEDs, see Appendix 5, Hardware Specifications.

There are two methods for controlling LED behavior:

  • Auto Control - See Section 24.5.3.1, LED Control Auto.

  • Manual Control - See Section 24.5.3.2, LED Control Manual.

  • A Function Key can be in the Secured State and the Locked Out State at the same time. Whenever this occurs, the LED's Secured State setting takes precedence over the LED's Interlocked State setting.

  • The Dialog Table can also control Function Key LEDs, see Section 5.6, Working with the Dialog Table for more information.

  • We recommend using LED Control Auto to control the LED's colors and blink speeds.
