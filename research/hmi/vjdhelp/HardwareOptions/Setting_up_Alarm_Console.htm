24.8.2 Setting Up the Illuminated Switch

To configure the illuminated switch, first you need to add the illuminated switch driver to your project. For more information, see Section 24.8.1, Adding the Illuminated Switch.

You can configure the illuminated switch lamps and switches globally for a target node or individually for a panel node. You can also print labels for the illuminated switch lamps at the IO Manager node. The following table summarizes the illuminated switch features that are available at each node:
