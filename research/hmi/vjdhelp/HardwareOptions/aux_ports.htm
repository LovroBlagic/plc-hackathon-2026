24.6 DIO Ports

A DIO Port is a hardware interface on your target machine that provides input and output signals to connected equipment. Vijeo Designer supports the following pins on the DIO Port: ALM, RUN, and BUZZ.

  • Not all target machines support the DIO port, see Appendix 5, Hardware Specifications.

  • For most target types, you can find DIO pins in the AUX interface.

  • When a target machine is restarted, the DIO Port is initialized to 0 (OFF).

  • For some iPCs, you can choose either ALM or RUN by configuring the Target setting, DIOPort Out 1, to either Alarm or Error. For some iPCs, you only have the ALM option. See Section 4.5.1, Target Properties.

The following table lists the pins on the DIO port supported by Vijeo Designer.

Name of DIO Pin on Hardware

Name of DIO Pin in Vijeo Designer

Description

ALM
(DOUT_1 on Targets with a RAS Port)

Alarm

The ALM pin turns on when an alarm in either the assigned alarm group or the assigned alarm category becomes active. The ALM pin turns off once all active alarms in either the specified alarm group or the specified alarm category return to normal (RTN), become acknowledged (ACK), or change to the unacknowledged (UNACK) state.

See Section 16.2.3, Setting up the Alarms and Events Node for information on how to specify an alarm group or an alarm category to output to the ALM pin.

RUN
(DOUT_1 on Targets with a RAS Port)

Error

The RUN pin turns on when a run-time event occurs. The run-time event also triggers the Active Event Viewer to display. The RUN pin turns off when the user closes the Active Event Viewer.

See Section 28.1, Run-time Events for information on run-time events.

BUZZ
(DOUT_0 on Targets with a RAS Port)

DIO DOut0

The BUZZ pin is controlled by the user. You can turn the BUZZ pin on and off by writing values to the BOOL system variable _DIOPort.DOut0. Use the following methods to write values to the _DIOPort.DOut0 and control the BUZZ pin:

  • Connected Equipment: see Section 6.7.3, Using System Variables on Connected Equipment.

  • Scripts: see the following section, Script Methods for Controlling the BUZZ port.

  • Animation: see Section 9.2.7, Creating A Custom Switch.

  • Data Displays: see Section 11.1, Overview.

  • Switches: see Section 9.2, Creating Switches.

The following table describes how the BUZZ pin's on/off states correspond to the values of the system variable _DIOPort.DOut0.

_DIOPort.DOut0 Value

Script Methods for Controlling the BUZZ pin

The following lists some script variable methods you can use to control your target machine's BUZZ pin.

Turn the BUZZ pin ON

_DIOPort.DOut0.write(1);

Turn the BUZZ pin OFF

_DIOPort.DOut0.write(0);

Reading the BUZZ pin value

_DIOPort.DOut0.getIntValue();

 

For more information on script variable methods, see Section 18.9.1.6, Variable Methods.
