24.5.4 Adding and Removing Function Keys

You can add and remove Function Keys from both the Panel Function Key dialog box and the Target Function Key dialog box. When adding function keys for external keyboards on some target types, you can set up the Shift, Ctrl, and Alt keys to be required to activate the Function Key on the Keyboard. For more information on the Function Keys supported by your target, see Appendix 5.9, Function Keys Supported by Hardware Platforms. For more information on the differences between Panel Function Keys and Target Function Keys, see Section 24.5, Function Keys: Differences between Panel Function Keys and Target Function Keys.

 

Setting up Target Function Keys:

  1. In the target properties, click the Function Keys ellipsis button to display the Target Function Key Setting dialog box.

  2. Click the Function Key List's Add Button.

  3. Use the Key drop-down list to select a Function Key and click Add.

  4. In the Function Key List, select the newly added Function Key.

  5. User the Operation drop-down list to set up an Operation for the selected Function Key. See Section 9.5, Operations.

 

Setting up Panel Function Keys:

  1. In the panel properties, click the Function Keys ellipsis button to display the Panel Function Key Setting dialog box.

  2. Click the Function Key List's Add Button.

  3. Use the Key drop-down list to select a Function Key and click Add.

  4. In the Function Key List, select the newly added Function Key.

  5. User the Operation drop-down list to set up an Operation for the selected Function Key. See Section 9.5, Operations.

 

Removing Function Keys:

  1. In either the Panel Function Key dialog box or the Target Function Key dialog box, select the Function Key you want to remove from the Function Key List.

  2. Click the delete button in the Function Key List.
