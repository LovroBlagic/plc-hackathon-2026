8.4 Rotating Objects Using Variable Values

8.4.1 Rotate Animation - The Tool for Rotating Objects

Using Rotate Animation, it is very easy to rotate an object based on changing variable values. For example, you can draw a meter needle or fan blades and add rotating motion to them.

Example 1: A measuring device needle rotates based on changes in the Water variable, which stores water temperature values.

Example 2: Fan blades rotate based on changes in the Fan variable, which stores rotation angles.

  • Use only integer values for Rotate Animation. If you use real data type, values to the right of the decimal point are ignored.

  • Not all objects support Rotate animation. For more information, see section 8.1.2, Animation Supported by Objects.

  • If you apply both Rotate animation and Fill animation to an object, the Fill animation will not follow the movement caused by the Rotate animation.
