8.7 Other Animation Features

Vijeo-Designer includes several other useful animation features.

Touch Animation

Give an object or an image the ON/OFF functionality of a switch or other behaviors when touched, such as writing values to variables.

Touch Animation is useful for creating custom switches. For information about switches, see Section 9.2.7, Creating a Custom Switch.

Value Animation

You can display a variable value on the panel, or allow data inputs to the variable from the keyboard/keypad. You can also add Value Animation to text strings for display or keyboard entry. For more information about keyboard inputs, see Chapter 11, Displaying and Inputting Data.

Using a BOOL variable, you can display different messages based on the discrete state. For more information, see Section 10.5, Creating Your Own Lamp, and Section 11.6, Displaying Text Using String Display.
