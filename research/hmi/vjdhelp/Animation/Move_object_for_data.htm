8.3 Moving Objects Using Variable Values

8.3.1 Position Animation - The Tool for Moving Objects

Position animation moves objects vertically, horizontally, or diagonally based on variable values. As the variable value changes, so does the relative position of the object. Configure Position Animation by setting the Value Range and the object's Position Range in pixels.

  • Use only integer values for Position Animation. If you use real data type, values to the right of the decimal point are ignored.

  • Not all parts support position animation. For more information, section 8.1.2, Animation Supported by Objects.
