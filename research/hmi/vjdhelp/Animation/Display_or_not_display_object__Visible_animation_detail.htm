8.5.3 Working With Visibility Animation

  1. On the panel, draw an object or a text object you want to display or hide at runtime.
    The animation will toggle between making the object visible or not depending on the variable's values. For more information on how to draw objects, see Chapter 7, Drawing Graphics.

  2. Open the Animation Properties dialog box using one of the following methods.

Method

Details

Double-click

Double-click an object.

 

  • If you are working with a text object, double-clicking opens the Text Editor. To open the Animation Properties dialog box, right-click the text object and click Animation.

Right-click

Select the object and right-click. Select Animation from the menu.

 

Icon

Select the object on the panel, and click the Animation icon from the Edit toolbar.

Menu

Select the object, and then select Animation from the Edit menu.

  1. Click to open the Visibility tab. Select the Enable Visibility Animation checkbox to switch between the display and hide modes based on changing variable values.
    If you want the object or the text string to blink, select the Enable Blink Animation checkbox, and set the blink speed to either Slow or Fast.

  1. Specify a BOOL or integer variable, or boolean expression.
    Once the variable or expression is set, the object will behave as follows:

 

BOOL variable

ON

Value other than 0

OFF

0

False

 

If you specify a variable for Blink Animation, the object behaves as follows:

  • If you created lamps from the Toolchest, the integer values are different for blink animation. To start blinking (ON), the value must be set to 1. To stop blinking (OFF), the value must be any value other than 1.

When Blink speed is set to Slow, ON/OFF blink cycle is approximately one second (0.5 sec ON and 0.5 sec OFF). When speed is Fast, ON/OFF blink cycles are approximately 0.7 seconds ((0.35 sec ON and 0.35 sec OFF)

  1. Click OK to apply the settings and close the Animation Properties dialog box.

  • If you type a variable name that does not exist in the project, the New Variable dialog box displays.

  • If you click Apply or if you click another animation tab, the settings are applied but the dialog box does not close.
