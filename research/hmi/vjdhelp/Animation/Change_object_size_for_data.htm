8.2 Resizing Objects Using Variable Values

8.2.1 Size Animation - The Tool for Resizing Objects

Using Size animation, it is easy to resize an object based on changing variable values.

For example, an object representing a roll of newsprint can become larger or smaller based on the value of the Roll variable. For example, in a newsprint plant, a value of 1000 could mean the roll is full and ready to be taken off the production line.

  • Use only integer values for Size Animation. If you use floating point data type, values to the right of the decimal point are ignored.

  • Not all objects support size animation. For more information, section 8.1.2, Animation Supported by Objects.

8.2.2 Getting Started With Size Animation

To add Size Animation to an object, follow the steps below.

Steps

1.On the panel, draw an object that will be resized at runtime using animation.

2. Double-click on the object to open the Animation Properties dialog box. Click on the Size tab.

3. Enable Vertical or Horizontal Size Animation, enter the variable, and define the value ranges.
