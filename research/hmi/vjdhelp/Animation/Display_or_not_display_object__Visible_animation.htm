8.5 Displaying or Hiding Objects Using Variable Values

8.5.1 Visibility Animation - The Tool for Displaying or Hiding Objects

If you want to make an object or a text string visible or invisible to the panel operator based on changing variable values, Visibility Animation is the best tool to use.

For example, the value in the Full variable can be used to trigger the display or hide of an image that shows a given quantity of waste inside the incinerator: 0 when the garbage incinerator is empty and 1 when it is full.

For objects that have Touch, Color or Value Animation defined, you can also define Visibility Animation and you can display the object on the screen as required.

Visibility Animation can also trigger Blink Animation.

e.g. Show (On) and Hide (Off), and the blink speed (fast or slow).

  • You can use only integer and BOOL variables or boolean expressions with Visibility Animation.

  • Not all objects support Visibility Animation. For more information, see Section 8.1.2, Animation Supported by Objects.
