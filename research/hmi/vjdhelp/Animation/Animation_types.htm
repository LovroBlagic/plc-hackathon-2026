  • For information on animation supported by the parts, Switch, Lamp, Data Display, Message Display, Meter, Bar Graph, Selector, Video Display, Alarm, and Trend Graph, see their associated chapters.

  • If the LineStyle property for an object is set to INVISIBLE, the Line Color tab is disabled for Color animation.

  • If the Pattern property is set to INVISIBLE, Fore Color is disabled for Color animation; however, you can still use Back Color animation.

  • You cannot add Fill animation to an object when the Pattern property is set to INVISIBLE.

  • You cannot add Value animation to a text object when it's rotated.

  • Rectangles do not support Rotate animation when the Shape is Rounded or Cut.

  • Scales do not support Size animation when the Shape is Circular.

  • Grouped objects that include parts, such as switches, data displays, graphs, and Toolchest parts, only support Visibility animation and Blink animation.

Adding Animation to the Grouped Drawing Objects

When you place several drawing objects on a panel and group them, you can set Color, Position, Rotate, Touch, and Visibility Animation.

For example, you may create a drawing object, such as a line or dot, for which you cannot set up Touch Animation. However, you can set up Touch Animation if you group these drawing objects.

For more information, see Section 7.4.6, Grouping/Ungrouping Objects.

  • Touch animation for the grouped object is not available if it includes an Alarm Summary or an object set up with Value Animation.

If you are adding Animation to a group object, note the following:

  • If Animation is set for an individual object in the group, you cannot add another of the same animation to the group, except for Visibility animation. In other words, Visibility animation supports nesting, but none of the other animations support nesting.

  • If you create an object for which you cannot set up Color or Rotate Animation, you cannot set Color and Rotate Animation when these objects are included in the group object.

  • If there are parts in the group object, you cannot set Animation.

  • You cannot set up Fill, Size, and Value Animation to the group object.
