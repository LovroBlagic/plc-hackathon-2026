8.6 Changing Colors using Variable Values

8.6.1 Color Animation - The Tool for Changing Colors

If you want to make a graphical object or a text string change colors based on changing variable values, Color Animation is the best tool to use.

For example, if you want to monitor a range of values from sensors on a pipeline, you can set the Color Animation for the pipeline to change to a certain color based on the value ranges.

Vijeo Designer provides the following options for color animation:

  • Free Form: Used to create color changes based on value changes for a single graphical object.

  • By State: Used to create the same color changes based on values across multiple graphical objects.
