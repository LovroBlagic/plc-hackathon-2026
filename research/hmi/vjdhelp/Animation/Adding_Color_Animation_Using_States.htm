8.6.3 Adding Color Animation Using States

By State color animation uses color resources to create color changes based on specific values for graphical objects. You can set color resources based on the number of states and change the color of the object based on the values for each state.

If you have multiple objects that change colors based on value readings, you can create multiple graphical objects that use the same color resource.

Once you create one graphical object with the appropriate state values and color resource, you can copy this object. If you need to update the values, each object needs to be updated individually. However, if you want to change the colors applied to the object, simply change the color resource. This change affects all objects that use the resource.

If you have a grouped object, the By State mode is disabled and only the Free Form mode is available.

  1. Double-click the graphical object to display the Animation Properties dialog box.

  2. In the Mode drop-down list on the Color tab, select By State.

  3. Set these options as follows:

    Option

    Description

    Enable Color Animation

    Select this check box to use animation for this object.

    Data Type

    Select either BOOL, String, or Integer from the drop-down list. To toggle the color on and off with only two states, select BOOL. To change the color based on more than two integer values, select Integer.

    Variable

    Click to display the BOOL or Integer variables. Select a variable from the Expression Editor Pad then click OK. For more information on variables, see Section 6.1, About Variables and Device Addresses.

    No. of States

    If the Data Type is set to BOOL, the number of states is automatically set to two.

    If the Data Type is set to Integer, select the number of states to use. You can set from two to 32 states.

    Value List

    If the Data Type is set to String or Integer, click the ellipsis to open the Value List. In the Value List, you can set up values to a color's state. When the control variable's value switches to one of the values in the value list, the color switches to the corresponding state. For more information, see Section 21.8, Using Value List.

    Color Resource

    Either select or create a color resource to match these states. If there are existing color resources that match the number of states, these resources are displayed in the drop-down list.

    If no color resource are displayed, you can create a new resource. Click to create a new resource and open the Color Resource Library. The number of states in the Resource Library matches the number of states for the object. Invalid is also displayed to allow you to set the color for this state.  

    You can also edit an existing resource. Click to edit an existing resource in the Color Resource Library.

    For more information, see Chapter 21, Setting Up Reusable Resources.

     

  4. Click OK to confirm your settings in the Animation Properties dialog box.
