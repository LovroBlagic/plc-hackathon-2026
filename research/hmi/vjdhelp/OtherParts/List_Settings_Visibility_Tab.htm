14.2.3 Visibility Tab

Use this tab to define invisibility and blinking.

 

Property

Description

Enable Visibility

Select Enable Visibility, and then select a BOOL or integer variable or enter a boolean expression that controls whether the Message or Image Display is visible (ON) or not (OFF).

  • If true, the Message/Image Display is visible.

  • If false, the Message/Image is not visible.

  • Touch inputs are possible only when the object is visible.

  • If in the middle of data input this variable turns off, your input will not be stored. Whatever you were typing will be gone.

Invisible when in invalid state

If selected, the message or image display will not be drawn when it is in an invalid state. The message or image display is in an invalid state if the value of the variable does not equal an Integer Value. For more information on assigning Integer Values to a state, see Section 21.8, Using Value List.

Enable Blink

Select Enable Blink to make the Message/Image Display blink. You can choose a BOOL or integer variable or enter a boolean expression.

  • If true, the Message/Image Display will blink.

  • If false, the Message/Image Display will not blink.

  • You cannot Enable Blink objects that use a resource set up with blink colors or blink images.

Speed

Set the blinking speed to fast or slow. A fast blink rate is 350 ms and slow blink rate is 700 ms.
