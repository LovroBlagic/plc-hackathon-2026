14.2.1 General Tab

This section describes how to define the general settings for Message and Image Displays.

Message Display

In the General tab of the Message Display, define the variable or expression that controls the display. Define messages in the selected text resource.

Image Display

In the General tab of the Image Display, define the variable or expression that controls the display. Define images in the selected image resource.

 

Properties

Property

Description

Name

The message or image display's name.

Whenever a display is created, a default name is generated. When renaming the display, its name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

For details, see Appendix 9, Naming Conventions.

Variable

The value of the variable or expression defines which message or image to display. When the value equals the associated value defined in the resource, it displays the corresponding text or image.

The data type of this field depends on the selected resource. When the resource is set up with Data Type = Integer, enter an integer variable or expression. When the resource is set up with Data Type = String, enter a string variable or expression.

  • To enable data inputs from the display, enter a single variable. If you use an expression, Input Mode is disabled.

States

Define the number of different messages or images to display (1 to 255). This number must be less than or equal to the number of states in the associated text or image resource.

Style

For Message Displays, select the frame around the display. Use the color resource to define the frame colors.

Color Resource

For use with Message Displays, define the color of the message and frame in Color Resources. You can define a different set of colors for each state.

 

  • For information about resources and how they can improve the usability of your application, see Section 21.1, Setting Up Reusable Resources.

  • Click the New Resource icon to define a new set of resources (see Section 21.1.4.1, Creating Resources: Parts dialog box).

  • Select a resource from the list to use property definitions in an existing resource (see Section 21.1.4.2, Selecting Resources For Your Part).

  • Click the Resource View icon to edit the selected resource.

Text Resource

For use with Message Displays, define the text strings to display in Text Resources. You can define a different string for each state, and for each user language.

Image Resource

For use with Image Displays, define the image for each state in Image Resources.

Alignment

For use with Message Displays. Select the horizontal (left, center, or right) and vertical (top, middle, or bottom) alignment of the display text.
