14.5 Example: Combined Message/Image Display

In many applications, you may want to display both a message and an image to convey information to the user. For example, the previous section used just an Image Display to show the current state of the conveyor belt. If we wanted our application to also display instructions to the panel operator, then we would add a Message Display with the same state conditions.

This example builds on the example from Section 14.4 by adding a Message Display. The following table lists the image and message to display to the user when the conveyor belt is in the defined state.

With the added Message Display, the application now provides the panel operator with instructions that are especially important when there is a problem.

0 = Conveyor belt is stopped (safe).

1 = Conveyor belt is in operation, moving forward (unsafe).

2 = Conveyor belt is in operation, moving backward (unsafe).

3 = Conveyor belt is paused (neutral).

255 = Conveyor belt has a problem or error (danger).
