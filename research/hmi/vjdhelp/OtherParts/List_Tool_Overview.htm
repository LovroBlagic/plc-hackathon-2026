14.1 Message/Image Display: Overview

You can use the Message and Image Display tools to create message and picture displays that change as the associated variable or expression value changes. You can display 256 different messages or images, as these tools support states 0 to 254 and the Invalid state.

Message and Image Displays are useful in conveying information quickly to the panel operator. The information could be in the form of a text string that gives instructions to the panel operator, or the information could be an image that shows the current state.

Message and Image Displays also accept touch inputs so you can change the state by writing a value to the associated variable.

Image Display Example

You can use the Image Display to display different images for the running states of a conveyor belt. The Image Display is drawn in the top-left corner in the following examples.

0 = Conveyor belt is stopped (safe).

1 = Conveyor belt is in operation, moving forward (unsafe).

2 = Conveyor belt is in operation, moving backward (unsafe).

3 = Conveyor belt is paused (neutral).

255 = Conveyor belt has a problem or error (danger).

  • Images consume lots of memory. Be careful when you use lots of images as the CF Card/SD Card and internal memory (flash memory) space is limited on the target machine.

Multiple Languages

The Message Display is integrated with Vijeo-Designer's Language feature, which offers you the ability to display a different message depending on the variable state and the user language. Each message can be up to 255 characters long.
