14.2.4 Advanced Tab

Use this tab to add a condition for enabling touch input.

 

Property

Description

Enable Interlock

Select Enable Interlock to set up a condition that must be true in order to change the display state. The condition can be a BOOL or integer variable or boolean expression. For more information, see Section 9.6, Using Interlock to Prevent Accidental Touch Input.

 

  • During data input, if the interlock variable turns OFF, data input is cancelled.

Security Level

Sets the Security Level for the Message/Image Display. Once a Security Level is defined, only users with the correct security level can access the Message/Image Display's functions. For more information on security levels, see Section 4.8.2.1, Protecting Panels and Parts from Unauthorized Users.
