14.2.2 Input Mode Tab

The Message and Image Displays can accept touch inputs.

 

Property

Description

Enable Input Mode

Enables you to change the state in the Message or Image Display.

 

  • This setting is unavailable if you enter an expression in the General tab's Variable property.

Field ID

Set up a unique field ID for triggering the input mode from the _TouchField system variable. The field ID must be a value between 0 and 2,147,483,647. The default value is 0. If the Field ID's value is 0, the input mode cannot be triggered from the system variable. Each Field ID should be unique for your project. For more information on system variables, see Section 6.7, System Variables.

Display Popup Keypad

Touching the Message or Image Display pops up a keypad.

Select the type of popup keypad you want to use.

  • Change-Immediate: Keypad that increments or decrements the state right away. To see what the keypad looks like, see Section 11.9.2.4 Change-Immediate Keypad.

  • Change-On-Enter: Keypad that increments or decrements the state when you touch the Enter key. To see what the keypad looks like, see Section 11.9.2.5, Change-On-Enter Keypad.

  • Numeric or String: Displays either a decimal or string keypad, depending on the data type defined in the text or image resource. Use the keypad to enter a value to the display variable. The list of appropriate values is in the associated text or image resource.

To see what the numeric and string keypads look like, see Section 11.9.2.2, Numeric Keypads or 11.9.2.1, String Keypads.

Increment Only

Touching the Message or Image Display increases the state. When you reach the last state and you touch the display again, you can choose to either not change the display (Stop at End), or display state zero (Rollover to Beginning.)

Decrement Only

Touching the Message or Image Display decreases the state.

When you reach state zero and you touch the display again, you can choose to either not change the display (Stop at Beginning), or display the last state (Rollover to End.)

Hold Delay

If you select this check box, you can add a delay (1 to 60 seconds) to the initial touch input.

When using a popup keypad, the keypad displays only after you've touched the display continuously for the defined number of seconds.

When using the increment or decrement operation, the display increases or decreases the state only after you've touched the display continuously for the defined number of seconds.

Buzzer On Touch

If you select this check box, the target machine beeps when the display is touched.
