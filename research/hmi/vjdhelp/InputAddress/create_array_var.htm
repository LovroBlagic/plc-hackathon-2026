6.8.1 Creating Arrays

You can create two types of arrays:

  • A user data type array.

  • A new variable that uses the Array Dimension property.

There are several differences between the two arrays. When you create an array data type using the User Data Types dialog box, you can easily create several variables using the created array data type. You can also add the array as an element in a structure data type. Finally, you can only create multi-dimensional arrays using user data types. In contrast, the Array Dimension property is only useful for creating one instance of a single-dimensional array. For more information on user data types, see Section 6.2.4, Creating User Data Types.

Creating a User Data Type Array

  1. Create an array data type using the steps described in Section 6.2.4.3, Creating Array Data Types.

  2. Select the newly created array data type in one of the two following ways.

  3. Right-click the Variable's node and select New Variable. Select User Data Types and then the name of the newly created array data type.

  • In the variable spreadsheet, select the drop down arrow beside the icon. Select User Data Types and then the name of the newly created array data type.

Creating an Array using the Array Dimension property

  1. Create a variable using the steps described in Section 6.2.2, Creating Variables.

  1. The Data Type and Data Source for the newly created variable will become the data type and data source for all the array's elements.

  1. Right-click the newly created variable in the Variable list, and select Properties. Alternatively, you can double-click the variable's row number to open the properties. The variable's properties are displayed.

  1. In the Array Dimension field, enter the number of elements to be created and press Enter. The array is created and the elements are added below the array variable.

  1. You cannot create multi-dimensional arrays using this method. To create a multi-dimensional array, use the User Data Types dialog box.

The array elements created reflect the properties of the parent variable. You can specify different properties for the individual elements in the array.

  • An array can have a maximum of 2048 elements.

  • The maximum length of names used in arrays is 256 characters. This character count includes the array variable name, element name, and symbols that designate elements. For example, the character count for MyArray[3] is 10 characters.
