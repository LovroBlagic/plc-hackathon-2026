6.13 Reference Variables

Vijeo Designer's reference variable feature allows you to create variables that reference other variables for their values. You can change the variable that is being referenced during run time. You can also change the variable that an object is referencing at run time.

This feature is particularly useful in a system where there is multiple equipment with several sets of similar data, for example, multiple compressors in one application. The panel operator can use the reference variable feature to dictate which set of data is to be controlled or viewed using an assembly of Vijeo Designer objects. With reference variables, you no longer have to create multiple panels with similar objects for each set of data.

Reference variables can be used in many objects, such as data displays, lamps, switches, Toolchest parts, and actions. Reference variables cannot be used in recipes and trend graphs. Also, alarms cannot be enabled on reference variables.

You can create a master panel of common objects that use reference variables and then apply the master panel to any base panel in your project. You can also place an assembly of objects using reference variables into the Toolchest for later use in projects. When the objects are dragged and dropped onto a panel from the Toolchest, the reference variables and parameter variables will be created in the project if they do not already exist. If a variable already exists, it will be automatically linked to the part. Therefore, you need to verify whether the  settings for the existing variable are correctly defined for the Toolchest part.

Key Terms

Before you use the reference variable feature, you must understand the key terms that are used:

  • Reference Variable is a dynamic variable that can be used in place of a regular variable in an object, part, or action. During runtime, the reference variable can access data from multiple variables, one at a time. For example, you can create reference variable RefDiscP to access DiscP1 on Station 1 or DiscP2 on Station 2. It depends on the value of the parameter variable (StationNum).

  • Reference String defines the variables that determines the reference variable's value during run time. The reference string is determined by the format and the values of the parameter variables at runtime. The reference string becomes the name of the variable that the reference variable will use for its value. For example, DiscP%d is the reference string, where DiscP is the format and %d is the parameter variable's value at runtime.

  • Parameter Variables are variables whose value is part of the reference string. At runtime, the parameter variable's value can be changed by the panel operator in order to access a set of variables. A reference variable can have one parameter variable (such as StationNum) or multiple parameter variables (such as PlantName and StationNum). You can have up to three parameter variables for each reference variable.

Before You Use the Reference Variable Feature

Using the reference variable feature requires planning and should start at the HMI design phase. Before developing a project with reference variables, the HMI designer needs to plan the following key elements:

  • The Vijeo Designer objects that will use the reference variables.  

  • The variable or multiple variables that will be referenced.

  • The parameter variables that will be used to direct the reference string.
