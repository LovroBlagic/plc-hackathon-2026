_ControllerStatus

Integer variable that stores the status value of the controller. For more information on the locked out status, see Section 6.7.1, System Variable List: _ControllerLockout.

 

_ControllerStatus Value

Controller State

0

N/A

1

Running

2

Stopped

3

Error

4

Locked Out

 

Read/Write Attributes

 

Read From Variable: Available

Write To Variable: Available

System Variable Attribute: Read/Write

 

  • Not all target machines support this feature. For a list of the target machines that support controllers, see Appendix 5, Hardware Specifications.
