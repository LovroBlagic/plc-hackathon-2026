_TimeZoneOffset

Integer variable that indicates the current value of the Time Zone Offset in minutes (-720 to 780 minutes) from GMT. See Sections 4.5.3, Displaying Data Using Time Zone and Configuring Daylight Saving Time and 6.7.2, Using Date and Time System.
