6.1 About Variables and Device Addresses 

6.1.1 Variables

Variables are named spaces in memory that store data values. You can think of the variable as a container for a value.

Create all the variables you need, then associate variables with switches, lamps, data displays and other objects on the panel.

6.1.2 Variables and Data Types

A variable's data type determine's the type of data that you can store in the variable. You can set up variables with the following data types.

In addition to the above data types, you can use another kind of data type, called a user data type, to create variables that contain collections of other variables. You can create two kinds of variables using user data types: array variables and structure variables. For more information on data types, see Section 6.2.1, Variable Types.

6.1.3 Variables and Device Addresses

To communicate with PLCs and other equipment connected to the target machine, create a variable and assign a device address to it.

The variable in Vijeo Designer, which is assigned to a device address, is updated whenever data changes on the equipment. By associating device addresses to variables, Vijeo Designer can read and display data from equipment.

When you connect multiple equipment to the target machine, you can display device address data from different equipment, on the same panel.

6.1.4 Source: Internal Versus External

Internal variables are variables that are not associated with an equipment, and are used solely for internal Vijeo Designer operations.

External variables are variables associated with a device address.

You can use both internal and external variables on the same panel.

  • One Target can have a maximum of 8000 or 12000 variables depending on the target type. For more information, see Appendix 4, Run-Time Specifications. Array and structure holders (the group node) also count as variables. A block variable counts as 1 variable.

  • You can use a maximum 800 variables on a single panel.
