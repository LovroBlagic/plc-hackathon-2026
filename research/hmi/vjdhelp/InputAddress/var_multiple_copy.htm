6.5.3 Making Multiple Copies of Variables

The procedure to make multiple copies of a variable is different depending on the variable's data type and data source.

Duplicating Internal Variables, Array Variables, or Structures

  1. In the Variables Editor, right-click a variable (one that is internal) and click Duplicate to access the Duplicate Variables dialog box.

  1. In the Duplicate Variables dialog box, enter an integer from 1 to 3000 in the Number of copies field and click Duplicate to duplicate the variables in the target.

Duplicating External Variables

  1. In the Variables Editor, right-click the selected variable (one that is external) and select Duplicate to access the Duplicate External Variables dialog box.

  1. In the Number of Copies field, enter an integer from 1 to 3000.

  2. You can increase the device address for each duplicated variable. Select the Increase the Device Address By checkbox, and enter the amount to increase the device address. Use the guidelines below when using Increase Device Address By.

  • BOOl variables: If the Increase value is 1, the device address increments by 1 bit.

  • INT, UINT variables: If the Increase value is 1, the device address increments by 16 bits.

  • DINT, UDINT variables: If the Increase value is 1, the device address increments by 32 bits.

  • Integer variables: If the Increase value is 1, increments the device address by the variable's data length. The data length can be 16 bits or 32 bits as defined in the variable device settings. You cannot increase device addresses if the integer's data length is set to bit field.

  • REAL variables: If the Increase value is 1, the device address increments by 32 bits.

  • STRING variables: If the Increase value is 1, the device address increments by the string byte count (NumOfBytes).

  1. Click Duplicate to duplicate the variables.

  • Using the duplicate command, you can create variables with device addresses that are out of range. Invalid device addresses are caught at validation.

  • When duplicating a variable that has a device address sub-element ending in a letter for Allen Bradley's DF1 Full Duplex, EtherNet/IP, and EtherNet/IP (Native) drivers, the device address does not automatically increment.

6.5.4 Deleting Variables

  1. Select the variables that you want to delete using any of the selection methods found in Section 6.5.1, Selecting Variables.

  2. Right-click the selected variables, click Delete, and then click Yes.

  • If you delete a variable that is used in a project, errors will appear during validation.

  • For information about finding and deleting unused variables, see Section 6.15.3, Listing and Deleting Variables.

  • You cannot delete elements in an array or structure using the variable spreadsheet. Elements can only be deleted in the User Data Types dialog box. For more information, see Section 6.2.4.4, Deleting User Data Types.

6.5.5 Editing Variables

You can edit variables in one of two ways:

  • Variable Editor

  • Variable Properties dialog box

To edit variables in the Variable Editor:

  1. Double-click the Variables node to display variables in the Variable Editor.

  2. Edit the variable's properties in the Variable Editor.

To edit variables in the Variable Properties dialog box:

  1. Double-click the Variables node to display variables in the Variable Editor.

  2. Double-click the row number for the variable you want to edit.

  3. Edit the variable's properties in the Variable Properties dialog box.
