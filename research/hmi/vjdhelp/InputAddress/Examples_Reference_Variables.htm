6.13.1 Examples of Reference Variable Use

This section describes how to set up reference variables with parameter variables, and describes how the parameter variable's value can be changed by the panel operator at runtime in order to change the variable the reference variable is pointing to. Using examples, this section describes how to use a reference variable:

  • With one parameter variable

  • With multiple parameter variables

  • In master panel objects.

Reference Variables with a Single Parameter Variable

In this example, the panel operator needs to monitor and control the compressors located in five stations. Using the reference variable feature, only one panel needs to be set up to display the set of data for the compressor at each station. The following table below shows the variables that you want to reference depending on the station at the plant you choose. The reference variables for each attribute (RefCaseP and RefDiscP) point to the target variable. When the station number changes, the values for each variable assigned to each attribute dynamically change.

At runtime, the set of data for each compressor located at five stations in the plant can be displayed without having to change panels, as shown in the image below. If the panel operator wants to view the set of data for the compressor at Station No. 2, simply change the station number from 1 to 2. For information on how to set up reference variables with a single parameter variable using the above example, see Section 6.13.2, Setting Up Reference Variables.

Reference Variables in Master Panel Objects

You can set up a master panel of common objects that can be used for all base panels in a project. The following example shows how you can use a menu created in a master panel that is common to two different panels in a project. One panel displays the layout for Building 1 and the second panel displays the layout for Building 2. Using the menu, you can switch between viewing Building 1 and Building 2, select a zone in the building that you want to view or control, and view or change the temperature and lighting data.
