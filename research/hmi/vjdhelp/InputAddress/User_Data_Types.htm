6.2.1.2 User Data Types and Folders

In the Variable List, user data type variables are displayed as a tree, which you can expand and minimize as necessary.

Array

An array variable is a collection of variables of the same data type.

You can add up to 2048 elements to an array.

You can create an array with up to 11 layers.

For information on creating arrays, see section 6.8.1, Creating Arrays.

  • An array's data source and scan group property determines the data source and scan group settings for all the elements in the array.

  • If an array contains a variable that can only be used with an external data source, the entire array will be external.

Structure

A structure variable is a collection of variables of different data types.

You can add up to 200 variables to the structure.

You can create a structure with up to 10 layers.

For information on creating structures, see section 6.12.1, Creating Structure Variables.

  • A structure's data source and scan group property determines the data source and scan group settings for all the elements in the structure.

  • If a structure contains a variable that can only be used with an external data source, the entire structure will be external.

Folder

Improve the management of variables by organizing your variables into folders. Variables inside a folder behave the same as similarly configured variables outside the folder.

You can edit only the Name and Description properties in a folder.

You can add up to 2000 variables to the folder.

  • You can create nested folders (folders inside a folder). A folder can have a maximum of five nested folder levels.
