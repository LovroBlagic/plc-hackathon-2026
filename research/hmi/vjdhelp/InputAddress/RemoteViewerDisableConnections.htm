_RemoteViewer.DisableConnections

Boolean variable that controls remote access between the Vijeo Design'Air client and server.

 

_RemoteViewer.DisableConnections Value

Control State

0

Connections are allowed.

1

  • Connections are not allowed.

  • All current connections will be closed.

  • This is the default value when the Vijeo Design'Air Security is enabled.

 

Read/Write Attributes

 

Read From Variable: Unavailable

Write To Variable: Unavailable

System Variable Attribute: Read Only

 

  • Not all target machines support this feature. For a list of the target machines that support controllers, see Appendix 5, Hardware Specifications.
