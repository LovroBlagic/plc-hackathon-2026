6.2.4.5 Importing and Exporting User Data Types

Importing User Data Types

To import data types in to the User Data Types dialog box:

  1. Open the User Data Types dialog box. See Section 6.2.4.1, Opening the User Data Types Dialog Box.

  2. Click Import.

  3. Select the file containing the user data types you want to import. The file extension should be VJDDataTypes.

  • When imported User Data Types have the same name as User Data Types in the project, the User Data Types are not imported and the existing User Data Types will not be overwritten.

  • When imported User Data Types have the same name as variables in the project, the User Data Types are not imported.

Exporting User Data Types

To export data types from the User Data Types dialog box:

  1. Open the User Data Types dialog box. See Section 6.2.4.1, Opening the User Data Types Dialog Box.

  2. Click Export.

  3. Type the file name and select the location you want to export to. The file extension will be automatically appended to the file name.
