6.3.4.3 Updating Linked Variables

If you make changes to the symbols in the equipment configuration software, you can update the corresponding variables used in Vijeo Designer by updating the link.

  1. Export the configuration file from the equipment configuration software.

For a list of PLC symbol files that Vijeo Designer can work with, see the table in Section 6.3.4.2, Data Type Import Rules.

  1. When you first linked the configuration file, you copied the file to the Vijeo Designer editor PC, or to a network folder visible from the PC. Copy the exported file overtop the previous file.

  2. Right-click the Variables node and click Update Link. Update Link is available if at least one PLC symbol file is linked.

The Update Link dialog displays all the configuration files that are linked to the target.

 

Dialog Item

Description

File Name, Equipment, Location

File Name: Name of the linked equipment symbol file.

Equipment: Name of the equipment node in the I/O Manager that the configuration file is linked to.

Location: Folder location of the equipment symbol file.

Update

Updates the link for selected PLC symbol file.

Update All

Updates all the linked PLC symbol files.

Remove

Removes the selected PLC symbol file.

Variables linked to the removed file are not deleted. Only the link is removed.

Close

Closes the dialog box.

  1. Select the link for the new configuration file then click Update.

  2. A confirmation box displays to indicate the variable data types and device addresses of variables will be updated to match the configuration file. Click Yes to complete the update.

All the variables linked from the configuration file are updated. If there was a change in device address in the configuration tool, then the same change is made to the linked variable in Vijeo Designer. If you made a change in the device address in Vijeo Designer, then it too will be updated to match the configuration file.

If for some reason you changed the data type of the linked variable, which is not recommended, then the variable data type will also be updated with the data type to match the PLC symbol file. For information on how data types are converted, see section 6.3.4.2, Data Type Import Rules.

All the other variable properties will remain unaffected.

  • If the equipment's PLC symbol file is not in the folder identified by the Location field in the Update Link dialog box, then you cannot update the link.

  • When you update the link to the PLC symbol file, updating will overwrite any changes you may have made to the linked variable's Data Format (BOOL, Integer, REAL, or STRING) and Device Address. All other property settings are preserved in the variable, including variable names. For example, if variable names are changed in a configuration tool (e.g., UnityPro) after the variables have already been imported into Vijeo Designer, their names will not be updated in Vijeo Designer. Similarly, if variables are deleted in a configuration tool after they have already been imported into Vijeo Designer, they will not be deleted in Vijeo Designer.
