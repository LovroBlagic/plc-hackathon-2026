6.8 Array Variables

An array is a collection of variables with the same data type and the same data source. Each variable in an array is called an element. The total number of elements in an array cannot exceed 2048.

Arrays like this example are highly useful because instead of making 24 individual variables to represent the hours of the day, you only need one array with 24 elements in it to represent the hours of the day.

Multi-Dimensional Arrays

A multi-dimensional array is an array that contains other arrays. For example, an array that contains two DINT arrays is a two dimensional array. An array cannot exceed 10 dimensions.

  • One Target can have a maximum of 8000 or 12000 variables depending on the target type. For more information, see Appendix 4, Run-Time Specifications. Array holders, structure holders, and folders also count as variables. A block variable counts as 1 variable.

  • If you want to access one of a number of consecutive device address values, instead of using arrays and setting up consecutive device addresses in each array element, use indirect addressing. See Section 6.3.3, Dynamically Referencing Device Addresses.

  • When you use array variables in a script, dynamically accessing array elements by using an index loads the entire variable array into memory. The reason the application operates this way is the editor cannot distinguish which array elements are used by the script at run time. As a result, the editor builds the application so it loads the entire array. If there are many elements in the array, it occupies a lot of memory and slows operations on the panel.

In the following example, IntegerArray is a Vijeo Designer integer array variable with 500 elements. Although the script uses only the first 10 of those elements, at run time all 500 array elements are loaded into memory.

int a[ ] = new  int[10];  // create local integer array

for (int i=0; i<10; i++)

{

a[i] = IntegerArray[i].getIntValue( ); // loads all 500 elements

}

Instead of loading all 500 elements of IntegerArray into memory, you can improve the performance by loading only elements 0 to 9 by changing the script as follows.

int a[ ] = new  int[10];

a[0] = IntegerArray[0].getIntValue( );

a[1] = IntegerArray[1].getIntValue( );

a[2] = IntegerArray[2].getIntValue( );

a[3] = IntegerArray[3].getIntValue( );

a[4] = IntegerArray[4].getIntValue( );

a[5] = IntegerArray[5].getIntValue( );

a[6] = IntegerArray[6].getIntValue( );

a[7] = IntegerArray[7].getIntValue( );

a[8] = IntegerArray[8].getIntValue( );

a[9] = IntegerArray[9].getIntValue( );
