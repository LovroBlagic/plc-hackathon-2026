_FileTransferStatus

Integer variable identifying the status of a single data transfer operation between the target and its CF Card/SD Card or USB drive. Multiple data transfer operations are queued and run sequentially, so the variable can rapidly switch from Ready/Busy/Ready as each transfer operation in the queue completes. For more information on the copy operation, see Section 9.5.15, Copy Data Operations.

_FileTransferStatus Value

Transfer Status

Ready

1
