  • Concept project file paths are limited to 25 characters.

  • Concept project files do not support arrays or structures.

  • When working with Concept project files, the Export Variable mode for OFS must be enabled before saving the application.

    Steps to enable Export Variable mode for OFS:

    1. Open the Concept.ini file (see c:\winnt).

    2. Find the following section.
      <; ExportVariables: enable/disable variable export for OFS
      <ExportVariables=1

    3. Set ExportVariables to 1.

    4. Save the Concept.ini file.

    5. In each Concept project, make a minor modification and save.

    6. Import the project into Vijeo Designer.
