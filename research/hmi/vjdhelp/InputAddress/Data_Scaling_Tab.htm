6.2.3.4 Data Scaling Tab

Data Scaling Tab

This field is available when DataType is an integer type or REAL, and the Source is External. Select Enabled or Disabled. DataScaling converts data between the Equipment and the HMI.

RawMin/RawMax

ScaledMin/

Scaled Max

This field is available when DataScaling is Enabled. It defines a legend that shows how PLC data is converted between the PLC and HMI display.

  • RawMin/RawMax refers to PLC data.

  • ScaledMin/ScaledMax refers to data displayed in the HMI. Values are rounded to the nearest supported decimal place.

If data is outside the RawMin/RawMax or ScaledMin/ScaledMax ranges, data is converted proportionally.

For example, if the RawMin/RawMax range is 0~10, the ScaledMin/ScaledMax range is 0~100, and the data in the PLC is 20, the value displayed on the HMI will be 200.

For variable value ranges, see Section 6.2.1.1, Basic Variable Types.
