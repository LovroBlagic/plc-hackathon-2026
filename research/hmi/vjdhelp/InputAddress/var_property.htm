6.2.3 Variable Properties

You can set up variable properties in the Variable Properties dialog box or in the Variable Editor.

The tables below list the variable properties and describe their functions.

6.2.3.1 Basic Properties Tab

Basic Properties Tab

The properties below detail the variable's basic settings.

Variable Name

Displays the variable name that can be edited. Enter up to 32 valid characters. Variable names must be unique within a target.

  • You cannot change the name of system variables, which begin with an underscore character. See Section 6.7, System Variables.

Description

Enter a description about the variable. You can enter up to 255 valid characters.

Array Dimension

When you use the variable as an array, this property defines the number of elements in the array. All elements in an array have the same data type. You can edit the data details of individual elements in the Property Inspector. See Section 6.8, Array Variables.

Block Elements

When using Block variables, this property defines the number of elements in the block (1 to 1024).

  • The size of each element is determined by the variable data type and data length.
    The Start Address defines where the block begins and the Number of units defines the total size of the block, which must fit into the supported device address range.

Size of Block REAL = Number of units x 32 bits

Size of Block INT, Block DINT, Block UINT, Block Integer = Number of units x Data Length

Data Type

Select the type of data to be stored in the variable. For information on data types, see Section 6.2.1, Variable Types.

Data Source

Select Internal to use variables internally within the target machine, or External so the variable can communicate with the equipment.

  • Internal variables are used only within the project and do not communicate with the equipment.

  • External variables obtain data by communicating with connected equipment.

Reference

This field is available only when the Source property is set to Internal. The Reference variable feature allows you to create variables that refer to other variables for their values. You can use the reference variable for objects, such as numeric displays and switches. At runtime, the values for the objects that use the reference variable can be changed dynamically by changing the values of the variables they reference to. For more information, see Section 6.13, Reference Variables.

To set up the Reference variable, enable this property, and then enter the Reference String and the parameter variables.

Reference String

This field is available when the Reference variable feature is enabled. The reference string is where you build the name of the variable that will be referenced at runtime. Enter a Unicode string that follows the syntax rules, where %s, %d, %nd, and %0nd are placeholders:

  • %s inserts the parameter as a string

  • %d inserts the parameter as a decimal number

  • %nd or %0nd inserts "n" (a number from 1-9) digits of a decimal number.

  • %nd, where "n" is a constant number, for example: Temp%3d would be Temp31, Temp32, Temp33, and so on.

  • %0nd,  where "n" is an integer indicating the number of leading zeros, for example: Temp%03d would be Temp001, Temp002, Temp003, and so on.

Define the parameter variables whose values will be used as part of the reference string for the reference variable. You can define up to three dynamic fields in the reference string. The variables must exist in the project for you to use as parameter variables. Click to open the Variables List and select internal or external variables. A parameter variable cannot be an expression and cannot be a reference variable. You can only set a parameter variable to the following data types: BOOL, Integer, and String. A parameter variable cannot be set to a Float data type.

 

If you want the reference variable to point at a set of variables at target start-up, you will need to use internal variables for the parameter variables and set the initial value for these internal variables.

Sharing

This field is available only when the Target property Data Sharing is set to Enabled and the Reference variable feature is not selected. Use this property to define which variables are available for viewing and editing from other targets.

Select None, Read-Only, or Read/Write.

  • None: The variable cannot be viewed or edited by other targets on the network. If an external application tries to access the variable, it will received an Access Denied error.

  • Read-Only: Other targets on the network can view the variable value.

  • Read/Write: Other targets on the network can view and edit the variable value.

Scan Group

The ScanGroup field is only available when the variable's Data Source is set to External. Select a scan group for the variable to receive data from.

To assign the variable to a Scan Group, it is necessary to configure the connected equipment in the Project Navigator. See Chapter 5, Communications.

Device Address

The Device Address field is only available when the variable's Data Source is set to External.

To set up the device address, the connected device must already be configured. See Section 5.2, Setting Up Your Equipment.

After you click  in the Device Address field, the Device Address Configuration dialog box displays. Use the dialog box to define the device address of the connected equipment that's associated with the variable.

Start Address

When using Block variables, this property defines the start of a block of device addresses associated with the variable.

  • The Start Address defines where the block begins and the Number of units defines the total size of the block, which must fit into the supported device address range.

Size of Block REAL = Number of units x 32 bits

Size of Block INT, Block DINT, Block UINT, Block Integer = Number of units x Data Length

To set up the start address, the connected device must already be configured. See Section 5.2, Setting Up Your Equipment.

After you click  in the Start Address property, the Device Configuration dialog box displays. Use the dialog box to define the device address that's associated with the variable.

Indirect Address

Available for external I/O variables, some variable types support the use of indirect device addresses.

By selecting Indirect Address and defining a variable for the offset, the device address for the variable can be defined at runtime.

For example, if 40001 is defined as the device address in a INT (16-bit Integer) variable, the value of the Indirect Address variable (also known as the offset) controls which device address is used by the variable. If the offset is 5, then the variable value is 31. If the offset is 0, then the variable value is 16.

For details about indirect addresses, see Section 6.3.3, Dynamically Referencing Device Addresses.
