6.13.2 Setting Up Reference Variables

This section describes how to set up reference variables with:

  • A single parameter variable

  • Multiple parameter variables.

Reference Variables with a Single Parameter Variable

This procedure describes how to set up reference variables with a single parameter variable using the example in Section 6.13. The example shows how to create the variables to display a set of data for compressors located at five different stations.

  1. Create the variables that will be referenced by the reference variables for each of the required data. From the example in Section 6.13, you would create a variable for each data (CaseP and DiscP) for each of the five stations in the plant. If you created an internal variable, set the initial value for the variable.

  1. Create the parameter variable. This is the variable whose value defines which variable the reference variable uses in order to access a set of variables. In the example, the variable you want to change is the Station Number. Set the initial value, and the Min and Max values for the parameter variable.

  1. Create the reference variables, and define the properties for each reference variable in the Variable Properties dialog box.

Select the data type. The reference variable's data type should be the same as the target variable's data type.

Reference

Select the check box to enable the reference variable feature.

Reference String

Enter the string format for the variable. The reference string is a Unicode string that follows the syntax rules, where %s, %d, and %0nd are placeholders:

  • %s inserts the parameter as a string

  • %d inserts the parameter as a decimal number

  • %0nd inserts "n" (a number from 1-9) digits of a decimal number with leading zeros as needed, for example: Temp%03d would be Temp001, Temp002, Temp003

Click next to the Reference String property to display the syntax rules. You can enter a maximum number of 200 characters in the Reference String. However, at runtime there is no limit on the size of the reference string.

The Sample field displays a sample derived from the format entered in the Reference String property.

  1. Create an assembly of Vijeo Designer objects on your panel. You can place the objects on a base panel or on a master panel.

  2. Define the variable for each object, and configure the object's settings as required.

In the example, the panel comprises numeric displays for the Station No., Case P, and Disc P. Each has the following numeric display settings:

  1. Station No. –  Select StationNumber in the Variable property, and select Enable Input Mode.

  2. CaseP –  Select RefCaseP in the Variable property, and select Enable Input Mode.

  3. DiscP  –  Select RefDiscP in the Variable property, and select Enable Input Mode.

 

Reference Variables with Multiple Parameter Variables

This procedure describes how to set up reference variables with multiple parameter variables using the example of monitoring the compressors located in four stations at two plants in Section 6.13. The example shows how to create the variables to display a set of data for compressors located at each of the four stations in two plants.

  1. Create the variables the reference variables will use for each of the required data. From the example in Section 6.13, you can either create a variable for each data (CaseP and DiscP) for each station in the each plant, or you can create a structure variable for each plant as shown in the following image.

  1. Create the parameter variables. This is the variable whose value defines which variable the reference variable uses in order to access a set of variables. In the example, the variables you want to change are the Plant Name and Station Number. Create a string variable for the Plant Name (PlantLetter) and a DINT variable for the Station Number (StationNum). Set the initial values for both parameter variables (if they are internal variables), and the Min and Max values for StationNum.

  1. Create the reference variables, and define the properties for each reference variable in the Variable Properties dialog box.

Property

Description

Variable Name

Enter the name of the reference variable.

Data Type

Select the data type. The reference variable's data type should be the same as the target variable's data type.

Data Source

Set to Internal.

Reference

Select the check box to enable the reference variable feature.

Reference String

Enter the string format for the variable. The reference string is a Unicode string that follows the syntax rules, where %s, %d, %nd, and %0nd are placeholders:

  • %s inserts the parameter as a string

  • %d inserts the parameter as a decimal number

  • %nd or %0nd inserts "n" (a number from 1-9) digits of a decimal number.

  • %nd, where "n" is a constant number, for example: Temp%3d would be Temp31, Temp32, Temp33, and so on.

  • %0nd,  where "n" is an integer indicating the number of leading zeros, for example: Temp%03d would be Temp001, Temp002, Temp003, and so on.

Click next to the Reference String property to display the syntax rules. You can enter a maximum number of 200 characters in the Reference String. However, at runtime there is no limit on the size of the reference string, which becomes the variable name.

The Sample field displays a sample derived from the format entered in the Reference String property.

  1. Create an assembly of Vijeo Designer objects on your panel. You can place the objects on a base panel or on a master panel. Define the variable for each object, and configure the object's settings as required.

In the example, the panel comprises switches for the Plant Name and numeric displays for the Station No., Case P, and Disc P. You can create two switches so you can quickly go to Plant A or Plant B. To do this, set up a String operation for each switch, set the Source to "A" for one switch and "B" for the other. Set the Destination to the parameter variable PlantLetter.

The numeric displays for the example are configured as follows:

  1. Station No. –  Select StationNumber in the Variable property, and select Enable Input Mode.

  2. CaseP –  Select RefCaseP in the Variable property, and select Enable Input Mode.

  3. DiscP  –  Select RefDiscP in the Variable property, and select Enable Input Mode.
