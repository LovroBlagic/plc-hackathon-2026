_AirPlus.Connections

DINT variable that indicates the number of Vijeo Design'Air Plus clients connected to the target machine. The maximum connection allowed is 1. For information on disabling a Vijeo Design'Air Plus connection, see Section 6.7.1, System Variable List: AirPlus.DisableConnections.

 

_AirPlus.Connections Value

Connection State

0

No connection.

1

A connection exists.

 

Read/Write Attributes

 

Read From Variable: Unavailable

Write To Variable: Available

System Variable Attribute: Read only

 

 

  • Not all target machines support this feature. For a list of target machines that support controllers, see Appendix 5, Hardware Specifications.
