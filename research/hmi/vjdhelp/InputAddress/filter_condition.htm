6.16.5 Conditional Expressions Used in Filters

It is possible to combine conditions in Vijeo Designer's filters. Refer below to the explanations and examples of the delimiter types and their usage.

  • Conditional expressions are case sensitive.

List of Delimiters in Filter Conditional Expressions

Delimiters

Description

^

For strings starting with ^, variables with names that have their starting portion matching the filter string are retrieved.

For example, when MY is specified as the filter condition, all variables containing MY are retrieved, but when ^MY is specified, only variables that have names starting with MY are retrieved.

$

For strings ending with $, variables with names that have an ending portion matching the filter string are retrieved.

For example, when DISK is specified as the filter condition, all variables containing DISK are retrieved, but when DISK$ is specified, only variables that have names ending with DISK are retrieved.

.

A period in a conditional expression that represents any single character.

For example, when ABC is specified as the filter condition, all variables containing ABC will be retrieved. However, when A.C is specified, AAC, ABC, AZC, and so on, are retrieved.

[ ]

Variables that match a single character that appears within the square brackets are retrieved.

The brackets can include character ranges, which are designated by a hyphen (-) between the first and last characters in the ASCII code range.

For example, when [a-tA-TzZ] is specified, variables with capital and small letters from A to T, and capital and small Z, are retrieved.

( )

Strings specified within parentheses ( ) are considered to be a single character.

For example, ^BA(NA)+$ displays BANA, BANANA, BANANANA, and so on, but filters out BANNA or BANNAAN. The ^ indicates that the variable must begin with BANA. The + indicates that the variable could have one or more number of occurrences of NA. The $ indicates that the  variable name must end with NA.

*

Expressions that match zero, one, or more occurrences of the preceding character or preceding expression in brackets.

For example, Ar*gh matches Agh, Argh, Arrgh, AArrgh, and so on. The expression (AB)*45 matches 45, AB45, xxxAB45, xxxABAB45, and so on.

+

When at least one occurrence of the character immediately before the + (or the String in parentheses) exists, a match is found.

For example, when ABCD is specified as the filter condition, all variables containing ABCD are retrieved, but when AB+CD is specified, variables with names containing ABCD, ABBCD, ABBBCD are retrieved. However, ACD is not retrieved. Also when (AB)+CD is specified, variables with names containing ABCD, ABABCD, ABABABCD, and so on, are retrieved, but ACD, BCD and CD are not retrieved.

?

Variables that match zero or one occurrence of the preceding character or preceding expression in brackets are retrieved.

For example, when ABC is specified as the filter condition, all variables containing ABC will be retrieved, but when AB?C is specified, variables with names containing AC and ABC are retrieved; however, ADC and ABBC are not retrieved.

|

Variable names that match either the expression preceding the pipe character or the expression after the pipe character are retrieved.

For example, DISC|BOOL matches all variable names with the letters DISC or the letters BOOL anywhere in their names.

You cannot include spaces before and after the | character.

[^]

Variables that match any character except the single characters or character ranges that follow the carat symbol ("^") are retrieved.

For example, Mr[^A-Wa-z] matches MrX, MrY, and MrZ, but does not match MrA, Mra, Mr or Mrx.

When ^[^_] is specified, all system variables will no longer be displayed on the variable list, and when ^_ is specified, only system variables are displayed in the variable list.

 

Examples of Frequently Used Filters

Some examples of frequently used filters are shown below.

  • Retrieving variables starting with specific characters

To retrieve variables with names starting with the string ABC, specify ^ABC.

To retrieve system variables (names starting with underscore), specify ^_.

  • Retrieving variables ending with specific characters

To retrieve variables that have names ending with the string XYZ, use XYZ$.

  • Retrieving variables that begin and end with specific characters

To retrieve variables that have names starting with the string ABC and ending with XYZ, use ^ABC.*XYZ$.

  • Retrieving variables with names containing specific numbers

Variable default names begin with the variable type followed by a counter. For example, new integer variables are named Integer1, Integer2, and so on. For a list of these variables, use ^Integer[0-9]+$

  • The above specification does not apply to names with only Integer and no number. If Integer is also to be included in the retrieval, specify ^Integer[0-9]*$.
