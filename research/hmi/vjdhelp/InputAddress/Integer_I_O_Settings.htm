6.2.3.3 Integer I/O Settings Tab

Integer I/O Settings

These settings, Data Format, Signed, DataLength, OffSetBitNo, and BitWidth, are available only if the DataType is an integer type and the Source is External. These properties define the equipment settings for integers.

Data Format

This field defines the data format (BIN or BCD) for reading from and writing to the device address of the equipment.

Signed

This field is only available when the Data Format has been set to BIN.

  • 2's Complement: A number in the base-2 system (binary system) that is the true complement of another number. 2's complements are used to represent negative numbers.

  • MSB: Most Significant Bit. The highest-order bit of a binary number is used to represent negative numbers.

  • Unsigned: Reads the value as a positive integer. If the Data Length is 32 bits, a message box states that only Numeric display part can display 32 bit unsigned range.

Data Length

Three Data Length options are available:

  • 16 bits defines the length of the device address that stores the data.

  • 32 bits defines the length of the device address that stores the data.

  • Bit Field defines specific bits in the word device used by the variable.

  • When you want to reference specific bits in a word address, select Bit Field then specify the bits using OffsetBitNo and BitWidth properties.

  • When you associate the variable with external 32 bit equipment, set the Data Length property to 32 bits.

OffsetBitNo

This property defines the start bit for a specified range of bits.

Use this setting in combination with the BitWidth to work with a single bit or a group of bits in the word device address.

This field is available only when DataLength is Bit Field.

The valid range is 1 to 31, even if you selected Unsigned in the Signed field. You cannot use a 32 bit offset because Java does not support 32 bit unsigned values.

  • OffsetBitNo + BitWidth must be less than 32. If address size is 16 bits, OffsetBitNo + BitWidth must be less than 16.

BitWidth

This property defines the number of bits, starting from the OffsetBitNo, used by the variable.

Use this setting in combination with OffsetBitNo to work with a discrete bit or a group of bits in the word device address.

This field is available only when DataLength is Bit Field.

  • OffsetBitNo + BitWidth must be less than 32. If address size is 16 bits, OffsetBitNo + BitWidth must be less than 16.
