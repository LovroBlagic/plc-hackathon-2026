6.2.4.3 Creating Array Data Types

  1. Open the User Data Types dialog box. See Section 6.2.4.1, Opening the User Data Types Dialog Box.

  2. Click Add Array.

  1. Type a name for the Array.

  2. Select the data type for the Array. The data type can be a basic data type or a user data type, such as a structure or another array.

  3. Enter the dimensions for the array. To create multi-dimensional arrays, enter a comma separated list of dimension sizes. For example, entering 2,3 will create an array with two branches, each with three elements.

  • Select an array and click Modify Array to change the name, type, or dimensions of the array.

  • An array can have a maximum of 2048 elements.

  • When you link a variable or symbol from equipment, it is possible to import and use an array with more than 2048 elements in your project. However, if you try to edit the number of elements in the array using the User Data Types dialog box, the number of elements will be limited to 2048 or less. Therefore, if you need an imported array with more than 2048 elements, do not edit the number of elements after importing.
