6.2.4.2 Creating Structure Data Types

  1. Open the User Data Types dialog box. See Section 6.2.4.1, Opening the User Data Types Dialog Box.

  2. Click Add Structure.

  3. Type a name for the new structure data type.

  4. Click Add Element to add an element to the structure.

  1. Enter a name for the element and select a data type. The data type can be a basic data type or a user data type. Some data types include additional settings. If you select:

  2. String: Define the number of characters the string can store in the Number of Bytes property.

  3. Integer: Define the data format, the data length, the bit offset, the bit width, and whether the Integer is signed or unsigned.

  1. To change the properties of an element, select the element and click Modify Element.

  2. To change the position of an element in the structure, select the element and click Move Up to move the element up the structure's list, or click Move Down to move the element down the list.
