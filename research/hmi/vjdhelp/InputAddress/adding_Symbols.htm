6.3.4.1 Adding Symbols to the Variable List

In order to import symbols, aliases, or variables from equipment configuration software to Vijeo Designer, you must first link the equipment's PLC symbol file to Vijeo Designer and then, using the New Variable From Equipment Dialog Box, select the Symbols to add to Vijeo Designer.

Follow the instructions in the sections below to add symbols to Vijeo Designer.

  • Linking the equipment's PLC symbol file.

  • Adding Symbols and Variables using the New Variables From Equipment Dialog Box.

  • Be aware of how the PLC Symbol file data types are converted into Vijeo Designer data types. For more information on the general rules, Section 6.3.4.2, Data Type Import Rules. For more information on the conversion rules specific to your equipment configuration software's data types, see your equipment configuration software's section below 6.3.4.2, Data Type Import Rules.

  • When importing .STU symbol files, UnityPro must be installed on the same computer as Vijeo Designer.

  • When importing .XVM symbol files, UnityPro does not need to be installed on the same computer as Vijeo Designer.
