_AirPlus.DisableConnections

Boolean variable that controls data sharing access between the Vijeo Design'Air Plus client and the target machine.

 

_AirPlus.DisableConnections Value

Control State

0

Connections are allowed.

1

  • Connections are not allowed.

  • All current connections will be closed.

 

Read/Write Attributes

 

Read From Variable: Available

Write To Variable: Available

System Variable Attribute: Read/Write

 

 

  • Not all target machines support this feature. For a list of target machines that support controllers, see Appendix 5, Hardware Specifications.
