6.2.3.2 Data Details Tab

Data Details Tab

The properties below are detailed settings related to the variable's data.

Initial Value

This field specifies the variable's initial value at Runtime startup. This property only appears when Source is set to Internal.

For variable value ranges, see Section 6.2.1.1, Basic Variable Types.

NumOfBytes

This field is only available when the data type is STRING. NumOfBytes defines the storage length for the string in bytes. NumOfBytes values can be between 2 to 100. Only use even numbers to define string length.

The number of characters the string supports is defined by the NumOfBytes and the driver string encoding.

  • Internal String Variables
    NumOfBytes and the number of characters the String supports are equivalent. For example:
    NumOfBytes = 100
    Maximum number of characters = 100

  • External String Variables
    ANSI and ASCII Encoding    : NumOfBytes and the number of characters the String supports are equivalent. For example:
    NumOfBytes = 100
    Maximum Number of Characters = 100

    Unicode Encoding    : Number of characters the String supports is half the value of NumberOfBytes. For example:
    NumOfBytes = 100
    Maximum Number of Characters = 50

For more information on setting the driver's string encoding, see Section 5.2.4, Setting Up Character Codes.

Retentive

Select Enabled to retain the values of internal variables in the event of a target shut down. The variable values are stored in SRAM and are restored when the target powers up or restarts.

The number of retentive variable values that can be stored are restricted by the amount of available SRAM. In the Target properties, you can check how much SRAM is available or used in the Retentive Variable property under SRAM Usage.

Retentive variable values are deleted every time a project is downloaded. This is because the SRAM is cleared every time a new project is downloaded.

Input Range

This field is available when the DataType is an integer type or REAL. Select Enabled or Disabled.

InputRange restricts data written to the variable from the HMI, and it limits animation, script, and any other data inputs from the HMI display. Data write operations by the equipment are not limited by this function. At Runtime, when you use a keypad/keyboard and you input data out of the Min/Max range, the color of the entered value changes to red. If you are working with a monochrome target machine, the entered value blinks.

  • This field is disabled when using a UDINT (32-bit Unsigned Integer). The editor always defines the range from 0 to 2,147,483,647. However, using a part or a script, it may be possible to assign a negative value to the UDINT. In such cases, Vijeo Designer automatically converts the value to a positive number before storing it in the UDINT.

Min/Max

This field is available when InputRange is Enabled. Min/Max defines the range of values that you can write to the variable from the target machine.

For variable value ranges, see Section 6.2.1.1, Basic Variable Types.

  • The value entered in Max must be greater than the value entered in Min.

Log User Operations on Variable

Select the check box so you can monitor value change events for internal and external variables. For example, this feature is very useful in monitoring changes in recipes.

A system event group must be created for this setting to have an effect at runtime. If a system event group is not created, event logging will not occur.

This property is not available for reference variables.

  • HMIG2U, HMIG3U, HMIGTUX, XBTGC, XBTGT, XBTGH, HMIGTO, HMISTO, HMISTU, HMISCU, XBTGK and HMIGK Series accept up to 500 variables.

  • HMIG5U, HMIG5U2, HMIG5U22, iPC and  XBTGTW Series accept up to 1000 variables.

  • Each target type has a different limitation on the number of variables you can set up with the Log User Operations on Variable option. After changing the target type, if you exceed the maximum number of variables for the particular target type, you will see an error when building the project. This is true if the project exceeds any target-specific limitation.

Logging Group

Assign the variable to a data logging group. A data logging group contains a set of properties that specifies the data collection method and data storage details for a variable. You would create a logging group from the Data Logging node in the Navigator window. For more information, see Section 13.1, About Data Logging.
