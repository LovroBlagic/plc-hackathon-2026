_RemoteViewer.Connections

DINT variable that indicates if a remote connection between the Vijeo Design'Air client and server exists. For more information on disabling a remote connection, see Section 6.7.1, System Variable List: _RemoteViewer.DisableConnections.

 

_RemoteViewer.Connections Value

Connection State

0

No connection.

1

A connection exists.

 

Read/Write Attributes

 

Read From Variable: Unavailable

Write To Variable: Available

System Variable Attribute: Read only

 

  • Not all target machines support this feature. For a list of the target machines that support controllers, see Appendix 5, Hardware Specifications.
