The data type used in configuration tools are imported into the Vijeo Designer data types as shown in the table below. See the notes listed below the table for some general rules on importing. For specific information on how your equipment configuration software's data types are imported into Vijeo Designer data types, see the associated Configuration Tool's section.

  • When linking string symbols that are converted to the String data type, you may need to configure the length of the string in the Vijeo Designer variable properties.

  • Make sure the value used in the equipment does not exceed the data range for a Vijeo Designer variable; otherwise, the variable may display an invalid value. For information about limits for each data type, see Section 6.2.1, Variable Types.

  • Vijeo Designer has a limit on the number of variables it can support. This number depends on the target type. For more information, see Appendix 4, Run-Time Specifications. Some configuration tools can configure more variables than Vijeo Designer can support. Be aware of Vijeo Designer's variable limit when designing your system.

  • For structure variables, if you select the structure's root variable, all the elements in the structure will also be selected. The structure and all its elements will then be created identically in Vijeo Designer. Otherwise, if you select one or more variables in the structure without selecting the root variable, individual variables will be created in Vijeo Designer linked to the specific variables you selected.

  • Vijeo Designer has a limit of 10 layers in its structure variables. Some configuration tools can configure more. Be aware of Vijeo Designer's structure layer limit when designing your system.

  • If you select Variables that combine equipment and name in the Create as property, the variable names can be truncated. This option will generate the variable names like this: EquipmentName_SymbolName. The object name is limited to 32 characters. Therefore, depending on the length of the equipment's name and the symbols' names in the PLC symbol file, some variable names can be truncated.

  • When you import a symbol that uses the IEC 61131 format for device addresses, make sure the driver is configured to match your PLC. If you incorrectly select 0-based addressing for a 1-based address setting, or the other way around, all addresses will be off by 1. To correct the addressing, change your driver to the correct addressing scheme and in the Symbol Import dialog box, click Update Link. For information on the Update Link function, see Section 6.3.4.3, Updating Linked Variables.

  • When you import variables from a CSV file, the Bit Addresses will only be imported when the target contains a single scan group, or when a target contains two or more scan groups and the names of the scan groups match the names of the corresponding scan groups in the CSV file.
