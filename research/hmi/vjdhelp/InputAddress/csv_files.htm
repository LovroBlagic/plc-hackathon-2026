6.6 Copying Variables Between Projects

The variable database supports the following file formats for importing and exporting variables:

  • XML Files (*.xml)

  • ANSI CSV Files (*.csv)

  • Unicode CSV Files (*.csv)

  • ANSI TXT Files (any delimiter) (*.txt)

  • Unicode TXT Files (any delimiter) (*.txt)

You would export and import variables if you need to:

  • Back up variable data

  • Share variables from one project to another

  • Alarm actions cannot be exported and imported in CSV file format.

  • If you are using Microsoft Excel to edit an exported *.txt file, we recommend using Excel's Text Import Wizard to import the *.txt file into Excel. By using the Text Import Wizard, you can specify the *.txt file's field delimiter and set how the data is organized in Excel. Be aware that once you Save the edited (*.txt) file in Excel, the *.txt file's field delimiter is replaced with the Tab delimiter. When you import the edited *.txt file back into a project, specify that the *.txt file uses the Tab as a field delimiter.

  • When importing or exporting .csv or .txt files between operating systems with different languages, select Unicode CSV Files or Unicode TXT Files as the file type.

6.6.1 Exporting Variables

  1. Right-click the Variables node and select Export Variables.

  • User Data Type information is not exported with variables. If User Data Types are used, you must export both the User DDT file and the variable files. For more information, see Section 6.2.4.5, Importing and Exporting User Data Types.

  1. In the Export Variables dialog box, select the destination, type the name for the file, and specify the file type.

When exporting, you can save the variable file in one of four different file type formats:

  1. Unicode XML (*.XML)—saves the file as an Unicode XML file.

  2. ANSI CSV Files (*.csv)—saves the file as an ANSI CSV comma-separated or semi-colon value file.

  3. Unicode CSV Files (*.csv)—saves the file as an Unicode CSV comma-separated or semi-colon value file.

  4. ANSI TXT Files (any delimiter) (*.txt)—saves the file as an ANSI TXT file. Specify the file's field delimiter from the Field Delimiter drop-down list.

  5. Unicode TXT Files (any delimiter) (*.txt)—saves the file as an Unicode TXT file. Specify the file's field delimiter from the Field Delimiter drop-down list.

  1. Select either Comma (,) or Semi-Colon (;) in the Field Delimiter property.

  1. When exporting variables to a CSV file, you cannot use a delimiter that is the same as a decimal symbol. For example, when French is set as the regional/language option and the comma is used as a decimal symbol, you cannot export variables with a Comma delimiter.  You must select the Semi-Colon delimiter. When English is set as the regional/language option, you must use the Comma delimiter.

  1. Click Save.

6.6.2 Importing Variables

  1. Right-click the Variables node and click Import Variables.

  1. If User Data Types are used, you must import the User DDT file prior to the variable import. For more information, see Section 6.2.4.5, Importing and Exporting User Data Types.

  1. In the Import Variables dialog box, select the file to import and specify the import options:

Options:

File Types:

    • Unicode XML (*.XML) imports the file as an Unicode XML file.

    • CSV Files (Comma delimited) (*.csv)—imports the variable file as a comma-separated or semi-colon value file.

    • TXT Files (Any delimiter) (*.txt)—imports the variable file as a text file. Specify the field delimiter the .txt file uses in the Field Delimiter drop-down list.

Field Delimiter:

    • Comma (,)

    • Semi-Colon(;)

When importing:

    • Do not overwrite existing variables—Variables from the import file are not imported if a variable with the same name exists in the project.

    • Overwrite existing variables—Variables from the import file will import and overwrite any variables with the same name in the project.

    • Allow Unassigned Scan Groups—The following table describes the different scenarios when this feature is disabled and enabled:

    • Do not import Alarm Messages—When cleared, variable alarm messages are imported. When checked, variable alarm messages are not imported.

  1. When importing variables from a CSV file, you cannot use a delimiter that is the same as a decimal symbol. For example, when French is set as the regional/language option and the comma is used as a decimal symbol, you cannot import variables with a Comma delimiter. You must select the Semi-Colon delimiter. When English is set as the regional/language option, you must use the Comma delimiter.

  1. Click Open to import the variables.

After the process completes, a message box opens to inform you of the number of imported variables.
