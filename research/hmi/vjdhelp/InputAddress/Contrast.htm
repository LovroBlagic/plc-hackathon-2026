_Contrast

Integer variable that stores the value of the target's contrast level. You can adjust the target's contrast level by writing to this variable. _Contrast's input range corresponds to the target's supported contrast levels. Any value written to the _Contrast system variable that is outside the variable's input range is ignored. See Appendix 5.3, Brightness and Contrast Levels Supported by Hardware Platforms.

 

Read/Write Attributes

 

Read From Variable: Available

Write To Variable: Available
