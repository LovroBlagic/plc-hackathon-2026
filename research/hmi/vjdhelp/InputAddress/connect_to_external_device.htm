6.3 Connecting to Equipment

6.3.1 Creating Device Addresses

For equipment to communicate with a target machine, you must set up a device driver and specify device addresses. Follow the steps below to set up device addresses in the target machine.

Steps

1. Add the device driver. See Section 5.2.1, Adding a Device Driver.

2. Create a variable.

3. Set the variable's source to external.

4. Set the target machine's device address.
