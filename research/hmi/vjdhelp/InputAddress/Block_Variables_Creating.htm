6.9.1 Creating Block Variables

Creating block variables is very similar to creating any other type of variable.

  1. Right-click the Variable's node, select New Variable, and click either Block INT, Block UINT, Block DINT, Block Integer, or Block REAL.

  1. Define the variable properties. See Section 6.2.3, Variable Properties.

Note the following properties used distinctly to block variables.

Block Elements: Defines the number of elements in the block. Each element stores an integer or real value.

  • The Block Elements and DataType define the size of the block.
    Each element in a Block REAL variable is 32 bits: the block size is Block Elements  x 32 bits.
    Each element in a Block INT or Block UINT  variable is 16 bits: the block size is Block Elements  x 16 bits.
    Each element in a Block DINT variable is 32 bits: the block size is Block Elements  x 32 bits.
    The size of each element in a Block Integer variable is defined by the DataLength property: the block size is Block Elements x DataLength.

Start Address: Defines the first device address in the block.

  • The maximum number of Block Elements is 1024.
