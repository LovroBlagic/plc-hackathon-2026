_UserLevel

Integer variable storing the value of the logged in user's security level. During the situations when a user is not logged into a target, the integer will store the following values:

 

Situation

_UserLevel Value

Runtime starts up to unsecured panel

-1

User logs out using a logout part or script

0

User is logged out by inactivity time-out

-1

 

For more information on Security, see Section 4.8, Setting up Security Protection for Targets and Projects.

Read From Variable: Unavailable

Write To Variable: Available

System Variable Attribute: Read only
