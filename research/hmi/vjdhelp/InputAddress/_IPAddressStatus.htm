_IPAddressStatus and _IPAddress2Status

BOOL variable that identifies the status of the new IP Addresses after run time executes the Set IP Address operation. This variable is automatically added when the Set IP Address at Run Time property is Enabled and is automatically removed when the Set IP Address at Run Time property is Disabled. For more information on the Set IP Address operation, see Section 9.5.25, Set IP Address.

The _IPAddressStatus system variable indicates the command execution status for Ethernet 1 and is supported for a single LAN target model. The _IPAddress2Status system variable indicates the command execution status for Ethernet 2 and is supported for a dual LAN target model. To obtain a list of target machines that support dual LAN ports, see Appendix 5, Hardware Specifications.

_IPAddressStatus Value

Status Description

TRUE

Address is valid.

FALSE

Address is in an invalid format or is blank.

FALSE

Address is out of range for the class.

FALSE

Address is duplicated.

FALSE

No network connection.

FALSE

DHCP is set to Enabled.
