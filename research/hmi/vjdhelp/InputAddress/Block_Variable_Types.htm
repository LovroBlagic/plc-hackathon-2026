6.2.1.3 Block Variable Types

Block INT, Block DINT, Block UINT, Block Integer

The block variable, available for use in recipes, scripts, block trend graphs and XY graphs only, is a single variable that is associated with multiple device addresses.

Using block variables streamlines communication as data from multiple device addresses is loaded into a single packet.

 

  • The block variable counts as one variable even though it's associated with multiple device addresses.

  • After working with block variable values on the target machine, you need to use the sendData method for scripts and the Send command for recipes, to update block values on the equipment. For more information about block variables, see Section 6.9, Block Variables.

  • Use the Block Integer type that best matches your data requirement. The generic Block Integer variable should only be used for compatibility with older projects.
