Adding Symbols to the Variable List

You can use the New Variables From Equipment dialog box to add linked symbols, aliases, and variables to Vijeo Designer. Once the symbols, aliases, and variables are added they become external variables.

The New Variables From Equipment Dialog Box is accessible when:

  • An equipment's symbol file is successfully linked

  • You are working with SoMachine and you have published your variables

There are a few ways to access the New Variables From Equipment dialog box:

  • Right-click the Variables node and click New Variables From Equipment

  • Click the New Variables From Equipment icon in the Variable Editor

  • Click the New Variables From Equipment icon in the Expression Editor Pad

To add linked symbols, aliases, and variables to Vijeo Designer using the New Variable From Equipment dialog box:

  1. In the New Variables From Equipment dialog box, define the following properties in the dialog box.

 

Dialog Item

Description

Equipment

This drop-down list displays the equipment linked to a PLC configuration file or SoMachine equipment.

Select the equipment to display its list of available symbols, aliases, and variables.

Linked File

This field displays the path and file name of the PLC symbol file. If the file cannot be found, this field displays the path and filename in red.

Click the Update button when the PLC symbol file has changed, from either the time you linked the file, or the last time you updated the file. After you update, the list of symbols are refreshed to reflect the data in the PLC symbol file.

  • This field is unavailable when SoMachine equipment is selected. SoMachine automatically updates the variables in Vijeo Designer each time you make a change to the variable in SoMachine.

Displays all bool, real, integer, and string data types.

Displays bool data types.

Display real data types.

Display integer data types.

Display string data types.

Filtered by

Use this field to show the symbols, aliases, or variables that start with the characters defined in the filter. Filters are applied to the column you select.

For example, if the Name column is selected and Filtered by = Hi*, then the symbols, aliases, or variables whose names start with Hi* display. If the Address column is selected, the filter applies to the addresses.

When adding variables:

Create as

Elements in equipment folder: Creates elements in a single folder for each selected check box item.

Variables that combine equipment and name: Creates a variable for each selected check box item. The new variable is named by combining the equipment name and the selected check box item's name.

Variables that keep the same name: Creates a variable for each selected check box item. The new variable uses the same name as the selected check box item's name.

Variable named: Creates a single variable using the name defined in this field. This field is unavailable when multiple symbols are selected. You cannot use Vijeo Designer reserved words for the names of variables.

  • Importing linked variables fails if  you use Vijeo Designer reserved words for the names of variables.

  • If a variable with the same name already exists, when you click Add the name of the new variable is slightly modified to avoid conflicts.

  • After adding the variable, you can rename the variable and still retain the link to the symbol, alias, or variable.

Add to Scan Group

This drop-down list displays the scan groups defined for the equipment you selected in the Equipment drop-down list. Select the scan group you want associated with the symbol, alias, or variable.

  • The scan group defines how often PLC equipment is scanned for data changes. If you assign many symbols (over 1000) to a fast scan group, it could slow operations on the target machine.

Add

This button adds the selected items to the list of available variables.
