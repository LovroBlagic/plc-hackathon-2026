_ControllerLockout

The BOOL variable _ControllerLockout locks and unlocks the controller’s stop mode. A locked controller cannot restart until the controller is unlocked. Attempts to restart a locked controller are ignored and an error message appears. This feature is important to prevent injury resulting from unintended startup of the system. For more information, see the Safety Interlock danger message in Safety Precautions.

You can only initiate lockout once the controller stops. If the controller is running and you attempt lockout, the attempt is ignored and an error message appears. For more information on stopping and starting the controller, see Section 4.13.3, Controller Operations: Start/Stop/Lock.

You can check the controller's state (running, stopped, locked, etc) by reading the value of the system variable _ControllerStatus. For more information, see Section 6.7.1, System Variable List: _ControllerStatus.

 

_ControllerLockout Value

Controller State

0

Controller is unlocked and can start.

1

Controller is locked.

 

Read/Write Attributes

 

Read From Variable: Unavailable

Write To Variable: Unavailable

System Variable Attribute: Unavailable

 

  • Downloading to a target with a locked controller does not reset the lockout. Once download completes, the target's controller is still locked out.

  • Target machines set up with a controller support this feature. For a list of the target machines that support controllers, see Appendix 5, Hardware Specifications.
