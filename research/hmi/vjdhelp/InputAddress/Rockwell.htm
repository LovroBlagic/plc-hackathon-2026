Be aware of the following information when linking Rockwell variables:

  • You must have .NET 1.1 installed in order to link the Rockwell variables.

  • Only L5K files generated by RSLogix 5000 v13, v15, v16, v17, v18, v19, and v20 can be imported into Vijeo Designer. You cannot import tags defined in add-on instructions.

  • Variable names in Vijeo Designer are limited to 32 characters. Rockwell variable names that have more than 32 characters will be truncated.

  • Colons (:) used in module-defined tag names are converted to an underscore character (_) for the associated Vijeo Designer variable name.

  • Rockwell L5K user-defined structures (UDS), pre-defined structures (PDS), and module-defined structures (MDS) are converted to Vijeo Designer user data type definitions.

  • Vijeo Designer limits the number of variables and user data type definitions in each user application. Be aware of these limits when defining variables for use with Vijeo Designer. For information on the number of variables and user data type definitions on a single target machine, see Section 6.1, About Variables and Device Addresses, and Section 6.2.4, Creating User Data Types.

  • 64-bit Rockwell data types LINT and LREAL are converted to 32-bit data types in Vijeo Designer. Please avoid values that exceed the data range of Vijeo Designer data types.

  • You cannot add the following predefined elements as variables to Vijeo Designer, because they contain Vijeo Designer reserved words:

  • CC.E and IMC.E (where E is a reserved word)

  • MANUAL_VALVE_CONTROL.Bottom (where Bottom is a reserved word)
