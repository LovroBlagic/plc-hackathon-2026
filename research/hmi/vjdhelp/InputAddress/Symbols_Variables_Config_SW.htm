6.3.4 Importing Aliases, Symbols, and Variables From Equipment Configuration Software

Vijeo Designer can link the names and device addresses of aliases, symbols, and variables set up in equipment configuration software to Vijeo Designer variables. By linking to the equipment's PLC symbol files, you do not have to type the same name in two different tools.

This feature saves you time not only when you first implement your system, but also during maintenance. Whenever you make a change to the equipment configuration, you can update Vijeo Designer with the same information.

In order to import symbols, aliases, or variables from equipment configuration software to Vijeo Designer, you must first link the equipment's PLC symbol file to Vijeo Designer and then, using the New Variable From Equipment Dialog Box, select the Symbols to add to Vijeo Designer. See Section 6.3.4.1, Adding Symbols to the Variable List for more information.

  • The following instructions use the word symbols to represent the different terms (aliases, symbols, variables, and so on) used by different equipment configuration software for named register locations.

  • Instead of importing symbols, to link Hot Standby PLC (M580) information, you can enable M580 Redundant CPU Variables. For more information, see Modbus TCP/IP Driver manual.
