6.11 Recipe Variables

When working with recipes, there are two types of variables:

  • Recipe Control and Parison Control variables: Run recipe operations such as selecting recipes and sending recipe values. Also store error and status values that result from recipe operations.

  • Ingredient variables: Represent ingredients in a recipe. Each ingredient variable stores the value for its associated ingredient.

Ingredient Variables

When you add an ingredient to a recipe you specify a variable, which generates two copies of the variable. In the above diagram, DINT01 is below the Target node, and another copy is below the RecipeGroup1 folder variable. The data source for the copy in the RecipeGroup1 folder is Internal.

At runtime, because RecipeGroup1.DINT01 is internal, it does not update as part of the normal scan process for external variable values.

When the value on the equipment (address 40601) changes, the value in DINT01 also changes. RecipeGroup1.DINT01 does not change.

Because ingredient variables are internal, you can manipulate recipes and recipe groups without affecting the current recipe process. Only until you specify a recipe command (via the recipe control variables) will data be synchronized between the ingredient variables and on the equipment.

 

Snapshot updates the ingredient variables (ReciptGroup1.DINT01) with values from the equipment.

Send writes the ingredient variables to the equipment.
