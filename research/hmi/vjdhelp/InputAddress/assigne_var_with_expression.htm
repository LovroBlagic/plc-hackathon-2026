6.14 Assigning Variables Using Expressions

6.14.1 What are Expressions?

Expressions are equations, similar to scripts, that allow you to use variables easily. You can create expressions anywhere the icon is displayed. The following example shows expressions typed in the Animation dialog box.

You can enter multiple variables into a single expression, as long as their resulting data types are the same.

Expressions enable you to use variables with mathematical and conditional operators. Mathematical expressions are used to calculate numerical values such as TankLevel + 60. Conditional expressions are used to compare numerical values such as TankLevel > 30.

 

6.14.2 Entering Expressions

  1. In the expression field, click to display the Expression Editor Pad.

To display a keypad and enter expressions, click .

 

The expression editor operates in the same way as a calculator. Enter an expression using the keypad, math function list, and variable list. The expression displays in the Expression box. If the expression is invalid, it displays in red. If the expression is valid, it displays in black. For examples of expressions, see the remainder of this chapter.

  1. Click OK to display the expression you typed in the Animation dialog box.

  • In the Animation Properties dialog box, expressions cannot exceed 225 characters (not including spaces).

  • You can enter single expression only. Plus, you do not need a semicolon [ ; ] at the end of the expression.

  • If there is an error in the expression, the expression displays in red.

  • You cannot enter conditional expressions into Value Range and Display Range fields. Use mathematical expressions.

  • In the Touch animation Condition Setting dialog box, use conditional expressions only.

  • When you use a large array in expressions, it may slow some operations such as change panel and animations.

  • Use string variables in string expressions only. Mathematical and conditional expressions do not support string variables.

6.14.3 Rules for Expressions

Operators

Scripts and expressions are different. For example, you cannot use just any Script operator in expressions. Only the following operators are supported:

  • Mathematical operators

+

-

*

/

(

)

&

|

  • Conditional operators

! =

<

<=

>

>=

==

&&

||

!

(

)

  • Bit shift operators

<<

>>

>>>

 

For information about how each of these operators work, see Section 18.3.5, Operators.

Data Type

If the data types are identical, you can use multiple variables in one expression. The following is an example of a valid expression, where the two variables are of the same DINT data type:

  • MyDINT01 + MyDINT02

The following is an example of an invalid expression, where the two variables are of data types DINT and STRING respectively:

  • MyDINT01 + MyString01

When expressions are displayed in red, it means that there is an error in the expression. Variables with different types will not work in an expression.

6.14.4 Using Arrays in Expressions

When specifying array elements, you can enter element numbers such as Tank[5] and Tank[13].
If you use script methods, you can also use variables to specify the array element, as in Tank[MyInteger.getIntValue() + 10].

For example, if you want to change the reference to an array element depending on the amount of water in the tank, use an expression in the Animation Properties dialog box.

  1. Display the Animation Properties dialog box.

  2. Type the array variable Tank[ ] then use the variable water to specify the array element, Tank[water.getIntValue( )]

  • The above example describes how to indirectly access elements in Vijeo Designer variable arrays. Be careful when using this method to define array elements, especially when there are many elements in the Vijeo Designer variable array.

For example, when Tank has 200 elements and you use the above expression, all 200 elements in the array must be loaded into memory. The amount of space required is the same as if 200 individual variables were loaded into memory.

To avoid this memory problem, use a constant to define the array element: Tank[10]

  • Array variable elements cannot be used to define other array variable elements. For example, the following expression would fail validation: Tank[Array[1].getIntValue()]

6.14.5 Using Structure, Folder, and Recipe Variables in Expressions

In folder and recipe variables, the topmost node is a folder that organizes variables for easy viewing and referencing.

When specifying elements of structure, folder and recipe variables, type the node and variable name, for example:

  • RecipeGroup1.BOOL01

  • Folder01.STRING01

  • Structure101.REAL01
