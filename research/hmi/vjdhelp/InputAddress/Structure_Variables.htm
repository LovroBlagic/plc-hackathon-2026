6.12 Structure Variables

A structure is a variable that holds a collection of other variables. Each variable in a structure is called an element. An element can be of any data type except a folder. A structure cannot contain a folder while a folder can contain a structure. For information on the differences between a structure and a folder, see section 3.4, Upgrading Vijeo Designer Projects.

You can create a nested structure by adding another structure or an array as an element. You can have a maximum of 10 layers in a nested structure. Each layer can have a maximum of 2048 elements.

A structure's data source and scan group property determines the data source and scan group settings for all the elements in the structure.

  • A target can have a maximum of 8000 or 12000 variables, depending on the target type. For more information, see Appendix 4, Run-Time Specifications. Array, structure, and folder holders (the group node) also count as variables. A block variable counts as 1 variable.

  • To link Hot Standby PLC (M580) information in your project, enable M580 Redundant CPU Variables instead of creating structure variables. For more information, see Modbus TCP/IP Driver manual.

6.12.1 Creating Structure Variables

  1. Create a structure data type using the steps described in Section 6.2.4.2, Creating Structure Data Types.

  2. Select the newly created structure data type in one of the following ways:

  3. Right-click the Variable node and select New Variable, select User Data Types, and then select the structure to base the variable on.

  • In the variable spreadsheet, select the drop down arrow beside the icon, select User Data Types, and then select the structure to base the variable on.

  1. Set the structure's Data Source and ScanGroup properties. For more information, see Section 6.5.5, Editing Variables.

  • The maximum length for the name of the structure and its elements is 32 characters each. For arrays, this character count includes the array variable name and element name. The character count does not include symbols that designate elements. For example, the character count for MyArray[3] is 7 characters.
