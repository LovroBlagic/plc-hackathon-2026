6.2 Setting Up Variables

6.2.1 Variable Types

There are three groups of variable types: basic variables, user data type variables, and block variables. Basic variables include BOOL, INT, UINT, DINT, UDINT, Integer, REAL, and STRING variables. User data type variables are variables that contain collections of other variables. They include Array, Structure, and folder variables. Block variables are used to write to multiple device addresses in a single step. They include Block INT, Block UINT, Block DINT, Block Integer, and Block REAL.

REAL

Stores a numeric value, either from -3.4028e+038 to -1.1754e-038, 0 and 1.1754e-038 to 3.4028e+038.

Because real variables can hold larger values than integer types, use reals to store calculations, constants, and so on, when data precision is not an issue. If data precision is necessary, use an integer type.

Although real values can store large values, its precision is limited to seven digits. For example, in the value 1.2345678, only the first seven digits (1.234567) are guaranteed. Any digits after the first seven are calculated approximations only.

At runtime, processing a real takes more time than processing an integer type variable.

  • Be careful when using real variables in mathematical expressions. For example, a value stored in a real variable as 0.1 is actually 0.1000000014901161. Because the precision of real variables cannot be confirmed beyond seven decimal places, do not use real variables in comparison operations.

  • To denote the decimal point, Vijeo Designer accepts only the period [ . ]. Other methods of denoting the decimal point, such as the comma [ , ] used in many European countries, are not accepted.

  • When using external REAL variables, make sure that the "Double Word word order" setting in the Equipment Configuration dialog box matches the setting in the equipment. If the settings do not match, the values of the external REAL variables will not display properly.

STRING

Stores from 2 to 100 characters.

You can define the number of characters the string can store in the NumOfBytes property.

  • NumOfBytes accepts even numbers only.
