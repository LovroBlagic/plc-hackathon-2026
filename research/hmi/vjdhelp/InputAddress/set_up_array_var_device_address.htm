6.8.2 Setting Up Device Addresses in Arrays

Elements in an array have the same data type and data source as the array's parent variable. You can assign different device addresses to individual elements in an array using the following steps.

  1. In the array's parent variable, set the Source to External.

  1. Right-click the parent variable, and select Configure Device Address. The Configure Device Address dialog box opens.

  1. Select the scan group. See Section 6.3.2, Dividing Variables into Scan Groups.

  2. Click the Base Device Address's ellipse to display the device address keypad. Enter the device address into the keypad, and press OK.

  3. If the device addresses of the array elements grow consecutively by the defined number of bits, select the Increase Device Address By check box and specify the additional width.

  4. If the device addresses of a BOOL array element is set to increase by 1, then the device address increases by 1.

  5. If the device addresses of an Integer array element is set to increase by 1, then the device address increases by the variables' data length. For INT and UINT, the device address increases by 16 bits. For DINT and UDINT, the device address increases by 32 bits. You cannot increase device addresses if the integer's data length is set to bit field.

  6. If the device addresses of a REAL array element is set to increase by 1, then the device address increases by 32 bits.

  7. If the device addresses of a STRING array element is increased by 1, then the device address increases by the byte count that is defined in NumOfBytes field in the array's parent variable.

  1. Click OK.
