6.7.2 Using Date and Time System Variables

The date and time system variables are based on Greenwich Mean Time (GMT) offset by the target's Time Zone and Time Adjustment (Daylight Saving Time) settings. Although the values you can store in _Year4 is 2000 to 2037 GMT, the valid values for the year depends on your Time Zone. If you live in North America, the year can be 1999 to 2037. If you live in Asia the year can be 2000 to 2038.

The valid date and time range is January 1, 2000, 0:00:00 GMT to December 31, 2037, 23:59:59 GMT. That means if you live in Hawaii where the Time Zone is GMT -10:00, the valid date and time range is December 31, 1999, 14:00:00 to December 31, 2037, 13:59:59. If you live in New Delhi where the Time Zone is GMT +5:30, the valid date and time range is January 1, 2000  5:30:00 to January 1, 2038, 5:29:59. For information on setting the Time Zone, see Section 4.5.3, Displaying Data Using Time Zone and Configuring Daylight Saving Time.

You can use the time zone offset variable to configure the local time in the target. An example of using this variable is if an operator in Toronto is looking at alarm records generated in Vancouver. The target used by the operator in Toronto has a time offset of GMT -300 minutes, while the target used by the operator in Vancouver has a time offset of GMT -480 minutes. The time zone offset configuration for the target allows the operator in Toronto to see the local time stamp of when the alarm record was generated, not the Vancouver time stamp. For more information on how to set up the time zone in the configuration menu, see Section 26.4.2, Setting Up the Date/Time.

  • The _TimeZoneOffset system variable does not take into account the Daylight Saving Time settings of the target machine.
