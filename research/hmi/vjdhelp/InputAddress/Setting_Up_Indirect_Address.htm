6.3.3.1 Setting Up an Indirect Address

Not all drivers support indirect addresses. See Section 6.3.3, Dynamically Referencing Device Addresses.

To set up a variable for indirect addressing:

  1. Create a variable and set its source to External. See Section 6.2.2, Creating Variables.

  1. In the Variable Properties dialog box, enable Indirect Address.

  1. Define a variable to use as the offset in the Indirect Address field.
