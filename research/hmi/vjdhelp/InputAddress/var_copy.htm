6.5 Selecting, Copying, Deleting, and Editing Variables

Vijeo-Designer allows you to select, copy, delete, and edit variables individually or in groups.

6.5.1 Selecting Variables

Users have three choices for selecting variables:

  • Individually: Click on a variable's row to select individual variables.

  • Selectively: Hold down the CTRL key and click individual rows to select a group of discontinuous variables.

  • Consecutively: Select the first row for your group of consecutive variables, hold down the SHIFT key and click the last row.

6.5.2 Copying Variables

Use any of the variable selection methods (individually, selectively, and consecutively) to select the variables you want to copy.

  1. After you select the variables you want to copy, right-click the selected variables and select Copy.

  1. Right-click the destination Variables node, and select Paste. The selected variables will be pasted into the new target.

  • When copying variables within the same target, numbers are appended to the variable name. For example, when copying and pasting a variable called Temperature, a variable by the name of Temperature01 is created.

  • When pasting variables onto a different target and the variables are set up with device addresses, the destination target must be set up with drivers, equipment, and scan groups with the same names as those referenced by the variables.

  • You cannot select or copy an element within an array or structure. You cannot paste a copied array into an array or structure.
