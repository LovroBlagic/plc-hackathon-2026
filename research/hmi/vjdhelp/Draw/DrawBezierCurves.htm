7.2.5 Drawing Bezier Curves

A Bezier curve is defined by four points—two nodes (the start point and end point) and two control points that determine the curve of a segment by its varying angle and distance from a node.

Typically, a node has one gravity control point for each adjacent segment. Therefore, because a Bezier Curve contains only one segment between the start point node and the end point node, it contains only two gravity control points—one for each node.

  1. Click the Bezier Curve icon in the graphical objects toolbar.

  1. Click the panel to set the Bezier curve's start point.

  1. Click the panel a second and third time to set the two gravity points.

  1. Click the panel a fourth time to set the end point. Continue clicking on the panel to place as many Bezier Curves as needed.

  1. Right-click the panel to exit the drawing mode. The last object drawn will become selected.

  2. Modify the attributes of this Bezier Curve in the Property Inspector.

The following table describes the Bezier Curve's properties.

Property

Description

Name

The object's name.

Whenever an object is created, a default name is generated. When renaming an object, its name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

For details, see Appendix 9, Naming Conventions.

Top

The coordinates, in pixels, of the top-left corner of the object.

  • Top is measured from the top of the object to the top of the panel. Enter a value from -32768 to (32767 - object height).

  • Left is measured from the left side of the object to the left side of the panel. Enter a value from -32768 to (32767 - object width).

By changing these properties, the graphical object can be moved up, down, left, and right.

The width of the object's line, from 1 to 9 pixels when the LineStyle property is set to either Solid or Invisible. Must be set to a 1-pixel width when LineStyle is set to a pattern other than Solid or Invisible.

Animation

The ellipsis button opens the Animation Properties dialog box, where you can apply animation to the object.

For details, see Chapter 8, Animating Graphics.

  • The settings you make to a tab in the animation dialog box are applied once you change tabs. The Cancel operation only works for the animation tab that you are currently in.

Save Defaults

The forward-arrow button saves the current property settings as the new default property settings.

Restore Defaults

The back-arrow button restores the original default property settings.

Placeholder

You can assign a placeholder in any property that requires a variable definition. Click the ellipsis to open the Placeholders dialog box and edit the variable placeholder for the object. The dialog box only displays if you had set up a placeholder for the object. For more information on placeholders, see Section 21.2.4, Working with Variable Placeholders.

 

Editing a Bezier Curve

  1. Click the Bezier Curve to display its selection box and eight handles—one handle at the top, bottom, both sides, and at each corner.

  1. Hover the Select tool over the Bezier Curve to display a crossed double arrow , then click the Bezier Curve a second time to display its four nodes—the start point, end point, and two gravity control points. When you hover the Select tool over any one of these four nodes on the Bezier Curve, the crossed double-arrow changes to a + sign.

  1. Click one of the four nodes on the Bezier Curve and drag to adjust the curve of that segment.

  1. Click the panel to set the change.
