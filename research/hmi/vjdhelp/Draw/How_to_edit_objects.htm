7.4 Editing Graphical Objects

After creating and displaying Graphical Objects on the panel, you can use various methods of editing—with the menu items, the toolbar icons, or the right-click menu items—to select, move, manipulate, and arrange these objects.

For details on the various methods of editing graphical objects, see the section that corresponds to that method:

  • 7.4.1 Selecting Graphical Objects

  • 7.4.2 Refining Selections

  • 7.4.3 Resizing Objects

  • 7.4.4 Cutting/Copying/Pasting/Deleting Objects

  • 7.4.5 Duplicating Objects

  • 7.4.6 Grouping/Ungrouping Objects

  • 7.4.7 Arranging the Order of Objects

  • 7.4.8 Rotating/Flipping Objects

  • 7.4.9 Aligning Objects

You can also edit the properties of each object in the Property Inspector. When selected, an object's properties will display in the Property Inspector.
