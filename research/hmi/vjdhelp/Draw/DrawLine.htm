7.2.2 Drawing Lines

  1. Click the Line icon in the Graphical Objects toolbar.

    If you are drawing for target machines (i.e., not tablets or smartphones), you can click the Line dropdown arrow to select one of the following styles from the Line list.

  2. Normal Line: Line with no arrow at either end.

  3. Start Direction Line: Line with an arrow at its start point.

  4. End Direction Line: Line with an arrow at its end point.

  5. Bi-Directional Line: Line with an arrow at both ends.

If you want, you can change your selection in the Direction field of the line properties.

  1. Click the panel to set the line's start point. Continue clicking on the panel to place as many lines as needed.

Pressing the CTRL key while moving the Line tool will draw a line at a 0-, 45-, or 90-degree angle.

  1. Right-click the panel to exit the drawing mode. The last object drawn will become selected.

  2. Modify the attributes of this line in the Property Inspector.

The following table describes the Line's properties.

Property

Description

Name

The object's name.

Whenever an object is created, a default name is generated. When renaming an object, its name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

For details, see Appendix 9, Naming Conventions.

Top

The coordinates, in pixels, of the top-left corner of the object.

  • Top is measured from the top of the object to the top of the panel. Enter a value from -32768 to (32767 - object height).

  • Left is measured from the left side of the object to the left side of the panel. Enter a value from -32768 to (32767 - object width).

By changing these properties, the graphical object can be moved up, down, left, and right.

Left

Width

The object's width and height can be set from 1 to 3000 pixels.

Height

Back Color

The object's background and line colors.

LineColor is the color of the object itself, and BackColor is the color of the object's background layer when the LineStyle property is set up with a pattern other than Solid or Invisible. When the LineStyle property is set to either Solid or Invisible, the color of the object's background layer will not be displayed.

For more information, see Sections 7.3.1, Color Palette, 7.3.2, RGB Values, and 7.3.3, Previewing Colors for Target Machines.

Line Color

HW Back Blink

The object's BackColor and LineColor blink speeds. The default setting is [No] for no blink, or [Fast], [Medium], or [Slow] to set the property's blink speed.

These properties are displayed only when the TargetColor property is set to blink.

For details about the blink feature, see Section 7.3.4, Blink Feature.

HW Line Blink

Line Style

The object's line style.

Line Width

The width of the object's line, from 1 to 9 pixels when the LineStyle property is set to either Solid or Invisible. Must be set to a 1-pixel width when LineStyle is set to a pattern other than Solid or Invisible.

Direction

The location of the object's arrow head. The default setting is [None] for no arrow head, or [Start], [End], or [Both] to set the direction of the object's arrow head.

Animation

The ellipsis button opens the Animation Properties dialog box, where you can apply animation to the object.

For details, see Chapter 8, Animating Graphics.

  • The settings you make to a tab in the animation dialog box are applied once you change tabs. The Cancel operation only works for the animation tab that you are currently in.

Save Defaults

The forward-arrow button saves the current property settings as the new default property settings.

Restore Defaults

The back-arrow button restores the original default property settings.

Placeholder

You can assign a placeholder in any property that requires a variable definition. Click the ellipsis to open the Placeholders dialog box and edit the variable placeholder for the object. The dialog box only displays if you had set up a placeholder for the object. For more information on placeholders, see Section 21.2.4, Working with Variable Placeholders.
