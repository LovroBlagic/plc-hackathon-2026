7.2.6 Drawing Rectangles

  1. Click the Rectangle icon in the graphical objects toolbar, then click the Rectangle arrow to select one of the following styles from the Rectangle list.

  2. Rectangle: Normal rectangle shape.

  3. Round Rectangle: Rectangle shape with rounded corners.

  4. Cut Cornered Rectangle: Rectangle shape with straight-edged diagonal corners.

The roundness of the corners' angles can be defined in the Corner Property.

  1. Click the panel to set the rectangle's start point. Continue clicking on the panel to place as many rectangles as needed.

Pressing the CTRL key while moving the Rectangle tool will draw a square.

  1. Right-click the panel to exit the drawing mode. The last object drawn will become selected.

  2. Modify the attributes of this rectangle in the Property Inspector.

The following table describes the Rectangle's properties.

Property

Description

Name

The object's name.

Whenever an object is created, a default name is generated. When renaming an object, its name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

For details, see Appendix 9, Naming Conventions.

Top

The coordinates, in pixels, of the top-left corner of the object.

  • Top is measured from the top of the object to the top of the panel. Enter a value from -32768 to (32767 - object height).

  • Left is measured from the left side of the object to the left side of the panel. Enter a value from -32768 to (32767 - object width).

By changing these properties, the graphical object can be moved up, down, left, and right.

Left

Width

The object's width and height can be set from 1 to 3000 pixels.

Height

Fore Color

The object's foreground, background, and (border) line colors.

ForeColor is the color of the object's filled foreground.

LineColor is the color of the object's border.

BackColor is the filled color of the object's or its border's background layer when the Pattern or LineStyle properties are set up with a pattern other than Solid or Invisible. When the Pattern property is set to either Solid or Invisible, or the Fore Color is set to Transparent, the color of the object's background layer will not be displayed. When the LineStyle property is set to either Solid or Invisible, the color of the border's background layer will not be displayed.

For more information, see Sections 7.3.1, Color Palette, 7.3.2, RGB Values, and 7.3.3, Previewing Colors for Target Machines.

Line Color

HW Fore Blink

The object's ForeColor, BackColor, and LineColor blink speeds. The default setting is [No] for no blink, or [Fast], [Medium], or [Slow] to set the property's blink speed.

These properties are displayed only when the TargetColor property is set to blink. For details about the blink feature, see Section 7.3.4, Blink Feature

HW Back Blink

HW Line Blink

Line Style

The object's border line style.

Line Width

The width of the object's border line, from 1 to 9 pixels when the LineStyle property is set to either Solid or Invisible. Must be set to a 1-pixel width when LineStyle is set to a pattern other than Solid or Invisible.

Pattern

The object's fill pattern.

Shape

The shape of the object's corner—Normal, Rounded, or Cut. The angle of Rounded or Cut corners can be defined in the Corner sub-property.

Animation

The ellipsis button opens the Animation Properties dialog box, where you can apply animation to the object.

For details, see Chapter 8, Animating Graphics.

  • The settings you make to a tab in the animation dialog box are applied once you change tabs. The Cancel operation only works for the animation tab that you are currently in.

Save Defaults

The forward-arrow button saves the current property settings as the new default property settings.

Restore Defaults

The back-arrow button restores the original default property settings.

Placeholder

You can assign a placeholder in any property that requires a variable definition. Click the ellipsis to open the Placeholders dialog box and edit the variable placeholder for the object. The dialog box only displays if you had set up a placeholder for the object. For more information on placeholders, see Section 21.2.4, Working with Variable Placeholders.
