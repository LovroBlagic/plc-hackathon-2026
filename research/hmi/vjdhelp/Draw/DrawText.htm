7.2.12 Drawing Text Objects

  1. Click the Text Object icon in the graphical objects toolbar.

  1. Click the panel to set the text object's start point then its diagonally opposite end point.

When the Text Editor window opens, you can type and edit your text or modify the font settings.

  1. In the Text Editor, type the text that you want to display in your text object.

  2. If you want to apply your text string to another language, do one of the following:

  3. Overwrite the text string in all other languages with your text string, or

  4. Copy your text string only to other languages that have no string settings.

For details about using multiple languages, see Section 20.2, Switching Languages.

  1. Click OK to display your defined text string in the text object's selection box. Continue clicking on the panel to place as many text objects as needed.

  1. Right-click the panel to exit the drawing mode. The last object drawn will become selected.

  2. Modify the attributes of this text object in the Property Inspector.

The following table describes the Text object properties.

Property

Description

Name

The object's name.

Whenever an object is created, a default name is generated. When renaming an object, its name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

For details, see Appendix 9, Naming Conventions.

Top

The coordinates, in pixels, of the top-left corner of the object.

  • Top is measured from the top of the object to the top of the panel. Enter a value from -32768 to (32767 - object height).

  • Left is measured from the left side of the object to the left side of the panel. Enter a value from -32768 to (32767 - object width).

By changing these properties, the graphical object can be moved up, down, left, and right.

Left

Width

The width and height of the object's selection box can be set from 1 to 3000 pixels.

Bitmap Display

Select either Yes or No to format the object's text as a bitmap image.

Selecting Yes to format the object's text as a bitmap image. This feature allows you to display graphical representations of fonts that might otherwise be unavailable on the target machine.

When the BitmapDisplay property is Yes:

  • Some text objects with bitmap display enabled may be invisible during Simulation and/or run time. Simulate and check your project before downloading it to a target machine.

  • Text objects support only Position animation and Visibility animation, and not Value animation or Color animation. For details, see Section 8.7, Other Animation Features.

  • In a target with multiple user languages, the text object becomes a bitmap image on the panel. You can still edit the text string, but the language will be fixed to the language selected when BitmapDisplay was set to Yes. When you set the BitmapDislay back to No, you will be able to change languages, but the text will remain identical in all languages until you edit the string in each language.

Text Color

The object's text, background, and border line colors.

TextColor is the color of the text within the object's selection box.

LineColor is the border color of the object's selection box.

BackColor is the color of the background layer for the text object's selection box and also for its border when the LineStyle property is set up with a pattern other than Solid or Invisible. When the LineStyle property is set to either Solid or Invisible, the color of the border's background layer will not be displayed.

For more information, see Sections 7.3.1, Color Palette, 7.3.2, RGB Values, and 7.3.3, Previewing Colors for Target Machines.

Text Blink

The object's TextColor, BackColor, and LineColor blink speeds. The default setting is [No] for no blink, or [Fast], [Medium], or [Slow] to set the property's blink speed.

These properties are displayed only when the TargetColor property is set to blink. For details about the blink feature, see Section 7.3.4, Blink Feature.

3D Color

The object's three-dimensional color setting is available only when the FontStyle property is set to 3D and BitmapDisplay is No.

  • 3DColor is not supported on text objects when Value animation has been applied.

3D Blink

The text object's 3DColor blink speed. The default setting is [No] for no blink, or [Fast], [Medium], or [Slow] to set the property's blink speed.

These properties are displayed only when the TargetColor property is set to blink. For details about the blink feature, see Section 7.3.4, Blink Feature.

Line Style

The border line style of the object's selection box.

Line Width

The width of the object's border line, from 1 to 9 pixels when the LineStyle property is set to either Solid or Invisible. Must be set to a 1-pixel width when LineStyle is set to a pattern other than Solid or Invisible.

Text

The ellipsis button opens the Text Editor.

Font

The font type applied to the object.

The fonts available on the target machines depend on the BitmapDisplay setting.

For details about supported fonts and sizes, see Appendix 5, Hardware Specifications.

Font Size

Select an integer from 1 to 255. The font size settings is not available for all types of fonts.

  • When you set up a text object's font size then change the target machine type, the text object's font size may also change.

Font Height

The height and width of the text object's Vijeo font.
These properties are displayed on the target machine when BitmapDisplay is set to No.

For details about supported fonts and sizes, see Appendix 5, Hardware Specifications.

Font Style

The text object's font style—Normal, Bold, or 3D.

The 3D FontStyle property is displayed only with Vijeo fonts—when the BitmapDisplay property on the target machine is set to No.

Restore Fonts

The back-arrow button restores the current default fonts, as set up in the ActiveUserLanguage property.

For details, see Section 20.2.4, About User Application Language Switches.

Animation

The ellipsis button opens the Animation Properties dialog box, where you can apply animation to the text object.

When the text object's BitmapDisplay property is Yes, the Color and Value animations are not supported.

For details, see Chapter 8, Animating Graphics.

  • The settings you make to a tab in the animation dialog box are applied once you change tabs. The Cancel operation only works for the animation tab that you are currently in.

The ellipsis button opens the Animation Properties dialog box, where you can apply animation to the text object.

When the text object's BitmapDisplay property is Yes, the Color and Value animations are not supported.

  • The settings you make to a tab in the animation dialog box are applied once you change tabs. The Cancel operation only works for the animation tab that you are currently in.

Restore Defaults

The back-arrow button restores the original default property settings.

Placeholder

You can assign a placeholder in any property that requires a variable definition. Click the ellipsis to open the Placeholders dialog box and edit the variable placeholder for the object. The dialog box only displays if you had set up a placeholder for the object. For more information on placeholders, see Section 21.2.4, Working with Variable Placeholders.

Editing Text Objects

  1. Right-click the text object and click Edit Text to open the Text Editor.

  1. When the Text Editor opens, you can edit your text or modify the font settings.

  1. Click OK to display your edited text string in the text object's selection box.
