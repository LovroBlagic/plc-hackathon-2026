7.3.4 Blink Feature

There are two types of blink:

  • Hardware blink. This type of blink occurs when an object's color values have been set to blink using the TargetColor setting in the target properties. Hardware blink has four settings—fast, medium, slow, or none. For more information on the target machine colors that support blink, see Appendix 5.1.2, Target Color. This section describes hardware blink.

  • Animation blink. This type of blink occurs when the software determines a particular condition has been met. All target machines support animation blink. Animation blink has three settings—fast, slow, or none. You can set up animation blink in the Visibility tab for objects such as lamps, switches, meters, and message displays. For more information on how to set up animation blink, read the online help for the object's Visibility tab.

The hardware blink feature is often used to indicate warnings or alarms. For target machines that support the blink feature, you can set the following color properties for an object to blink:

  • Some target machines support different blink speeds, see Appendix 5.1.2, Target Color, for your target machine's supported blink speeds.

  • You cannot set up the blink feature for images.

  • For more details on how hardware blink and animation blink operate during simulation, see Section 25.3, Simulating Runtime Operations.
