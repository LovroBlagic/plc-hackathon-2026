7.2.9 Drawing Pie Shapes

  1. Click the Pie icon in the Graphical Objects toolbar.

  1. A pie shape is an angled wedge cut from an ellipse's center to its circumference. Click the panel to set the start point of an ellipse's selection box.

  2. Click the panel a second time to set the ellipse's diametric end point. A line segmenting the ellipse from the center to the circumference appears.

Pressing the CTRL key while moving the Pie tool to set the ellipse's selection box will draw a perfect circle.

  1. Draw the pie shape counter-clockwise. Click the panel at an angle that intersects the ellipse—once to set the start-point side of the pie shape, and again to set the angle of the pie shape. Continue clicking on the panel to place as many pie shapes as needed.

Pressing the CTRL key while defining the arc's start or end points will segment the arc at 45-degree angle increments.

  1. Right-click the panel to exit the drawing mode. The last object drawn will become selected.

  2. Modify the attributes of this pie shape in the Property Inspector.

The following table describes the Pie Shape's properties.

Description

Name

The object's name.

Whenever an object is created, a default name is generated. When renaming an object, its name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

Top

The coordinates, in pixels, of the top-left corner of the object.

  • Left is measured from the left side of the object to the left side of the panel. Enter a value from -32768 to (32767 - object width).

By changing these properties, the graphical object can be moved up, down, left, and right.

Changing the Angle of the Pie Shape

  1. Click the pie shape to display its selection box and eight handles—one handle at the top, bottom, both sides, and at each corner.

  1. Hover the Select tool over the pie shape to display a crossed double arrow , then click the pie shape a second time to display the start and end points of its arc.

  1. Hover the Select tool over the pie shape's start or end point to display a cross symbol +, then click and drag the point to change the length of the pie shape's arc.

  1. Release the cross symbol to set the change.
