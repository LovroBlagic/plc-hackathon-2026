7.2.15 Drawing Mode

When you select a graphical object, you would left-click on the panel to place the object. This action places you in the Drawing Mode, which allows you to draw one or multiples of the same object by continuously left-clicking on the panel. While in Drawing Mode, you can:

  • Modify the color and other attributes of your current object, and create subsequent objects that use those attributes until you exit the Drawing Mode.

  • Modify the color and other attributes of your current object, and save them as your default attributes by clicking Save Defaults in the Property Inspector. Subsequent objects you create would use the default attributes.

To exit the Drawing Mode, either right-click or press ESC.
