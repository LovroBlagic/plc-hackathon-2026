Group

Outputs the alarm or event group name.

AlarmCurCount

Outputs the number of currently active alarms to .csv file. Available only for an alarm group.

AlarmSumCount

Outputs the total number of alarms that were triggered to .csv file since the target machine started up. Available only for an alarm group.

AlarmActiveStateCount

Outputs the number of alarms in Active State to .csv file. Available only for an alarm group.

AlarmACKStateCount

Outputs the number of alarms in ACK State to .csv file. Available only for an alarm group.

AlarmUNACKStateCount

Outputs the number of alarms in UNACK State to .csv file. Available only for an alarm group.

Title

In addition to alarm and event group information, you can add a title, limited to 32 characters. In this title you can add the current date and time using the following placeholders.

Symbol

Description

%Y

The year when the file was saved (4 digits)

%M

The month when the file was saved (2 digits)

%D

The day when the file was saved (2 digits)

%E

The day of the week when the file was saved (3 letters)

%h

The hour when the file was saved (2 digits)

%m

The minutes component of the time when the file was saved (2 digits).

%s

The seconds component of the time when the file was saved (2 digits)

%n

The file number
 

When By File No. is selected as the File Name format, uses a value from 0 to 999999.

 

When By Date is selected as the File Name format, uses a value from 0 to 999 with a 4-digit date, or 0 to Z (35) with a 6-digit date.

%%
