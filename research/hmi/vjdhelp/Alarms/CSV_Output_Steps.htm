16.3.6.1 Steps for Save to File Output

The steps for configuring .csv file output are explained below.

Configuration Procedure

1.Select the Alarm Group, Event Group, or Alarm Category to output to a .csv file, and enable the SaveToFile property.

2. Configure the file output settings in the SaveToFile dialog box.

3. Download the project to the target machine and start runtime.

4. Enter a value in the Control Variable and File Number Variable. The corresponding alarm or event message will be saved in the .csv file.
