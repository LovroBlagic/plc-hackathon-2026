16.3.1.4 Remote Categories

You can share alarm groups and event groups between target machines. A remote category is a collection of shared alarm groups and event groups.

The example below shows a typical setup for alarm/event group sharing. Alarm Group 1 in the server target is shared with the remote category in the client target. This allows the client target to view and interact with the alarms in the server target’s Alarm Group 1. Remote categories do not behave exactly like normal alarm/event categories. For more information on remote category behavioral key points, see Section 16.3.1.4, Remote Categories: Remote Category Key Points.
