16.5.2 Changing the Backlight Color

You can control the target's backlight color so that at runtime the backlight color can change in response to the priority level of events that occur. In Vijeo Designer, the following events are assigned priority levels:

  • Data change from the backlight variable

  • User-defined backlight color operation

  • Alarm events

  • Target panel change.

The backlight color only changes on a base panel when a backlight color action is triggered. For example, if you set up a backlight color action on a popup panel or a master panel by touching a switch, the backlight color will change on the base panel underneath a popup panel or the base panel using the master panel.

To check if your target supports this feature and the supported backlight colors, see Appendix 5, Hardware Specifications.

The following table describes how backlight color changes, based on the events associated with each priority level, from the highest priority level (1) to the lowest (4).

Priority Level

Event

Description

1

Data Change from Backlight Variable

Backlight color is set when you associate an internal or external variable with the backlight color in the target properties. The priority level is set to 1 when the value of a variable changes to a valid backlight color value. If the backlight color value is set to 255 (Relinquished), priority level 1 will be relinquished and priority levels 2 to 4 will be checked to see which level will gain control of the backlight.

For information on how to set up the backlight color for this priority level, see Setting Up Backlight Color Change with a Variable.

2

User-Defined Backlight Color Operation

Backlight color is set by using a switch or action defined with a backlight color operation. The backlight color will not fall back to lower priority level backlight colors, unless the value 255 (Relinquish) is written to the variable.

For information on how to set up the backlight color for this priority level, see Setting Up Backlight Color Change with a Switch or Action.

3

Alarm Events

Backlight color is set when an alarm occurs in the alarm group, event group, or alarm category defined in the Alarm Backlight Control. When the alarm is acknowledged (ACK) or returns to normal (RTN), priority 3 becomes inactive and relinquishes the color. The backlight color for priority 4 is then set, unless a higher priority item becomes active.

For information on how to set up the backlight color for this priority level, see Setting Up Backlight Color Change for Alarm Events.

4

Target Panel Change

Backlight color is set when there are no higher priority backlight colors currently active.

For information on how to set up the backlight color for this priority level, see Setting Up Backlight Color Change for Target Panel Change.

 

Setting Up Backlight Color Change with a Variable

  1. In the target properties, click Backlight to open the Backlight properties.

  2. Select Color, and define the variable expression you want to associate with the backlight color. The value of the integer variable or expression defines the backlight color. For more information on the Color property, see Section 4.5.1, Target Properties. For more information on the values for the supported colors, see Appendix 5.12, Backlight Colors Supported by Hardware Platforms.

  • If the value of the variable is set at 255 (Relinquish), the backlight color will not be set for priority level 1, and the backlight color will be set for the next priority level, if the next level is also not relinquished.

Setting Up Backlight Color Change with an Action or Switch

  1. Create a switch or an action. For more information, see Section 9.2, Creating Switches, or Section 9.4, Creating Actions.

  2. Define the operation for your action or switch by selecting Backlight Color in the Operation property.

  3. Select the Backlight Color from a selection that is supported for the target you are using. Select 255 (Relinquish), if you do not want to set a backlight color for priority level 2.

Setting Up Backlight Color Change for Alarm Events

  1. In the target properties, click Backlight to open the Backlight properties, and then click Alarm Backlight Control.

  2. Define the Alarm Backlight Control properties (Group, Default Alarm Backlight Color, and Color By Severity). For more information on the properties, see Section 4.5.1, Target Properties.

Setting Up Backlight Color Change for Target Panel Change

  1. In the panel properties, select the color in the Backlight Color property. The default is color 0 for the target.
