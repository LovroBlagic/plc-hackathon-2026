16.3.2.3 Displaying Derived Function Block Status Messages

When Derived Function Blocks (DFB) generate alarms, you can display the DFB's status and status messages on the target machine. The messages, which are stored in either default (system) or custom .sto files, cannot display in the alarm summary but can display in a String Display.

  • Custom .sto files are not saved with the project and cannot be exported with the project. To save .sto files in the project, you need to assign a valid path where the .sto files are located.

The following example shows how to use a switch to display the .sto message of the current alarm.

Adding .sto Files

  1. Double-click the diagnostic alarm group node to display the Alarm Group Settings dialog box, and click the Messages tab.

  2. Select the Enable STO File Decoding check box.

  3. If you are using custom derived function blocks, then select Use Custom Path and define the location of the custom .sto files.

  • The .sto file uses the locale of the current user language to determine which language file to use.

  • Custom .sto files must include language folders as part of the path: ENU for English, FRA for French, DEU for German, ITA for Italian, ESP for Spanish, POR for Portuguese, CHN for Simplified Chinese, CHT for Traditional Chinese.
    For example, type C:\STOFiles when .sto files are located in C:\STOFiles\ENU\DFBFilename.sto.

  1. Click OK.

Adding script

  1. In the Navigator window's Variables tab, create a String variable to store the DFB status message.

  2. On the panel draw a switch and add a script operation.

  3. In the script editor, write the following script to copy the DFB status message to the String variable DFB_StatusMsg.

// Get status message for diagnostic alarm

String tempDFBName = DiagBuffer.getDfbName(AlarmSummary01);

String tempMsg = DiagBuffer.decodeStatusWords(AlarmSummary01);

DFB_StatusMsg.write("DFB: " + tempDFBName + ": " + tempMsg);

 

Displaying the Status Message

  1. On the same panel as the switch, draw an alarm summary object and set its Alarm Group to the diagnostic alarm group, and enable Direct Selection.

  2. Draw a String Display object beside the alarm summary and set its Variable to the status message variable. Make sure the Display Length is long enough to handle the entire string.

  3. At runtime, when a DFB alarm appears in the alarm summary, touch the alarm message.

  4. When the alarm message is selected, touch the switch set up with the DiagBuffer script. The .sto file's status message appears in the String Display object.

  • The maximum number of characters you can display is 100 characters, which is the maximum number of characters the String variable can store. As a result, long .sto messages may get truncated.

  • Status messages and STO messages can change without the Diagnostic Buffer generating a new diagnostic alarm record. To ensure the String Display always shows the most current message, change the script that retrieves the message to a periodic script.

  • Status Words must be declared as public variables in order to read the corresponding DFB status messages in Vijeo Designer.
