16.3.5 Printing Alarm and Event Messages

You can print alarm messages as they occur in real-time or print alarm and event messages in batches. You can also perform real-time and batch printing at the same time. Batch printing prints all messages in the corresponding alarm or event group when the control variable is set appropriately.

Real-Time Printing

Real-time printing prints in Log format and prints an alarm message each time the alarm state changes between Active, Acknowledged (ACK), Unacknowledged (UNACK), and Returned to Normal (RTN). To set up Real-time printing see Section 16.3.5.2, Configuring Real-time Printing.

 

Batch Printing

Batch printing prints alarm and event messages when signaled by the Print Control Variable. Batch printing can print alarm messages in the Active, Log, or History format, and event messages in the Log or History format. To set up Batch printing, see Section 16.3.5.3, Configuring Batch Printing.
