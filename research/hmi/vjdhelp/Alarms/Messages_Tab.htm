16.2.6.2 Messages Tab

Define the language, font, and font size for messages in the Messages tab. For example, you can define the text and back colors for alarm messages in the four states (Active, ACK, RTN, and UNACK), or define the colors for event messages by their severity .

The following table describes the Messages tab properties.

Property

Description

Languages

Set the font, font width, and font height for alarm messages in each language.

  • Language option is available only if you have more than one language configured for your project. See Section 20.2.6, Adding a User Application Language.

  • For targets with a panel size of 200x80, the font width and height cannot exceed 16 pixels.

Color by severity

Severity

Enables you to configure message colors for an alarm or event severity. You can set up 1 to 999 different severity colors.

For example, if an alarm triggers and the alarm's severity is listed in the severity list, the alarm summary displays the alarm's message in the color configured for the severity. For more information on alarm severity, see Section 16.2.5.1, Severity.

The Severity list box lists the severities associated with the summary. Severities not associated with the summary display with an asterisk beside the severity number.

To enable alarm severity coloring, select the Color by severity check box. Use the Severity add button to add a severity or use the delete button to delete a severity from the severity list.

To define colors for an alarm's severity:

  1. Select the severity in the Severity list.

  2. Configure the Active, ACK, RTN and UNACK colors.

To define colors for an event's severity:

  1. Select the severity in the Severity list.

  2. Configure the RTN colors.

Text Color

Back Color

For events, select the RTN Text Color and RTN Back Color. The RTN Text Color sets the text color for the events in the summary. The RTN Back Color sets the background color for the events in the summary.

For alarms, select a text and back color for each of the following alarm states.

Active

The Active Text Color sets the text color for active alarms. The Active Back Color sets the background color for active alarms. The background color works only if you select the Enable check box.

ACK

The ACK Text Color sets the color for the acknowledged alarms. The ACK Back Color sets the background color for the acknowledged alarms. The background color works only if you select the Enable check box.

RTN

The RTN Text Color sets the color for alarms that have returned to normal. The RTN Back Color sets the background color for alarms that have returned to normal. The background color works only if you select the Enable check box.

UNACK

The UNACK Text Color sets the color for alarms that have not been acknowledged but have been restored to normal. The UNACK Back Color sets the background color for alarms that have not been acknowledged. The background color works only if you select the Enable check box.

UNACK is available only if Alarm Behavior is set to Optional ACK mode.

Column Colors

The Column Colors properties are enabled when you have set the Display Mode property to Double Line and are not available for targets with a small panel size of 200x80.

Same as Messages

Select the check box to set column text and column background colors to the same colors as messages.

When the Sane as Messages check box is selected, the Column Text Color and Column Background Color properties are disabled.

Column Text Color

Click the color box to open the color palette and choose the color you want for the text in the summary column.

Column Background Color

Click the color box to open the color palette and choose the color you want for the background in the summary column.
