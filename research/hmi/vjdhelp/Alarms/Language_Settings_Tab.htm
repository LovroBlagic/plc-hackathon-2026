16.3.6.5 Language Tab

If your project is set up with multiple languages, you can save alarm messages in any of the languages. The Language tab is only available for an alarm group. For an event group, the selected language is the system language you are using when the event occurred.

  1. In the SaveToFile dialog box, click the Language tab.

  1. In the Language tab, select which language method to use. Select from Current Language Used in Runtime, Specific to Output, or Control By Variable.

Current Language Used in Runtime

Saves in the current user language at runtime.

  • After saving begins, changing the user language on the panel does not change the language.

Specific to File Output

Select the language of the alarm messages you want to save to file.

Control By Variable

Specify an integer variable, and in it store the language number of the language that you want to use when saving to file.

  • Find the language number in each Language's properties.

  • You can save the following items in the alarm summary in the specified language:

  • Alarm messages

  • Title (date, alarm time, acknowledge time, and so on)

  • Alarm type messages (HiHi, Hi, Lo, LoLo)

  • Alarm state messages (Alarm, ACK, UNACK, Recovery)
