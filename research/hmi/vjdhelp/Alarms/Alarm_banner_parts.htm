16.4.3 Local Alarm Banner

Local alarm banners only display on the panels on which they are placed. Also, local alarm banners are not affected by any error window that may pop up. The local alarm banner will be hidden by the error window, if it happens to be beneath it, but its position will not change.

For single line alarm banners, when the alarm is off or is not active, the alarm banner will not be displayed in runtime.

The following features are supported by a Local alarm banner, but not by the Global Alarm Banner.

  • You can move the alarm banner to any position on the panel.

  • You can arrange multiple local alarm banners on one panel.

  • The color of the frame can be specified.

Local Alarm Banner in Single Line and Double Line Mode

In Single Line Mode, alarm banner messages scroll from the right side of the banner frame to the left. See Section 16.4.3.2, Creating a Single Line Local Alarm Banner, for more details.

In Double Line Mode, the most recent alarm banner message is shown on the panel in a two line display. The message is fixed, meaning the entire message remains on the panel without scrolling. The order in which each message is replaced by another is determined by the alarm state. See Section 16.4.3.3, Creating a Double Line Local Alarm Banner, for more details.

16.4.3.1 Steps for Creating a Local Alarm Banner

Procedure

1. Create an Alarm Group.

2. Create variables and setup the alarm messages, assign alarm groups, and define other alarm parameters.

3. Open the Panel that you want to display an Alarm Banner.

4. For a single line local alarm banner, drag an Alarm Banner part from the Toolchest and drop it onto the panel. For a double line local alarm banner, click the Alarm Summary icon, select Alarm Banner from the drop-down list, and draw it on the panel. Set up the Alarm Banner properties.
