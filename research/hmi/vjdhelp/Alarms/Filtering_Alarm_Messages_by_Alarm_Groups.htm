16.3.1.3 Filtering Messages by Groups

Use the filter to change the group or alarm category displayed in the summary during run-time. The filter lists all the groups and the alarm categories nested under the assigned alarm category. The filter lists the groups and alarm categories by their labels. For more information on labels, see Section 16.2.4, Group Settings.

Setting Up the Filter

  1. Create a summary. See Section 16.2.6, Setting Up an Alarm and Event Summary.

  2. In the General tab, click the Alarm and Event Group list, select the alarm category to display in the summary.

  3. Click the Buttons tab, select Filter in the Available Buttons column, and add it to the Top, Left, Right, or Bottom of the summary.

  1. Compile and run the project. During Runtime, use the Filter to select the alarm group, event group, or alarm category to display in the summary.
