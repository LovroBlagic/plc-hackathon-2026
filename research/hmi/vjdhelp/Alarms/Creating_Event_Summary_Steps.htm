16.2.2.4 Creating Event Summary Steps

To display event messages, use the following steps.

Steps

1. Under the Alarms & Events node in the Navigator Window's Project tab, create an event group and define the event group settings.

2. (Optional) Define the users so they may display in the Event Summary's User Name column. For more information on how to set up a user, see Section 4.8.3, Creating Security Users.

3. (Optional) If you want to monitor variables, select the variables to be monitored using the Log User Operations on Variable property in the Variable properties. For more information, see Section 6.2.3.2, Data Details Tab.

4. (Optional) If you want to create custom messages for display:

  • Configure a text resource to define messages.

  • Create an Event Message operation to trigger the event message by using a switch, action, or script.

5. Place an Event Summary on the panel, assign the event group, and define other Event Summary properties. For more information, see Section 16.2.6, Setting Up an Alarm and Event Summary.
