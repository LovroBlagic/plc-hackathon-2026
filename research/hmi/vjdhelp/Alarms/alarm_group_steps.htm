16.2.2.3 Creating Alarm Summary Steps

To display alarm messages, use the following steps.

Steps

1.  Under the Alarms & Events node in the Navigator Window's Project tab, create an alarm group.

2. Create a variable.

3. In the variable properties, enable the alarm and define the alarm settings.

4. Place an Alarm Summary on the panel, assign the alarm group, and define other Alarm Summary properties.
