16.3.6.7 File Output Limitations

When saving alarm and event messages to a .csv file, you must note the following.

  • The maximum number of alarm messages that you can save is specified in the Num Of History Alarms and Num Of Log Alarms properties in the Alarm Group Property Inspector.

  • The maximum number of event messages that you can save is specified in the Total Records property in the Event Group window.

  • When you save multiple alarm groups, event groups, and alarm categories at the same time, the alarms group, alarm category, and event group will save in the order that they were created. For example, if you created alarmgroup1 before alarmgroup2, then alarmgroup1 will save before alarmgroup2.

  • When you select By File Number for the File Name format and select File Number Auto Increment, when you change the value in the control variable, the alarm is saved to a file, and the filename is appended with a file number. This file number increases by 1 after every save operation, and does not depend on the alarm type.
