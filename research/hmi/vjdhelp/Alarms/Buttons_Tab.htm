16.2.6.4 Buttons Tab

Select the Enable Buttons check box to define and position operation buttons on your summary. Select the operations that you want to add to the summary from the Available Buttons list. During Runtime, the summary displays and positions the operation buttons that you define in the Buttons tab.

  • You can create summary operation buttons using switches. For more information, see Section 16.2.7, Creating Alarm or Event Operations.

  • The Buttons tab is not available for targets with a panel size of 200x80.

Property

Description

Top

Lists the operation buttons that you selected and positioned at the top, bottom, left, or right. The position you assign here for the button will be its position in runtime.

For example, select Cursor On and click Add Left.

In Runtime, the Cursor On button is placed in the left side of the summary.

You can select whether you want a small or large button size. The small size option is 40x40 pixels, and the large size option is 60x60 pixels.

Bottom

Left

Right

Use the up/down icon to move a button in the Button Position list up/down or left/right in the display order.

For the left/right button position, the icon is equivalent to Left, and the icon is equivalent to Right.

 

In the Editor, if you selected more operation buttons than can fit in the Top, Bottom, Left, or Right position on the summary, a yellow arrow displays to indicate that the summary needs to be enlarged. If you do not enlarge the summary, the operation buttons that cannot fit will not display at runtime. The yellow arrow also does not display at runtime.

Run Touch Action

Enables touch action associated with the variable's alarm. It runs the Alarm Touch Action set up in the alarm. For information on how to set up Touch Actions, see 16.3.4.2, Touch Actions.

When the selected message is an event message, there will be no action.

ACK

Acknowledges the selected alarm.

For Active and History display modes, when acknowledging an active alarm, the color of the alarm changes to its acknowledged colors, and the time when the alarm is acknowledged is added.

For Log summary, a new row is added for the acknowledged alarm.

There is no change when acknowledging an alarm that has already returned to normal.

When the selected message is an event message, there will be no action.

ACK All

 

Acknowledges all the alarms in the alarm summary.

When the selected message is an event message, there will be no action.

Clear

The purpose of this operation is to remove an alarm message that displays erroneously. This could be a result of equipment failure such as a sensor that is faulty, or a result of a single alarm generating five alarm messages.

 

The clear operation removes all instances of the alarm from all alarm summary displays, for all alarm summary types (Active, History, and Log). The variable remains in the alarm state, but its associated alarm message does not appear anymore in any alarm summary display. Even if the alarm changes from Hi to HiHi, the alarm message will not appear.

 

This behavior is a result of forcing the alarm to a returned to normal state. As a result, the alarm message can only be generated again after the alarm returns to normal. Returned to normal alarms cannot be cleared.

 

None of the display modes add a message when the alarm returns to normal.

When the selected message is an event message, there will be no action.

Clear All

Clears all the Active, Acknowledged, and Not Acknowledged alarms from the alarm summary. Returned to Normal alarms cannot be cleared by the Clear All button.

 

None of the display modes add a message when the alarm returns to normal.

When the selected message is an event message, there will be no action.

Delete

When you run the delete operation on the alarm summary, it deletes the alarm from the current alarm list. The alarm is not deleted from other alarm lists, which is unlike the clear operation.

There are three alarm lists: Active, History, and Log. The alarm summary display is associated with one of these lists.

 

Log alarm summary displays show a message when the alarm returns to normal, even for deleted alarms. Active and History alarm summary displays do not add a message when a deleted alarm returns to normal.

Delete All

The delete all operation deletes the alarms and events displayed in the summary from the current list.

 

There are three alarm lists: Active, History, and Log. The alarm summary display is associated with one of these lists.

 

Log alarm summary displays show a message when the alarm returns to normal, even for deleted alarms. Active and History alarm summary displays do not add a message when a deleted alarm returns to normal.

Filter

Selects the alarm group to attach to this alarm summary. The entries in the list include the alarm group picked in the property inspector and all the groups and categories nested in it. This button can be positioned Top or Bottom. This operation is available only through built-in operation buttons.

  • Filter is available only through built-in operation buttons.

  • Jump is available only through switches.
