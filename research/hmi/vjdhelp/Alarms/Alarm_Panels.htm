16.1 Alarms and Events

Alerting Alarms to Users

In Vijeo-Designer, you can indicate alarms to the user with the following display formats and features:

  • Alarm Summary Display – You can display a list of alarms on a panel by using the alarm summary. Alarms can have four states: Active, Acknowledged (ACK), Not Acknowledged (UNACK), and Returned to Normal (RTN). The alarm summary can display alarms that are in these four states. You can print these alarm messages or save them to a .csv file. For more information, see Section 16.2, Setting Up the Alarm and Event Summary.

  • Alarm Banner – You can display active and UNACK alarm messages on a panel using the alarm banner. If multiple alarms become active at the same time, the banner alarm messages display in order of activation. You can stop alarm messages from displaying by setting up the alarm banner's Display Message property for the target node. Form more information, see Section 16.4, Alarm Banner.

  • Actions – You can set up operations such as e-mail, popup windows, scripts, etc., to alert users to alarm conditions. For more information on setting up operations to run on specific alarm conditions, see Section 9.4.1, Actions Wizard.

  • Sound – You can use sound to alert users to an alarm activating. For more information, see Section 16.5.1, Setting Up Alarms to Play Sound Files.

  • You need to connect the target machines to speakers in order to use the sound feature. For information on which targets support sound, see Appendix 5, Hardware Specifications.

Displaying Events to Users

In Vijeo-Designer, you can indicate events to the user with the following display formats and features:

  • Event Summary Display – You can display a list of events (user actions, system error events, and system events) on a panel by using the event summary. Events only have one state in the event log and in the event display. You can print these event messages or save them to a .csv file. For more information, see Section 16.2, Setting Up the Alarm and Event Summary.

  • Actions – You can set up an event message operation to display predefined event messages. At runtime, an event message would display when an operator touches a switch or sets off an action trigger. For more information on setting up the operation in a switch or action, see Section 9.5.22, Event Message Operations, Section 9.2, Creating Switches, and Section 9.4, Creating Actions.
