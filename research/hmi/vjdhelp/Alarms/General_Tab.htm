16.2.6.1 General Tab

In the General tab, you can define display and operation attributes for the summary.

The following tables describe the General tab properties.

  • Alarm Property Settings

 

Property

Description

Name

The summary's name.

Whenever a summary is created, a default name is generated. When renaming the summary, its name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

For more information, see Appendix 9, Naming Conventions.

Description

Type in a description of the summary up to 255 characters long.

Alarm and Event Group

Use the drop-down list box to assign either an alarm group, event group, or an alarm category to the summary. Alarms and events associated with the selected alarm group, event group, or alarm category will be displayed in the summary at Runtime. For more information, see Section 16.3.1, Alarm and Event Groups.

 

  • Use an alarm category to display messages from several alarm groups and/or event groups. The groups can be from the same target. For more information, see Section 16.3.1.2, Displaying Multiple Groups.

Alarm and Event List

For an event group, you can select History or Log to display historical or log records. When Active is selected, no records will be shown for the event group in the summary.

For an alarm group, you can select Active, History, or Log.

  • Active: Displays alarms that are in either the Active or Acknowledged (ACK) states. Once the alarm is returned to normal (RTN), the alarm message is removed.

  • History: Displays alarms that are in the Active, Acknowledged (ACK), Not Acknowledged (UNACK), or Returned to Normal (RTN) states. The History Alarm Summary uses one row for the states of a single alarm. However, when an alarm changes state from RTN to active, the alarm message displays on a new row in the alarm summary. Each time an alarm changes state, the alarm message color changes to the corresponding state color, and the date and time are changed to when the alarm was activated, acknowledged, or returned to normal.

  • Log: Displays a new alarm message for each change in state: Active, Acknowledged (ACK), Not Acknowledged (UNACK), and Returned to Normal (RTN). The Log Alarm Summary displays alarm messages in the corresponding state color.

When History or Log is selected, the alarm remains in the alarm summary even after the alarm returns to normal (RTN).

 

Sort By

You can select from the following:

  • Time: Alarms and events are sorted in chronological order. Newest alarms and events display first.

  • Severity: Alarms and events are sorted by their severity. Alarms and events with the highest severity level display first. For more information on alarm severity, see Section 16.2.5.1, Severity. For more information on event severity, see Section 16.2.4.2, Event Group Settings: Severity.

  • State: Alarms are sorted by their state and display in the following order: Active/UNACK first, RTN second, and ACK last. If you select this option for events, no sorting will take place.

Scroll Direction

Select either Up or Down for the scroll direction.

  • Up: The alarms and events display in the summary from bottom to top in the order specified by the Sort By property. The newest or the most severe alarms and events appear at the bottom of the summary.

  • Down: The alarms and events display in the summary from top to bottom in the order specified by the Sort By property. The newest or the least severe alarms and events appear at the top of the summary.

This property is not available for targets with a panel size of 200x80.

Display Mode

Configures the display mode for the summary. Select Single Line, Double Line, Three Line, or Four Line.

  • Single Line: The summary displays messages in a single line.

  • Double Line: The summary displays messages in two lines. The first line displays the alarm's date, time, and state. The message starts on the second line.

  • Three Line or Four Line: The summary displays messages in three or four lines based on your selection. The first line still displays the alarm's date, time, and state. The message starts on the second line. If your message is longer than the column width, the message automatically wraps to the next line.

  • For target machines with a panel size of 200x80, this property is fixed to Single Line.

  • Messages that do not fit using the defined Display Mode are truncated.

  • When using multi-line messages:

  • You cannot change the alarm summary's Message column width at run time.

  • The alarm summary does not display a horizontal scroll bar.

  • Alarm banners display in double-line rows only.

Back Color

Sets the background color for every cell of the summary.
  • Action Selection Settings

 

Cursor Type

Select the cursor type. This property is not available for targets with a panel size of 200x80.

None

When none is selected, the summary will not have a cursor or a vertical scroll bar and Cursor on Action will be disabled. Also, the summary will only scroll down.

Reverse Color

Reverses the background color to show the cursor position.

For alarms, when Reverse Color is selected:

  • The alarm state's text color cannot be the same as the back color of the alarm summary.

  • You cannot have different back colors for the different alarm states.

Arrow

Displays an arrow to mark the cursor position.

When used, a column that displays the arrow indicator is added to the summary.

Blink

Enables the message to blink to indicate the selected alarm or event. The rate at which the message blinks is 1 second.

    • When Blink cursor type is selected and an alarm or event is highlighted, the text and the background colors of the selected message alternate between the specified Back Color for the state and its XOR Color, respectively. If the XOR color is too hard to distinguish from the specified color for the state:

    • Use a different color for the message.

    • Use Arrow instead of Blink.

    • Use Reverse Color.

Cursor On Action

When TouchAction is selected from the drop-down list box and an alarm or event is highlighted in the summary, its Touch Action is executed. The default selection is None. This property is not available for targets with a panel size of 200x80.

See 16.3.4.2, Touch Actions for more details.

Enable Touch Action

When enabled, you can run the touch actions associated with the alarm or event when an alarm or event is selected.

For more details, See Section 16.3.4.2, Touch Actions.

Auto Cursor

When Auto Cursor is selected for events, the cursor moves to the most current event message in the summary.

For active state alarms, the cursor moves to newly activated alarm messages in the summary.

This property is not available for targets with a panel size of 200x80.

Direct Selection

When selected, you can select alarms or events in the summary by touching them.

This property is not available for targets with a panel size of 200x80.

Large Scroll Bar

Select Enable to display a larger scroll bar on the summary. This property is not available for targets with a panel size of 200x80.

 

  • If Direct Selection or Auto Cursor is selected, you do not need to add an operation button or cursor display switch. The following table describes when you would need a cursor display switch.

Cursor Display Options

Cursor Display Switch Needed?

Direct Selection

No. You can select alarms and events by touching the summary.

Auto Cursor

No. The cursor displays automatically.

Neither option selected

Yes. Cursor is shown or hidden only when you use a Display/Hide cursor switch or operation button.

This property is not available for targets with a panel size of 200x80.

Row Separator

When selected, displays the summary's grid lines.

Line Color

Sets the color of the summary's grid line.

Back Color

Sets the color for spaces in the grid's line style when a pattern other than Solid or Invisible is selected.

Line Style

Sets the line style of the summary's grid line.

Line Width

Sets the line width of the summary's grid line.
