16.2.6 Setting Up an Alarm and Event Summary

This section describes how to set up an alarm summary, event summary, or alarm banner on:

  • Targets with a panel size of 320x240 and larger

  • Targets with a panel size of 200x80

Setting Up an Alarm and Event Summary on a Target (320x240 and larger)

  1. On the panel, click the Summary icon in the Graphical Objects parts toolbar. Select Alarm Summary, Event Summary or Alarm Banner from the drop-down list.

  2. Draw the summary on the panel.

  3. Double-click the summary to display the Alarm Summary Settings, Event Summary Settings, or the Alarm Banner Settings dialog box.

  4. Use the following tabs to define the Alarm Summary, Event Summary, or Alarm Banner settings as required by your project.

  5. General Tab

  6. Messages Tab

  7. Columns Tab

  8. Buttons Tab

The sections describing the above tabs use the Alarm Summary Settings dialog box as an example.

 

Setting Up an Alarm and Event Summary on a Target (200x80)

  1. On the panel, click the Summary icon in the Graphical Objects parts toolbar. Select Alarm Summary, Event Summary or Alarm Banner from the drop-down list.

  2. Draw the summary on the panel.

  3. Double-click the summary to display the Alarm Summary Settings, Event Summary Settings, or the Alarm Banner Settings dialog box.

  4. Use the following tabs to define the Alarm Summary, Event Summary, or Alarm Banner settings as required by your project.

  5. General Tab

  6. Messages Tab

The sections describing the above tabs use the Alarm Summary Settings dialog box as an example.

With the small panel size, there are no columns to define on an Alarm Summary, Event Summary, or Alarm Banner. The buttons that are displayed on the summary or banner are described as follows:

Button Operation

Icon

Description

Previous

Takes you to the previous, older alarm or error message.

Next

Takes you to the next, newer alarm or error message.

ACK

Acknowledges the selected alarm.

For Active and History display modes, when acknowledging an active alarm, the color of the alarm changes to its acknowledged colors, and the time when the alarm is acknowledged is added.

For Log summary, a new row is added for the acknowledged alarm.

There is no change when acknowledging an alarm that has already returned to normal.

When the selected message is an event message, there will be no action.

Exit

Exits you from the summary.
