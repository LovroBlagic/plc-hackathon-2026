16.3.3.2 Alarm Summary Columns

In the alarm summary, you can display various information about alarms, such as the alarm message, date, or active time. You can also display information related to word alarms, such as Type, Value and Limit. This section describes how to set up and display these items.

Setting Up

  1. On the panel, double-click the alarm summary to display the Alarm Summary Settings dialog box.

  2. Click the Columns tab.

  3. Depending on the requirements for your project, select Type, Value, or Limit. Then click Add to display this information in the alarm summary.

Type

This column displays the alarm type: HiHi, Hi, Lo, LoLo, NRML, MIN%, MAJ%, MIND, MAJD. In the alarm group properties, you can change the messages displayed in the Type column to suit your project.

Value

This column displays the value of the variable when the alarm became active.

Limit

This column displays the alarm threshold that was exceeded to produce the alarm.

 

Editing Type Messages

When displaying the Type in the alarm summary, you can change the Type messages to suit your project. Follow the steps below to edit your Type messages.

  1. Right-click the alarm group and click Settings to display the Alarm Group Settings dialog box.

  2. In the Type Messages area, edit each message as required.

 

LoLo

Available only for variables with the Limit alarm type selected.

Message notifies the user the value is below the LoLo value.

Lo

Message notifies the user the value is below the Lo value.

Hi

Message notifies the user the value is above the Hi value.

HiHi

Message notifies the user the value is above HiHi value.

NRML

Available for all alarm types.

Message notifies the user the value has returned to normal. When using Active alarm summary displays, the message entered here will not appear.

MIN%

Available only for variables with Deviation (Percent) alarm type selected.

Message notifies the user the value has exceeded the MINor Percentage limit.

MAJ%

Message notifies the user the value has exceeded the MAJor Percentage limit.

MIND

Available only for variable with the Deviation (Fixed) alarm type selected.

Message notifies the user the value has exceeded the MINor Deviation limit.

MAJD

Message notifies the user the value has exceeded the MAJor Deviation limit.

 

  • You can also change the Alarm Type Messages in the Property Inspector for the Alarm Group.
