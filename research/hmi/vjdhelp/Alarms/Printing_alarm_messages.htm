16.3.5.1 Steps for Printing Messages

This Section explains the steps to set up message printing.

 

Steps

1. Select the proper printer for your target machine.

2. In the Project node's properties, enable the printer and set up the Printer Type and Printer Setup.

3. If you are Real-time printing, select the Alarms and Events node and enable Real-time printing.

 

If you are Batch printing, select the Alarm Group, Event Group, or the Alarm Category to print, and enable the print feature.

4. Define the properties for real-time or batch printing.

5. Download the project to the target machine and start runtime.

6. If you print in real-time, printing starts automatically. If you select Batch printing, printing will only start once the Print Control variable has the specified value.
