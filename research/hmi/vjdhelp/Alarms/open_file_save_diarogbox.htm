16.3.6.2 Selecting an Alarm Group, Event Group, or Alarm Category to Output to File

You can output alarm and event messages from alarm groups, event groups, and alarm categories to a .csv file at a Run-time Data Location. This section describes how to set up save properties for the alarm group, event group, or alarm category.

  1. Right-click an alarm group, event group, or alarm category, and select properties.

  2. In the Property Inspector for the Alarm Group or Event Group, click in the SaveToFile property to display the SaveToFile dialog box.

  3. In the SaveToFile dialog box, specify the file output settings.
    See Section 16.3.6.3 Control Tab Settings.
