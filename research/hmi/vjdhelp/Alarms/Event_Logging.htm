16.2.2.2 Event Logging

Event logging is automated in Vijeo Designer. When an operation or event occurs, it is logged. The events and their corresponding records are logged, organized into event groups and can be viewed in the Event Summary. There are three types of events:

  • User Events - User events are generated each time a user performs an operation, such as change panels, or change recipes. These events are recorded only when an Event Group is created and you have configured the events.

  • System error events - System error events are generated when an error event occurs. To view the records in a summary, a System Error Group needs to be created. These events are always recorded. For a list of system error event messages, see Section 28.2.4.1, Run-time Event Messages.

  • System events - System events are generated when operators interact with the system to perform actions and operations. These events are recorded only when a System Event Group is created. For a list of system event messages, see Section 28.2.4.3, System Event Messages.

By defining event groups, you can set up a group of event records for display, save a group of event records to a file output, or configure a group of event records for batch printing.

This section describes these key features in Vijeo Designer's event logging:

  • Custom event messages

  • Variable tracking

  • System language support.

Custom Event Messages

You can create custom event messages for user events. For example, in a vegetable processing plant, you can trigger the wash cycle action, and then generate custom event messages to indicate that the wash cycle has started and the subsequent events that occur in the wash cycle.  

Custom event messages are created in a text resource. You can create a plain text message – see Section 21.1.4.4, Defining Values for Each Property in Each State. Or you can create a message with dynamic content – see Section 21.1.5.12, Setting Up Messages with Dynamic Content.

Viewing Custom Event Messages

To enable an event message to display at runtime, you can configure an Event Message operation in a switch, action, selector, panel function key, or target function key. In the configuration, you must specify the Text Resource where you have predefined the event message and then define the event message you want to generate. For more information on this operation, see Section 9.5.22, Event Message Operations.

You can print event messages and save them to a single CSV file.

Variable Tracking

You can use the variable tracking feature to monitor user-initiated value change events for:

  • Internal and external variables. Select the Log User Operations on Variable property in the Variable Properties dialog box. For more information, see Section 6.2.3.2, Data Details Tab.

  • Some system variables. You can monitor system variables that support the Write To property. Set the Write To property to a variable that is being tracked. For a list of variables that support Write To property, see Section 6.7, System Variables.

The variable tracking feature is most useful for monitoring value changes to ingredients in a recipe. To do this, you must flag all recipe internal variables for monitoring with a change variable event message. To flag the variables, select the Log User Operations on Variable property in the Variable Properties dialog box. When an operator changes an ingredient, the event will be recorded in the log.

System Language Support

For system error events, the messages are displayed in the currently selected language. If the language selection changes, the existing records and new records switch to the newly selected language.

Events and system events are logged using the selected system language. For system events, the messages are displayed in the language selected at the time the event was recorded. If the language selection changes, the existing messages do not switch to the newly selected language. Only the new events are logged in the newly selected language.
