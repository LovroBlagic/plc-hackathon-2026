16.4.5 Changing User Languages in Alarm Banners

If you change the user language at run time, the language of alarm messages on all alarm banners also change. For information on how to change the user language at run time, see Section 20.2.8, Switching to a Different User Application Language.

If the language changes while an alarm message is currently scrolling across an alarm banner, the alarm banner goes blank, and the message restarts from the beginning in the new language. If more than one message is scrolling when the user language changes, then the messages restart from the first message.

The alarm banner's Display Message Property further controls the behaviour of alarm messages when the user language changes. For more information on Display Message properties, see Section 16.4.4, Ending Alarm Banner Messages.
