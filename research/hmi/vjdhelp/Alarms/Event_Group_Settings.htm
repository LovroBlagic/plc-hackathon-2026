16.2.4.2 Event Group Settings

  1. Create an event group. You can create event groups (records user actions), a system error group (records system error events), and a system event group (records system events).

  2. Right-click the event group to display the Event Group Settings window.

  1. Define the properties for the event group.

Property

Desccription

Event Group Name

The event group's name.

Whenever an event group is created, a default name is generated. When renaming an event group, its name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

For more information, see Appendix 9, Naming Conventions.

Output

Save to File

To output an event records to a .csv file, enable the Save to File check box and click the Configure button to display the Save to File dialog box. For more information, see Section 16.3.6, Outputting Alarms and Events to a .CSV File.

Batch Printing

To print event records, enable the Batch Printing check box and click the Configure button to display the Batch Printing dialog box. For more information, see Section 16.3.5, Printing Alarm and Event Messages.

Total Records

Use this field to set the maximum number of event records to be kept in storage. You can enter a value from 1 to 10,000.

When the number of records reaches the maximum number, the first record will be removed to save the newest record.

 

  • Events are recorded in both History and Log, which results in having two event records for each event that occurs. For example, if you set 10,000 as the maximum number of total records, you can only store 5000 event records.

Backup Records

Enter Yes to back up records in the storage location specified in the Record Storage property so that the records will not be deleted when Runtime shuts down.

Record Storage

This property is available if you entered Yes in the Backup Records property. Enter the storage location for the event records.

  • SRAM: Stores event records in the SRAM.

  • SRAM and File: Stores the event records in the SRAM until the number of records has been reached, as specified in the Records in SRAM property. Then the data in SRAM is stored in this location: \PUBLIC\PROJECTS\<target name>\DATA\SYSTEM\<event group name>\

Records in SRAM

This property is available if you entered Yes in the Backup Records property. If you selected SRAM and File in the Record Storage property, enter the number of records to be stored in SRAM.

If you selected SRAM in the Record Storage property, this property will be grayed out and the number of records in SRAM will be the same as the number specified in the Total Records property.

Severity

Specify the severity level, from 1 to 999, of all the records in the group. This is used when the summary displays the records sorted by severity.

Language

Available when multiple languages are set up in the Language node. Displays the records in the selected language.

Label

Defines the event group's name that displays in both the event summary's Group and Filter columns. You can define a different label for each of the available languages. You can enter up to 32 characters for each alarm group name.

Sharing

Defines the event group's sharing capabilities.

  • None: Event group data is not shared.

  • Read/Only: Event group data is read-only. Target clients can only view event data. Operations on a client target, such as ACK and Delete, are ignored.

  • Read/Write: Event group data is read/write. Target clients can read and write event data. Operations on a client target, such as ACK and Delete, are supported. For more information on event operations supported for remote categories, see Remote Category Key Points: Remote Alarm Operation Support.

Sharing is only available when Data Sharing is enabled on the target. For more information on enabling Data Sharing, see Section 4.5.1.5, Remote Access: Data Sharing.

Overwrite Text in All Languages

Available when multiple languages are set up in the Language node. Overwrites the text in all languages with the text defined in the Label. For more information, see Section 20.2, Switching Languages.

Copy Text to Empty Languages

Available when multiple languages are set up in the Language node. Copies the text defined in the Label to languages that do not have labels yet. For more information, see Section 20.2, Switching Languages.

Record Counter

Counts the number of records in the event record database. You will need to enable this property when the group is contained in an alarm category.

Select the check box to enable the field. Enter a variable or select one from the Variables List.

 

  • After a project with event groups has been downloaded, you cannot modify the properties for the event group unless the logged data on the target is deleted at the time of download. If you change any of the values in the event group properties without deleting the logged data on the target, the new values will be ignored and the existing values will continue to be used. Also a message will display to indicate the mismatch between the existing event group configuration and the downloaded configuration.
