16.3.6 Outputting Alarms and Events to a .CSV File

You can output alarms and events to a Runtime Data Location as a .csv file, which you can process using Microsoft Excel or other programs. For a list of Data Locations supported by each target series, see Appendix 5.11.2, Suppported Drives by Target Types.

The following diagram shows an example of alarms that output to the CF Card/SD Card as a .csv file from the target machine, and the alarm .csv file being copied to a folder on the editor PC.

  • When the Runtime Data Location is full, the .csv file cannot be saved. Make sure you have enough disk space.

  • You can use the Data Manager or the Command line to copy alarm files and event records from the target machine to a folder on the editor PC. See 20.5, Managing Run-time Data.
