16.3.4 Setting Up Alarm Actions

In the summary, you can set up actions for each alarm, such as switching panels, displaying pop up windows, running scripts, and so on.

There are two ways to run alarm actions.

  • Alarm Trigger Action
    The Alarm Trigger Action runs when an alarm is triggered.

  • Alarm Touch Action
    The Alarm Touch Action runs when the alarm message is selected. Touch actions run regardless of the state the alarm is in: Active, Acknowledged, Not Acknowledged, or Returned to Normal.

You can specify the following operations for alarm actions.

Bit

Set or reset bit addresses (BOOL variables).

Word

Define word address values (integer or REAL variables).

Scripts

Execute scripts.

Special

Run one of these operations: Previous Panel, Restart Runtime, Exit Runtime, Configuration, Play Sound, Stop Sound, Change Panel, Change Language (Runtime System), and Change Language (User Application).

Popup Window

Display popup windows, close popup windows.

Text Display

Display a text file within a text display part.
