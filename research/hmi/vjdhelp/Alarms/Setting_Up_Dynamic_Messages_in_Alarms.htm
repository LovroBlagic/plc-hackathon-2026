16.3.8 Setting Up Dynamic Messages in Alarms

To insert dynamic content into alarm messages:

  1. In the General tab of the Alarm Group Settings dialog box select the Dynamic Message check box to enable this feature. Alternatively, you can enable it in the Alarm Group properties.

  2. Select On Every State or On Active State as the trigger for updating the alarm’s dynamic message. When you select On Every State, the dynamic message updates on every alarm state change. When you select On Active State, the dynamic message updates only when an alarm becomes active.

  3. In the Alarm spreadsheet under the Message column, click the ellipsis to open the Alarm Message Editor.

  4. Right-click the text field to display the shortcut menu.

  5. Click Insert to open the shortcut menu.

  6. Select Time stamp or Variable.  

For more information on how to format placeholders, see Adding Dynamic Content in Section 21.1.5.12, Setting Up Messages with Dynamic Content.

For information on how to generate alarm messages in multiple languages, see Sections 20.2.7, Associating a Language with a Text Object or an Alarm.

  • You need secondary or optional drive space to store alarm messages with dynamic content when you enable alarm backup. The amount of additional space depends on the number of unique placeholders you use. The data location is specified by Runtime Data Location setting. For more information, see Appendix 5.11.1, Types of Data Locations.

  • When using dynamic messages in alarms, the size of your dynamic messages affects the maximum number of alarms. You must monitor the project's DRAM usage at run time before using the project in a factory setting.

  • When you use time stamps in alarm messages, the date and time is converted to the time zone of the target machine that is accessing the application. As a result, the same alarm message may show different date and time when viewed on target machines that are in different time zones.
