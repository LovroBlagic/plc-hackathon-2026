16.3.2.2 Displaying Multiple Diagnostic Alarm Groups in an Alarm Summary

By using an alarm category, you can display multiple alarm groups and multiple diagnostic alarm groups in the same alarm summary object.

In the following example, variable alarms are allocated to alarm groups AG1 and AG2. DiagAG1 is associated with Modbus (RTU) equipment and DiagAG2 is associated with Uni-Telway equipment.

Creating an Alarm and Event Category

  1. Right-click the Alarms and Events node, and select New Alarm and Event Category to display the Alarm and Event Category Settings dialog box.

  2. Select the groups and diagnostic alarm groups, and then click Add.

  3. Define the other Alarm and Event Category settings (see Section 16.3.1.2, Displaying Multiple Groups).

  4. After you complete the configuration, click OK. The Alarm and Event Category node is created with the selected groups.

Displaying the Alarms

  1. Draw an alarm summary on the panel and double-click it to display the Alarm Summary Settings dialog box.

  2. In the General tab, click the Alarm Group list, select the alarm category to link to the alarm summary, and click OK.

The alarm summary will now display alarm messages from the alarm category's alarm groups and diagnostic alarm groups, in sequential order. You can change the order using the Sort By setting.
