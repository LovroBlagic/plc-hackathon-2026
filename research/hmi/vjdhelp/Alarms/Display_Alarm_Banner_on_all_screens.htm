16.4.2 Global Alarm Banner

In the Target properties, you can configure the alarm banner so alarm messages scroll across every panel even in the middle of a change panel operation. Alarm banners can be set up to display in one of three positions: Top, Middle, or Bottom. When there are no alarm banner messages, the panel operates normally. You can use an alarm category to display messages from multiple alarm groups. The alarm groups can be from the same target.

  • You can only set one global banner display for each project.

  • When an error window is displayed, the banner is displayed at the bottom of the error window and its height is 20 pixels.

  • The alarm banner uses severity to determine the messages displayed.

  • If the Global Alarm Banner and the Active Event Viewer display at the same time, the Global Alarm Banner is appended to the bottom of the Active Event Viewer. For more information, see Section 28.1.1 Active Error Viewer: Global Alarm Banner and the Active Error Viewer display at the same time.

16.4.2.1 Steps to Set Up the Global Alarm Banner

Steps

1. Create an Alarm Group

2. Create variable and set up the alarm messages, alarm groups, and define other alarm parameters.

3. In the Target properties, enable the Alarm Banner.

 

16.4.2.2 Creating a Global Alarm Banner

  1. Create an alarm group to use with the alarm banner. See Section 16.2.4, Group Settings.

  • If you want to display an alarm banner message in only a few panels, use the alarm banner part. For more information, see Section 16.4.3, Local Alarm Banner.

  1. In the Variable Editor, double-click the variable's row number that the alarm banner uses. In the Variable Properties dialog box that opens, select the Alarm tab and select the Alarm check box.

  2. Specify the alarm group.

  1. The banner message can use the Trigger Action setting. For more information, see Section 16.3.4.1, Trigger Actions.

  2. Keep the number of alarms displayed on the alarm banner to a minimum. To do this, ensure the alarm group you specify only contains a minimum number of alarms (less than 20). If an alarm banner has to assemble a huge number of alarms for display, it results in a performance problem causing the panel to change slowly.

  1. In the Target node's properties, set Alarm Banner to Enabled and define the other alarm banner settings as required.

Property

Description

AlarmGroup

Select the alarm group or alarm category whose alarm messages are displayed in the alarm banner.

Position

Define the alarm banner position: Top, Middle, or Bottom.

Font

Click the ellipsis button to display the Font Editor dialog box where you can define the Language, Font, Font Style, and Font size of the alarm banner messages.

  • When the alarm banner is displayed at the bottom of the error window, the font height is always 16 pixels, despite your selection.

BackColor

Define the background and the text color of alarm banner messages.

TextColor

Display Message

You can end the alarm banner display using one of the three conditions:

  • Only Once

  • Stop when RTN

  • Stop when UNACK or RTN

  • Scroll to end when RTN

For more details on terminating conditions, see Section 16.4.4, Ending Alarm Banner Messages.

Scroll Rate

Banner alarm messages can scroll across the panel using one of three speeds:

Fast: 200ms

Medium: 400ms

Slow: 800ms

Move Button

Enables a move button for the alarm banner.

 

  • When you select Display Popup & Alarm Banner in the Object Information of the View menu, you can select Enable Object Info to enable or disable the global banner display in Vijeo-Designer. However, banner display parts are always displayed in Vijeo-Designer and cannot be changed using Enable Object Info.
