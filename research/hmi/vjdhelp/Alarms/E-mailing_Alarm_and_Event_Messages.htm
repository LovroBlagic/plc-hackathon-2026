16.3.7 E-mailing Alarm and Event Messages

You can configure the columns and format of the alarm and event records that will be embedded in an e-mail attachment. If you do not configure the Columns and Format tabs for the alarm records, the following default settings will apply:

  • Selected Columns: Date, Active Time, ACK Time, RTN Time, Message

  • Date Format: yy/mm/dd

  • Time Format: 24:00:00

  • Language: the active user language.

For more information on how to add an alarm record attachment to an e-mail, see Section 9.5.20, E-mail Operations.

 

Columns Tab

  1. In the Property Inspector for the Alarm & Event Groups node, click the ellipsis in the E-mail Attachment property.

  1. In the Columns Tab, set up the following:

Property

Description

Available Columns

Select the columns from the list. For more information on each column item, see Section 16.2.6.3, Columns Tab.

Selected Columns

Determine the display order of the columns for the alarm records output.

Field Delimiter

Select a value from the combo drop-down box to use as the separator of the data in each record.

 

Format Tab

In the Format tab of the E-mail Attachment dialog box, select the date format, time format, and language for the alarm records output.

Property

Description

Date Format

Select a date format from the list.

Time Format

Select a time format from the list.

Language

Select a user language set up in the target. If the selected language is deleted from the target, the language selection changes to the first language in the list.
