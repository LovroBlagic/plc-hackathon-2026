16.5 Alarm Alerts - Notifying Users of an Alarm

In addition to displaying alarm messages in an alarm summary display and scrolling them across panels using alarm banner, you can alert users of the alarm conditions by playing a sound file or changing the backlight color.

Depending on how you set up your system, you will probably want to output sound for critical alarms only. For information on how to set up alarms to emit sound, see Section 16.5.1, Setting Up Alarms to Play Sound Files.

Changing the backlight color is suitable for showing when there is an active alarm on the target machine. For information on how to change the backlight color, see Section 16.5.2, Changing the Backlight Color.
