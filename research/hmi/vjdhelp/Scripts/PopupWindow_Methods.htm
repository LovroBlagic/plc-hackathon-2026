18.9.1.3 Popup Window Methods

Use the following methods to interact with popup windows and popup window panels. 

Method

Description

changePanel

Changes the panel displayed in the popup window, using the panel ID as its parameter.

close

Closes the popup window.

getPanelID

Returns the ID number of the panel displayed in the popup window.

getStatus

Returns the status of a popup window.

Status

Description

0

Not open

1

Hidden

2

Open and displayed

move

Moves and resizes a popup window.

moveOffset

Moves a popup window relative to its current position.

open

Opens a window. The parameters determine the popup window position.

previousPanel

Changes to the previously displayed panel in the popup window.

show

Shows or hides a popup window that's open.

For information on how to set up and use popup windows, see Chapter 15, Popup Windows.
