18.3.5 Operators

Use the operators below to evaluate script expressions and statements.

  • Arithmetic

  • Prefix and Postfix

  • Comparison

  • Conditional and Logical

  • Bit

  • Assignment

Use the Add operator (+) to perform string concatenation. In other words, you can concatenate strings with the Add symbol, "Hello " + " " + "Billy" creates the string "Hello Billy".

Comparison Operators

These operators compare two values. The expression evaluates to true when the defined comparison is true. The expression evaluates to false when the defined comparison is false.

Operator

Expression

Description

>

X > Y

Greater than.

Returns true when X is greater than Y.

>=

X >= Y

Greater than or equal to.

Returns true when X is greater than or equal to Y.

<

X < Y

Less than.

Returns true when X is less than Y.

<=

X <= Y

Less than or equal to.

Returns true when X is less than or equal to Y.

==

X == Y

Equal to.

Returns true when X is equal to Y.

!=

X != Y

Not equal to.

Returns true when X is not equal to Y.

Conditional and Logical Operators

Operator

Expression

Description

&&

X && Y

Conditional AND.

Returns true when both X and Y are true.

Returns false when either X or Y is false.

Evaluates Y when X is true.

||

X || Y

Conditional OR.

Returns true when either X or Y is true.

Evaluates Y when X is false.

!

!X

Logical NOT.

Returns false when X is true.
Returns true when X is false.

&

X & Y

AND.
Returns true when both X and Y are true.

Always evaluates both.

|

X | Y

OR.
Returns true when X and Y are different (one is true and the other is false.)

Always evaluates both.

Bit Operators

Operator

Expression

Description

>>

X >> Y

Right shift. Shifts the bits in X, to the right, by the Y number of bit positions. Preserves the sign.

<<

X << Y

Left shift. Shifts the bits in X, to the left, by the Y number of bit positions. Preserves the sign.

>>>

X >>> Y

Zero fill, right shift. Shifts the bits in X, to the right, by the Y number of bit positions, and fills in shifted bits on the left with 0s, thereby not preserving the sign.

&

X & Y

Bitwise AND.

Returns result of AND operation at the bit level.

X

0 1 0 0

Y

1 1 0 1

Result

0 1 0 0

|

X | Y

Bitwise OR.

Returns result of OR operation at the bit level.

X

0 1 0 0

Y

1 1 0 1

Result

1 1 0 1

^

X ^ Y

Bitwise XOR.

Returns result of XOR operation at the bit level.

X

0 1 0 0

Y

1 1 0 1

Result

1 0 0 1

~

~X

Bitwise complement.

Flips the bits in the value X.

Assignment Operators

Operator

Expression

Description

=

Assign (X & Y) to X. True/false.

|=

Assign (X | Y) to X. True/false.

^=

X ^= Y

Assign (X ^ Y) to X. True/false.

<<=

X <<= Y

Shift bits in X left by Y bits, and assign value to X.

>>=

X >>= Y

Shift bits in X right by Y bits, and assign value to X.

>>>=

X >>>= Y

Shift bits in X right by Y bits, fill in with 0s, and assign value to X.
