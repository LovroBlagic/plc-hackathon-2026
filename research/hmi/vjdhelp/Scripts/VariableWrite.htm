write

Function

Enables the script to interact with Vijeo-Designer variables.

  • Before working with any external variables, you should check the data integrity (isDataQualityGood).

  • When you use this script method to write to the same external variable multiple times consecutively in a very short time span (less than 1 second), some of the write operations may be dropped to maximize communication efficiency. The final write operation is always performed.

  • If every single write operation to the external variable is required for the equipment to run correctly, use Bit and Word Write operations available in switches, text and message displays, bar and meter graphs, selectors, function keys, Touch animation, and variable alarm actions.

Format

void VariableName.write(boolean value);

void VariableName.write(int value);

void VariableName.write(float value);

void VariableName.write(String value);

void BlockVariableName.write(boolean value, int index);

void BlockVariableName.write(int value, int index);

void BlockVariableName.write(float value, int index);

void BlockVariableName.write(int[] valueArray);

void BlockVariableName.write(float[] valueArray);

Parameter

Parameter

Description

boolean value

Specifies the boolean value (true/false) to write to the variable.

The boolean value can be a local boolean variable or an expression that evaluates to true or false.

Parameter

Description

int value

Specifies the integer value to write to the variable.

The integer value can be a local int variable, a Vijeo-Designer variable value (retrieved using getIntValue(); ), or an expression that evaluates to an integer.

Parameter

Description

float value

Specifies the floating point value to write to the variable.

The floating point value can be a local float variable, a Vijeo-Designer REAL variable value (retrieved using getFloatValue(); ), or an expression that evaluates to a float.

Parameter

Description

String value

Specifies the string value to write to the variable.

The string value can be a local String variable, a Vijeo-Designer variable value (retrieved using getStringValue(); ), or an expression that evaluates to a String, such as a character or character array.

  • Make sure the number of characters in the string parameter does not exceed the capacity of the variable. Only the number of characters that can fit are stored in the variable, and the excess characters are dropped.

  • Use quotation marks to identify text strings.
    For example: StringVar.write("This is a text string");

  • When you use quotation marks or backslashes, you need to add a backslash [ \ ] when used in a text string.
    For example, to write the string "See Spot run" said Jane, the script is: StringVar.write("\"See Spot run\"said Jane");
    To write the string \\MyComputer, the script is: StringVar.write("\\\\MyComputer");

Parameter

Description

boolean value

Specifies the boolean value (true/false) to write to the element in a block variable.

The boolean value can be a local boolean variable or an expression that evaluates to true or false.

  • Writing to block variables does not update the values on the equipment. Use sendData( ) to write values from the target machine to the equipment.

int index

For block variables, specify the index position of the element that you are writing to. Element numbers begin with 0.

Description

int index
