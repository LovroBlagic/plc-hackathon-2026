write

Function

Sends the defined string as a bytestream to the defined communication port.

You can use the script driver read/write methods to run basic communications between the target machine and an equipment. That equipment can be a PLC, printer, or another target machine.

Format

boolean ScriptDriverName.write(

boolean clearBuffer,

int numOfBytes,

byte[] data );

Parameters

Parameter

Description

boolean clearBuffer

When true, clears the target machine's receive buffer (script driver buffer) of any data before transmitting.

  • Use this parameter when you expect a reply from the serial equipment. Set this parameter to true to remove all the data stored in the receive buffer, which makes it easier to parse any data that's received.

  • If the connected serial equipment is initiating the sending and receiving of data, then this parameter should be false — data in the script driver buffer is not cleared. There might be data that still needs to be read that was sent by the connected equipment.

int numOfBytes

Defines the number of bytes in the data transmission. You can write up to 1024 bytes of data in a single transmission.

  • Try to set up applications so you don't have to write large amounts of data. All operations on the target machine are blocked until the write operation is complete.

  • When writing 1024 bytes with a transmission speed of 19200 bps, the target machine ceases to run for 2 to 3 seconds.

byte[] data

Data sent to the communication port defined in the script driver.

Return Value

Returns true when the data is successfully written to the driver's buffer. Otherwise, returns false.

Comments

A true return value does not guarantee the data is successfully written to the device. A true return value only means the data is successfully written to the driver's buffer.

The write method blocks other operations from running while sending data over the serial port.

To use the script driver read/write methods, first you need to set up a script driver. See Section 18.8.3, Setting Up the Script Driver.
