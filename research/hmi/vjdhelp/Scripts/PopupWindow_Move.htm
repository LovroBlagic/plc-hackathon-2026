move

Function

Moves and resizes a popup window.

Format

boolean PopupWindowName.move(int X, int Y, int width, int height);

Top-left corner of panel is origin point (coordinates 0,0). Positive X values move window to the right, negative X values move window to the left. Positive Y values move the window down, negative Y values move the window up.

Parameters

Use the following parameters when working with this operation. All the parameters must be defined, even if you're just moving the popup window, or even if you're just resizing the popup window.

Parameters

Description

int X

Defines the coordinates of the popup window, relative to the left side of the graphical panel.

The target machine supports movement in 8 pixel intervals. If you define a move of 7 pixels, there is no movement.

int Y

Defines the coordinates of the popup window, relative to the top of the graphical panel.

int width

Value defines width of window.

The target machine supports window sizes in 8 pixel intervals.

int height

Value defines height of window.

The height defined here is the height of the popup window panel, without the title bar.

Return Value

Returns true when the move operation is successful.
