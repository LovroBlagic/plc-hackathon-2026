Sys.validateUser

Function

Checks the login user name and password of the operator who is authorizing a protected action or operation that requires approval before executing.

User names, passwords, and security levels are configured in the Security node. For more information on setting up security in your project, see Section 4.8, Setting up Security Protection for Targets and Projects.

Format

void Sys.validateUser(String UserName, String UserPassword, IntegerVariable SecurityLevel);

 

Parameters

Parameter

Description

UserName

The name and password of the operator who is authorizing the action or operation.

UserPassword

SecurityLevel

Use a Vijeo Designer integer variable to store the operator's security level, as output by this method.

At run time, the value written to the variable will be:

  • -1 or less: Indicates validation failed (for example, incorrect password).

  • Greater than 0: Indicates the user's security level when validation is successful.

The value in this variable will not return zero.
