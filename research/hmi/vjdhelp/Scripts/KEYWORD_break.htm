break

{

[statement1];

break;

[statement2];

}

Brackets [ ] indicate optional items. Keywords are bolded.

break exits the current block of statements, whether it be a block of case statements or a loop (for, while, do-while). In the script above, encountering break jumps out of the block, so statement2 is not run.

Example

In the example below, switch evaluates the expression "choice", then jumps to the matching case. When the break keyword is encountered, it exits the case statements.

int choice = 1;

String msg;

 

switch (choice)

{

case 1:

variable1.write(0);

break;

case 2:

variable1.write(1);

break;

}

In the next example, index is incremented by 2 at the end of each loop. The conditional expression index!=9 can never be false. If not for counter, the for statements would loop infinitely. Counter increments at every loop, and once it is greater than 10, the break keyword is encountered and the for loop is exited.

for (int index=0, counter=0; index!=9; index=index+2)

{

msg = "The current index is " + index;

counter++;

if (counter > 10)

break;

}
