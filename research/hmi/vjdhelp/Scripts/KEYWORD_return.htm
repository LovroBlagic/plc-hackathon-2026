return

[statements]

return;

[statements]

Brackets [ ] indicate optional items. Keywords are bolded.

return exits the script. Use return when you want to exit from the middle of script code.

Comments

None

Example

In the example below, switch evaluates the expression and executes the matching case statements. When the expression does not evaluate to any of these case values, the default is run, and when we encounter the return keyword, the script is exited.

int option=1;

 

switch (option)

{

case 1:

variable1.write(1);

break;

case 2:

variable2.write(2);

default:

return; // exit script

}

// more statements

In the example, case 1 breaks out of the switch and runs more statements; case 2 exits the script because it runs its case statements then runs the default statements.
