getMax

Function

For use with variables set up with an input range, this method returns the maximum value of the integer type or REAL variable's input range. Using this method, you can make sure the writes to the variable do not exceed the maximum value.

  • If this method is used with a variable that does not have a defined input range, the method will return the maximum value that the variable can store. See section 6.2.1, Variable Types for more information on variables.

Format

int IntegerVariableName.getMax()

float RealVariableName.getMax()

Return Value

Returns the variable's maximum value, as set up in the variable's input range.
