18.3 Writing Scripts

After adding the script and setting up the trigger, write the script in the script editor.

In the example script above, there are five basic components.

  • Script Variables. Variables declared and used locally in the script, for mathematical operations and conditional expressions.

  • Vijeo-Designer Variables. The Variable Editor lists the Vijeo-Designer variables. To use Vijeo-Designer variables in the script, get its value and assign it to a script variable.

  • Methods. Object-oriented programming term for function or subroutine. Methods are operations you can run on a given object.

  • Flow Control Keywords. Java keywords that control the flow of operations in Vijeo-Designer scripts. In addition to flow control, there are Java keywords that can add logic to your applications.

  • Operators. You can use operators to perform various mathematical, conditional, and assign type operations.

18.3.1 Basic Steps in Writing Scripts

  1. Declare script variables.
    See Section 18.3.2, Script and Variables.

  1. Use variable methods to get the value from Vijeo-Designer variables to script variables.
    See Section 18.3.2, Script and Variables.

  1. Use operators and flow control keywords to write the program that manipulates local script variables.
    See Section 18.3.5, Operators, and 18.3.6, Keywords.

  2. Use other objects and methods. If necessary, use the variable write method to assign results from script operations to Vijeo-Designer variables.
    See Section 18.3.2, Script and Variables, and 18.9.1, Vijeo Designer Methods.
