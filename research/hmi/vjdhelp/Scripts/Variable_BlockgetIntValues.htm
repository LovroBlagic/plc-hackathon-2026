getIntValues

Function

Enables the script to interact with entire Vijeo-Designer Block Integer type variables.

  • Before working with any shared or external variables, you should check the data integrity (isDataQualityGood).

  • After working with block variable values, use the write method to edit the block on the target machine, then use the sendData method to write values to the equipment.

Format

int[] BlockVariableName.getIntValues();

 

Return Value

Returns an integer array with all the elements in the Block Integer variable.
