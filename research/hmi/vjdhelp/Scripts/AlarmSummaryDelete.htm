delete

Function

The purpose of this script is to remove the alarm from the alarm list that is displayed by the alarm summary.

There are three alarm lists: Active, History, and Log. The alarm summary is associated with one of these lists. When you run the delete method on the alarm summary, it deletes the alarm from the associated alarm list. This operation is unlike the clear method, which deletes the alarm from all three alarm lists.

Another difference between the delete and clear methods is that the delete method, after an alarm is deleted, displays an alarm message when the alarm state changes (e.g. Hi to HiHi, Hi to Normal, and so on).

You can use a parameter to ensure only the specified alarm type is deleted.

  • When used with a diagnostic alarm group, this script method does not affect alarms in the PLC's diagnostic buffer. This script method interacts only with the alarm summary display. You can use this method on all alarm messages in history and log alarm displays, and on acknowledged alarm messages in active alarm displays.

Format

int AlarmSummaryName.delete(int Msg_State);

Parameters

Parameter

Description

int Msg_State

Specifies the type of alarm deleted in this operation.

0: Deletes the alarm message, no matter what state it's in.

1: Deletes an active or unacknowledged state alarm message.

2: Deletes a returned to normal (RTN) state alarm message.

3: Deletes an acknowledged state alarm message.

4: Deletes an active state alarm message.

5: Deletes an unacknowledged state alarm message.

Return Value

Returns an integer, 1 when the alarm is delete, 0 when the alarm isn't deleted.

See Also

clear, clearAll, deleteAll
