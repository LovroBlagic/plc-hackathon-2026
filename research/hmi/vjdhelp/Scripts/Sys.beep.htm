Sys.beep

Function

Forces the target machine to beep once. If you want multiple beeps, call this method multiple times.

Use the parameter to define whether to always beep when called or beep depending on the Buzzer setting in Target properties (which can also be set up in the Configuration menu's Touch Buzzer setting.)

Format

void Sys.beep(boolean ForceBeepOn);

Parameter

Parameters

Description

boolean ForceBeepOn

When the parameter is true, beeps when the method is called.

When the parameter is false, and in the Target properties Buzzer = Enabled, beeps when the method is called. If Buzzer = Disabled, then there is no beep when the method is called.

  • The configuration menu buzzer settings are None and When Press Touch Object, which correspond to Disabled and Enabled in the Target properties.

Return Value

None

Comments

Use this script method to program a beep. For example, you may want a beep when an alarm is triggered (alarm trigger action.)
