18.8 Using the Script Driver

The script driver is a generic serial communication driver that allows you to communicate with simple serial equipment. The script driver, along with the read and write Vijeo Designer methods, provides the means to send and receive bytestreams of data over the serial port.

For information about the structure and parameters of the read/write methods, see Section 18.8.2, Script Driver Methods.

Why Do You Need to Use a Script Driver?

The script driver is intended for simple serial communications, such as communicating with a Windows hyperterminal, sending messages to a printer, or sending messages to a Text Display equipment. On these remote equipments you can display important status information such as the current number of alarms, the number of widgets created, and remaining inventory.

Schneider Electric recommends you use the script driver for simple communications only.

  • Warning: If you run the script with a high frequency to read and write large numbers of characters to the script driver, you may force other parts of the runtime application to slow down.
