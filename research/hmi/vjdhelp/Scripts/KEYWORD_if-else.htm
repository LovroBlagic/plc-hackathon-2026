if-else

if (conditional expression)

{

[statements executed when conditional expression is true];

}

[else]

{

[statements executed when conditional expression is false];

}

Brackets [ ] indicate optional items. Keywords are bolded.

The expression used in if statements must return true or false. Unlike C syntax, numeric values do not evaluate to true or false.

if evaluates the conditional expression. When the expression returns true, it runs the block of statements after if. When the expression returns false, it jumps to the else statements if there are any.

Comments

if-else conditional statements can be embedded or nested. There is no preset limit on the number of levels.

Example

In the example below, local variables temp and normal get temperature values from the system. These values are then compared. The msg variable is assigned different strings when the comparison returns true and when it returns false.

int temp, normal;

String msg;

temp = FurnaceTemp.getIntValue();

normal = FurnaceNorm.getIntValue();

 

if (temp > normal)    // comparison

msg = "Temperature is too high";

else

msg = "Normal temperature";
