18.9.1.2 Alarm and Event Summary Methods

Use the following methods to interact with Alarm and Event Summary objects.

Method

Description

ack

Acknowledges the selected alarm in an alarm or event summary.

ackAll

Acknowledges all the active state alarms in an alarm or event summary.

An alarm summary displays the alarms belonging to an alarm group, so this command functions in a similar fashion as the alarm group's ack method.

clear

Removes the alarm selected in the alarm or event summary from the system.

clearAll

Clears all the alarms from the alarm database that are in the alarm summary's alarm group. This method can also clear all the events from the event database that are in the event summary's event group.

cursorUp

Moves the cursor up one row in an alarm or event summary.

cursorDown

Moves the cursor down one row in an alarm or event summary.

cursorOn

Displays the cursor on the first alarm or event in the summary display.

cursorOff

Removes the cursor from the alarm or event summary.

delete

Deletes the selected alarm or event from the database.

deleteAll

Clears all the alarms from the alarm summary, or clears all the events from the event summary.

jumpTo

Moves the cursor to the row in the alarm or event summary as defined by the parameter.

moveTop

Moves the cursor to the top alarm in the alarm or event summary.

moveBottom

Moves the cursor to the bottom alarm in the alarm or event summary.

pageUp

Moves the cursor one page up in an alarm or event summary.

pageDown

Moves the cursor one page down in an alarm or event summary.

showSubDisplay

Runs the touch action of the variable selected in the alarm or event summary row.
