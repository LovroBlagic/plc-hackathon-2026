Defining Device Address at Runtime

Describes how to set up a panel where you can define the data for multiple variables. Using variables assigned to device addresses D500 to D514, the sample script enables you to read and write data from multiple device addresses from a single control point.

If you use only data display parts, you'll end up placing a data display for each device address. Using scripts, you need only two data displays and two switches.

See Section 18.7.1, Defining Device Address at Runtime.
