getProperty

Function

Returns an integer array containing the values of the equipment's properties.

Format

int[] EquipmentName.getProperty(String param);

Parameter

Parameter

Description

String param

A string variable that has the setting information requested from the equipment.

  • The string parameters below work only if your device driver uses the corresponding communication settings. Please test your equipment to ensure operation.

Con_IPAddress

Returns an integer array containing the value of the equipment's IP address.

Con_DualRedundantIPAddress

Returns an integer array containing the value of the backup equipment's IP address. This parameter is useful when communication is broken between the primary equipment and the target, and you need the backup equipment's IP address.

Con_EquipmentAddress

Returns an integer array containing the value of the equipment's address.

Con_SlaveEquipmentAddress

Returns an integer array containing the value of the equipment's slave address.

  • This parameter is only supported for Modbus RTU.

Con_UnitNumber

Returns an integer array containing the value of the equipment's Unit Number.

  • This parameter is only supported for Modbus TCP/IP.

Con_LocalStationAddress

Returns an integer array containing the value of the local terminal's address.

Con_HardwareProtocol

Returns an integer array containing the value of the equipment's serial interface.

Example:

Return Value

Returns either an integer array for the equipment parameter, or null.
