Sys.setTime

Function

Changes the time on the target machine.

You can also change the time from the Configuration menu, but using scripts makes it possible to change the time while still running Vijeo-Designer Runtime.

Format

boolean Sys.setTime(int hours, int minutes, int seconds);

Parameters

Parameter

Description

int hours

First parameter defines the hours using a 24 hour clock. Parameter may contain up to two digits, and acceptable values are 0 to 23. 0 is equivalent to 12am midnight. If you define a value of 24, it changes to 0.

int minutes

Second parameter defines the minutes (0-59). Parameter may contain up to two digits.

int seconds

Third parameter defines the seconds (0-59). Parameter may contain up to two characters.

Use  –1 as any of the parameters to ignore that parameter.

Example:

Sys.setTime(12, 0, -1);

// set the hours to 12, minutes to 0, and do not change the seconds

Return Value

Value

Description

false

Failed to set the time on the target machine. Usually indicates invalid parameters, but may also indicate a communication error.

true

Successfully set the time on the target machine.
