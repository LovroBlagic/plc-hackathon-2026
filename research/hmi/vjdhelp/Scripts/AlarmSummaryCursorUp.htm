cursorUp

Function

Moves the cursor up one alarm in an alarm or event summary display. The parameter defines the type of alarm or event to move to.

Format

int AlarmSummaryName.cursorUp(int Msg_State);

Parameters

Parameter

Description

int Msg_State

Specifies the type of alarm or event the cursor moves to.

0: Cursor moves up one message.

1: Cursor moves up to the next active or unacknowledged state alarm message.

2: Cursor moves up to the next acknowledged state alarm message.

3: Cursor moves up to the next returned to normal (RTN) state alarm message.

4: Cursor moves up to the next active state alarm message. (Mandatory ACK only.)

5: Cursor moves up to the next unacknowledged state alarm message. (Mandatory ACK only.)

Return Value

The following return values indicate the results of the operation.

Value

Description

0

Operation is successful.

1

Cursor is off. Cursor must be on to use this operation.

2

Cursor cannot move up anymore. Cursor is at the top message.
