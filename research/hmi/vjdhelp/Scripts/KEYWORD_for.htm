for

for (initialize; conditional_expr; expression)

{

[statements];

}

Brackets [ ] indicate optional items. Keywords are bolded.

Comments

initialize Evaluated once to initialize variables.

conditional_expr Conditional expression that controls when to exit the loop. As long as this conditional expression is true, the for statements are repeated.

expression Evaluated after the for statements, and usually used to change the value of variables in the conditional_expr.

Use the break keyword to exit the loop prematurely, passing control to the statement after the for loop.

  • When using loops (do-while, for, while), be careful not to create an infinite loop. Infinite loops, which cannot be caught at validation, will cause the target machine to crash as more and more memory is used by the script.

  • If you use for loops in On Startup, On Panel Open, On Panel Close, Trigger Action, or Conditional scripts, and the script takes more than five seconds to complete, the script will be terminated so panel operations can continue.

  • If you use for loops in touch scripts, which include Touch animation, switches, On Touch Panel application scripts, and alarm touch actions, and the script takes more than five seconds to complete, the script will be terminated so touch panel operations can continue.

Example

Message repeats until the expression c <= 10 is false.

String msg;

 

for (int c=1; c <= 10; c++)

{

msg = "Current count is " + c;

}
