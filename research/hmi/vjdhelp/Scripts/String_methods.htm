18.9.2.2 String Methods

Vijeo-Designer supports these methods from the standard java.lang String class. Use String methods to compare strings, return the string length, return an edited string, among many other operations.

To use String methods, create a String variable then call the variable and method plus any parameters.

String stringVar1;   // declare String variable

boolean rv;

rv = stringVar1.startsWith("var"); // call String variable and method

                                   // Test if starts with "var"

To use String methods with a string variable from Vijeo-Designer's Variable List, get the Vijeo-Designer string variable and assign it to a local script variable.

String s = StringVariable.getStringValue();

 

Certain string methods require the string variable to be initialized before use.

String str = "";    // Initialize string before use
