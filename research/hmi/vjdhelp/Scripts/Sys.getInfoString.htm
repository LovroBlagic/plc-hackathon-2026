Sys.getInfoString

Function

The getInfoString() system method returns a string representing system information. getInfoString() will not continuously scan for data changes in the system information. You must request new values each time they are needed.

Format

String Sys.getInfoString(int param);

Parameters

Parameter

Description

int param

An integer variable or value that represents the information being requested.

  • APPLICATION_BUILD_DATE

  • APPLICATION_BUILD_TIME

  • BUILD_NUM

  • DEFAULT_GTWY

  • DEFAULT_GTWY_1

  • DEFAULT_GTWY_2

  • DNS_ADDRESS_1

  • DNS_ADDRESS_2

  • IP_ADDRESS_1

  • IP_ADDRESS_2

  • MAC_ADDRESS_1

  • MAC_ADDRESS_2

  • PROJECT_NAME

  • SUBNET_MASK

  • SUBNET_MASK_1

  • SUBNET_MASK_2

  • TARGET_NAME

  • TARGET_TYPE

  • VERSION_NUM

Examples (Ethernet 1 IP Address):

Sys.getInfoString(IP_ADDRESS_1)

Sys.getInfoString(IP_ADDRESS)

Examples (Ethernet 2 MAC Address):

Sys.getInfoString(MAC_ADDRESS_2)

Return Value

Returns a string with the requested system information.

Returns an empty string if the requested system information is unavailable or unsupported.

  • The value displayed by the getInfoString() method is the system information at Startup. That information will not be updated once the program is running.

  • getInfoString() is available in the expression editor for String Display, Action, and Switch.

  • When using the return value, for example in a String display part, make sure the part's Display Length is set to 100 to display all the characters. For return strings longer than 100 characters, only the first 100 characters are displayed.

  • getInfoString() always returns an empty string when used in Web Gate.
