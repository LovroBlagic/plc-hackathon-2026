add

Function

This method adds the specified parameter to the integer or REAL variable, making it ideal for increment and decrement type operations. Both positive and negative values can be added for addition and subtraction operations.

Format

boolean IntegerVariableName.add(int value);

boolean RealVariableName.add(int value);

boolean RealVariableName.add(float value);

boolean RealVariableName.add(double value);

Parameter

Parameter

Description

int value

Specifies the integer value to add to the variable.

float value

Specifies the real value to add to the variable.

double value

Specifies the double precision real value to add to the variable.

  • Integer type variables accept only int values as a parameter.

  • Real variables accept int, float, and double values as parameters.

Return Value

Returns true if the add operation is successful. Returns false if the add operation failed.
