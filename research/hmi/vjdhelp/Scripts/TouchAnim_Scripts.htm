18.2.1 Touch Scripts

Touch scripts are scripts that can run when the associated function key, switch, or touch-animated drawing is touched.

  • There are some drawings and object that cannot support Touch animation. For a list of objects that support Touch animation, see Section 8.1.2, Animation Supported by Objects.

  • If a touch script uses while or for loops, and takes more than two seconds to complete, the script will be terminated so touch panel operations can continue.

 

Adding Scripts to Switches

You can create a script and run it when a switch is touch. This requires you to create a switch with a script operation. For more information on creating switches, see Section 9.2, Creating Switches.

 

Adding Touch Animation Scripts

You can create a script and run it when a graphical object is touched. This requires you to add touch animation to a graphical object and then configure a script operation to run when the object is touched. For information on adding touch animation and setting up touch animation operations to graphical objects, see 9.2.7.1, Adding Touch Animation to an Object.

 

Adding Scripts to Function Keys

You can create a script and run it when a function key is pressed. Simply add a function key to your project and create a script operation for it. For information on how to add a function key to your project, see Section 24.5.4, Adding and Removing Function Keys. For more information on script operations, see Section 9.5, Operations.
