getMin

Function

For use with variables set up with an input range, this method returns the minimum value of the integer type or REAL variable's input range. Using this method, you can make sure any writes to the variable are not less than the minimum allowable value.

  • If this method is used with a variable that does not have a defined input range, the method will return the minimum value that the variable can store. See section 6.2.1, Variable Types for more information on variables.

Format

int IntegerVariableName.getMin()

float RealVariableName.getMin()

Return Value

Returns the variable's minimum value, as set up in the variable's input range.
