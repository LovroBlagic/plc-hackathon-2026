setLabel

Function

Enables the script to change the Recipe Label at Runtime to the value in the parameter.

  • Changing RecipeGroupNumber or RecipeNumber updates RecipeLabel. However changing RecipeLabel does not change the associated recipe, so RecipeGroupNumber and RecipeNumber remain the same.

  • RecipeLabel updates when the active language is changed in Runtime.

  • Any change to the Recipe Label must be saved with a save operation, or it will be lost when another recipe is loaded or the Runtime is rebooted.

Format

boolean RecipeControl.setLabel(String value);

boolean RecipeControl.setLabel(String value, int LanguageID);

Parameter

Parameter

Description

String value

Specifies the string value to write to Recipe Label.

  • If more than one language exists, the string value will be set to the recipe label of the current language.

Parameter

Description

String value

Specifies the string value to write to Recipe Label.

int LanguageID

Specifies the language ID.

Return Value

Returns true if Recipe Label was changed successfully.

Returns false if Recipe Label was not changed because of a data entry error.

  • The editor can validate the data type and syntax but not the value. Invalid data entry is handled at Runtime.
