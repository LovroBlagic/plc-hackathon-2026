18.9.1.6 Variable Methods

Use the following methods to interact with variables in the Variable List.

Method

Description

ack

Changes the state of the variable's alarm from active to Acknowledged.

add

Adds the defined parameter to the variable. Parameter values can be negative for subtraction, or positive for addition.

enableScaling

Defines the data conversion settings for external variables.

flushToStorage

Flushes variable history in the memory buffer to the Secondary Drive.

getIntValue

Returns an integer value of the Vijeo-Designer variable.

getIntValues

Returns an integer array when used with a Block Integer variable.

getFloatValue

Returns a real value of the Vijeo-Designer variable.

getFloatValues

Returns a real array when used with a Block REAL variable.

getMax

For use with variables set up with an input range, this method returns the maximum value of the integer or real variable's input range.

getMin

For use with variables set up with an input range, this method returns the minimum value of the integer or real variable's input range.

getSize

Returns the number of units (elements) in the block variable.

getStringValue

Returns a string value of the Vijeo-Designer variable.

isDataQualityGood

Returns true when the variable value can be trusted.

sendData

Writes the defined block variable values to the equipment.

setMinMaxValues

Defines the minimum and maximum values you can input from the target machine.

toString

Returns a String object of the name of the variable.

write

Writes the parameter value to the Vijeo-Designer variable.

X

Returns the value of an individual bit in an integer variable.

XW

Writes to an individual bit in an integer variable.
