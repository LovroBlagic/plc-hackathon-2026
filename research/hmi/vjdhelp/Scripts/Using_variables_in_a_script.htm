18.3.2.2 Using Variables in Scripts

To use a Vijeo Designer variable in a script, you should first get its value and assign it to a script variable. You can then use the script variable in any expression.

  1. Declare a script variable.
    Make sure it's a data type that can support the Vijeo Designer variable.

int x = 0;

Vijeo Designer Variable

Supported Script Data Types

BOOL

Normally use boolean.

You can also use int, long, float, or double.

INT, UINT, DINT, UDINT, Integer

Normally use int.

You can also use long, float, or double.

REAL

Normally use float.

You can also use double.

STRING

Use the String class.

 

E.g. String a = "Vijeo Designer String";

For information on how to set up script variables, see Section 18.3.2.1, Declaring Script Variables.

  1. Get the value of the Vijeo Designer variable, and assign it to the script variable.
    At the end of the get method, make sure you add brackets ( ) then a semicolon ; .

x = LineA_Output.getIntValue();

The getValue method you use depends on the data type you want to work with. The following table lists the most probable methods you would use with each Vijeo Designer variable data type.

  1. Use the local script variable.

if (x  <= 10 )

  • To get the value of a BOOL variable, use the getIntValue() method.

  • Each Vijeo Designer variable supports methods to return its value as an integer, real, or string.

Example:
The value of Vijeo Designer integer variable LineA_Output is 561.

LineA_Output.getIntValue( ) returns 561

LineA_Output.getFloatValue( ) returns 561.0f

LineA_Output.getStringValue( ) returns "561"

  • When using the get value method for Vijeo Designer variables, you can use the shortcut menu to select the variable and variable method.
