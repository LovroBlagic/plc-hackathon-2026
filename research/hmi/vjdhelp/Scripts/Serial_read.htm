read

Function

Reads the bytestream from the defined communication port.

You can use the script driver read/write methods to run basic communications between the target machine and an equipment. That equipment can be a PLC, printer, or another target machine.

Format

int ScriptDriverName.read(

int timeout,

int numOfBytes,

byte[] data );

Parameters

Parameter

Description

int timeout

Specifies the length of time the read method waits for data before it stops. For most purposes, the timeout should be zero.

  • When there is no data to read from the serial port, the script driver waits for the defined timeout period. During the timeout, the script blocks other operations of the same type from running, which could cause operator inputs to be ignored or delay periodic scripts. Use the timeout only when you have a specific need for a timeout.

  • Do not specify a long timeout if you expect data may not be available for reading.

  • For information about the side effects of using a timeout, see Section 18.8.1, Important Points About the Script Driver.

int numOfBytes

Defines the expected number of bytes in the bytestream.

  • The maximum amount of data you can read is 1024 bytes. To read more data, run the read method again.

  • The numOfBytes and the number of elements in the byte array should be the same. If numOfBytes is larger, then you might read more data than can be stored.

byte[ ] data

Storage area for the bytestream. When you read data from the serial port, it's stored in this byte array.

  • When referring to data in the array, remember that array element references begin at 0.
    So, to read the eighth byte in the bytestream, use data[7].

Return Value

Returns the number of bytes received. The value (0) means either an error has occurred or nothing is read.

  • The maximum return value is numOfBytes. Even if the script driver buffer contains more data, numOfBytes defines the maximum number of bytes that is read.
    For example, if there are 110 bytes of data in the script driver buffer and numOfBytes is 100:

  • reads 100 bytes

  • return value is 100

  • 10 bytes remain in the script driver buffer.

If there are 10 bytes of data in the script driver buffer and numOfBytes is 10:

  • reads 10 bytes

  • return value is 10

  • 0 bytes remain in the script driver buffer.

Comments

To use the script driver read/write methods, first you need to set up a script driver. See Section 18.8.3, Setting Up the Script Driver.
