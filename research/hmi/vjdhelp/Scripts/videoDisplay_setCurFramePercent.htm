setFrame

Function

Moves the video playback to the defined location.

Format

void VideoDisplayName.setFrame(int value);

Parameter

Parameter

Description

int value

Integer value (0-100) that defines where the video playback is moved to.

 

0 = Start of Video

100 = End of Video

Return Value

None
