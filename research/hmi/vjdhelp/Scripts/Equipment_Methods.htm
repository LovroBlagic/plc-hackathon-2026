18.9.1.10 Equipment Methods

Use the following methods to interact with the equipment.

Method

Description

commitConfig

Saves the modified IP address to SRAM and resets the Ethernet connection. You do not need to restart the target machine for the changes to take effect.

getProperty

Returns an integer array containing equipment property values.

getStringProperty

Returns a single string that contains either the name of the equipment driver or the start address of the Dialog Table.

openConfig

Opens the equipment's configuration settings.

setProperty

Writes the specified property setting to the equipment's SRAM.

 

Example

The following examples show how to configure slave addresses and an equipment IP address using equipment methods. For more examples, see Section 18.7.3, Defining Equipment IP Address at Run Time.

 

Configuring Modbus RTU Equipment

int[] slaveAddress = {255};

ModbusEquipment01.openConfig();

ModbusEquipment01.setProperty("Con_SlaveEquipmentAddress", slaveAddress);

ModbusEquipment01.commitConfig();

 

Configuring Modbus Slave Equipment

int[] slaveAddress = {255};

ModbusSlaveRTU01.openConfig();

ModbusSlaveRTU01.setProperty("Con_EquipmentAddress", slaveAddress);

ModbusSlaveRTU01.commitConfig();

 

Configuring Modbus TCP Equipment

int[] ipAddress = {192, 168, 1, 10};

ModbusEquipment01.openConfig();

ModbusEquipment01.setProperty("Con_IPAddress", ipAddress);

ModbusEquipment01.commitConfig();
