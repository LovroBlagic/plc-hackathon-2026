deleteAll

Function

This script method removes all the alarm messages displayed in the alarm summary. The method can also remove all the event messages displayed in the event summary. The method's parameters define the types of alarms or events removed from the summary display.

If you assign an Alarm Summary to an Alarm Category, the deleteAll script method resets the Current counter. If you assign an Alarm Summary to an Alarm Group, the deleteAll script method does not reset the Current counter.

The deleteAll method should not be confused with the clearAll method. The clearAll method removes messages from the summary display and the message database. Another difference between deleteAll and clearAll is that messages removed by deleteAll can appear again in the summary if the message’s state changes (e.g. Hi to HiHi, Hi to Normal, and so on). Messages removed by clearAll will not appear in the summary again unless the message becomes active.

  • When used with a diagnostic alarm group, this script method does not affect alarms in the PLC's diagnostic buffer. This script method interacts only with the alarm summary display. You can use this method on all alarm messages in history and log alarm displays, and on acknowledged alarm messages in active alarm displays.

Format

int AlarmSummaryName.deleteAll(int Msg_State, int Disp_State);

Parameters

Parameter

Description

int Msg_State

Specifies the type of alarms or events deleted in this operation.

0: Deletes all alarm or event messages, no matter what state they're in.

1: Deletes all active or unacknowledged state alarm messages.

2: Deletes all returned to normal state alarm messages.

3: Deletes all acknowledged state alarm messages.

4: Deletes all active state alarm messages.

5: Deletes all unacknowledged state alarm messages.

int Disp_State

Specifies the range of alarms deleted in this operation.

0: Deletes all the alarm messages in the alarm summary display.

1: Deletes only the visible alarm messages in the alarm summary display. In other words, the alarms on the current page.

Return Value

Returns an integer, which is the number of alarms that were deleted in this operation.

See Also

clear, clearAll, delete
