18.9.1.7 DiagBuffer Methods

Use the following methods to interact with the status messages stored in .sto files associated with the curerntly selected diagnostic alarm. For information about diagnostic alarms, see Section 16.3.2, Diagnostic Alarm Groups.

Method

Description

decodeStatusWords

Returns the .sto file status messages associated with the selected alarm.

updateStatusWords

Retrieves the current status word values associated with the selected alarm.

getDfbName

Returns the .sto filename associated with the selected alarm.

getStatusWords

Returns an integer array that stores the status words associated with the selected alarm.
