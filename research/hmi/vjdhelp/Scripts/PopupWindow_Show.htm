show

Function

Shows or hides the popup window.

Format

boolean PopupWindowName.show(boolean Status);

Parameters

Parameter

Description

boolean Status

Shows (true) or hides (false) the popup window.

Return Value

Returns true when the show or hide operation is successful.

Comments

Vijeo-Designer Runtime supports the display of up to three popup windows at a time. Hiding a popup window is not the same as closing it. If three popup windows are open, you must close and not just hide one of them before you can display another popup window.

After opening a popup window, use show( ) to display the window frame, and changePanel( ) to display the popup window panel.
