18.3.2 Script and Variables

When working with Vijeo-Designer scripts, there are two types of variables:

  • Vijeo-Designer variables

  • Script variables

Variables created in Vijeo-Designer cannot be used directly in script expressions. To use a Vijeo-Designer variable in a script, use the variable's get value method and assign the result to a local script variable. You can then use the script variable in script control statements, mathematical operations, and other script expressions.

  • When using Vijeo-Designer variables in scripts, the value must be assigned to a local script variable. The Vijeo-Designer variable is independent of the local script variable, and their values could be different. This could cause problems, especially with external variables, because the Vijeo-Designer variable value can change in the middle of a script process, while the script continues to work with the previous variable value.

Script Variable Name

The following limitations apply to script variable names.

  • Script variables are case-sensitive. For example: Int01 and int01 are considered two different variables.

  • Cannot use a number as the first character in a script variable name.

  • Cannot use Java and Vijeo-Designer keywords as a script variable name.

  • Cannot use the names of Vijeo-Designer variables as a script variable name.

Initializing Variables

After declaring the local script variable, good programming practice is to initialize its value.

In particular, before you can use the script variable in a comparison, the variable must be assigned a value.

String variables are also required to be initialized before use in certain Java string methods.

The following example illustrates the importance of initializing script variables.

int a,b=0;        // Only b is initialized to 0

if(a==0)          // CanNOT compare, a is undefined

if(b==0)          // Compare with 0

     String str = "";  // Initialize string before use

 

End of Statement Marker, the Semicolon (;)

At the end of every statement, make sure you add a semicolon (;). Without the semicolon, the script will not pass validation and will produce syntax errors.

Examples of variable declarations

short a;        // short

int b = 0;      // integer initialized to 0

long c, d=0, e; // 3 variables of type long, d initialized to 0

char f[];       // character array

char[] f = new char[100]; // character array with 100 elements
