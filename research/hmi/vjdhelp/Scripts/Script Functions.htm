18.9.1 Vijeo Designer Methods

In object-oriented programming languages, method is the term applied to functions. Methods are associated with a distinct object and perform operations on that object.

Using the methods provided in Vijeo-Designer scripts, you can automate processes based on changes in variable values and other events.

To call a method, name the object and method plus any parameters, as shown in the following example:

objectName.method( parameter1, parameter2, ...);

In Vijeo-Designer scripts, there are a limited number of objects that provide methods you can use.
