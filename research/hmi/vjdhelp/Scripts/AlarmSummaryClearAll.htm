clearAll

Function

The purpose of this script method is to remove a message completely from the system.

The clearAll script method clears all the alarms in the current alarm summary display, or clears all the events in the current event summary display. Clearing removes all instances of these alarms from all alarm lists (Active, History, and Log).

The variables remain in the alarm state, but their associated alarm messages do not appear anymore in any alarm summary display. Even if alarms change states, such as from Hi to HiHi, these alarm messages will not appear.

This behavior is a result of forcing the alarms to a returned to normal state. As a result, an alarm message can only be generated again after the alarm returns to normal. Returned to normal alarms cannot be cleared by the clearAll script method.

Use a parameter to ensure only the specified alarm type is cleared.

  • When used with a diagnostic alarm group, this script method does not affect alarms in the PLC's diagnostic buffer. This script method interacts only with the alarm summary display. You can use this method on all alarm messages in history and log alarm displays, and on acknowledged alarm messages in active alarm displays.

Format

int AlarmSummaryName.clearAll(int Msg_State, int Disp_State);

Parameters

Parameter

Description

int Msg_State

Specifies the type of alarms cleared in this operation.

0: Clears all active, ACK, and UNACK state alarm messages in the alarm summary. RTN state alarm messages are not cleared.

1: Clears all acknowledged state alarm messages.

int Disp_State

Specifies the range of alarms cleared in this operation.

0: Clears all the alarm messages in the alarm summary display.

1: Clears only the visible alarm messages in the alarm summary display. In other words, the alarms on the current page. For log alarm summary displays and the Msg_State = 0, also removes any active, acknowledged, or unacknowledged alarms associated with the cleared alarms.

  • When you clear an alarm, its state changes to returned to normal (RTN) and runs associated alarm actions.

When Alarm Behavior = Optional ACK:

  • Clearing the alarm runs actions set up with the Condition = When alarm returns to normal.

  • When the alarm is in the active state, clearing the alarm also runs actions set up with the Transition = Active to RTN.

  • When the alarm is in the ACK state, clearing the alarm also runs actions set up with the Transition = ACK to RTN.

When Alarm Behavior = Mandatory ACK:

  • Clearing the alarm runs actions set up with the Condition = When alarm returns to normal.

  • When the alarm is in the active state, clearing the alarm also runs actions set up with Transition = Active to ACK, and Transition = ACK to RTN.

  • When the alarm is in the ACK state, clearing the alarm also runs actions set up with the Transition = ACK to RTN.

  • When the alarm is in the UNACK state, clearing the alarm runs actions set up with the Transition = UNACK to RTN.

Return Value

Returns an integer, which is the number of alarms that were cleared in this operation.
