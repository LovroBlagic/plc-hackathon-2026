Sys.setTargetIPAddress

Function

Available on single and dual LAN target machines that support Ethernet. Changes the target machine's IP Address, Subnet Mask, and Default Gateway at run time.

  • Windows-based target machines (such as iPCs and HMIG5U) do not support IP address change at run time and cannot run the Sys.setTargetIPAddress script.

Format

boolean Sys.setTargetIPAddress (String IP, String subnet, String gateway, Constant);

Parameters

Parameter

Description

String IP

The new Target IP Address. The value is a string in a four-octet decimal format, enclosed in double quotation marks.

String subnet

The new Subnet Mask. The value is a string in a four-octet decimal format, enclosed in double quotation marks.

String gateway

The new Default Gateway. The value is a string in a four-octet decimal format, enclosed in double quotation marks.

Constant

Specifies Ethernet 1 or Ethernet 2. Valid entries are:

  • Blank = Ethernet 1

  • ETHERNET_1 = Ethernet 1

  • ETHERNET_2 = Ethernet 2

Examples (Ethernet 1):

The following examples change the original Target IP Address to 10.187.230.100 and set it to Ethernet 1. The Subnet Mask and Default Gateway, with no new string values in the double quotation marks, remain unchanged.

Sys.setTargetIPAddress("10.187.230.100", "", "");

Sys.setTargetIPAddress("10.187.230.100", "", "", ETHERNET_1);

Example (Ethernet 2):

The following example changes the original Target IP Address to 10.187.230.100 and sets it to Ethernet 2. The Subnet Mask and Default Gateway, with no new string values in the double quotation marks, remain unchanged.

Sys.setTargetIPAddress("10.187.230.100", "", "", ETHERNET_2);

Return Value

Returns TRUE when the Target IP Address is set successfully. Value is set to the _IPAddressStatus variable.

Returns FALSE when the Target IP Address fails to set (for example, when DHCP is set to Enabled or there is no network connection).
