18.7.2.2 Script Operation

Displaying popup windows is easiest when you use switches or Touch animation. But there may be scenarios when you want something else to trigger the display of a popup window. That's when you use scripts.

In the following script, the popup window displays when a variable value changes. The variable changes as a result of an alarm that is triggered.

  • You can use alarm trigger actions (see Section 16.3.4 Setting up Alarm Actions) to set up the same functionality as described in this example. However, with alarm trigger actions you have to set up the same operation in each and every variable. If you have 100 alarms, you have to set up 100 alarm trigger actions. This example enables you to set it up once so that it runs for multiple alarms.

18.7.2.3 Setting Up Variables and Popup Window

Variables

Name

Description

Error

BOOL array variable, with 11 elements, used to track which alarms are triggered.

Assign device addresses (00100 to 00110) to each array element.

Error[0] = 00100 ... Error[10] = 00110.

AlarmsActive

Internal BOOL variable.

When any element in the Error variable turns ON, AlarmsActive is turned ON.

This variable acts as the display trigger for the popup window.
