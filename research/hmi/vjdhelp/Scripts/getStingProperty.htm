getStringProperty

Function

Returns a single string containing the name of the equipment's driver or the start address of the Dialog Table.

Format

string EquipmentName.getStringProperty(String param);

Parameter

Parameter

Description

String param

A string variable that represents the setting information requested from the equipment.

  • Con_Protocol

  • Con_DialogTable_StartAddress

Example:

ModbusEquipment01.getStringProperty("Con_Protocol");

Return Value

Returns a string containing the equipment information. Or returns an empty string.

See Also

commitConfig, getProperty, openConfig, setProperty
