setProperty

Function

Writes the specified property setting to the equipment's SRAM. The new setting comes to effect once you restart the equipment or use the commitConfig method.

  • This script method does not validate the parameter values written to the equipment. We recommend that you use the getProperty() method to make sure that the correct values are written.

Format

boolean EquipmentName.setProperty(String param, int[] value);

Parameter

Parameter

Description

String param

This parameter identifies what part of the equipment you are setting up.

This parameter must be defined with one of the following strings:

  • "Con_IPAddress"

  • "Con_SlaveEquipmentAddress"

  • "Con_UnitNumber"

  • "Con_DualRedundantIPAddress"

  • "Con_EquipmentAddress"

Use "Con_IPAddress" to define the equipment's IP address.

Use "Con_SlaveEquipmentAddress" to define the equipment's slave address. (Modbus RTU only)

Use "Con_UnitNumber" to define the equipment's Unit Number. (Modbus TCP/IP only)

Use "Con_DualRedundantIPAddress" to define the equipment's backup IP address.

Use "Con_EquipmentAddress" to define the equipment's address for Modbus Slave.

  • Setting the equipment's IP address to 1.1.1.1 puts the equipment into Offscan mode. For more information on Offscan, see Section 5.3, Collecting Driver Statistics.

int [ ] value

Integer array with four elements used to define the equipment's IP address or slave address.

  • When the IP address is 192.168.1.10, the IP address values in the array are as follows: array[0]=192, array[1]=168, array[2]=1, array[3]=10.

  • In the Con_EquipmentAddress string array, the first element is the Equipment ID.

  • The Con_SlaveEquipmentAddress parameter is only available for Modbus RTU.

 

Example

See the example scripts in 18.9.1.10 Equipment Methods.

Return Value

Returns true if the setting exists and if the value can be written to SRAM.

Returns false if the setting does not exist or if the value cannot be written to SRAM.
