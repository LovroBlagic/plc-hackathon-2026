Sys.clearAllDataLoggingInMemory

Function

Clears all Data Logging data from the target's SRAM or DRAM. This method does not clear the Data Logging data saved to external media. Once the data is cleared, Trend Graphs monitoring this data will be update and cleared. When clearing Data Logging data from SRAM, a NO_DATA record will be recorded with the current system time to the Data Logging file.

Format

void Sys.clearAllDataLoggingInMemory()

 

Return Value

None
