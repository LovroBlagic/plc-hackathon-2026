18.3.3 Array and Structure Variables

18.3.3.1 Using Vijeo-Designer Array Variables in Scripts

When you want to work with a Vijeo-Designer variable array, use square brackets [ ] to denote the array element. Otherwise you can work with Vijeo-Designer variable array elements like you would any other variable.

The following example illustrates how to use a constant or a variable to identify the array element.
