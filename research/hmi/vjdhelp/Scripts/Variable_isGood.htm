isDataQualityGood

Function

Enables you to check the integrity of external variables. Variables associated with equipment could contain values that have not been updated as a result of communication errors.

You can use this method to check the integrity of variable values, especially if the variable is used to initiate other processes.

  • Before working with any shared or external variables, you should check the data integrity.

Format

boolean VariableName.isDataQualityGood();

Return Value

Returns true when the variable value is current.

Returns false when a communication or other type of error has occurred. The variable value is now out of date.

Example 1:

if (Integer01.isDataQualityGood())

{

// Quality is good

value = Integer01.getIntValue();

}

else

{

value = -1;

}

 

Example 2:

boolean quality = Integer01.isDataQualityGood();
