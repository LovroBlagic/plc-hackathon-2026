18.8.5 Example: Sending Messages to a Text Display

Using the script driver and the read and write methods, you can communicate with virtually any serial device.

In the following example, an alarm is triggered and displays on the target machine. The target machine also sends the alarm message to a marquee text display so everyone on the factory floor can view the alarm.

Before Writing the Script

  1. Add the script driver and rename it Text_Display.
    See Section 18.8.3, Setting up the Script Driver.

  2. Connect the equipment to the defined COM port.
    See Section 18.8.4, Cable Connections.

Writing the Script

  1. In the variable's alarm properties, click Trigger Action, then add the Script function to display the Script Editor.

  1. Write script to send an alarm message to the COM Port, and ultimately to the text display.

// 1. Create script variables

// For working with alarm message and message length

char[] sendToDisplayTMP; // temporary char array

byte sendToDisplay[];    // byte array for write op.

int numOfChar = 0,       // string length

i, j;

 

// alarm message

String alarmMsg = "Emergency FIRE Zone 12";

 

// 2. Calculate alarm message length

numOfChar = alarmMsg.length();

sendToDisplay = new byte[numOfChar];

 

// 3. Convert UNICODE alarm message into ASCII bytes

sendToDisplayTMP = alarmMsg.toCharArray();

for (i = 0; i < numOfChar; i++)

{

sendToDisplay[i] = (byte)sendToDisplayTMP[i];

}

 

// 4. Send message

Text_Display.write(true, numOfChar, sendToDisplay);

 

1. Create script variables

Create local script variables for working with the alarm message. The character array and byte array will store the alarm message and the length of the alarm message. The various integer variables are required as temporary storage for values.

The next line is the alarm message that we want to show in the marquee text display.

2. Calculate alarm message length

Get the number of characters in the alarm message and create a byte array with the same size. Note that Strings and characters in Vijeo-Designer use UNICODE. The byte array will store the actual alarm message sent to the text display.

3. Convert UNICODE alarm message into ASCII bytes

Convert each UNICODE character in the character array into a byte and assign it to the corresponding element in the byte array. Each of these bytes is equivalent to an ASCII character.

  • This example assumes the text display supports ASCII characters only.

4. Send message

Finally, send the message to the serial port.

At runtime, when the alarm is triggered, the script outputs the message "Emergency FIRE Zone 12" to COM1. Connected to COM1 is a marquee display, which then displays the message.

  • You cannot send a String directly to the script driver. First convert the String to a byte array.

  • If your serial equipment requires start and end control characters, add them to the byte array.

  • If writing to a printer or other serial equipment, you can also send control characters in the byte array. E.g. Carriage return, bold, new page.
