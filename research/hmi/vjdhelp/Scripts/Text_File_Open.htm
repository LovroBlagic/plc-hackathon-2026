TextFile.open

Function

Opens the text file specified as the parameter. The filename is the alias of the text file.

Format

int TextFile.open(string filename);

Example

See the example scripts in 18.9.1.11 File Methods.

Return Value

Return Value

Description

0

File opened successfully.

1

File is not found.

2

Another file is currently open.

3

File cannot be opened.

 

See Also

TextFile.readLn, TextFile.close
