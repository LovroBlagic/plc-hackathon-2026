Sys.getInfoInt

Function

The getInfoInt() system method retrieves an integer value representing system information based on the parameter passed to the method. getInfoInt() will not continuously scan for data changes. You must request new values each time they are needed. The value is retrieved as an integer.

Format

int Sys.getInfoInt(int param);

Parameters

Parameter

Description

int param

An integer value that represents the information being requested.

  • TOTAL_DRAM_USAGE
    Returns the target's total DRAM usage.

  • FREE_KBYTE_SECONDARY
    Returns in kilobytes the amount of free space available on the target's secondary drive.

  • FREE_KBYTE_OPTIONAL
    Returns in kilobytes the amount of free space available on the target's optional drive.

  • FREE_KBYTE_MAIN
    Returns in kilobytes the amount of free space available on the target's main drive.

  • HMI_APPLICATION_CHECKSUM
    Returns the application checksum. This parameter is only supported when the Check Project Integrity property is enabled in the target's properties. For more information, see Section 4.5.1, Target Properties.

  • STATION_NUMBER
    Returns the ID of the Junction Box connected to the XBTGH target. This parameter is only supported for XBTGH targets connected to a Junction Box.

Example:

Sys.getInfoInt(TOTAL_DRAM_USAGE)

Return Value

Returns 0 or -1 if the property is not supported by the target machine.

Other Return Values:

  • TOTAL_DRAM_USAGE - Integer value between 0 - 2,147,483,648KB - returns 0 if memory value is less than 1KB

  • FREE_KBYTE_SECONDARY - Integer value between 0 - 2,147,483,648KB - returns 0 if memory value is less than 1KB

  • FREE_KBYTE_OPTIONAL - Integer value between 0 - 2,147,483,648KB - returns 0 if memory value is less than 1KB

  • FREE_KBYTE_MAIN - Integer value between 0 - 2,147,483,648KB - returns 0 if memory value is less than 1KB

  • HMI_APPLICATION_CHECKSUM - 32 bit unsigned integer value.

  • STATION_NUMBER - Integer value between 0-255.

  • getInfoInt() is available in the expression editor for Numeric Display, String Display, Message Display, Selector, and Switch.

  • When used in a Data Display part, the information value will not be automatically updated. You must refresh the panel (for example, via a panel change) to get the latest value.

  • When using the return value, for example in a String display part, make sure the part's Display Length is set to 100 to display all the characters. For return strings longer than 100 characters, only the first 100 characters are displayed.

  • getInfoInt() always returns 0 when used in Web Gate.

  • The station number ID is defined by the Junction Box's Rotary Switches. For more information on the Junction Box Rotary Switches, see the Junction Box manual which is available from the Vijeo Designer DVD.

  • Application checksum can also be retrieved using an operation. For more information, see Section 9.5.13.2, Checksum.

  • Station number can also be retrieved using an operation. For more information, see Section 9.5.13.1, Station Number.
