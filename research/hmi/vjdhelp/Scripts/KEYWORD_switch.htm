switch-case-default

switch (expression)

{

case literal01 :

[statements executed when expression equals value1];

[break];

case literal02 :

[statements executed when expression equals value2. ];

[default] :

[statements executed when none of the case values match the expression];

}

Brackets [ ] indicate optional items. Keywords are bolded.

The switch expression must evaluate to an int or char. Use literal values to identify case statements.

switch evaluates an expression then jumps to the case that matches the expression value.

If the evaluated value is not represented in any of the case values, then it jumps to the default statements if they exist, or exits the switch block if they don't exist.

case statements are run one after another until the break keyword, or the end of the switch block. Either scenario exits the switch statements.

Comments

Each case uses a literal value, which includes integers and characters. Note that characters evaluate to a number.

Although the default keyword is optional, using it in every set of case statements is a good programming practice.

Example

In the example below, switch evaluates the expression "option", jumps to the matching case, then writes a value to variable1.

char option;

switch (option)

{

case 'a':

variable1.write('b');

break;

case 'b':

variable1.write('c');

break;

case 'c':

variable1.write('d');

break;

default:

variable1.write('a');

}
