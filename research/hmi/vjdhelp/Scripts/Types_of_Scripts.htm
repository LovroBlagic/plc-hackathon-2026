18.2 Types of Scripts

There are three types of scripts: Panel, Touch, and Alarm. Select the script that works best for when you want the script to run, and for what you want the script to do.

Run the Script:

Use:

When a specific panel is open

Panel Script

When you want to run the script only when the associated panel is open, use panel scripts.

For more information on how to create a panel script, see Section 9.4, Creating Actions.

When an object is touched

Touch Script

When you want to run the script when an object is touched, or when a function key is touched, use a touch script.

There are three ways to set up touch scripts: add Touch animation to an object and add a script operation, draw a switch and add a script operation, or add a script operation to a function key.

  • When working with touch scripts, because the script editor is a dialog box, to add [Tab] spaces, press [Ctrl]+[Tab].

When an alarm occurs

Alarm Scripts

When you want to run the script when an alarm occurs, in the associated variable set up an alarm trigger script.

  • When working with alarm trigger scripts, because the script editor is a dialog box, to add [Tab] spaces press [Ctrl]+[Tab].
