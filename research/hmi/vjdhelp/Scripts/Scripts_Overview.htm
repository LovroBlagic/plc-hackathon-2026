18.1 Programming with Scripts

A Vijeo-Designer script contains instructions written by experienced users to program how the target machine reacts to real-time events, such as: a touch, a panel change, or a change in value. The main reason for using Vijeo-Designer scripts is because the programming operation is not possible using either parts or animation. Another reason to use scripts is you can use external source variables in script operations to add a programming dimension that may not be available in the equipment program.

Vijeo-Designer Scripts and Java

Vijeo-Designer scripts are based on the Java programming language. You can use a portion of the Java classes and methods, in addition to Vijeo-Designer specific methods. Although there are some differences (see Section 18.3.4 Key Points) between Java and Vijeo-Designer scripts, for the most part you can use operators and objects just as you would programming in Java.

Structure

There are two parts to scripts: the Trigger and Coded Instructions.

Trigger

The trigger defines when the script is run. The triggers are different depending on the type of script.

Instructions

Instructions refer to the actual script, as viewed in the script editor.
For details, see Section 18.3 Writing Scripts.

Set up the trigger and instructions for your scripts in the following order.

Steps

1. Create a new script. There are three types: Panel, Touch, and Alarm.

2. Set up the trigger.

3. In the script editor, write the coded instructions that are run when the script is triggered.

4. Validate the script.
