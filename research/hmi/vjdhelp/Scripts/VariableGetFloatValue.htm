getFloatValue

Function

Enables the script to interact with Vijeo-Designer variables. BOOL, Integer type, and REAL variables can return a float value.

  • Before working with any shared or external variables, you should check the data integrity (isDataQualityGood).

Format

float VariableName.getFloatValue();

float BlockVariableName.getFloatValue(int index);

Parameter

Parameter

Description

int index

For block variables, specify the index position of the element that you are getting the data from. Element numbers begin with 0.

  • After working with block variable values, use the write method to edit the block on the target machine, then use the sendData method to write values to the equipment.

Return Value

Returns the value of a Vijeo-Designer REAL variable.

Returns 0 when you access a block variable element that's out of bounds.

  • There is no way to check between a good value of 0 or a bad value (array index out of bounds) of 0. The panel displays a runtime event message to indicate an invalid access to a block variable has been made, but there is no way to automate this check.

  • When using scripts to get the value of a specific element in a block variable, and the index you specify does not exist, the script will simply return the value "0". Check to make sure index accesses in scripts to a block variable are run correctly.
