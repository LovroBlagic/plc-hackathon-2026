18.9.2 Java Methods

18.9.2.1 Math Methods

Vijeo-Designer supports the following math methods from the standard math class.

To use these methods in a Vijeo-Designer script, name the Math package and method plus any parameters, as shown below.

Math.method(parameter1, parameter2, ...);

Example:

Math.sin( double(Var1.getIntValue( )) );

For more details about each method above, please refer to standard Java documentation.

  • Java uses double precision values for most Math methods and Vijeo-Designer scripts can also work in double precision. However, Vijeo-Designer variables support single precision only.
    When writing a double to a Vijeo-Designer float variable, behind the scenes the script typecasts the value to a float, which may cause loss of data and precision.

double d = Math.sin(90);

Float01.write( d );

// d is typecasted

// Float01.write( float(d) );
