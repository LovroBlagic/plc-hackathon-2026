18.9.1.4 Sound Methods

Using Sound methods, you can play sound files (.wav, .daf) on the target machine. You can play one sound file at a time.

  • Not all target machines support the playing of sound files. Refer to your target machine manual to check if it supports sound files.

Method

Description

Sound.play

Plays the sound file once.

Sound.loop

Repeats playing the sound file.

Sound.stop

Interrupts and stops playing any sound files.
