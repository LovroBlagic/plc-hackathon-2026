18.5 Editing Scripts

When writing scripts, editing commands are available in the right-click menu.

  • You can Cut, Copy, Paste, or Delete highlighted blocks of text.

  • You can Undo or Redo any operation, if you've made an error.

  • You can use the Find/Replace command when searching the script.
    Find/Replace operates on the current script only. If you want to run the same Find/Replace operation on other scripts, in the Find/Replace dialog box select the desired find/replace options from the drop-down list.
