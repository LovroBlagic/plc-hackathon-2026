while

while (conditional expression)

{

[statements executed when conditional expression is true];

}

Brackets [ ] indicate optional items. Keywords are bolded.

Comments

Statements are repeated so long as the conditional expression evaluated by while is true.

Use break to exit the block of statements.

The difference between while and do-while loops is when the condition is tested. while loops check the conditional expression before running any statements, and do-while runs the statements at least once before checking the conditional expression.

  • When using loops (do-while, for, while), be careful not to create an infinite loop. Infinite loops, which cannot be caught at validation, will cause the target machine to crash as more and more memory is used by the script.

  • If you use while loops in On Startup, On Panel Open, On Panel Close, Trigger Action, or Conditional scripts, and the script takes more than five seconds to complete, the script will be terminated so panel operations can continue. This does not include periodic scripts.

  • If you use while loops in touch scripts, which include Touch animation, switches, On Touch Panel application scripts, and alarm touch actions, and the script takes more than two seconds to complete, the script will be terminated so touch panel operations can continue.

Example

Message displays over and over again until value is greater than or equal to 10.

int counter=0, value=0;

String msg;

 

while (value <= 10)

{

++counter;

msg = "Current count is "+counter;

value++;

}
