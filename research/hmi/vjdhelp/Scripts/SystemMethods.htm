18.9.1.5 System Methods

Use the following methods to interact with the target machine system.

Method

Description

beep

Overrides the Buzzer setting and enables the target to beep.

clearAllDataLoggingInMemory

Clears all the Data Logging data from SRAM or DRAM.

clearBiometricSwitch

Clears the content of the Biometric Switch at run time.

createProcess

Starts an application program on the target machine from the script.

exitRuntime

Exits the runtime application.

flushAllDataLogging

Moves all Data Logging data from the memory buffer to permanent storage.

getInfoInt

Retrieves the requested system information as an integer value.

getinfoString

Retrieves the requested system information as a string value.

getLastFieldRequested

Retrieves the field ID of the last display object to have its input mode turned on.

getLastFieldUpdated

Retrieves the field ID of the last display object to have enter pushed on its keypad.

isPlatform

Checks whether the script is running on the target machine (HMI) or in a browser (Web Gate).

removeProcess

Terminates an application program started up with createProcess.

login

Logs a user into the target machine.

logout

Logs out the current security user.

setDate

Changes the date on the target machine clock.

setTargetIPAddress

Changes the network settings (Target IP Address, Subnet Mask, Default Gateway) at run time.

setTime

Changes the time on the target machine clock.

validateUser

Checks the login user name and password of the operator who is approving a protected action or operation.
