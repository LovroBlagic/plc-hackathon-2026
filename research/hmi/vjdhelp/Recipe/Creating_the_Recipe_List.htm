17.4.1.5 Creating the Recipe List Part

The Recipe List part displays the recipes of the Recipe Group currently loaded in Vijeo Designer Run Time. This part is for display purposes only. The Recipe Group displayed by the part is controlled by the Recipe Control selected in the part's RecipeControl property. For more information on Recipe Controls, see Section 17.3.5, Setting Up Recipe Controls.

To add the Recipe List:

  1. Click the Toolchest icon in the menu bar to open the Toolchest window.

  2. Select the Recipe folder.

  3. Move the Recipe part onto a panel using the drag and drop operation.

  4. In the part's properties, define the properties for the part. The following table lists the part's properties:

Property

Description

Name

The Recipe List's name.

Whenever an object is created, a default name is generated. When renaming an object, its name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

For details, see Appendix 9, Naming Conventions.

Description

Describes the purpose of the part. This property is read-only.

Version

This property is read only and displays the editor version that created the part.

Top

The coordinates, in pixels, of the top-left corner of the object.

  • Top is measured from the top of the object to the top of the panel. Enter a value from –32768 to (32767 minus object height).

  • Left is measured from the left side of the object to the left side of the panel. Enter a value from –32768 to (32767 minus object width).

By changing these properties, the graphical object can be moved up, down, left, and right.

Left

Width

The width and height of the object in pixels. You can change the width and height of the object by editing these properties.

Height

RecipeControl

Select the Recipe Control variable that defines the Recipe Group displayed in this part. The Recipe Control's RecipeGroupNumber variable defines which Recipe Group is displayed in the part.

ListScrollButtonSize

Set the size (large or small) of the arrow button.

  • When you change the scroll button size, the change will not be shown in the Editor. To view the size change of the buttons, you must run simulation or download the project to a target.

  • When you change the size of scroll buttons from small to large, the size of the Recipe part will not change, just the size of the scroll buttons. As a result, the larger buttons may shorten the text fields next to them. To accommodate the larger button size, you may want to make the Recipe part larger, or shorten recipe names or ingredient names to ensure they fit in the shorter text fields.

DisplayFont

The font type applied to the object.

For details about supported fonts and sizes, see Appendix 5, Hardware Specifications.

TextColor

Defines the part's font color.

RestoreDefaults

Restores all values to the default settings.
