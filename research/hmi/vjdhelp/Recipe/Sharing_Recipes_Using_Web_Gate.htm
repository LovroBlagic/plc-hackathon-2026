17.6.8 Sharing Recipes Using Web Gate

Recipes can be shared between a target machine server and a Web Gate client. For information on Web Gate, see Section 23.2, Monitoring Target Machines with Web Gate.

Recipe data is stored on the target machine server. A Web Gate client connects to the server and views the recipe data. The client can then make an adjustment to the recipe using a recipe Toolchest part or recipe control variable. After the adjustment, the client saves the changes to the data on the server using the recipe Save operation.

  • The data sharing property for recipe ingredient variables is always enabled in Web Gate.

Since recipe data is always stored on the target machine server, recipe operations behave differently when run on a Web Gate client compared to when they are run on the server.

Recipe Operation

Behavior on a Web Gate Client

Send

Downloads the recipe data displayed on the Web Gate client to the PLC. Send does not save recipe data changes onto the target machine server before downloading to the PLC. You must perform a save operation to save the recipe data to the target machine server.

Snapshot

Displays the PLC's recipe data on the Web Gate client. You must perform a save operation to save the recipe data to the target machine server.

Load

Displays the selected recipe data on the Web Gate client.

Save

Saves the recipe data from the Web Gate client to the target machine server.

Delete

Deletes the recipe data on the target server.

Compare to Equipment

Compares the recipe data on the PLC to the recipe data shown on the Web Gate client.

 

  • For variables assigned to ingredient values in a recipe group, set the Sharing property to None. If the Sharing property is set to Read/Write or Read Only, in Runtime the bad quality icon displays beside the ingredient values when Load or Snapshot is used in Web Gate. After Load or Snapshot is applied from Web Gate, you will not be able to send recipes from Web Gate or Runtime. The message "Invalid Recipe" displays in the Error Status
