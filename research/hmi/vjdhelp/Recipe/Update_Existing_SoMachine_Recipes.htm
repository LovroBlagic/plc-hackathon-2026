17.6.10.2 Update Existing SoMachine Recipes

The following instructions describe how to update existing SoMachine recipes with new values using the SoMachine Recipe Manager part during run time.

  1. Select the Recipe Definition of the recipe you want to update.

  1. Select the Recipe Name.

  1. Select an ingredient value that you want to change.

  1. Enter the change you want to make to the ingredient value.

  1. Press the Apply button to update the recipe on the controller.
