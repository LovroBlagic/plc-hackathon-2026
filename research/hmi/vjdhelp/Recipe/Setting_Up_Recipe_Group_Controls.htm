17.3.5 Setting Up Recipe Controls

In the Editor, you can define a set of recipe control variables to monitor and control one or more recipe objects during Runtime operations. You can create Recipe Controls for each Vijeo Designer project and Parison Controls for each Parison Graph.

You can use the recipe controls set up in the Editor to manipulate the associated recipe object in Runtime. Recipe control variables are internal variables that you can assign as Read From and Write To variables. For more information, see Section 17.3.5.2, Using Recipe Controls to Automate Your Processes. For information on how to manipulate the recipe object in Runtime, see Section 17.6, Working with Recipes at Runtime.

17.3.5.1 Recipe Control and Parison Control Variables

Each Recipe Control and Parison Control set contains these recipe control variables:

  • RecipeGroupNumber - an integer variable that controls which recipe group will be used during the operation. A recipe group is a unique number ranging from 1 to 65535. An equipment, script, or touch animation may control this variable.

  • RecipeNumber - an integer variable that controls the current recipe used during the operation. A recipe number is a unique number ranging from 1 to 65535. A zero value indicates that a recipe is not in use.

  • RecipeLabel - a string variable that retrieves the current recipe label of the active language to display in a Recipe part. The variable is read-only and set in Runtime whenever RecipeGroupNumber or RecipeNumber are changed.

  • Write To Variable must be a string variable otherwise an error message will appear.

  • In String Display, if you select RecipeLabel as the Variable and Enable Input Mode is enabled, a warning appears stating that Input Mode will be disabled. Otherwise, Enable Input Mode is grayed out.

  • Operation - an integer variable that controls recipe object operations, and transmits recipes to and from the equipment. If the values match, the status variable is set to Comparing Match. If the values do not match, the status variable is set to Comparing Mismatch.

 

  • Bits 1 (Snapshot) and 3 (Save) can be ON at the same time. The Snapshot operation runs first and the Save operation begins when Snapshot is complete.

  • Other than the combination of bits mentioned above, if more than one bit is ON or an invalid value is entered, the operation will be in error.

  • OperationsLock - an integer variable that controls whether the Send operation is available. The bit in the variable indicates whether the operation is locked.

  • If the bit is on, the operation is locked, preventing data from being sent to the equipment.

  • If the bit is off, the operation is unlocked.

  • Status - each bit in this integer variable indicates the recipe's current operation status. Multiple bits can be on at a time.
    Recipe controls set the value in the status variable to indicate the current activity being performed. Depending on what Clear Option you select, the value in the status variable may not change until another operation is performed, or until you reset its value using parts, scripts or equipment program. See Section 17.3.5.3, How the Clear Option for Recipe Controls Work (Timing Charts).

  • Error - integer variable that receives error codes when an error occurs during a recipe group operation in Runtime.
    Recipe controls set the value in the error variable to indicate the error. Depending on what Clear Option you select, the value in the error variable may not change until another operation is performed, or until you reset its value using parts, scripts or equipment program.   • AccessRight - an integer variable that specifies the access right of the current user. The bits in the Access Right control variable and the bit values in the Recipe Access Right determine if the user can run recipe operations. For the current user to work on Recipe operations, a bitwise AND operation between the Access Right control variable and the Recipe Access Right must equal the Recipe Access Right. (See example, below.)

Access Right

0000 0101 0010 0110

Recipe Access Right

&  0000 0100 0000 0100

Result (bitwise AND)

0000 0100 0000 0100
 

In the above table, the current user can work with the Recipe because the bitwise AND result is the same value as the Recipe Access Right. For information on access rights, see Section 17.8, Setting Up Security for Recipes. For information about bitwise AND operations, see Section 18.3.5, Operators: Bit Operators.

  • ParisonMasterPointTag - This is only used in Parison Recipe Groups. It is a read-only integer variable that defines the number of master points in the Parison Graph.

    • You cannot use Parison Recipe Groups with normal Recipe Controls and vice versa.
