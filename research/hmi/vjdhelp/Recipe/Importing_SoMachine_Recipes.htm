17.3.6.5 Importing SoMachine Recipes

Recipe files exported from SoMachine can be imported into Vijeo Designer using Vijeo Designer's Recipe Import. Some SoMachine recipes and recipe ingredients may not be fully compatible with Vijeo Designer recipes. Be aware of the following information when importing SoMachine recipes:

  • The Min and Max settings for SoMachine recipes that use variables will be ignored.

  • Vijeo Designer creates the SoMachine recipe ingredient variable as an internal variable and sets the imported recipe ingredient to this variable. Be aware of how SoMachine variable types are brought into Vijeo Designer variable types. For more information, see Section 4.13.2.,1 Using SoMachine Variables in Vijeo Designer: SoMachine Variable Types to Vijeo Designer Variable Types.

  • Ingredient variables that are sub-elements of an array or structure are created as a single variable in Vijeo Designer.

  • The following characters in variable names will be converted to underscores "_": dots ".", commas ",", brackets "[]".

  • An imported variable whose name conflicts with an existing variable will have "_00" appended to its name to make it unique.
