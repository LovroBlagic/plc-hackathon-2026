17.3.4 Editing a Recipe Group

The Recipe Group Editor window, resembling a spreadsheet, displays all the contents for a recipe group. Use this window to define or modify the ingredients list, recipes, and other values for a recipe group. You can also use this window to import recipes from a .csv file and export the recipe group and recipes to a .csv file. The changes you make in the Recipe Group Editor are saved when you save your project.

In the following example, Great Pizza Works has defined specific ingredients to create different pizza recipes, such as pepperoni, ham and pineapple, and vegetarian. The ingredients list for the recipe group, Toppings, includes: pepperoni, ham, pineapple, cheese, mushrooms, red peppers, spinach, onions, and green peppers.

Using the Recipe Group Editor

  1. Select the recipe group you want to edit.

  1. In the Recipe Group Editor window, modify properties for an existing recipe group or define the properties for a new recipe group.

The following tables list the Recipe Group Editor properties.

Left Pane

Property

Description

Recipes

Displays the recipe values. To add a new recipe, click the New Recipe icon. Click to select a recipe from the Recipes list and to display it in the Recipe Group editor. To display more than one recipe and the ingredients' values, hold the Control key and click to select the desired recipes. Ingredient values for selected recipes are displayed in a column.

Values that you enter should be within the defined Min and Max range. Invalid recipe values are displayed in red.

Labels

Displays the recipe label in the active language. When the Recipe Labels view is expanded, all the languages are displayed for the recipe labels.

Click to expand the Recipe Labels view, where you can manage IDs, assign the access right for each recipe, and display the recipe labels in different languages.

  • Recipes: Displays the recipe names, but only in the Editor. At Runtime, the target machine displays the name according to the language assigned to the recipe. You can enter up to 32 characters for each recipe name.

  • ID: Displays a unique recipe ID. You can enter a value from 1 to 65535.

  • Access Right: Indicates the access rights for the recipe. Enter a value from 0 to 65535.

  • Language: Displays the recipe name as it will appear in Runtime.

Click to return to the original Recipe Labels view.

Right Pane

Property

Description

Ingredient Variable

Displays a list of variables associated with an ingredient. Creating a recipe group will not automatically generate ingredient variables.

To create an ingredient variable, right-click in the right pane and select Add New Ingredient, or click the New Ingredient icon . Each row displays a variable for a single ingredient, with the exception of block variables. When you add a block variable, each element in the block is added as an ingredient.

Click to open the Expression Editor Pad, where you can select an existing variable or create a new variable. For more information, see Section 6.2.2, Creating Variables.

  • The Ingredient Variable Name is not displayed at runtime in the Recipe Manager or other recipe list objects. The Label property stores the string displayed at runtime. If the application is set up with multiple languages, each language can use a different label for each ingredient.

Label

Displays the ingredient name that is presented to the panel operator. The label can be up to 32 characters long.

Click to expand the view, where you can change an ingredient label for multiple languages. In the following example, the labels are for three languages: English, French, and Spanish.

Editable

Select if you want the ingredient to be editable in Runtime. Clear the check box if you want the ingredient to be fixed. Block variables are set up as a complete block. This setting is not available for individual addresses in the block.

Min

Specify the minimum and maximum values for the ingredient. The values entered here controls the values that the operator can enter for the ingredient value in Runtime. These settings are not available for BOOL, string, or block variables.

  1. Use the right-click menu in the right pane of the Recipe Group Editor to work with recipe ingredients.

  • Add New Ingredient - Creates an ingredient variable. This menu item is available when the total number of ingredients is less than or equal to 1024. If the total number exceeds 1024, the menu item is disabled.

  • Insert New Ingredient - Adds a new blank row in the ingredient table.

  • Move/Drop - Moves one or more selected consecutive rows in the ingredient list and places the rows in another location in the ingredient list. You cannot move individual block variable elements. You have to move a block variable and its elements as a unit. The move/drop operation is cancelled when you interrupt the operation with other operations, such as adding new ingredients, delete ingredients, and when you click outside of the Recipe Group Editor window.

  • Delete Select Ingredient(s) - Removes a selected ingredient variable. You can select and delete multiple ingredient variables.
