17.8.2 Using the Access Right as a Recipe Group or Recipe Filter

You can use the Recipe Group or Recipe access right as a filter in Recipe lists. The filter works the same way as recipe security access, and is best described using an example.

Given the following Recipe Group and Recipe access rights, recipe list objects display only those that are allowed by the current User access right. For information on how to calculate access rights, see Section 17.8, Setting Up Security for Recipes.

Different User access rights affect which Recipe Groups and Recipes are available for selection.

If User Access Right = 0

If the User access right is zero, then the only things the user can view are items with an access right of zero. Since all the Recipe Groups and Recipes have an access right greater than zero, none of these items are visible.

 

If User Access Right = 3

Recipe Groups

Recipe Groups with access rights of 3 (Dough and Toppings) are visible. The Sauce Recipe Group is hidden because its access right is 5.

Recipe Group Access Right Calculation

The access right to Dough and Toppings (3) equals the User access right (3).

User = 3

0000 0000 0000 0011

Recipe Group = 3

&  0000 0000 0000 0011

Result (bitwise AND) = 3

0000 0000 0000 0011

The Result of the bitwise AND operation (3) equals the Recipe Group access right (3).

The access right to Sauce (5) is greater than the User access right (3). In all instances, if the access right to an item is greater than the User access right, then access is denied.

User = 3

0000 0000 0000 0011

Recipe Group = 5

&  0000 0000 0000 0101

Result (bitwise AND) = 1

0000 0000 0000 0001

The Result of the bitwise AND operation (1) does not equal the Recipe Group access right (5).

Recipes

After selecting the Dough Recipe Group, select the recipe.

Recipes with access rights of 3 (Thin Crust and Deep Pan) are visible. The Special Recipe is hidden because its access right is 7.

Recipe Access Right Calculation

The access right to Thin Crust and Deep Pan (3) equals the User access right (3).

User = 3

0000 0000 0000 0011

Recipe = 3

&  0000 0000 0000 0011

Result (bitwise AND) = 3

0000 0000 0000 0011

The Result of the bitwise AND operation (3) equals the Recipe access right (3).

The access right to Special (7) is greater than the User access right (3).

User = 3

0000 0000 0000 0011

Recipe  = 7

&  0000 0000 0000 0111

Result (bitwise AND) = 3

0000 0000 0000 0011

The Result of the bitwise AND operation (7) does not equal the Recipe access right (7).

 

If User Access Right = 7

Recipe Groups

Recipe Groups with access rights of 3 (Dough and Toppings) and 5 (Sauce) are visible.

Recipe Group Access Right Calculation

The User access right (7) is greater than the Dough and Toppings access right (3).

User = 7

0000 0000 0000 0111

Recipe Group = 3

&  0000 0000 0000 0011

Result (bitwise AND) = 3

0000 0000 0000 0011

The Result of the bitwise AND operation (3) equals the Recipe Group access right (3).

The User access right (7) is greater than the Sauce access right (5).

User = 7

0000 0000 0000 0111

Recipe Group = 5

&  0000 0000 0000 0101

Result (bitwise AND) = 5

0000 0000 0000 0101

The Result of the bitwise AND operation (5) equals the Recipe Group access right (5).

Recipes

After selecting the Dough Recipe Group, select the recipe.

Recipes with access rights of 3 (Thin Crust and Deep Pan) and 7 (Special) are visible.

Recipe Access Right Calculation

The User access right (7) is greater than the Thin Crust and Deep Pan access right (3). If the ON bits for the User access right match the ON bits for the Recipe access right, then access is accepted.

User = 7

0000 0000 0000 0111

Recipe = 3

&  0000 0000 0000 0011

Result (bitwise AND) = 3

0000 0000 0000 0011

The Result of the bitwise AND operation (3) equals the Recipe access right (3).

The User access right (7) and Special Recipe access right (7) are equal.

User = 7

0000 0000 0000 0111

Recipe  = 7

&  0000 0000 0000 0111

Result (bitwise AND) = 7

0000 0000 0000 0111

The Result of the bitwise AND operation (7) equals the Recipe access right (7).
