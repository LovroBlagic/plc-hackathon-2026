17.4.1.2 Creating Recipe Operation Buttons

Recipe operation buttons are switches that use the values in the Operation Control variable to perform specific recipe operations: Select, Load, Send, Compare, Snapshot, Save, and Delete.

  1. Click the Toolchest icon in the menu bar to open the Toolchest window.

  2. Select the Recipe folder.

  3. Move the Recipe part onto the panel using the drag and drop operation.

The part is displayed on the panel.

  1. Double-click the part to open the Switch Settings dialog box. The following Operation is set up to use the default recipe control. If you need to change the recipe control, you can do so in the General tab of the Switch Settings dialog box (below). For more information, see Section 9.2, Creating Switches.

  • Operations are performed in the order that they appear in the operation list.

  1. If necessary, customize the look, shape, and label for your switch. For more information, see Section 9.2, Creating Switches.

  2. Click OK. A switch to trigger the operation is created.
