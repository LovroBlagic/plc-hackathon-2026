17.6 Working with Recipes at Runtime

After downloading recipes to the target machine, you can perform the following recipe operations at runtime.

17.6.1 Steps to Operate a Recipe at Runtime

Steps

1. Select the recipe group and recipe to view on the target machine or send to the equipment.

2. If you load the recipe, you can then change recipe data on the target machine or compare the original with the modified data.

3. Send the data to the equipment.

4. If recipe data is modified on your equipment, you can then get a copy of these values on the target machine.

5. When the recipe data changes on either the target machine or on your equipment, you can, if required, save the recipe data to the recipe group file, then upload the recipe to the Editor.
