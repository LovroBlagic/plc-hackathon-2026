17.6.10.1 Create new SoMachine Recipes

The following instructions describe how to create a new recipe using the SoMachine Recipe Manager part during run time.

  1. Select the Recipe Definition that you want to create the recipe for.

  1. Select the recipe name whose ingredient values you want to copy to the new recipe.

  1. Change the selected recipe's name to the name of your new recipe.

  1. Touch the Save button to save the new recipe to the controller.
