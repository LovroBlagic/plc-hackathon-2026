17.6.5 Comparing Recipe Data

You can compare the current recipe values on the equipment with the values displayed on the target machine that are stored in memory. If the values match, the status variable is set to Bit 2=ON (Compare Match). If the values do not match, the status variable is set to Bit 3=ON (Compare Mismatch). The information from the compare operation, whether it is a Compare Match or Compare Mismatch, is displayed in Runtime.

This section describes how, at Runtime, you can perform a Compare operation using objects displayed on the target machine.

Select a recipe group and recipe on the target machine, then perform the Compare operation.

  • If the two sets of values match, the Status display and Text display will display the Compare Match information.

  • If the two sets of values do not match, the Status display and Text display will provide you with the Compare Mismatch information.

  • Ingredient values currently displayed on the target machine are not affected by the Compare operation.
