17.8 Setting Up Security for Recipes

Access right is a security feature that prevents unauthorized personnel from editing or viewing recipe ingredients and recipe groups. The current user's access right is determined by a Recipe Control variable: AccessRight.

When determining if a user can view recipes and recipe groups, or run recipe operations, AND the binary value of the AccessRight control variable with the binary value of the Recipe or Recipe Group Access Right. If the result is the same as the Recipe or Recipe Group Access Right, then the user has access. If the result is different, then the user is denied access.

For information about bitwise AND operations, see Section 18.3.5, Operators: Bit Operators.

Access Accepted

In the following table, the current user can work with the Recipe because the bitwise AND result is the same value as the Recipe Access Right.

Access Right = 1318

0000 0101 0010 0110

Recipe Access Right = 1028

&  0000 0100 0000 0100

Result (bitwise AND) = 1028

0000 0100 0000 0100

Access Denied

In the following table, the current user cannot work with the Recipe because the bitwise AND result does not match the Recipe Access Right.

Access Right = 4390

0001 0001 0010 0110

Recipe Access Right = 1028

&  0000 0100 0000 0100

Result (bitwise AND) = 4

0000 0000 0000 0100

 

You can set up the access right for the:

  • User in the hardware or in scripts.
    For information on how to set up user access rights, see Section 17.8.1, Setting the User Access Right.

  • Recipe Group in the properties of the selected Recipe Group.

  • Recipe in the Recipe editor's expand view.
