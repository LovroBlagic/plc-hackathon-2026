17.3.5.3 How the Clear Option for Recipe Controls Work (Timing Charts)

The AutoClear Option setting in Recipe Controls change how the values in Operation, Status, and Error variables are cleared after an operation complete.

The following are timing charts for the Load operation for these cases:

Clear Option = Operation Variable, No Error

  • The operation is successful when Busy is OFF.

Clear Option = Operation Variable, Error

  • If the operation is completed in error, the status and error variables reset to zero when the next operation is run, or you can reset the variables manually.

Clear Option = Status/Error Variables, No Error

  • The operation is successful when Busy is OFF.

Clear Option = Status/Error Variables, Error

  • If the operation is completed in error, the error and status variables reset to zero when either the operation variable is reset or the next operation is run.

Clear Option = None, No Error

  • The operation is successful when Busy is OFF.

Clear Option = None, Error

  • The error and status variables reset to zero when the next operation is run, or you can reset the variables manually.
