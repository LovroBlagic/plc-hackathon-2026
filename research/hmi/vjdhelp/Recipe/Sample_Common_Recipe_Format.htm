17.3.6.3 Sample Common Recipe Format

The common recipe .csv file format contains recipe group data, including all the recipes within the recipe group. In a common recipe format, you can add and delete recipes, change the values for the recipe group data, and change the labels. The following is a sample of a common recipe format.

The following table describes the columns and rows in the full version recipe format.

File Header Row

Column Name

Description

Format Name

Indicates the recipe format.

Format Version

Displays the version of the file format.

Recipe Group Name

Displays the name of the recipe group.

Product Version

Displays the name and version of the product.

Recipe Block Row

Column Name

Description

Data Type

Specifies the data type of each ingredient.

Minimum

Indicates the minimum value allowed for the recipe ingredient.

Maximum

Indicates the maximum value allowed for the recipe ingredient.

Recipe Set

Lists the recipe values for each ingredient.

Name

Displays the name of the ingredient label in SoMachine recipes. There is no output in this field for Vijeo Designer.

Comments

Displays comments related to the ingredient in SoMachine recipes. Comments are typically used for units of measure (such as, fl. oz.) in SoMachine. There is no output in this field for Vijeo Designer.

Ingredient Label Row

Column Name

Description

Languages

Identifies the ingredient names for each column of labels for each language.

Recipe Label Row

Column Name

Description

Languages

Identifies the recipe labels for each language.

Recipe Group Label Row

Column Name

Desription

Languages

Identifies the recipe group labels for each language.
