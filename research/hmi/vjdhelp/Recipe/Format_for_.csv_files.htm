17.3.6.4 Sample Full Recipe Format

The full recipe .csv file format contains recipe group data, including all the recipes within the recipe group. This full recipe format is aimed specifically for advanced users to add and delete recipes, change the values for the recipe group data, change the labels, and change the structure of the recipe (such as adding and removing ingredients). The following is a sample of a full recipe format.

The following table describes the columns and rows in the full version recipe format.

Recipe Group Row

Column Name

Description

Name

Indicates the name of the recipe group.

Access Right

Specifies a numeric value from 0 to 65535 to indicate the access right for the recipe group

Send Mode

Indicates how the recipe data is to be transmitted to and from the equipment. It can be a conditional or unconditional send.

Language Table Row

Column Name

Description

Lang ID

Specifies the numeric value for the language.

Locale

Specifies the supported locale: ENU (English), DEU (German), ESP (Spanish), FRA (French), ITA (Italian), CHN (Simplified Chinese), POR (Portuguese), CHT (Traditional Chinese).

Lang Name

Specifies the supported language.

Ingredient Row

Column Name

Description

Ingredient Name

Specifies the ingredient variable name.

Data Type

Indicates the data type, which can be an INT, DINT, UINT, Integer, REAL, BOOL, STRING, Block Integer, Block INT, Block DINT, Block UINT, or block REAL.

Editable

Indicates whether the ingredient can be editable in Runtime. TRUE indicates the ingredient is editable; FALSE indicates that it is not editable.

Array Size

Indicates the number of units, between 1 and 1024, in a block variable.

Min

Indicates the minimum and maximum values for the ingredient.

Max

Ingredient Label for the Lang ID

Specifies the ingredient labels for the language ID.

Recipe Row

Column Name

Description

Recipe Name

Indicates the recipe name.

Recipe ID

Indicates the unique ID for the recipe.

Access Right

Indicates the access rights for the recipe group, which is a numeric value from 0 to 65535.

Recipe Label

Indicates the labels for each recipe.

Recipe Ingredient Row

Recipe Name

Indicates the recipe name

Ingredient Value (Each Recipe)

Indicates the value for the specific ingredient.
