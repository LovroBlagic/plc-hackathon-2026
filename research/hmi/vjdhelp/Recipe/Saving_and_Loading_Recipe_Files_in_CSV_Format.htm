17.3.7 Exporting and Importing Recipe Files in CSV Format

This section describes how to create operations to:

  • Export recipe files in .csv format. When this operation is triggered at runtime, all the recipe files are saved as a set of .csv format files to the selected drive on the target machine.

  • Import recipe files in .csv format. When this operation is triggered at runtime, one or multiple recipe files can be loaded as .csv format files from a removable drive to the target machine.

Exporting Recipe Files to CSV Format

  1. Create a switch or panel function key. For more information, see Section 9.2, Creating Switches, or Section 24.5.2, Panel Function Key.

  2. In the When Touch tab, select the Copy Data To Drive operation.

  3. Define the settings for this operation. For more information, see Section 9.5.15.1, Copy Data To Drive Operation.

  4. Save the project.

Importing Recipe CSV Files into the Target

  1. Create a switch or panel function key. For more information, see Section 9.2, Creating Switches, or Section 24.5.2, Panel Function Key.

  2. In the When Touch tab, select the Copy Data From Drive operation.

  3. Define the settings for this operation. For more information, see Section 9.5.15.2, Copy Data From Drive Operation.

  4. Save the project.
