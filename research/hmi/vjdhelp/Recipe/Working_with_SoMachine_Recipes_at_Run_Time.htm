17.6.10 Working with SoMachine Recipes at Run Time

SoMachine recipe data is stored on the controller in a text or binary file. The SoMachine Recipe Manager part loads recipe data directly from the controller's recipe file. Be aware that Vijeo Designer's SoMachine Recipe Manager part can only display SoMachine recipes stored in ASCII format.

 

The SoMachine Recipe Manager part supports the following operations:

SoMachine Recipe Operation

Behavior on a Controller

Apply

Overwrites the recipe values on the controller with the recipe values displayed in the part.

Save

The save operation either:

Loads the selected recipe values from the controller in the part.

-or-

If you have entered in a new recipe name, the save operation creates a new recipe.

Delete

Deletes the selected recipe data on the controller.

 

Using the SoMachine Recipe Manager's Apply, Save, and Delete recipe operations described above, you can do the following:

  • Create New SoMachine Recipes

  • Update Existing SoMachine Recipes

  • Delete SoMachine Recipes

  • Monitor the SoMachine Recipe Operation Status
