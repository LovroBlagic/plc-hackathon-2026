17.6.10.4 Monitor SoMachine Recipe Operation Status

The SoMachine Recipe Manager part's status Apply, Save, and Delete status lamps are controlled by the function block output variables xDone, xExecute, xError.

The following table shows the Apply button's lamp status color based on the values of apply function block output variables xDone, xExecute, xError:

Output Variable Value

Status Lamp Color

xExecute = 1

xDone = 0

xError = 0

xExecute = 0

xDone = 1

xError = 0

xExecute = 0

xDone = 0

xError = 1

  • You can change the operation lamp status colors. For more information, see Section 17.4.1.5, Creating the SoMachine Recipe Manager.

  • For more information on function block output variables xDone, xExecute, xError, see the SoMachine online help.
