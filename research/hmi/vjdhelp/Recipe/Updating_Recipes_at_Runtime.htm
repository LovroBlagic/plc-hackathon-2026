17.6.9 Updating Recipes at Runtime

You can generate a recipe in CSV file format, update some values in the file, and then place the file back into the target using a USB memory stick or CF Card/SD Card.

The following procedure shows how you can export a recipe to a CSV format file, make updates to the recipes, and then import the recipe back into the target.

  1. Click a switch or a panel function key that has been configured with the Copy Data from Drive operation to import a recipe in CSV file format to the target. For more information, see Section 9.5.15.2, Copy Data From Drive Operation.

  2. Open the recipe CSV file in Excel to update the recipes. You can add recipes to the recipe group, modify ingredient values in one or more recipes in the file, or update labels. For more information on sample recipe CSV file formats, see Section 17.3.6.3, Sample Common Recipe Format, and Section 17.3.6.4, Sample Full Recipe Format.

  1. Using a USB memory stick or CF Card/SD Card, place the file back into the target machine.

  • When you place the file back into the target, updates to the ingredients and labels will be made. Any updates you make to the Min/ Max values and the Data Type will be ignored.
