17.3 Setting Up a Recipe Group in the Editor

This section describes the steps to create and define a recipe in Vijeo-Designer, how to export and import a recipe group, and how to download a recipe group.

17.3.1 Steps to Set Up a Recipe Group

To set up a recipe group, use the following steps.

Steps

1. Right-click the Recipes node and create a new recipe group or parison recipe group.

2. Enter the recipe group data in the Recipe editor, and add ingredients.

3. If needed, create variables for the ingredients.

4. Draw the recipe panel.

5. If the recipe group is to be operator controlled, set up the Recipe Manager part.
