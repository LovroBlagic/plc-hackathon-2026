17.5 Downloading Recipe Groups to the Target Machine

You can download recipe group data using either of these download methods:

  • Standard project download, where all files, including recipe group files, are downloaded to the target machine.

  • Recipe group download, where one or more recipe group files are downloaded to the target machine.

  • Data Transfer Tool, where you use the command line interface to transfer the recipe group files onto the target machine. Using the Data Transfer Tool, you can update recipe group files even while the target machine is still running.

Recipe Group files are stored in different folder locations depending on the Download To property:

This section describes how to download a recipe group using Vijeo-Designer. For more information on how to download a project or how to download a recipe group file using the Data Manager or the Command Line, see Section 20.5, Managing Run-time Data.

To ensure that you download recipe group files to the correct target machine, the Recipe function provides the Signature level of security. Signature is defined by the ingredients in a recipe group. When you build and download a project, the recipe group files generated from Vijeo-Designer must be synchronized with the recipe group files in runtime. If the files do not match, they would not be used in runtime. Vijeo-Designer incorporated this level of security to ensure the integrity of the recipe group files.

Preparing for the Download

Before you perform a download, you should check for any existing recipe group files on the target machine. If there are recipe group files, then you need to back up those files. Downloading may alter any changes you made to the recipe group data in Runtime. Backing up your recipe group files will prevent you from losing your changes.

You should also check the size of the recipe file (.RCP) before you perform a download. If there is insufficient disk space on the CF card/SD Card for the RCP file, the download will not complete. RCP file size is based on the number of recipes and number of ingredients in a recipe group. There are various methods for downloading your project. Select the method best suited for your needs and your development environment. Ethernet, Serial, and USB download require connecting the development PC and target machine together. File System download (Secondary Drive or network folder) is best suited when downloading to a remote target machine without a network available.

  • The target machine you use also limits the download methods available. For more information on the download methods available for the supported target machines, see Section 25.6, Downloading the Project.

  • You can also send recipe files to the target machine using the Data Manager or the Command Line. For more information, see Section 20.5, Managing Run-time Data.

Downloading Recipe Groups

If you want to download a specific recipe group, in the Navigator window, right-click the recipe group and select Download Recipe Group.

If you want to download all the recipe groups, in the Navigator window, right-click the Recipes node and select Download All Recipe Groups.

When downloading recipes to the target, the Editor will always download the binary version of the files.

During the download process, the Editor validates recipe group data to ensure the values are correctly entered. A recipe group download is successful if the values are correctly entered and there is no mismatch of values. For instance, the download proceeds and is successful if you add or modify recipes but do not change the ingredients. You must also ensure that the Project Identifier is set for the correct target. If the Project Identifier matches with the target, then the download is successful.

Once validation is completed and successful, the recipe group data and the associated recipes are downloaded to the target machine.

A recipe group download fails if there is a mismatch of values on the equipment or values are incorrectly entered. For instance, new variables, newly added or deleted ingredients, or panel changes may cause a mismatch of values between the Editor and target machine. You will need to review your recipe data, then build and download the recipe group.
