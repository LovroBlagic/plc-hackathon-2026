17.3.6 Exporting and Importing Recipe Groups

The Editor supports the following file formats for importing and exporting Recipe Groups:

  • .csv (comma separated value)

  • .txt file

  • .rcp (Recipe) file

For the .csv file format, you can select either an ANSI or Unicode .csv file type to produce a full recipe format, or UTF-8 .csv file type to produce a common recipe format. To view samples of the recipe formats, see Section 17.3.6.3, Sample Common Recipe Format, and Section 17.3.6.4, Sample Full Recipe Format.

The sections within this book describe how to do the following:

  • Export a single Recipe Group

  • Export all the Recipe Groups

  • Import a single Recipe Group

  • Import all the Recipe Groups

 

  • If you are using Microsoft Excel to edit an exported *.txt file, we recommend using Excel's Text Import Wizard to import the *.txt file into Excel. By using the Text Import Wizard, you can specify the *.txt file's field delimiter and set how the data is organized in Excel. Be aware that once you Save the edited (*.txt) file in Excel, the *.txt file's field delimiter is replaced with the Tab delimiter. Therefore, when you import the edited *.txt file back into Vijeo-Designer, specify that the *.txt file uses the Tab as a field delimiter. See Importing a Recipe Group.

  • Excel files cannot be imported directly into Vijeo Designer.

  • You can also use the Data Manager to both retrieve Recipe Groups from a Target Machine during Runtime and send Recipe Groups to a Target Machine during Runtime. See section 20.5, Managing Run-time Data.

  • If you want to import CSV recipe files from another project that contains user data type variables, you must use the following steps:

  • Import the user data types from the other project. See section 6.2.4.5, Importing and exporting User Data types.

  • Import the variables from the other project. See section 6.6.2, Importing Variables.

  • Import the CSV recipe files.

Reasons to Export and Import

  • Back up the recipe group data

  • Use the recipe group data in another project or in another target machine

  • Edit recipe group data in a .txt or .csv file

  • Use a text editor to create a new recipe group
