17.6.4 Getting Recipe Data Modified on the Controller

This section describes how to use the Snapshot operation to get recipe values that have been modified on the equipment.

When values change on the equipment and you want to update the ingredient values for the recipe group, you can perform the snapshot operation to capture and store the changed data in the recipe group.

  • To check how the recipe values on the target machine (the values in memory) and the current recipe values on the equipment compare, you can perform a Compare operation. For details, see Section 17.6.5, Comparing Recipe Data.

In this example, the recipe values on the target machine have already been sent to the equipment.

When the values change on the equipment, but not on the target machine, you can get the new values from the equipment.

Press the Snapshot button on the target machine.

The Snapshot operation copies the values from the equipment to the target machine and fills the Ingredient variables with these new values. Touch Save to store these values to the current recipe.
