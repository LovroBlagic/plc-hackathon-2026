22.1.1 Setting Up Shared Variables

  1. In the Target properties, set Data Sharing to Enabled.

  1. In the Variable properties, set Sharing to Read-only or Read/Write.

  2. Read—You can read the variable value on another target or on Web Gate.

  3. Read/Write—You can read and write to the variable from another target or from Web Gate.

  1. Set up references to the shared variables in scripts and Variable and Expression fields: TargetName.VariableName

For example, to reference a variable named arm01 on target1, type: Target1.arm01

  • While each target has a set of variables, other targets can access these variables, as long as the targets are in the same project.

  • You cannot share system variables. However, you can indirectly share system variables by using the Read From Variable and Write To Variable properties.

  • You can only share recipe variables using Web Gate.

  • Data from remote variables is not logged. Only data from local variables is logged and stored on the target.
