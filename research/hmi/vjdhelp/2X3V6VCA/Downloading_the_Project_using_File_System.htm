Downloading the Project to HMIGXO using File System

Use File System to download the user application and runtime system files from an optional drive to your target machine.

  • During download, do not forcibly exit Vijeo-Designer, or turn off either the PC or target machine. Trying to cancel or interrupt the download process can make the target machine inoperable. If you have trouble starting the target machine, see  Recovering the System on HMIGXO Targets.

  • If the versions of  Vijeo-Designer editor and Vijeo-Designer Runtime don't match, download will not proceed. You will need to update them. For information on displaying version numbers, see Section 26.4.4, Displaying Version Information.

Downloading

  1. In Vijeo-Designer, right-click the Target node and click Properties to open the Property Inspector. Set Download to File System.

  2. In the Path, define the location of the USB memory stick.

  • Only local path names are supported for download. To download to a network drive, first map the network drive to your local drive and then define this path for download.

  • In the download path, use ASCII characters only.

  1. Right-click the Target node and click Download. The user application is downloaded to the defined location.

  2. After Vijeo-Designer indicates the download is complete, make sure the USB memory stick completes writing before you remove it.

  3. Insert the USB memory stick into the USB port of your target machine. Turn on the target machine.

  4. After all the data is copied over, the run time and user application begin.
