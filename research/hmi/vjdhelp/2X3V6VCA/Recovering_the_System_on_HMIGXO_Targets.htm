Recovering the System on HMIGXO Targets

Use this recovery method when the Vijeo Designer Runtime is damaged on the target machine.

  1. Recovery Methods erase both the project on the target machine and any run-time data files.

  2. If you need additional serial recovery cables, contact your local Customer Care Center.

  1. On the Vijeo Designer editor PC, click the Windows Start button, then point to Programs, Schneider Electric, Vijeo-Designer, Tools, and click Runtime Installer.

  2. In the Vijeo-Designer Runtime Installer dialog box, select your target series from the drop-down list box.

  3. Select the Recovery check box.

  4. Follow the instructions shown in the Vijeo-Designer Runtime Installer dialog box to recover the system on the target machine.
