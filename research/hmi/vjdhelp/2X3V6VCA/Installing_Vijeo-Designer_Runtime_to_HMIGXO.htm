Installing Vijeo-Designer Runtime to HMIGXO Series

Before you download the project to the target machine, you need to download the run-time system files. The Runtime Installer is a separate application used to download, install, and upgrade Vijeo-Designer Runtime.

To install Vijeo Designer Runtime over the USB ports using the Vijeo Designer Runtime Installer:

  1. Connect the USB cable to the Type A USB port on the Editor PC and the mini-B USB port on the HMIGXO target machine.

  • Use the mini-B USB port on the HMIGXO only for installing Vijeo Designer Runtime or for downloading a project.

  1. On the Vijeo-Designer editor PC, click the Windows Start button, then point to Programs, Schneider Electric, Vijeo-Designer, Tools, and click Runtime Installer.

  2. In the Vijeo-Designer Runtime Installer dialog box, select the series number of your target machine. Set Download to USB.  

  3. Click Send to start the installation. When the run time installation is complete, a message box displays.

  4. Click OK to close the message box and click Exit to close the Vijeo-Designer Runtime Installer dialog box.
