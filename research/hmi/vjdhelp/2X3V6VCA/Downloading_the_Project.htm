Downloading the Project to HMIGXO

Before you can download a project, you must successfully validate and build it. The download operation transfers all the necessary files to the target machine to run the user application.

The HMIGXO target machine series support the following download methods:

 

Target

Download Method

HMIGXO3501

USB

HMIGXO3502 HMIGXO5502

USB, File System

 

  • For the downloaded application to run on the target machine, you must first install the Vijeo-Designer Runtime. Also, the versions of the downloaded files and the Vijeo-Designer Runtime must be compatible. For information on installing Vijeo-Designer Runtime see Installing Vijeo-Designer Runtime to HMIGXO Series.

  • We recommend you back up your projects after making changes. See Section 21.5, Backing Up Projects.

  • If you cannot download a project from Vijeo-Designer to the target machine, run the build operation again and ensure there are no errors during the validation or build.

  • The script and security run-time generated data are overwritten during download. Run-time generated data preserved at download include: data logging, alarms (.csv), and screen snapshots.

  • Data stored on SRAM, such as data logging, alarm backups, retentive variables, and the event log are deleted at download.

  • Runtime configuration settings are overwritten after the project download, except for Network, Brightness, Contrast, Backlight and Multimedia settings.
