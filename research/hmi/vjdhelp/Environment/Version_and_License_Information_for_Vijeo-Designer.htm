2.3 Version and License Information for Vijeo Designer

To view Vijeo Designer's About dialog box, from the Help menu click About. The About dialog box contains general software information, software license information, and the End User license agreement.

The About dialog box contains three tabs:

  • General Tab - Contains the Vijeo Designer logo, name of the software, version number, and copyright information.

  • License Tab - Contains the user name, company name, product reference and serial numbers, license status (whether the software has been registered or not), and either a Register button if the software has not been registered or an Upgrade button if the software has been registered.

  • License Agreement Tab - Contains the End User license agreement information.

  • All tabs contain a link to the Schneider Electric web site at the bottom of the About dialog box.
