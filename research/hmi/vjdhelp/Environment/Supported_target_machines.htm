*1 New target machines (HMIGTO, HMIGK, HMIPEP, HMIPSP, HMIPSO, HMIBMU and HMIBMP) are only supported by the newest versions of Vijeo Designer. If you recently purchased new target machines (HMIGTO, HMIGK, HMIPEP, HMIPSP, HMIPSO, HMIBMU and HMIBMP), update your Vijeo Designer editor (build time) to ensure compatibility.

*2 The Harmony XBTGC and HMISCU Series are only available when SoMachine is installed with Vijeo-Designer. If SoMachine is not installed, Vijeo-Designer will not display XBTGC and HMISCU as supported target types.

 

  • Some target machines may require the use of a CF Card (Schneider Electric manufactured, 16MB or more recommended) or SD Card (2GB or more recommended) to access certain functions. To check whether your target machine supports a CF Card/SD Card, see Appendix 5, Hardware Specifications.

  • The Smart iPC target machine is packaged with two CF cards. As CF cards have a limited number of write operations, one CF card is used as the Main Drive, which you should reserve for the operating system. The other CF card is used as the Secondary Drive (using the PCMCIA port) to store data logging files, recipe files, Vijeo-Designer applications, and temporary files.
