  • In Vijeo Designer, it is not possible to access network drives created by a standard Windows user account, even if Vijeo Designer is being run with administrator privileges. This is a known Windows limitation dating back to Windows Vista.

    To work around this problem, a registry entry can be created to enable network drives for all users.

    1. Click Start, type "regedit" in the Start Programs and Files box, and then press ENTER.
    2. Locate and right-click the registry subkey
    HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System.
    3. Point to New, and then click DWORD Value.
    4. Type EnableLinkedConnections, and then press ENTER.
    5. Right-click EnableLinkedConnections, and then click Modify.
    6. In the Value data box, type 1, and then click OK.
    7. Exit Registry Editor, and then restart the computer.
