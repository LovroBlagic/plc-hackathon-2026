Using Online Help

  • Context-Sensitive: Click on an object, dialog box, icon, or navigator node in Vijeo-Designer and press F1 to display information on the selection.

  • Table of Contents: From the Help menu in Vijeo-Designer, click Contents to display the help's table of contents.

  • Index: The online-help system provides index. Type a word or scroll through the list in the index to easily find the information you require. To use the index, start the online help and click the Index.

  • Search: The online-help system also provides a search engine. To use the search engine, start the online help and click the Search tab. Type in a word, phrase, or expression to search.

Click at the edge of the search engine's input box and use the expression operators to narrow the search conditions.

The following expression operators are available:

    • AND

    • OR

    • NEAR

    • NOT

For example, type "Animation AND Drawing" to search for topics with both words.

Type "Animation OR Drawing" to search for topics that use either word.

Type "Animation NEAR Drawing" to search for topics with the word Animation that is located in close proximity to the word Drawing.

Type "Animation NOT Drawing" to search for topics with the word Animation but without the word Drawing.

Use quotation marks around your phrase to narrow down your search.
