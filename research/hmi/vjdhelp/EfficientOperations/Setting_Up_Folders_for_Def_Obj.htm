21.1.4.2 Managing Folders for Definition Objects

You can organize definition objects into a folder structure and create up to a maximum of five levels of folders under the Link Objects node. Within each folder level, you can create as many folders and sub-folders as you want. The Folder Count property in the Link Objects properties displays the total number of folders that exist in your folder structure.

  • The folder name has to be unique for folders on the same level in the folder structure. The same name can be used for folders on different levels in the folder structure.

This section describes how to:

  • Create a folder and sub-folder

  • Copy or move a folder

  • Delete a folder and sub-folders

  • Add definition objects to folders

Creating Folders

To create a folder:

  1. Right-click the Link Objects node, and select New Folder.

  2. Specify a name for the folder.

To create a sub-folder:

  1. Right-click the folder and select New Folder.

  2. Specify a name for the sub-folder.

Copying and Moving Folders

To copy or move a folder:

  1. Select the folder you want to copy or move, and right-click.

  2. Select Copy to duplicate the folder or Cut to move the folder.

  3. If you want the folder to be a first level folder, right-click the Link Objects node and select Paste Folder. If you want the folder to be located under another folder, right-click that folder and select Paste Folder.

Deleting Folders

To delete all folders under the Link Objects node:

Right-click the Link Objects node, and select Delete All Folders.

To delete all sub-folders under a folder:

Right-click the folder node, and select Delete All Folders. This delete function removes all sub-folders and their contents. It does not remove the top folder node.

To delete a folder:

Right-click the folder node and select Delete Folder. This delete function removes the folder node and all its contents.

 

Adding Definition Objects to Folders

To copy a definition object into a folder:

  1. Select the definition object you want to copy, and right-click.

  2. Select Copy to duplicate the definition object.

  3. Select the folder you want to place the definition object in, right-click and select Paste Definition Object.
