21.11 Changing the Installed Language

The Language Selection Tool allows you to change Vijeo Designer's language for:  

  • Dialogs and menus in the Editor

  • Online help

  • PDF manuals

  • Report template files

  • Runtime Installer and Data Manager.

You can only switch to a language that you installed during the Vijeo Designer installation. You must have administrator rights to change Vijeo Designer's language.

To switch the language:

  1. Open the Language Selection Tool doing one of the following:

  • In the Windows Start menu, point to Programs, Schneider Electric, Vijeo Designer‚ Tools, and click Language Selection Tool.

  • In the Editor, click the Tools menu, and select the Language Selection Tool.

  1. Exit all instances of Vijeo Designer.

  2. In the Vijeo Designer Language Selection window, select the installed language to switch to.

  3. Click Set Language.

  • If you have an instance of Vijeo Designer running and you click Set Language, a message displays informing you to exit Vijeo Designer before the language change can take place.

  • When you switch language, the Toolchest folders remain in English.

  • When you change the language, the names of the shortcuts and folders in the Start menu will remain in the original language. However, the program or tool will open in the language you switched to.
