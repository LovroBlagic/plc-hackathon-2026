21.7 Renumbering Field IDs

The Renumber Field IDs feature enables you to automatically renumber all the field IDs for display objects with input mode enabled. The field IDs are renumbered starting from the integer value you specify in the Renumber Field IDs dialog box. The display objects' Z-order determines the order in which the objects' field IDs are renumbered.

To renumber Field IDs:

  1. Right-click on an empty space in the panel's drawing area, and select Renumber Field IDs.

  2. In the Renumber Field IDs dialog box, enter a number between 1 and 2,147,483,647.

  3. Click OK to begin renumbering field IDs.
