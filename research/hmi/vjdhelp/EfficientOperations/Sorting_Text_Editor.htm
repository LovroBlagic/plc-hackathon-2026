21.1.5.13 Sorting in the Text Resource Editor

You can sort a text resource by state, by Integer Value, or by Label (if one language is defined) or Language (if more than one language is defined).

To sort by Integer Value or by Label/Language, click the column header, and the values are sorted in ascending order. Click the column header to change the sorting to descending order. The indicator for ascending order and descending order is displayed in the column header.

To sort by state, right-click the text resource grid and select Sort by State. When sorting by state, the values are always in ascending order. The Sort By State option is disabled if the text resource is already organized by state.
