21.5 Backing up Projects

Vijeo Designer provides two features for backing up your projects:

Backup Manager

The Backup Manager creates a backup of your project and stores the backup on your PC.
Using the Backup Manager you can:

  • Add comments—write a description of the project backup.

  • Create backups—create a project backup and store it on your PC at: C:\Documents and Settings\"UserName"\My Documents\Vijeo-Designer\Vijeo-Manager\'ProjectName"\*.bkm

  • Get backups—retrieve the backup projects created with the Backup Manager and load them into Vijeo Designer.

  • Export backups—export the project backups created with the Backup Manager to any location on your network or PC.

  • Delete backups—delete the project backups that were created with the Backup Manager.

Main Drive, CF Card/SD Card, or USB Drive Backups

Users can create backups of their projects and store them on their target machine's main drive, CF card/SD card, or USB drive. CF card/SD card or USB drive backup is only available for target machines that support CF cards/SD cards or USB drives. See Appendix 1, Hardware Manuals for your target machine's specifications.
Using this feature you can:

  • Download backups—create a copy of your project and download it to your target machine's main drive, CF card/SD card, or USB drive at: Data/Project/*.vdz.

  • Upload backups—upload backups from your target machine's main drive, CF card/SD card, or USB drive into Vijeo Designer.

  • Compare Main Drive, CF Card/SD Card, or USB drive backups to editor projects—compare a backup project on a target machine's main drive, CF card/SD card, or USB drive to a project in Vijeo Designer.
