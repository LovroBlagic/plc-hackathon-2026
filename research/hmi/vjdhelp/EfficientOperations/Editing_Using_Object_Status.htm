21.6 Editing with Object Information

Vijeo-Designer's Object Information feature lets you visually check an object's property settings—its Name, Animation, Variables and associated Arrays, Popup Window panels — all at once, instead of individually.

The Object Information feature provides you with quick access to the following key object information directly on the graphical editor:

  • Variable Name

  • Variable Address

  • Object Name

  • Z-Order

  • Tab-Order

  • Animation

  • Change-Panel Link

  • Field ID

  • Display Popup and Alarm Banner

To access, select View from the menu and then Object Information. You can display all or specific object information.

Alternatively, you can turn ON the information you want from the Object Information toolbar.

  • Turn on the Object Information toolbar. Select Toolbars from the Tools menu. Select Object Information to display the toolbar. Click the icons to display Object Information.

 

The following table describes the Object Information feature's property settings.

Property

Description

Variable Name

The name of variables associated with the object.

 

Click a variable name to display its properties. The Variable Properties window is displayed. Make edits to the variable properties as required.

 

Variable Address

The device address of variables associated with the object.

Object Name

The object's name as displayed in the Property Inspector.

Z-Order

The order of the objects as they are layered. The objects are numbered according to when they are drawn: the first object will be numbered 1, and the last object will have the highest Z-order number.

Tab Order

The order of data inputs as defined in a tab group.

Animation

Icons represent the types of animation associated with the object.

 

Click the animation icon on the object whose properties you want to display. The Animation Properties window is displayed. Make edits to the animation settings as required.

Change-Panel Link

Displays the destination panel for a change panel operation. The destination panel is set in the switch or in a part's touch animation properties. By clicking the switch or the part, you can open the destination panel.

FieldID

Displays the field ID for the input mode of each display object.

When a master panel is linked to a base panel, the master panel objects will not have their field IDs displayed on the base panel. Only the base panel objects will have their field IDs displayed.

If there are field ID conflicts between the master panel and the base panel, the project cannot be validated in the editor. At runtime, if there are field ID conflicts, object display will be determined by Z-Order.

Display Popup & Alarm Banner

The popup window's position, size, panel ID and window name.

The alarm banner message's position, size, and alarm banner ID.
