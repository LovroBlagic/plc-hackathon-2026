21.4.2 Exporting Projects

Before you can export the project, you must first close the project file. Otherwise the Export Project menu item is disabled.

  1. In the Navigator window's Vijeo-Manager tab, right-click the project file that you want to export, then click Export Project.

  1. In the Export Project window, specify a location to save the project file in, then click Save to export the project file to that folder.
