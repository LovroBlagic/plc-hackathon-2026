21.1.5.6 Displaying Properties and States for Specified Parts

When configuring properties for a resource, the default is to display all properties and states in all object types. To simplify configuration, you may want to reduce the states and properties to display only those for a particular part.

  1. To reduce the states and properties displayed in the resource editor, click the appropriate filter icon.

    Color Animation Filter

    Switch Filter

    Lamp Filter

    Data Display Filter

    Message Display Filter

    Meter Filter

    Bar Graph Filter

    Selector Filter

    For example, the following diagram lists Color Resource states and properties for all objects.

    When you select the Lamp and Data Display icons, you can reduce the Color Resource states and properties as shown.

  2. To display all the states and properties in the resource again, click the Show All icon .
