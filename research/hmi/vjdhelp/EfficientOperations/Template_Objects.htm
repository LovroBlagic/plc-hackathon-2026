21.2.4 Working with Variable Placeholders

In Vijeo Designer, you can create a single object or a grouped collection of objects and assign a variable placeholder for each object. You can place the single or grouped object in the Toolchest, where it can be later used as a template object. You can reuse or replicate the template object for all instances you need the common functions and components in the template object.

For example, you can set up a group of objects that include numeric displays and switches to create a template object. You can assign placeholders in the variable definitions of the numeric displays and switches, group the parts, and then add the newly created template object into the Toolchest. This enables simple and efficient reuse of objects in project design. When you are ready to use the template object, you can drag and drop it on your panel, and replace each placeholder with another variable in your project.

In setting up template objects, there are two roles:

  • Template Object Creator: A person who designs and builds the group of objects, creates the Structure variable and adds elements to the structure, and assigns the placeholder in the variable definition for each object.

  • Designer: A person who uses the template object by dragging and dropping the object into the panel and replaces the placeholder with another variable as needed.

Where Variable Placeholders are Supported

The following Vijeo Designer components support variable placeholders:

  • All graphics objects, single or a grouped collection

  • All Toolchest objects

  • Animation on graphic objects

  • Animation on alarm summaries

  • Panels with panel actions

  • Master panels and popup panels

If you use an object that does not support variable placeholders, the Make Placeholder option is disabled when you create the template object. For more information on how to create the template object and the Make Placeholder option, see How to Build a Template Object.

 

How Variable Placeholders are Used

In Vijeo Designer, placeholders can be assigned in the variable expression for parts, graphical objects, and panel actions. The placeholder is defined based on an existing variable. The Template Object Creator adds placeholders, and the Designer assigns a different variable to replace the placeholder. A placeholder is defined based on existing variables in the project and is enclosed by the $ character. For example, Motor is a structure variable and can be defined as a placeholder in the variable definition as: $Motor$.Speed

You can use as a placeholder:

  • A variable, for example: $Integer01$

  • A structure or array variable: $Motor$.Speed

  • One or more elements in a structure variable, for example: $Motor$.Status.Speed or $Motor$.Speed

  • Any variables in a folder, for example: $Folder1$.Motor01.Speed

  • One or more elements in an array variable, for example: $Motor.Array$[3][4], $Motor.Array[3]$[4], or $Motor.Array[3][4]$

  • For one variable field in an expression. A valid integer data expression is, for example: $DINT01$ + DINT02 + DINT03
