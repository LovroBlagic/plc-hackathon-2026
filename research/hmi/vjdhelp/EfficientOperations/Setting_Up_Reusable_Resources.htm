21.1 Setting Up Reusable Resources

You can set up the color, text strings, and images in the Resource Library, and then use them over and over again in your Switches, Lamps, Data Displays, Message Displays, Image Displays, Bar Graphs, Meters, Selector switches, and Color Animation.

Reusing color, text, image, and font resources can reduce the overall work required to create your panels, and to maintain changes, but careful planning is required. You should design your resources early, during the planning and designing phase. When you create the HMI project, you should create the resources before you even begin drawing.

For example, your company may have a policy to display critical messages in a red background, warning messages in a yellow background, and other information in a black background. To make sure colors are consistently used, you should set up a color resource and apply them to the various parts.

Color, text, and image resources include information on:

  • The objects associated with the resource

  • Which states are included in the resource

  • Values for object properties in each state.

With text resources, you can:

  • Define different fonts for each message.

  • Set up predefined messages. For more information on how to enter messages in the Label column, see Section 21.1.4.4, Defining Values for Each Property in Each State.

  • Set up messages with dynamic content that can contain current variable values, time, and date. For more information, see Section 21.1.5.12, Setting Up Messages with Dynamic Content.

Resource Library Benefits

You would use resources to create a consistent look and feel to HMI applications. Benefits to using resources are:

  • Reduced Errors

  • Reduced Maintenance

  • Reduced Localization

Reduced Errors

In an application that uses the Resource Library, the color scheme is consistent—for example, red means on and green means off. When panel operators see the color red, they instantly know that equipment is running and that they should remain cautious. The panel operator knows this because all HMI applications use the same color scheme.

Text resources also produce the same result. There is less misunderstanding as messages are used consistently, no matter which panel is displayed.

Reduced Maintenance

If there is a change in the color scheme, change in one of the text strings, or change in one of the images, you only have to make the change in one location—the Resource Library. If you decide not to use resources and a change has to be made, you would have to make the same change in every single instance of that color, text string, or image.

Reduced Localization

If the project is a multi-language project, the number of strings that require localization is reduced. When the same string is used in multiple objects, instead of sending out for localization multiple instances of the same string, you can send out just one string when you use the Resource Library.

  • When you are drawing Message or Image Displays, you would always use resources. When you are drawing Meter, Bar Graph, and Selector switches, we recommend using resources, though you do not have to.

  • One reason you may not want to use resources for your objects is that the object appears in one location only. As a result, the overhead to create a resource to support just one object may not be justified. Once that object begins appearing elsewhere, you may want to convert the properties to a resource library to ensure consistency and ease of maintenance.
