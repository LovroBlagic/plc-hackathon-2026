21.5.2.1 Downloading Editor Project to Main Drive, CF Card/SD Card, or USB Drive

The Editor Project files are compressed Vijeo-Frame Archive Files (*.vdz) that contain the project and the data files associated with the project, such as sound files, image files, and text files. These files are downloaded to main drive and CF card/SD card in the following directory:

\\"projectname"/Data/Project/*.vdz

If the Data Location is set to Optional Drive, where the files are downloaded to the USB drive, the files are downloaded to the following directory:

\\PUBLIC\PROJECTS/"projectname"/Data/Project/*.vdz

 

LOSS OF DATA DURING BACKUP

  • The backup process may not complete successfully if the project size is greater than the available space on target machine's main drive, CF card/SD card, or USB drive. Before you download backups, check the project size and available space on your destination drive.

Failure to follow these instructions can result in loss of data or equipment damage.

 

  1. Right-click the Target node and click Properties.

  2. Under the Download sub-section, enable the Include Editor Project.

  1. Download the project to a target machine.
    For more information on downloading to a target machine, see Section 25.6, Downloading the Project.

  • CF card/SD card or USB drive Backup is only available for target machines that support CF cards/SD cards or USB drives. See Appendix 1, Hardware Manuals for your target machine's specifications.

  • If your project has multiple data files, the Vijeo-Frame Archive file (*.vdz) may be too large for your main drive, CF card/SD card, or USB drive. Check the size of the Vijeo-Frame Archive file (*.vdz) and your main drive, CF card/SD card or USB drive capacity before each backup. You can check the (*.vdz) project file size by exporting the project to your computer. See Section 21.4.2, Exporting Projects.

  • Backup Manager project backups are not included in the main drive, CF card/SD card,  or USB drive backup file. For more information on the Backup Manager, see Section 21.5.1, Backing up Projects on your PC.

Backup concurrency problems

Backup concurrency problems can occur when you download the project and a backup to multiple targets. For example, you have a project with two targets: target 1 and target 2. You download the project with a backup to target 1. Then you modify the project and download the project with a backup to target 2. The backup on target 1 is now no longer concurrent with the project in the editor.

To either avoid backup concurrency problems or to fix backup concurrency problems, we recommend you do the following:

  • Avoiding Backup Concurrency Problems
    To avoid backup concurrency problems, download the project to all the targets at the same time so that the project backups on the targets are all concurrent with each other.

  • Fixing Backup Concurrency Problems
    You can use the Compare to Backup feature to identify which project backup on your target's is the most up-to-date backup. The Compare to Backup feature compares the project backup on the target machine's main drive, CF card/SD card, or USB drive to a project in the Vijeo Designer. See Section 21.5.2.3, Comparing Main Drive, CF Card/SD Card, or USB Drive Backups to Editor Projects.
