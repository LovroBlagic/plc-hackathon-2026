21.1.4 Link Objects

The Link Objects node in the Resource Library are also known as definition objects. The link objects feature allows you to create and update definition objects in panels more efficiently. A definition object is a grouped collection of objects you can create once, and place it into your panels to create multiple instances of the definition object. This feature enables you to design your panels, not only more efficiently, but also consistently.  

You can design and create a library of definition objects in the drawing area using one or a combination of the following:

  • Shapes (such as rectangles and arcs) and parts (such as numeric displays and switches) from Graphical Tools

  • Toolchest parts

  • A Group object of shapes, parts and Toolchest parts

  • A nested Group object (that is, a Group object containing Group objects).

Configure each shape, part and Toolchest part in the definition object, by defining common properties and instance properties.

You can place one or several instances of the definition object on the graphical panels in your project. Each instance is linked to the definition object. If you make any changes to the definition object, all instances of that definition object will be updated.

The Link Objects node is located in the Navigator window’s Resource Library. The Link Objects node contains folders and a sub-node for each definition object created in the target. You can organize definition objects into a folder structure. For more information, see Section 21.1.4.3, Managing Folders for Definition Objects.

For more information on working with definition objects, see:

  • Section 21.1.4.1, Creating a Definition Object

  • Section 21.1.4.2, Managing Folders for Definition Objects

Common Properties

Common properties contain values that are defined in the definition object and shared by all the instances of the definition object. You can change values in the common properties only in the definition object. After you change the value, all instances of the definition object are updated.

All properties for an object are common properties, with the exception of the properties that are specific to an instance – the object's Name, Top, and Left – and can only be configured in each instance.

 

Instance Properties

Instance properties have variable or constant values that are defined in the definition object and are not shared by all the instances of the definition object. Precede the variable value with the "@" symbol to indicate that the Variable property is an instance property and that you should modify the value in each instance of a definition object. For example, in NumericDisplay01 of a definition object, enter @DINT01 in the numeric display's Variable property to indicate that this field is an instance property.

You can define any property that accepts an expression as an instance property. For instance, switches, numeric displays, lamps, actions, and animation have properties that accepts expressions. Properties that are specific to an instance, such as the object's name and its position, are also instance properties.

 

Drawing Area

When creating a new definition object, use the drawing area to design and build the definition object. The size of the drawing area is the same as the target panel size. The drawing area does not limit the size (width and height) of the definition object. The definition object can be bigger or smaller than the drawing area.

In the drawing area, you can:

  • Add Toolchest parts

  • Add shapes and parts (such as rectangle, switch, and alarm summary)

  • Define common and instance properties for each object.
