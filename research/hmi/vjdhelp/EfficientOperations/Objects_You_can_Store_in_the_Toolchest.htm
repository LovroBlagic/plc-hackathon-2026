21.2.2 Objects You Can Store in the Toolchest

The following table describes the objects you can store in the Toolchest.

What is Actually Stored

Where You Can Use the Object

All graphic objects

The graphical object and any attached animations.

Variables used by parts and animation are not stored.

Panel node

Panel, and panel objects (includes animation).

Graphical panels

Template Objects

A single or a grouped collection of objects (such as graphical objects and parts) and any attached animations.

Includes placeholders for variables in objects, parts and animation.
