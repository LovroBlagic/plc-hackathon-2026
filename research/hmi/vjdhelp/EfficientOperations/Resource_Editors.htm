21.1.2 Resource Editors (Color, Text, Image)

The Color, Text, and Image Resource editors display a list of the resource names (ID) in the Resource Library alongside a table that displays the states and properties of objects associated with the current resource.

An example of the Color Resource editor with colors for the switch, lamp, and meter is shown below.

Color, Text and Image resources can be used in Switches, Lamps, Message Displays, Meters, Bar Graphs, and Selectors. Additionally, Color resources can be used in Data Displays and Color Animation.

When setting up:

  • Color resources, you can set up the text color, frame color, and other color settings for when objects are in the Invalid state, state 0, state 1, up to every state in the object.

  • Text resources, you can define the message and font for each state. If the target is set up with multiple languages, you can define messages and fonts for each state in every language.

  • Image resources, you can define an image for each state.

When drawing objects that support the use of resources, you can select any of the color, text, or image resources that are defined and listed in the Resource Library.

For information on how to configure resources, see Section 21.1.5, Working with Resources.

21.1.2.2 Resource States and Properties

When configuring the states and properties for the resource, keep in mind that each resource defines different ranges of states and different sets of properties for different objects.

States and properties may operate differently for different objects. Refer to the topic of the associated object for information about a particular state or property.

Message Display/Image Display: Resources can define values for states 0 to 254, in addition to the invalid state.

Meter/Bar Graph: Color resources can define values for the Min, LoLo, Lo, Normal, Hi, HiHi, and Max states; Text Resources can define values for positions (states) 0 to 31; Image resource defines the value for the Normal state.

Selector: Color resources can define values for a Selector's Invalid and Normal states; Text resources can define values for positions (states) 0 to 31; Image resource defines the value for the Normal state.

Data Display: Color resources can define values for the LoLo, Lo, Normal, Hi, and HiHi states.

Color Animation: Color resources can define values for Invalid, On, Off, and 0-255.
