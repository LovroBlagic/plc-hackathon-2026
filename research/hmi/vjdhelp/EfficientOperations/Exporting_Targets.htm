21.12 Exporting Targets

Target data can be exported into XML format. Exported target data is saved as a .hmix file type. Exported target data includes:

  • Alarm Configuration Data (Groups, Categories, Event Groups)

  • Logging Group Data

  • Variables

  • Language Node Properties

  • Basic Target Properties

  • Basic Communication Driver Information

To export target data into XML format:

  1. Right-click the target node and select Export.

  2. In the Save As dialog box, specify a save location and the exported target's XML file name.

  3. Click save to export the target data.
