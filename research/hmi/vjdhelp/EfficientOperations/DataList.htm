21.3 Editing Objects with the Graphics List

The Graphics List provides a list of all the objects that are on the current graphical panel and displays information about objects, as shown below.

The following table describes Graphics List properties.

Property

Description

Order

Shows the order in which objects are drawn on the panel. e.g., in the Graphics List above, SymPolygon01 was drawn first and Polygon01 was last. If the column title is clicked, the Graphics List displays the objects in ascending (first to last) or descending (last to first) order.

Object Name

Name of the object. If the column title is clicked, the Graphics List displays the objects by name, in ascending (A-to-Z) or descending (Z-to-A) alphabetical order.

Position

Object's coordinates on the display panel.

Animation

Type of animation associated with the object.

Variables

Variables associated with the object. Only the variable's name is displayed—the type of variable is indicated only if described in the variable's name.

The Graphics List is useful for quickly checking animations and variables that are associated with objects.

Graphical objects are often layered and hidden behind other objects. The Graphics List displays all objects, making it easier for you to select and edit the properties and animation settings for each object, including grouped objects.

Graphics List Toolbar

When you select an object on a panel, it is highlighted in the Graphics List and its properties are displayed in the Inspector. The following table describes the capabilities of the Graphics List toolbar icons:

Icon

Description

Change Toolbar Location. Switches the position of your toolbar (top or left-side).

Show Groups Expanded. Displays all the individual objects for all groups in the Graphics List.

Send To Back. Positions an object to the last layer behind other objects.

Move Forward. Moves an object forward one layer.

Move Backward. Moves an object back one layer.

Bring To Front. Brings your object to the foremost layer.

Group Object. Allows you to group your objects.

Ungroup Object. Allows you to ungroup your objects.

Delete. Allows you to delete a selected object.

Select Objects in the Graphics List

  • To select an object, click the object that you want from the list.

  • To select multiple, successive objects, click the first object in the series, then press the shift key and click the last object to select that range of objects.

  • To select multiple, non-successive objects, press the ctrl key and click to select the objects individually.

Sort Objects in the Graphics List

By default, objects are sorted in display order. When sorted by Name, items are sorted in the order of ASCII codes. When sorted by Position, items are sorted by Left, Top, Right, and Bottom coordinate values, in that order. When sorted by Animation, items are sorted by the animation's alphabetical order.

  1. In the Graphics List, click the column title to change the current sort order.

  2. Click the column title again to reverse the sort order.

Display Animation Property Settings

  1. Select an object from the Graphics List.

  2. Right-click, and select Animation.

Display Object Property Settings

If you want to change or check an object's properties, you can display them by selecting Properties from either from the Graphics List or from the panel.

Right-click an object's name from the Graphics List or the object itself from the panel, then click Properties to display the object's settings in the Property Inspector.
