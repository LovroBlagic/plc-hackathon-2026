21.5.2.3 Comparing Main Drive, CF Card/SD Card, or USB Drive Backups to Editor Projects

Users can compare a project backup on a target machine's main drive, CF card/SD card, or USB drive to a project in Vijeo Designer. The Compare To Backup feature compares the project backup's Revision History to the editor project's Revision History. Using this comparison, you can identify which project backup is the most up-to-date. For more information on Revision History, see section 4.6.5, Recording Revision History.

  1. In the Vijeo-Manager tab, right-click the project you want to compare a backup to and click Compare to Backup.

  2. In the Compare To Project dialog box, specify the connection configurations:

Property

Description

Connection Type

Specify the connection type:Ethernet, Serial, or USB.

IP Address

For Ethernet only.

Specify the target's IP Address.

COM Port

For Serial Upload only.

Specify the COM port that connects the PC to the target machine.

Baud Rate

For Serial Upload only.

Select the transmission speed supported by the COM port.

Data Location

Specify the location of the backup files: Main, Secondary, or Optional drive.

  1. Click OK to connect to the target machine and display the Comparison Result dialog box.
    Compare the two project's Revision History information.

Description
