21.1.5.4 Defining Values for Each Property in Each State

Numeric or Text

  1. Click the field to display the text cursor and type the value.

  2. When working with text, type [Ctrl]+[Enter] to enter a carriage return in the cell.

Color

  1. To change color settings, click the field to display the color palette.

  2. Select the desired color.
    For information about Color settings, see Section 7.3.1, Color Palette.

Font Resource

  1. Click the Font Name field to display a list of the current font resources.

  1. Select the font resource for the current message. Click New Resource to display the New Resource dialog box and create a new font resource (see Section 21.1.4.1, Creating Resources).

  • When the user application is set up with multiple languages, the Label column is replaced by the user language name.

Image

  1. Click the Image field.

  1. Select the image for the current state and click Open.

The selected image filename is added to the image property.
