21.4 Importing and Exporting Projects

You can save Vijeo-Designer projects by exporting them as compressed files (VDZ file). Exporting projects is useful for writing to removable media such as a CD-ROM or USB drive, for sending by e-mail, or copying to another PC computer over the network. You may import compressed project files in VDZ format. The recipient can then import the compressed project file (VDZ file) into their Vijeo Designer editor.
