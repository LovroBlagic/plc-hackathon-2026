21.8 Using Value List

Use Value List to assign Integer values to an object's state. When the control variable's value switches to one of the values in the value list, the object switches to the corresponding state. You can specify 2 to 32 values.

  • Value List is only available for Selectors and Color Animation. If data type is Integer, the Value List will indicate the Integer Value, as shown below. If data type is String, which Color Animation now supports, the Value List will indicate the String Value.

Property

Description

State

The state number is a unique number that identifies the state of an object. It starts at 0 and increments sequentially to 31.

Integer/String Value

The Integer Value can be any unique integer between (negative) –2,147,483,648 and 2,147,483,647.

The String Value supports a maximum of 32 characters and supports Unicode.

  • For the object to change to the correct state, the value of the variable must equal an Integer Value. If the value of the variable does not equal an Integer Value, the object is in an invalid state.

  • If the Integer Value is not within the valid range or is not an integer, an error message displays.

  • The control variable can be an internal or external variable.

  • Value List cannot be used with a BOOL data type.
