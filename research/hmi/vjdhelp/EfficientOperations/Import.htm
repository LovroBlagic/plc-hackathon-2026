21.4.1 Importing Projects

Projects can be imported and opened regardless of whether Vijeo-Designer is running or not.

When Vijeo-Designer is Not Running

When Vijeo-Designer is not running, you can import a project by double-clicking the Vijeo-Designer project file (.vdz file) in Windows Explorer. The project is imported and automatically opens in the Editor.

  • The double-clicking function to import a project works only when the Vijeo-Designer Editor is not running.

  • The original project (.vdz file) will not be updated when the imported project is modified and saved.

When Vijeo-Designer is Running

The following procedure describes how to import a project if you are already in the Editor.

  1. In the Navigator window's Vijeo-Manager tab, right-click the Vijeo-Manager node (or on a specific folder to import the project into that folder), then click Import Project.

  1. Select a file from the Import Project window, then click Open.

The project file is imported into Vijeo-Designer, in the Project Manager tab.

  • The original project (.vdz file) will not be updated when the imported project is modified and saved.
