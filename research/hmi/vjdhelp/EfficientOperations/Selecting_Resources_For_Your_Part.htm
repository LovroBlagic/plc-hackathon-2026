21.1.5.2 Selecting Resources for Your Part

After creating resources for your application (see Section 21.1.4.1, Creating Resources), you can reference the resources in parts. The following describes how to select a resource from the parts dialog box, using the Meter as an example.

  1. After drawing the Meter, the Meter Settings dialog box displays.

  1. Click the Color tab, and then click the Color Resource field to display the color resources available. Select the color resource you want to use with this Meter part.

  1. Change the color settings in the dialog box. These changes are also made to the selected resource.

You can change resource settings in the part settings dialog box for Meters, Bar Graphs, and Selectors, in addition to the resource editor. To change resource settings for Message and Image Displays, use the resource editor.

  • Parts cannot have more states than the associated resource.
