21.5.2 Backing up Projects to Main Drive, CF Card/SD Card, or USB Drive

Users can back up projects to a target machine's main drive, CF card/SD card, or USB drive. Backup files are compressed Vijeo-Frame Archive Files (*.vdz) that contain the project file and the data files associated with the project, such as sound files, image files, and text files.

  • CF card/SD card or USB drive backup is only available for target machines that support CF cards/SD cards or USB drives. See Appendix 1, Hardware Manuals for your target machine's specifications.

  • If your project has multiple data files, the Vijeo-Frame Archive file (*.vdz) may be too large for your main drive, CF card/SD card, or USB drive. Check the size of the Vijeo-Frame Archive file (*.vdz) and your main drive, CF card/SD card, or USB drive capacity before each backup. You can check the (*.vdz) project file size by exporting the project to your computer. See Section 21.4.2, Exporting Projects.

  • Backup Manager project backups are not included in the main drive, CF card/SD card, or USB drive backup files. For more information on the Backup Manager, see section 21.5.1, Backing up Projects on your PC.

Using this feature you can:

  • Download backups—create a copy of your project and download it to your target machine's main drive, CF card/SD card, or USB drive.

  • Upload backups—upload backups from your target machine's main drive, CF card/SD card, or USB drive into Vijeo Designer.

  • Compare Main Drive, CF Card/SD Card, or USB drive backups to editor projects—compare backup projects on your target machine's main drive, CF card/SD card, or USB drive to projects in Vijeo Designer.
