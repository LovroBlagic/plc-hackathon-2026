21.1.4.1 Creating a Definition Object

Use the Link Objects node in the Resource Library to design and create definition objects. You can then create multiple instances of the definition object for the Target node.

You can create a maximum of 100 definition objects for each Target node. The Object Count in the Definition Objects properties displays the total number of definition objects in the Target node. You can copy and paste definition objects from one Target node to another Target node within the same project.

You cannot import definition objects from other projects. You also cannot drag and drop a definition object into the Toolchest; if you do, it is no longer a definition object. It becomes a Toolchest part that you can use for other target nodes in your project. The common and instance properties that are configured for the object remain, but the object no longer has links with other instances of the definition object.

This section describes how to:

  • Create a definition object  that you can use in the project.

  • Create multiple instances of a definition object on one or more panels in your project.

  • Update instance properties defined in the definition object.

Create a Definition Object

  1. Right-click the Link Objects node and select New Object.

–or–

If you want to create a definition object within the definition object folder structure, right-click a folder and select New Object.

  1. In the drawing area, design the definition object by adding Vijeo Designer graphical objects and parts, and Toolchest parts. The drawing area is used solely for designing and displaying objects. For more information, see Drawing Area.

  2. Define the properties of the graphical objects, parts and Toolchest parts with common properties and instance properties.

To define an instance property, insert the "@" symbol in front of the expression or constant value to indicate that the Variable property is an instance property. For example, in Switch01 of a definition object, enter @BOOL01 in the switch's Variable property to indicate this field is an instance property

  1. When you define instance properties for Vijeo Designer shapes, parts, and Toolchest parts, in the definition object's properties, click the ellipsis in Instance Properties. In the Instance Properties dialog box, define the alias for each instance property in the list.

The following table describes the columns in the Instance Properties dialog box.

Column

Column Name

Description

1

Row Numbers

Displays the row numbers, starting from 1. This column is read-only.

2

Name

Displays a hierarchical list of object names and properties to identify the instance property. This column is read-only.

For example, the name can be: GroupObject02.GroupObject01.Switch01.Action.Bit.DestinationVariable

3

Alias

Enter a unique alias name for the instance property. You can enter from 1 to 32 characters.

The alias can contain alphanumeric characters (A-Z, a-z, 0-9), Unicode characters, and the underscore (_) character. The alias must start with a letter.

For example, an alias can be: Switch01_ON

 

After creating the definition object, you can create instances of the definition object.

  • You can drag and drop a definition object create in a Target node to the Link Objects node of another Target node.

  • If you drag and drop a definition object into the Toolchest, it is no longer a definition object. It becomes a Toolchest part that you can use for other target nodes in your project. The common and instance properties that are configured for the object remain, but the object no longer has links with other instances of the definition object.

Create Multiple Instances of a Definition Object

  1. Drag a definition object and drop it into a panel. You have created one instance of the definition object.

  2. Select the instance, right-click, and select Duplicate. This function creates another instance of the same definition object in the panel. Repeat this step to create as many instances as you want.

Update Instance Properties Defined in the Definition Object

  1. Click an instance of the definition object on the panel.

  2. In the Property Inspector for the instance object, click the ellipsis button in Instance Properties. The Instance Properties dialog box opens to display a list of all the instance properties for this instance object.

The following table describes the columns in the dialog box.

Column

Column Name

Description

1

Row Numbers

Displays the row numbers, starting from 1. This column is read-only.

2

Alias

Displays the alias names of instance properties defined for the definition object. This column is read-only.

3

Value

Enter the expression for each property. This value is specific to this instance and is not shared by the other instances of the definition object.

  1. Click OK.
