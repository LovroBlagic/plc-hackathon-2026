21.1.5.5 Setting the Same Value to Multiple States

This procedure describes how you can set multiple states to the same value for colors, blink, text (labels), and Font Name.

  1. In a single property column, click and drag the pointer to select the states you want to configure.

  1. Select or enter the value.

The entire range of states are now defined with the same value.

  • You cannot change the Integer Value or String Value used by Message and Image Displays in this way because you cannot have multiple states that use the same value.

  • You cannot change multiple properties in this way, only multiple states in the same property.

  • You cannot use this method in the Font Resource editor because you cannot multi-select between resources. Each row in the Font Resource editor is a font resource.

  • You can also use the keyboard to multi-select cells. Use [Shift]+click to select a range of cells. Use [Ctrl]+click to select non-consecutive cells.
