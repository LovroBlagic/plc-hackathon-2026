21.1.5.8 Viewing Multiple Resource Types

You can view both Color and Text Resources at the same time to enhance configuration of Color and Text Resources.

  1. In the Navigator window, hold down the [Shift] key and click both the Color Library and Text Library nodes.

    The resource editor displays the properties of both resource types.

You can sort in a multiple resource view. For more information on how to sort, see Section 21.1.4.13, Sorting in the Text Resource Editor. When you sort the text resource by Integer Value or by Label (if you have one language defined) or Language (if you have more than one language defined), all the color resource columns will be sorted with the text resource. If you reset the text resource to Sort by State, the color resource columns will also be sorted with the text resource.

  1. In the Text Name and Color Name lists, select the text resource and color resource you want to view.

    The editor combines the property values of both resources so you can see how the settings map between resource types. Shaded areas are states that are undefined in one of the resources, and indicate the number of states between resources do not match.

    You can change the resource values as you would in any other resource editor display. For example, you can click the filter icons to display states and properties for specified parts only.
