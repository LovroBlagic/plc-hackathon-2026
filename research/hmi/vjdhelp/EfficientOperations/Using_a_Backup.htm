21.5.1.2 Working with Backups

Restoring a Backup

When you restore a backup project, it overwrites the current version. To make sure you will be able to retrieve your current project, back it up BEFORE you use the Get function.

  1. Right-click a project, and click Backup Manager.

  2. In the Backup Management dialog box, select the version you want to restore and click Get.

  1. In the Backup Manager message box, click Yes to overwrite the current project with the selected backup version.

Using the Backup on a different project

With the Export function, you can use a backed up version of the project for use as a different project.

  1. Right-click a project, and click Backup Manager.

  2. In the Backup Management dialog box, select the backup version of the project and click Export to open the Backup Manager dialog box.

  1. In the Backup Manager dialog box, enter the destination folder to export the project into, then enter or rename the backup project's file name and click Save.

  1. Import the backup project file into Vijeo-Designer. See Section 21.4.1 Importing Projects for more information.
