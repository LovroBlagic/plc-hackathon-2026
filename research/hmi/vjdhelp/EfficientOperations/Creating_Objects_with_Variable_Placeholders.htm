21.2.4.1 Example of Creating Objects with Variable Placeholders

For example, the Template Object Creator wants to create a motor faceplate to control each motor in the factory. To do this, the Template Object Creator needs to:

  • Create a Structure variable called Motor, with Structure variable elements Speed, Start, and Stop.

  • Create a numeric display for Speed, a switch for Start, and a switch for Stop.

  • Define the variables for the numeric display and switches.

  • Group the collection of objects and then drag to the Toolchest for future use by a Designer.

The Designer needs to use the motor faceplate to control each of the three motors on the factory floor. To do this, the Designer will:

  • Drag and drop three instances of the motor faceplates created by the Template Object Creator onto the panel.

  • In each object, replace the placeholders with valid variables.

For more information on how to build and use the template object based on this example, see How to Build a Template Object and How to Use a Template Object.

For an example on how to directly communicate with a PLC using Placeholders, see Section 4.13.11, Using SoMachine MED Toolchest Parts.

How to Build a Template Object

  1. Create a structure variable (Motor) and add elements: Speed (integer variable), Start (discrete variable), and Stop (discrete variable). For more information on structure variables, see Section 6.2.4.2, Creating Structure Data Types.

  2. Create a switch with a Bit Set operation. In the Destination property:

  3. Select the structure variable and the element from the Variables List: Motor01.Start.

  4. Highlight Motor01, right-click and select Make Placeholder. The variable definition in the Destination property now contains the following placeholder for the motor: $Motor01$.Start.

  1. Create a second switch with a Bit Reset operation. In the Destination property:

  2. Select the structure variable and the element from the Variables List: Motor01.Stop.

  3. Highlight Motor01, right-click and select Make Placeholder. The variable definition in the Destination property now contains the following placeholder for the motor: $Motor01$.Stop.

  1. Create a numeric display. In the Variable property:

  2. Select the structure variable and the element from the Variables List: Motor01.Speed.

  3. Highlight Motor01, right-click and select Make Placeholder. The variable definition in the Destination property now contains the following placeholder for the motor: $Motor01$.Speed.

For more information on how to set up a numeric display, see Section 11.3, Displaying Values Using Numeric Display.

  1. Group the objects. You have now created the Motor faceplate.

  2. Move the Motor faceplate to the Toolchest for future use.

Example of How to Use a Template Object

  1. Drag and drop the Motor faceplate from the Toolchest onto your panel. The Placeholders dialog box opens for the template object.

  2. In the Replace Variable column, type in the variable or select from the Variable dialog box a valid variable for each object in the Motor faceplate. Or click the New Variable icon to create a variable of the same data type as the one saved in the template object. If the variable you entered is invalid, an error displays at validation.

For example:
The placeholder $Motor$ is replaced with variable Motor01. $Motor$.Speed, $Motor$.Start, and $Motor$.Stop are replaced with Motor01.Speed, Motor01.Start, Motor01.Stop, to control Motor 1 on the factory floor.

  1. Repeat steps 1 and 2 to complete creating the three instances of the motor faceplate. You can replace the variable placeholders with:

  • Motor02.Speed, Motor02.Start, Motor02.Stop, to control Motor 2 on the factory floor, and

  • Motor03.Speed, Motor03.Start, Motor03.Stop, to control Motor 3 on the factory floor.

If you need to update the placeholder variables again, in the graphic object's properties, click the ellipsis in the Placeholder property to open the Placeholders dialog box.
