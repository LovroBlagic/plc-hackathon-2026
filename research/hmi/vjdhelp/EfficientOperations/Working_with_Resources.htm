21.1.5 Working with Resources

There are two parts to resources:

  • The Resource Library icons in the Navigator window

  • The resource editor visible when you click a Resource Library icon.

When working with resources, you are working primarily in the resource editor. For information about the layout in resource editors, see Sections 21.1.2, Resource Editors (Color, Text, Image) or 21.1.3, Font Resource Editor.

You can perform the following resource operations:

  • Selecting Resources For Your Part

  • Adding and Deleting States

  • Defining Values for each Property in each State

  • Setting the Same Value to Multiple States

  • Displaying Properties and States for Specified Parts

  • Changing the Objects Associated with a Resource

  • Viewing Multiple Resource Types

  • Editing Text and Font Resources in a Multiple Language Application

  • Deleting Resources

  • Copying Resources Between Targets and Projects

  • Setting Up Dynamic Content in a Text Resource

  • Sorting in the Text Resource Editor
