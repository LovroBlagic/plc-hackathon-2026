Deleting States

  1. Select the row by clicking the state number.

  1. Use the Delete State icon , or right-click the selected row and click Delete State. You can delete numbered states only. In the example, the purple colored state is deleted and the remaining number states are 0 to 3.

  • To delete multiple states, select multiple rows (states) then use the Delete State icon .
