9.5 Operations

This section lists all the available operations for Vijeo-Designer. Be aware that not every operation will be supported for each target machine and each Switch, Selector, Function Key, Action, and Touch Animation. When in doubt as to what is supported, refer to the Editor because the Editor will only list the operations that are supported for the selected target machine, Switch, Selector, etc.
