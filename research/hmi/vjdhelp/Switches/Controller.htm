9.5.18 Controller Operations

Use the dialog to set up the start and stop operations for the controller application.

  • Start - Starts the application program on the XBTGC controller or the PLC controller

  • Stop - Stops the application program on the XBTGC controller or the PLC controller

 

  • Alternatively, you can use a Toolchest part to start and stop the controller. For more information on this Toolchest part, see Section 4.13.3, Controller Operations.
