9.2.7 Creating a Custom Switch

You can create your own switch by drawing the object that you want to use as your switch and then adding Touch animation to the object. To do this, choose an object from the Graphical Objects toolbar, and then use the Animation Properties dialog box to add Touch animation to the object. You can also add other animation at the same time, if required.

Steps

1. Draw an object to be used as a switch.

2. Add Touch animation to the object you have created.

3. Specify the condition for Touch animation to run.

 

 

  • If you want to create a radio button, delay switch, and alarm operation switch, use parts. For more information, see Section 9.2, Creating Switches and Section 9.2.6.1, Example of Creating a Switch.
