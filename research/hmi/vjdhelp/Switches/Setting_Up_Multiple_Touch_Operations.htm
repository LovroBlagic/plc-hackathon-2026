9.2.7.4 Setting Up Multiple Touch Operations

You can set up multiple touch operations on a switch created using a graphical object, such as a rectangle or ellipse. When working with Touch Animation, you can add up to 32 Touch operations. For more information on operations, see Section 9.5, Operations.

 

Select the following buttons to add or remove touch operations.

Button

Description

Add

Adds a new line at the end of the list.

Insert

Adds a new line before the selected line. For example, if you want to insert a new line between lines 6 and 7, select line 7 and click Insert.

Delete

Deletes the selected line.

Delete All

Deletes all the touch operations in the list. You cannot delete the first line.

Moves one line up in the list.

Moves one line down in the list.
