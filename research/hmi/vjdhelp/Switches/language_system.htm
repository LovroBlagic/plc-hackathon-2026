9.5.8 Language Operations

Use the dialog to set up language-related operations. For example, you can create an operation that changes the displayed language. For more information about each option, see Section 20.2, Switching Languages.

 

Operation

Description

Change System Language

Changes to the specified language. The error messages and configuration menu is displayed in the specified language in Runtime.

This list shows only the system languages you've selected in the System Language Manager. For details, see Section 20.2.2 Configuring the System Language.

Change User Language

Changes to the specified language, when multiple languages are set up. The display changes to the selected language.
