9.4.4 Example of Creating an Action

Both the PLC and target machine use internal clocks. The following steps describe how to synchronize the date and time on a PLC and target machine with an action that runs once every 24 hours.

To create this action, review the following sections:

  • Before Writing the Action

  • Creating the Action

  • Actions that update the date/time on the target machine from equipment should not be run every second or even every minute. Only run actions when necessary.

Before Writing the Action

This action can be run in the following environment:

Target Machine

Can be set up to run on all target machines.

Equipment

Any equipment supported by Vijeo-Designer

Device Addresses

30220 to 30222

30230 to 30232

  • This example uses device addresses for a Modbus PLC. Actual device addresses differ depending the type and model of PLC you use. See your PLC manual for details.

 

You also need to create the following variables for use in the action.

Variable Name

Description

PLC_Date_Year

External variable, integer data type, associated with the device address (30220) that stores the Year. Make sure the value range is 1980 to 2037.

PLC_Date_Month

External variable, integer data type, associated with the device address (30221) that stores the Month. Make sure the value range is 1 to 12.

PLC_Date_Day

External variable, integer data type, associated with the device address (30222) that stores the Date. Make sure the value range is 1 to 31.

PLC_Date_Hours

External variable, integer data type, associated with the device address (30230) that stores the Hours portion of the time. Make sure the value range is 0 to 23.

PLC_Date_Minutes

External variable, integer data type, associated with the device address (30231) that stores the Minutes portion of the time. Make sure the value range is 0 to 59.

PLC_Date_Seconds

External variable, integer data type, associated with the device address (30232) that stores the Seconds portion of the time. Make sure the value range is 0 to 59.

Creating the Action

Because the date/time synchronization must run no matter what panel is displayed, we need to use an action. The following sample runs the action every day at midnight.

  • In the Navigator window's Project node, add an action and set these properties:

  • Trigger Type: Conditional

  • Trigger Variable: PLC_Date_Day

  • Trigger Condition: On Data Change

  • Trigger Description: Set_Date_Time

  1. The action runs when the date changes. The trigger condition for On Data Change tracks when the date changes. This action runs each night at midnight when the date changes.

The following script divides BCD 4-digit data into upper and lower 2-digits, then converts the data from BCD to BIN format. The script assumes a Vijeo-Designer variable named BCD_4 is associated with the device address that stores the time as a BCD 4-digit value.

// Create and initialize script variables

int BCD_HL;

int BCD_High=0, BCD_Low=0, hours=0, minutes=0;

 

// Read value from Vijeo-Designer variable BCD_4

// Assign to local script var BCD_HL

BCD_HL = BCD_4.getIntValue();

 

// Mask bottom bits, shift to lower bits

BCD_High = (BCD_HL & 0xff00) >> 8;

 

// Mask upper bits

BCD_Low = BCD_HL & 0xff;

 

// Convert BCD to binary to get hours

hours = (BCD_High/16)*10 +(BCD_High%16);

PLC_Date_Hours.write(hours);

 

// Convert BCD to binary to get minutes

minutes =(BCD_Low/16)*10 +(BCD_Low%16);

PLC_Date_Minutes.write(minutes);
