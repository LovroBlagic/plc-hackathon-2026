9.4.5 Example of Creating a Panel Action

You are required to view event messages in run time. The following steps describe how to open the Event Log Viewer when the panel is displayed at run time.

  1. In the Navigator window's Project tab, right-click the Panel or Panel Actions node, and click New Action.

  2. In the Action Settings dialog box, define the following properties and click Next.

  3. Trigger Type—set to Event.

  4. Trigger Event—set to On Open.

  1. Select the System operation, select Event Log, and click Add.

  2. Click Finish.

For more information on the Action Settings properties, see Section 9.4.2, Actions Wizard.
