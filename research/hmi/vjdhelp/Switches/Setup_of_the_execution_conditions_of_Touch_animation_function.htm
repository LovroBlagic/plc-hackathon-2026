9.2.7.3 Setting Up Conditions for Touch Animation

  1. Double-click the Condition cell to open the Condition Setting dialog box.

  1.  Select either Always or Conditional in the Conditional dialog box, described as follows:

Condition

Description

Always

The switch is always enabled.

Conditional

The switch is enabled only if the specified variable or expression is True.

In the If text box, specify a BOOL or integer variable or expression for reference.

The following table shows each data type and their True and False values.

 

Data Type

True/ON

False/OFF

BOOL

1

0

Integer

Other than 0

0

  1. Click OK to confirm the settings and close the Condition Setting dialog box.

  2. In the Animation Properties dialog box, click OK to confirm the settings, and close the Animation Properties dialog box.

  • If the specified variable does not exist in the project, the New Variable dialog box opens when you click another Animation tab, the Apply button, or OK to exit the Animation Properties dialog box. Create a new variable in this dialog box.

  • Instead of clicking OK to confirm settings, you can click Apply or the tab for a different animation.
