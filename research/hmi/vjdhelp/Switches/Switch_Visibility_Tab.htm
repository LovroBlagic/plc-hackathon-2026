9.2.4 Switch Visibility Tab

Use the Visibility tab to set up features such as Visibility and Blink.

 

Property

Description

Enable Visibility

Select Enable Visibility and then select a variable that controls whether the switch is visible (ON) or not (OFF). You can set up a BOOL or integer variable, or a boolean expression.

  • If true, the switch will be displayed

  • If false, the switch will not be displayed.

  • If the switch is not visible, the Touch operation is disabled.

Invisible when in invalid state

This check box is not available for switches.

Enable Blink

Select Enable Blink to make the switch blink. You can set up a BOOL or integer variable, or a boolean expression.

  • If true, the switch will blink.

  • If false, the switch will not blink.

  • If the switch is not visible, the Touch operation is disabled.

Speed

Set the blinking speed to fast or slow. A fast blink rate is 350 ms and a slow blink rate is 700 ms.
