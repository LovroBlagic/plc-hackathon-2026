9.5.22 Event Message Operations

Use the dialog to set up an event message operation, so that at runtime, you can generate a custom event message.

 

Property

Description

Event Group

Defines the event group that the custom message will appear in.

Text Resource

Adds the text resource where the custom messages have been defined.

  •  Creates a new text resource. You can define the custom messages within this new text resource. For more information on how to create a text resource, see Section 21.1.4.1, Creating Resources. For more information on how to create dynamic content in a text message using a text resource, see Section 21.1.5.12, Setting Up Messages with Dynamic Content.

  •  Exits the Switch Settings dialog box and opens the Text Resource Editor. You can edit predefined custom messages in the Text Resource Editor.

  • If you define custom event messages using Text Resources, limit your message to 160 characters. Messages that exceed this limit will be truncated in the Event Summary's Message column.

Use Predefined Message

Allows you to choose a message from the set of predefined messages in the text resource.

Message

Allows you to select a predefined message from the drop-down list.

Use Message Index

Allows you to choose the message to display at runtime by entering an integer variable that references the message Index. The Index is the value associated with the Integer Value of each message in the text resource.

Variable

Allows you to select the integer variable from the Variables List.
