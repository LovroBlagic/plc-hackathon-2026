9.3.8 Selector Advanced Tab

 

Property

Description

Enable Interlock

Select Enable Interlock to set up a condition that must be true in order to change the state. The condition can be a BOOL, integer variable, or boolean expression. For more information, see Section 9.6, Using Interlock to Prevent Accidental Touch Input.

  • During data input, if the interlock variable turns OFF, data input is cancelled.

Security Level

Sets the Security Level for the Selector. Once a Security Level is defined, only users with the correct security level can access the Selector's functions. For more information on security levels, see Section 4.8.2.1, Protecting Panels and Parts from Unauthorized Users.
