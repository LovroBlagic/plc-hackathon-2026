9.5.10 System Operations

Use the dialog to set up operations related to the run time. For example, you can create an operation that restarts Runtime, exits Runtime, or displays the configuration menu.

Property

Description

Restart Runtime

Restarts the run-time application.

Exit Runtime

Shuts down Vijeo Designer Runtime on the target by performing all of the following:

  • Stops all run-time operations on the target

  • Stops all PLC communications on the target

  • Runs all On Shutdown Event Actions on the target - For more information on Shutdown Event Actions, see Section 9.4.2, Actions Wizard.

  • Flushes the target's simulated SRAM data to the target's Main Drive - For information on the Main Drive, See Section 5.11.1, Types of Data Locations. For information on flushing SRAM, see SRAM Data Flush Rate in Section 4.5.1, Target Properties.

  • Exits Vijeo Designer Runtime. Windows based targets (iPC, XBTGTW) exit and return to the target's operating system screen. All other targets exit and show a shutdown panel that allows you to restart or power off the target.

  • Not all target machines use simulated SRAM, see Appendix 5, Hardware Specification.

Configuration

Opens the Runtime configuration menu. For more information, see Chapter 26, Setting Up the Target Machine.

System Error Log

Allows you to display the System Error Log viewer.

Login Screen

Allows you to display the System Login Screen. For more information, see Section 4.8.4.1, Logging In at Run-Time.

Logout

Allows you to logout a user. For more information, see Section 4.8.4.2, Logging Out at Run-Time.

Lock Input

Locks out all touch inputs on the target machine.

  • Be aware that once you lockout touch inputs on the target, you cannot unlock touch inputs using a touch input method such as a Switch, Function Key, etc. We recommend setting up a scheduled Action to unlock touch inputs, see Section 9.4, Creating Actions.

Unlock Input

Unlocks the locked out touch inputs on the target machine.

 

  • For switches, you can only set up system operations in the When Touch tab.

  • You can set either a panel operation or a system operation in the part. Only one of those operations can be used in the part at one time.
