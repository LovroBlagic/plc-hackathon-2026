9.3.6 Selector Input Mode Tab

 

Property

Description

Enable Input Mode

Enables data input using a popup keypad or touch actions.

  • If you configure an expression or a float variable in the Variable property, Input Mode is unavailable.

Field ID

Set up a unique field ID for triggering the input mode from the _TouchField system variable. The field ID must be a value between 0 and 2,147,483,647. The default value is 0. If the Field ID's value is 0, the input mode cannot be triggered from the system variable. Each Field ID should be unique for your project. For more information on system variables, see Section 6.7, System Variables.

Display Popup Keypad

Touching the Selector pops up a keypad.

Select the type of popup keypad you want to use.

  • Change-Immediate: Keypad that increments or decrements the state right away. To see what the keypad looks like, see Section 11.9.2.4 Change-Immediate Keypad.

  • Change-On-Enter: Keypad that increments or decrements a value, then changes to the selected state only when you touch the Enter key. To see what the keypad looks like, see Section 11.9.2.5, Change-On-Enter Keypad.

  • Numeric: Displays a decimal keypad. To see what the keypad looks like, see Section 11.9.2.2, Numeric Keypads.

  • The Numeric Keypad is not available when the Selector's Control Type is Word by Bit.

  • The Selector's Numeric Keypad cannot write decimals to the control variable.

Increment Only

Touching the Selector increases the state. When you reach the last state and you touch the display again, you can choose to either not change the state (Stop at End), or display state zero (Rollover to Beginning).

Decrement Only

Touching the Selector decreases the state.

When you reach state zero and you touch the display again, you can choose to either not change the state (Stop at Beginning), or display the last state (Rollover to End.)

Hold Delay

If you select this check box, you can add a delay (1 to 60 seconds) to the initial touch input.

When using a popup keypad, the keypad displays only after you've touched the display continuously for the defined number of seconds.

When using the increment or decrement operation, the display increases or decreases the state only after you've touched the display continuously for the defined number of seconds.

Buzzer On Touch

If you select this check box, the target machine beeps when the Selector is touched.

Enable Actions

Enables you to add operations for the Selector's states. You can add up to a maximum of 16 operations for each state.

  • When actions are enabled, you must set up at least one action for the Selector.

  • Operations are only triggered when the user changes the Selector's state through touch inputs. Operations do not trigger when the value of the control variable is changed by the PLC or other touch objects.

State

This property specifies the state you are configuring the label for. Use either the drop-down list of the next and previous buttons to select the state. The number of states is configured in the General Tab, see Section 9.3.3, Selector General Tab.

Operation

Select from one of eleven types of operations. The operations run when an operator touches the Selector to advance the Selector into its next state. The list of available operations depends on your type of target machine. Check the Editor to see the list of supported operations. For the list of all available operations and descriptions of the operations, see Section 9.5, Operations. For more information on creating multiple operations for one selector, see Section 9.5.19, Setting Up Multiple Operations.

  • Only one system operation can be set up for each Selector.

  • Only one panel operation can be set up for each Selector.

  • Selectors do not support Alarm Operations and Bit Momentary ON/OFF Operations.

Operation List

Displays a list of the operations for the state.

For each state, you can set up 16 operations. For details, see Section 9.5.19, Setting Up Multiple Operations.
