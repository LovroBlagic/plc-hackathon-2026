9.5.20 E-mail Operations

Use the dialog to set up an e-mail recipient, subject, message, and attachment for the E-mail operation. E-mail messages can be a text message or a Vijeo Designer Form. By using a form, you can e-mail current variable values, current alarm statuses, current recipe values, etc. E-mail text messages can contain dynamic content such as variable values and time stamps. For more information on adding dynamic content to e-mails, Section 21.1.5.12, Setting Up Messages with Dynamic Content: Adding Dynamic Content. For more information on creating forms, see Section 27.3, Working with Forms.

You can also send Email or SMS messages to your tablet/smartphone with a link to open the Vijeo Design’Air Plus App and launch the alarm page. For more information, see Accessing the Alarm Panel from Email or SMS message in Section 23.1.1.3 Working in Vijeo Design’Air Plus.

  • To use E-mail operations on the target machine, set E-mail to Enabled in the Target properties.

Select either of these options:

  • Alias, to send to an alias name that represents one or more e-mail addresses. Use the drop-down list box to select an Alias. If you select this option, you cannot modify e-mail addresses at run time.

Define the message. You can enter up to 1000 characters in the e-mail message, which may include regular text and dynamic content. You can enter up to 160 characters in SMS messages to your smartphone. For information on content length, see Determining Content Length in an E-mail Subject and Message.

The <Attachment info> displayed beside this check box indicates the type of attachment set up for the e-mail.

 

Determining Content Length in an E-mail Subject and Message

For regular text, the content length is the number of characters entered.

For dynamic content that uses a time stamp, the content length is determined by the length of the format string. For example, the character count in the YYYY/mm/dd format string is 10 characters.

For dynamic content that uses a variable, the content length is determined as follows:

  • The content length is the variable value (the output), not the variable name. The only time the variable name counts as the content length is when a variable that does not exist is entered, for example:

    <var:Folder01.Folder02.REAL01>
    The variable REAL01 does not exist. The variable name (    Folder01.Folder02.REAL01) is counted as the content length, which is 24.

  • For the following variables, the content lengths are as follows:

    String Variable     - The content length is the value (up to a maximum of 100 characters) defined in the Num of Bytes property in the Variable Properties dialog box. For example, if the Num of Bytes property is defined as 30, the content length is 30. The following is an example of a String variable in the dynamic content:
    <var:STRING01>

    BOOL Variable     - The content length is 1 character. The BOOL value is either 0 or 1. The following is an example of a BOOL variable in the dynamic content:
    <var:Folder01.Folder02.Folder02.Folder04.Folder05.BOOL01>

    Integer Variable     - The content length is 10 characters. The following is an example of an Integer variable in the dynamic content:
    <var:Folder01.Folder02.Folder02.Folder04.Folder05.DINT01>

    Real Variable     - The content length is 17 characters. The following is an example of a Real variable in the dynamic content:
    <var:Folder01.Folder02.REAL03>
     

  • You can provide an explicit format string to specify the content length of the String, BOOL, Integer, or Real variable value, for example:

    <var:STRING01,20>
    Though the Num of Bytes property is defined as 30, the String's byte length specified in the explicit format string, which is 20, takes precedence.

Configuring the Attachment Settings

In the Attachment dialog box, specify the attachment by configuring the following settings:  

Property

Description

Type

Select one of the following types of data you want to attach:

  • Alarm & Event. Attaches a CSV file of the specified alarm or event group, system error group, system event group, or alarm category to the e-mail.

  • Captured Image. Attaches an image you captured to the e-mail (for example, a JPG file).

  • Data Logging. Attaches DAT data logging files to the e-mail.

  • File. Attaches any file on the target that you want to send with the e-mail.

  • Recipe. Attaches RCP or CSV recipe files to the e-mail.

  • Recorded Video. Attaches a video you recorded to the e-mail (for example, a MPG file).

Alarm Group / Variable / Recipe Group

If the Type property is set to:

  • Alarm & Event, the Alarm Group property is displayed. In the drop-down list box, select the alarm group, event group or category to attach to the e-mail so its data is in the CSV file attachment.

  • Recipe, the Recipe Group property is displayed. In the drop-down list box, select the recipe group so its data is in the RCP or CSV file attachment.

    When data is selected as the CSV file type, select the Source Drive as either the Secondary Drive or Optional Drive. The Source Drive selection depends on where the recipe CSV file is generated at run time. To determine this, configure a switch with a Copy Data to Drive operation with Recipe selected. Then use the Destination Drive to indicate the Source Drive.

  • Data Logging, the Variable property is displayed. Select the variable associated with the logging group so its data is in the DAT file attachment.

  • Captured Image, File, or Recorded Video, the Variable property is disabled.

Newest File by Date

The file with the latest time stamp is attached to the e-mail.

This property is disabled if the Type property is set to File.

File Name from Variable

Select if you want to attach a string variable to the e-mail. The variable's value must include the file name. At run time, Vijeo Designer looks for the file in the following location:

<Defined Drive Location> \PUBLIC\PROJECTS\<target name>\DATA\<Type folder>

For non-iPC targets, the <Defined Drive Location> is the USB drive or the CF Card/SD Card.

Depending on the type of the attachment, the file is stored in one of the following folders:

  • Alarm and Event: ALARM\<alarm group name>

  • Data Logging: LOG

  • Captured Image: SNAPSHOT

  • Recorded Video: VIDEO

When you set the type of the attachment to File, you must specify the full path and file name in the string variable.

You can not use this method to select recipes.

File Name

Select if you want to attach the file specified in the text box. Enter the file name in the text box. If the Type property is set to File, you must enter the full path and file name. The text box allows a maximum of 100 characters.

This property is disabled if the Type property is set to Recipe.

Latest Records

Select if you want to attach the latest alarm or event records. This property is displayed when the Type property is set to Alarm & Event.

  • Alarm & Event List: Select the database  (Active, History, or Log) to retrieve the records from. For an event group, you can only select History or Log records.

  • If Active is selected for an event group, no records will be retrieved for the e-mail attachment.

  • Most Recent: Enter the number of most recent records to retrieve from the database. You can specify up to 200 most recent records from the Active, History, or Log database.

  • All: Select if you want to retrieve all the records from the Active, History, or Log database.

Recipe Format

Select the recipe file format (RCP or CSV) for the recipe attachment. This property is enabled only when the Type property is set to Recipe.
