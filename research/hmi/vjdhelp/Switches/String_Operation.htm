9.5.3 String Operations

Use the dialog to set up String operations. The string operation can either write a string to the defined string variable or add a string to the defined string variable.

 

Property

Description

Overwrite

Writes the string in the Source field to the String variable in the Destination field.

Add

Adds the string in the Source field to the String variable in the Destination field.

 

  • When using an external variable with a very small frequency (for example, 1 second), the action may execute before the PLC has fully initiated. Therefore, the external variable may not be updated properly when the Action is first triggered, causing unexpected results.
