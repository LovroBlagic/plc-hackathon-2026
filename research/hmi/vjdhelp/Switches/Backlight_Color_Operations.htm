9.5.21 Backlight Color Operations

Use the dialog to configure the backlight color for the panel, so that at runtime, the backlight color can change in response to various events that occur. For more information on which targets support the Backlight Color operation, see Appendix 5, Hardware Specifications.

The backlight colors and values that are available are specific to the target you are using. The value 255 (Relinquish) selection means you do not want the backlight color to be set priority event that occurs. The backlight color will fall back to the color set for the next priority event that does not have Relinquish as the setting. For more information, see Section 16.5.2, Changing the Backlight Color.
