9.5.9 Script Operations

Use the dialog to set up script operations. You can create an operation that executes a script. Click New Script to open the Script editor window, and enter the script you want to run. Click Add to add the script directly to the operation list.

 

When editing an existing script, click Apply to apply any edits to the script. Click Add to add another copy of the script to the operation list.

For more information, see Chapter 18, Scripts, and Section 18.3, Writing Scripts.
