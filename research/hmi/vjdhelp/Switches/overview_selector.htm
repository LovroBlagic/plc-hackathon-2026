9.3.1 Circular Selector

The Circular Selector is a rectangular part with a rotating indicator in the center. The indicator's rotation is controlled by a control variable. When the value of the control variable changes, the indicator rotates into the corresponding state on the Circular Selector. Each Circular Selector can have 2 to 32 states when Word by Value is selected or 2 to 33 states when Word by Bit is selected. The Circular Selector's labels and scales identify the states on the Circular Selector. Each state can be set up with actions (max 16 actions per state) that trigger when panel operator changes the Selector's state by touch inputs.
