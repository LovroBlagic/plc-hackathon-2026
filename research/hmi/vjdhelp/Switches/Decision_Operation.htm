9.5.23 Decision Operation

Use the dialog to set up a decision operation. The decision operation runs sets of operations depending on the decision expression’s true/false value. You can create a set of operations to run for the expression’s true value and create a different set of operations to run for the expression’s false value. For more information on expressions, see Section 6.14, Assigning Variables Using Expressions.

  • Decision operations cannot be nested within other decision operations.

  • Not all operations are available for the decision operation. Click the add button to view the list of operations available for the decision operation.

Property

Description

IF

Defines the decision operation's expression. For more information on entering expressions, see Section 6.14.2, Entering Expressions.

TRUE

Defines the operations to run when the expression is true.

FALSE

Defines the operations to run when the expression is false.

*

The asterisk displays above the true and false operation lists. The asterisk indicates an operation modified in the true or false operation lists is not updated in the switch’s operation list. Click the Apply button to update the switch’s operation list with the modified decision operation.

 

Decision Operation Buttons

Button

Description

The Add button adds operations.

The Edit button edit the selected operation.

The Delete button deletes the selected operation.

The Up Down buttons change the order or the selected operation. Operations run in the order they are defined in. For more information on running multiple operations, see Section 9.5.19, Setting Up Multiple Operations.
