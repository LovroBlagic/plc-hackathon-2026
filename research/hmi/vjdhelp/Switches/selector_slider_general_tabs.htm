9.3.3 Selector General Tab

This section describes how to define the settings in the General Tab for:

  • Circular Selector

  • Vertical/Horizontal Selector

Circular Selector Settings General Tab

The following table describes the General Tab's Properties.

Property

Description

Name

The Selector's name.

The Selector's name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions. See Appendix 9, Naming Conventions.

Indicator Style

Select the Indicator style from the Indicator Style drop-down list. Select Browse to open a Style Browser that contains a larger list of Indicators to choose from.

Indicator Size

Specify the size of the Indicator. An Indicator's size is defined as a percentage of the Selector's radius, which is measured differently in the following two situations:

  • Selector without labels
    If labels are disabled, Indicator Size is defined as a percentage of the Selector's radius, measured from the center of the Selector to the edge of the Selector's plate.

  • Selector with labels
    If labels are enabled, Indicator Size is defined as a percentage of the Selector's radius, measured from the center of the Selector to the edge of the longest label.

  • The Indicator's size cannot be less than 20%.

Num Of States

Specify the number of states the for the Selector. You can select between 2 to 32 states when Word by Value is selected or 2 to 33 states when Word by Bit is selected.

Control Type

Select the method to control the Selector. Select Word by Bit or Word by Value.

Word by Bit

When you select the Word by Bit method, the Number of States you specify (2–33) determines the maximum number of bit positions. The number of states includes state 0 (when all the bits are OFF) and each bit position from bit 0 to bit 31 for 33 states.

The following diagram shows the state of the Selector as determined by the bit position that is set to ON.

  • If you specify an external variable with a bit length of 16 bits, the maximum number of states is 17.

  • If a bit greater than the highest state (as defined by the Number of States) is ON, the Selector displays in its Invalid State.
    In the following example, there are 22 States (State 0 to State 20) and all bits are off. If any bit higher than bit 20 is ON, the state will be Invalid.

  • If more than one bit is ON, the highest bit defines the state.
    In the following example, there are 17 States (All Off, and Bit 0 to Bit 15). If Bit 1 and Bit 15 are ON, the state is 16.

  • When a Float variable is selected as the control variable, Float values are typecast into Integer values and then evaluated as a binary number, which controls the Selector's state.

Word by Value

When you select the Word by Value method, you can set up 2 to 32 states. The variable value (0–31) defines the Selector state.

  • If the value of the variable is less than 0 or greater than the highest defined state, the Selector will display in the invalid state.

  • When a REAL variable is selected for the control variable, real values are typecast into a Integer value, which defines the Selector's state. For example, the real value 5.6 is typecast into the Integer value 5, which sets the Selector's state to 5.

Value List

When you select the Value List method, you can set up values to a selector's state. When the control variable's value switches to one of the values in the value list, the selector switches to the corresponding state. To open the Value List dialog box and enter values, click the icon beside the property. For more information, see Section 21.8, Using Value List.

Variable

Defines the variable that controls the Selector's states.

The Variable field accepts integer variables, REAL variables, expressions, and BOOL variables.

  • If you configure an expression or a REAL variable in the Variable property, Input Mode is unavailable.

You can set up a variable placeholder for a message or image display. Select the structure variable and the element from the Variable List. To edit the variable placeholder you have set up for your object, in the Property Inspector for the object, click the ellipsis to open the Placeholders dialog box. The dialog box only displays if you had set up a placeholder for the object. For more information on placeholders, see Section 21.2.4, Working with Variable Placeholders.

Category

The Category's drop-down list defines the Selector's Plate Style.

Select from:

  • Primitive
    Primitive allows you select the Selector's Plate Style from the predefined styles available in the Plate Style drop-down list.

  • User Defined
    User Defined allows you to select your own image as the Selector's Plate Style. Add the image to the Selector in the Color tab; see Section 9.3.4, Selector Color Tab.

Plate Style

Available when Category is set to Primitive. This property defines that the Selector part looks like. Select the Selector's Plate Style from the drop-down list. Click Browse to open a Style Browser that contains a larger list of Plate Styles to choose from.

Start Angle

Defines the angle where the Indicator begins its rotation.

The image below shows how the degrees are marked on the Circular Selector.

End Angle

Defines the angle where the Indicator ends its rotation.

Direction

Defines the direction the Indicator rotates:

  • Clockwise

  • Counter Clockwise

Selector Preview

This feature creates a preview of the Selector based on the settings you defined in the Start Angle, End Angle, and Direction properties.

Show Scale

This property enables each of the Selector's states to have a scale.

Width

Specifies the width of the Selector's scales. Select a width between 1 and 9 pixels.

Length

Specifies the length of the Selector's scales. Length is defined as a percentage, which is measured differently in the following two situations:

  • Selector without labels
    If labels are disabled, the Scale Length is measured from the edge of the Indicator to the Selector's plate.

  • Selector with labels
    If labels are enabled, Scale Length is measured from the edge of the Indicator to the edge of the longest label.

Indicator Width and Height

Specify the Indicator's Width. The Indicator's Width is defined as a percentage. The percentage is measured differently for the Vertical Selector and the Horizontal Selector.

  • The Indicator's width and height cannot be less than 20%.

Vertical Selector

The width for the Vertical Selector's Indicator is measured differently in the following two situations:

  • Vertical Selector is without labels:
    If labels are disabled, the Indicator Width is measured as the width of the Plate.

  • Vertical Selector has labels:
    If labels are enabled, the Indicator Width is measured from the side of the Plate to the edge of the longest label.

The height for the Vertical Selector's Indicator is measured as a percentage of the Indicator's width. For example, if your Indicator's width is 100 pixels and you specified 50% as the Indicator height, the height will be 50 pixels.

Horizontal Selector

The width for the Horizontal Selector's Indicator is measured as a percentage of the Indicator's height.

For example, if your Indicator's height is 100 pixels and you specified 50% for the Indicator's width, the Indicator's width will be 50 pixels.

The height for the Horizontal Selector's Indicator is measured differently in the following two situations:

  • Horizontal Selector is without labels
    If labels are disabled, Indicator height is measured as a percentage of the plate's height.

  • Horizontal Selector has labels
    If labels are enabled, Indicator Width is measured from the side of the Plate to the edge of the label.
