9.5.1 Bit Operations

This section describes how to select operations for the bit operation. A bit operation allows you to set, reset, and toggle single bit of data.

Operation

Description

Set

Turns on the BOOL variable specified in the Destination field.

Reset

Turns off the BOOL variable specified in the Destination field.

Toggle

Toggles on/off the BOOL variable specified in the Destination field.

  • If the Bit is on, it turns off when triggered.

  • If the Bit is off, it turns on when triggered

Momentary ON

Turns on the BOOL variable specified in the Destination field while the part is touched. When the part is released, the variable turns off.

Momentary OFF

Turns off the BOOL variable specified in the Destination field while the part is touched. When the part is released, the variable turns on.

 

 

  • For switches, the only bit operation you can set up in the While Touch tab is Momentary ON/OFF.

  • For actions, the Momentary ON and Momentary OFF options are not available.

  • When using an external variable with a very small frequency (for example, 1 second), the action may execute before the PLC has fully initiated. Therefore, the external variable may not be updated properly when the Action is first triggered, causing unexpected results.
