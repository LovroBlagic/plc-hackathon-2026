9.5.5 Popup Window Operations

Use the dialog to set up Popup-related operations. For information on how to set up Popup windows, see Section 15.1.2, Steps to Set Up Popup Windows.

 

Operation

Description

Open Popup or
Close Popup

Open Popup opens the popup window panel. You can also specify the coordinates for the popup window panel in the Location property.

Close Popup closes the popup window panel.

Panel Name or
Panel ID (Expression)

Select Panel Name for a static popup window display. Select Panel ID (Expression) when you want to dynamically define the popup window panel.

From the Panel Name drop-down list, select the panel to display in the popup window.

In the Panel ID (Expression) list:

  • Select the popup window group that contains the popup window panel you want to display.

  • In the Variable field, define a variable or expression that results in an integer value.

Location

When set to Open Popup, you can specify the location where the popup window panel will open at runtime.

  • At Position—opens the popup window panel at the specified (x,y) coordinates. If you specify (0,0) as the x,y coordinates, the top left corner of the popup window panel displays in the top-left corner of the graphical panel.

  • Centered—opens the popup window panel in the center of the screen.

 

  • There are two types of popup windows.

  • Panel Only: The popup window closes when you change panels.

  • Persistent: The popup window remains open even when you change panels.

  • Popup windows are set up in the Popup Window Group's properties. See Section 15.2, Setting Up Popup Windows.
