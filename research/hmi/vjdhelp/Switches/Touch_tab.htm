9.2.1 Switch General Tab

This section describes how to define the general settings for a switch and a radio button.

  • Switch Settings

  • Radio Button Settings

Switch Settings

In the General tab, define a mode for the switch, and select the shape of the switch and the operations that run when the switch is touched, while it's touched, and when it's released.

The following table describes each property in the General tab.

Property

Description

Mode

Select either Switch or Switch with Lamp.

Switch

No control to change the switch color. This is the default selection.

Switch with Lamp

The switch changes color or label based on the value of the lamp variable.

Name

The switch's name.

Whenever a switch is created, a default name is generated. When renaming an switch, its name must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

For details, see Appendix 9, Naming Conventions.

Lamp

Set up the variable to control the switch color and label. Use the lamp variable to provide feedback when the state actually changes. This property is enabled only when Switch with Lamp mode is selected.

Category

Select either Primitive, Bitmap or User Defined. Depending on the category you select here, the shapes in the Style list change.

Category

Description

Primitive

Defines the shapes available in the Style list. Using Primitive, you can define colors for the various states of a switch.

Bitmap

Defines the bitmap shapes available in the Style list. You cannot edit colors using this option.

User Defined

Allows you to define your own images for the various states of the switch. To select your own images, in the Category field, set to User Defined and define the image for the corresponding switch state in the Color tab.

Style

Defines the shape of the switch. The shapes available differ depending on the category (Primitive, Bitmap, or User Defined).

 

When category is Primitive or Bitmap:

  • Select a switch image thumbnail from the list.

  • Click Browse... to open the Style Browser and select a pre-defined switch image.

  • Specify the colors for the Primitive switch. Bitmap and pre-defined switch colors cannot be changed.

When category is User Defined:

  • Select the bitmap images created for your project.

  • In the Color tab, click the Browse button and set images for a switch's Up/Down and On/Off states.

  • Colors for User Defined images cannot be changed in Vijeo-Designer. Use the program that created the images to modify their colors.

Reverse on Touch

Select to reverse the switch colors when touched.

Set up operations for each of the three touch conditions.

 

 

Touch Condition

Description

When Touch tab

Defines the operations that run when the switch is touched.

While Touch tab

Defines the operations that are repeatedly run while the switch is touched. The list of available operations depends on your type of target machine. Check the Editor to see the list of supported operations.

When Release tab

Defines the operations that run when you stop touching the switch. The list of available operations depends on your type of target machine. Check the Editor to see the list of supported operations.

Operation

Select one of the following operations. The Operation settings depend on the type of operation you select. The list of available operations depends on your type of target machine. Check the Editor to see the list of supported operations. For the list of all available operations and descriptions of the operations, see Section 9.5 Operations. For more information on creating multiple operations for one switch, see Section 9.5.19, Setting Up Multiple Operations.

Operation list

Displays in each touch tab a list of the operations that run when a touch takes place. On a single switch, you can set up a total of 32 operations.  See Section 9.5, Operations for the list of available operations. For information on setting up multiple operations, see Section 9.5.19, Setting Up Multiple Operations.

Category

Description

Primitive

Defines the shapes available in the Style list. Using Primitive, you can define colors for the various states of a switch.

Bitmap

Defines the bitmap shapes available in the Style list. The list includes bitmap images that you had previously defined. You cannot edit colors using this option.

When category is Primitive or Bitmap:

  • Select a switch image thumbnail from the list.

When category is User Defined:

  • Select the BMP, PNG, or JPG images created for your project.

  • In the Color tab, click the Browse button and set the image for a switch's Up/Down and On/Off states.

  • Colors for User Defined images cannot be changed in Vijeo-Designer. Use the program that created the images to modify their colors.

Reverse on Touch

When selected, the switch reverses colors when touched.

Radio Action

Group ID

Define a group number from 1 to 1000. Multiple switches with the same Group ID act as a single radio button

  • You can only set up radio switches on the same panel. If you place radio buttons with the same ID on separate panels, they will operate as two different radio buttons.

Off Delay

Select this option and define the number of seconds. For radio buttons that use this feature, when the switch is touched and turned ON, it turns OFF after the defined number of seconds elapse. You can define a delay from 1 to 60 seconds.

  • If the variable (bit) assigned to the radio button is turned ON by a method such as using a program on equipment or script other than the Touch operation, the Off Delay is ignored.

Radio Variable

When the switch is touched, the variable defined in this property turns ON. Other switches with the same group ID will be turned OFF.
