9.5.13.2 Checksum

The Checksum operation retrieves the application's checksum in an integer value. Programmers can use this feature to check the application's checksum and run different actions and operations based on the returned value. This feature is only available when the Check Project Integrity property is enabled in the target's properties. For more information, see Section 4.5.1, Target Properties.

Return Value

Returns -1 if the operation is not supported by the target machine.

Returns 32 bit unsigned integer value.

  • The application checksum can be retrieved using a script operation. For more information, see Section 18.9.1.5, System Methods: Sys.getInfoInt.
