9.2.5 Switch Advanced Tab

Use the Advanced tab to set up features such as Interlock and Buzzer.

 

Property

Description

Enable Interlock

Select Enable Interlock to set up a condition that must be true in order to use the switch. The condition can be a BOOL or integer variable or expression. For more information, see Section 9.6, Using Interlock to Prevent Accidental Touch Input.

Buzzer On Touch

If you select this check box, the target machine beeps when the switch is touched.

Hold Delay (sec)

If you select this checkbox, the delay feature can be set to the switch.

Pressing Time

The touch operations that you set in the Touch Action tab is executed after the switch is touched and held down for the number of seconds defined in this field. If the switch is released before the defined number of seconds, the touch operations will not be executed. The setting range is 1 to 60 seconds.

Enable Monitor

This feature, similar to a switch's lamp, changes the switch's display state according the value of a variable. When the Monitor variable turns ON, the switch displays in its on state. When the Monitor variable is OFF, the switch displays in its off state. The Monitor only controls the display of the switch and does not control any switch touch conditions.

  • Not all switch styles support the Monitor feature. Test your application thoroughly on the run-time platform before going into a production environment.

  • This property is unavailable for Radio buttons. See Section 9.2.6.2, Example of Creating a Radio Button.

Security Level

Sets the Security Level for the Switch. Once a Security Level is defined, only users with the correct security level can access the Switch's functions. For more information on security levels, see Section 4.8.2.1, Protecting Panels and Parts from Unauthorized Users.
