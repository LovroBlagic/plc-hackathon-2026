9.5.16 Image Capture Viewer Operations

Use the dialog to set up Image Capture Viewer operations.   

 

Property

Description

Image Capture Viewer

Select the Image Capture Viewer that the switch operations will interact with.

Forward

Go to the next JPEG image in the JPEG file list.

Backward

Go back one JPEG image in the JPEG file list.

Delete

Delete the JPEG image currently being viewed. This function is enabled only if you had selected the Allow Deletion check box in the Image Capture Viewer dialog box. For more information, see Section 7.2.14, Displaying JPEG Images.
