9.3.7 Selector Visibility Tab

 

Property

Description

Enable Visibility

This property makes the Selector invisible or visible.

When the value defined in this field is true (ON), the Selector is visible. When the value defined in this field is false (OFF), the Selector is invisible.

Select a BOOL or integer variable or enter a boolean expression to control the Selector's invisibility.

  • If in the middle of data input this variable turns off, your input will not be stored. Whatever you were typing will be gone.

Invisible when in invalid state

If selected, the Selector will not be drawn when it is in an invalid state. The Selector is in an invalid state if the value of the variable does not equal an Integer Value. For more information on assigning Integer Values to a state, see Section 21.8, Using Value List.

Enable Blink

Select Enable Blink to make the Selector blink. You can choose a BOOL or integer variable or enter a boolean expression.

  • If true, the Selector blinks.

  • If false, the Selector does not blink.

Speed

Set the blinking speed to fast or slow. A fast blink rate is 350 ms and a slow blink rate is 700 ms.
