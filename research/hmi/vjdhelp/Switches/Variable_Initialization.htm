9.5.24 Variable Initialization

Use the dialog to create a list of variables and initialization values for each variable. Once the variable initialization operation runs, the values write to the variables. Initialization values can be expressions, numbers, strings, or variables. For more information on expressions, see Section 6.14.1, What are Expressions?

To add a variable and set up an initialize value:

  1. Click the Add button to create a new row.

  2. Click the Variable cell and define the variable for the cell.
    For more information on defining variables, see Section 6.2.2.2, Creating Variables in Variable or Expression Fields.

  3. Click the Value cell and define a number, string, variable, or expression for the initialization value.
    For more information on defining expressions, see Section 6.14.2, Entering Expressions.

To delete a row:

  • Click a row and then click the Delete button.

To set a value to multiple variables:

  1. Hold Ctrl and click all the Value cells that you want to set the value for.

  2. Release Ctrl and define a number, string, variable, or expression for the initialization value in the open Value cell.
    For more information on defining variables, see Section 6.2.2.2, Creating Variables in Variable or Expression Fields. For more information on defining expressions, see Section 6.14.2, Entering Expressions.

Once you define an initialization value, the value populates to all the selected cells.
