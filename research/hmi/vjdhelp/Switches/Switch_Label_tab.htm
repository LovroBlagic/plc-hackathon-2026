9.2.3 Switch Label Tab

Use the Label tab to set up text to display on a switch. There are two Label Types available: Static and On/Off. For Static Label Type, the label you define appears on the switch for all the different switch states. For On/Off Label Type, you can create two different labels to correspond to the two On/Off Lamp States.

 

Property

Description

Label Type

To set up labels on the switch, select Static or On / Off.

  • Disabled: Select to disable the Switch labels.

  • Static: Select if you want to set the same string to all states on the switch. The label you define in the Label setting is applied for all states.

  • On / Off: Select if you want to set up different labels for the lamp variable's On and Off states. This label type is only available if you have selected Switch with Lamp for the Mode; see Section 9.2.1, Switch General Tab. The touch condition does not change the label.

When you select Static or On / Off as the Label Type, the following settings become available so that you can configure the text labels for the Switch.

Text Resource

Available when Label Type is On / Off.

Select the Text Resource you created in the Resource Library to use for the switch's Labels. For more information on using Resources in your parts, see Section 21.1.4.2, Selecting Resources for Your Part.

Language

Select the language that you want to set up the label for. For more information, see Section 20.2, Switching Languages.

Font Resource

Select the Font Resource you created in the Resource Library to use for the switch's Labels. For more information on using Resources in your parts, see Section 21.1.4.2, Selecting Resources for Your Part.

(ON/OFF) Label

Font

Select a font for the text.

Font Style

Select a style for the text, either Normal, Bold, or 3D. 

You can specify the text color and the 3D color used for the shadow of the text, see Section 9.2.2 Switch Color Tab.

Label Text Box

Enter up to 255 characters of text to be displayed on the switch for the touch state and lamp state defined in the State property.

  • When inputting multiple lines of text, the carriage return [Enter] also counts as a character.

  • Tabs are not supported by Editor or Runtime.

Font Size (Width/Height)

Set the text width and height.

Overwrite Text in All Languages

Available when multiple languages are set in the Language node. Overwrites the text in all languages with the text defined in the Label. For more information, see Section 20.2, Switching Languages.

Empty Languages Operation

Available when multiple languages are set in the Language node. Click the list box and select one of the following:

  • Text content only: Copies the text defined in the label and pastes it in the languages that have empty labels.

  • Text content, font, size, and style: Copies the text font, size, and style defined in the label and pastes it into the languages that have empty labels.

Alignment

 

Select the placement of the text. You can select a combination of horizontal and vertical alignments.
