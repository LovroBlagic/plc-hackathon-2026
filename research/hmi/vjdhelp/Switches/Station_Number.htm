9.5.13.1 Station Number

The Station Number operation is only supported for the XBTGH target machine that are connected to a Junction Box. The operation retrieves the ID of the Junction Box connected to the XBTGH target machine. Programmers can use this operation with an On Startup action to run actions and operations when the XBTGH is connected to a new Junction Box and restarted.

Return Value

Returns -1 if the operation is not supported by the target.

Returns integer value of 0-255.

  • The station number ID is defined by the Junction Box's Rotary Switches. For more information on the Junction Box Rotary Switches, see the Junction Box manual which is available from the Vijeo Designer DVD.

  • The Junction Box station number can also be retrieved using a script operation. For more information, see Section 18.9.1.5, System Methods: Sys.getInfoInt.
