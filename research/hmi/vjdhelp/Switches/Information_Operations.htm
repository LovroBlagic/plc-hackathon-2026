9.5.13 Information Operations

Use the dialog to set up Information operations. An information operation writes the requested system information value to a string or integer variable defined in the Destination field.

  • If the requested information is not supported on the target machine, integer operations return 0 or -1 and string operations return an empty string.

Property

Description

Information

Select the system information you wish to retrieve from the Target Machine.

  • Application Build Date (String)

  • Application Build Time (String)

  • Build Number (String)

  • Default Gateway 1 (String)

  • Default Gateway 2 (String)

  • DNS Address 1 (String)

  • DNS Address 2 (String)

  • DRAM Usage (Integer)

  • Free Main (Integer)

  • Free Optional (Integer)

  • Free Secondary (Integer)

  • HMI Application Checksum (Integer)

  • IP Address 1 (String)

  • IP Address 2 (String)

  • MAC Address 1 (String)

  • MAC Address 2 (String)

  • Project Name (String)

  • Station Number (Integer)

  • Subnet Mask 1 (String)

  • Subnet Mask 2 (String)

  • Target Name (String)

  • Target Type (String)

  • Version Number (String)

For Integer variables, if the value is higher than 32 MB, the function returns to 0. It is recommended that you use a DINT data type if the Integer value is higher than 32 MB.

Destination

The Destination variable's type must be the same type as the return value. Errors may occur during runtime if the variable types are not the same. See above for the variable type returned by each operation.

For string variables, make sure the Destination variable's Display Length is set to 100 to display all the characters. For system information values longer than 100 characters, only the first 100 characters are displayed.

 

  • For switches, Information Operations are only available from the When Touch tab.
