9.3.5 Selector Label Tab

 

The following table describes the Label tab properties for the Circular Selector, Vertical Selector, and Horizontal Selector.

Property

Description

Label Type

Select the type of Label from the Label Type drop-down list.

  • Disabled: Disables the Selector's labels.

  • User Defined: Define the Label for each of the States.

Location

This property is only available for the Vertical and Horizontal Selectors.

This property defines the location of the Labels for the Vertical and Horizontal Selector.

Vertical Selector

Horizontal Selector

Left

Top

Right

Bottom

 

Text Resource

Available when Label Type is Enabled.

Select the Text Resource you created in the Resource Library to use for the Selector's Labels. For more information on using Resources in your parts, see Section 21.1.4.2, Selecting Resources for Your Part.

State

This property specifies the state you are configuring the label for. Use either the drop-down list or the next and previous buttons to select the state. The number of states is configured in the General Tab, see Section 9.3.3, Selector General Tab.

Font Resource

Select the Font Resource you created in the Resource Library to use for the Selector's Labels. For more information on using Resources in your parts, see Section 21.1.4.2, Selecting Resources for Your Part.

Language

Select the Label's language. You can set up a different label for each user language. For more information, see Section 20.2, Switching Languages.

Font

Select the font from the Font drop-down list.

See Appendix 5, Hardware Specifications for more information on Vijeo-Designer fonts.

Font Style

Select the font's style: select Normal, Bold, or 3D.

Font Width

Select the font's width. The font widths available depend on the font selected.

Font Height

Select the font's height. The font heights available depend on the font selected.

Font Size

This property is only available for selected Fonts. Select the font's size.

Overwrite Text in All Languages

Available when multiple languages are set up in the Language node. Overwrites the text in all languages with the text defined in the Label. For more information, see Section 20.2, Switching Languages.

Empty Languages Operation

Available when multiple languages are set in the Language node. Click the list box and select one of the following:

  • Text content only: Copies the text defined in the label and pastes it in the languages that have empty labels.

  • Text content, font, size, and style: Copies the text font, size, and style defined in the label and pastes it into the languages that have empty labels.
