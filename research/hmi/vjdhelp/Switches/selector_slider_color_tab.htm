9.3.4 Selector Color Tab

Use the Color tab to define the color settings for the Selector's normal and invalid states.

 

Property

Description

Name

The Selector's name.

Names must be unique within the target, must contain no more than 32 valid characters, and must follow the naming conventions.

For details, see Appendix 9, Naming Conventions.

Indicator Style

Select the Indicator style from the Indicator Style drop-down list. Select Browse to open a Style Browser that contains a larger list of Indicators to choose from.

Image Resource

Available when Category is set to User Defined.

Select an image you created in the Resource Library to use as the background for the Selector. For more information on using Resources in your parts, see Section 21.1.4.2, Selecting Resources for Your Part.

Image

Available when Category is User Defined and Image Resource is set to Use Local Settings.

Set an image for the Selector's Plate Style. Click Browse and use the Open dialog window to select the image.

Color Resource

Select the color resource that you created in the Resource Library for the Selector.

For more information on using Resources in your parts, see Section 21.1.4.2, Selecting Resources for Your Part.

Category

The Category's drop-down list defines the Selector's Plate Style.

Select from:

  • Primitive
    Primitive allows you select the Selector's Plate Style from the predefined styles available in the Plate Style drop-down list.

  • User Defined
    User Defined allows you to select your own image as the Selector's Plate Style. Use the Image Resource property or the Image property to add the image to the Selector. For more information, see above for descriptions of the Image Resource property and the Image property.

Plate Style

Available when Category is set to Primitive. Select the Selector's Plate Style from the drop-down list. Click Browse to open a Style Browser that contains a larger list of Plate Styles to choose from.

Transparent Color

Available when Category is User Defined.

Set a color in the Selector's image to become transparent.

To make a color transparent:

  1. Select the Transparent Color check box.

  2. Click the color box to open the Color Palette.

  3. Select the color to turn transparent and click OK.

Color Settings

Specify the colors for the Selector's Normal and Invalid states. The properties for the Normal and Invalid states are described below.

Text Color

Defines the label's text color.

3D Text

Only available if 3D is selected for the Font Style in the Label tab.

Defines the 3D text's shadow color.

Indicator Fore

Defines the fore color.

Indicator Back

Defines the back color.

Scale Color

Defines the scale color.

Frame Color

Only available when the Plate Style selected has a frame.

Defines the frame color.

Plate Color

Defines the plate color.
