Select a pattern for the switch's Fore and Back colors.

When you select pattern 1:Solid, only the Fore Color displays. When you select a pattern other than 1:Solid, both the Fore Color and Back Color display.

If the Pattern is solid, the Back Color will not display.
When the Pattern setting is solid, only the Fore Color (in this case, green) displays as a solid pattern.

When the Pattern setting supports two colors, both the Fore and Back Colors (in this case, green and black) display a two-color pattern.

When Category is User Defined

The Style settings for the User Defined category vary depending on the mode you select. If your mode setting is Switch, you would create a 2-state switch. For a 2-state switch, specify an image for each switch state: down-on and up-off.

If your mode setting is Switch with Lamp, you would create a 4-state switch. For a 4-state switch, specify an image for each of the four states:

  • Switch variable ON (down), OFF (up), and

  • Lamp variable ON (down) and OFF (up).
