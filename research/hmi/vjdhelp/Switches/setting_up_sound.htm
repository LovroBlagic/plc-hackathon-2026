9.5.7 Sound Operations

Use the dialog to set up Sound-related operations. You can create an operation that performs the sound function (such as play, play repeatedly, or stop) for a specified sound file. This section describes how to select the options for the sound operation. For more information on sounds and the supported sound file formats, see Section 24.2, Target Machine Sound Files.

Select one of the following Sound operations:

Property

Description

Play Once

Play the selected sound file once.

Repeat Play

Play the selected sound file repeatedly.

Stop Sound

Stop playing the sound file.
